# 会戦

`dotnet run --project BattleSim -c Release 0 engage > docs/engage.md` の出力。手で編集しない。
各編成を3本の部隊列にぶつけ、それぞれ seed 0..199 の 200 試行。
投入部隊数 1〜3 は同一編成の複製（組み合わせは測らない）。

勝った部隊は生存駒の HP・最大HPの損耗・蘇生回数・墓守の層(-1) を持ち越して次の波と戦う。
状態異常（毒・燃焼・痺れ・標的・破片）と攻撃力の一時変動は波の境界で消える。

部隊列は3本。敵の中身はどれも既存5波のままで、並びと長さだけが違う。

- **順路**（5部隊） — 既存5波の並び順。第1期の基準
- **逆順**（5部隊） — 強い波が先頭。第1削り専用（突破数は第五波の独立勝率の測り直しにしかならない）
- **地点**（3部隊） — 順路の先頭3波。1地点の想定サイズ

### 表の読み方

- `突破率(n)` は n 部隊投入で列の全部隊を抜いた試行の割合。`期待突破数(n)` は抜いた部隊数の平均。
- `非線形` は 期待突破数(2部隊) ÷ (期待突破数(1部隊)×2)。**1.00 を超えるなら第1部隊の削りを
  第2部隊が拾えている**＝複数部隊制が噛み合っている証拠。期待突破数(1部隊) が列の長さに
  近い編成は ×2 が列の長さを超えるので、頭打ちで 1.00 を下回る（弱いのではなく測り切れないだけ）。
- `入場戦力` は各部隊戦に入る時点の味方の生存数と HP（**編成全体の定義上の**総最大HPに
  対する割合。死んだ駒の枠も分母に残るので、% は部隊の残存戦力を表す。生き残りの健康度
  ではない）。到達しなかった試行は分母から外し、到達率を併記する。1部隊投入の走行から集計する。
- `第1削り` は最初の Battle で敵の先頭部隊の総 MaxHp を削った割合。**勝てなくても削れる編成**
  （特攻隊）はここに出る。逆順の節にだけ載せる（順路・地点では第一波が全編成必勝で
  一律 100% になり無情報）。

## 地点（3部隊） — 標準の測定系

マップ上の1地点は敵1〜3部隊（design/concept_wave_engagement.md §7）。5波1本の順路では
全編成が突破 0% に潰れるのに対し、この列は部隊数を積むと突破率が 0〜100% に散る——
現時点で唯一、編成の序列として機能する分布なので主表とする。
