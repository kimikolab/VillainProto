# 会戦（5部隊連戦）

`dotnet run --project BattleSim -c Release 0 engage > docs/engage.md` の出力。手で編集しない。
各編成（味方1部隊）を既存5波の部隊列にぶつけ、seed 0..199 の 200 試行。

勝った部隊は生存駒の HP・最大HPの損耗・蘇生回数・墓守の層(-1) を持ち越して次の波と戦う。
状態異常（毒・燃焼・痺れ・標的・破片）と攻撃力の一時変動は波の境界で消える。

- `突破率` は5部隊すべて抜いた試行の割合。`独立積` は同じ seed 群で各波を独立に
  戦った勝率の積（＝持ち越しが無かった場合の理論全抜き率）。**この2列の差が会戦の効き目。**
- `第1削り` は最初の Battle で敵第1部隊の総 MaxHp を削った割合。**勝てなくても削れる編成**
  （特攻隊）はここに出る。突破 0 でもこの列が高ければ、第2部隊への繋ぎとして価値がある。
- `突破分布` は 0〜5 部隊抜きの試行数。「第2部隊で落ちる」と「第5部隊で落ちる」を区別する。
- `引分` は 30ターン到達（味方が退く扱い）の総回数。独立5戦では一度も起きないが、
  消耗した部隊同士は膠着し得るので数えている。
