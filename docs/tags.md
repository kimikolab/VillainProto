# 駒のタグ

`dotnet run --project BattleSim -c Release 0 tags > docs/tags.md` の出力。手で編集しない。表は `UnitTags`（`BattleCore/UnitCatalog.cs`・手で書く・`Id` で引く）。**表示だけで、どの規則も読まない。**

- 軸（何で働くか・1〜2 個）: 燃焼・毒・感電・呪い・移動・標・生贄・破片・自傷・手番
- 役割（隊の中で何をするか・1 個）: タンク・アタッカー・サポート・ヒーラー・付与・反応——「付与」＝ 状態を相手に付ける ／「反応」＝ 状態がある場面で強くなる
