# 活動量

`dotnet run --project BattleSim -c Release 0 pulse > docs/pulse.md` の出力。手で編集しない。
代表編成 × 全ステージ、seed 0..199。数字は**1戦あたりの平均**。

**`振/T` と `干渉/T` のズレが体験の密度を測っている。** どちらも1ターンあたりの回数。

- `振/T` は攻撃を振った回数（`PerformAttack` を通った回数）
- `干渉/T` は実際にダメージを通した回数。攻撃・反撃・破裂・毒のどれでも、
  その駒が起点になって盤面が動いた回数

| 形 | 読み方 |
|---|---|
| 振 ≒ 干渉 ≒ 1.0 | 自分の手番で殴るだけ。数値であって出来事ではない |
| 振 ≒ 0 / 干渉 大 | **反応型。** 手番を持たず、起きたことに反応して盤面を動かす |
| 振 大 / 干渉 ≒ 0 | **空振り。** 毎ターン振っているのに何も起きていない |
| 振 ≒ 0 / 干渉 ≒ 0 | 置物。発火条件が満たされていない |

分母は**戦闘の全ターン数**（その駒が生きていたターン数ではない）ので、
早く落ちる駒は下がる。`落ちた` 列と合わせて読む。

> **`干渉 0` は「価値が無い」ではない。** 呪詛（ネル）・萎縮（クビ）・庇い（ガルド）は
> ダメージを経由せずに盤面を変えるので、この列には最初から出ない。
> ここで測れるのは**体験の密度**であって貢献度ではない。
> 貢献度は `ablate`（抜いたときの勝率差）の側で見ること。
> この表だけを見て駒を消すと、静かに効いている駒から先に消える。

`与ダメ(味)` は味方に与えたダメージ。破裂・生贄・吸いはここに出る。
敵味方を混ぜて数えると、**味方を削ることで仕事をする駒が出力の大きい優等生に見える**。
`被(味)` は受けたダメージのうち味方由来のぶん。ここが `被ダメ` の過半を占める駒は、
敵ではなく編成に殺されている。
