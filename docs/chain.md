# 連鎖の深さ

`dotnet run --project BattleSim -c Release 0 chain > docs/chain.md` の出力。手で編集しない。
代表編成 × 全ステージ、seed 0..199 の 200 試行。全ステージ通算。
`連鎖深度`は1ターンで味方が倒した敵の数の最大値（全試行平均 / 最大値）。
`決着T`は勝利した試行だけの平均ターン数（短いほど速攻で畳んでいる）。

`残存`は**勝った試行だけ**の生存数（平均 / 出撃数）。**勝ち方の質**を測る列で、
低いほど「なんとか勝った」になる。勝率が同じでも、5体残して勝つ編成と
1体残して勝つ編成は別物だが、勝率表では区別がつかない。
`全滅勝ち`は生存1体での勝率（勝った試行のうち何%がぎりぎりだったか）。
