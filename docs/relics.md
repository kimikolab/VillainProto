# レリックの札と両端

`dotnet run --project BattleSim -c Release 0 relics > docs/relics.md` の出力。手で編集しない。札は `RelicCatalog.All`、両端は `RelicBridges`（`BattleCore/Relics.cs`・手で書く）。**両端は表示と作戦マップの候補の規則だけが読む——どの戦闘の規則も読まない。**

- 引き金 ＝ 何が起きると働くか ／ 効果 ＝ 何になるか。語は駒のタグ（`docs/tags.md`）。「誰でも」＝ その端はどの駒でも満たす

| 札 | 種類 | 引き金 | 効果 | 文 | 何を何に変えるか |
|---|---|---|---|---|---|
| 軋む足 | 繋ぎ | 移動 | 誰でも | 動かされるたび攻撃力 +2 | 移動 → 火力（ヨミの軋みの汎用化・割り込みは無い） |
| 火付けの矢 | 繋ぎ | 誰でも | 燃焼 | 攻撃が当たった敵に火を点ける（燃焼） | 攻撃 → 燃焼 |
| 毒の足跡 | 繋ぎ | 移動 | 毒 | 動かされるたび、向かいの敵（自分のレーンの最前）に毒 1 | 移動 → 毒 |
| 弾性 | 繋ぎ | タンク | 移動 | 敵に殴られると、殴った敵を自分のレーンで1つ後ろへ弾く（既存の弾き返しの札そのもの・弾かれた敵は転倒する） | 被弾 → 敵の移動（ハネの弾き返しの流用） |
| 萎える心 | ゴミ | 誰でも | 呪い | 敵に殴られて削られると攻撃力 −2 | 読み手: ウツ（逆しま・弱体を強化に逆転） |
| 痺れる足 | ゴミ | 移動 | 手番 | 動かされると次の手番を失う（転倒） | 読み手: ガン（号令・目覚まし＝手番を失った味方を買い取る） |
| 身を固める | 変換 | 誰でも | タンク | 開戦時に素の攻撃力 × 3 を最大HPに足し、攻撃力は 0 になる | 壁・挑発役化（攻 → HP） |
| 帯電の足 | 繋ぎ | 移動 | 感電 | 動かされたとき自分が感電していれば、向かいの敵（自分のレーンの最前）に感電を付ける | 移動 → 感電 |
| 押し毒 | 繋ぎ | 毒 | 移動 | 毒を帯びた敵を殴ると、その敵を自分のレーンで1つ後ろへ押す（後ろの駒とは入れ替わる） | 毒 → 敵の移動 |
| 溢れの刃 | 繋ぎ | ヒーラー | 誰でも | 回復が溢れた（最大HPで切られた）分だけ、そのターン攻撃力 +同値 | 回復 → 火力 |
| 勢い余り | 繋ぎ | 誰でも | 移動 | 敵を倒すと、隣の味方（席番号の小さいほう）と入れ替わる | 撃破 → 移動 |
| 毒を招く | ゴミ | 毒 | 毒 | 受ける毒の層が 2 倍 | 読み手: ベニ（結界の中では毒の刻みが回復）・ヴィオ（味方の毒を吸って攻撃力と腹に変える） |

12 枚（両端の無い札 0 枚）。
