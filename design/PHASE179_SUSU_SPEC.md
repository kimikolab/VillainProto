## 0. なぜこの駒か

自傷を持つ軸（燃焼・反撃・毒漏れ・破裂）は、敵のダメージに加えて自分のダメージを払うので、他の隊より最初から不利。
うまくいっている軸には**自傷を食う変換器**がいる（カドの巻き込み → ムド・ドハ／毒漏れ → ベニ・ヴィオ）。
**燃焼軸には変換器が1枚もいない**（ヒヨは燃えている味方を強めるだけ）。第178期でホタの死因の 69% が敵の攻撃と出たので、
回復で耐える方向ではなく、**自傷の総量を敵全体への火力に変えて殲滅を速くする**方向で解く（ポンの決定）。

## 1. 拾い屋のスス

| | 中身 |
|---|---|
| 数値（仮） | HP 64／攻 3／速 6／単体／据置 |
| 常時 | **味方が味方から受けたダメージ**を、その量だけ**灰**として溜める（上限なし。戦闘が終われば 0） |
| 手番 | **灰を投げる**：溜めた灰の量ぶん、**敵全体**を撃つ（攻撃力は乗らない。通常の `ApplyDamage` を通す＝軛で切られる・庇いは Single でないので素通り）。投げたら灰は 0。**灰が無い手番は攻3の通常攻撃** |
| マイナス | **灰を溜めたまま倒れると、その灰が隣接する味方に降る（等分）。** 敵から受けたダメージは灰にならない |
| フレーバー | 誰かの後始末ばかりで、自分の手柄になったことが一度もない。だから投げ返す先を敵に変えた。 |
| 枠 | **裂きのキリと入れ替え**。キリは `UnitCatalog` に残し、`All`／`Presets` から外す（対照として残置。第164期の作法） |

### 1-1. 「味方が味方から受けたダメージ」の範囲（Phase 0 で確定して報告書に書く）

数える: ボルグ・カドの巻き込み／ゾトの破裂／ナラの削り／燃焼・毒の削り（tick）／リィカの生贄／ゴルムの吸い／ヒビの受け増し分 など、
**`ApplyDamage` の `source` が味方**であるもの、および **`source` が無い継続ダメージ**（燃焼・毒の tick）。
数えない: 敵が `source` のもの。惨禍（カド）による 1.5 倍の増分は**数える**（既定）。

ノブ: `AshRule.CountHavoc`（既定 true）／`AshRule.CountDot`（既定 true）／`AshRule.Multiplier`（既定 1.0）／
`AshRule.FalloutOnDeath`（既定 true。**マイナスを 0 にする対照**）。
**`AshRule` は `Run` の引数を増やさず、既存の規則の束にフィールドとして足す**（第154期・第178期の作法）。

### 1-2. 画面

- 灰の量を駒の上に常時表示（ガレの破片と同じ見せ方。数字1つ）
- 投げた瞬間は敵全体に飛ぶ絵（既存の全体攻撃の再生で足りるはず。足りなければ `Attack` の型を全体にするだけ）
- 演出の本番は Codex の担当。この期は数字が読めれば足りる
