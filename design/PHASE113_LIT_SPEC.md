# 第113期 —— 灯の対象選択（Phase 0 に (G14) の波及調査を畳む）

起点: 第110期で譲渡条件を V1（窓）にしたが、**穴は譲渡の側になかった**——
`トモ×ハギ` は段1（敵の死の通知）が 0.13〜0.90 回/戦しか来ず、**ハギは自分の手番に1度も振らないので撃破の起点を持たない台**だった。
段3 の `CanReact` 1.59 は全部ドルガ（のろま）。**「最も遅い味方」を選ぶ機構は、遅い層に集まる
「手番を使わない駒」に構造的に当たる。** 第111期でトモは `Presets.Compare` に入った（`灯×薙ぎ (トモ×ドルガ)`）ので、
**この期から拒否権が立つ状態で測れる。**

**この指示書は自己完結させてある。** 規約は `CLAUDE.md` の規約節（(G1)〜(G14)）。

## 0. 主題

### 0-1. 現行の対象選択（実装から引いた。`TaillightTrait.OnTurnStart`）

> **自分を除く生存味方のうち `Def.Speed` が最小。同速は `Slot` 昇順（`PickOne` を使わない）。
> `AcceptsSupport` は自前で濾す**（支援拒否の駒が最も遅い側にいたら飛ばして次へ）。

濾しは `AcceptsSupport` の1つだけ。**「灯を受け取れるか」は見ているが「灯を使えるか」は見ていない。**

### 0-2. 灯が無駄になる3つの形

| 形 | 駒 | 何が起きるか |
|---|---|---|
| **(A) 自分の手番に振らない** | ハギ（`Pursuer`）・カド（`Immobile`）ほか `CanAct` 偽の駒 | 灯（`AtkBonus`）はターン外の攻撃には乗るが、**譲渡した手番は丸ごと潰れる** |
| **(B) 手番を攻撃に使わない** | `Actions` が `Skill` の駒（ノノ・ミオほか） | 灯は攻撃力なので**術には乗らない**。譲渡も術1回に化ける |
| **(C) 休み番がある** | ドルガ（`Sluggish`） | **偶数ターンは `CanAct` 偽**。灯は乗るが、譲った手番の半分は捨てる |

**(A)(B) は恒久（駒の性質）、(C) はターンごとに変わる。** 濾しの版を分けるのはこの区別に沿う。

### 0-3. 測る版（**灯の対象は「最も遅い味方」のまま。濾しだけを足す**）

**「最遅を照らす」を捨てない。**尾灯というフレーバーと、「遅いから捨てられた駒を主役にする」という
軸そのものがそこにあり、`攻撃力が最大の味方` に変えると**ただの汎用強化**になる（第46期の「性質を切るノブは
律速の項に付けないと強度ノブに落ちる」の同型）。

| 版 | 濾し | 埋める穴 |
|---|---|---|
| **W0 現行** | `AcceptsSupport` のみ | —（対照） |
| **W1 手番型に限る** | ＋**恒久的に手番で攻撃しない駒を飛ばす**（(A)(B)）。飛ばした先の「次に遅い駒」へ | (A)(B) |
| **W2 その場で振れる駒に限る** | W1 ＋ **そのターン `CanAct` が偽の駒を飛ばす**（(C)） | (A)(B)(C) |

**W1 の判定は駒の定義から引く**（`CanAct` を実装で常に偽にする特性を持つ／`Actions` が `Skill` だけ）。
**W2 の判定は毎ターン `OnTurnStart` の時点で引く**——ここが分岐台。

> **W1 と W2 は「静的な濾し」と「動的な濾し」の対比であって、強さの大小ではない。**
> W2 は毎ターン対象が動きうるので、**灯の累積が切れる回数（`TaillightSwitches`）が増える**はず。
> **「濾しを厳しくするほど良い」なら W2 が最良になり、そうでないなら累積が効いている証拠になる。**

### 0-4. この期で触らないもの

- **譲渡条件**（V1・窓のまま）。V2（即時）は残置のまま測らない
- **`Lumen = 5`・速さ・HP・攻撃力**
- **同速の解決**（`Slot` 昇順のまま。`PickOne` を増やさない）
- **`Presets.Compare` / `Presets.Cross` の行**（第111期に閉じたばかり）

## 2. 実装

`TaillightRule` に**濾しのノブ**を1つ足す（第110期に足した `TaillightImmediate` と同じ形。**static にしない**）。

    enum LitFilter { SupportOnly /*W0・既定*/, ActingOnly /*W1*/, ActingNow /*W2*/ }

- **既定は `SupportOnly`**。**W0 の経路は1文字も変えない**（自己検査 (a) で `compare` 305 セルを示す）
- 濾しは `OnTurnStart` の候補ループの `continue` 条件に足すだけ。**選び方（速さ最小・同速は `Slot` 昇順）は触らない**

- **W1 の (A)(B) の判定は駒の定義から**（`UnitDef` と特性の型）。**戦闘中の状態を読まない**——読むと W2 との差が消える

**方向だけ書く**（上限にも下限にもならない）。

## 4. 予測（**測る前に書く**）

1. **W1 でハギ台の潰れが 0 になる**（(A) の濾しが効く）。ただし**帰属はほとんど動かない**——
   ハギ台は段1（死の通知）が 0.13〜0.90 回/戦しか来ないので、**譲渡の質を上げても量が無い**
2. **W2 の替が W1 の 1.5 倍以上**。ドルガは1ターンおきに濾しに掛かるので、**主判定行では毎ターン対象が振動する**
3. **主判定行の帰属は W1 > W0、W2 < W1**。W2 は替で灯の累積（到達点 +15〜30）を失う
4. **Q6 は W2 で危うい**——「そのターン振れる駒の最遅」は速さ順の下位2枚を往復するだけになる可能性がある
5. **拒否権は 60 行とも ±0.0**（トモは1行にしか居ない）

**予測が外れた項目は、外れた理由を「何を数えていなかったか」の形で報告書に書く**（第109期の反省）。

## 6. 結論の書き方と分岐

報告書 `design/PHASE113_LIT.md` の冒頭に、**1つの引用ブロック**で Q1〜Q6 の○×と、採る版を1行。

- **Phase 0 の P-4 が 3 行以上**: **この期を席の期に切り替える。**灯の対象選択は第114期へ送る。
  席の期の中身は「P-3 の代替席を帯A で追試し、差 5.0pt 未満なら情報セルの多い側を採る」。**(G14) の波及が本体**
- **W1 が Q1・Q2 を通り Q5 を落とさない**: **W1 を採用**。W0・W2 はノブで残置。§3-3 の席を測り直す
- **W1 が Q1 を通るが Q2 が下がる**: **採らない。**「灯は使えない駒に乗っても損ではない」＝
  **灯の価値は譲渡ではなく `AtkBonus` の累積にある**という結論になる。これは第110期の
  「V2 が埋めるはずだった穴は譲渡の側になかった」と同じ向きで、**譲渡機構そのものの再検討**を第114期に立てる
- **W2 が W1 を上回る**: W2 を採用。ただし **Q6（対象の分布）が 2 枚未満なら採らない**——
  振動するだけの機構は「配置と編成を考えさせる」に反する
- **どれも W0 を上回らない**: **W0 のまま。**対象選択は「灯の側では直せない」と確定し、
  第114期は「被害で育つ駒 × 死なない駒」へ移る
