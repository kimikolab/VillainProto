## 2. (S2) ムドの再判定（**2つめのコミット**）

### 2-1. 較正をやり直す（**測る前に書く。数字を見てから選ばない**）

**現行（`Amount`）の実測**: `AtkBonus` の到達点 **33**（攻3 → 攻36）。**被弾 7.21 回/戦**（第96期）。

    33 ÷ 7.21 = 4.58  →  丸めて **+5**

> **`+5` は較正から導かれる値であって、測った結果から選んだ値ではない。**
> **第106期が対照として `+5` を測っているので、循環を避けるために
> seed 帯を変えて測り直す**（第89期 (P1) と同じ作法）。

**`RageRule.Mode = Count` のとき、殴られた回数ごとに攻撃力 +5。**

### 2-2. 判定

> **Q1: ムドを含む行の第2〜5波平均が現行より上がること。**
> **Q2: `AtkBonus` の到達点が現行（33）と ±3 以内であること。**
> **総量を変えず速度だけを変えるのがこの変更の目的**なので、**到達点が動いたら較正が違う。**
> **Q3: `+24` への到達ターンが現行（2.69T）より早いこと。**

**拒否権（分母 = `compare` 61行全体。第91期 (G1)(G2)）は従来どおり。**
**第106期の `+3` は拒否権が 3 行立った。** `+5` で立たないかを確認する。

**規約 (G10): 分母は第2〜5波。第一波は参考。**

### 2-3. 落ちた場合

**「量で育つ」のままで確定する。** ムドは**保留ではなくなる**——
**第106期で「育つ前に落ちる」が実測で否定された**ので、**現行の形が正しかった**ということ。
**ビジュアルは現行（被弾で育つ・攻3→36）で確定してよい。**

## 3. (S3) ハリ（**3つめのコミット**）

### 3-1. 律速は3期にわたって同じ

| 期 | 実測 |
|---|---|
| 第83期 | 3分の器具で**唯一「切れる」判定** |
| 第85期 | 両側読み（味方の傷も読む）を足して救えず。**律速は振り回数 2.15 回/戦** |
| 第106期 | **第104期の再行動が 0.00 回/戦しか届かない**——**再行動は傷の書き手にしか渡らず、ハリは読み手** |

**`SutureTrait` の発火は2つの条件の積**——**手番があり、かつ殴った相手に傷があること。**
**手番が 2.15 回しか回らない**うえに、**そのうち相手に傷がある回だけ**。

### 3-2. 第105期が答えを示している

> **回復の 90.3% は手番の外から出る。**

**ハリは回復を出す駒なのに手番型で、それがロスターで例外的な形だった。**

> **発火口を手番の外へ移す。**

### 3-3. 形（**測る前に固定**）

```csharp
public enum SutureFire { Swing, OnWound }
public readonly record struct SutureFireRule(SutureFire Fire)
{
    public static SutureFireRule Default => new(SutureFire.Swing);   // 現行。測定中はここ
}
```

**`OnWound` のとき、`SutureTrait` は「傷が書かれたとき」に発火する。**

- **`BattleContext.Wound`（第93期の窓口）が実際に傷を書いたときに走る**
- **糸口の選び方は現行のまま**（両側読み・第85期採用）。**`SutureRule` を触らない**
- **1ターン1回まで。** 傷の書き込みは **8.4 回/戦**あるので（巻き込み則 8.09 ＋ 刻み 0.28 ＋ 裂き 0.07・
  第93期）、**上限が無いと発火が4倍になる。1ターン1回なら決着ターン数ぶん＝2.5倍**
- **ハリの手番は通常攻撃に戻る**（攻10）。**手番外型になり、出力も増える**
- **`ctx.Heal` を経由する**（渇きに課税されることは第39期の設計意図）
- **`ctx.PickOne` を使わない**（第89期 (h)）

### 3-4. 判定

> **Q4: ハリの発火回数が 2.15 回/戦を上回ること**（**律速が外れたかの直接の確認**）。
> **Q5: ハリを含む行の第2〜5波平均が上がること。**
> **行名を `Presets.Compare` から引いて数え直すこと。**
> **Q6: 第105期の器具（`tempo`）で、ハリが手番外型に移ること。**

**拒否権は従来どおり。** **回復が増えるので、耐久系の行が天井に張り付かないかを見る**
（規約 (G9) により拒否はしないが**記録する**）。

### 3-5. 落ちた場合

**ハリを切る判断の材料が揃う。**
**この期では切らない**——ロスターは 52 枚で確定しており、**切るなら代わりが要る。**
**「発火口を移しても救えなかった」と記録し、第108期以降の入口にする。**
