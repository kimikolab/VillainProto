## 実装の形（測る前に固定）

- **札3枚**（どれも保持者 0 枚・規定のミオは M5 のまま）: `MireBurst`（B1）・`MireBurstStack`（B2）・`MireBurstAll`（B2x）。版は M5 の札に1枚を足すだけ。**`Run` の引数は増やさない。**
- **量**: B1 ＝ 毒の層 ÷ 2、B2 ＝ **毒の層 ×（1 ＋ 印）÷ 4**——**切り捨ては最後に1回**（`毒 ÷ 4` を先に切り捨ててから掛けると、毒 3 層以下は印がいくつあっても 0 になるので）。毒と印は**倒れた瞬間の値**。量が 0 なら爆ぜない（数える）。
- **窓口**: `HandleDeath` の「印の移り」の位置で `EnqueueBurst`。**幅優先**（連鎖の最初の死が列を回し、爆発で倒れた駒は列の後ろ・隣へは席番号の順に当てる）。**1つの駒は1回しか爆ぜない**（蘇生されても）。倒れた駒ごとに ①爆ぜる → ②印が隣へ移る（M5・生き残った隣へ）。
- **爆発は状態異常のダメージ**: `ApplyDamage(隣, 量, 倒れた駒, isFriendlyFire: true)`——棘・板の反射は鳴らず（相手陣営の一撃にしか返らない）、粛の窓口を通らない。**燃焼の脆さは乗る**（経路 8「澱みの爆発」）。**撃破は連鎖の最初の死を倒した一撃の主**（放電と同じ札 `_shockKiller`）。HP に届いた隣が感電していれば既存の規則で弾ける。
- **B2x の味方側**: 隣がベニの結界の内側なら反転で回復（`InverseHeal` の kind 4・放電と同じ口）。
- **乱数を引かない**。札が無ければ比較1つで抜ける。
- **台本**: `BattleEventKind.MireBurst`（隣1体ごと・どこから `SpreadFromId` → どこへ `TargetId`・量・段 `Slot`・印・脆さの分 `BrittleExtra`・反転なら `InverterId`）、直後にその駒への `Damage`。最初の爆発ごとに見せ場（`Highlight`）の1行。

## 予測（Phase 0 の後・実装前にコミット）

- **P1**（回帰）: B0 は前段と `compare` 305 セル全文一致・台本も一致。**印を持つ駒が倒れない戦は B1〜B2x で台本ごと一致**。ラウだけの2行は 0 セル。
- **P2**（決着）: **`compare` はほとんど動かない**——ミオのいる5行のうち4行は既に全波 100%、`刻み×澱み` は倒れた敵の毒が 1〜2 層で B2 でも1発 1 前後。**動くセルは 0〜3（すべて `刻み×澱み`）**。
  台では**決着ターンが縮む**: 倍率 200 の R1〜R4 で B2 は B0 より **−0.2〜−0.8 T**、B1 はその半分以下。**倍率 200 の勝率は R1 P2・R4 X字・R4 P2（B0 で 70〜82%）で B2 が +5pt 以上**。
  **ラウの台（R1・R2）の上げ幅は R3・R4 より大きい**（倒れた瞬間の毒が2倍）。
- **P2'**（連鎖の長さ）: 倒れた瞬間の隣は平均 1.2 体・35% が 0 体で、1発は敵の HP（倍率 200 で 50〜200）に比べて小さい（B2 で 15〜50）。**雷の台では 2 体以上が爆ぜる連鎖は連鎖全体の 25% 未満**。`毒` の行（1発 100 前後）では 40% 以上。
- **P3**（段）: 指示書の P3（**連鎖の後ろほど大きい**）には**逆を張る**——**移りは爆発の後で、生き残った隣にしか移らない**ので、爆発で倒れた隣（次の段）は外側の印を受け取らない。**段 2 以降の1発の平均は段 1 以下**。
  育つのは**連鎖の中ではなく戦の中**——**戦の後の連鎖ほど1発が大きい**（2本目以降の連鎖の1発の平均が1本目より大きい）。
- **P4**（ラウ）: 同じ死で「印の移り」と「疫み」が重なるのは B0 で既に1戦 1.3〜3.8 回（Phase 0）。**B2 では R1・R2 の1発の平均が R3 の 1.5 倍以上**（毒が2倍・疫みが生き残った隣に毒を足してから次の死が来る）。
  **ラウが弾く感電は B2 でも1戦 0.2 回未満**（ラウはほとんど振らない）——ラウの仕事は「弾く」ではなく「燃料を積む」。
- **P5**（B2x）: **味方側の爆発はほとんど起きず、B2x は B2 と ±2pt 以内**（倒れた味方の毒は 0〜1.6 層）。指示書の P5（B2x で勝率を下げる台が出る）には**逆を張る**——出るとしても `compare` の毒の行（味方の毒 3〜6 層）で、雷の台 R1〜R4 では出ない。
- **P6**（雷と澱みの交互）: 爆発で弾けた感電は1戦 0.5 回未満（感電は先に弾かれていて、倒れる頃に残っている隣は少ない・R322 の続き）。**連鎖の最初の死が放電で倒れた割合は 20% 以上**（放電が倒した敵が爆ぜる向きのほうが多い）。

## 判断の材料（ポン向け・線は置かない）

1. **ポンの絵「敵が爆弾のように連鎖して消えていく」**: 爆発そのものは**倒れた敵のほぼ全員**で起きる（1戦 4.4〜5.0 回）。ただし**1本の連鎖で2体以上が爆ぜるのは 1〜4 割、3体以上はまれ**——倒れる瞬間の隣が平均 1.2 体しかいないから。
   **絵として見えるのは「後から倒れる敵ほど大きく爆ぜる」**（1本目の連鎖 3〜10 → 3本目 17〜114）。「次々に誘爆する」より「だんだん爆発が大きくなる」。
2. **B1 と B2 は勝率ではほぼ同じ**（どちらも燃料があれば爆ぜる）。**B2 は1発が 2〜3 倍大きく、決着をさらに 0〜0.4 ターン縮め、後半の爆発が派手**。
3. **ラウは雷の編成で「弾く役」にはならない**（1戦 0.01 回）。**燃料を積む役**で、爆発の1発を 1.3〜1.7 倍にする。弾く役を足したいならトウ・クビのいる台（R1・R4）のほうが爆発で感電を弾く（1.0〜1.6 回）。
4. **B2x（味方側でも爆ぜる）は雷の編成では何も起きない**（味方の毒が 0〜1 層）。代金として効くのはカタのいない毒の行だけ。
5. **`compare` はほぼ動かない**（ミオの行は既に天井）——この版の値打ちは台の決着の短さと全員生存で出る。
