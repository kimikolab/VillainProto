## 0. 出発点

第16期で3つ決まった。

**(1) 片側だけの特徴量は、交互作用成分と構造的に相関しえない。**
`|r| = 0.000000` は恒等式（交互作用の残差は行にも列にも和が 0）。第12期以来ずっと、**全分散の 28% を占める成分に、原理的に手が届かない道具で測っていた**。「予測できない」が14期分繰り返されたのは、現象ではなく測定設計の問題だった。

**(2) 骨格は2つの時計。**
勝敗は「味方が削り切るまで」と「敵に削られ切るまで」の競走で、波はこれを別々に動かす。編成は **甲群（出力が時間で育つ）/ 乙群（出力が一撃圏に縛られる）** に割れる。第6〜7期の原理は「個体HP と体数」ではなく **「個体HP と総攻」の2軸**に訂正された。

**(3) 真の障害が1本に絞られた。**
**`総攻` が反撃軸・毒軸の出力を桁で外している。** 溜め改は S4 で打点の 78% が手番外（カドの反撃）から出て、毒軸は `総攻` 20〜22 で毎ターン 45〜127 を削っている。甲群も乙群も式に「味方の出力」を持つのに、**静的に使える出力量が `総攻` しかない**。

**14期分「地力が測れない」と言い続けた原因が、ここに集約される。** `総攻` は手番の攻撃しか表しておらず、反撃・毒・破裂・反射というこのゲームの主要な出力経路がまるごと抜けている。

## 1. この作業の狙い

**編成の「出力の実体」を、目的変数から独立に測る特徴量を作る。**

**循環に注意。** 目的変数（波ごとの勝率）と同じ戦闘から出力を取ると、第14期の同語反復と同じ問題になる（敵を削り切ることが勝ちなので、その戦闘での与ダメは勝率の言い換え）。

したがって **固定の参照台で1回だけ測り、その値を全波に対する特徴量として使う。**

## 3. Phase HA — 参照台

### 3-1. 要件

参照台は**編成の出力を測るための的**であって、勝敗を測る場ではない。要件はこう。

1. **全編成が同じ条件で殴れること。** 特定の編成だけが有利／不利にならない
2. **決着しないこと（または十分長いこと）。** 早く倒してしまうと「出力が時間で育つ」甲群の値が取れない。**甲乙の分割そのものが時間の話**なので、時間を確保する必要がある
3. **中立であること。** 波の性質が特徴量に混入しない

### 3-2. 設計案

**単一の def を並べただけの的**を作る。既存の def から選ぶ（新規作成しない）。

- **硬さ**: 決着しない、または `MaxTurns`（30）近くまで持つだけの総HPが要る。`Warden`（145/12/3）を6体並べれば総HP 870
- **返り討ち**: 敵が強すぎると味方が先に全滅して出力が取れない。**逆に敵が全く殴り返さないと、被弾駆動の出力（反撃・被弾強化・自傷）がゼロになり、甲群の出力が測れない**

**ここが設計の核心。** 「殴られること」で出力する編成があるので、**殴り返さない的では反撃軸の出力が 0 になる**。かといって殴り返しが強すぎると味方が落ちて時間が取れない。

推奨: **硬くて攻撃力が低い的**（例: `Warden` を並べるが、可能なら攻撃力の低い def を使う）。**どの def をどう並べたか、なぜそれを選んだかを必ず書く。**

### 3-3. 中立性の確認（必須）

**性質の違う参照台を2種類作り、編成の出力の順位が一致するかを確認する。**

- 一致する（順位相関が高い）→ 出力は台に依存しない量。**単一の特徴量にしてよい**
- 一致しない → 出力は台に依存する量で、**単一の特徴量にはできない**。その場合は**止まって報告する**（何を測るべきかが変わる）

2種類の台は、**要件を満たしつつ性質が違う**ものにする。例: 少数高HP と 多数中HP。**判定基準として、第13期の半割（補正後 0.99 前後）を上限に使う。**

### 3-4. 受け入れ条件

- 18モード差分ゼロ
- 台の定義（def / 体数 / 配置）と選定理由
- 2台間の順位相関と、半割の上限

## 4. Phase HB — 出力特徴量

### 4-1. 測るもの

**(A) 実効打点/ターン**
参照台での「敵に与えた総ダメージ ÷ 決着ターン数」。**第13期の受け手側測定をそのまま使う**（敵の `DamageTaken` 合計 − 敵の `TakenFromAlly`）。毒・燃焼・反撃・破裂、どの経路も漏れなく入る。

**(B) 立ち上がりの傾き**
甲乙の分割が「出力が時間で育つか」なので、**1本の数字では足りない**。T1 / T3 / T5 の累積打点を取る。

- 甲群（時間で育つ）→ 凸。T5 の増分が T1 より大きい
- 乙群（一撃圏に縛られる）→ ほぼ線形

**傾きの表し方は実装者判断でよいが、明記すること**（例: `T5の増分 ÷ T1の増分`、あるいは T1〜T5 の累積打点に対する二次項）。**甲乙の分割を数値化できているかが判定基準。**

**(C) 被弾駆動比**
参照台で、**手番の攻撃以外から出た打点の割合**。溜め改の 78% がこれ。`総攻 × 手番数` を引いた残りで近似できるはず。**近似の方法を明記する。**

### 4-2. やり直すこと

出力特徴量を加えて、**第14期・第15期・第16期の分析を順にやり直す。**

1. **第16期 GB の交互作用項**: 積の材料を `総攻` から **(A)** に差し替える。**`|r| = 0.000000` は恒等式なので片側だけでは依然 0 のまま**——**積にして初めて意味を持つ**。ここを取り違えないこと
2. **第15期 FB の波ごとの分解**: 目的変数は波ごとの単発勝率。第一近似が `総攻` や `与ダメ効率` から (A)(B)(C) に替わるか
3. **第16期の甲乙の分割**: (B) で甲群と乙群が数値的に分離できるか。**12事例の分類と一致するか**

### 4-3. 判定

| 観測 | 結論 |
|---|---|
| (A)(B)(C) を材料にした積で交互作用成分の説明力が上がる | **16期分の壁の原因が `総攻` だった**ことが確定。特徴量が揃ったので、ステージ設計に使える |
| 波ごとの説明力は上がるが、交互作用成分は上がらない | 出力は測れたが、**交互作用は出力では説明できない**。別の成分がある |
| (B) で甲乙が分離できない | 第16期の分割は人間の解釈であって、**数値的な実体が無い**可能性。そう記録する |
| どれも上がらない | 出力の測り方が悪いか、参照台が中立でない。**§3-3 の中立性の結果と突き合わせて報告する** |

### 4-4. 受け入れ条件

- 18モード差分ゼロ
- (A)(B)(C) の定義と、近似を使った箇所の明記
- 第14〜16期の値との対比表
- **積の候補は第16期と同じく10個以内。総当たり禁止**
