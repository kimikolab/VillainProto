## 1. 足すもの

### 1-1. 隊の「勝ち筋の一行」

左の部隊パネルの隊名の下に、**その隊がどうやって勝つか**を1行で出す。

- 書式: **「誰が何をして、どう勝つか」だけ。** 弱点・向いている道は書かない（案B）
- **ターン外の行動（反撃・追撃・割り込み）で勝つ隊は、その言葉を必ず入れる**
  ——敵の表示「粛（ターン外の行動が止まる）」と**同じ語**で書く。プレイヤーが2つを結べるのは語が同じときだけ
- 同様に、回復で保つ隊は「回復」、1発の大きさで勝つ隊は「1発」の語を入れる（渇き・軛の括弧書きと揃える）
- **下書きは Claude Code が `compare` の行の注記・特性の実装から起こし、報告書に3本並べる。ポンが直す前提**

### 1-2. 駒の「何をする駒か」の一行（15 枚ぶん）

「この隊の中身を見る」の各駒に、**特性の説明を1〜2行**出す。

- **手書きしない。** 既存の元データ（`docs/units.md` を生成している特性の説明・`UnitDef` のフレーバー）から引く。
  どこから引いたかを報告書に書く。元データに無い駒があれば名指しする
- 既存の「送り先の一行」（カド・ハネ・ゴルム・バサの4枚）は**別の行として残す**（見出しを分ける:「何をする」／「どの道で」）
- 数値（HP・攻・速）と席も出す

### 1-3. 敵部隊の中身

右のパネルの敵部隊を選ぶと（または接敵ダイアログで）、**敵の並び（席・名前・HP・攻・速）と特性の説明1行**が読める。

- 波ルールの保持者には印を付け、「**この駒が倒れるとルールが消える**」と出す（第110期・第118期の設計どおりの事実）
- 用語は**括弧の中を主、名前を従**にする: 「ターン外の行動が止まる（粛）」の順に入れ替える

### 1-4. 戦闘の後の1行（案B の本体）

戦闘からマップに戻ったとき、結果の下に**盤面ルールが実際に何をしたか**を1行で出す。`BattleResult` の帳簿から引くだけ。

| ルール | 出す文（味方側の数字だけ） | 引く場所 |
|---|---|---|
| 粛 | 「ターン外の行動が **N 回**止められた」 | `BoardRuleLedger.HushBlocked[味方]` |
| 渇き | 「回復が **N 回**（計 M 点）通らなかった」 | `DroughtHits` / `DroughtEffective`[味方] |
| 軛 | 「1発が 25 で切られた: **N 回**（計 M 点ぶん）」 | `YokeLedger` の味方側 |
| 保持者 | 「ルールの保持者は **t ターン目**に倒れた」／「最後まで倒せなかった」 | `HolderFallTurn` |

- **N が 0 のルールは出さない**（出すのは起きたことだけ）
- 評価の言葉（「相性が悪い」「送り先を間違えた」）は**書かない**。数字だけ

### 1-5. 小さい直し

| 項目 | 中身 |
|---|---|
| 操作の案内 | 初回だけ、部隊パネルの上に「① 隊を選ぶ → ② 道を選ぶ → ③ 接敵したら戦う／引き返す」を出す。「この隊の中身を見る」に気づかれなかったので、隊を選んだら中身のパネルを**最初から開いておく** |
| 戦闘ごとの記録 | 「出した順」をやめ、**戦闘1回につき1行**（何戦目／隊／道・何番目の敵／勝敗／残り枚数と HP）。結果画面と、マップ上の履歴の両方に出す |
| 生存枚数 | 結果画面は「**盤上に残った枚数／未出撃を含む全体の枚数**」の2つを名前を付けて出す |
