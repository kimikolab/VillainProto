# 第102期 —— 境界に選択を置く（蘇生・回復・持ち越しから1つ）

起点: 第101期（`RecoverRule` を掃引・**持ち越しの代金は HP ではなく体だった**・
毎境界まるごと全快でも突破率 0.97 → 5.81%・**帯までの距離の 91% を死者の側が持っている**・
**帯は R100 と RFull のあいだにある**）

**この期は駒・特性・数値・戦闘中の判定に触らない。** 触るのは**会戦の境界の規則**だけ。

**この指示書は自己完結させてある。** リポジトリの外にある文書を参照しないこと。

---

## 0. 主題

### 0-1. 境界がしている3つの処理を、1つだけ免除する

`EngagementEngine.CarryOver` は境界で3つのことをしている。**それぞれが別の通貨の代金**である。

| 境界がしていること | 免除すると | 通貨 |
|---|---|---|
| 死者は戻らない | **蘇生** | **体** |
| HP は削られたまま持ち越し | **回復** | **HP** |
| `AtkBonus` と状態異常を全消し | **持ち越し** | **積み上げ** |

> **新しい機構を1つも作らない。「3つの罰のうち1つだけ免除する」形にする。**

第101期で **通貨が3つとも実測された**——体が 91%、HP が 9%、積み上げは「育つ駒は会戦で二重に不利」。
**3つを並べて1つ選ばせる形が、そのまま選択肢になる。**

### 0-2. 「持ち越し」は負も一緒に持ち越す

`CarryOver` は **`StatusKeys.All`（毒・傷・燃焼・破片・痺れ・標・なまり・深手・呪い）を一律に消している。**
**持ち越すなら負の状態異常も一緒に持ち越す。**

**積み上げだけを持ち越すと常に得になり、選択にならない。**
負も持ち越せば**盤面によって災厄にも資産にもなる**——ムドが育っているなら得、味方が毒まみれなら自殺行為。
**可変コスト型の判断になる。**

### 0-3. 判定の本体は勝率ではない

> **各境界で最良だった選択肢の分布。1つに偏るなら、選択肢として成立していない。**

**3つが盤面によって入れ替わって初めて選択。**
「いつも蘇生が最良」なら、それは選択肢ではなく**回復ノブの一種**にすぎない。

## 2. 変更の定義（**測る前に固定**）

### 2-1. ノブ

```csharp
public enum BoundaryChoice { None, Revive, Heal, Carry }

public readonly record struct BoundaryRule(BoundaryChoice Choice)
{
    public static BoundaryRule Default => new(BoundaryChoice.None);   // 現行。測定中はここ
}
```

**`RecoverRule`（第101期）は残置する。** 併用しない——**`RecoverRule` が既定（0, false）でないときは
`BoundaryRule` を無視する**か、逆にするかを決めて**コメントに書く**。

### 2-2. 3つの免除の中身

**`CarryOver` の中で分岐する。既存の並べ替え（`OrderBy(u => u.Slot)`）を動かさない。**

| | 中身 |
|---|---|
| **`Revive`** | **倒れた味方1体を `MaxHp / 2` で戻す。** 消去と `OnCarryOver` は現行どおり全員に走る |
| **`Heal`** | **生存者を `MaxHp` まで全快**（第101期の R100 と同じ）。死者は戻らない |
| **`Carry`** | **`StatusKeys.All` の消去と `ResetAtkBonus()` と `WhetReceived = 0` をしない。** それ以外は現行どおり |

- **蘇生は半分**（`MaxHp / 2`）。**蘇生は体を返すが HP は返さない**——3つの通貨を分離するため。
  **端数は切り捨て。最低 1。振らない。**
- **蘇生する駒は「最後に倒れた駒」。** 同着は**スロット昇順**。
  **`ctx.PickOne` を使わない**（第89期 (h)。候補2個以上で `Roll` を消費する）。
  **この選び方は振らない**（§6）。
- **スロットは元のまま。** 境界で再配置しないのが現行の規則。
- **召喚された駒（胞子・亡者）は蘇生の候補に入れない。** 儚い駒は持ち越さない、が現行の規則。
- **`ActionIndex = 0` は `Carry` でも維持する**——
  「行動周期は Battle スコープ。溜めかけたまま波が変わると次の部隊戦の初手に大技が落ちる」と
  コメントに理由が書いてある。**積み上げの話ではない。**
- **敵側には一切適用しない。** 敵は波ごとに新しい部隊。**確認して書くこと。**

### 2-3. `Carry` と `OnCarryOver` の関係（**Phase 0 で決める**）

`OnCarryOver` は「**消去した後に、持ち越したい状態を各特性に再構成させる**」ための窓口である。
**`Carry` は消去をしないので、`OnCarryOver` を呼ぶと二重に処理する特性がありうる。**

> **Phase 0 で `OnCarryOver` を実装している特性の全数と、それぞれが何をしているかを列挙し、
> `Carry` のときに呼ぶか呼ばないかを決めてからコミットする。**

**第101期の実測で、継ぎ接ぎのヴェルは `RFull` で −36.9pt と特異に動いた**
（`charges` / `sewn` / `MaxHp` 半減が会戦スコープ）。**ヴェルは必ず個別に確認する。**

## 3. 測るもの

**73行** × **seed 0..199** × **地点（3波）**。
**第100期の `run` の定義をそのまま使う**（新しい定義を作らない）。

### 3-1. 4つの方策

| 方策 | 意味 |
|---|---|
| **常に蘇生** / **常に回復** / **常に持ち越し** | 固定。第101期の掃引の延長 |
| **最良** | **その境界から先を3通り試して、最も良かったものを取る（上限）** |

**「最良」の定義（測る前に固定）**: **突破波数が最大 → 同値なら残存が最大 → 同値なら先に評価した順**
（蘇生 → 回復 → 持ち越し）。**地点は3波なので境界は2つ、探索は 3 × 3 = 9 通り。**

**死者が0体の境界では蘇生を選べない。** 候補から外し、**その境界を「選択肢2つ」として分母を分けて数える。**

### 3-2. 主判定

> **Q1（選択が成立しているか）: 最良だった選択肢の分布が、どれか1つに 60% 以上偏らないこと。**
> **分母（各境界の回数・選択肢が3つあった境界と2つだった境界）を必ず併記する**（規約 (G12)）。

> **Q2（帯）: 「最良」の突破率の中央値が 5〜50% に入り、突破率 0% の行が 37 行を下回ること。**
> 第101期の実測は R0 0.0% / R100 0.0% / RFull 53.0%（上限を 3.0pt 超過）。**帯はそのあいだにある。**

> **Q3（選択肢の価値）: 「最良」と、固定3つのうち最良のものとの差。**
> **差が無ければ「選ばせる意味がない」。**

### 3-3. あわせて見るもの（**判定ではない**）

- **圧勝率と残存**（方策ごと）。**比べる相手は R0 ではなく第101期の R100**（規約 (G11)）。
  **抜けた試行数を必ず併記**（規約 (G12)）。
- **同値塊の割合**。高いときは順位相関を判定に使わない（規約 (G13)）。
- **育つ駒の扱い。** ムド・カド・ヨミ・リィカを含む行で、**`Carry` が最良になる割合**。
  **「育つ駒は会戦で二重に不利」が選択で解けるか**が、この機構の設計上の狙いのひとつ。
- **ヴェルとの競合。** 境界の蘇生が無料だと、**自分の `MaxHp` を半分払って蘇生する駒の意義が薄れる**。
  ヴェルを含む行で `Revive` が最良になる割合を単独で出す。
- **`Carry` が災厄になった回数。** 負の状態異常を持ち越して、それが原因で落ちた試行。
  **可変コスト型として機能しているかの直接の証拠。**
