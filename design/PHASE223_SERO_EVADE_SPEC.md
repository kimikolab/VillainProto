## 1. 目的

移動軸のアタッカーを、**新基準のアタッカー**として作り直す。最近作り直した支援・状態異常の駒（リリ・ツギ・カタ・ミオ）が1戦 200〜500 を出しており、今のアタッカーはそれに負けている。

ポンと決めた形:
- **回避**: あらゆる攻撃を確率で避け、避けたら撃ち返す。避けるほど攻撃力が上がる
- **段は移動回数で上がる**: 回避で動いても、バサやシオに動かされても段が上がる＝**移動軸の中にいるだけで育つ**
- **マイナスは隊列をめちゃくちゃにすること**: 回避するたび隣の味方（選べない）と入れ替わる。配置が大事な編成には入れにくい
- **段で撃ち方が変わる**: 追い撃ちが貫きに、手番が乱れ撃ちに（絵の変化を重視）
- （版）**状態異常を矢に乗せる**: セロが帯びている毒・燃焼・感電を、矢で敵にうつす

## 2. 今のセロ（第222期）

- HP42・攻11・速12・単体。札 `Sniper`・`Coward`
- 戦闘中に一度後退してから後列にいると攻撃力2倍＋敵の後列を狙う貫き（最初から後列では発動しない）
- マイナス: 3分の1削られると後列の味方を突き飛ばして逃げる

## 3. 新しいセロ

| 項目 | 内容 |
|---|---|
| 数値 | HP42・攻11・速12（仮・変えない） |
| 手番 | 通常攻撃（単体）。段2から**乱れ撃ち** |
| 回避 | **敵の攻撃による被弾**を確率で回避する（単体・薙ぎ・貫き・全体・敵の術の直撃・反撃・追い打ち）。範囲攻撃なら自分に来た分だけ。回避した一撃は0（破片も減らない） |
| 回避しないもの | **状態異常のダメージ**（毒・燃焼の刻み・放電・澱みの爆発）。味方からのダメージ（巻き込みほか） |
| 回避率 | 30%（仮）。段3で 45% |
| 追い撃ち | 回避したら、攻撃してきた敵へ撃ち返す（現在の攻撃力・単体）。段1から**貫き**（その敵を通る経路を前から後ろへ。経路に属さない席の敵なら単体） |
| 成長 | 回避するたび攻撃力 +3（仮・戦のあいだ下がらない） |
| マイナス | **回避するたび、隣の生きている味方1体（選べない・乱数）と入れ替わる**。入れ替わった2体は「隊列を動かされた」扱い（ヨミ・シオほかが反応）。隣に誰もいなければ入れ替わらず回避だけ |
| フレーバー案 | 「逃げ足だけは誰にも負けない。撃ち返す暇まであるくらいに。」 |

### 段（移動回数）

セロが**隊列を動かされた回数**（`OnMoved`・出どころを問わない。回避の入れ替え・バサ・シオ・ハネ・庇いほか）で段が上がる。

| 段 | 移動回数 | 変化 |
|---|--:|---|
| 0 | 0〜2 | 手番は単体・追い撃ちは単体 |
| 1 | 3 | 追い撃ちが貫き |
| 2 | 6 | **手番が乱れ撃ち**: 5本の矢を、生きている敵へ1本ずつ乱数で撃つ（前列の規則は無視・矢は後列にも届く・同じ敵に重なってよい）。1本＝現在の攻撃力 |
| 3 | 10 | 回避率 45%・追い撃ちも2本 |

- 追い撃ちはターン外の攻撃なので、粛（第二波）では止まる。回避と入れ替えは止まらない（行動ではない）
- 1回の攻撃で回避の判定は1回（多段の攻撃なら1段ごと）

### 状態異常の矢（版で分ける）

セロが帯びている状態を、**セロの矢が当たるたび**（手番・追い撃ち・乱れ撃ちの各1本）敵に付ける。セロ自身の状態は減らない（消費しない）。

| セロの状態 | 矢で付くもの |
|---|---|
| 毒 | 毒 +2 層 |
| 燃焼 | 燃焼（付与・残りを3に戻す） |
| 感電 | 感電 |

- 当たった一撃で相手の感電が弾ける（既存の規則）→ その後で矢の状態を付ける（弾けた相手に新しい感電が付く）
- セロは回避するので、**帯びた感電が弾けずに残りやすい**（カタの代金の感電を撃ち続けられる）
- シガとの違い: シガは自分の感電を使い切って移す／セロは持っている限り撃ち続ける

## 5. Phase 0

- **Q0-1 回避を挟む場所**: 敵の攻撃の被弾が通る口（`PerformAttack` の各型・術の直撃・反撃・追い打ち）と、状態異常のダメージの口の分け方。回避をどこで判定すれば「攻撃だけ・状態異常は除く」を1箇所で満たせるか
- **Q0-2 移動の供給**: 規定化後の盤面（シオの手番あり）で、セロが動かされる回数と出どころ（台ごと・ターン別）。段1・2・3 に届くターンの見当

- **Q0-4 追い撃ちの貫き**: 攻撃してきた敵が経路に属さない席（9体の波の ○前2・○後2）にいるときの扱い
- **Q0-5 過去の測定**: `design/` を grep（回避・被弾無効・撃ち返し・セロの過去の版）
- **Q0-6 台**: §7 の台の駒を数えて予測を書く

## 6. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** セロのいない行は 0 セル。E0 は前段の盤面と台本が一致
- **P2** E1 のセロの与ダメは、同じ台のヨミ・カタ・ベニと並ぶかそれ以上（新基準のアタッカー）。9体の波では回避の機会が増え、段が早く上がる
- **P3** 移動軸の台では、セロの入れ替えでヨミが動かされる回数がさらに増える
- **P4** 庇い・後列前提の駒を含む台では、E1 は E0 より下がる（隊列が崩れる代金）
- **P5** E2 は、カタの隣のセロが感電を撃ち続け、敵の連鎖の回数が増える。燃焼の矢は燃焼の脆さ（F1）で次の矢が伸びる
- **P6** セロが倒れる原因は、攻撃より状態異常のダメージ（回避できない）が主になる
