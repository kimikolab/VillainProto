## 0. 出発点

第5期で、勾配列の候補は代金の**平均**を狙い帯に乗せることには成功したが、**向き**（どの型の編成に安いか）は作れなかった。第1波候補の「単体持ち − 範囲持ち」の代金差は 1a +3.1pt / 1b +3.1pt / 1c +2.4pt で、編成間のばらつき（約 9pt）に埋もれている。

第5期の分析はこう説明している——雑兵波は2〜3ターンで決着するので、範囲が節約できるのは敵の半手分しかない。**この作業はその説明を検証し、条件を変えれば向きが作れるかを一度だけ試す。**

### 2つの仮説

`農兵`（30HP / 攻8 / 5〜6体）で割れなかった理由として、方向の違う仮説が2つ立つ。**どちらが正しいかで、作るべき波が正反対になる。**

- **仮説 H1（戦闘が短すぎる）**: 範囲の利得は「敵を早く減らして被弾を減らす」ことなので、減らした状態で経過するターンが多いほど効く。総HP 150 では2〜3ターンで終わり、複利が効く前に決着する。→ **総HPを上げて戦闘を長くする**（1体あたりの攻撃は下げて代金を保つ）
- **仮説 H2（1体あたりの価値が低すぎる）**: 1体倒して減る被弾は攻撃力そのもの。農兵は攻8 なので、範囲で3体倒しても 24/T しか減らない——味方の総HP（約300）に対して誤差。→ **1体あたりの攻撃を上げ、HPは一撃圏に置く**（速く溶けるので総代金は抑えられる）

分析としては **H2 のほうが有望**に見える。1キルの価値 = その駒の攻撃力 × 残りターン数 なので、農兵の攻8 では分子が小さすぎる。ただし H1 が効く可能性も消えていないので、両方測る。

**H2 には罠がある**: 1体あたりの攻撃を上げると総攻撃力が上がり、波が「安く」なくなる。**この作業では代金の帯（20〜30%）より向きを優先する。** 向きが作れると分かってから、体数を減らして帯に戻せばよい。逆は不可能（向きが作れない波はいくら安くしても配分判断を生まない）。

## 2. Phase P — 安い波の再設計

### 2-1. 新しい素材

**新しい `UnitDef` は新しい Id で追加してよい**（既存 def は数値も含めて触らない）。仮説ごとに素体を用意する。

- **H1 用**: 個体HPを上げ、攻撃を下げた雑兵。総HPで戦闘を長くし、総攻撃力で代金を抑える。目安 45HP / 攻6 前後
- **H2 用**: 個体HPを下げ、攻撃を上げた雑兵（薄い硝子大砲）。**HPは味方の素の単体打点（14〜20）の1〜2発圏に置く**——一撃圏にないと範囲で倒しきれず、H2 の前提（1キルの価値）が成立しない。目安 24HP / 攻16 前後

数値は実装者が調整してよいが、**なぜその数値かをコメントで残す**（既存の敵 def はすべてそうなっている）。特に「HP を味方の打点の何発圏に置いたか」は明記すること。

### 2-2. 候補の組み方

第1波の位置に、**H1 系 2〜3案・H2 系 2〜3案**を組む。既存の `1a/1b/1c`（農兵）は対照として残す。

制約は第5期と同じ:

- 1波あたり最大6体（前3・中1・後2）
- 貫きは1波に1枚まで / 全体攻撃は1波に1枚まで
- `AttackPattern` を追加しない
- **雑兵波には範囲持ちの敵を入れない。** 敵側の攻撃型は測定の交絡になる（1c で斧を入れたのは第5期の判断だが、今回は向きを測るのが目的なので、敵は単体で揃える）

候補の設計軸を意識的に振ること。**総HP × 1体あたりの攻撃**の2軸で、少なくとも4点は取りたい（低HP低攻＝農兵 / 高HP低攻＝H1 / 低HP高攻＝H2 / 中間）。

### 2-3. 測ること

`gradient` の物差し（代金の平均・標準偏差・範囲持ち/単体の差）に、**媒介変数として決着ターン数を足す**。仮説 H1 は「ターン数が伸びれば向きが出る」と言っているので、ターン数を測らないと H1 の検証にならない。

候補ごとに出す:

| 候補 | 総HP | 総攻/T | 代金平均 | 代金SD | **単体−範囲** | 平均ターン数 | 勝率0%の編成数 |
|---|--:|--:|--:|--:|--:|--:|--:|

- `単体−範囲` は第5期の `HasAoe` と同じ静的な区分（`Def.Pattern` が薙ぎ／全体の駒を1体でも含むか）でよい。**区分の定義を変えない**（第5期の +3.1pt と直接比べられるようにするため）
- **成功条件: `単体−範囲` が編成間の標準偏差と同程度以上（およそ 8pt 以上）**。第5期の +3.1pt は「無い」と判定した水準なので、そこを明確に超えたときだけ「向きが出た」と言う

### 2-4. 追加で見たいこと（軽いので同じフェーズで）

**`単体−範囲` の区分は粗い**（薙ぎを1枚持つだけで範囲側に入る）。向きが出た候補については、**範囲持ちの枚数**（0枚 / 1枚 / 2枚以上）で代金が単調に下がるかを1表出す。単調なら本物、1枚と2枚で差が無いなら区分の副作用を疑う。

### 2-5. 受け入れ条件

- `compare` / `chain` / `pulse` / `ablate` / `dump` / `engage` / `seats` / `handoff` / `cost` の差分 **ゼロ**（新 def を足しても既存の波が参照しなければ何も動かない。**動いたら既存 def を触っている**）
- `EnemyCatalog.Stages` / `Columns` が不変
- 対照として残した農兵候補（1a/1b/1c）の代金と `単体−範囲` が、第5期の値と一致すること（**測り方が変わっていないことの検算。一致しないまま先へ進まない**）
- 候補の全数値（def の HP / 攻撃 / 速度 / パターン / 配置）が報告かコメントで読めること

## 3. Phase Q — 記録と報告

### 3.1 README に書くこと

「検証で分かったこと」に追記:

- **H1 / H2 のどちらが効いたか、あるいはどちらも効かなかったか。** 数字（`単体−範囲` とターン数）を根拠に
- **どちらも効かなかった場合は、それを結論として書く**: 「代金の向きは敵の攻撃パターン構成では作れない。向きを作るなら特性側（自傷の固定費のような、編成の内部構造に課金する形）でしか作れない」。**これは失敗ではなく、次の方向を確定させる結果**なので、そう書く
- ターン数と `単体−範囲` の関係。H1 が言う「長ければ割れる」が量的にどうだったか

### 3.2 「未解決の課題」に記録すること

**この作業では実装しないが、失わないように書き留める。**

- **自傷型の軸を強化する方向（ポン氏の方針、2026-08-25）。** 第5期で「自陣を削って戦う型は敵が弱くても固定費を払う」（死の連鎖系・惨禍系が第1波でも代金 50% 付近、逆しま系・移動系は 13〜22%）ことが分かった。方向は**自傷のリターンを大きくするか、この軸自体を強化する**。「厄介者をどこの戦場に送るか」がそのまま戦力配分になる形で、コンセプト（`design/concept_wave_engagement.md` §16）と直結する
- **キャラクター（敵含む）ごとのスキル・攻撃パターンの相談が控えている（ポン氏、2026-08-25）。** 会戦のシステムと計測が一段落したら着手する
- **第二波の従軍司祭がダミーである件。** ステージ定義のコメントは「回復役の司祭はレーン0の奥行き2」「支援役はレーンを選べば潰せる」と教えるつもりで書かれているが、`priest` は特性なしの素の 40/9/8 で**何も回復しない**。第二波が重い理由の一部がこれの可能性がある（潰す価値のない標的を狙撃するのは純粋な損）。**修正すると `docs/balance.md` が動くので独立した作業**。第5期で新設した `Chaplain`（継ぎ当て持ち）が素材になる

### 3.3 報告してほしいこと

1. **向きは出たか。** 候補ごとの `単体−範囲` を、第5期の農兵（+3.1pt）と並べて
2. **H1 / H2 のどちらが効いたか。** ターン数と `単体−範囲` の対応。H1 が正しければターン数の長い候補ほど割れているはず
3. **代金の帯を犠牲にした分はどれくらいか。** 向きが出た候補の代金平均。20〜30% からどれだけ外れたか。体数を減らして帯に戻せそうか
4. **範囲持ちの枚数で単調に下がるか**（§2-4）
5. **どちらも効かなかった場合**: 説明として最も確からしいものを1つ。**推測は推測と明記する**

## 4. 作業ルール

1. Phase P → Q の順。**フェーズを跨いで1コミットにしない**（Q は文書のみ）
2. コミットメッセージに「動いた docs/ の行」を書く。動いていないなら「compare 差分ゼロ」と明記
3. コード・コメント・ログは日本語。既存の文体（**却下した案とその理由も書く**）に揃える
4. CONTRIBUTING.md のチェックリストを通す
5. 長時間ジョブは前景で待ち切る。`layout` は走らせない
6. **採用を決めない。** 推奨は出してよいが、`Columns` への追加も `Stages` の変更もしない
7. 以下を見つけたら**実装前に止まって報告する**:
   - 対照（農兵候補）の値が第5期と一致しなかった場合
   - H2 の素体を作ろうとして、味方の打点の分布が広すぎて「一撃圏」が定義できない場合（**推測で数値を決めず、打点の分布を報告する**）
   - 向きが出た候補が、代金の帯から極端に外れた場合（例: 60% 超）。**その候補はもはや「安い波」ではないので、位置の役割そのものを見直す必要がある**
