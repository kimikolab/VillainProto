# 第201期 指示書 —— パターン2を遊べるようにし、席を選んで測り直す

**線は置かない**（採否はポンが遊んで決める）。この文書は `design/PHASE201_FORMATION2B_SPEC.md` として置くこと。
報告は `design/PHASE201_FORMATION2B.md`。診断は第200期の `BattleSim/Modes/Formation2.cs` に足す。

手順の順序: Phase 0 → **予測のコミット** → 実装 → `compare` → 診断。

## 1. 目的

第200期（`design/PHASE200_FORMATION2.md`）で、味方の陣形を隊ごとに持つ形（`FormationShape`）が入り、パターン2（ひし形・前衛1枚）で戦えるようになった。見えたこと:

- **前衛1枚は「分散しない盾」**。X 字では敵の単体攻撃が前衛2枚に分かれるが、パターン2では D の1枚に集まる。D が耐えれば圧勝し（毒・毒+耐久 +15〜17pt）、耐えなければ崩れる（4行で D のスィドが2ターン目までに倒れる）
- ガルドはパターン2で落ちる（庇う隣の前衛がいない・受け流し2回では集中に追いつかない）。上がったのはササだけ
- **パターン2の値は席を選んでいない**（残りを X 字の席の順で詰めただけ）。燃焼の行はボルグがガルドの隣に来て 88.4 → 10.2

今期は3つ:
1. **編成画面でパターン2を選べるようにする**（ポンが遊んで決めるための入口）
2. **パターン2の席を選んで測り直す**（X 字も同じ条件で席を選び、公平に比べる）
3. **スィドの版（S／S+反／S+HP）をパターン2の D で比べる**（前衛1枚では「D が耐えるか」が全てなので、第196期で保留した判断をここで材料にする）

## 2. 編成画面でパターン2を選ぶ

- 編成画面（DemoApp の出撃の入口）で、**隊ごとに陣形を X 字／パターン2 から選べる**ようにする
- パターン2を選んだら、配置の枠を**図のとおりの形**（1レーン中衛・2レーン後衛/中衛/前衛・3レーン中衛）で見せる。**右が前**
- 席の表示名はパターン2では A〜E ではなく、位置が分かる名前にする（例: 「前衛」「中衛・上」「中衛・中央」「中衛・下」「後衛」）。X 字の表示名は今のまま
- 第200期の起動引数（`--demo-shape=p2` / `--demo-p2-front=…`）は残してよい
- 作戦マップの部隊にも陣形を持たせるかは Phase 0 で見積もり、重ければ次期（報告に書く）

## 3. 席を選んで測り直す

### 3.1 席の選び方（測る前に固定）

- 対象の行ごとに、**5枚の並べ方 120 通り**をすべて試す（X 字もパターン2も同じ）
- **選ぶ試行と、測る試行を分ける**（選んだ試行でそのまま測ると上振れする）
  - 選ぶ: 第2〜5波 × seed 0..49 の平均勝率が最大の並び（同値は並びの辞書順で最小）
  - 測る: 選んだ並びを第2〜5波 × **seed 100..299** で測る
- 既に席の総当たりの道具（過去の reseat 系の診断）があれば、それを使ってよい。無ければ新しく書く

### 3.2 表A —— 毒パ（第200期と同じ7行）

| 列 | 内容 |
|---|---|
| 元 | 今の行のまま（X 字・席は今のまま） |
| X・選 | X 字で席を選んだ最良 |
| P2・選 | パターン2で席を選んだ最良 |

- 行の駒の組み合わせは第200期の表A の「P2」の列と同じ（スィド・ベニ入り、ガルド抜き）。**元だけはガルドありの今の行**
- 最良の並びで **D（前衛）に誰が選ばれたか**を行ごとに書く

### 3.3 表B —— タンクの土俵（第200期と同じ6行・同じタンクの入れ替え）

| 列 | 内容 |
|---|---|
| X・ガルド・選 | X 字・ガルドあり・席を選ぶ |
| P2・ガルド・選 | パターン2・ガルドあり・席を選ぶ |
| P2・ゴルム・選 ／ P2・ササ・選 ／ P2・スィド・選 | パターン2・ガルドをそれぞれのタンクに替え・席を選ぶ |

- **D を固定しない**（タンクが D に来るとは限らない。どこに来たかを書く）
- 読むのは「席を選んだうえで、パターン2でガルド以外のタンクがガルドにどこまで近づくか」

### 3.4 表C —— スィドの版（パターン2の D）

表A の7行で、**P2・選 の最良の並びを固定**したまま、スィドの版だけを替える。

| 版 | 内容 |
|---|---|
| S | 規定（第196期） |
| S+反 | 殴られたときの毒 +4 → +8 |
| S+HP | HP 84 → 100 |

- 最良の並びでスィドが D にいない行は、その旨を書き、**スィドを D に置いた並びのうちの最良**でも測る（D のスィドを見るのが目的）
- 読むのは勝率と「D が2ターン目までに倒れた割合」

### 3.5 帳簿（最良の並びの戦・1戦あたり）

- D が倒れた割合とターン、D が受けた攻撃の内訳（単体／薙ぎ／貫通／全体）
- 薙ぎ・貫通で巻き込まれた人数の平均
- 最良の並びの席の傾向（D に来た駒、後衛に来た駒の一覧）

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0 を見てから入れる。

- `compare` は ±0.0（今の行は触らない）
- 表A: P2・選 は第200期の P2（席を選ばない）より上。X・選 との差は、第200期の −3.2pt より縮む
