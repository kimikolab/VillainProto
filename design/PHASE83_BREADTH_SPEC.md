### 0-1. なぜ引き直すか（**設計の目標が先にある**）

ポンの設計目標（2026-09-03）:

> **同じ軸で固めれば最良、というゲームにはしたくない。**

**第82期の物差しはこの目標と逆を向いていた。**

- **横軸が「単独の帰属 +1.5」**だったので、**1枚で働く駒が上に来る**

### 0-2. 新しい物差し

    主判定  = 有意な正の相乗を持つ相手の数（広さ）
              うち「キーを共有しない相手」の数を重く見る
    副      = 最良の相乗の大きさ
    床      = 単独の帰属が大きく負でないこと
    拒否権  = 既存61行を壊さないこと（回帰）＋ 主判定19行に在席

**単独を床に落とすのが要点。** 上には効かせないが、下は切る。
**「1枚では地味だが、意外な相手と噛む駒」を上げ、「相方を引けないと何もしない駒」は床で止める。**

**拒否権1（理想台では働いている）を廃止し、「既存61行を壊さない」に置き換える。**
前者は 44/51 に立ってほぼ常時発動だったが、後者は**実際に壊す駒でしか立たない。**
**拒否権が拒否権として機能するようになる。**

## 2. 新しい物差しの定義（**測る前に固定。数字を見てから動かさない**）

### 2-1. 主判定 —— 広さ

    広さ(A) = |{ B : 相乗(A,B) > 0 かつ |相乗| > 2×SE }|
    独立の広さ(A) = そのうち KeysOf(A) ∩ KeysOf(B) = ∅ である相手の数

**順位は「独立の広さ」で付ける。同数なら「広さ」。それでも同数なら「最良の相乗」。**

**「独立の広さ」を主にする理由**: 同キーの相手との相乗は**軸を深くする**方向で、
**設計目標と逆**。キーを共有しない相手との相乗が**「想定していない噛み合わせ」の実測値**。

### 2-2. 3分の線

| 群 | 条件 |
|---|---|
| **残す** | **独立の広さ ≥ 3**（キーを共有しない相手と3組以上噛む） |
| **転生** | 独立の広さ < 3 かつ **広さ ≥ 3**（軸の中では噛むが、外へ出ない） |
| **差し替え候補** | **広さ < 3**（誰とも噛まない） |
| **床で落ちる** | 上の群にかかわらず、**単独の帰属 < −1.5**（**1枚で盤面を悪くする**）→ **差し替え候補へ移す** |

**線の根拠**:
- **3組**は「相方が引ける確率」から。**ドラフトで5枚中に特定の1枚が来る確率は約 10%**なので、
  **3枚いれば 27% で誰かが来る**。**1〜2組では実プレイでほぼ発火しない**
- **−1.5** は第62期以来の帰属の閾値の符号違い。**新しい数字を作らない**

### 2-3. 拒否権（**差し替え候補から外す条件**）

1. **既存61行を壊す**——その駒を**素体に差し替えた版で、その駒を含む行の第2〜5波の平均が
   **−5.0pt 以上落ちる**行が1行でもある（**第46期の閾値**）
2. **主判定19行に在席する**
3. **その駒が唯一の書き手であるキーがある**（`TraitEntryMap.Supplies`。第82期の実測では **1 体**）

**第82期の拒否権1（理想台では働いている）は廃止する。理由は §0-1。**
**廃止したことと、それによって何体が切れるようになったかを報告書に明記すること。**

**拒否権3の読み方の訂正**（第82期 3-7）: `Supplies` は**書き手を駒で数える表**なので、
**読み手の唯一性は入らない**（シガ＝痺の唯一の読み手・ウロ＝破片の唯一の読み手は当たらない）。
**この期では拒否権3を「唯一の書き手」のままにする**が、
**「唯一の読み手」を別表で数えて併記する**（切ると軸の出口が消えるので、判断の材料にはなる）。

### 2-4. 軸ゲーの監視指標（**この期から毎期出す**）

    同キーの組の相乗の分布 対 共有無しの組の相乗の分布
      平均 / 中央値 / 上位30 に占める割合 / 有意な正の割合

**同キーが上位を独占していれば「軸を固めるゲーム」、共有無しが食い込んでいれば
「想定外の噛み合わせが起きる盤面」。**第81期の実測は後者寄り（上位10 に 4 組）。

### 2-5. 埋め草の偏りの確認

**規則 P（攻撃力 → HP の2段）は攻2〜3 を引かない**（第80期）。
**埋め草を「49 体から無作為3枚」に変えた版**で `pairs2` を回し直し、**上位30・下位30 の一致**を見る。
**追加の戦闘はここだけ**（§1-1 の「原則ゼロ」の例外。**予算を先に計算する**）。
