## 0. 主題

### 0-1. 何が問題か（第109期の実測）

現行の譲渡条件は **「自分の手番より前に、このターン敵が倒れていたら」**（`TaillightTrait.SawKey == Turn`）。
トモは速3で味方最遅なので、条件は「このターン敵が1体でも倒れたか」とほぼ同義になる。実測で2つの穴が出た:

| 穴 | 実測 | 構造 |
|---|---|---|
| **(1) 撃破が起きたターンに戦闘が終わる** | `トモ×ハギ` 門2 = 0.01〜0.26 回/戦 | 撃破 → 追い打ち → 連鎖 → 全滅。**トモの手番が来ない** |
| **(2) 決着が伸びる波ほど1ターンに倒れる敵が減る** | `トモ×ドルガ` 門2 = 第2波 2.23 → **第4波 1.20**（軛） | 律速は「敵が硬いか」ではなく「1ターンあたり何体倒れるか」 |

> **「撃破を作る側」と「撃破を条件に動く側」は、条件を読む側が遅いと同席させても噛み合わない。**
> 第109期の予測は5つ中3つ外れ、3つとも「撃破がトモの手番より前に来るか」を数えていなかった。

### 0-2. この期でやること

**条件の版を3つ並べ、同じ台・同じ対照で門と出力を測る。** 新しい駒は作らない。トモの数値（HP54・攻0・速3・`Lumen = 5`）は動かさない。

| 版 | 譲渡の条件 | 埋める穴 | 実装の差分 |
|---|---|---|---|
| **V0 現行** | 自分の手番で、**このターン**敵が倒れていたら譲る | — | なし（対照） |
| **V1 窓** | 自分の手番で、**このターンか前のターン**に敵が倒れていたら譲る | (2) | `OnAction` の条件 1 行 |
| **V2 即時** | **敵が倒れた瞬間**（`OnAnyDeath`）、ターン外に灯した味方へ手番を渡す。**1ターン1回**。自分の手番では何もしない | (1)(2) | `OnAnyDeath` に譲渡を移す |

**V2 は「ターン外の行動」なので `CanActOutOfTurn` を通す＝粛（第二波）で閉じる。**
これは欠陥ではなく読み手が1つ増える形——現在、粛を読む味方側の機構は
**棘・仇討ち・軋み・追い打ちの4本**（`CanActOutOfTurn` の doc）で、V2 はその5本目、
かつ**「他人をターン外に動かす」初めての機構**になる。**第二波で譲渡が 0 になることを、V2 の判定に含める**（§1-4 Q4）。

### 0-3. この期で触らないもの（境界を先に引く）

- **灯の対象選択**（最も遅い味方・`AcceptsSupport` で濾す・同速は席昇順）は3版とも同一。
  第109期 §3-2 の「`CanAct` 偽の駒（ハギ・カド・ヒヨ・ノノ・ミオ）に譲っても潰れる」は**この期では直さない**
  ——条件と対象を同時に動かすと何が効いたか読めない。**潰れた回数は3版で数えて並べる**だけ
- **1ホップ**（`BattleContext.Yielding`）は3版とも据え置く
- `Lumen`・速さ・HP・攻撃力の掃引はしない

## 1. 測り方

### 1-1. 実装（**3版を1つのノブで切り替える。既定は V0**）

`TaillightRule(YieldMode Mode)` を `readonly record struct` で足し、`BattleContext` のコンストラクタから
他の Rule（`HushRule` / `EncoreRule` / `BetrayRule`）と同じ形で受ける。
**既定は `YieldMode.OwnTurn`（= V0 現行）**。**static のノブにしない**（Trait は共有シングルトン・`layout` は並列実行）。

    enum YieldMode { OwnTurn /*V0*/, OwnTurnWindow /*V1*/, Immediate /*V2*/ }

- **V0**: 既存の `OnAction` の条件 `SawKey == Turn` をそのまま
- **V1**: `OnAction` の条件を `SawKey == Turn || SawKey == Turn - 1` にする。**`SawKey` の書き方は変えない**（ターン番号を書くだけ・掃除不要の作法を守る）。`OnCarryOver` で 0 に戻すのも現状どおり
- **V2**: `OnAnyDeath`（敵の死）で、以下を**全部**満たすとき `ctx.TakeTurn(lit)` を呼ぶ。
  `OnAction` は計数だけして何もしない
  1. `self.IsAlive`・`lit` が生きている
  2. **`ctx.CanActOutOfTurn(lit)`**（動くのは灯した味方なので、問うのも `lit`。粛・痺れ・`CanReact` がここで効く）
  3. `!ctx.Yielding`（1ホップ。V2 では**譲った手番の中の撃破からは再度譲らない**の意味になる）
  4. **このターンまだ譲っていない**（`YieldedKey = Turn` を書いて比べる。`SawKey` と同じ作法）
  5. `ctx.TeamAlive(敵)`（行動順ループと同じ番人。倒れたのが最後の1体なら譲らない）

  **`ctx.Interrupt` で包むかどうかは Phase 0 で決めて理由を書く**（§3 の 3）。
  **`Yielding` は V2 でも `try/finally` で必ず戻す**（例外で立ちっぱなしになると以後の譲渡が永久に止まる）。

**V0 の経路は1文字も変えない。** ノブを渡さない `compare` が第109期と同じ盤面であることを自己検査 1 で示す。

### 1-2. 台（**測る前に決める。第109期の台は2台が床だったので組み直す**）

**`Presets.Compare` 61行・`Presets.Cross` 12行は触らない。** 診断のローカル台で測る。

**パートナー4枚は第109期と同じ**（ドルガ／ムド／ソム／ハギ）。**変えるのは土台3枚。**
第109期の土台（ガルド・キリ・ボルグ）は総攻が薄く（ボルグ18＋ガルド9＋キリ打点1）、
パートナーが攻38のときしか台が生きなかった。

**土台を選ぶ規則は第109期の3つを据え置き、(3) を「実装前に数える形」に直す**（第109期 §9-2）:

| | 規則 |
|---|---|
| (1) | 土台3枚は**速さ ≥ 8**（`Stoic` のガルドだけは速4でも可——灯の候補から自前で外れる） |
| (2) | **`AtkBonus` を他人に書かない**（号令・吐き戻し・横流し・蘇生を外す）。灯の到達点に別経路を混ぜない |
| (3) | **素体版（トモ → HP54・攻0・速3・特性なし）の第2〜5波平均が 40〜95% に入る台を、4台中3台以上**にする |

**(3) の手順**: 土台候補を **Phase 0 で列挙し、V0 も V1 も V2 も回す前に素体版だけ先に回して**帯に入る組を選ぶ。
候補は (1)(2) を満たす駒から引く（実装から数えること。第109期に手作りの速さ表がずれた）。
例として **キリを攻の実体がある速≥8の駒（ハネ／ナラ／ソラ／セロ 等）に替える**のが最小の差分だが、
**選んだ理由と、落とした候補の素体版の値を報告書に書く**。
帯に入る組が4台中3台に届かない場合は**届いた台だけを分母にして、分母を明示する**（規約 (G4)）。

席は第109期どおり **ボルグの巻き込みがパートナーにもトモにも当たらない**配置を守る:

    前1 = パートナー ／ 前3 = ガルド ／ 中央 = 土台の入替駒 ／ 後1 = トモ ／ 後3 = ボルグ

**対照**: 各台の**素体版**、および **V0 版**（3版の比較は V0 が対照）。seed 0..199・5波。判定の分母は第2〜5波（規約 (G10)）。

### 1-3. 門（**鎖が繋がっているか。大きさではない**）

3版 × 4台 × 波別で、回/戦:

| 門 | V0 | V1 | V2 |
|---|---|---|---|
| 門1 灯 | 3版で同一のはず（対象選択は触っていない） | ← | ← |
| **門2 条件成立** | 自分の手番で「このターン撃破あり」 | 自分の手番で「このターンか前ターンに撃破あり」 | 敵の死の瞬間に 1〜5 を全部満たす |
| 門3 譲渡 | `TakeTurn` を呼んだ回数 | ← | ← |
| **潰れ** | 譲った先が `Stalled` を返した回数（内訳: 痺れ／まどろみ／`CanAct` 偽） | ← | ←（＋ **`CanActOutOfTurn` で止まった回数**。内訳: 粛／痺れ／`CanReact`） |

**V2 だけ、門2 の手前に「敵の死 → `lit` 生存 → `CanActOutOfTurn` → 未譲渡」を段で数える**。どこで切れるかが波で違うはず（第二波は `CanActOutOfTurn` で全部切れる）。

### 1-5. 紙（**門ではなく出力**。規約 (G7)。分子について3つを先に書く）

1. **分子は譲渡の与ダメ**＝ 譲渡/戦 × 譲られた駒の1手番の出力。第109期の実測で1譲渡あたり **13.1〜27.7**（ハギ台は 0.0）
2. **門ではなく出力**: V2 は譲渡が**ターン外**に来るので、譲られた駒の攻撃力にそのターンの灯がもう載っている（`OnTurnStart` は行動順の外）。**V0 と同じ単価**で数えてよい
3. **分母を削るか**: 譲渡が増えれば決着が早まる側（分母が減る）。V2 で撃破 → 譲渡 → 撃破 の連鎖が出ると**第109期の「サイクルが閉じる前に戦闘が閉じる」がさらに強く出る**。上限にも下限にもならないので、**紙は方向だけ**書く

## 2. 予測（**測る前に書く**）

1. **V2 でハギ台の門3 が 0.18 → 1.0 以上**になる。追い打ちと譲渡は同じ `OnAnyDeath` で立つので、Q3 も同時に通る。
   **ただし譲られた先がハギなら潰れる**（ハギは `CanAct` 偽）——ハギ台の灯の対象は速7のハギではなく速8以上の土台になるはずなので、
   **Phase 0 で「この台で誰が最遅か」を先に数える**
2. **V1 は第四波の門2 が 1.20 → 2.0 前後**（前ターン分が乗る）。ただし**第五波の伸びは小さい**（決着 5.2T・撃破がターンに集中する波では窓を広げても重ならない）
3. **V2 の第二波は譲渡 0**（Q4）。**それでも第二波の帰属は V0 を下回らない**——灯そのものは止まらず、V0 でも第二波の譲渡は 1.72 回/戦 で出力の主は灯のほう
4. **V2 の潰れは V0 より減る**（V0 の潰れは「譲った先がのろまの休み番」0.42/戦。V2 はターン外なので `Sluggish` の `CanAct` は通り、代わりに `CanReact` で切れる——**のろまは `CanReact` を持つか Phase 0 で確認**）
5. **V1 と V2 の帰属は、ドルガ台では V2 > V1 > V0、ムド台では差が小さい**（ムドは育つ前に決着する床の際）。
   **順序が逆なら「即時は出力を前倒しするだけで総量は増えない」の証拠**として記録する

## 3. Phase 0（**戦闘は §1-3 の門のみ**）

1. **第109期の4台（旧土台）で V0 をノブ経由で回し、第109期の表A（門1/門2/門3・波別）と一致すること**

3. **V2 を `ctx.Interrupt` で包むか**: `InInterrupt` を読んでいる箇所を grep し（軋みのヨミが `OnMoved` で読む・追い打ちのハギは読まない）、
   **包むと「譲られた手番の中でヨミが動かされても割り込めない」**ことを確認したうえで決める。理由を書く
4. **`CanReact` を持つ特性の一覧**（`Sluggish` が該当するか。V2 の潰れの内訳に効く）
5. **各台で「トモを除いて最も遅い味方」を実装の速さ表から確定**（灯の対象＝譲渡の先）。**その駒が `CanAct` 偽／`Actions = [Skill]` でないこと**
6. **`TakeTurn` をターン外（敵の手番の中）から呼んだときに壊れる帳簿が無いか**: `TurnActor` の入れ子（`TakeTurn` は `prevActor` を戻す）、`IdleTurn`、

   これは `CanActOutOfTurn` が痺れを弾くので起きないはずだが、**弾いていることを自己検査で示す**）
7. **GodotApp が台本を再生できるか**（ターン外の `TakeTurn` のイベント列で落ちないこと。表示の正しさは問わない）
8. **過去に「ターン外に他人を動かす」機構を測っていないか** `design/` を grep

## 5. 結論の書き方

報告書 `design/PHASE110_YIELD.md` の冒頭に、**1つの引用ブロックで答えを書く**。
**Q1〜Q5 の○×と、採る版を1行で。**

### 分岐

- **V2 が Q1・Q3・Q4 を通り、Q5 を落とさない**: **V2 を採用**。`TaillightTrait` の既定を `Immediate` にし、
  doc の「自分の手番より前に」を書き換える。**V0・V1 の経路は削除せず対照として残置**（ノブで切り替え可能なまま）。

- **V2 が Q1 を落とす**（ハギ台で即時でも譲れない）: 段の表（§1-3）でどこで切れたかを書く。
  **「灯の対象がハギ自身」なら対象選択の問題**で、この期の範囲外——第111期の入口に「手番型に限る対象選択」を置く
- **V1 だけが Q2 を通り、V2 が伸びない**: **V1 を採用**。V2 は「即時は前倒しであって増量ではない」として記録
- **どれも V0 を上回らない**: **V0 のまま**。トモの譲渡は「撃破を作らない台でだけ働く」機構として `Presets` に入れるか、
  第111期に「機構を据え置いて対象選択だけ変える」を試すかを次の入口にする
- **帯に入る台が3台に届かない**: 届いた台だけで判定し、**分母を明示**。ソムとハギの台が床のままなら
  「ソム・ハギは土台の総攻を足しても床」を記録して、その2台は Q1・Q3 の門だけを見る
