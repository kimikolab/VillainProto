# 第277期 指示書 —— ノミの転生(豆鉄砲: 攻撃力を連撃の回数に変える)

読み手は Claude Code。転生段の2駒目。需要「手数特化」(RELIC_PLAN 4.6 の豆鉄砲)×ノミ(✕・第275期対応表)。

## 0. 転生の形

**核は変えない**: 執着(`Fixate`: 一度狙った敵が倒れるまで他の敵に目を向けられない)・「刻んだ相手が倒れるともう一度動く」・踏込——捨てられた理由と動き方はそのまま。

**変えるのは攻撃の形だけ**: **攻撃力を連撃の回数に変える。** 攻10 → 1ダメージ×10連撃(同一対象・1手番1拍)。

- 一発が小さいので**軛(1発25上限)に一切切られない**
- 「被弾するたび」を読む装置すべての起爆回数が10倍になる: 被弾の燃焼(燃えた敵に6×火勢が発ごと)・弾性・敵の殉教者の成長(裏目の読み合い)
- 贔屓などの**攻撃力の上乗せがそのまま弾数になる**(強化の読み替え)
- 傷の書き手としての顔は版で振る(下記)

1文の叩き台: 「一撃を十に割り、同じ場所を彫り続ける。一彫りは浅い。」(最終はポン)

## 1. Phase 0

1. **連撃の実装点**: セロの乱れ撃ち(5本)の実装を読み、流用できるか。発ごとに `OnAfterAttack`・被弾側フックが回るか、それとも1攻撃として畳まれるか——**ここが成立条件の本体**
2. **被弾の燃焼が「1発ごと」か「1攻撃1回」か**(第256期の採用形を確認)。1攻撃1回なら豆鉄砲は成立しない(RELIC_PLAN 4.6 の注記どおり)——その場合は実装に入らず報告して止まる
3. `Carve`(傷)・「もう一度動く」・萎縮などの**発ごと/攻撃ごとの発火単位**を列挙(もう一度動くが発ごとに判定されると多重発火する——1攻撃1回に固定)
4. 1ダメージの最小値の扱い(防御・萎縮で0になるか。0が並ぶなら「最低1」の既存規則の有無)
5. ノミの compare 在席行(第275期の表)と、傷の読み手(エグ・ナタ・ハリ)の在席行
6. 類似実験の grep(連撃・多段攻撃)

## 2. 版

| 版 | 内容 |
|---|---|
| N0 | 旧ノミ(対照) |
| N1 | 連撃化。傷は**1攻撃につき1**のまま(傷の供給量は不変・手数だけ10倍) |
| N2 | 連撃化。傷を**1発につき1**刻む(傷の機関銃)。`PerWound` +2 が発ごとに乗るので連打内で自己増幅する(1+3+5+…) |

N2 は壊れる可能性を織り込んで測る(プロトタイプ段階: 壊れの記録だけ取り、怖がって削らない)。

## 3. 測定

- 回帰: ノミ不在の行は 0 差分
- ノミ在席の既存行(あれば)+検証行2本: **傷の読み手の行**(エグ/ナタ/ハリ系)と**燃焼の行**(被弾の燃焼との橋。ボルグ/ホタ/ヒヨ系にノミを差した形)× N0/N1/N2 × 本編第2〜5波+ボス+チェック波
- 機構の実測: 1戦の総発数・被弾の燃焼の発火数(N0比)・傷の供給数・「もう一度動く」の発火数・軛の波で切られた量(N0 比で 0 になるはず)
- 手数チェック波は豆鉄砲の見せ場のはず——倒しTで N0 と比較

## 4. 予測(Phase 0 の発火単位の確認後・実装前に書くこと)

- N1: 軛+手数チェックで N0 を大きく超える。燃焼の行では被弾の燃焼の起爆役として橋になる
- N2: 傷の読み手の行で跳ね、自己増幅で単体火力も N1 を超える。壊れ(100%張り付き)が出るならここ
- ボス(動じない・単体)では執着が空転しないので安定して刻めるが、蝕みは毒のみ読むため不干渉

## 5. 採否(面白さ探索の基準)

- 「被弾するたび」装置との接続が実測で確認でき、N0 と**違う勝ち方**をするか
- 執着・もう一度動くの個性が連撃の下でも残っているか(発火数で確認)
- 1文が短いまま。壊れは記録のみ(採否にしない)。N1/N2 どちらを規定にするかは実測を見てポンに選択肢を出す
