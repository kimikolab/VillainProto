## 2. 移設の実装

### 2-1. 形

**継ぎ当て（`MenderTrait`・ノノ）の形をそのまま踏襲する。**
`OnAction` に本体を置き、`OnTurnStart` は `ActsOnPattern` が偽のときだけ従来どおり発火させる。

```csharp
public override void OnAction(BattleContext ctx, UnitState self, UnitAction action) => Favor(ctx, self);

public override void OnTurnStart(BattleContext ctx, UnitState self)
{
    if (!ActsOnPattern(self)) Favor(ctx, self);
}
```

**保持者が1枚でも分岐を残すこと。** 継ぎ当てのコメントが記録している事故
（味方のノノと敵の従軍司祭長が同じ特性を共有していて、無条件に移すと司祭長の回復だけが静かに消えた）
と同じ形が、後で敵側にこの特性を配ったときに再発する。

`UnitDef.Actions` は **`[Skill]` 1要素**にする（ノノと同じ）。
**周期に「その駒が永久に実行できない種別」を混ぜない**——1要素なので該当しないが、
`ActionIndex` が空回りしないことを確認すること。

版の切り替えは `Run` への引数（`FavorRule` に `OnTurn` を足すか、既存の `KindleRule` を拡張）。
**書き換え可能な static のノブは置かない。既定は現行（ターン頭）**にしておき、
**引数なしの `compare` が `docs/balance.md` と一致すること**を検算に使う（第59期 11-5）。

### 2-2. 測る条件

対象は**フイを含む4行**。

| # | 版 | 内容 |
|--:|---|---|
| V0 | 現行 | `OnTurnStart`・`(Gain 4 / Loss 2)` |
| **V1** | **移設** | `Actions = [Skill]`・`(4 / 2)` |
| V2 | 移設 + 素体 | 同数値・特性なしの素体に差し替えた版（**体の値段**の分離） |

**V2 を必ず置くこと。** 移設は出力を捨てるので、勝率が下がったときに
「機構が弱くなった」のか「攻5 が消えただけ」なのかを分ける対照が要る。

## 4. 掃引（移設が通ったときだけ）

**移設で代金の相手の集合が変わる**（第58期 9-3 は「代金の相手は構造的に非燃焼なので
`Gain` では縮まない」だった。移設はその集合そのものを動かす）ので、**律速が変わっている可能性がある。**

| 版 | Gain | Loss |
|---|--:|--:|
| 現行値 | 4 | 2 |
| a | 4 | 4 |
| b | 6 | 2 |
| c | 2 | 2 |

**4点だけ。** 代金の集合が縮んだなら `Loss` を上げる余地があるはずで、
**a が現行値を上回るかどうかが「集合が縮んだ」ことの独立な検算になる。**
**各点の対照は V2（素体）で足りる**（体の値段はノブで動かない）。
