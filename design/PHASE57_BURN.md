### 1-3. 波ルールと燃焼 —— **予測**

| 波ルール | 燃焼に課金するか | 理由 |
|---|:-:|---|
| 粛（第二波・ターン外の行動禁止） | **しない** | 刻みは `TickStatuses`。`CanActOutOfTurn` を通らない |

## 3. 作ったもの

### 3-1. 計数（盤面を動かさない）

`UnitTally` に 9 本。**どれも誰も読んで分岐しない私有カウンタ**（第49期の `ScapegoatDotByUnit`、
第56期の `Whetted` と同じ扱い。`verbose` 非依存）。

| 名前 | 置き場所 | 数えるもの |
|---|---|---|
| `BurnLit` | `BattleContext.Ignite` | 火が**点いた**回数（`relit == false`） |
| `BurnRelit` | 同 | 火が**煽られた**回数（既燃への再付与＝**捨てられた供給**） |
| `BurnLitAlly` | 同 | `BurnLit` のうち `friendly: true`。陣営別集計との**突き合わせ用** |
| `BurnTicks` | `TickStatuses` の燃焼ループ | 燃えたターンの延べ数 |
| `BurnTaken` | `ApplyDamage` の `Hp -= amount` | 燃焼で**実際に HP を失った量**（全段を通した後） |
| `BurnSoaked` | `ApplyDamage` の破片の段 | 燃焼の刻みのうち**破片が吸った**量 |
| `BurnDeaths` | `TickStatuses` | 燃焼の刻みで倒れた回数（**指示書 §2-1 に無いが表A に要る**） |
| `BurnAttacks` | `PerformAttack` | **燃えている状態で振った**回数（`Attacks` の内数。**表C に要る**） |
| `FirstBurnTurn` | `Ignite` | 最初に火が点いたターン（**表C に要る**） |

**着火は「誰が付けたか」ではなく「誰に付いたか」で持った**（指示書の指定どおり）。
`Ignite` は付け手を受け取らないので、引数に足すと呼び出し規約が変わる。

**`BurnSoaked` は `ApplyDamage` に既定値つき引数 `burnTick` を1本足す側を採った**（§2-1 の2案のうち前者）。
理由は 2 つ:

- **破片の残量の差では、肩代わりで分割された段の吸収が数えられない。** 巨躯・分かちは
  `u != source` を見るが `source` は刻みでは `null` なので**成立してしまう**（除外されているのは
  吐き戻しだけ）。分割先で吸われた量も同じ刻みのぶんなので、**`burnTick` を3つの再帰呼び出しに
  引き継いだ**（棘守りの中継・巨躯の `blocked`・分かちの `taken`）
- **`ApplyDamage` の中は `OnDamaged` の連鎖で盤面が動く**ので、呼び出しの前後で残量を引くと
  「刻みが吸われた量」に連鎖で足された破片が混ざる

`burnTick` は**計数専用で、盤面の判断には一度も使っていない**（`isFriendlyFire` と同じ形）。

### 3-2. 対照（同数値・特性だけを落とした素体）

診断のローカルに 2 つ。`UnitCatalog` には足していない（第49期の `SgPlain` と同型）。

| 対照 | 中身 |
|---|---|
| `BorgNoCinder` | HP 60 / 攻 18 / 速 8 / 薙ぎ / **`Splash` を残し `Cinder` だけを落とす** |
| `HotaPlain` | HP 78 / 攻 6 / 速 7 / 単体 / **特性なし** |

**`Splash` を残すのが要点**——一緒に落とすと「巻き込みが消えたから勝った」と混ざる。

## 6. 判定（Q1〜Q5）

### Q1 —— 供給は過剰か（H2）

**全体の捨て率 35.5% → 中間。** 基準どおり波別・行別に分ける。

| 波 | 捨て率 | | 行 | 捨て率（波の幅） |
|--:|--:|-|---|---|

| 2 | 33.6% | | 燃焼 (ボルグ×ホタ) | 26.1〜55.0% |
| 3 | 29.0% | | 毒→被弾強化 (グザ×ムド) | 14.5〜50.2% |
| 4 | **49.5%** | | 縛め非収入型 (クグ×速攻) | 9.1〜43.4% |
| 5 | **19.5%** | | 止め改 (トメ×薙ぎ) | 0.0〜46.0% |

| | | | 逸らし (ソラ×カド) | **2.4〜35.2%** |

**H2 は「大半が捨てられている」までは言えないが、方向は正しい。** 3 分の 1 が捨て札で、
**第四波では約半分。** 支配している変数は1本で、**「ボルグが何ターン振り続けたか」**である
——ボルグは殴るたび隣接味方を再着火するので、火は消えず、2 回目以降の着火はすべて捨て札になる。
だから捨て率は決着ターン（表A' の 3.2 → 8.8）とボルグの生存に沿って動き、
最長の `速攻` 第四波（16.6T）で 65.8%、最短の `止め改` 第一波（2.0T）で 0.0% になる。

**系: 非スタックの通貨では「毎ターン撒く」供給者は、自分で自分の供給を捨てる。**
供給を増やす設計（2枚目の書き手）は、**この捨て札の山を増やすだけになる可能性が高い。**

### Q2 —— ホタは供給を待っているか（H1）

**燃えている状態で振った割合 100.0%（全5波・1000戦）→ 待ちは存在しない。H1 は否定。**

初着火は全波で第1ターン（1.00）。ボルグ（速8）> ホタ（速7）で、火の粉は `OnAfterAttack` なので
**ホタが最初の手番を迎える時点で既に燃えている。**

### Q3 —— 燃焼は通貨か（H3）

**燃焼を読んで分岐する箇所は engine 1 本（`TickStatuses` の刻み）＋ 駒 1 本（`PyreTrait`）＝ 2 本。**
基準の「2 本未満」には**届かなかった**ので、字義どおりには「通貨ではない」と断じられない。

しかし**表E の 18 セル（9 通貨 × 双方向）はすべて 0**で、
残った 2 本のうち engine の 1 本は**燃焼そのものの実装**である。
**他の通貨との接続点は 0、駒の読み手は 1。**

**H3 は実質的に正しい。** 燃焼はダメージ層としか繋がっておらず（§1-2 の 12 段はすべて
「ダメージ」を読んでいて「燃えている」を読んでいない）、**現状の燃焼は
「1枚の駒だけが読める、遅くて時間制限のあるダメージ」である。**

**注: 「読み手が 0 でない」と「接続がある」は別。** 第48期の「敵側の読み手は 10 通貨すべて 0」を
第50期に engine の窓口で訂正したのと同じ形で、**読み手の本数を数えるだけでは
「誰と繋がっているか」は出ない。**

| 止め改 (トメ×薙ぎ) | −0.1 | +1.2 | **0**（符号が反転。|帰属| < 1.5） |

**資産 2 / 代金 3 / ゼロ 2。** 分かれ目は隣接の顔ぶれで、
**代金側 3 行はすべて `着火(味) ≥ 2.16`**（毒→被弾強化 3.29 / 縛め非収入型 3.21 / 鱗改 2.16）、
**資産側 2 行はすべて `着火(味) ≤ 2.19`**（速攻 2.19 / 範囲耐性 1.96）。
ただし境界の 2.16 と 2.19 が逆順なので、**`着火(味)` 単独では説明が付かない。**

より確かなのは**波ごとの符号**で、火の粉が正に出るのは
**編成の出力が足りず、決着が伸びて刻みが積み上がる中間帯の波**である
（速攻の第3波 6.5 → 18.5 / 第4波 76.0 → 96.0）。逆に負に出るのは
**すでに勝てている行の第4〜5波**（鱗改の第4波 89.5 → 77.5 / 第5波 38.5 → 25.0）で、
**味方の燃焼が生存を削っている。**

### Q5 —— 第五波 4.5% の犯人

**条件2（熾火なし）で第五波は 4.5% → 0.0%（B帯 5.8% → 0.0%）。上がらない。**

**落としているのはホタ側ではない。** ホタを素体に落とすと第五波はむしろ全滅する。
第五波の 4.5% を作っているのは台のほうで、**ホタは 4.5% を稼いでいる側**である。

## 7. 仮説の当否

| 仮説 | 当否 | 根拠 |
|---|:-:|---|
| **H1** 燃焼に足りないのは2枚目の書き手 | **否定** | ホタは全 1000 戦で 100% 燃えた状態で振り、初着火は例外なく第1ターン。**待ちが存在しない**（表C・Q2） |
| **H2** 供給は既に足りていて着火の大半は捨てられている | **半分正しい** | 捨て率は全体 35.5%・第四波 49.5%・最長の行で 65.8%。「大半」ではないが**3分の1〜半分は捨て札**。しかも捨て率はボルグが振り続けるほど上がる（表A・Q1） |
| **H3** 燃焼が接続しているのはダメージ層だけで、事実を読んで分岐するのはホタ1枚 | **正しい** | 表E の 18 セル（9 通貨 × 双方向）がすべて 0。ダメージ層 12 段のうち燃焼を読む段は 0（§1-2・Q3） |

**指示書の「H2 と H3 が両方正しければ、書き手を足しても読み手を足しても効かない」は成立しない。**
理由は H1 の否定のされ方にある——**供給は「余っている」のではなく「一切足りていないわけではない」だけ**で、
実測の読み手はたった1枚しかないのに **100% 稼働・帰属 +52.3pt** を出している。
**捨て札が積み上がっているのは読み手がホタ1枚しかないからで、
2枚目の読み手はその捨て札をそのまま食える。**

**Phase 0-3 の予測（波ルールは燃焼に課金しない）は当たった**（表A'）。
燃ダメ ÷ 決着T は 4 種類の波ルールをまたいで 6.16〜7.61 でほぼ一定。
