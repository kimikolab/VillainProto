### 実装の形（測る前に固定）

- **札を割る（(b)）**: `TraitId.Kindle`（火を分ける）を足す。`Kindle` の名前は未使用（`Brand` は別の札）。手番のラベルで分ける——`KindleTrait` は「火を分けた」の手番だけ、`TaintTrait` は**それ以外の手番**で働く
- `Actions = [Skill 火を分けた, Skill 澱みを分けた, Skill 澱みを分けた]`。着火は `ctx.Ignite(味方, friendly: true, source: ベニ)`（支援拒否にも点く・乱数なし・席番号順）

- ヴェル: `Heal` を `HealOutcome` を返す形にし、`Inverted` なら縫い跡を残して手番を終える（殴らない）。**ヴェルがベニの隣にいない行は1ビットも動かない**
- 台本: 手番の `Skill` の `Text` が「火を分けた」「澱みを分けた」で区別できる。**反転の裏には表示専用のイベント `HealInverted` を足す**（`ActorId` 回復させた駒・`TargetId` 受けた駒・`Amount`・`Text` ＝ 裏の保持者の名前）——`Damage` の直前に1件。**盤面は読まない**

## 実装（予測のコミットの後）

- `TraitId.Kindle`（`KindleTrait`・「火を分けた」の手番だけで隣の生存味方全員に `Ignite(friendly: true, source: ベニ)`）。`TaintTrait` は**「火を分けた」以外の手番だけ**で働く1行を足した
- ベニ: `Traits = [Inverse, Kindle, Taint, InverseLeak]`・`Actions = [火を分けた, 澱みを分けた, 澱みを分けた]`。文面は指示書の案のまま
- **`Heal` の戻り値を `HealOutcome`（None / Healed / Full / Blocked / Drought / Inverted）にした**。既存の呼び出し口は文として呼んでいるので1本も変わらない。**分岐に使うのはヴェル（`StitchTrait`）だけ**——`Inverted` なら縫い跡を残して手番を終え（殴らない）、`Drought` の枝は今までどおり
- **表示専用のイベント `BattleEventKind.HealInverted`** を足した（`InverseLeakHit` の中・`Damage` の直前に1件。`ActorId` 回復させた駒・`TargetId` 受けた駒・`Amount`・`Text` 裏の保持者の名前）。**盤面は読まない**。再生側（`Main.cs`）は知らない種類を素通りする（変更 0 行）
- 計数: `KindleActs / KindleDry / KindleTargets`・反転の回復の **1〜3 ターン目の分**（毒・燃焼・起爆）と燃焼の名目（全体・1〜3 ターン目）・`KindlePostBurn`（ベニの火を持ったまま隣から外れた味方の燃焼の刻み）
- `checkup` の分類表・`TraitKeyMap`（燃焼）・`Map11Relations`（「火を分ける」の線・澱み分けの `Echo` を「火→毒→毒」に）に `Kindle` を足した
- **`Run` の引数は増やしていない**。`TickStatuses` と反転の分岐は第190期のまま（触ったのは計数の2行）

### 台本（§7・Codex 向けメモの材料）

- **ベニの手番が火か毒か**: `Skill` の `Text` が「火を分けた」／「澱みを分けた」で分かれる（(h) で確認）。**区別できる**
- **反転の回復**: 刻みの `Status`（`Text` 毒／燃焼）の直後に同じ駒の `Heal`（`ActorId` ＝ ベニ）。`Status` に紐づく `Damage` が無いので、今の再生では「[毒] 発動」の札のあとに回復の数字が出る
- **反転の裏**: **`HealInverted` を足したので区別できる**（直後の `Damage` の出どころは回復役のまま）。再生側はまだ読んでいないので、今は第190期と同じく「回復役が味方を殴った」ように見える
