## §0. 目的

- 第五波で 95% を超える行: 12（第184期前）→ **22**

敵の性格（特性・波ルール・配置）は1つも変えず、**数値だけを一律に上げるつまみ**を1本作り、その値を決める。

## §1. 作るもの

### 1-1. 規則 `EnemyScaleRule(int HpPercent, int AtkPercent)`

- 敵陣営の駒が盤面に出るとき（`Materialize` 相当・召喚を含む）、**最大HPと素の攻撃力**を
  `HpPercent` / `AtkPercent` 倍にする（切り捨て・最低1）
- **味方には一切かけない**。第一波（チュートリアル）にもかける（測定では除外する）
- 既定は `(100, 100)`（＝現行と1ビットも違わない）。採用値は §3 の基準で決めてから既定を差し替える
- 波ルールの数値（軛の上限25・渇き・粛など）、殉教者の成長量、敵の特性の係数は**触らない**
- `Run` の引数は増やさない（既存の規則の束に1本足す）

## §3. 採用基準（**測る前に固定し、予測と一緒にコミットする**）

S0〜S4 の対角線の中から1つ選ぶ（H3・A3 は分析用で採用候補にしない）。

1. **主基準**: `compare` 61行 × 第2〜5波の**情報セル数が最大**の版
2. 同数（差が2セル以内）なら、**第五波で 95% を超える行が少ない**版
3. それでも決まらなければ、**低い方の倍率**（強くしすぎない）
4. **足切り**: 主判定19行の第五波平均が **40% を下回る版は採らない**（ゲームとして成立しなくなる水準の目安）

## §4. 測定

1. S0 が現行の `docs/balance.md` と0件差分であること
2. 各版で: 波平均（全61行・主判定19行）／情報セル数／第五波 95% 超の行数／0% の行数（新たに生まれたもの）
3. **転生した駒の在席行**（第178〜186期で触った駒: ホタ・ウツ・スス・ムド・ヴィオ・ガン・ヴェル・ラウ・ヒサ・ザン・クグ・シガ・バン・ソラ）が
   各版でどう落ちるか。**特定の軸だけが崩れる版は無いか**（倍率が性格を変えていないかの確認）
4. H3 と A3 を S3 と並べ、HP と攻撃のどちらが解像度に効いているか
5. 診断台（ハイパーキャリー: ソラ×ガン×ガルド×ヒサ／ヒサ×ムド×ザン×トメ／クグ×シガ）を各版で。100% 張り付きが解けるか
6. 採用した版で `docs/` 再生成・`audit` ずれ0件・`ctx.PickOne` 総数不変

## 予測（実装前に宣言・コミット。**編成表の実駒を数えて書くこと**）

方向のみ:
- 情報セルは倍率とともに増え、ある点で 0% の行が増えはじめて減りに転じる（山型）
- HP を上げると撃破が遅れ、死亡・撃破トリガー系の行が下がりやすい。攻撃を上げると耐久系の行が下がりやすい
- 軛のある第四波は、攻撃の倍率が効きにくい（上限で切られる）
