### Q0-1 「受け流さなければ受けていた打点」は取れるか

取れる。受け流しの判定（`ApplyDamageBody` の受け流しの出口）が在庫を1つ減らす時点の `amount` で、既に `NoteParry` が `ParryBlocked` に足している値そのもの。
この値は段の並びで次の位置にある:

- **後**（済んでいる）: 攻撃側の補正（萎縮 −50%・痺れ毒——どちらも `PerformAttackBody` で `atk` を作る段）、範囲の盾（バンの差し替えは配る側）、破片、肩代わり（庇いの差し替え）、惨禍・§1 の +50%、据え・散開・萎縮 −30%・矢面の半減・踏みしめの層、`lethal: false` のクランプ
- **前**（まだ）: 猶予（1 で止める）と**軛の上限（25）**

したがって「受け流した刃」は**軛で切られる前の値**。第四波では受け流さなければ 25 に切られていた一撃も、切られる前の打点で数える（指示書の「受け流しの判定の時点の値」どおり）。

### Q0-4 勝敗の判定と、相打ち勝ちを1経路に閉じる方法

- 戦の終わりは2箇所: ターンの頭（どちらかが全滅なら抜ける）と、行動順ループの各手番の前（相手陣営が全滅なら抜ける）。
- 勝敗は最後の1行 `playerWon = TeamAlive(味方) && !TeamAlive(敵)` だけ。**両陣営が同時に全滅すると負け**。
- 相打ちの流れは `ApplyDamage(ガルド)` → `OnDamaged`（ここで斬り返し → 敵の `HandleDeath` → 敵の死亡通知）→ ガルドの `HandleDeath`。**斬り返しで最後の敵が倒れた時点で、ガルドはまだ死亡処理の前**。
- 閉じ方: **相打ちの斬り返しの直後に「敵陣営に生きている駒がいない」なら `BattleContext` の印（相打ち勝ち）を立て**、最後の1行を「`(味方が生きている || 印) && 敵が全滅`」にする。印を立てる口は相打ちの斬り返し1箇所だけ（`dying` の枝）。敵の死亡通知で分裂・召喚が湧けば敵は全滅していないので立たない。

### Q0-5 生存者 0 の勝ち

- **会戦（`EngagementEngine.Run`）**: 部隊の尽き方は「投入した駒の生存数」と `PlayerWon` で決める（`clearedE` ＝ 敵の生存 0 ／ `lostP` ＝ 味方の生存 0 または負け）。相打ち勝ちは**両方が立つ**——敵部隊を1つ抜き、味方部隊も1つ失う。両方が最後の部隊なら従来どおり「両方同時に尽きたら味方敗北」。割り算は無い。
- **作戦マップ（`Map11State.Resolve`）**: こちらも生存数で分ける——敵のマスは制圧、味方の隊は `Lost`。`PlayerWon` を読むのは道中の回復だけで、生存 0 の隊には掛からない。迎撃の勝ちの計数（`Map11Time`）は1つ増える。
- **BattleSim の診断**: `PlayerSurvivors` で割る箇所は 0 件（`grep`）。生存 0 の勝ちは「辛勝（生存 1 以下）」に数えられる（`chain` など）。**意味として正しいので直さない。**
- **DemoApp の画面**: 勝ちの演出（`ShowVictoryPortraits`）は全駒に勝利の動きを流す——倒れた駒にも流れるかは演出側で確かめる（Codex 側）。

## 実装

- 規定の札 `TraitId.LastStandHold`（`LastStandHoldTrait`）をガルドに載せた。3点は **const 3本**で切り替える——
  `HoldCountsParried`（2.1）／ `HoldKeepsStock`（2.2）／ `HoldMutualWin`（2.3）。対照は1点ずつ外した札
  （`LastStandHoldOldScar` / `LastStandHoldNoStock` / `LastStandHoldMutualLoss`・保持者 0 枚）で、第198期の規定は `LastStandScar`（保持者 0 枚）として残した。
  **const だけにすると版の比較のたびにビルドし直すことになる**ので、規定の札の振る舞いを const で決め、対照は札で並べる形にした（どれも1プロセスで回せる）。
- **2.1**: engine の受け流しの出口で、剣を抜く前なら私有キー `LastStandTrait.ParriedKey` に**判定の時点の打点**（軛より前）を足す。抜く瞬間に（身に受けた傷 ＋ 受け流した刃）× 10% を上乗せにする。
- **2.2**: 抜いた瞬間に在庫を捨てない。構え直し（`ParryTrait.OnTurnStart`）と庇いの補充（`GuardianTrait.Reward`）は `ShieldDropped`（＝盾剣以外の剣の段）で止めたまま。受け流しの判定は第198期までと同じで、受け流した一撃は `OnDamaged` に届かないので斬り返さない。
- **2.3**: 相打ちの斬り返しの直後に `BattleContext.MarkLastStandVictory` が「相手陣営に生きている駒が 0」なら印を立て、`BattleEngine.Run` の勝敗の1行を「（味方が生きている **または** 印）かつ 敵が全滅」にした。**印を立てる口は相打ちの枝の1箇所だけ。**
- 表示専用: `BattleEventKind.LastStandVictory`（相打ちで勝った瞬間）、`LastStand` の `StatusRemaining` ＝ 上乗せの量。
- `Run` の引数は増やしていない。乱数は引かない。

### 読み

1. **勝てるようになったのは延命ではなく打点**（R306）。入った戦の勝率は 25.8 → 60.2% だが、倒れた戦の「抜いてから倒れるまで」は 0.9 → 1.1 ターンしか延びない。延びたのは「倒れる前に終わる戦」で、倒れた割合が 74.2 → 47.5%。
2. **寄与は 傷 ＞ 在庫 ＞ 相打ち勝ち**（入った戦の勝率で −25.6 ／ −8.9 ／ −7.7pt）。上乗せの元を広げたのが本体で、在庫と相打ち勝ちはほぼ同じ大きさ。
3. **盾剣（62.1%）には 1.9pt 届かない**が、在席行の勝率では 81.2 対 81.5 とほぼ並ぶ。盾剣は倒れにくく（33.4%）、199 は相打ちで決める（倒れた 47.5% のうち 7.7pt が勝ち）——**勝ち方が違う**。
4. **相打ち勝ちは入った戦の 7.7%**（相打ちが起きた戦 39.5% の約 5 分の 1）。印は相打ちの1箇所でしか立たず、生存 0 の勝ちは全部この経路（自己検査 (d)）。

### 台本（§6-8）

- **上乗せの量**: `LastStand` の `StatusRemaining`（加えた攻撃力・×2 の前）。`Amount` は抜いた後の攻撃力。鎧の光の強さはどちらからでも引ける。

- **残った構えでの受け流し**: 抜いた後も既存の `Parry` イベントがそのまま出る。
- DemoApp は未知のイベントを素通りするので完走する（`渡し` 第五波 seed 14 が相打ち勝ち・`礫` 第五波 seed 9 は 198 で負け → 199 で勝ち、どちらも `DEMO_SMOKE_COMPLETE won=True`）。
