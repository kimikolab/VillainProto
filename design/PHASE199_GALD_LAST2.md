### Q0-1 「受け流さなければ受けていた打点」は取れるか

取れる。受け流しの判定（`ApplyDamageBody` の受け流しの出口）が在庫を1つ減らす時点の `amount` で、既に `NoteParry` が `ParryBlocked` に足している値そのもの。
この値は段の並びで次の位置にある:

- **後**（済んでいる）: 攻撃側の補正（萎縮 −50%・痺れ毒——どちらも `PerformAttackBody` で `atk` を作る段）、範囲の盾（バンの差し替えは配る側）、破片、肩代わり（庇いの差し替え）、惨禍・§1 の +50%、据え・散開・萎縮 −30%・矢面の半減・踏みしめの層、`lethal: false` のクランプ
- **前**（まだ）: 猶予（1 で止める）と**軛の上限（25）**

したがって「受け流した刃」は**軛で切られる前の値**。第四波では受け流さなければ 25 に切られていた一撃も、切られる前の打点で数える（指示書の「受け流しの判定の時点の値」どおり）。

### Q0-3 抜いた瞬間の受け流しの在庫

**0 が 15.9% ／ 1 が 39.7% ／ 2 が 44.4%**（3 以上は 0）。平均 1.29。第五波は 0 が 17.9%、第2〜4波は 0 が 4.5〜6.3% と少ない。

### Q0-4 勝敗の判定と、相打ち勝ちを1経路に閉じる方法

- 戦の終わりは2箇所: ターンの頭（どちらかが全滅なら抜ける）と、行動順ループの各手番の前（相手陣営が全滅なら抜ける）。
- 勝敗は最後の1行 `playerWon = TeamAlive(味方) && !TeamAlive(敵)` だけ。**両陣営が同時に全滅すると負け**。
- 相打ちの流れは `ApplyDamage(ガルド)` → `OnDamaged`（ここで斬り返し → 敵の `HandleDeath` → 敵の死亡通知）→ ガルドの `HandleDeath`。**斬り返しで最後の敵が倒れた時点で、ガルドはまだ死亡処理の前**。
- 閉じ方: **相打ちの斬り返しの直後に「敵陣営に生きている駒がいない」なら `BattleContext` の印（相打ち勝ち）を立て**、最後の1行を「`(味方が生きている || 印) && 敵が全滅`」にする。印を立てる口は相打ちの斬り返し1箇所だけ（`dying` の枝）。敵の死亡通知で分裂・召喚が湧けば敵は全滅していないので立たない。

### Q0-5 生存者 0 の勝ち

- **会戦（`EngagementEngine.Run`）**: 部隊の尽き方は「投入した駒の生存数」と `PlayerWon` で決める（`clearedE` ＝ 敵の生存 0 ／ `lostP` ＝ 味方の生存 0 または負け）。相打ち勝ちは**両方が立つ**——敵部隊を1つ抜き、味方部隊も1つ失う。両方が最後の部隊なら従来どおり「両方同時に尽きたら味方敗北」。割り算は無い。
- **作戦マップ（`Map11State.Resolve`）**: こちらも生存数で分ける——敵のマスは制圧、味方の隊は `Lost`。`PlayerWon` を読むのは道中の回復だけで、生存 0 の隊には掛からない。迎撃の勝ちの計数（`Map11Time`）は1つ増える。
- **BattleSim の診断**: `PlayerSurvivors` で割る箇所は 0 件（`grep`）。生存 0 の勝ちは「辛勝（生存 1 以下）」に数えられる（`chain` など）。**意味として正しいので直さない。**
- **DemoApp の画面**: 勝ちの演出（`ShowVictoryPortraits`）は全駒に勝利の動きを流す——倒れた駒にも流れるかは演出側で確かめる（Codex 側）。
