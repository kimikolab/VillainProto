# 第270期 指示書 —— レリックの器と最初の札（段0〜段2の最小）

読み手は Claude Code。新しい本線「レリック」の最初の期。目的・原則・候補は本文に埋め込んである（Web 側の構想メモは参照しない）。

## 0. 位置づけ

**レリック＝編成のとき駒に後付けできる「繋ぎ」の札。** 目的は「移動軸は移動軸だけ、毒パは毒だけで組む」が最適にならないようにすること——ある軸の資源（移動・毒・感電・燃焼・回復・被弾）を別の軸の資源に変える橋を架け、軸を混ぜた編成が答えになりうる状態を作る。

実装の土台はある: 駒の特性はすべて札（`TraitId`）の組み合わせなので、レリックは「編成時に駒へ札を1枚足す」形で乗る。

時期の根拠: ボス（第269期確定・compare 61行中 0% が52行）が「測る壁」として立った今、「レリックを付けると勝てるようになる行が出るか」という形で、レリックの価値をかつてなく具体的に測れる。

### 設計の原則（全期間有効）

1. **駒の1文は駒のもの、レリックは繋ぎだけ**。駒の個性（捨てられた理由）を上書きしない
2. **ただ強くする数値のレリックは作らない**。基本は「引き金 → 効果」。例外は制約つきの変換（攻→HP で攻は0になる等）と速さの微調整（±1〜2）——純増ではなく「選択」になるものだけ
3. **マイナスのレリックは読み手がいることが条件**（そのマイナスを得に変える駒がロスターに1体以上いる）
4. **軸をまたぐ繋ぎを優先**
5. **枠は1体1個まで**（部隊の上限はまだ決めない）
6. 地味な文面が既存規則と組んで想定外に働くのは歓迎。ただし起きる挙動は規則に明記し、不具合にしない
7. **駒に依存する数値は汎用化してから**（ヨミの +9 はヨミのもの。レリックなら「動かされるたび +2」）

### ⚠ レリックは転生の代替にならない（ポンの条件・全期間有効）

- レリックで✕・△の駒が勝者になっても、**その駒の転生候補としての評価は変えない**。評価はレリック抜きの素の駒で下したものであり、レリックで立つのは外部の文脈であって駒の1文ではない
- レリックの測定結果を `roster_audit` や転生候補の棚（✕16・△30・○6）に書き戻さない
- レリックの設計目的に「✕駒の救済」を置かない（目的は軸の橋架け。救済が副産物として起きたら、報告に「素の個性は不変・転生判断の材料にしない」を併記する）

## 1. Phase 0（段0: 札の棚卸し）

1. **持ち運べる札の仕分け**: 既存の `TraitId` を3分類する——(a) そのまま別の駒に付けられる札 (b) 汎用化（数値・対象の持ち主依存を外す）すれば使える札 (c) 持ち主の1文と不可分で持ち出せない札。§3 の候補それぞれに「既存札の流用か・新規か・実装の規模」を書く
2. **器の実装点**: 編成の枠に札を1枚足す最小の形（`Formation` / 編成の定義のどこに乗るか）。駒の素の札との発火順・重複（同じ `TraitId` が素とレリックで二重になるケース）の扱いを決める
3. **BattleSim の受け口**: 編成定義にレリックを書く記法と、compare 等の既存の測りがレリック無しで1バイトも変わらないことの確認方法
4. 過去にレリック類似（後付けの札）を測った期がないか `design/` を grep

## 2. 段1: 器

- 編成の各枠にレリックを**1個まで**付けられるようにする（`BattleCore`）。付けない枠は従来と完全同一
- DemoApp の選択画面はこの期ではやらない（Codex 分担・器が固まってから）

## 3. 段2の最小: 札6個前後

候補表から、**棚卸しで安く書けるもの**を優先して6個±2を選ぶ。構成の条件: **軸をまたぐ繋ぎ ≧ 3・ゴミ ≧ 2**。

### 候補（叩き台・選定は Phase 0 の棚卸しに従う）

| 種別 | レリック（仮） | 文面 | 橋／読み手 |
|---|---|---|---|
| 繋ぎ | 軋む足 | 動かされるたび攻撃力 +2 | 移動 → 火力（ヨミの汎用化） |
| 繋ぎ | 火付けの矢 | 攻撃が当たった敵に燃焼 1 | 攻撃 → 燃焼 |
| 繋ぎ | 毒の足跡 | 動かされるたび、隣の敵に毒 1 | 移動 → 毒（蝕みの読み手にもなる） |
| 繋ぎ | 弾性 | 殴られると、殴った敵を1つ後ろへ弾く | 被弾 → 敵の移動 |
| ゴミ | 萎える心 | 被弾すると攻撃力 −2 | ウツ（弱体を強化に逆転） |
| ゴミ | 痺れる足 | 動かされると次の手番を失う | ガン（号令）・バン（据え） |
| 変換 | 身を固める | 攻撃力を HP に変える（攻撃力は 0） | 壁・挑発役化 |

## 4. 測定（この期は正しさの確認まで。本判定は第271期）

- **回帰**: レリック無しの全既存測定（compare 305セル・`checkwave`/`bosswave` の再現）が 0 件差分・全行一致
- **器の自己検査**: 札の付与・1体1個の制限・素の札との重複時の挙動が仕様どおり
- **スイープ（気配の確認）**: `bosswave` の7台 × 実装した札それぞれ1個（付け先は各台で1枠・選び方は固定規則で）で、動く向きが札の文面と合っているか。固有の勝者探し・混成率はやらない（総当たりの器具は第271期）
- **個性の保存**: 札を付けた駒の元の役割の指標（例: ヨミの与ダメ）が消えていないことを1例以上

## 5. 予測（Phase 0 の後・実装前に書く）

方向のみ: 毒の足跡・火付けの矢は蝕み・燃焼の既存読み手に乗って `bosswave` で正の向き、ゴミ2枚は読み手（ウツ・ガン・バン）のいない台では純粋な負の向き。±0 であるべき組（札を付けない台・レリック非対応の測り）を先に列挙する。
