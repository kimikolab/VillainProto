# 第265期 指示書 —— 本編ボス波「勇者パーティー」（第六波）

読み手は Claude Code。チェック波（第260〜264期・`design/CHECK_WAVE_SUMMARY.md`）の成果を本編に載せる最初の期。器具・札・7台はそのまま使う。

## 0. 位置づけ

検証波 B3-桁（全体攻撃・動じない・HP 3,000・天井 +11）は物差しとしては完成したが、本編に置くには2つの「取り上げた解答」を返す必要がある:

- **動じない（完全無効）**は制御軸の解答を丸ごと消している。検証波では正しいが、本編では「回避可能な課税」（渇きの祭司の形）に変える
- **毎ターンの回復**も同じ。削り切る以外に「回復を断つ」解答があるべき

→ ボスを**本体＋取り巻き2体**の形にし、取り巻きがこの2つの源になる。割る順序そのものがプレイヤーの解答になり、軸ごとに順序が違えば「同じ波に別の理由で勝つ」が成立する。

**フレーバー: 勇者パーティー。** 敵ロスターの頂点は勇者候補（速14・Executioner）。最終波がその完成形「勇者」なのはテーマの収まりが良く、天井（毎ターン成長）は Executioner の雪だるまと同族の性質として読める。捨てられた駒たち vs 選ばれた者たち。

## 1. 決定（この期はこの前提で進める）

1. **第六波として `Stages` に足す**（本編の波。倍率なし）。既存5波のセルは1つも動かさない（compare は列が増えるだけ）
2. **形: 勇者（中央）＋支え＋癒し手の3体**
   - **勇者**: B3-桁 の本体ベース（全体攻撃・HP 3,000・天井 +11・攻 12・速 14）。ただし**回復と動じないは自前で持たず、取り巻きから受ける**
   - **支え**: 生きている間、勇者は動じない（手番を奪う効果を受けない）。倒れると勇者に転倒・痺れが通る
   - **癒し手**: 毎ターン勇者を最大HPの一定割合回復（W3-割合 の式の流用・対象は勇者のみ）。倒れると回復が止まる
   - 取り巻きの体は既存の敵と同数値＋特性1枚（候補: 城塞の重装兵 145/12/3。従軍司祭 40/9/8 は検証波の実測で即割れするので不適）
3. **勝ち＝敵全滅**（通常規則のまま）。勇者だけ倒して終わりにはしない
4. **回復課税（渇き系・混ぜ/雷への R362 対策）はこの期に入れない**。B3-桁 の実測で混ぜ・雷は天井が効く前に倒し切っており（T6〜8.8）、「負けない」ではなく「勝っている」。闇鍋を避け、ノブは取り巻き構造だけにする

3. **取り巻きの席と到達手段**: `ENEMY_FORMATION_PLAN` の席の表（○後2 は前列・中列全滅後の単体か全体でしか届かない等）を現地のコードで確認し、§3 の2版の席が意図どおりの到達差になるか

## 3. 版（席だけを動かす）

| 版 | 支え | 癒し手 | 課税の向き |
|---|---|---|---|
| H-制御税 | **○後2**（貫き以外届かない） | 後1 | 制御解禁が遠い＝移動・雷に重い |
| H-回復税 | 後1 | **○後2** | 回復断ちが遠い＝長期戦の台に重い |
| 対照 | なし（B3-桁 の既測をそのまま併記・再測不要） | | |

どちらを規定にするかは測ってから決める。取り巻きの数値・勇者の数値は2版で完全同一（差分は席だけ）。

## 4. 測定と採否

- 7台 × 2版、seed 0..199。指標は連続量（倒しT・純実入り・崩れ始め）＋**支え/癒し手を割ったT と割った順**＋副に勝率
- 採否（検証器具ではなく本編の波なので、基準は「勝つ編成の集合」ではなく**解答の分化**）:
  - **割る順序が軸で分かれる**こと（全台が同じ順序なら取り巻きは飾り＝棄却）
  - 2版で**倒しT の順位が入れ替わる台がある**こと（席が課税として効いている証拠）
  - 全軸が勝てること（勝率 0% の台が毒以外に出ないこと。出たら数値ではなく構造を疑う）
  - 既存5波 305 セル 0 件・`checkwave` の再現全行一致

## 5. 予測（Phase 0 の机上計算で数値を足してから実装）

- **移動・雷**: 支えを先に割る。割った後は転倒・痺れで勇者の手番を削り、倒しT が B3-桁 より縮む。H-制御税では支えに届きにくく倒しT が伸びる（移動は単体中心なので特に）
- **燃焼**: どちらも割らずに最速で削り切る（T3〜4）。2版の差がほぼ出ない台として予測
- **毒+ベニ+ラウ**: 癒し手を先に割って長期戦に持ち込む。H-回復税で最も苦しい
- **混ぜ**: 全体への被弾反応で手数が伸びる（第262期の発見）ので、取り巻きが増えた分だけ倒しT が縮む方向
- 割った順の分化が3通り以上出れば、この波は「同じ波に別の理由で勝つ」を本編で初めて体現する
