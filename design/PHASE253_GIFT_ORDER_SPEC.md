# 第253期 指示書 —— ボルグの育ちを規定に・ギフトの渡す順（ボルグ → ホタ）

置き場所: `design/PHASE253_GIFT_ORDER_SPEC.md`。報告は `design/PHASE253_GIFT_ORDER.md`。
期の番号が使用済みなら、空いている番号で回してよい（指示書のファイル名は変えない）。
この期は**線を置いて規定化する**（ポンの判断）。

## 1. 目的

第252期で、ボルグの爆炎の発動が遅い問題はほぼ解けた（本編 400/300 で爆炎 0.13〜0.53 → 0.90〜1.39/戦、初めて撃つ周回 T3.2 → T1.4〜1.8）。効いたのはほぼ「守るほど燃え上がる」（B1）。

残る1点: **九体の波では、まだボルグの番が来ない**（T3-244 で 0.01 → 0.02）。ボルグは周回2 に 69% の戦で火勢4 に届いているのに、2体に渡すギフトでホタが先に動き、焼き尽くすで戦が終わる（R355）。直すのは育ち方ではなく**渡す順**。

ポンの判断:

- 規定にする組: **守るほど燃え上がる（B1）＋ 開幕の火勢（B2）＋ 溜め火（O1）＋ 渡す火（H1）**（第252期の推し。M1+ から B3 を抜いた形。この組そのものはまだ測っていない）
- ボルグのあぶれた火は**溜め火**（爆炎が主役になる方。勝ちやすさは鎧の火が上だが、燃焼の勝率は第五波以外は天井）
- **2体に渡すギフトは、ボルグ → ホタの順**（爆炎で敵の脆さと味方の回復を作ってから、ホタが焼き尽くす）

## 2. 足すもの

### 2.1 ギフトの渡す順

| 項目 | 内容 |
|---|---|
| **渡す順** | ヒヨが**2体に**ギフトを渡すとき、相手にボルグが含まれていれば、**ボルグの手番を先**にする（もう1体はその後）。相手の選び方（指名・火勢・P′）は今のまま。1体に渡すときは変えない |

- 渡す火（H1）の火勢の上げは、両方の相手に、手番が始まる前に今までどおり
- ボルグの爆炎で戦が終わった場合、2体目の手番は来ない（今の規則どおり）

## 4. 線（測る前に決める）

**N2 を規定にする条件**（T3-244 と T3-238 の2席で）:

1. 本編の第2〜5波 × 400/300 の勝率の平均が、N0 より 1.0pt 以上下がらない
2. **九体の波（新兵・農兵）× 200/200・400/300 で、ボルグの爆炎が N0 より増える**

両方を満たせば N2 を規定に。2 を満たさず 1 を満たすなら N1 を規定にし、渡す順は報告に回す。1 を満たさなければ、どれも規定にせず報告する。

規定にするもの（N2 の場合）:

| 駒 | 規定に足す札 |
|---|---|
| ボルグ | 守るほど燃え上がる（B1）・開幕の火勢（B2）・溜め火（O1） |
| ヒヨ | 渡す火（H1）・渡す順 |

- `units.md` のボルグ・ヒヨの文面は、第252期の報告 §6 の候補から入れる（渡す順の1文を足す）
- 旧の駒は対照として残す。第233〜252期の燃焼の測定用モードがその期の駒に固定されていることを確かめる
- `FIRE_AXIS_SUMMARY.md` に第252〜253期を追記
