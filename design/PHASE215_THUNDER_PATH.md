## 0. Phase 0（実装前・盤面は第214期のまま）

### Q0-1 第214期の表を T0 で再現できるか

第214期の `shock run` をそのまま回し直して、第214期の出力と行ごとに突き合わせた。**数字はすべて一致**（表A〜E・表E' の全行）。
違ったのは2つだけ——所要時間の行と、表C'（連鎖を起こした駒の多い順）で**同じ値（0.25/戦）の2駒の並び順**が入れ替わった3行。
後者は `Parallel` の合流順で `Dictionary` の列挙順が変わるためで、**値ではなく並べ方**の揺れ。同値は Id の順で並べるように直した（表示だけ）。

あわせて、**台の席を選ぶ版を第214期の K1（＝T0）に固定した**（`ShockDiag.KataT0`）。T1 を規定にして `UnitCatalog.Kata` の札が変わっても、
台の席は第214期と同じまま動かない（指示書 §6「第214期の台・席をそのまま使う」）。固定の前後で席は1つも変わらない（上の突き合わせがそれ）。

### Q0-2 T1 でも取り残しが残りうる形（手で数えた）

T1 の比べ方: ① 種類が多い → ② その先に跳べる相手（隣で・未命中・生存・帯びた敵）が少ない → ③ 席番号。**全員の種類が同じとき**:

| 敵の形 | T0（席番号だけ） | T1 |
|---|---|---|
| X字 5体 | 前1 → **中央** → 前3 → 後3（後1 を取り残す） | 前1（先は 2＝中央・後1）→ **後1**（先 1）…中央（先 3）より少ない → 中央 → 前3（先 1・後3 と同数で席番号）→ 後3 ＝ **全員** |
| X字 ＋ ○前2 に召喚（6体） | 前1 → 中央 → 前3 → 後3（後1・○前2 を取り残す） | 前1（先 3・前3 と ○前2 と同数で席番号）→ 後1（先 1）→ 中央 → 後3（先 1・○前2 と同数で席番号）→ 前3 → ○前2 ＝ **全員** |
| X字・前1 が倒れている（4体） | 前3 → 中央 → 後1（後3 を取り残す） | 前3 → 後3（先 1）→ 中央 → 後1 ＝ **全員** |
| X字・中央が倒れている | 前1–後1 と 前3–後3 の2組に割れる——**どちらでも1組しか回れない**（2体取り残す・跳ねの規則では直らない） | 同じ |
| パターン3 5体 | 前衛 → 中衛・上 → 後衛・上 → 後衛・下 → 中衛・下 ＝ 全員 | 同じ道（中衛・上と中衛・下は先 2 で同数・席番号） |

**T1 でも取り残しが残る形は、種類がばらばらなとき**——第一の鍵は種類なので、前1 から見て中央の種類が後1 より多ければ、T1 でも中央へ跳んで後1 を取り残す。
**第214期の表B では1発の種類が混ざっている**（台1 X 字: 1 種 36% ／ 2 種 52% ／ 3 種 12%、台3 X 字: 1 種 56% ／ 2 種 44%）——種類が揃わない主な理由は
スィドの痺れ毒（攻撃力の高い敵から）・ムドの呪い（殴ってきた敵）・前の手番の感電の残り。
