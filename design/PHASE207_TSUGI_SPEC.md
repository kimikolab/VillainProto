## 1. 目的

### 1.1 ポンの第一目標

**ヒーラーの代わりに耐久して、一人も落ちずに勝てるライン**を目指す。
リリ（施しのリリ・第204〜206期）は回復役の席を取った。ツギは**回復を使わずに**、同じ仕事（誰も落とさない）をする。

### 1.2 背景

- 置き去りのナラ（HP62／攻9／速8・`Forsake`）はポンの評価で △「一部の駒限定のヒーラー。使いにくい」。理想台の帰属 −4.83（素体より弱い 6 枚の1つ）
- 速さの軸（速い味方を癒し遅い味方を削る）は「速さの差で回復量が変わるだけ」としてポンが不採用
- **渇きの第三波ではリリも無力**（回復は `Heal` の入口で止まる）。回復を使わないヒーラーが欲しい
- ポンの参考: スターレイルでは「ヒーラーかバリアか」を選んで耐久編成を組むことが多かった
- 破片を作る既存の駒はどれも条件付き・受け身（ヒビ＝範囲攻撃を受けたとき全員に薄く／ウケ＝隣の弱体を背負った分／ササ＝切り落とした分を突き飛ばした味方に）。**手番で毎回、狙って厚く配る駒はいない**

### 1.3 像と絵コンテ

**継ぎ当てのツギ**。壊れた鎧や瓦礫を拾って、仲間に無理やり貼り付ける小柄な職人娘。背中に鉄板・木片・骨片・盾の残骸を積んでいて、戦闘中にガチャガチャ貼る。

- フレーバー: 「治せない。だから、これ以上壊れないように塞いだ。」

1. 敵の大物が大剣を振りかぶる
2. ツギが背中から板を引き抜き、前衛にガチャガチャ貼り付ける
3. 大剣が板を砕き、破片が散る——ツギがそれを拾って背中に放り込む

## 2. 変更

### 2.1 駒

- ナラを**その場で**ツギに転生させる（第204期のリリと同じ扱い）。表示名・`Id`（`"tsugi"`）・`UnitCatalog` のフィールド名を変え、`Presets` の行名に「ナラ」「置き去り」が入っていれば直す（行の中身は変えない）
- 旧ナラの定義は**対照として残す**（`All` には入れない）。`ForsakeTrait` は触らない
- HP62／攻9／速8 は据え置く。`Actions = [Skill]`（手番は貼ることに使い、通常攻撃は出ない）
- 旧ノノの対照（`UnitCatalog.Nono`・表示名「継ぎ当てのノノ」）と表示名の「継ぎ当て」が重なる。対照は `All` に無いので実害は無いはずだが、Phase 0 で名前を引いている診断・台本が無いか確かめる

### 2.2 手番: 板を貼る（本体）

1. **破片が最も薄い味方**を選ぶ（ツギ自身を含む。同値は HP 割合が低い方、それも同値なら既存の同値割りの窓口）
2. その味方に**破片**（`StatusKeys.Armor`）を足す。量は
   **max(`PlankFloor`, 生きている敵のうち最も高い攻撃力) ＋ 背中の在庫（§2.4）**。規定 `PlankFloor = 6`
   - 攻撃力は**その時点の値**（上げ下げ込み）。ネルが下げれば板も薄くなる（そのときは敵の一撃も弱い）
   - 在庫は貼った分だけ使い切る（0 に戻る）
3. その味方に**板の印**（新しい状態キー `plank`・表示「板」）を付ける。印は**その味方の破片が 0 になったとき**に消える
- 破片は回復ではないので、**渇きでも止まらない**。支援を受け付けないガルド（`Stoic`）にも届く（ヒビの破片と同じ扱い。Q0-3 で確かめる）

### 2.3 マイナス: 板は燃えやすい

- **板の印を持つ味方に燃焼が付くとき、燃焼の残りターンを倍にする**（点く・点け直し・移される、のすべての経路。Q0-4 で経路を列挙する）
- ねらい（符号が編成で変わる）:
  - **ホタ**: 燃えている間は攻撃4倍・貫き・火に焼かれない。長く燃える＝長く強い。しかも破片で守られ「すぐ落ちる」が解ける（**資産**）
  - **ベニ**: 自分と隣の味方の火の削りは回復に化ける（ベニの手番で隣に火を配る）。長く燃える＝長く癒える。溢れは紅蓮に溜まる（**資産**）
  - **ボルグ**: 両隣の味方に火が移る。板を貼った隣は長く焼かれる（**災厄**）
  - **リリ**: 燃えた敵から火を吸い取って味方へ移す（編成次第）
- **ツギ自身が火を点ける手段は無い**。火の書き手がいない編成ではマイナスは 0

### 2.4 背中の在庫: 瓦礫を拾う

- 戦場で何かが壊れると、ツギが拾って背中に積む（**ツギが生きている間だけ**）:
  - **味方の破片が砕けた**（敵の一撃で剥がれた・ガレが砕いた・ウロの破片が剥がれた等）: 砕けた量の `ScrapRate`%（規定 50）
  - **駒が倒れた**（敵味方を問わない）: 1体につき `ScrapPerFall`（規定 5）
- 在庫は次の手番で板に上乗せして使い切る（§2.2）
- ねらい: 最初は「一撃ぶん」の板だが、戦が荒れるほど厚く貼れる。**ガレと循環する**（ツギが貼る → ガレが砕いて撃つ → ツギが拾う → 次はもっと厚く）

### 2.5 版（**並べる・採用は決めない**）

## 4. 診断

**主な指標は「全員生存勝ち」**（勝った戦のうち、味方が1体も倒れなかった戦の割合。および全戦に占める割合）。ポンの第一目標。

1. `compare` のツギ在席行（旧ナラの行）。版は §2.5 の4つ。第2〜5波
2. **差し替え診断（`swap`・`compare` には入れない）**: リリの在席 8 行で、**リリの席にツギ（T3）を置いた版**を作り、リリ（第206期の規定）と比べる。行ごと × 波ごとに:
   - 勝率・**全員生存勝ち**・倒れた味方の平均数・決着ターン・膠着
   - **第三波（渇き）と第四波（軛）を特に見る**（リリが渇きで無力な波）
   - カドの与ダメ（破片でカドの反撃が止まるか。リリ版と比べる）
3. **火の診断（`compare` には入れない）**: `燃焼 (ボルグ×ホタ)` のリリの席にツギを置いた行。T1 / T2 / T3 で:
   - ホタが燃えていたターン数・ホタの与ダメ・ホタが倒れた戦の割合
   - ボルグの隣の味方が受けた燃焼ダメージ
4. ベニのいる `compare` 行があれば、ベニの隣の1枠をツギに替えた診断行を1つ（決め方は任せる。無ければ作らない）。ベニの回復量・紅蓮の回数を T1 / T2 で比べる
5. 帳簿（版ごと・1戦あたり）: 貼った回数・貼った破片の合計・受け止めた量（破片で止まった被ダメ）・在庫の拾い（砕け／倒れ別）・1回あたりの厚さ・板の印で倍になった燃焼の回数・ツギが倒れた戦の割合

診断台は回さない。

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0-1・Q0-6 を数えてから入れる。

- ツギを含まない行は ±0.0。T0 は第206期の表と一致
- T1 はナラの在席行で T0 を上回る（旧ナラは遅い味方を削っていた）
- 差し替え診断: **第三波（渇き）ではツギがリリを上回る**。第二・五波ではリリが上回る行が多い（リリは火力も出すため）
- 差し替え診断: カドのいる行では、ツギの版でカドの与ダメが下がる（破片で受けると反撃しない・第204期の前例）
- 火の診断: T2 でホタの燃えていたターン数と与ダメが T1 より増え、ボルグの隣の味方の燃焼ダメージも増える
- 在庫（T3）は、倒れる駒が多い波・破片がよく砕ける行で板を厚くする
- **天井（99〜100%）の行は勝率に出ない**。全員生存勝ちの差で読む（R092）

1. ツギを含まない `compare` 行が 0 セル差分。T0 で第206期の表と一致

### `units.md` の文面（案・T3）

- 名前: 継ぎ当てのツギ
- 特性: 手番で、破片が最も薄い味方に板を貼る（最も強い敵の一撃ぶんの破片・最低6）。回復ではないので渇きでも止まらず、回復を受け付けない味方にも届く / 味方の破片が砕けたり、誰かが倒れたりすると、瓦礫を拾って背中に積み、次の板を厚くする
- マイナス: 板を貼られた味方は燃えやすい。火が付くと、倍の間燃え続ける。自分では攻撃しない
