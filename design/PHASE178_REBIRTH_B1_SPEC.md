# 第178期 指示書 —— B群の転生 1枚目・2枚目（熾のホタ／逆しまのウツ）

置き場所: `design/PHASE178_REBIRTH_B1_SPEC.md`。報告書は `design/PHASE178_REBIRTH_B1.md`。
前提: `docs/roster_audit.md`・`design/TURN_SLOT_PLAN.md`・ポンの駒別評価（✕16・△30・○6）。

## 0. 基準（この期から B群 全体に使う）

ポンの言葉:「移動軸が今一番楽しいのは、混乱→味方の移動→バフ→追加攻撃→敵撃破（SE）が流れるように来るから」。
**B群（数字は強いが退屈）の駒が退屈なのは、殴っても次の出来事に繋がらないから。**
手番の作り直しは「ダメージを増やす」ではなく **「連鎖の輪を1つ足す」**（殴ると何かが起き、それが別の駒の引き金になる）。

数値の線は置かない。**回帰確認だけ**（その駒を含まない `compare` の行が動かないこと）。採否は遊んで決める。

## 1. 熾のホタ —— 軸の側を直す

現状: 「燃えている間、攻4倍・貫き」（既に条件付きの変質を持っている）／「自分では火を点けられない」。
`compare` の燃焼行は第2〜4波 100%。**ポン:「すぐ落ちる」**。燃えないと働かず、燃えると毎ターン削られる。

### 1-1. まず1回だけ数える（戦闘は既存の器具で）

燃焼 (ボルグ×ホタ)・火選り (ヒヨ×ホタ)・死軸×ヒヨ の3行 × 第2〜5波 × seed 200 で:
ホタが**倒れた試行の割合**／倒れたターンの中央値／**死因**（燃焼の削りで倒れた／敵の攻撃で倒れた）／燃えていたターン数の中央値。
`life` か `route` の既存の口で足りるはず。足りなければ最小の集計を1つ足す。

### 1-2. 変更（1行）

> **火には焼かれない**（燃焼の削りを受けない。燃えている判定と攻4倍・貫きはそのまま。自分で火を点けられないのも変わらず）

- 実装は `Pyre` の中で、燃焼の tick のダメージをホタ本人にだけ 0 にする（燃焼の状態は消さない）
- **ノブ `PyreTickHeal`**（既定 0）: ポンの次の案「燃焼ダメージで回復」を、値を入れるだけで試せる形にしておく。この期は 0 のまま
- 1-1 の死因が「敵の攻撃」が過半なら、この1行では足りない可能性が高い。**それでも入れて測り、報告に「足りない」と書く**（次の耐久役の材料）

## 2. 逆しまのウツ —— 手番を連撃に

現状: 「弱体化されるほど攻撃力が上がる（下げ幅の3倍）」／「強化されると半減」。
**ポン:「通常攻撃で殴るだけで非常につまらない。周りに何も与えない」**。

### 2-1. 変更

> **弱体化されるほど、手番の攻撃回数が増える**（攻撃力は素のまま。下げ幅 N ごとに +1 回、上限は仮に 5 回）
> 強化されると攻撃力が半減する（マイナスはそのまま）

- 「攻撃力 3倍」を「回数」に置き換える。総ダメージが近くなる N を Phase 0 で計算して仮置きする（合わせ込みはしない）
- 1発ごとに独立した `Attack`/`Damage` イベントを出す（**再生側で1発ずつ音が鳴る**ことが狙い。1イベントに束ねない）
- 各発は通常攻撃と同じ扱い（傷・毒・燃焼・軛の判定が1発ごとに走る）。標的は毎発、通常の標的選択で取り直す（前の1発で倒れていれば次へ）
- 他の駒との噛み合いは**1発ごとに通常どおり**:
  - **殉教者の庇い**: 5発それぞれに割り込める
  - **軛**: 1発ずつ 25 で切られる（素の攻撃力なので連撃はほぼ切られない ＝ **軛に強い**）
  - **断罪**: ウツの連撃は手番内の行動なので痺れない

### 2-2. engine

`TURN_SLOT_PLAN.md` §3 の形 (1)(2) では書けない（回数は `ModifyAttack` に無い）。
**`PerformAttack` の直前で回数を問う口を1つ足す**（`ModifyHitCount(self, hits) -> int`、既定 1）。
Modify 系の4本目。**ウツ以外の駒の値は 1 のまま**（回帰確認の根拠）。
