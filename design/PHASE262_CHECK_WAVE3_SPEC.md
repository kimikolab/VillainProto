## 0. 位置づけ

第261期で手番は直った（振れた割合 0% → 91.7〜100%）が、量が足りなかった:

- ボスの一撃は名目の 5〜50% しか入らない（萎縮・澱み・毒の鈍り・庇い・破片）。1戦の総量は最大でも 116 で、5体の隊を崩す桁に届かない
- 癒し手（145）も1窓で 146〜350 を受けて T1.3〜4.0 に倒れる
- 倍率なしの第四波は6台とも3ターンで割る＝土台の上に何を乗せても先に土台が崩れる

この3つは独立ではない。**この盤面の守り（萎縮・庇い・破片・澱み・鈍り）は全部「単体の重い一撃」への守り**で（敵の打点が全部25以下の世界で育ったロスター）、1体のボスの単体攻撃はその焦点に全部吸われる。構造を直す。

## 1. 決定（この期はこの前提で進める）

1. **ボスを全体攻撃にする**（第261期 §5 の候補1）。庇いは Single にしか効かない（設計の中核）ので全体は庇いを構造的に抜け、萎縮・破片が一撃ずつ効いても総量が5体分になる。天井は +4 のまま（候補2 は却下——単体のまま量を盛っても「誰に入るか」が庇い・標的で制御され続け、壁だけ殴って隊は崩れない）。守りの無効化（候補3）も却下——破片・庇いは測定対象の軸そのもの
2. **土台の波を 400/300 にする**（手数チェック側）。倍率なしの第四波は波として存在していなかった
3. **癒し手も倍率に乗せる**（145/12/3 → 倍率後 580 相当）。1窓最大（約350）を自然に超えるので体を手で盛らない。「重装兵と同数値＋特性1枚・倍率は波全体に等しくかかる」で作法が保たれる
4. ボスは引き続き倍率なし（ローカル駒・HP 3,000 規定）。ノブは「全体化」だけ動かし、HP・天井・回復は第261期のまま

## 2. Phase 0

1. **全体攻撃の実入りの机上計算（R361・第261期の再発則）**: 名目（攻12 × 5体）に萎縮・破片・澱み・鈍りの係数を当て、ターンごとの実入りと「隊が崩れ始めるT」を台ごとに見積もる。天井 +4 と重ねて、燃焼（倒しT3）・雷（T6）・移動（T10.5）のどこが天井に捕まるかを先に書く
2. **萎縮・澱みの適用範囲**: 全体攻撃の各命中に個別に乗るのか、主目標のみか。全体化で挙動が変わる守りを列挙する
3. **400/300 での癒し手の生存見積もり**: 1窓最大 350 に対し倍率後の体で何窓持つか。軛の重装兵も倍率に乗る（145→580）ので、軛が外れにくくなる＝手数チェックがより軛前提になることを前提として書く
4. **400/300 の素の第四波（癒し手なし）での6台の成績**を対照として先に取る（本編の実測があれば引用で可）。土台だけで落ちる台がないか

## 5. 予測（Phase 0 の机上計算で数値を足してから実装する。方向は以下）

- **ボス**: 全体化で庇いが抜けるのでガルド系の受けは効かず、崩れ始めは机上 T9 前後。**燃焼（T3）・雷（T6）は逃げ切って勝ち、移動（T10.5）は際どく、毒（倒せない）は負け**。混ぜ（T8.8）は勝ち寄りの際どさ
- **手数チェック**: 敵が 400/300 で硬くなり、回復 50 が上に乗る。**雷（31発×11.5・軛に切られない）が最有力、燃焼は大技が切られて最も苦しい**。移動は敵前衛の処理に手数を食われて中位
- **符号が逆になる筆頭は燃焼**（手数 ×・ボス ○）。移動が逆向き（手数 ○・ボス ×）に出れば2軸独立の最良の証拠
- 第261期の発見「ボスが動くほど移動の手数が増える」（ヨミ・ハネは敵の手番に反応）は全体攻撃でさらに強まるはず——全体は毎ターン5体に被弾イベントを配る。移動・混ぜの倒しTが縮む方向に効くことを予測に織り込む
