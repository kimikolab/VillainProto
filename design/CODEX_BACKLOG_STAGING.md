# Codex 向け作業リスト —— `DemoApp` の演出（Claude Code の手が空かない間に進められるもの）

置き場所: `design/CODEX_BACKLOG_STAGING.md`。

## 前提と約束

- 触るのは **`DemoApp` の戦闘の再生まわりとアセットだけ**。`BattleCore` / `BattleSim` / `docs/` には触らない
- **台本（`BattleEvent` の列）に今あるデータだけで作る。** データが足りないと分かったら、作らずに「足りないもの」をメモして次へ進む
- **文字を足さない。** ポンの観察:「いたるところでテロップが出まくっているし2倍速なので読み取るのは難しい。文字でわからせる方向は無理」。**2倍速で見て分かること**が合格の線
- 良し悪しは言わない（「不利」「相性が悪い」などは出さない）。**起きたことを見せるだけ**
- 1項目ずつ、`SealEffectCheck` と同じ形の**演出確認シーン**で見られるようにしてからポンに見せる

## A 群 —— 封じの続き（粛の鎖と同じ文法。データは `BattleEventKind.Sealed` に全部ある）

| # | 項目 | 中身 | 頻度の目安 |
|--:|---|---|---|
| A1 | **粛の鎖の仕上げ** | 保持者が倒れたら**鎖が砕ける**。砕けた直後の追加攻撃はいつもの青いオーラで出る（対比で意味が分かる）。頭上の仮の文字「封じ」と ★ の文字は消す | 1戦 9.4 回 |
| A2 | **軛（1発が 25 で切られる）** | 大振りの一撃が当たる瞬間に**頭を押さえられて止まる**絵。色は**黄**（接敵ダイアログの「1発」と同じ色）。切られた量が大きいほど強く | **1戦 11.2 回（最多）** |
| A3 | **渇き（回復が通らない）** | 回復の光が届く前に**枯れて散る**。色は**緑**（「回復」と同じ色） | 1戦 4〜10 回 |
| A4 | **保持者の目印** | ★ の文字の代わりに、保持者の足元か頭上に**ルールの色の印**（紫＝粛／緑＝渇き／黄＝軛）。倒れたら消える | 常時 |

**色の約束**: 紫＝ターン外の行動（粛）／緑＝回復（渇き）／黄＝1発（軛）。マップの接敵ダイアログと同じ色にする。

## いまは作れないもの（台本にデータが無い。Claude Code 側の仕事が先）

- **「誰が動かしたか」の描き分け**（バサの入れ替え／ハネの押し出し／敵の曝き）。`Move` に原因が載っていない
- **特性ごとの専用演出**（1駒が複数の特性を持つとき、どの特性が起こした出来事かが台本に無い）
- **開戦時にヒサが標を付ける瞬間**（標そのものは照準マークで見えている。「ヒサがやった」が台本に無い）
- **断罪（反撃すると痺れる）の封じ**。帳簿が無い。痺れそのものは B5 で出せる

これらに当たったら、**無理に推測で作らず**、この節にメモを足して次へ進むこと。
