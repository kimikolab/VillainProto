# ハギ：鎌の統一と、反り・ひねりを使う空中刈り下ろし

2026-10-26。v4の「鎌の形がばらばら」「鎌を持って軽く跳ねている」というフィードバックへの修正版。DemoAppの空中クリップをv5へ切り替えた。

## 修正

待機絵の鎌から `scythe-master.png` を作り、一続きの大きな銀の非対称三日月・根元の楕円穴1つ・溝3本・金の装飾・真っ直ぐな黒い柄・刃の内側への接続を共通参照にした。空中動作の全7原画を一姿勢ずつ描き直した。2×2シートでは鎌が縮んだため不採用。着地の斜めの柄が曲がった2案も不採用とし、水平に握る原画へ変更した。視点に伴う描かれた投影寸法の差はあるため、武器の完全な幾何一致を保証する3Dモデルではない。

深く踏み込む → 胸を反らせて離陸 → 肩と腰をひねって背面を見せる → 腰を前へ出し、背後へ大鎌を引いて空中で溜める → 体を前へ起こして頭上から振り下ろす → 深く着地する。跳躍頂点は1.12から1.48へ約32%高くした。フィニッシュ時は頂点と着地の溜めを長くする。

組み込みimage_genで制作。黒いボブ、赤・黒・グレーと金の衣装、片脚タイツ、下着が露出しないスカートを維持。通常の地上回転斬りv3と、初撃／最後の敵への適用条件は継続。戦闘ルール・ダメージ・攻撃回数は変更していない。
