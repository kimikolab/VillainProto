# 棘鎧のカド 正面立ち絵 v2 — 決め立ち

生成日: 2026-09-20
生成方法: Codex 組み込み ImageGen
編集対象: `design/art/kado/kado-front-v1.png`
採用先: `DemoApp/assets/portraits/kado.png`

## 修正内容

- 左右対称の棒立ちをやめ、肩と腰へ小さな逆向きの角度をつける。
- 片脚を半歩前へ置き、細身の輪郭に流れを作る。
- 片手を胸の黒薔薇へ添え、反対の棘腕を外へ開く。
- 攻撃姿勢にはせず、不動の守護者らしい静かな威圧感を維持する。
- 顔、体型、呪鎧、配色、既存キャラに合わせた仕上げは維持する。
