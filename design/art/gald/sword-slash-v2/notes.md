# ガルド・上段からの一刀両断 v2

2026-10-18。ユーザー指定: 「迫力が足りない」「剣道の上段の構えのように構えて、一刀両断する感じ」。

## 制作方針

両手と柄を兜より上へ上げ、剣を頭の後ろへ倒した上段を明確に見せる。後ろ足を支点に前脚へ踏み込み、肩・腰・両腕が前下方へ進む。横薙ぎではなく、頭上から前方の低い位置へ斬り下ろす。

盾なし・両手剣の状態を維持。制作時点では攻撃素材の改訂のみ。その後、ユーザーの指示でモーションと大剣閃をゲームへ適用した。適用内容と検証は `integration.md`。承認済み待機モーションと戦闘ルールは本作業では変更しない。

## 基準画と生成記録

基準画2枚は組み込み imagegen で作成。全文プロンプトとモードは `imagegen-prompts.json`、原画は `source-jodan.png` / `source-finish.png`。承認済みの剣構えは `source-guard.png`。

`prepare.py` は原画を拡大変形せず共通キャンバスへ平行移動し、後ろ足を基準に踏み込み分を残す。`*-workflow.json` にローカルWan2.2 Fun Inpaint 14Bの始終点指定、全プロンプト、seed、サイズ、再生用元コマ数を保存。`jobs.json` と `*-result.json` が実行識別子・履歴。

購入済み素材の記録とEffectBlocks v4の実ファイルを再確認した。NatureBlocksは背景、EffectBlocksは粒子・着弾等であり、今回必要なガルドの両手剣の関節動作は含まないため、原画差分とローカル動画生成を使用。購入素材の原本は変更しない。

## 候補の検品

- 初回 `cut` は踏み込みの方向が出たが、途中で手と柄が崩れたため候補を作り直した。
- `cutB` は動作をゆっくり示すプロンプトに変更。頭上を通る剣先の余白が不足するため、さらに上側へ640px足した `cutC` を生成。
- 動作の起点・終点は同じ。途中を逆再生して復帰を作る方法は使用しない。
- `native/` に元のRGBAコマ、`*-sheet.jpg` に全姿勢、`*-raw.mp4` に緑背景の元動画を保存。

## 採用版

`cutC` も途中で剣が体の裏へ回り、`recover` は剣が重複したため、動画の補間候補は採用しない。`candidateC.*` は比較用の出力。

最終版は、一枚の連続原画シート `source-six-poses.png` から作成した6姿勢のキーアニメーション。原画は組み込み imagegen、全文は `imagegen-six-poses-prompt.txt`。`clean-sheet-workflow.json` は背景・透過を整えるローカルComfyUIの処理。`sheet_animation.py` は6体を連結領域で分離し、後ろ足の接地位置を基準に平行移動して同じ画面へ置く。部位を貼り付けたり、斬撃を逆再生したりしていない。

原画の出力は1536×1024で、指定した等間隔グリッドには揃わなかった。固定セルで切ると水平の剣先が欠けるため、実際の6体の外形を使って分離した。`poses/pose00.png`〜`pose05.png` と `gald-jodan-cleave-keyposes.jpg` が採用した全姿勢。

- 上段0.52秒 → 斬撃0.20秒 → 振り切り保持0.40秒。全1.12秒、25fps、28コマ（原画6姿勢と保持分）。
- 透過連番は `frames/f000.png`〜`f027.png`、784×608 RGBA。後ろ足基準は `[148,572]`。
- 刃を頭上から前上方、水平、下方へ順に動かす。兜の上に両手を上げた上段から始まり、振り切りまで見せる単発素材。低い待機構えからの準備・待機への復帰はこの版に含めない。
- プレビューは `gald-jodan-cleave.gif`（末尾に0.8秒の確認用停止を追加）。単発再生は `gald-jodan-cleave.mp4`、透過動画は `gald-jodan-cleave.webp`。
- 全28 RGBAコマ、枠との接触0、緑残り0を検査。MP4をデコードして28コマであることも確認。

再生成は `sheet_animation.py` を使用する。`assemble.py` は不採用の補間候補Cのプレビュー用であり、採用版の書き出しには使わない。自然さと力強さの最終判断はユーザーの動画確認で行う。

Gitには採用版の原画・透過シート・プロンプト・書き出しコード・プレビューとゲーム用連番を保存する。上記の不採用候補の動画・中間フレームはローカルの制作履歴として残し、コミットには含めない。`frames/` と `poses/` は `sheet_animation.py` で再生成できる。
