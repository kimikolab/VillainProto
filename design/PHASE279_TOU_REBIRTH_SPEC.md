## 2. トウの転生(帯電の粉)

### 2.1 転生の形

現在: 痺れ粉のトウ(HP46/攻3/速11)「攻撃した相手を高確率で1ターン動けなくする」/「自分の火力はほぼ無い」/前科「自分の粉で味方を眠らせた」。

**変える**: 痺れ粉 → **帯電の粉**。
- **攻撃した相手に感電を付ける**(即時の痺れ → 弾けて初めて止まる遅延の痺れ。「止める駒」の核は感電の弾け経由で残る)
- **前科を機構に昇格**: **粉は隣の味方にも漏れ、味方も帯電する**(マイナスの顕在化。フレーバーの1行がそのまま特性になる)

### 2.2 なぜこの形か(記録すること)

- 感電の供給2枚目。ソム(敵陣の中に置く)と役割が分かれる(トウは狙った敵へ直接・速11で誰より先に撒く)
- **味方への漏れが、帯電の足の「感電と移動の交差」を味方側から閉じる**——移動軸の駒がトウと組み、漏れた帯電を札で弾に変える。マイナスが札の読み手で資産化する(萎える心×ウツと同型)
- カタ(跳ね)・シガとの行動順: 速11は撒き手として先に動ける

### 2.3 Phase 0

1. 感電の付与量の単位(層)と、味方側の感電の挙動(味方の感電は弾けるのか・弾けると味方が痺れるのか)——**漏れの代金の実体を実装前に書く**
2. 既存の Stun 書き手の現状(トウが抜けると即時の痺れはクグのみ。シガの読みが細らないか——シガの条件が「動けない敵」なら感電の弾けで供給される)
3. トウの compare 在席行(逆位の分析で痺れが言及された行など)と、既存行への影響範囲
4. 帯電の足×トウ×移動の書き手の検証台を組む準備(ハネ・バサ等の移動の書き手+トウ+札)
5. 類似実験の grep

### 2.4 版

| 版 | 内容 |
|---|---|
| T0 | 旧トウ(対照) |
| T1 | 帯電の粉(敵へ感電N・隣の味方へ感電M の漏れ)。N/M は Phase 0 の層の単位で決めて予測に書く |
| T2 | T1 から漏れなし(敵への付与のみ)——**漏れの代金の対照**(漏れの有無で何が変わるかの切り分け) |

### 2.5 測定

- 回帰: トウ不在の行は 0 差分(凍結後の fast/full で)
- トウ在席の既存行+検証行: **感電の行(62行目)にトウを加えた形**と**移動×トウ×帯電の足の検証台** × T0/T1/T2 × 本編第2〜5波+ボス+チェック波
- 機構の実測: 敵への感電付与数・味方への漏れ数・漏れた帯電が札(帯電の足)で弾に変わった数・感電の弾けによる痺れ数(T0 の即時痺れ数と比較)
- **帯電の足の再測**(交差が閉じたので): 検証台で固有の勝者が立つか。立てば「供給待ち」解除

### 2.6 予測(Phase 0 の後・実装前に書く)

- T1 は感電の行で供給2枚目として機能し、移動×札の検証台で帯電の足が初めて働く
- T2(漏れなし)との差が小さければ「漏れは代金として機能していない」——その場合も採否には使わず記録(漏れはフレーバーの機構化なので、無害でも意図どおり)
- 旧トウの即時痺れ→遅延痺れで、先手で止める価値は下がる(速11の意味の変質)。下がり方を実測で

### 2.7 採否(面白さ探索の基準)

- 感電の供給としてソムと**違う使われ方**をするか(直接撒き vs 餌経由が実測で分かれるか)
- 帯電の足の読み手接続が確認できるか
- 1文が短いまま・前科のフレーバーが機構として残っているか
