## 2. 器具と線（**測る前に固定した**）

**器具は第82期（＝第81期の 2×2）の写しで1文字も変えていない。測定データも同じ台・同じ席・同じ戦闘 seed。**

    y11 = 両方が本物 / y01 = A 素体・B 本物 / y10 = A 本物・B 素体 / y00 = 両方が素体
    単独(A)   = y11 − y01               ← 第69期の標準器具（**この期では床にしか使わない**）
    相乗(A,B) = y11 − y10 − y01 + y00   ← 第81期の 2×2（**この期の主判定の素**）

**変えたのは線だけ**（指示書 §2）:

| 量 | 定義 | 線 | 根拠 |
|---|---|--:|---|
| 広さ(A) | \|{ B : 相乗(A,B) > 2 × SE }\| | **3** | 相方が引ける確率 ≒ 10% × 3 枚 = 27%（指示書 §2-2） |
| **独立の広さ(A)** | そのうち `KeysOf(A) ∩ KeysOf(B) = ∅` の相手の数 | **3** | **順位はこれで付ける**（設計目標＝軸をまたぐ噛み合わせ） |
| 床 | 単独の帰属 | **−1.5** | 第62期以来の帰属の閾値の符号違い。**新しい数字を作らない** |
| 拒否権1 | 素体に落とすと `CompareBuilds()` の行が落ちる幅の最大 | **5.0** | 第46期の閾値 |

    残す     : 独立の広さ ≥ 3
    転生     : 独立の広さ < 3 かつ 広さ ≥ 3
    差し替え : 広さ < 3
    床       : 群にかかわらず 単独 < −1.5 なら差し替えへ落とす

台: 埋め草3枚（残り 49 体・規則 P）＋ A ＋ B・席は規則配置 H・弱い波 60%・第2〜5波・戦闘 seed 0..7・
**全 1,275 組 × 128 台**（系列 2 × K 64・交互配り）。理想台は `CompareBuilds()` 61 行 × seed 0..199。

### 15-3. この期に確定した事実（後の期で誤って引かないための固定）

- **「広さ」（有意な相手の数）は標本数に依存する量なので、2系列に割ると器具そのものが変わる。**
