# 第271期 指示書 —— レリックの本判定（総当たり・固有の勝者・混成率・ゴミの成立）

読み手は Claude Code。第270期（器と札7枚・`relic sweep`）の続き。札の数値（+2・毒1・−2 等）はこの期も動かさない——先に探索、調整は後。

## 0. 位置づけ

器は立ち、気配は出た（火付けの矢×毒の台 45→100%・身を固めるの符号反転）。この期はレリックという機構そのものの採否を、計画時に定めた4つの物差しで判定する:

1. **固有の勝者**: そのレリックが無いと勝てない編成が生まれるか
2. **混成率**: レリックによって、最良の編成が「軸を混ぜた編成」になるか
3. **ゴミの成立**: マイナスの札が、読み手と組むと「付けない方より強い」か
4. **個性の保存**: 札を付けても駒の元の役割の指標が消えないか

## 1. Phase 0

1. **総当たりの規模の見積もり**: compare 61行 × 5枠 × 札7枚 ×（ボス規定形＋本編第2〜5波）× seed 200 の実行時間を概算し、重すぎるなら絞り方を提案して報告書に書いてから走らせる（絞りの優先: 波を減らすより seed を減らす方を先に）
2. **「部隊で札1枚まで」の制限**: この期の総当たりは全枠に配るのではなく**部隊に1枚だけ**（どの枠に付けるかは総当たり）。複数枚の組み合わせは空間が爆発するので次送り。器の仕様（1体1個）は変えず、測りの範囲として絞る
3. **ゴミの読み手の台**: compare 61行のうちウツを含む行・ガンを含む行を列挙する。無い読み手は臨時の検証台（compare の行の形式で5枚・残置）を組む。ウツ×萎える心・ガン×痺れる足の2組が最低限
4. **「軸を混ぜた編成」の判定規則**: 第264期の軸の核リスト（燃焼: ボルグ・ホタ・ヒヨ／移動: バサ・セロ・ヨミ・シオ・ハネ／雷: シガ・ツギ・カタ／毒: グザ・ミオ・ラウ・両属は数えない）を流用し、「2軸以上の核を含む行」を混成と定義。61行それぞれに軸タグを付けた表を先に作る

## 2. 測定

### 2.1 総当たり（`relic grid` 等・新しい器具）

- compare 61行 × 札7枚 ×付け先5枠（部隊1枚）× 波（ボス規定形＋本編第2〜5波）
- 行×波ごとに「素の勝率」と「最良の札・枠・勝率」を出す。主指標は勝率と倒しT（R364: 与ダメ系は使わない）

### 2.2 四つの物差し

| 物差し | 測り方 | 採用の下限 |
|---|---|---|
| 固有の勝者 | ボスで素 0% → 札1枚で勝率が有意に正になる行の数 | **≧ 3行**（気配の1例を超えて再現すること） |
| 混成率 | 各波の最良の行（素）と最良の行＋札（レリックあり）を比べ、混成の行が最良になる波の数 | **≧ 1波**で最良が混成に変わる、または混成の行とトップの差が札で縮む傾向 |
| ゴミの成立 | ウツ台×萎える心・ガン台×痺れる足で「付けた方が強い」か（勝率または倒しT） | **2組中 ≧ 1** |
| 個性の保存 | 固有の勝者になった行で、札を付けた駒の元の役割指標が保たれているか | 全例で確認（消えた例は札の設計不良として記録） |

### 2.3 既存波への影響の観察

本編第2〜5波で、札1枚が既存の勝敗を動かす幅（最大Δ）を波ごとに出す。これは採否ではなく「レリックの強さの桁」の現況把握（数値調整の期の下敷き）。

## 3. 予測（Phase 0 の軸タグ表を見てから、実装前に書く）

- 固有の勝者の筆頭は**毒の書き手を持つ行 × 火付けの矢**（蝕み＋燃焼の脆さの重ね）と、**移動の核を持つ行 × 軋む足**。3行は超えるはず
- ゴミ: ウツ×萎える心は「被弾のたびに強化」になるので成立。ガン×痺れる足は、痺れの供給が自傷（自分の移動札が要る）なので**同じ行に移動の書き手がいる場合のみ**成立——条件付きの予測として書く
- 身を固めるは総当たりで「毒・支援寄りの行でだけ正」の形を保つはず（符号反転の再現）

## 4. 作法・回帰

- レリック無しの全既存測定が 0 件差分・全行一致（第270期と同じ4本＋`relic check`）
- **転生の評価への不書き戻し**（第270期の条件・継続）: 固有の勝者に✕・△の駒が含まれても評価は変えず、報告に「素の個性は不変」を併記
- 測って採らなかった札・臨時台は対照残置。報告は `design/PHASE271_RELIC_JUDGE.md`
- 採否がすべて下限を超えたら、レリックは機構として**採用**。数値調整・札の増補・部隊枠数・画面（Codex）は次の期の論点として引き継ぎに書く
