## 1. Phase 0（`boss283 p0`・実装前の調査）

### 1-1. ヒーラーの機械的定義（§3-1）

`BattleCore/Traits.cs` を器具が走査し（コメント行を除く）、`ctx.Heal(` の書き手 21 箇所と、破片（`StatusKeys.Armor` の `SetCounter`）の書き手 7 箇所を、囲むクラス → 札 → `UnitCatalog.All` の保持者に引いた。
宛先と回数（味方へ／自分へ／敵へ・繰り返し／1回）は人が付ける列で、**付け漏れが 0 であることは自己検査 (a) が確かめる**。

**定義: 宛先が「味方」かつ繰り返し書ける回復（`ctx.Heal`）・破片（HP の前に削られる別資源）の書き手を持つ駒**。境界は測る前に次のとおり決めた:

| 駒 | 書き手 | 扱い | 理由 |
|---|---|---|---|
| ゴルム | `ColossusTrait`（倒れたとき1回の還し）・`DrainTrait`（自分） | **数えない** | 味方への書き込みは1回だけ（指示書の境界の例） |
| ベニ | engine の `InverseHeal`（隣の味方の毒・燃焼を癒しに変える） | **数える** | Traits.cs の外の書き手なので器具が足す。ボスは毒も燃焼も撃たないが、定義は駒で決める |
| ツギ | `PlankTrait`（板＝破片） | **数える** | ポンがヒーラーとして名指し。破片は回復と同じに数える |
| ササ | `BraceTrait`（味方へ破片） | **数える** | 機械的定義に入る（寿命側の候補から外した） |
| ヒビ | `ShatterTrait`（範囲を受けると味方全員へ破片） | **数える** | 同上 |
| ムド ／ ウロ ／ リィカ | 自分だけ（暴発の吸い・鱗・墓守） | 数えない | 宛先が自分 |

→ **ヒーラー 7 枚: ヴェル（縫い）・リリ（吸い渡し）・シオ（拾い上げ）・ササ・ヒビ・ツギ・ベニ**。

### 1-2. 守りの駒と標の入口の棚卸し（§3-2・§3-4）

味方に標を書く札（ザンの仇指しの入口）は `DivertTrait`（ソラ・自分に標）・`GoadTrait`（カリ）・`BeckonTrait`（ヒサ）の3つ（`MarkerTrait` は `All` に保持者 0）。
ボスは全体攻撃1体なので、**単体攻撃への介入（庇う・後備え・引き寄せ）は効かない**——ガルドの庇い・セッキの後備え・ソラの引き受けは素通りする。全体攻撃に効くのは肩代わり（ゴルムの巨躯は「型を問わず」・ドハの分かちは「薙ぎでも全体でも」）と軽減（バンの据え・クビの萎縮・ヒサの矢面）。
R374 の 0 化: ガルドの受け流し（構え）は全体攻撃にも掛かる——**標持ちがガルドならザンの仇指しは立たない**（第282期で 0.24 回）。

寿命側の候補（ヒーラー以外）: **ヒサ・ソラ・ドハ・ゴルム・バン・クビ・セッキ・ガルド・カド・ウケ・ガン の 11 枚**（ガンは第282期の新台の顔ぶれ）。カリ（味方に標を書くが本体は攻撃の渡し手）は指示書の {壁・守り・ヒーラー} に入らないので外した。
