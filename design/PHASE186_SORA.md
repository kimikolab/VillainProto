| Q0-2 | 逸らしを入れる段 | **`ApplyDamageBody` の入口（棘守りの上限・駒の被ダメ修正・惨禍より前）で半分に割る**。逸らす半分は**素の攻撃の量**で、ソラの取り分にだけソラ側の段（惨禍 +50%・据え・散開・萎縮・**ヒサの半減**・巨躯・分かち・破片・受け流し・身構え・軛）が掛かる（指示書の推奨どおり）。逸らした半分は**敵への別の `ApplyDamage` 呼び出し**で、そちらでは敵の段（**§1 の +50%**・破片・軛）が敵の側で掛かる。**逸らす方を先に入れる**（棘守りの中継と同じ順。ソラが倒れても逸らした分は既に届いている）。呪いの共有（`hexShare`）・刻み・徴収・中継は逸らさない |
| Q0-3 | 「ソラが標を付けた敵」を引けるか | **引けない**——標は二値で出どころを持たない。**ソラの側に記憶を置く**（`DeflectTrait.TargetKey` ＝ 相手の `InstanceId + 1`・ヒサの `beckonTarget` と同じ作法）。`DivertTrait` が毎ターン頭に焦点を付けた相手をそこへ書く。**ザンが付けた標とは記憶で区別される**。**逸らす条件は「その相手が生きている」だけ**にした——トメが標を消費しても指差しは次のターン頭まで残る。**+50% は標が残っているときだけ**乗る（§1 の条件そのまま）。記憶は `InstanceId` を持つので `OnCarryOver` で捨てる |
| Q0-4 | ヒサがソラに標を付けた場合 | `DivertTrait` は**自分を剥がさない**（`ally == self` を飛ばす・`Traits.cs` の `DivertTrait.OnTurnStart`）。半減は「標がある かつ ヒサの記憶がこの駒を指す」の積（`BeckonGuardOf`）なので、ソラの自前の標でそのまま成立する。**穴が1つ**: ヒサは手番ごとに**現在HP**で選び直し、付け替えるとき**前の相手の標を 0 にする**——ソラの HP が隣の味方より下がると**ソラの自前の標まで消える**（次のターン頭に付け直すまで、敵の 75% の引きも外れる）。`火選り無風型` はヒサの隣がカド（96）とソラ（96）の同値で、**開戦時は席番号の若いカドを指す** |
| Q0-5 | 逸らした分で敵が倒れたとき | 出どころ（`source`）は元の攻撃者のままなので**撃破者は敵自身**。`HandleDeath` は陣営が同じなら `Kills` を数えない（ソラにも付かない）。**処刑（`ExecutionerTrait`）は陣営を見ない**ので、第三波・第五波の勇者候補の逸らされた一撃が味方を倒すと**勇者候補が +7 育つ**（第147期の混乱と同じ形）。断罪（`Condemn`）は出どころが同陣営なら何もしない。帳簿に「逸らしで倒した数」を置く |
| Q0-6 | 過去の類似 | **反射を採らなかった判断**: `design/LESSONS_101_.md`（第137期 Q0-7 で書き戻し）——「被ダメージの一定%を返すと敵の火力に比例し難易度カーブを平坦化する／被弾しないので HP の代金を踏み倒す」。**この案は半分を必ず受ける**（代金は払う）・**返す先は攻撃者ではなくソラが指差した敵**なので別物として扱う（指示書どおり）。**火力に比例する点は残る**。第50期（ソラの初出・`design/PHASE50_DIVERT.md`）は「代金は代金でなかった」（自分の標を外すと −3.9 / −33.3pt）。第126期はソラの生存 **2.32T・落ち率 100.0%**（`止め改`）。肩代わりの割合は庇い 50 → 100%（第136期）・殉教者 75%（第35期に 50/75/100 を掃引） |
