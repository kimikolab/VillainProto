## 1. 目的

第228期で、ガルド抜きの移動軸は主判定（9体の新兵・敵 HP200%／攻200%）の全員生存 99.0%、本編の第2〜5波の平均 91.2% に届いた。
この期は、ポンが仕様を見直して挙げた3つを入れる:

1. **バサの段で、味方の入れ替えも増やす**: 段が上がると扱う風の規模が大きくなる。敵だけでなく味方も大きく揺れる＝移動軸の加速（代わりに隊列の乱れも大きくなる）
2. **敵の移動を味方の移動に変える（追い風）**: バサ・ハネが敵を後ろへ動かしたとき、空いた前へ味方が踏み込む
3. **転倒と麻痺の違いを出す**: 今はどちらも「次の手番を失う」だけ。**転倒は倒れて壁にならない＝隊列の穴**にする

## 2. バサの嵐（段で味方の入れ替えも増える）

| 敵の乱れの段 | 入れ替える敵 | 入れ替える味方（今） | 入れ替える味方（新） |
|---|--:|--:|--:|
| 0 | 2 | 2 | 2 |
| 1 | 3 | 2 | **3** |
| 2 | 3 | 2 | **3** |
| 3 | 4 | 2 | **4** |

- 敵の数・混乱の上限は今のまま。段の条件（敵の移動の累計）も今のまま
- 入れ替える味方は今と同じく選べない（乱数）
- 文面の芯: 「段が上がるほど風が大きくなり、敵も味方も大きく揺れる」

## 3. 追い風

| 項目 | 内容 |
|---|---|
| 条件 | **バサ・ハネ**が敵を**後ろの行へ**動かしたとき（バサの入れ替え・ハネの吹っ飛ばし・弾き返し・突き返し） |
| 効果 | その敵がいた経路（貫きの経路）と同じ経路の**味方**のうち、**最も後ろの行にいる味方1体**が、その経路で1つ前の席の味方と入れ替わって前へ踏み込む |
| 移動の扱い | 入れ替わった2体とも「隊列を動かされた」。前へ出た側は「前へ突き出された」（ヨミなら +22） |
| 除外 | HP が最大HPの4割を切っている味方は踏み込まない（シオが緊急退避で下げた駒を前に戻さないため）。その場合は次に後ろの味方で探す |
| 起きないとき | 敵が経路に属さない席にいた／味方の経路に前後の2体がいない |

- 敵1体を後ろへ動かすたびに1回。1ターンの上限は置かない（Phase 0 で実数を見て、多すぎれば報告）
- 「向かいの経路」は味方と敵で同じ経路の番号（1 と 3）を使う

## 4. 転倒は隊列の穴

**転倒（`StatusKeys.Stagger`）で倒れている駒は、壁にならない。**

| 項目 | 内容 |
|---|---|
| 前列の規則 | 「前列が生きている限り後列は狙われない」の判定で、**転倒している駒は前列に数えない**。前列が全員転倒（または倒れた）なら後列を狙える |
| 庇い・身代わり | 転倒している駒は、庇い・身代わり・受け流し・逸らしなど**標的を引き受ける介入をしない**（敵の殉教者の庇い・味方のガルドの庇い・カドの身代わりほか） |
| そのほか | 手番を失うのは今のまま。転倒は「動けない敵」に数える（第226期のまま） |

- 敵味方どちらにも同じ規則（味方が転倒する口があればそれにも）
- 痺れ（`Stun`）は今のまま（立ったまま動けない＝前列にいれば後ろを守る）
- 文面の芯: 「倒れた者は盾にならない」

## 7. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** バサ・ハネのいない行で転倒の口が無い行は 0 セル。G0 は前段の盤面と台本が一致
- **P2** G1・G2 で味方の移動の累計が増え、ヨミ・セロ・シオの段が早まる。G1 は隊列の乱れで落ちる駒も増えうる
- **P3** G3 で、転倒した前列の後ろの敵（祭司・殉教者ほか）へ味方の単体攻撃が届き、本編の第三波・第五波が伸びる
- **P4** G3 は、転倒の口を持たない行ではほぼ動かない。ササのいる行（味方が転倒しうる）では、味方の後列が狙われる代金が出る
- **P5** G4 で主判定の全員生存が 99.0% 以上、本編の平均が 91.2% から上がる
