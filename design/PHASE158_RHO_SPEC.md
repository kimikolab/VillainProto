## 1. 探す軸

### 1-1. 候補から外したもの（**Web 側が実装を読んで外した。確認だけすること**）

**「地点ごとに波ルールを変える」は既に成立している。**
波ルール（粛・渇き・軛・断罪）は `Stage` の属性ではなく**敵ユニットとして編成に置かれている**
（粛の伝令 `Husher`・渇きの祭司・殉教者ほか）。`順路5` はその5波をそのまま列にしたものなので、
**地点ごとに性格が違う状態で ρ 0.857 が出ている。** 新しい軸ではない。

> **Phase 0 でこれを実装で確認すること。** 違っていたら報告書に書き、この期の候補に戻す。

### 1-2. 本命 —— `BoundaryChoice.Carry`（HP 以外の通貨を持ち越す）

第157期から一般化できることが1つある。

> **会戦では、すべての資源が最終的に HP に換算される。**
> 境界が `StatusKeys` を全消しし `AtkBonus` を 0 に戻すので、**持ち越す通貨が HP 1本しかない。**

これが駒の差が薄まる理由の説明になっている。実際、第157期で外れた予測はほぼ全部この形だった。

- 破片（ヒビ・ウロ・ガレ）と `AtkBonus`（ムド・ウツ）は「境界で消える」——**通貨が落とされている**
- **ガルドの「HP を1点も払わずに時間を買う」が両方の点で逆だった**のも同じ
  ——在庫は毎ターン戻るが、**戻す条件は生きていること**で、HP は会戦を跨ぐ唯一の持ち越し資源

`BoundaryChoice.Carry` は **`StatusKeys.All` の消去と `ResetAtkBonus()` と `WhetReceived = 0` をしない**。
**負も一緒に持ち越す**ので可変コスト型——毒まみれの部隊で持ち越せば自殺行為になる。

**第102期に測っているが、そのときの目的変数は突破率であって ρ ではない。**
第157期の走査では `順路5 × BCarry` は **平均 2.233 / SD 0.823** で、
**平均の割に SD が高い**（R100 は平均 2.552 で SD 0.897）。**ρ は測っていない。**

### 1-3. 併せて測る点

`stage run` は既にあるので、**点を増やすだけで ρ が出る**。次を同じ 61行 × 305枠で回す。

| 点 | なぜ |
|---|---|
| 順路5 × R0 | **対照**（第157期の値を再現すること。ρ 0.857 / SD 0.318） |
| 順路5 × RFull | **対照**（同 ρ 0.884 / SD 0.808） |
| **順路5 × BCarry** | **本命**（ρ 未測定） |
| 順路5 × BRevive | `BoundaryChoice` のもう一方（体だけ返す）。ρ 未測定 |
| **逆順路5** × R0 と BCarry | **列の順序**。持ち越しがあるなら順序で別の編成が勝つはず。`engage` が既に逆順を持っている |
| 地点3 × R0 と BCarry | 短い列。**消耗が効く前に決着する側**の対照 |
| 地点2 × R0 | 一番短い列。**ρ が 1 に近づくはず**（単発に近い）という予測の確認 |

> **`RecoverRule` と `BoundaryRule` は併用できない**（engine が禁じている。
> `RecoverRule.Active` が真なら `BoundaryRule` は無視される）。**組み合わせないこと。**

## 2. 判定

### 2-1. 線（**測る前に固定する。結果を見てから緩めない**）

対照は `順路5 × R0`（ρ 0.857 / SD 0.318）。

| # | 条件 | 線 |
|---|---|---|
| 1 | **序列が動いた** | **ρ ≤ 0.75** |
| 2 | **駒の差が立っている** | **SD ÷ 列長 ≥ 0.162**（第157期 §1-2 の正規化。`地点2 × R0` と同じ水準） |
| 3 | **本丸** | **1 と 2 を同時に満たす点が1つ以上ある** |

**片方だけなら既に手段がある**（境界を緩めれば SD は上がる）。**両立が要件。**

### 2-2. ρ が下がった理由を分けること

**ρ はノイズでも下がる。** 帰属がほぼ 0 の枠が多いと、順位が実質ランダムになって ρ が落ちる。

> **したがって ρ を報告するときは、必ず次の2つを併記すること。**
> - **帰属の絶対値が q1（第1四分位）を超える枠だけに絞った ρ**
> - **その枠の数**
>
> 全枠の ρ と、絞った ρ の**両方**を出す。**絞ったほうでも下がっていて初めて「序列が動いた」。**

これは第157期 §2-3 (ii) の「q1 = 0.000 だとノイズの大きさで判定が変わる」の再発防止である。

### 2-3. 動いた駒を名指しすること

ρ が下がった点では、**単発と会戦で順位が大きく入れ替わった駒**を上位10枚挙げる。
**その駒が持っている通貨**（破片・`AtkBonus`・毒・層・在庫）を併記すること。

> **ここがこの期の一番の収穫になる。** 「どの通貨を持ち越すと序列が動くか」が分かれば、
> 次に作るべき機構が決まる。

## 4. 予測（**実装前に書き切る。外れても消さない**）

1. **`BCarry` は ρ を下げる。** 持ち越す通貨が増えるので、破片・`AtkBonus`・毒を持つ駒の順位が動く
2. **`BCarry` で上がる駒**：ヒビ・ウロ・ガレ（破片）／ムド・ウツ（`AtkBonus`）。
   第157期の R0 で**負に出ていた駒**（ヒビ −0.280 ／ ウロ −0.184 ／ ムド −0.379 ／ ガレ −0.136）が反転するはず
3. **`BCarry` で下がる駒**：毒を撒く駒（グザ・ミオ・スィド）。**負も持ち越すので自分の毒が味方に残る**
4. **`地点2 × R0` は ρ が最も高い**（列が短く単発に近い）
5. **逆順列は ρ を下げるが SD は上げない**（順序が変わるだけで通貨は増えない）
6. **RFull は ρ が最も高い**（第157期で 0.884。持ち越しの経路を消しているので単発に近い）
