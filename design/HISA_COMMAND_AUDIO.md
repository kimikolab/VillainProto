# ヒサの号令・庇い：音声素材一覧

配置先は `DemoApp/assets/audio/se/`。MP3、先頭の無音は短く、ループなし。未配置でも演出は動く（下記の専用音だけ無音）。速度を上げても音程は変えない。同種の音は重ねず、戦闘終了・画面離脱時に止める。

| ファイル名 | 内容・台詞 | 目安 | タイミング |
|---|---|---|---|
| `hisa_command_voice.mp3` | ヒサ「ほら、あいつだよ」。軽く誘導する調子 | 0.6〜1.0秒 | 敵を指差した瞬間 |
| `hisa_cover_voice.mp3` | ヒサ「…こっちだ」。低く短く、覚悟を決める | 0.4〜0.7秒 | 味方の前に立ち、自分を指す瞬間 |
| `hisa_command_ball.mp3` | 小さな光が灯る、短い結晶音 | 0.10〜0.20秒 | 玉の数が増えた通知につき1回 |
| `hisa_command_send.mp3` | 玉が指先に集まり敵へ飛ぶ軽い風切り音 | 0.25〜0.40秒 | 号令の玉が飛び始める瞬間 |
| `hisa_quiet.mp3` | 声が詰まる／息を飲む小さな音。台詞なし | 0.15〜0.30秒 | 粛・痺れで黙った通知。各ターン1回まで |

上2つは台詞、下3つはSE。満杯で捨てるときの専用音は不要。羽の照射・被弾・ザンの仇討ちは既存SEを使用する。

標撃ちのレーザー調整でも追加収録は不要。既存の `misa_beam_1.wav`〜`misa_beam_3.wav` と
`misa_beam_hit.wav` を発射位置・着弾位置に合わせて同時に鳴らす。倍速でも音の胴を残す。

鼓舞は未採用のため今回の収録対象には含めない。第303期の規定では粛の間は叫びも止まる。静かになったことが分かるよう、沈黙音を派手にしない。

## 支給済み：敵の標付与・層加算（2026-10-10）

- 元ファイル：`D:/Assets/SE/Helton Yan's Pixel Combat - Single Files/DSGNTonl_USABLE-Scifi Select_HY_PC-001.wav`
- 配置：`DemoApp/assets/audio/se/mark_add.wav`（原音をそのままコピー、SHA-256一致）。2.5秒・96kHz・24bit・ステレオ。
- 敵への初回付与、標の層が増えた瞬間に再生。号令の同時加算は着弾時に1回。減少・同値更新・同じ付与の重複通知では鳴らさない。
- 独立した3発音枠、音程は固定。倍速でも原音の余韻を保ち、再戦・終了時に停止する。
- 聞き取りづらさへの修正：再生ゲインを −16 dB から −4 dB へ変更（+12 dB）。原音ファイルは変更していない。
- `ShockMarkAudioCheck.tscn -- --mark-mix` は最終の Master 出力を採取する。初回付与・層加算・号令着弾を左右×1倍/2倍で確認。修正前の頭0.4秒の平均は約 −35 dBFS、修正後は約 −24 dBFS、単音ピークは約0.477。実戦台本16再生でも付与・加算のSE件数一致を確認した。
