# 第192期 指示書 —— ベニ自身を結界の内側に入れる

**線は置かない**（採否はポンが遊んで決める）。この文書は `design/PHASE192_BENI_SELF_SPEC.md` として置くこと。
報告は `design/PHASE192_BENI_SELF.md`。診断は `BattleSim/Modes/Beni.cs` に版を足す。

手順の順序: Phase 0 → **予測のコミット** → 実装 → `compare` → 診断。

## 1. 目的

第191期（`design/PHASE191_BENI_CYCLE.md`）で、ベニが2〜3ターン目に倒れることが残った課題になった。
原因の1つは規則の穴である。反転の対象は「ベニに隣接する味方」で、**ベニ自身は入っていない**。
そのため、隣の味方には毒が薬になるのに、ベニだけがグザの漏れ・カタの逆流・ボルグの火の粉で削られる。

今期は**この穴だけを埋めて、倒れやすさがどれだけ残るかを測る**。HP・席・溢れた回復の扱いは触らない。

## 2. 変更（1点だけ）

反転・反転の裏の対象に**保持者自身を含める**。

| 規則 | 第191期 | 第192期 |
|---|---|---|
| `Inverse`（毒・燃焼の削り → 回復） | 隣接する味方 | **隣接する味方＋ベニ自身** |
| `InverseLeak`（回復 → ダメージ） | 隣接する味方 | **隣接する味方＋ベニ自身** |
| 手番（火→毒→毒） | 隣接する味方 | **変えない**（自分には配らない） |

- 実装の入口は `AdjacentHolder`（`BattleEngine.cs`、「保持者自身は含まない」のコメントがある関数）。保持者自身を含める判定を足す。**`Inverse` と `InverseLeak` の両方に効くこと**、`Taint` / `Kindle`（手番の配り先）には効かないことを確認する
- 反転由来の回復が再反転しないガードは第190期のまま
- ノブは `const bool InverseIncludesSelf = true` を1本（偽で第191期に戻る。回帰の対照）

### 2.1 狙っている絵

- 毒・燃焼の書き手（グザ・カタ・ボルグ・ゾト）と組むと、ベニ自身も癒える。**毒軸・燃焼軸にいるときだけ生き延びる**
- 書き手がいない編成では今までどおり脆い（自分で自分を癒す閉じたループにはしない）
- 反転の裏も揃うので、ノノ・ヴェル・シオ・ナラがベニを回復するとベニが傷つく。「結界の内側は回復が毒になる」で規則が一貫する

## 4. 診断

版は **第191期（自身を含まない）／ 第192期（自身を含む）／ 第192期・マイナスなし（`InverseLeak` を外す）／ 素体**。

1. `compare` のベニの在席行（第2〜5波）
2. 差し替え表（第190期 5.2 と**同じ25行・同じ席**）。Δ素体 と第191期版との差を併記
3. 帳簿（1戦あたり）:
   - **ベニが倒れたターンの平均と、倒れた割合**（今期の主な読み）
   - ベニ自身が受けた反転の回復（毒・燃焼の内訳）と、反転の裏でベニ自身が受けたダメージ（出どころ別）
   - ベニが倒れた後に、隣の味方が本物の火と毒で受けたダメージ（第191期と比べる）
   - 反転の回復の総量と、そのうち満タンで溢れた量
4. 診断台は回さない

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0-2・Q0-3 の実駒を数えてから入れる。

- ベニを含まない行は ±0.0
- グザ・カタ・ボルグの誰かがベニと同席する行で、ベニの倒れるターンが遅くなる
- 書き手が同席しない行では、ベニの倒れやすさはほぼ変わらない
- 回復役（特にヴェル）が隣にいる行では、ベニ自身が反転の裏で削られ、第191期より下がる行が出る

## 6. 受け入れ

1. ベニを含まない `compare` 行が 0 セル差分。`InverseIncludesSelf = false` で第191期の表と一致
2. 新しい処理が乱数を引かない
3. 反転由来の回復が再反転しない（自己検査）
4. `docs/` を再生成して `audit` ずれ 0 件。`units.md` のベニの行は下の文面
5. DemoApp の門が `ok=True`、ベニ在席行の再生スモークが完走

- マイナス: 自分と隣接する味方は、回復を受けるとかえって傷つく / 自分では攻撃しない
