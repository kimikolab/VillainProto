## 2. 列の型（**データに決めさせる**）

### 2-1. 手で分類しない

第163期 §5 は「**先頭2波に重い敵（第四波・第五波）が入るか**」の二値で割って、
カド +34.1 という大きな差を出した。**これは当たっているが、手で置いた軸である。**

> **R244（連続量の線は列長に強く、二値の線は弱い）**があるので、**二値の手置きは足場が弱い。**
> **データから型を出すこと。**

### 2-2. 列どうしの相関行列

**各列について、52 体の帰属を並べたベクトルを作る**（52 次元）。
**12 列 × 12 列の相関行列**を出し、**似た列を束ねる**。

- 相関が高い列どうし ＝ **同じ型**（同じ駒が効く）
- 相関が低い／負の列どうし ＝ **別の型**（別の駒が効く）

**束ね方は機械的に**（例: 相関 0.7 以上で連結）。**閾値は結果を見る前に決めて書くこと。**

### 2-3. 列長は別の軸として扱う

第163期 §4 の留保——**反転 15/14 枚のうち半分は列長に反応していた**。
`地点2` と `地点3` を含めると、**列長の効果が型に混ざる。**

> **型の分類は列長5 の 10 列だけで行うこと。**
> `地点2` / `地点3` は**列長という別の軸**として、相関行列には載せるが**型の判定には使わない。**
> （載せれば「列長が近い列は相関が高い」が見えるはずで、それ自体が確認になる）

### 2-4. 型が出たら名前を付ける

**型ごとに「何が共通しているか」を1行で書くこと**（先頭の波・重い波の位置・波の並びの散らばりなど）。
**本編のステージを組むときにそのまま使える語**にすること。

## 3. 52 枚のカタログ

### 3-1. まず3つに分ける

| 群 | 条件 | 意味 |
|---|---|---|
| **送り先で化ける駒** | 列レンジが帯レンジより十分大きい | **どこへ送るかが判断になる** |
| **どこでも同じ駒** | 列レンジも帯レンジも小さい | 送り先を選ばない。**編成の骨** |
| **ノイズに埋もれた駒** | **帯レンジが大きい** | 列の効果は読めない。**そもそも帰属が小さい** |

**分ける線は結果を見る前に決めて書くこと。** 第163期の実測が材料になる
（帯軸の反転は **0 枚**・帯で1つも順位が動かない駒が **9 枚**）。

### 3-2. 「送り先で化ける駒」に送り先を付ける

| 列 | 内容 |
|---|---|
| 駒 | |
| 札 | |
| **上がる型 / 下がる型** | §2 で出した型の名前 |
| 平均順位の差 | 上がる型 − 下がる型 |
| **帰属の符号が変わるか** | カドは −0.275 〜 +1.221 で**符号ごと変わった**。同じ駒が他にいるか |
| 帯レンジ | ノイズの大きさ（0.0 なら完全に読める） |
| 一行 | 「**重い敵に早く会う列で働く**」のように、**プレイヤーに言える形**で |

> **「一行」の欄が本編に一番効く。** 数字ではなく**言葉で言えるか**が、
> プレイヤーに教えられるかどうかを決める。

### 3-3. 理由が言えるものには理由を書く

第163期はカドについて、**`Immobile` なので `与えた総害` の 100% が棘の反射 ＝ 出力が浴びた量そのもの、
会戦は負けた時点で止まるから「重い敵に<u>早く</u>会うか」で値段が決まる**（R247）と書いている。

**同じ形の説明が付く駒には付けること。** 付かないものは「理由は不明」と書く。**推測で埋めない。**

## 4. `checkup` との突き合わせ（**この期の3つ目の柱**）

### 4-1. 表を1枚作る

| 駒 | `checkup` の単独 | `checkup` の群（残す/転生/差し替え） | **列レンジ** | **送り先で化けるか** |
|---|--:|---|--:|:-:|

**`checkup` の値は第152期のもの**（52枚 × 1,326組・残す32 / 転生18 / 差し替え1 / 別扱い1）。
**再計算しない。既存の値を引くこと。**

### 4-2. 見たいのは4つの象限

| | 列レンジ 大 | 列レンジ 小 |
|---|---|---|
| **単独 高** | 強くて、送り先も選ぶ | **編成の骨**（どこでも強い） |
| **単独 低** | **「送り先を選べば働く駒」** ← **ここが本命** | **本当に弱い駒** |

> **左下の象限がこの期で一番価値がある。**
> `checkup` が「転生」「差し替え」と判定した駒がここに入っていたら、
> **その判定は単発戦の物差しによるもの**で、**送り先を選べる本編では別の評価になる。**
>
> **特に次の駒を名指しで確認すること**——
> 継ぎ当てのノノ（単独 −0.24・52枚で唯一の差し替え候補）／断ちのナタ（+0.65）／
> 逃亡兵セロ（+1.42）／置き去りのナラ（−9.20）／萎縮のクビ（−12.52）。
> **クビは第163期で既に「軽い先頭の列すべてで1位」と出ている**——左下の実例になりうる。

### 4-3. 右下（本当に弱い駒）も名指しする

**列レンジも小さく単独も低い駒**は、送り先を選んでも働かない。
**転生の優先順位は、そちらから決めるべきである。**

## 9. 書き方の規約

1. **線・閾値は Phase 0 で確定する。結果を見てから動かさない**
2. **線は「量の定義 ＋ 単位 ＋ その値が出た対照 ＋ 独立に動く変数への依存」の4点で決める**（R238）
   ——**この期で疑うべき依存は列長**（§2-3）と**群の数**（第163期 R245: 順位レンジは群の数が多いほど機械的に大きく出る）
3. **順位統計を使う前に同値塊を数える**（規約 (G13)）
4. **手で置いた二値の軸を結論にしない**（R244・§2-1）
5. 数値は実物を開いて確認する。指示書の表から引かない
6. 予測は実装前に書き切り、外れても消さない
7. **推測で埋めない。理由が言えないものは「不明」と書く**（§3-3）
