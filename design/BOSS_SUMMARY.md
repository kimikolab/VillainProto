# ボスのまとめ（第265〜269期）

`CHECK_WAVE_SUMMARY.md` と同じ役割の文書。チェック波の B3-桁（物差し）を本編のボスに作り替え、4期かけて形を決め、第269期に**規定形を確定した**。
器具は `bosswave`（`BattleSim/Modes/BossWave*.cs`）。**盤面・ロスター・本編の5波は1ビットも動いていない**（`compare` は5期とも 0 セル）。**ボスは `Stages` に載っていない**（§6）。

## 1. 規定形（第269期）

`EnemyCatalog.BossRegular`（波は `EnemyCatalog.BossRegularWave`・中央に1体）:

| 項目 | 値 |
|---|---|
| 体 | HP 3,000・攻 12・速 14・**全体攻撃** |
| 天井 | 攻撃力が毎ターン +11（`BossRise11`・ターン数から再計算・`AtkBonus` に積まない） |
| 動じない | 手番を奪う状態（痺れ・転倒・組み付き・竦み・混乱）が付かない（`BossSteadfast`・第261期の札） |
| 回復 | ターン頭に自分を最大HPの 40%（`BossMend40`・刻みの後） |
| 蝕み | 回復が「勇者に積まれた毒の層 × 37」だけ減る（`VenomTaxSeal`・下限 0・層は消費しない） |
| 倍率 | なし（`EnemyScaleRule.None`） |

**蝕みは毒を書く全ての台に効く**（混ぜのベニの開戦の澱みを含む）。「毒の書き手を1枚差す」がボス戦の編成の選択肢になるのは**意図した帰結**（第269期 決定 2）。

正式な指標（`bosswave run` の見出し）: **倒しT**・**純実入り**（勇者が入れた − 隊の回復）・**崩れ始め**・**蝕みで減った回復**・**層の推移**。副: 勝率・全員生存。

## 4. `compare` 61 行の成績（`bosswave compare`・規定形）

**ボスに勝てる行はごく少ない**: 100% の行 **5 ／ 61**（毒+耐久・澱み喰い・燃焼・火選り・火選り無風型）・95% 未満 56・**0% の行 52**・平均勝率 11.2%。

- 書き手（グザ・スィド・ミオ・ラウ・ベニ）が 3〜4 枚の行は平均 66%、0〜2 枚は 0〜6.7%
- ノブを1つ緩めても全体図はほぼ変わらない（`bosswave knobs`）: HP 1,500 で 0% の行 52 → 47・天井 +4 で 52 → 52・回復なしで 52 → 44
- **7台（軸の代表に組んだ台）は勝つが、`compare` の代表編成の大半は勝てない**——ボスは「その戦のために組んだ台」だけが越える壁になっている（第269期の診断）

## 5. 設計判断の要点

- **中核規則を解答の源泉にする**: 「庇い・標的は単体にしか効かない」（第267期・刻みは庇えない）・「回復は `ctx.Heal` の入口1箇所」——新しい例外を作らず、既にある非対称から解答が立つ形を選んだ
- **波の設計で駒の穴を埋めない**: 毒の 0% は毒軸ロスターの既知課題（第264期）で、ボスの構造を毒のために曲げない（取り巻きも庇いも採らなかった）。その上で、**波側に資源の読み手を置く**（蝕みは「毒の層」を読む）——駒を足さずに、軸の個性（層を積んで縛る）をそのまま解答にする
- **代金は機会費用として既に在ることがある**（第266期）: 全体攻撃のボスは毎ターン5体に被弾を配る＝反応する台の燃料なので、制御で止めることが自分の手数を削る。追加の代金装置（不屈）は要らなかった
- **一番単純な形が正解だった**: 取り巻き・庇い・不屈と構造を足すたびに別の穴が開き、D-40（1体・自前の回復）に札を1枚足す形に落ち着いた
- **到達は表だけで数えない**（R363）・**代金が何で払われるかを先に書く**（R362 の再発・第266期）

## 6. 残っている論点

- **`Stages` への配管**: `Stage` は5枠の `Formation` で ○後2 も9枠も表せない。`Stages.Count` を数える行が 646 あり、足すと平均・会戦・作戦マップが一斉に動く。作り替えは作戦マップ設計の期に送った
- **難度**（§4）: 規定形は `compare` の大半に 0%。本編の波として置くなら倍率ノブ（HP・天井・回復率）の再検討が要るが、ノブ1つでは全体図が動かない（§4）。**値はこの期では決めていない**
- フレーバー名（勇者・札の固有名）と演出（Codex 分担）・会戦／作戦マップでのボス戦の扱い
- 毒軸ロスターのテコ入れ（転生の本線）
