## 2. 決めたこと（本体）

- **版**: `UnitCatalog.WataWu`（`WataCallBlade`）／ `WataWm`（`WataCallMire`）。
  - 規定のワタ（WT-u ＋ 配り）の後ろに札を1枚足し、`Actions = [Skill「重さを返す」]`。ワタ自身は殴らない。
  - HP 84 ／ 攻 8 ／ 速 7 はそのまま・`All` の外・保持者 0 枚。
  - 文面: プラスの末尾に指示書の案の文。マイナスの末尾に「。自分では殴らない」。
- **「手番で押し付けたとき」の読み方で迷った所**:
  - ワタの押し付け（`RelayThrough` で最も強い敵へ渡す）は、**味方が弱体を受けた瞬間**に起きる。ワタの手番の中では1度も起きない。
  - そこで「**前の自分の手番から今の手番までに、1度でも敵へ押し付けていたら**」鳴る、と読んだ。
  - 押し付けた敵は手番まで控え（`_wataPush413`）、手番で読んで消す。相手は控えた敵のうち、生きていて今の攻撃力が最も高い1体（同じなら席番号）。1手番に鳴るのは1回。
- **「応える」の口**: engine の `BattleContext.WataCall413`（札は `WataCallTrait.OnAction` から呼ぶだけ）。
  - **W-u**:
    - 応える味方は、ワタ以外の生きた味方のうち下げ幅（−AtkBonus）が最も大きい1体（同じなら席番号）。下げ幅 0 なら誰も応えない。
    - 発数はその味方の手番と同じ（`ModifyHitCount`・ウツなら5発）。全部その敵に固定して振る（`_forcedTarget`）。敵が倒れたら残りは振らない。
    - 届くかは応える味方の的の集合（`TargetPool`）で決め、届かなければ何も起きない。
  - **W-m**:
    - 応えるのは `Erupt` の保持者（同じなら席番号）。怒りを全部吐く（閾に届いていなくても・怒りは 0 に）。
    - 暴発と同じ経路: 割り込み（`Interrupt`）の中、泥（塗り）を最初の1発より前に散らす、`eruptBurst` を立てる（M2 の重さ・M-d が乗る）、1発ごとに回復 +2。的は押し付けた敵に固定し、倒れたら通常の的選び。
    - 吐きは `EruptFires` に数えない（別の計数 `Wg413Vents`）。
  - どちらも手番の外の行動なので、痺れ・粛に止められる（`CanActOutOfTurn`・W-u は `Other`、W-m は `Erupt` の経路）。乱数は引かない（`ctx.PickOne` 0）。
- **試遊の台**: 「版・W-u 呪い」「版・W-m 呪い」（`Presets.WataGift413`・「試遊・呪い」のワタを版に）を `Presets.Versions` の末尾に足した。鎖の終端（`Common.VersionRows412`）で外す。

## 5. 読み（§5 の順）

1. **鳴るか**: ほぼ毎回は鳴らない。鳴るのはボスの T2・T3（毎戦2回）が中心。止まる理由は3つ。
   - (a) **T1 は鳴らない**。ワタの最初の手番までの重荷は、配り（ウツ ／ ムドの受け口）が全部吸う。第412期 §6 の「T1 だけ回す」の裏返し。
   - (b) **精鋭 ／ 強4 ではワタが T1.6〜2.6 に倒れる**（自傷 30〜45 ／戦・HP 84）。
   - (c) **届かない**。押し付けは今の攻撃力が最も高い敵へ行き、それが後列のことが多い。前列が生きている間、ウツの刃は届かない（近衛 0.8 ／戦・強4 1.0 ／戦）。
   - それでも、ボスでは W-u の2回（ウツ 10 発 ／戦・与ダメ 875 ／戦）で倒しT が **6.0 → 4.0**。精鋭 ／ 強4 の倒しT は動かない。
2. **W-u と W-m のどちらが考えることを増やすか**:
   - 数字では W-u（ボスで −2T）。W-m は吐く怒りが 1.25〜1.57 で、暴発に回るはずの怒りを先に使うだけになり、発の合計がほぼ変わらない（ボス 29.6 → 29.3）。
   - 「溜めて暴発か、ワタで吐くか」の選択は形の上では立つが、規定のムド（M-u）が毎ターン閾を越えるので、吐く前に暴発してしまう（吐いた回の 100% が閾に届かない吐き）。
   - 倒しT が同じなら W-m、という線は、ボスで W-u が 2T 速いので当てはまらない。
3. **トモ（手番の軸）との重なり**:
   - 条件が分かれている。トモは自分の手番に灯で最も遅い味方へ手番を譲る。W-u は押し付けがあった手番に呼ぶ。
   - 相手も分かれている。トモは最も遅い味方、W-u は最も呪われた味方（実測は全部ウツ）。
   - ただ、ウツが「遅い」側に立つ台では、両方がウツへ手番を足すことがありうる。この期はトモとワタを同じ台に立てていないので、測っていない。
4. **寄せ集め**: `compare` でワタを含むのは「渡し (ワタ×ドハ)」の1行だけだった（指示書の「弱体×破片 (ドハ×ワタ×ヒビ)」は今の `compare` に無い）。
   - この行では味方が弱体を受けないので押し付けが起きず、W-u ／ W-m とも1度も鳴らない（手番 4.6 ／戦が全部「押し付け無し」）。
   - ワタが殴らなくなる分だけ、近衛が 56.5 → 51.5（−5.0）。−10pt を越える行は無い。
5. **席**: 「ワタを後ろに」は、鳴る回数では成り立つ（精鋭で 3〜10 倍）。倒しT では成り立たない。ワタは前1 で殴られて重荷を拾うのが仕事で、後ろに下げると拾う量そのものが減る（第412期 §6）。
   - 強4 だけは、後1 ／ 後3 でワタの倒れる割合が 100% → 59〜61%（W-u）に下がり、鳴る回数が 0.75〜0.78 に上がる。倒しT は 6.0 → 6.1〜6.2 で、ほぼ同じ。
   - 席の選択肢が増えたとまでは言えない。
