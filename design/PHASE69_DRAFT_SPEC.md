## 1. 作るもの（測定台1つ）

診断 `draft`。**既存モードは書き換えない。`CompareBuilds()` も `Stages` も `UnitCatalog` も触らない。**

### 1-1. 標本の作り方（**測る前に固定**）

1. `UnitCatalog.All`（51体）から**無作為に5体**を選ぶ（重複なし）
2. 5体を5席（0〜4）に置く。**置き方は §1-2 の2通り**
3. **既存の5波すべて**に対して回す（第一波も実行して集計から除外。既存の作法どおり）
4. これを **N 標本 × M seed** 繰り返す

**標本の乱数は測定の乱数と分ける。**標本抽選用の seed 系列（`draftSeed`）と、
戦闘用の seed 系列を別に持つこと。**同じ標本に対して両方の配置を回す**（対応のある比較にする）。

**N・M は Phase 0 で決める**（§2-1）。**決め方の規則を先に書き、決めた値を測定前に報告書へ記す。**

### 1-2. 配置の2通り

| 版 | 置き方 |
|---|---|
| **R（無作為）** | 5体を無作為に5席へ。**ドラフトの下限** |
| **H（規則）** | 決定的な規則で置く。**規則は §1-3 で固定し、標本ごとに変えない** |

**配置の価値 = H − R**（同じ標本・同じ戦闘 seed での差）。

### 1-3. 規則配置（**測る前に固定。標本を見て変えない**）

**プレイヤーが最低限の判断をする想定**を、盤面の既存の規則だけで書く:

1. **前列（席 0・1）には、その5体のうち最大HPの2体**を置く（前列が先に狙われるため）
2. **後列（席 3・4）には、残りのうち攻撃力が高い2体**
3. **中央（席 2）は残りの1体**
4. **同値は `Def.Id` の辞書順**（乱数を引かない＝決定的）

**この規則が最適である必要はない。**必要なのは「決定的で、素人が思いつく程度の判断」であること。
**規則を強くすると配置の価値が過大に出る**ので、**上の4行から増やさないこと。**

### 1-4. 数える量

| 量 | 定義 |
|---|---|
| **標本の勝率** | 波ごと・全体 |
| **駒ごとの在席時勝率** | その駒を含む標本の平均勝率（R / H 別） |
| **駒ごとの寄与** | `ablate` 相当。**その駒を同数値・特性なしの素体に差し替えた版との差**（R / H 別） |
| **相方の有無** | 第68期 §1-4 の機械的定義（**同じキーの書き手または読み手が同席しているか**）。標本ごとに判定 |
| **配置の価値** | H − R（全体・駒ごと） |
| **枚数効果** | 同じキーの駒が 1 / 2 / 3 枚同席した標本の勝率 |

**素体の差し替えは全駒ぶん作らない。**§2-2 の対象駒だけ。

## 2. Phase 0（測る前に決める・数える）

1. **N と M の決め方**: 「駒ごとの寄与の 95% 信頼区間の幅が **±1.5pt** を下回る」ことを条件に、
   **試算して決める**。51体が均等に出るなら 1 駒あたりの在席標本数は `N × 5 / 51`。
   **試算の式と決めた値を報告書に書く**。1標本 = 5波 × M seed
2. **時間の見積もり**を先に出す。**30分を超えるなら N を減らして精度の条件を緩める**のではなく、
   **対象駒（§2-2）を絞る**こと。**精度の条件は動かさない**
3. **素体を作る対象駒を決める**（§2-2）。**測る前に固定**
4. **陰性対照**: 標本に含まれない駒の値が動かないこと（当たり前だが、標本の乱数と戦闘の乱数が
   混ざっていないことの検算になる）
5. `docs/balance.md` の現在値を控える（**61 行 × 5 波 = 305 セル**）

### 2-1. 対象駒（素体を作る駒）

**全51体は重い。以下の規則で選ぶ（測る前に固定）:**

- **第68期の表D で「相方なし行が 0」だった 27 駒**——**単独で一度も測られていない駒。この期の主題**
- ＋ **移動軸の3枚**（ヨミ・バサ・シオ）——第67期で「2枚では一人前以下」が出た軸の検算
- ＋ **対照として、理想編成で寄与が最大級の3枚**（第68期の表D で相方あり行の寄与が上位）

**合計 33 前後。** これを超えるなら「相方なし行が 0」の27駒を優先し、残りを削る。

### 予測（**測る前に書く**）

| # | 量 | 予測 |
|--:|---|---|
| P1 | 標本の平均勝率（R） | **61行平均 67.2% を大きく下回る**。**30〜50%** |
| P2 | 配置の価値（H − R） | **+3〜+8pt**。**0 に近ければ、5スロットX字は配置の判断を生んでいない**（第57期以来の問い） |
| P3 | 相方あり / なしの寄与差 | **相方ありが大きい**。差は**移動・燃焼など供給が細い軸で最大** |
| P4 | 枚数効果 | 移動軸は **2枚 < 1枚 + 1枚の和**（相方が要るので2枚目から効く＝劣加法ではなく優加法） |
| P5 | 単独で強い駒の型 | **自己完結型**（ドルガ・ゴルム・ガルドのような、他人を必要としない駒）が上位 |
| P6 | 理想編成での寄与との相関 | **低い**。r < 0.5。**高ければ、ドラフト台を作る必要が無かったことになる** |
