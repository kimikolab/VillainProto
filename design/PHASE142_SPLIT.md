## 4. 詰まった所

### (a) `static` ローカル関数はクラスに入れると private になる

段1 の最初のビルドが **518 エラー**（`CS0122 アクセスできない保護レベル`）で落ちた。
`static void Foo()` はローカル関数としては呼べるが、**クラスの中では `private static`** になり、
**`using static Common;` は見えるものしか取り込まない。**
直しは各宣言の頭に **`public` の1語**だけ。**それ以外は1バイトも変えていない。**

### (b) `RelayDiag` が既に `ember` モードのものだった

`BattleSim/Relay.cs` は**ファイル名に反して第130期の `ember` モードの本体**で、`RelayDiag` を使っている。
`relay` モード（第43期・転嫁）を出すとクラス名が衝突する。
**器具が衝突で止まるようにしてあったので実際にそこで止まった**ので、
`relay` だけクラス名を `RelayModeDiag`（`Modes/RelayMode.cs`）にした。
**`Relay.cs` の側は名前も中身も触っていない**（動いているものを動かさない）。

### (c) `docs/` の再生成が `bash` の `>` ではできない

`dotnet … > docs/units.md` を Git Bash から叩くと、**出力が cp932 に化ける**
（`Console.OutputEncoding` がコンソールのコードページになるため）。
PowerShell 7（`[Console]::OutputEncoding` が utf-8）から取り、
**CRLF・BOM 無し**で書くと `docs/units.md` と**ハッシュまで一致**する
（作業ツリーの `docs/` は CRLF。git は `core.autocrlf=true` で LF に正規化して持っている）。

**ついでに CONTRIBUTING.md の `reseat` の分割コマンドが古い**ことが分かった——
`reseat "" 0 28` と `reseat "" 28 28` では **61 行のうち 5 行が落ちて 125 行短くなる**。
第140期に `reseat` が 93 秒になって1回で回せるようになったので、**分割の形はもう使わない**
（文書にも「その必要は無い」と書いてある）。**この期では文書を直していない**——
分割の形は「切り分けたい場合の形」として残っているだけで、**シャード幅が古い**という話なので、
**次に触る期に直す**（指示書 §5 の「動いているものを動かさない」に寄せた）。

**`測った診断` の列だけが 54 行動いた。他の列は両方の表で1文字も動いていない**（機械で照合）。

## 7. この期で分かったこと（則）

1. **1メソッドに畳んだ巨大なファイルのコンパイル代金は超線形。**
   律速は行数ではなく**1メソッドの大きさ**。だから**大きいモードから出すと、出した行あたりの効きが大きい。**
2. **`static` ローカル関数は外側のスコープを1つも捕まえられない。だから別クラスへ移すのは安全。**
   第139期の 52GB は**ローカル関数に包んだ**から起きた。**クラスに出す限りその経路が無い。**
   `using static` で取り込めば**呼び出し側を1箇所も直さずに済む。**
3. **構造を動かした期は、構造から索いている生成物を必ず疑う**（§6-1）。
4. **測定の精度は対象の大きさに合わせて上げ直す。**
   22 GB / 234 秒の頃は1回取りで足りたが、1 GB / 7 秒では ±0.1 GB・±0.6 秒の揺れが判定をひっくり返す。
5. **「1行だけ直す」に割引は無かった**（差分ビルド 244 秒 ≧ クリーン 234 秒）。
   C# はアセンブリ単位でコンパイルするので、**1行触れば 70,065 行が丸ごと再コンパイルされる。**
   **分割後も割引は無い**（差分 7.4 ≒ クリーン 7.5 秒）——**変わったのは「丸ごと」の中身の大きさだけ。**
   だから**効くのは分割であって、増分ビルドに期待することではなかった。**
