## 1. 部A —— 配置の図（`DemoApp` の `Map11*` だけ）

### 1-1. 隊と敵の中身を「X字の図」に置き換える

- 5席（前1・前3／中央／後1・後3）を**盤面と同じ並び**で描く。1席 ＝ 小さな札（**名前・HP バー・死者は灰色**。立ち絵があれば顔）
- **説明文は図に載せない。** 札を選んだ（またはホバーした）ときだけ、下に「何をする」「どの道で」を出す
- 敵も同じ図。**空席は空席として描く**（先遣は後1 が空いているのが見える）。盤面ルールの保持者には ★
- 第170期の文章のパネルは**畳む**（消さない。図の下の「くわしく」で開ける）

### 1-2. 駒どうしの関係を線で描く

**「その席である理由」が見えるようにする。** 対象は**隣接・列・席に依存する特性**だけ。

- 例: ヒサ（前1）→ カド（後1）に線と1語「標」。ガルド → 庇う範囲。ノノ → 回復の届く先
- **線の元データを手書きしない。** Phase 0 で、15 枚の特性のうち隣接表・行・席を読むものを実装から列挙し、
  「誰から誰へ・何の関係か」を**実際の編成に当てて機械で引く**（R260: 手書きの表は網羅性を機械で確かめる）。
  機械で引けない関係は**描かずに報告書で名指しする**
- 線は札を選んだときだけ濃くする（常時ぜんぶ描くと読めない）

### 1-3. 「決める瞬間の隣」に置く

接敵ダイアログ（戦う／引き返す）に、**隊の勝ち筋の一行**と**敵のルールの1行**を上下に並べる。
同じ語（ターン外の行動／回復／1発）は**同じ色**にする。**良し悪しの語は足さない**（案B のまま）。

## 2. 部B —— 封じのイベントを台本に出す（`BattleCore` に最小限）

### 2-1. engine

第170期 §2 の調査どおり、3箇所に**台本へ出すだけの1行**を足す。

| ルール | 足す場所 | 出す中身 |
|---|---|---|
| 粛 | `CanActOutOfTurn` の `if (hushed)` の中（**`sole` が真のときだけ**＝粛が単独の原因で止めたとき） | 止められた駒・止められた行動の経路（`OutOfTurnRoute`） |
| 渇き | `Heal` 入口の `if (DroughtBinding)` の中 | 回復されるはずだった駒・通らなかった量 |
| 軛 | `ApplyDamage` の `if (yokeBinding)` の中 | 殴った駒・殴られた駒・切られた量 |

- イベント種別は**新しい種別を1つ**（仮に `Sealed`。中にルールの種類を持つ）にするか、既存の `Highlight` に乗せるかを **Phase 0 で決める**。
  基準は「再生側が**封じを他の強調と区別できる**こと」
- `DemoOpening` に `Traits` を足す（保持者が誰かを再生側が知るため）
- **判定・数値・乱数の消費順は1つも変えない。** 帳簿（`BoardRuleLedger` / `YokeLedger`）の数と、台本に出たイベントの数が**一致する**ことを自己検査で確かめる

### 2-2. 再生側（仮の表示）

- 止められた駒の頭上に、**短い文字を浮かせるだけ**: 「封じ」（粛）／「渇き」（渇き）／「25 で止まる」（軛）
- 保持者が生きている間、**保持者の札に ★ と1語**（例「粛」）を出し続け、倒れたら消す（S-3）
- **エフェクト・音・カメラは作らない**（Codex の担当。部C の表が渡す材料）

## 3. 部C —— 演出の穴の棚卸し（調べて表にするだけ）

**「絵が付いた駒だけが認識される」**ので、どの特性に絵が無いかを一覧にする。Codex に渡す発注表になる。

対象: マップ 1-1 に出る**味方 15 枚と敵 18 体**の特性すべて。

| 列 | 中身 |
|---|---|
| 駒・特性 | |
| 発火の頻度 | 3隊 × 4区画を各 20 戦回した、1戦あたりの平均発火回数（帳簿・`TallyByUnit`・台本から引ける範囲で） |
| 台本にイベントがあるか | ある（種別）／**無い**（ログの文字列だけ）／**どこにも無い** |
| 再生側に専用の絵があるか | ある／汎用の絵に丸められている／**無い** |
| 他の特性と絵が同じで区別が付かないもの | 例: **ハネの突き返しとバサの入れ替えはどちらも `Move`** |

- 表の末尾に、**「頻度が高いのに絵が無い」順の上位 10** を並べる
- **ハネについては名指しで1節**: ハネが1戦で何回・何をしているか、画面ではそれがどう見えているか

## 6. ポンが遊んだ後に答える問い（`design/PHASE171_WATCH_LOG.md` に雛形）

1. 配置の図を見て、隊の形は一目で分かったか。**カドが後衛にいる理由は図から読めたか**
2. 接敵ダイアログで勝ち筋と敵のルールが並んだとき、出撃前に「困りそうだ」と気づけたか
3. 戦闘中の「封じ」の表示で、**反撃が止められていることに戦闘の中で気づけたか**（第169期は「全然反撃発生しないな」で気づいた。今回は何を見て気づいたか）
4. 仮の表示（文字が浮くだけ）で足りないのは何か。**どう見えたら分かるか**（Codex への発注の材料）
5. 図にして、読まなくなったもの・まだ邪魔なものは何か
6. 図を見て、席を動かしたい・駒を替えたいと思った場面（次の期の組み直しの材料）
