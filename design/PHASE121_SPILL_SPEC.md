# 第121期 —— 巻き込み則の版を並べる（供給を engine から駒へ戻せるか）

起点: 第120期。

> **傷の供給の 89.4% は engine の巻き込み則**（`SpillWoundRule`）。駒（キリ・ノミ）は合わせて 6.9%。
> 味方比 93.1%・**深さ3以上の在庫は全部読み手のいない味方側**・書かれた傷の 94.7% は読まれずに消える。
> 傷を丸ごと外すと 55/73 行が ±0.00、**32〜91pt 落ちる上位6行は全部刻み系（ノミ／ソラ）**。
> `追撃×毒 (ハギ×グザ)` 第2波 −58.5pt（第90期の事故）は**巻き込みの傷を敵の毒が滲み則で読む往復の値段**だった。

**傷軸の実体はノミである。**ノミの通貨は engine の副産物（8.211/戦）の下に埋もれていて、素の状態で測られたことが無い。

### なぜ巻き込み則を疑うのか（**経緯。実装のコメントと第88期の報告から**）

巻き込み則は**第88期に、縫いの両側読み（`SutureRule.Both`・ハリ）と対で採用された**:

> 「読み手を広げる規則」と「供給を作る規則」は必ず対で測る。両側読み単独は Δ がちょうど 0（味方に傷が載る経路が無い）、
> 巻き込み則単独は符号が負（読み手がいないので味方の傷は代金だけ）。**両方で +5.74。**

**その対の片側（ハリ）は第108期にロスターから外れた**（→ トモ）。**供給の側だけが残って、味方に 8.211/戦 を書き続けている。**
第120期の「味方側に溜まった読めない在庫」は、この対が壊れた帰結である。

**この期は版を並べて測るだけ。** 機構は1つも作らない（ノブは既にある）。`Presets` は触らない。**採否は最後に決める**（§5）。

**この指示書は自己完結させてある。** 規約は `CLAUDE.md` の規約節（(G1)〜(G16)）。

## 0. 版

`SpillWoundRule(Enabled, Scope)` は既存のノブ。**新しい enum 値も足さない。**

| 版 | 設定 | 意味 |
|---|---|---|
| **S0 現行** | `Enabled: true, Scope: All` | 味方の刃6枚（余波・生贄・吸い・破裂・棘・置き去り）すべてが書く |
| **S1 絞り** | `Enabled: true, Scope: Dense` | **吸い（ゴルム）と余波（ボルグ）だけ**が書く（第86期 X2。実装済み） |
| **S2 停止** | `Enabled: false` | 味方に傷が載る経路が消える。**第88期以前の状態** |

**S2 が「供給を駒へ戻す」の完全形。S1 はその途中。** 3 版の並びで、落ち方が線形か段か（どの書き手が効いているか）が読める。

### 0-1. 触らないもの

### 2-3. 判定

| | 内容 | 線 |
|---|---|---|
| **Q1** | **器具の再現**（Phase 0 の 1） | 第120期の主要値と一致 |
| **Q2** | **在庫が駒側へ戻るか**: S2 で**味方比が 50% を切る**、**未読が 94.7% から 20pt 以上下がる** | 両方 |
| **Q3** | **刻み系 6 行が S2 で動かない** | 各行の第2〜5波平均が **±3.0pt 以内** |

| **Q6** | **回帰**: 既定経路で `compare` 305 セル 0 件・`docs/` 0 バイト差 | 調査の期 |

**Q3 がこの期の芯。** 刻み系が動かないなら、**傷軸の実体（ノミ）は巻き込み則と独立**で、供給を駒へ戻しても傷軸は残る。
動くなら、ノミの行が実は巻き込みの在庫で稼いでいたことになり、**「傷軸の実体はノミ」が崩れる**。

### 2-4. 予測（**測る前に書く**）

1. **S2 で味方比は 20% 以下**（残るのは棘の巻き込み `ThornWound` の既定 None なので実質 0。駒の経路は敵にしか書かない）
2. **未読は 94.7% → 60〜70%**。敵側は深さ1が 73.1% なので、**書いても断ちの閾値2に届かない分**が残る
3. **刻み系 6 行は ±1.0pt 以内**（Q3 通過）
4. **`追撃×毒` 第2波は +40pt 前後戻る**（往復の大半が消える）
5. **代金は 5 行以下・最大 −8pt 前後**——ノノの繕いを含む行（`耐久`・`傷×被弾`）とガルドの引き取りを含む行。
   **−10pt 超は 0 行**（Q5 通過）
6. **S1 は S0 と S2 の中間ではなく S0 寄り**——供給の密度が高い2枚（吸い・余波）が書く量の大半を占めているはず

**外れた項目は「何を数えていなかったか」の形で書く。**

## 5. 分岐（**採否はここで決める。ただし既定を変えるのは別コミット**）

- **Q2〜Q5 を通る**: **S2 を採用**（既定を `Enabled: false` に）。**第88期の採用を、対の片側が消えたことを理由に覆す**
  ——報告書に第88期の「対で測る」の則を引用し、**覆す根拠を書く**。
  代金の行（ノノ・ガルド）は**席の再判定と対**（第107期）。`docs/` は動く。**主判定19行に含まれる行があれば歯止めを書く**
- **Q3 が落ちる**（刻み系が動く）: **採らない。**「傷軸の実体はノミ」が崩れたので、**第120期の結論を書き直す**。
  ノミの行が巻き込みの在庫で稼いでいた分を数え、**ノミの再設計の入口に置く**
- **Q5 が落ちる**（代金が −10pt 超で 3 行以上）: **S1 を採るか、採らないか**。
  S1 で Q2〜Q4 が通るなら S1。通らないなら現行のまま、**代金を払っている行の読み手（ノノ・ガルド）の処遇**を先に決める
- **Q4 が落ちる**（`追撃×毒` が戻らない）: 第120期の再解釈が違う。**往復の経路をもう一度実装から辿る**
