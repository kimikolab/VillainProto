## 指示書の2度目の変更（ポンの指示・印の版の予測のコミットの後・実装の前）

- 印の効果を「刻みダメージ2倍」から「**刻みを2回**」に。2回目は1回目と同じ量で、**毒の層・燃焼の残りターンは1回分しか減らさない**。**軛は1回ずつに効く**。刻みで反応する札（ベニの反転・刻みの計数・起爆の味方側など）は2回反応してよい
- Phase 0 に、刻みごとに発火するものの一覧と、2回反応すると壊れるものがないかの確認を足す。起爆の刻みも2回にするかは Phase 0 で判断する

**上の Q0-7（起爆の二重の倍化）と Q0-8 の「二重に倍化する経路」は ×2 の版のために書いた**。2回の版では「同じ量をもう1回」なので、倍率が掛け合わさる問題そのものが起きない（両方持ちの ×2 は1回ずつに掛かる）。Q0-9（相手の選び方）はそのまま使う。

## Phase 0 の追加（`mio phase0` の Q0-10・戦闘0回）

`TickStatuses` の毒と燃焼のループで刻みのたびに走るもの 16 本を並べた（表は `mio phase0` の出力）。

- **1回だけにするのは2つ**——燃焼の残りターンの減算と、それに付いた区間の帳簿（`CloseBurnEpisode`）。毒の層は刻みで減らないので、毒の側に1回だけのものは無い
- **2回走ってよいもの**: 反転の回復（＋啜り）・刻みの計数（`BurnTicks`・毒の額面・着火の持続係数・澱み分け／火の計数）・`ApplyDamage`（破片・軛・肩代わり・`OnDamaged`）・台本の `Status`
- **壊れるものは見つからない**。注意は2つ——(1) **1回目で倒れた駒に2回目を当てない**（死亡処理が2回走る）、(2) 業（保持者 0 枚・計数専用）の燃焼の借りが2倍の速さで尽きる
- 台本は同じ駒に `Status` → `Damage` の組が2つ並ぶ（再生側は `Status` の直後の `Damage` を紐づけるので、組のまま読める）
- **起爆: 2回にする**。`DetonateOne` は層も残りターンも減らさないので、1体ぶんの本体を2回呼ぶだけで済み、1回だけにすべきものが無い。印の意味を「この駒の刻みは、どの口から来ても2回」に揃える

### 実装の形（印の版から変えたところだけ）

- 刻みの2回目は `TickStatuses` の毒と燃焼の各ループで、1回目の後に「印がある ∧ まだ生きている」なら**同じ量で本体をもう1回**（燃焼の減算と区間の帳簿は1回目だけ）。起爆は `DetonateOne` を同じ条件でもう1回

## 指示書の3度目の変更（ポンの指示・2回の版の予測のコミットの後・実装の途中）

## Phase 0 の追加（`mio phase0` の Q0-11・戦闘0回）

- Q0-10 の 16 本の分け方（1回の刻みの中で完結するもの／減算とその帳簿だけは1回）は、**回数が 1+n になっても変わらない**。層と残りターンは本体に入る前に1回だけ読んで量を決めているので、回数で量は変わらない
- **倒れた駒に次の回を当てない**（死亡処理・疫みの飛散・破裂・墓守の層が n 回走るのを防ぐ）
- 反転（ベニ）の内側の味方は回復が 1+n 回。軛は1回ずつなので、**回数が増えるほど上限の外側で素通りする量が増える**
- 回数の上限: 1体あたりの印はミオの手番ごとに高々 +1（同じ手番で中心と周りを兼ねない）なので、30 ターンでも n は 30 前後・1回の刻みは最大 31 回。桁あふれの心配は無い
- 業（保持者 0 枚・計数専用）の燃焼の借りだけは1回ごとに減るので 1+n 倍の速さで尽きる。**盤面で壊れるものは見つからない**
- **判断: 起爆も 1+n 回にする**（起爆は減算を持たないので、本体を回数だけ呼べばよく、1回だけにすべきものが無い）。両方持ちの ×2 は1回ずつに掛かる
