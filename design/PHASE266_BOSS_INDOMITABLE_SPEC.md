# 第266期 指示書 —— 勇者1体に戻す・動じないを「不屈」に差し替える

読み手は Claude Code。第265期（取り巻き構造・棄却）の続き。器具 `bosswave`・7台・seed 0..199 はそのまま。`Stages` は触らない（9枠の配管は構造確定後）。

## 0. 位置づけ

第265期の学び: 席による到達差は課税にならず（R363）、取り巻きは落ちると波ごと易しくなる。「割る順序」を解答にする道は閉じた。

一方、元の問題は残っている——検証波の「動じない」（完全無効）は制御軸の解答を丸ごと取り上げており、本編にはそのまま置けない（第261期にこの保留を明記済み）。

→ 取り巻きをやめて勇者1体に戻し、**無効化ではなくコスト付きの許可**にする:

**不屈: 手番を奪う効果（転倒・痺れ・組み付き・竦み・混乱）は通る。ただし受けるたびに勇者の攻撃力が +N される。**

制御軸は「今ターン止める」と「天井を余分に積む」のトレードオフを払う。完封すれば育ちすぎて負け、捨てれば第261期の完封（攻撃ターン0%）に戻る。「マイナスは連鎖のフック」の敵側版であり、転ばされるたびに強くなる勇者はフレーバーとしても成立する。

## 1. 決定

1. **形: 勇者1体（中央・9枠は使わない）**。全体攻撃・HP 3,000・天井 +11・攻 12・**速 14**（第265期対照で移動 82→71% のみの影響・壊れていない）・回復は自前（毎ターン最大HPの40%・W3-割合 の式）
2. **動じない → 不屈に差し替え**。手番を奪う5効果の書き込み（`SetCounter` の1点・第261期に確認済みの28箇所）は素通しし、通った回数 × N を攻撃力に積む
3. 「回復を断つ」解答（第265期で毒+ベニ+ラウ 0→89% を生んだ）は捨てない。ただしこの期には入れず、不屈の形が立ってから再設計する

## 2. Phase 0

1. **不屈の実装点**: 動じないと同じ `SetCounter` の入口で「拒否」を「通過＋計数」に変える最小の形。同一ターンに複数回受けたとき（転倒＋痺れ等）の計数、回復や萎縮など手番を奪わない効果を数えないことの確認
2. **机上計算（R362 の4段 ＋ R363 の注意)**: 各台が1戦で手番を奪う回数の実測（第261期の空振り354回などの計数が使えるはず）× N 候補で、勇者の最終攻撃力と崩れ始めTの見積もり。**N=0（素通し）で第261期の完封が全体攻撃でも再現するか**も先に見積もる
3. 不屈の積みが天井（+11/ターン）と同じ箱に入るか別の箱か（表示と計数の区別。合算でよいが、報告でどちら由来か分けられること）

## 3. 版（N だけを動かす）

| F-11 | 11 | 1回止める＝天井1ターン分 |

## 4. 測定と採否

- 7台 × 3版。指標: 連続量（倒しT・純実入り・崩れ始め）＋**手番を奪った回数**・**不屈由来の攻撃力**・勝率
- 採否:
  - **F-0 で制御軸（移動・雷）が完封または圧勝し、N を上げると勾配が出る**こと（止めた分だけ勇者が育ち、倒しT・勝率に跳ね返る）。N にまたがって単調な勾配が出なければ、不屈は飾り＝棄却
  - **完全無効（対照）と F-11/22 の間に、制御軸の成績の中間帯がある**こと（無効化とコスト付き許可が実際に違う波であること）
  - 全軸が勝てること・既存5波 305 セル 0 件・`checkwave`/`bosswave` の再現全行一致
- 「どの N を規定にするか」は勾配を見てポンが決める（この期は3点を並べるだけ）

## 5. 予測（Phase 0 の机上計算で数値を足す）

- **F-0**: 移動（ハネの転倒）・雷（痺れ）が勇者をほぼ完封し、第261期の形が全体攻撃でも再現。倒しTは両軸とも最短側へ
- **F-11 → F-22**: 移動・雷の倒しTが伸び、崩れ始めが早まる。転換点（止めるより殴る方が良くなる N）は、手番を奪う回数が多い移動の方が低い N で来るはず
- **燃焼・毒・混ぜ**: 手番を奪う手段をほぼ持たないので3版で動かない（±0 の回帰確認を兼ねる）。ここが動いたら計数の混入を疑う
- 対照（完全無効）と F-22 が一致したら、N=22 は実質無効＝コストが高すぎる証拠として記録する
