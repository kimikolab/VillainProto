## 0. 主題

### 0-1. これは「測り直し」であって「基準の差し替え」ではない

第62期は主判定 Q2 の**判定式が問いを測っていなかった**（`reseat` の帯の峰は機構ではなく台の配置感度。

**この期は、直した器具を先に書き、第62期が触っていない seed 帯で測り直す。**
第62期の値（席ごとの帰属が4行すべてで割れる）は**予測**として扱い、証拠には使わない。

### 0-2. 直した器具

> **配置の判断が生まれたか ＝ 席ごとの帰属（現行 − 同じ席の素体）の符号が割れるか。**
> 帯の峰は使わない。

「同じ席の素体」を引くことで、台の配置感度が消えて機構だけが残る。**これが第62期に欠けていた対照。**

### 0-3. 同時に測るもの——弱体も流す版（V3）

規則を対称にする: 「隣で起きる攻撃力の上げ下げを、全部いちばん遅い隣に押し付ける」。
1文のまま表と裏になる。盤面での違いは4つ（**予測として §1 に書く**）:

| 場所 | 強化だけ（V1） | 両方（V3） |
|---|---|---|
| 一番遅い隣が**不動のカド** | 強化が100%死蔵の**罠** | 弱体も100%消える＝**弱体の捨て場**。罠がトレードオフになる |
| 一番遅い隣が**ウツ（逆しま）** | 正の強化で半減 | 差し引きの**符号**で3倍か半減か——賭け |
| **横取りされた隣** | 育たない（代金） | 育たないが**弱体も受けない**（隔離）。弱体が厚い盤面では資産 |
| **ヒヨの隣** | 強化だけが集まる | ヒヨの強化と鈍りの**両方**が一番遅い1体に集まる |

**第61期の条件（符号が割れるには代金と資産が別のノブから出ていること）は満たす**——
強化の供給者と弱体の供給者は別の駒。

### 0-4. 第62期から引き継ぐ判断

- **選択子は「一番遅い」のまま。** 第62期 §11-3（選択子の向きは本体ではない。本体は端に誰が立っているか）を
  受け入れる。V2（一番速い）は測り直さない。フレーバー（遅さで捨てられた層に力を回す）で残す
- **「自分は育たない」は厳密な 0 ではない**（§11-4: 候補が空なら自分の取り分が残る）。
  **分岐は足さない**（強化が消える挙動のほうが読めない）。**駒の文だけ直す**:
  「隣に流せる相手がいる限り、自分の手元には残らない」
- **`AcceptsSupport` は自前で濾す**（第62期 §1-3 のまま）。ただし §11-5 の教訓を Phase 0 に入れる
  ——**席ごとに候補集合の大きさを数え、1枚に潰れる席は「選択子を測れない席」として先に印を付ける**

### 3-3. 採否の順序

1. **V1 の採否を先に決める**: Q1・Q2'・Q3・Q6 の4つすべて → 採る
2. **V1 が通ったときだけ Q9 を見る**: 3条件すべて → **V3 を採る**（V1 は残置）。1つでも欠ければ **V1 を採り V3 は残置**
3. **V1 が通らなければ V3 も採らない**（V3 で通っても採らない——器具を直した期に規則まで変えると
   「何で通ったか」が読めなくなる）。枠は空のまま持ち越し

### 3-4. 判定式の自己検査（**4項目**）

各判定について1行ずつ、測る前に書くこと。

- (a) 条件節が分母の何割を選ぶか（第59期）
- (b) その条件が真になる盤面は存在するか（第60期）
- (c) その判定が最大でどれだけ動くか（第61期）
- **(d) その量は機構を測っているか、台を測っているか——同じ量を素体で出して差が取れているか（第62期）**

**(d) は Q2' に対して特に**: 素体を引いていることを式で示す。
