## 前提の訂正

指示書との食い違いはいずれも**止めずに進めた**。3 件ある。

### 1. 指示書 §2-1 と §5 が、同じ現象に逆の意味を与えている（**紙の段階で点いた**）

§5 は「**S' の共有キー組数が S より大きい**」を「S' が壊れている兆候」＝
「結局『集まりやすいキー』を買っている」の証拠と定める。一方 §2-1 は同じことを予期して

> **枚数効果の傾きは「2枚目が効くか」なので、結果として同じキーが集まるが、それは規則の目的ではなく帰結。**

と書いている。**Phase 0（戦闘0回）でこの条件は点いた**——共有キーの組数は
**S' 2.93 対 S 2.90**（10 万回の抽選）、実測（11,000 標本）で **2.93 対 2.89**。
**差は 0.04 組**（10 組中）で、`check` の 5,000 標本では **2.92 対 2.92 で同値**である。

**実体は §2-1 の言うとおりだった。** S' が買っているのは**被弾**（傾き +19.36・**ロスター最多の 10 枚**）で、
**集まりやすいから買ったのではなく、傾きが最大だから買ったら保持者も最多だった。**
S が集めた 傷・痺 は S' では **0.88 → 0.01 / 0.59 → 0.16** に落ちている（§4-2）。
**兆候のもう片方（Q3 が外れる）は点いていない**（11キーすべて紙と ±0.01・符号も3本とも予測どおり）。

**判定は指示書の字義どおり扱う**——Q1 の値には「兆候が片方点いた」を併記し、
**次期の入口は §5 の対応表ではなく表D（傾きの地図）から引く**（§8）。
**この期は設計判断をしないので、どちらの読みが正しいかは決めない。両方の材料を §4-2 と §8 に置いた。**

### 2. Q4 の「4条件」は、§2-2 の定義では 8 条件になる

§2-2 は傾きの地図を「**11キー × 波（第2〜5波）× 波の強さ（既存 / 弱い）**」と定義する——
**4波 × 2つの強さ = 8 条件**である。一方 §3 の Q4 は「11キー × **4条件**」と書く。
**どちらが正かは指示書からは決まらない**ので、**測る前にコードへ 8 条件で固定し**、
集計2条件（既存·集計 / 弱·集計）と理想61行を併記した。**結果を見てから条件の数を選んでいない。**

### 3. 表E は S' と P の2版を出した（**判定の対象は S' のみ**）

§4 の表E は「S' の版」と書くが、**理想61行との r は比べる相手が無いと読めない**
（第71期の値は N 0.168 / P 0.150 / S 0.205）。**測る前にコードへ固定した規則**は:

> Q5 を満たした版があればその波設定、無ければ**中間帯が最大の版の波設定**を採り、**S' と P の2つ**を出す。

**P を並べたのが正解だった**——P の r は **A 帯 0.150 / 0.521・B 帯 0.149 / 0.527** で、
**第71期の Pw（0.150 / 0.521・0.149 / 0.527）と小数第3位まで完全に一致した。**

なお `check` の (4)（傾きの定数が第71期の写しか）は、最初 **11 キー中 3 件を「不一致」と出した。**
原因は**丸めで、食い違いではない**——定数は 1/100 単位の整数なので
強化 −0.895 / 弱体 −6.495 / 痺 −12.555 / 標 −3.295 は 0.005 だけずれる。
**線を 0.006 に直した**（丸め1つぶんより大きい食い違いだけを拾う）。**傾きの値は1つも変えていない。**
