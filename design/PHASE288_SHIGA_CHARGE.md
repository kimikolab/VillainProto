# 第288期 報告 —— シガの蓄電（感電軸のアタッカー化）

指示書は `design/PHASE288_SHIGA_CHARGE_SPEC.md`。器具は新しい `shiga288`（`BattleSim/Modes/Shiga288.cs`・第287期の `shock287` の候補・組・波・席を流用）。**規定のシガは1ビットも動かしていない**（版は `UnitCatalog.ShigaSGa` ／ `ShigaSGb` ／ `ShigaSGc`・採否はポン）。

## 0. 結論

- **SG-a（育つだけ）は効いた。** シガの与ダメは精鋭の上位台で 1.8〜2.2 倍（例: 近衛1 247.9 → 454.1 ／戦・1振り 41 → 77）、精鋭の格子で届いた台が **近衛 1,896 → 2,256（+19%）・大隊 449 → 485（+8%）**、届いた台のうち**シガが要る台は 近衛 1,339 → 1,697・大隊 134 → 162**。`compare` はシガ在席の2行が +0.9pt、ほかの 305 セルは 0 件、−10pt の行は 0。
- **SG-b ／ SG-c の雷霆は「撃つが当たらない」。** 雷霆の手番は精鋭の上位台で 1戦 1.0 回来るが、**その 91〜99% が空振り**（当たった敵が1体も感電していない）。速さ3 のシガが振る頃には、速い味方の一撃で敵の感電がもう弾けている。撃ち終えると蓄電が 0 に戻るので、**SG-b は SG-a より弱い**（近衛1 の与ダメ 454 → 414）。`compare` は SG-a と同じ値。
- **ボスに感電の答えは出なかった（全版で 0 台）。** 勇者に雷霆が当たる台はある（SG-c で 1戦 2 回・孤立の2倍・1戦 436 HP）。それでボスの格子の 0% を離れた台が 17 → 22 に増え、4 台は 0% から 55〜76% まで上がった。ただしその台は**シガ → ドルガにすると 98〜100% 勝つ**（シガがいない方が強い）。届いた台はどの版でもベニの毒と火の 2 組で、シガが要る台は 1 台のまま。
- **カタの居場所は戻らなかった。** 隣に置いてもカタがシガに足す蓄電は 1戦 0.07〜0.27（トウの漏れが先に感電を付けるので、二値の感電に上積みできない）。カタ → ドルガの落ちは版でほとんど変わらない（近衛 −10.0 → −9.0pt・大隊 −71.0 → −64.0pt）。精鋭の格子でのカタの寄与は 0.2% → 0.3%（近衛）・0.0%（大隊）。
- **手数（振り数）は律速ではなかった。** 律速は**供給の席**（トウの隣でないシガは蓄電 0）と**手番の位置**（雷霆の条件が、遅いシガの番までに消費される）。
- **参考 SG-c′（指示書に無い・雷霆の的を「当たった敵すべて」にした上限）**: 精鋭の上位台でシガの与ダメが規定の 2.7 倍（近衛1 657）になり、ボスは SG-c と同じ（勇者は常に感電している）。勝率はほとんど動かない（上位台は既に 100%）。

## 1. 実装（規則は指示書 §2 のとおり・測る前に固定）

- **蓄電の口は `BattleContext.MarkShock` の1行**（新しく感電が付いたとき・書き手を問わない）→ `GainCharge`（上限 4・私有キー `StoredChargeTrait.Key`・`StatusKeys.All` に入れない・`OnCarryOver` で 0）。保持者がいない戦は `_chargeLive` の比較1つで抜ける。電気鞭で感電を消しても蓄電は減らない。
- 攻撃力の上乗せは `StoredChargeTrait.ModifyAttack`（自己強化なので `Whet` を通さない）。
- **雷霆の枠は `WhipSwing.Bolt`**——振り始めに蓄電 4 かつ手番の鞭（反撃・割り込みは除く）で立つ。的は `WhipAmount` が「当たる前に感電していた敵」を控える。撃つのは `ThunderclapTrait.OnAfterAttack` → `BattleContext.Thunderclap`（`ApplyDamage` の直呼び・2倍の後に足す加算）。札の並びで責め鞭・電気鞭の後に走る（怖気の判定は雷霆の前の盤面）。
- **指示書に書かれていなかったので決めたこと**: **雷霆の一撃は感電を起爆しない**（感電の札に 4 を足した）。電気鞭は打った敵に感電を付け直すので、雷霆がそれを弾かせると、1回の一振りで連鎖が2回起きる。付け直した感電は次の味方の一撃のために残した。自己検査 (h) で、感電している駒に当てた雷霆 222 回すべてについて、当てた後も感電が残っていることを確かめた。
- 文面は指示書 §2-3 のとおり（プラスに追記・マイナスとフレーバーは規定のまま）。
- `ctx.PickOne` ／ `Roll` を新しい本体に使っていない（自己検査 (l) のソースの走査）。
