# 第31期 測定指示書 —— baseline 再確立（主判定編成の選び直し＋波間相関の現在値）

対象ブランチ: `master`（HEAD 084e065 から作業）
性質: **測定のみ。エンジン（BattleCore）への変更は一切禁止。** BattleSim / docs / 集計スクリプトの追加は可。
背景: 粛（第二波）の投入で情報セルの分布と波の独立性が動いた疑いがある。傷の拡張や粛の緩和判断に入る前に、新しい baseline を立てる（「baseline が無効化されたら先に立て直す」の再適用）。

## Phase 0: 前提確認

1. `master` HEAD が 084e065 以降であること、作業ツリーがクリーンであることを確認。
2. `docs/` の再生成を一度走らせ、コミット済みの内容と差分が無いことを確認する。
   - 差分があった場合は**そこで停止して報告**（前セッション終了時の docs が古い可能性があるため、原因を特定してから進む）。
3. 長時間ジョブは**フォアグラウンドで1回のツール呼び出し内**で実行すること（バックグラウンドは起動コマンドの終了とともに死ぬ）。

## Phase 1: 現在値の取得

1. `compare` を全40行 × 全波で実行し、勝率マトリクスを取得する。
2. `spread` を現在値で実行する。
3. 出力はそのまま `docs/` の該当ファイルに反映（既存の再生成フローに従う）。

この Phase の成果物が以降すべての入力になる。**シード・試行数は既存 baseline と同一条件**にすること。変えた場合は比較不能になる。

## Phase 2: 波間相関の再計算

### 2-1. 計算方法

- 入力: Phase 1 の 編成 × 波 の勝率マトリクス。
- **第一波は相関計算から除外する**（全行100で分散ゼロ、相関が定義できない。除外の妥当性は 2-3 で裏取り）。
- 第二〜第五波の**全ペア（6組）**について、編成をサンプルとした Pearson 相関を計算する。
  - 前々回の +0.88 は第2-3波だけだったが、粛は第4波との符号反転（+0.28→−0.28）も既に起こしているので、全ペアを一度に見る。
- 追加で、両波とも 0% または両波とも 100% の行（情報ゼロの行）を除いた場合の相関も併記する。全行版と除外版で符号や大きさが大きく違う場合はその旨を明記。

### 2-2. 固有の勝者・敗者の集計

各波について:
- **固有の勝者**: その波だけを高勝率（≥90）で抜け、他のどの波（第一波除く）でもそこまで届かない編成の数と名前
- **固有の敗者**: その波だけで低勝率（≤10）に落ちる編成の数と名前

閾値90/10は暫定。分布を見て不自然なら変えてよいが、変えた場合は理由を書くこと。

### 2-3. 判定材料の報告

- 第2-3波相関の新旧比較（+0.88 → ?）
- 「共有資源: 後列到達力」の説明がまだ成立しているか。粛は「後列到達力＋ターン外の手数」を課金するので、第三波（渇き）との共有部分が減っていれば相関は下がるはず——**下がっていた場合と下がっていなかった場合の両方について、どの編成が差を作ったかを行レベルで3例ずつ挙げる**（規則5: 予測と検証は軸名でなく駒を数えて書く）。

## Phase 3: 主判定編成の選定（提案まで。確定はしない）

### 3-1. 選定基準（優先順）

1. **情報セル数**: 第二〜第五波のうち、勝率が (0, 100) の開区間に入るセルが2つ以上ある行を候補プールとする。
2. **軸の被覆**: 各軸（死・毒・傷・溜め・カウンター・耐久・追撃 ほか、現行 compare の軸区分に従う）から最低1行。傷軸は入口の違い（キリ×エグ／ノミ系）が別の行として出ることが実測済みなので、**傷軸は2行**確保する。
3. **行間の冗長性排除**: 同一軸内で全波の勝率ベクトルがほぼ一致する行（相関 >0.95 目安）は片方に絞る。ミラー重複（reseat の既知残件）に該当する行があればここで併せて指摘。
4. **境界の番人**: 100% 天井に張り付いている行も**2〜3行だけ**残す（回帰検知用。「±0.0 が無変化の証明」に使うため、全部を情報セル持ちにしない）。

### 3-2. 成果物

- 主判定候補リスト（12〜16行目安）＋各行の採用理由1行
- 落とした行のリスト＋落とした理由（軸重複／情報ゼロ／ミラー等の分類つき)
- **第一波の扱いの提案**: compare の実行対象からも外すか、実行はするが主判定・相関から除外し続けるか。実行コスト（1波分の時間）と回帰検知価値を比較して提案を書く。**確定は測定報告後にこちらで行う。**
