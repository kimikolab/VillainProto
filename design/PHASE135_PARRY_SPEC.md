## 0. この期の性格

**HEAD は第134期**（重ね掛けの実測で層は落ちた。盤面は1ビットも動いていない）。

**燃焼から離れる。** 第130期から5期使って採用0で、
第134期が「**燃えている駒の 77.5% が火より先に倒れる**」を出した以上、
次に要るのは燃焼の設計ではなく**盤面の寿命**の話になる。それは重い。**溜まった宿題を1つ片付ける。**

### 0-1. ガルドは「一文と実装が食い違っている」ことが確定している駒

| | 一文 | 実装 |
|---|---|---|
| **強み** | 味方への攻撃を肩代わりし、**その傷のぶん強くなる** | 庇いは `SelectTargetChain` の段で**単体攻撃にしか効かない**。**「傷のぶん強くなる」は `AtkBonus` を1も動かさない**——`GatherRule`（第89期）は隣接する味方から**傷を1つ自分へ移す**だけで、コメントに「**ガルドは傷を1つも読まない**」「`ApplyDamage` を通さないので `AtkBonus` は1も動かない」と明記。**しかも第122期に `GatherRule(false)` が採用されている**ので、引き取りすら動いていない可能性がある |
| **欠点** | 味方全体に配られる強化も弱体も自分には乗らず、隣接する味方へそのまま流れる | `Stoic`。**1体を選ぶ回復・強化は受け取れない** |

**ガルドはいま「自分のための効果」を1つも持っていない。** 庇う（自分は損）、傷を集める（他人が使う）、
支援を受け取れない——**全部が他人のためか純粋な損**である。

### 0-2. ポンの実感と実測が一致している

- 第124期「**ガルドがただの耐久力のある壁にしか画面上は見えない**」
- 第125期「**ガルドがタンクなのに脆すぎてすぐ落ちる**」
- 第126期の実測: **平均生存 2.17T / 死亡率 98.5%**
- 第129期の延命台: 発火密度 **×0.65**（鍵は「味方の被弾」＝毎ターン起きる）。
  **予測 P6「ガルドは延命すれば起動する」は当たっていた**＝**守れば働く側の駒**

### 0-3. この期の形 —— **まず死因を測る。案はその後**

ポンの案:

> 味方を庇うときは被ダメージカット、そして敵の攻撃を受けるとき**確率でパリィして攻撃を無効化**。
> **バフや回復は出来ないけど技量でカバー**する方向性。

**方向は支持できる**（§0-2 のとおり守れば働く駒なので）。ただし**先に測るべきことがある。**

> **庇い・標的の介入は Single にしか効かない**（`CLAUDE.md` が設計の中核と明記）。
> つまりガルドは**第四波の薙ぎも第五波の全体も1つも庇えない。**
> **範囲で削られているなら、受け流しの回数が来る前に落ちる。**

**ガルドが何で死んでいるかを先に割る。** 第134期の則がここに効く:

> **同じ総数が3つの違う構造から出ていた。総数では区別できず、区間の最大値でしか割れない。**

ガルドの被弾も、総量で見れば「たくさん殴られている」だけである。**攻撃型別に割ると別の絵が出るはず。**

### 0-4. 確率ではなく**回数**にする

ポンの案は「確率でパリィ」だが、**回数に変える**。理由が3つ:

1. **確率は敵の火力に比例する。** `minus-trait-design-notes` が反射を却下した決定的な理由がこれ:
   「カドの反撃 = **自分の攻撃力**の2倍 → 自己完結。**真の反射 = 被ダメージの一定%** → 敵の火力に比例し、
   **難易度カーブを平坦化する**」。**無効化は量を返さないだけで、弾いた量が得になる点は同じ**——
   第五波の断罪や詠唱兵の全体を弾いたときの価値は、雑魚の一撃の何倍にもなる
2. **回数なら上限が自然に決まる。** 第118期の「**代金は係数で薄まらない**」からも、係数より回数のほうが安全
3. **ポンがバサの配置交換のランダム性を4期連続で不満に挙げている。**
   **主力のタンクの生死が運で振れる**と同じ不満になる

**ポンも「回数でも今よりかなり耐久できる、むしろ安定する」と同意している。**

### 0-5. **被ダメージカットは入れない**

軽減の在庫が既に厚い——**ドハ**（味方の被ダメの4割を肩代わり・薙ぎでも全体でも効く）、
**クビ**（味方全体の被ダメを30%下げる）、**ササ**（隣に味方がいない駒の被ダメを35%下げる）。
**受け流し1本に絞る**（差分を1つに閉じる）。

### 0-6. やらないこと（明示）

- **被ダメージカット**（§0-5）
- **庇いを範囲・貫きにも効かせること。** `CLAUDE.md` が設計の中核と明記している
  「庇い・標的の介入は Single にしか効かない」に触る。**やるなら独立した期を1本使う**（§8-1）
- **`GatherRule` の既定を変えること**（第122期の採用を覆さない。**測って報告するだけ**）
- **ガルドの能力値（HP100 / 攻9 / 速4）の変更**
- **スィド・ササのタンク化**（ポンの次の関心。§8-2）
- **`DemoApp`**（Codex の担当）／作戦マップ／`GodotApp` の削除（§8-6）

## 2. 予測（実装の前にここに書いてある。後から書き換えない）

### P0 —— 段1・段2 は台本も勝敗も変えない

**`compare` の 305 セルは `docs/balance.md` と 0 件差分。**

### P1 —— **総量の過半は単体。ただし致命打の過半は範囲**

**分母**: ガルドが受けた総量（Q0-1）と、倒れた戦の致命打（Q0-2）。

ガルドは庇うので**単体を引き受ける回数が多い**。**総量では単体が過半**になるはず。
一方、**HP100 を削り切るのは範囲**——第四波の薙ぎ・第五波の全体は庇えずに直撃する。
**致命打では範囲（薙ぎ＋全体＋貫き）が過半**になるはず。

> **これが「総数では区別できない」の実例になる。**
> **P1 が両方当たれば、受け流しは「総量は減らせるが死因には届かない」**ことになり、
> **N をいくつにしても効かない可能性が高い**（§5-1 で判定する）。

### P2 —— **`GatherRule` は 0 回/戦。一文は完全に死文**

Q0-4。**第122期に既定オフが採用されている。**
**1回でも起きていたら、既定の理解が間違っている。**

### P3 —— **庇いの機会は 1戦あたり 2〜4回**

Q0-3。第129期の延命台でガルドの発火密度は ×0.65 だった（鍵は毎ターン起きる）。
平均生存 2.17T なので、**庇いの成立は 2〜4回/戦**のはず。
**これがパリィの N の上限**——**機会が3回しかないのに N=5 は意味がない。**

### P4 —— **受け流しは生存Tを +1.0T 以上買える**

第117期・第126期で使った線（**ゴルム1枚だけが +1.0T を買っていた**）。
**回数制の受け流しは、第126期の案B（無条件の猶予・1戦1回）の +0.21T より大きいはず**——
**庇いに紐づくので発動機会が確実にある**。

### P5 —— **ガルドを含まない行は ±0.0**

段3 に進んだ場合の回帰。**動いたら事故。**

### P6 —— **受け流しはドハ・クビと重ならない**

Q0-8。ドハは割合で肩代わり、クビは全体の軽減、**受け流しは単発の無効化**。
**同じ行に入っても効果が乗算的に重ならない**はず。
**重なるなら、ガルドの個性が既存の軽減の強化版になってしまう。**

### 3-1. 段1 —— 死因の診断

### 3-2. 段2 —— 受け流しをローカル台で測る

**台の作り方**（第126期・第130期の教訓）:

- **庇いが確実に起きる台**にする。**ガルド＋庇われる味方＋土台**（全版で同一）
- **敵は単体攻撃と範囲攻撃の両方を持つ**（P1 の切り分けがそのまま効くので）
- **庇いの成立回数を毎版で計数する。0 なら測定不能として止める**

**N の決め方**（**線を後から動かさないため、決め方を先に固定する**）:

> **N は Q0-3 で実測した「庇いの成立回数/戦」の中央値を上限に、1 / 中央値 / 中央値×2 の3点を取る。**

**版**:

| 版 | 内容 |
|---|---|
| V0（対照） | 何も載せない |
| V1 | **庇った攻撃**を1戦に N 回だけ受け流す（無効化） |
| V2 | **自分への攻撃すべて**（庇いかどうかを問わない）を1戦に N 回だけ受け流す |

**V1 と V2 を分ける理由**: V1 は「庇うほど強い」でガルドの一文に沿う。
V2 は「技量」というポンの言葉に沿うが、**範囲攻撃も弾ける**ので P1 の死因に直接届く。
**どちらが効くかは死因の内訳しだい**なので、両方測る。

**測るもの**:

- **受け流した回数と量**（経路別。単体／薙ぎ／全体…）
- **ガルドの生存T**（V0 との差＝買った時間。**P4 の主判定**）
- **庇われた味方の生存T**（ガルドが長く生きると誰が得をするか）
- **勝率・決着T・残存**

**代金を付けない。掃引しない。**（第118・126・127・128・130・133期と同じ）

### 3-3. 段3 —— 載せる（**進まなくてよい**）

  **受け流しを足すのと同時に、死文を落とすか実装に合わせる**。

- **`checkup` の分類表に1行足す**（Q0-10・A7）
- **能力値・席・`Presets` は触らない**

## 5. 採否

### 5-1. **段2 に進まない判断がありうる**

**段1 の結果しだいで、この期は診断だけで終わってよい。**

> **P1 が両方当たった場合**（総量の過半は単体・**致命打の過半は範囲**）、

1. **ガルドの生存T が V0 より +1.0T 以上**（P4。第117期・第126期と同じ線）
2. **受け流した経路が、Q0-2 の致命打の経路と重なっている**
   （**総量を減らしただけでは死なないようにならない**）
3. **庇われた味方の生存Tも上がっている**（ガルドが長く生きる意味があるか）

**1 と 2 の両方を満たすこと。** 第129期のハギで「**増えた**」を線にして失敗しているので、
**「仕事をしたと言える量になった」**を線にする。
