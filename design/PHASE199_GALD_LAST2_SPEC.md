## 1. 目的

第198期（`design/PHASE198_GALD_LAST.md`）で剣の段が入り、30ターンの打ち切りは消えた。ただし:

- 抜いた時点で HP は約4割、受け流しを捨てるので**平均 0.9 ターンで倒れる**（R305）。打ち切りが負けに移っただけに近い
- 「背負った傷」の上乗せは攻撃力 +1.25 前後。庇った一撃の大半を受け流しが消すので、身に受けた傷の累計が平均 16.1 しかない
- 相打ちで最後の敵を倒しても、今の判定では負けになる

ポンの判断: **「盾を捨てる」は残す**。そのうえで剣の段を直す。受け流しを残す盾剣の版は採らない。

### 1.1 絵コンテ（直した後）

1. 最後の味方が倒れる。ガルドが盾を落とし、剣を抜く。**これまで受け止めてきた刃の分だけ、鎧のひびから光が漏れる**
2. 盾は無いが、体に残った構えで数合を受け流し、斬り結ぶ。斬られれば斬り返す
3. 構えが尽き、最後の一撃を受けながら放った一太刀が、最後の敵を倒す。**相打ちで勝つ**

## 2. 変更（3点）

### 2.1 受け流した刃も「背負った傷」に数える

- 剣を抜く瞬間の上乗せの元を、「庇いで身に受けた傷の累計」から **「庇いで身に受けた傷＋受け流しで無かったことにした刃の累計」** に変える
- 受け流した刃の量は、**受け流さなければ受けていたはずの打点**（受け流しの判定の時点の値）
- 割合は第198期と同じ `LastStandScarPercent = 10`（切り捨て）。攻撃力は第198期の決定どおり（素の攻撃力＋上乗せ）×2
- 剣を抜いた後の傷は数えない（抜いた瞬間に一度だけ決める）

### 2.2 抜いた瞬間の受け流しの在庫を残す（構え直しはしない）

- 剣を抜いた瞬間の受け流しの在庫は**そのまま残す**。在庫がある間は、向けられた刃を受け流す（第198期までと同じ判定）
- **毎ターンの構え直しはしない**。庇いによる在庫の補充もしない（守る味方がいないので起きないはずだが、明示的に止める）
- 在庫がある間も、剣の段の手番の攻撃（薙ぎ×2）と斬り返しは行う
  - 受け流した一撃には斬り返さない（ダメージを受けていないため）。斬り返しは第198期どおり「ガルドにダメージを与えた敵」に返す
- 在庫が 0 になれば、第198期の剣の段と同じ

### 2.3 相打ちで最後の敵を倒したら勝ち

- **ガルドの相打ち（倒れる一撃への斬り返し・`LastStandRiposte` の `Slot = 1`）で最後の敵が倒れた場合に限り**、その戦を勝ちとする
- ほかの「両陣営が同時に全滅する」経路の判定は変えない（範囲をこの1経路に閉じる）
- 勝ちになった戦の生存者は 0 体。会戦・作戦マップで「生存者 0 の勝ち」をどう扱うかは Phase 0 で確認し、落ちない・壊れないことだけを受け入れ条件にする

## 5. 予測（実装前に宣言してコミット）

### `units.md` の文面（案）

- 特性: 味方への単体攻撃を必ず庇う / 向けられた刃を回数ぶん受け流して無かったことにし、毎ターン構え直す。庇って身に受けるたび回数が1つ戻る / **守る味方がいなくなると、盾を捨てて剣を抜く。これまで受け止めた刃が力になり、倍の力で薙ぎ払い、斬られれば斬り返す。最期の一太刀で敵を倒せば、その戦は勝ち**
- マイナス: 守る味方がいる間は、自分からは決して攻撃しない / 剣を抜いた後は構え直せない / 味方全体に配られる強化も弱体も自分には乗らず、隣接する味方へそのまま流れる（1体を選ぶ回復・強化は受け取れない）
- フレーバー: 「誓約が壊れていて、もう誰の助けも届かない。」（現行のまま）
