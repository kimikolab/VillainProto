## 1. Phase 0（作る前に数える）

出力: `dotnet run --project BattleSim -c Release 0 miasma phase0`（所要 5.3 秒・seed 0..199）。
**盤面は1つも動かしていない**——この時点の `UnitCatalog.Guza` は `Actions` を持たないので
`ActsOnPattern` が偽 ＝ `MiasmaTrait.OnTurnStart` が従来どおり発火する。

### 1-1. 瘴気の窓口

- `MiasmaTrait.PerTurn` = **2**（敵全体）／ `MiasmaTrait.AllyLeak` = **1**（味方全体・**自分を含む**）
- 発火口: `OnTurnStart`（現行）／`OnAction`（移設後）。分岐は `Trait.ActsOnPattern`
- ターンの順序: `TickStatuses`（**毒 → 燃焼** の2ループ）→ `OnTurnStart` → 行動順ループ
- **毒のカウンタは刻んでも減らない**（毒ループは `ApplyDamage` を呼ぶだけで `SetCounter` しない）
  ——だから味方の漏れは**消してくれる駒がいなければ累積する**
- engine 側の窓口は `TickStatuses` の毒ループ 1 本（第50期の一覧のとおり）

`StatusKeys.Poison` を**読んで分岐する**駒側の窓口（8行での枚数つき）:

| 特性 | フック | 何をするか | 8行での枚数 |
|---|---|---|--:|
| `Blightfed`（澱み喰い・ヴィオ） | `OnTurnStart` | 味方の毒を**全部 0 にして**攻撃力 +4/層（**自分の毒は吸わない**） | 2 |
| `Devour`（毒喰らい・ベニ） | `OnTurnStart` | 毒に侵された敵の数 × 4 を味方全体に回復。**味方の毒の刻みを 2 倍にする** | 2 |
| `Amplifier`（澱み・ミオ） | `OnAction` | 毒に侵された敵の毒を +4 | 4 |
| `Contagion`（疫み・ラウ） | `OnAnyDeath` | 毒に侵された駒が倒れると残りの敵へ毒が飛ぶ | 3 |
| `Torment`（責め苦） | `OnAfterAttack` | 毒／痺れを負った相手を責める | 0 |

**澱み（ミオ）は既に第11期に `OnAction` へ降りている**（速8）。グザは速5なので、
移設するとミオより**後**になる——「同じターンにミオが増幅できる毒」が1ターンぶん減る。
これは指示書が挙げていない副次効果で、4 行に効く。

`Run` が `player` → `enemy` の順に `Add` した並びで、`Formation.Occupied()` は
スロット昇順に返す ＝ **味方はスロット昇順**（乱数も速さも入らない）。

## 3. 実装

**ヒヨ（`FavorTrait`・第60期）とまったく同じ形。** `MiasmaTrait` の本体を `Spread` に括り出し、
`OnAction` に本体を置き、`OnTurnStart` は `ActsOnPattern` が偽のときだけ発火させた。
**engine には規則も窓口も1行も足していない。**

足したのは**誰も読んで分岐しない計数 7 本**だけ（`BattleContext` → `BattleResult`）:

    MiasmaFires / MiasmaToFoe / MiasmaToAlly          瘴気の発火回数と撒いた層の総量
    PoisonBitePlayer / PoisonBiteEnemy                毒の刻みの**額面**を陣営で割ったもの
    PoisonTicksPlayer / PoisonTicksEnemy              その回数

`PoisonBite*` は**額面**（毒喰らいの倍率を掛けた後・肩代わり／破片／軛を通す前）で、
**実際に減った HP ではない**。P3（味方の毒の刻みが増えるか）は額面で読むのが素直で、
実害は勝率と `DamageTaken` の側に出る。

**版の切り替えは駒の側で行った**（`ActsOnPattern` は `UnitDef.Actions` を読むので規則では
切り替わらない。第60期 §0 の訂正1）。V1 / V2 / V3 は診断 `miasma` のローカルの `UnitDef` で、
**`UnitCatalog` は1バイトも触っていない。**

### 受け入れ基準 1・2 の検算

**分岐を足した直後・`UnitCatalog` を触る前**に `compare` を取り、
`docs/balance.md` と **305 セル 0 件**で一致することを確認した（第60期 §4 と同じ形）。
`UnitCatalog.Guza` は `Actions` を持たないので `ActsOnPattern` が偽 ＝
`OnTurnStart` が従来どおり発火する。**この期は最後まで採用しなかったので、
報告書執筆時点でも `compare` は 305 セル 0 件のまま**（＝受け入れ基準2・Q7 も自明に満たす）。

1. **`OnTurnStart` は「全員より先」という speed = ∞ の席である。**
