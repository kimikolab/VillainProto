# 第266期 報告 —— 勇者1体に戻す・動じないを「不屈」に差し替える

指示書は `design/PHASE266_BOSS_INDOMITABLE_SPEC.md`。器具は `bosswave indom0 ／ indom ／ check266 ／ log266`（`BattleSim/Modes/BossWave.Indom.cs`）。

**結論: 棄却（不屈は飾り）。** 移動・混ぜは勇者を毎ターン転ばせ続けるので、積んだ攻撃力で振る手番が来ない——N を 0 → 22 にしても全指標が1セルも動かない。勾配が出たのは雷だけ（全員生存 100 → 93%）。`compare` 305 セル 0 件・`checkwave` ／ `bosswave`（第265期）の再現は全行一致。


## 1. Phase 0

### 0-1 不屈の実装点

- 入口は動じないと同じ `UnitState.SetCounter` の1点。動じない（`BlocksControl`）は**値を書く前に拒否**し、不屈（`Trait.TaxesControl` ／ `OnControlGained`）は**値を書いた後に、実際に上がったときだけ**札に知らせる。保持者のいない駒は `ControlTaxed`（`Traits` を入れたときに1回だけ求める bool）で抜ける
- 数えるのは手番を奪う5キー（`StatusKeys.IsControl`）の値が**上がった回数**。同じ手番に転倒と痺れを受ければ 2 回、既に痺れている駒に同じ値を書けば 0 回、0 → 2 は 1 回（量ではなく回数）。回復・萎縮・毒の鈍り・燃焼は数えない（`check266` (a-3)〜(a-5)）
- 札は3版（`Indomitable0` ／ `Indomitable11` ／ `Indomitable22`）。勇者の回復は自前の札 `BossMend40`（`BossMendTrait` を最大HPの 40% で登録しただけ）

### 0-3 天井と不屈の箱

**別の箱にした。** 天井（`BossRiseTrait`）はターン数から、不屈（`IndomitableTrait`）は私有キー `indomitable` の回数 × N から、どちらも `ModifyAttack` で足す。`AtkBonus` には積まない（弱体の窓口・横取りに触れない）。内訳はキー別の私有キー（`indomitable:stun` など）に持つ。報告ではどちら由来かを「不屈の積み」「天井の積み」に分けて出す。

### 4-1 なぜ飾りになったか —— **連続の転倒は、勇者に積んだ攻撃力を一度も払わせない**

- 移動の1戦（`bosswave log266 移動 F-22 0`）: 勇者は T1 に1度だけ振り、その一撃にハネが突き返して転ぶ。**転んで手番を失ったターンにも「押し込めなかったが、打たれて転んだ」でもう一度転ぶ**ので、以後は毎ターン転んだまま。不屈は 9 回積んで攻撃力 +198 になったが、**その攻撃力で振る手番が来ない**
- だから移動・混ぜの 188 ／ 1,695・200 ／ 1,391 という「振れた手番」は3版で同じ数で、純実入りは 0.0（勇者は隊に1点も入れていない）
- 雷は痺れが 3.5 回 ／ 戦で途切れる（振れた手番 37.9%）ので、積んだ分が振れた手番で払われる——勾配が出たのは雷だけで、幅が小さいのは回数が少ないから
- **不屈は「止めるたびに強くなる」なので、「止め続ければ払わなくてよい」。** 代金が勇者の手番で払われる形のままでは、完封できる台ほど代金がゼロになる——指示書 §0 の「完封すれば育ちすぎて負け」は、**完封が途切れる台にしか成立しない**

### 4-2 副次の観察

- **完封しても倒しT は縮まない**（Phase 0 のとおり）: 移動・混ぜは勇者の全体攻撃に反応して手数を増やす台なので、勇者を止めると自分の削りも細る。移動の倒しT は F-0 T8.5 ／ D-40 T5.3。**制御の台にとって、完封は守りであって削りではない**
- **完全無効（D-40）のほうが制御の台に厳しい**（移動 全員生存 80.5%・崩れ始め 19.5%）——第261期の動じないの判断（制御の解答を取り上げる）は、今の盤面でも「波を難しくする」向きに働いている
- B3-速14（毎ターン全快）と D-40（40%）の差: 移動 71.0 → 99.0%。毎ターン全快が移動に重かった
