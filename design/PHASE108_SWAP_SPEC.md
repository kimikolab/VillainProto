起点: 第107期（席を3行差し替え・**ムドは「量で育つ」で確定**・

**52枚のうち役割が未確定の駒は1枚（ハリ）だけ**）

**この期は駒の入れ替えまで。トモの機構を測るのは第109期。**
**「行が変わったせい」と「駒が変わったせい」を切り分けるため。**

## 0. 主題

### 0-1. ハリを切る根拠は4期ぶん揃っている

| 期 | 実測 |
|---|---|
| 第83期 | 3分の器具で**唯一「切れる」判定** |
| 第85期 | 両側読み（味方の傷も読む）を足して救えず。**律速は振り回数 2.15 回/戦** |
| 第106期 | **第104期の再行動が 0.00 回/戦しか届かない**（再行動は傷の書き手にしか渡らず、ハリは読み手） |
| 第107期 | 発火口を `BattleContext.Wound` へ移しても救えず。
**傷の書き込みの 90.5% が巻き込み則＝味方側**なので枠を味方の傷が先に埋め、
**敵から糸を引く回数が 0.53 → 0.00**。`刻み×縫い` の +3.3pt の正体は
**「第74期に切り出した代金が消えたこと」**（繕い量は 23.1 → 20.1 と**減少**） |

**3期にわたって律速が同じ場所（振り回数）で、発火口を移しても解けなかった。**

### 0-2. ロスターの定義

> **ロスターは「編成に選べる 52 枚」で定義する。内部の `UnitDef` がそれを超えていてよい。**

召喚専用（背いた獣・胞子・亡者）が既にそうなっている。**`SutureTrait` / `SutureRule` /
`SutureFireRule` の実装は残置し、`UnitCatalog.All` から `Hari` を外すだけにする**
——**測って採らなかった機構は削除せず対照として残す**という作法に沿う。

### 0-3. 入れる駒

**尾灯のトモ。** 会話で形が固まっている。

| | 値 |
|---|--:|
| MaxHp | **54** |
| Attack | **0** |
| Speed | **3** |
| Pattern | 単体（**振らないので実質使わない**） |
| Traits | **`Taillight`（尾灯）1つ** |
| Actions | **`[Skill]` のみ**（**通常攻撃を振らない**） |

> **PlusText**: 毎ターン、自分を除いて最も遅い味方に灯をともす（攻撃力 +5・累積）
> **MinusText**: 灯は1体にしか灯らない。対象が変わると前の灯は消える。
> 自分の手番より前に敵が倒れていたら、灯した味方に手番を譲る。自分は動けない
> **Flavor**: 尾の灯は自分では見えない。照らせるのは、後ろにいる者だけ。

**攻撃力 0 の根拠**: 第87期の「接続子が両方とも出力ゼロだと5枠盤で橋が架からない」に当たらない。
**トモは術で出力を出す**——強化（`Whet`）は第105〜106期で4つ目の通貨として扱っている。
**通貨が違うだけで出力ゼロではない。** あわせて「素の通常攻撃しか振らない駒を減らす」方針に沿う
（`TURN_SLOT_PLAN` の実測: **46体中30体が素の通常攻撃しか振らない**）。

## 1. やること

### (T1) `刻み×縫い (ノミ×ハリ)` の席を埋める（**トモを入れない**）

現行: `front1: Dolga / front3: Golm / center: Nomi / back1: Vel / back3: Hari`

**この行は「ノミが刻んで、ハリが読む」＝傷軸の組を測る行**なので、
**トモ（傷と無関係）を入れると行の意図が消える。**

> **`Hari` の席に既存の傷の読み手を入れる。**
> **候補は 抉りのエグ と 断ちのナタ。**
> **行名は中身に合わせて変える**（`刻み×抉り` は既にあるので重複しないこと）。

**どちらを入れるかは Phase 0 で決める**——
**`Presets.Compare` の 61 行を読み、既存の行と組が重複しないほうを選ぶ。**
**選んだ理由を1行で書くこと。**

**席は `reseat` で確認する**（第107期で「**機構が変わった行の席は寿命が切れる**」が3行で確認された）。
**駒を入れ替えたのだから、その行の席は寿命が切れている。**

### (T2) `UnitCatalog.All` から `Hari` を外し、`Tomo` を足す

- **`SutureTrait` / `SutureRule` / `SutureFireRule` の実装は削除しない**（§0-2）
- **`UnitCatalog.Hari` の `UnitDef` も削除しない**（`Presets` から参照が消えるだけ）
- **`All` の枚数が 52 のままであること**を確認する

### (T3) `TaillightTrait` を実装する

```csharp
OnTurnStart(ctx, self):
    if (!self.IsAlive) return;
    target = 自分を除く生存味方のうち、Def.Speed が最小。同速は Slot 昇順
    if (target is null) return;
    if (target != 前回の対象) { 前回の対象の灯を消す; 前回の対象 = target; }
    target.AtkBonus += Lumen;        // Lumen = 5
```

```csharp
手番（Skill）:
    if (自分の手番より前に、このターン敵が倒れていた)
        灯した味方に手番を1回与える;     // 自分は動かない
    else
        （何もしない。灯は OnTurnStart で既にともっている）
```

- **`Lumen = 5`。振らない。**
- **灯は累積する。上限を数値で書かない**——**対象が変わると消える**ことと、
  **決着が 3〜7 ターン**であることで構造的に止まる（実質の天井は +15〜30）
- **自分は対象外。** 自己完結を避ける（第84期以降の原則）
- **`ctx.PickOne` を使わない**（第89期 (h)。候補2個以上で `Roll` を消費する）。**席番号で決定的に**
- **手番を与える経路は第104期の `TakeTurn`**（切り出し済み）を使う。
  **1ホップ**——**与えた手番の中で敵が倒れても、そこから再度譲らない**
- **`AtkBonus` を直接触るか、既存の窓口を通すかを Phase 0 で決める**——
  **第102期に `NecroTrait` が「エンジンが一律 0 にした後」を前提に帳簿を持っていた**ので、
  **帳簿を持つ特性と衝突しないことを確認する**

### (T4) `docs/` を再生成し、`Baseline` を測り直す

**駒が入れ替わるので `PrimaryFifthFloor` が動く。** 動いた値を第109期の拒否権に使う。
