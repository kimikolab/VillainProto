# 第242期 指示書 —— 火勢を入れる（燃え広がり・ヒヨのターンギフト・ホタの段）

置き場所: `design/PHASE242_FIRE_LEVEL_SPEC.md`。報告は `design/PHASE242_FIRE_LEVEL.md`。
**この期から盤面が変わる**（影の計算ではなく実装）。**規定は変えない**（版として並べ、採否はポンが遊んで決める）。

## 1. 目的

燃焼の軸のコンセプトは **「耐えて、燃え上がり、焼き尽くす」**。第239〜241期の影の計算で、火勢の形がほぼ決まった。

- **火勢（火の大きさ）は4段**。点け直しは火を**保つ**だけ、**育てる**のは燃え広がりとヒヨの煽り。育たなければ萎む（将来、敵の鎮火で下げられるように）
- **2ターン目からターンギフト**を撃てるのが目標（第241期の影では、ヒヨの火の育ち方 HS3 で 97.5%）
- **ヒヨのスペシャルはターンギフト**: ヒヨ自身の火勢3で1体、4で2体に手番を渡す。**相手は火勢の高い順**（同じなら攻撃力順・ポンの判断。火選りの名に合わせる）
- ターンギフトで得た手番は**粛に封じられない**（ターンを得ているのでターン外の行動ではない）
- 燃焼の軸は手数（割り込み）ではなく、**育てた火を叩き込む**。1ターン1手番の性格は保つ
- 3体の手番が毎ターン同じ絵にならないこと（第239期: 3体とも手番の種類と攻撃型が 100% 同じ・ヒヨは強化だけの絵が 86〜100%）

第241期で分かった追加の穴:

- **2ターン目に敵が燃えていない**（周回2の頭で 8体中 0.83体）。「2ターン目から一気に燃え広がる」が起きない
- **ボルグの火が消える**（中央で守られて殴られず、周回3で4戦に3戦消える）
- 加速（火勢2以上は +2）は入れない（ヒヨが 2 → 4 へ跳び、3で撃つか4まで待つかの判断が消える・R344）

大技（ホタの焼き尽くす・残り火、ボルグの放つ、余熱）は**次の期**。この期はその土台を入れる。

## 2. 入れるもの

### 2.1 火勢の土台

| 項目 | 内容 |
|---|---|
| 火勢 | 各駒に 0〜4。燃えていない駒は 0 |
| **保つ火** | 既存の着火すべて: 火勢0 なら 1 にして燃焼を始める。**1以上なら残りターンを戻すだけで火勢は上げない**（今の燃焼と同じ） |
| 消える | 燃焼が切れたら（残りターン 0）火勢 0 |
| **萎む** | ターンの終わりに、そのターン一度も育たなかった駒は −1（燃えている間は 1 未満にしない） |
| **燃え広がり** | **燃えている味方**の攻撃が、**当たる前から燃えていた敵**に当たると、その味方の火勢 +1。**1回の攻撃で同じ敵は1回まで**・当たった燃えていた敵の数だけ +1。本人の着火が点く前に判定 |
| 上限 | 4。4 の駒への育ちは捨てる（余熱は次の期） |

- 敵の火勢はこの期は持たない（敵は燃えているか・いないかだけ。今と同じ）
- 燃焼の刻み（6）・脆さ（+25%）・ヒヨの火の変換はこの期は火勢で変えない

### 2.2 ボルグ（2本）

| 札 | 内容 |
|---|---|
| **火の粉・広** | 火の粉（`Cinder`）の敵側の着火を、**薙ぎで当たった敵全員**に広げる（今は主目標だけ。隣の味方への着火はそのまま） |
| **火を保つ** | ボルグが攻撃した後、**自分にも火が点く**（保つ火・火勢は上げない） |

### 2.3 ホタの段

燃えている間のホタの型を、手番の時点の火勢で決める（燃えていないときは今と同じ素の単体攻撃）。

| 火勢 | 型 | 倍率 |
|---|---|---|
| 1 | 単体 | 攻撃力 ×4（今の熾火の倍率） |
| 2 | **貫き＋着火** | 貫きの経路の全員に ×4、当たった敵に着火 |
| 3 | **5連撃＋着火** | 同じ敵に 5 回、1回 ×1.6（合計 ×8）、1回ごとに着火（保つ火）。途中で倒れたら残りは次の敵へ（標的の選び方は通常どおり） |
| 4 | 3 と同じ（大技は次の期） | |

- 脆さは1回ごとに乗る。軛の上限も1回ごとに掛かる
- 燃え広がりは、5連撃でも**同じ敵は1回まで**

### 2.4 ヒヨ

| 項目 | 内容 |
|---|---|
| 手番 | 今の贔屓（燃えている味方 +4・隣の燃えていない味方 −2）は毎手番そのまま。**それに加えて**、下の「煽り」か「ターンギフト」のどちらか1つ |
| **煽り** | 燃えている味方（ヒヨ以外・火勢4 は除く）のうち**攻撃力が最も高い**1体の火勢 +1（同値は席の番号順） |
| **ヒヨ自身の火の育ち** | ヒヨが燃えている間、**煽るたびに自分も +1**、**味方が燃え広がりで育つたびに自分も +1** |
| **ターンギフト** | ヒヨの手番の時点で**ヒヨの火勢が3以上なら撃つ**（G3 即撃ち）。火勢3: 相手1体／火勢4: 相手2体。相手は**燃えている味方（ヒヨ以外）のうち火勢の高い順、同じなら攻撃力順、同じなら席の番号順**。撃ったらヒヨの火勢は 1 |
| ギフトの手番 | 相手はヒヨの手番の直後に、渡された順に**通常の手番を1回**行う（痺れ・まどろみ・`CanAct` は通常どおり問う。動けなければ空振り）。この手番は**ターン外の行動ではない**（粛に封じられない）。燃え広がりも通常どおり起きる |

- ヒヨが燃えていないときは火勢 0 なので、煽りだけをする（煽りで自分は育たない）
- ギフトの手番を渡された駒が同じターンの自分の手番をまだ迎えていなければ、自分の手番は別に来る

## 8. Codex 向けの演出メモ（報告に転記。この期は実装しない）

- ホタの段: 1 単体の一撃／2 炎の貫き／3 5連撃
- ベニの紅蓮は、隣の火勢に合わせて鮮やかになる
