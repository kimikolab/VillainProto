# 第222期 指示書 —— 移動軸の加速：シオに手番を・ヨミの割り込みを薙ぎに

置き場所: `design/PHASE222_DRIFT_SPEC.md`。報告は `design/PHASE222_DRIFT.md`。
**線は置かない**（採否はポンが遊んで決める）。

**前提**: カタの規定の札を S2 → S3（弾けた駒それぞれ50%で痺れる）へ差し替え済みであること（別作業で指示済み）。

## 0. 目的

ポンが移動改（バサ・ヨミ・シオ ＋ セロ・ガルド）で9体の検証波（敵 HP150%・攻115%）を遊んで分かったこと:

- ヨミは6ターンで攻61・与ダメ519まで育ったが、**育ち切る前の4ターン目にガルドが落ちた**（庇い12回・被108）
- 移動の供給源がほぼバサ1枚で、ヨミが動かされるのは1ターン1〜2回。**加速が足りない主因は供給の少なさ**
- 第221期の報告どおり、9体の波で崩れるのは「育つ軸」

そこで2つを足す:
1. **シオに手番を持たせる**: 傷ついた味方を下げ、元気な味方を前に出す＝**移動の供給＋守り**
2. **ヨミの割り込みを化けさせる**: 育つと攻撃が薙ぎになる＝**数に強くする**

逃亡兵セロの作り直し（回避アタッカー）は次の期（第223期）。

## 2. シオの手番

| 項目 | 内容 |
|---|---|
| 手番 | `Skill`「隊を組み替えた」: **最も傷ついた味方**（HP の割合が最も低い・同値は席番号の順）を、**後ろ側の隣の味方**と入れ替える。通常攻撃はしない |
| 後ろ側の隣 | 入れ替える相手は、その味方と隣接し、**より後ろの行**にいる生きている味方（複数なら席番号の順）。いなければ、次に傷ついた味方で探す。誰とも入れ替えられなければ何もしない |
| プラス | 動かされた味方を回復し、攻撃力を上げる（今と同じ。**入れ替えた2体とも**が対象） |
| マイナス | 元気な駒を前へ押し出すので、後列前提の駒や庇う駒の配置を崩すことがある／自分では攻撃しない |

- 入れ替えは既存の「隊列を動かされた」として扱う（ヨミの軋み・シオ自身の回復・ハネほか、移動を読む特性すべてが反応する）
- 前へ押し出された側は「前へ突き出された」扱い（ヨミなら +22）
- シオ自身が最も傷ついていれば、シオ自身を下げてよい
- 全員が満タンなら**何もしない**（無傷の味方を動かさない）

## 3. ヨミの薙ぎ

| 項目 | 内容 |
|---|---|
| プラス（追加） | **現在の攻撃力が閾値以上のとき、攻撃型が薙ぎになる**（割り込みも手番の攻撃も） |
| 閾値 | 版で決める（30 / 20） |

- 薙ぎの巻き込みは既存の表どおり（標的と同じ列の全員＋中央）
- 閾値を下回ったら（弱体で攻撃力が下がったら）単体に戻る

- **Q0-1 移動の供給**: V0 で、ヨミが動かされた回数と出どころ（バサ・ハネ・セロの逃亡・庇いほか）を1戦あたり・ターン別に。攻撃力が 20・30 に届くターンの分布

## 6. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** シオ・ヨミのいない行は 0 セル
- **P2** V1 でヨミが動かされる回数が増え、攻撃力 30 に届くターンが早まる
- **P3** V1 で最も傷ついた味方が後ろへ下がり、前衛の落ちるターンが遅れる。ただし庇う駒（ガルド）が下がると庇いが外れる代金が出る
- **P4** V2・V3 の薙ぎは9体の波で効き、5体の本編の波では小さい
