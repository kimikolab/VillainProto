## 0. いちばん中身のある結果

1. **移動の台では E1 のセロは「落ちない駒」になった——勝率より全員生存が動く。** S1（ポンの席）× 九/新兵 で
   **セロの倒れ 39.5% → 11.0%（115/115）／ 49.5% → 17.5%（150/115）**・全員生存 52.5 → 75.5 ／ 39.5 → 59.0%。勝率は ±3pt 以内（天井の近く）。
   与ダメは 91 → 138 ／ 95 → 167（1戦）で**同じ台の2位のまま**——1位のヨミ（386〜598）の 3〜4 分の1で、**「新基準のアタッカー」にはまだ届いていない**。
2. **代金のはずの入れ替えが、移動の台では資産になった**（R301 の再発）。E1 と E1−（入れ替えなし）を並べると、S1 × 九/新兵 で
   **セロの倒れ 19% → 11%・シオの倒れ 20% → 20%・全員生存 71.0 → 75.5%**、S2 × 150/115 × 第五波 で全員生存 87.0 → 92.5%。
   入れ替えのたびに**シオの移り木が動かされた2体を回復・強化し**（セロの攻撃力 T3 が E1− 20.2 → E1 21.4〜24.2）、段も早く上がる（S1 ポンの段2 到達 E1− 7.5〜20.2% → E1 19.0〜31.6%）。
3. **S4（`compare` のセロの12行）で下がったのは、入れ替えの代金ではなく外した旧札（臆病・後衛特化）だった**（R329）。
   S4 の平均は E1−E0 が **−1.5 ／ −6.8pt（本編 115 ／ 150）・−13.8 ／ −6.2pt（九/新兵）** で予測 P4 どおり下がったが、**E1−（代金なし）もほぼ同じだけ下がる**
   （+0.8 ／ −8.6・−13.5 ／ −6.4）。いちばん落ちた `後衛特化+後備え` は 150/115 × 本編で **86.4 → 39.5%（E1− 37.2%）**——あの行は「下がってから貫き2倍」のための行で、
   E1 には下がる札も2倍も無い。中央のセロはそのまま殴られ続け、**倒れる率 43% → 86%**。
4. **状態の矢（E2）は、味方がセロに毒か火を書く行でだけ働く。** S4 の `毒→被弾強化`（グザの瘴気の漏れ）で E2−E1 **+8.3 ／ +22.5pt**（本編 ／ 九・115）、
   `縛め非収入型`・`火選り代金型`（ボルグの火の粉）で +1〜+9pt、燃焼の矢で脆さの分が 1戦 +6〜+11。**指示書が E2 のために置いた S3（ベニ・ミオ・カタ）は第2〜3ターンで決着し**、
   セロが矢を撃つ回数そのものが少ない（感電の矢 0.33〜0.42 本/戦・敵の放電 +2〜4%）。

## 1. 実装

| 置き場所 | 中身 |
|---|---|
| `TraitId.Evade` / `EvadeTrait` | 回避（30%・段3 で 45%）・避けたら攻撃力 +3（`ModifyAttack`・私有キー）・追い撃ち・段（`OnMoved` で動かされた回数を数える・3 / 6 / 10）。判定の本体 `TryEvade` は engine の1箇所が呼ぶ |
| `TraitId.EvadeSwap` / `EvadeSwapTrait` | 回避の代金: 避けるたび隣の生きている味方1体（召喚枠を除く・乱数）と `SwapSlots(セロ, 相手の席, by: セロ)` |
| `TraitId.StatusArrow` / `StatusArrowTrait` | E2: `OnAfterAttack` でセロの毒（+2 層・`PoisonRoute.Arrow`）・燃焼（着火）・感電を矢が当たった敵へ。セロの状態は減らない |
| `BattleContext.ApplyDamageBody` の頭 | 回避の判定（札を読んで消した直後・逸らしより前）。条件は「出どころが相手陣営 かつ 刻み・徴収・中継・共有ではない」 |
| `PerformAttack` の枠（`_evadedNow`） | 主目標（貫きは先頭）が避けたら攻撃した側の `OnAfterAttack` を走らせない |
| `SelectTargetChain` の頭（`_forcedTarget`） | 追い撃ち・乱れ撃ちの的の固定（介入の鎖を通さない）。貫きなら的を通るレーン（`ForcedLane`・乱数なし） |
| `SwingTurn` の頭 | 段2 以上のセロの手番は乱れ撃ち（`Barrage`・5本・的は `Roll`） |
| `OutOfTurnRoute.Evade`（「追い撃ち」） | 追い撃ちは `CanActOutOfTurn` を通る（**粛の窓口の 10 本目**）。避けることと入れ替えは通らない |
| `PoisonRoute.Arrow` | `SoakRouteCount` 13 → **14**・燃焼の添字 12 → **13** |
| 台本（表示専用） | `Evade`（誰の攻撃を・入れ替わる相手 `PartnerId`・避けた量・段・避けた後の攻撃力）→ 2体の `Move` → `EvadeRiposte`（単体か貫き・何本目）→ その矢の `Attack`（`Reaction`）／ `EvadeStage`（新しい段・動かされた回数）／ `Barrage`（何本目・的）／ `StatusArrow`（付けた状態の名前）→ `StatusGain` |
| 計数（どれも読まない） | `UnitTally.Ev*`・`Arrow*`・`BattleContext.CurrentMover`（`SwapSlots` の中で動かしている駒） |

**決めたこと（指示書に無かった）**:
- 回避した一撃では**攻撃した側の `OnAfterAttack` も走らせない**（毒撃・傷・標・鞭の怖気づきがセロに乗らない）。
- **反撃の中で避けたときは撃ち返さない**（`Reaction` の再入禁止をそのまま使う）。粛・痺れ・組み付きで撃てない回避も入れ替えと攻撃力 +3 は起きる。
- 追い撃ちは**標的の鎖（庇い・後備え・標・執着）を通さない**（撃ち返す相手は決まっている）。的を通るレーンが2本（中央）なら生きている駒の多い方・同数は添字の若い方。
- 入れ替えの相手に**召喚枠の味方（胞子・餌）を入れない**（シオの組み替え・ヒサの逃げと同じ）。据えた足（バン）なら空振り（`SwapSlots` の入口）。
- 攻撃力の上乗せは `AtkBonus` ではなく私有キー＋`ModifyAttack`（弱体でも強化の横取りでも減らない・「戦のあいだ下がらない」）。会戦の境界で段と上乗せは 0 に戻す。
- 雷（カタ）の一撃を避けても、雷の後の感電はそのまま付く（`StrikeThunder` の最後が `MarkShock` を呼ぶ・直していない）。

## 予測（実装の前に書いた）

- **P1** セロのいない行は 0 セル。E0 は前段の盤面と台本が一致（`shockdigest e223` の全行一致）。
- **P2** E1 のセロの与ダメは **S1・S2 で5枚中1〜2位**（ヨミと並ぶ）。**S3 ではカタより下**（雷が1戦 100 を超えるため）。
  段は育ちきらない: **S1 × 150/115 で段2（乱れ撃ち）に届く戦は 20〜45%、段3 は 10% 未満**。9体の波では回避の回数が本編より多い（+20% 前後）が、段の到達はほぼ変わらない（外からの移動は9体の波のほうが少ない）。
- **P3** S1 でヨミが動かされる回数は E0 比 **+0.3〜+0.6 回/戦**（回避 0.8 回 × ヨミが隣の2枚の1枚）。
- **P4** S4 の12行の平均は **E1 < E0**（ガルドの隣の8行が主に下がる・後衛特化の貫き2倍も消える）。移動軸の2行（隊列崩し・移動改）だけは E1 ≥ E0。
- **P5** E2 × S3 で、カタの隣のセロは感電を撃ち続け、**敵の連鎖の回数が E1 比で増える**（+20% 以上）。燃焼の矢はベニの隣のときだけ乗り、F1 の脆さで次の矢が伸びる（1戦 +5〜+20 程度・小さい）。
- **P6** セロが倒れる原因は **S3 では状態異常のダメージが過半、S1・S2 では攻撃が過半**（S1・S2 には味方の状態の書き手がいない・敵の毒の書き手も少ない）——指示書の「状態異常が主」は S3 だけで当たると読む。
