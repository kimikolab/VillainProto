## 1. なぜこれをやるか

第12期で3つ分かった。

- **地力は単一の量ではない。** 最良の単相関 r=0.64（r²=0.41）、2変数でも 0.48。総HP は9位（0.25）
- **静的だけでは 0.35 / 0.16 しか説明できない。** 編成した時点では結果が決まっていない
- **台を替えると突破度の相関が 0.69 / 0.74 に落ちる。** 第4〜11期の壁（0.83〜1.00）は「同じ軸の変種を比べていた」ことの結果だった可能性がある

ただし**2つの判断が保留になっている。**

**(A) 毒軸の残差と閾値仮説の検定が、測定の穴に乗っている。** `TickStatuses` が `ApplyDamage(u, poison, null)` と source を渡さないので、毒軸の与ダメ・干渉・撃破が構造的に過小。「与ダメ効率 = 与ダメ ÷ 撃破数」は**分子と分母が同時に過小になる**ので、閾値仮説の検定として使った指標がいちばん壊れていた。

**(B) 台をまたぐ入れ替わり（ρ=0.74）が構造的なのか、単なるノイズなのか分からない。** ここが構造的なら、10期分の方向転換になる。

**この作業は (A) を潰してから (B) を判定する。**

## 3. Phase DA — 受け手側から測り直す

### 3-1. 方針

**毒の出どころを記録しない。編成単位で足りる**（ポン氏の判断。「部隊で協力して撒いて拡散して濃くする」がコンセプトなので、駒単位の帰属は粒度として細かすぎる）。

そして**帰属せずに済む方法がある**——敵側の tally を読む。

| 特徴量 | 従来（味方側・穴あり） | 今回（敵側・穴なし） |
|---|---|---|
| 与ダメ/戦 | 味方の `DamageToEnemy` 合計 | **敵全員の `DamageTaken` 合計 − 敵の `TakenFromAlly` 合計** |
| 撃破/戦 | 味方の `Kills` 合計 | **敵の死亡数**（誰が仕留めたかを問わない） |

毒・燃焼・破裂・反射、どの経路で削っても敵の `DamageTaken` には必ず載る。**`BattleCore` の変更が要らない。**

`TakenFromAlly` を引くのは、敵同士の巻き込み（ある場合）を編成の手柄にしないため。**引いた量が常に 0 なら、その旨を報告する**（敵側に巻き込みが無いことの確認になる）。

### 3-2. 過剰殺傷の扱い

`DamageTaken` は**振り切った量**を数える（第9期 `bill` の残差分析で確認済み。HP は 0 で止まるが tally は超過分も数える）。

**これは今回の目的には都合が良い。** 「与ダメ効率 = 与ダメ ÷ 撃破数」はオーバーキルの指標なので、**過剰分が入っているほうが正しい**。ただし**そういう定義であることを明記する**（第12期の味方側 `DamageToEnemy` も同じ性質かどうか確認し、違うなら値が変わる理由として報告する）。

### 3-3. やり直すこと

第12期 Phase CB と**同じ手順を、同じ計算方法で**やり直す。変えるのは与ダメ・撃破の出どころだけ。

1. 単相関の全一覧（15特徴量）。**第12期の値と並べて、どれがどれだけ動いたかを出す**
2. 第一近似とその r / r²
3. 残差と、残差の上位・下位5編成
4. 静的だけの説明力
5. **与ダメ効率の位置と符号** — 閾値仮説の検定をやり直す

**第12期で「毒軸の残差は測定の穴」と書いた部分が、実際に消えるか**が最大の確認点。消えなければ、穴は説明の一部でしかなかったことになる。

### 3-4. 受け入れ条件

- 18モードすべての差分 **ゼロ**（`BattleCore` を触らないので当然。**動いたら触っている**）
- 第12期の値との対比表
- 敵側の `TakenFromAlly` の合計値（0 かどうか）

## 4. Phase DB — 入れ替わりは構造的か

### 4-1. 問題

第12期の台間相関 ρ=0.74 は、**そもそもどれくらいなら「動いた」と言えるのか**の基準が無い。乱数のばらつきだけでも相関は 1.00 未満になる。

### 4-2. ノイズ上限を測る（これが要点）

**同じ台を seed で半分に割り、前半と後半で突破度の相関を取る。** これが「同じ条件を2回測ったときの一致度」＝**測定の信頼性の上限**。

- 半割の相関が 0.98 で、台間が 0.74 → **入れ替わりは本物**
- 半割の相関が 0.75 程度 → **台間の 0.74 はノイズと区別できない**。10期分の壁の解釈は変わらない

seed 200 を 100 + 100 に割る。**割り方（前半後半 / 偶奇）を明記する。**

### 4-3. 何が入れ替わりを生んでいるか

主の台（チャージ台・3波）と従（既存5波）は、**長さと構成の両方が違う**ので交絡している。**1つずつ振った台を作って切り分ける。**

**注意**: 第10期のチャージは master にマージ済みなので、**既存5波も詠唱兵・狙撃手が溜める世界**になっている。つまり主と従の差は「チャージの有無」ではない。

| 台 | 長さ | 構成 | 目的 |
|---|--:|---|---|
| T1 | 3 | 主の台そのまま | 基準 |
| T2 | 5 | 既存5波 | 基準（従） |
| T3 | 3 | 既存5波の先頭3つ | **T2 と構成が同じで長さだけ違う** |
| T4 | 5 | 主の台 + 既存の第4・5波 | **T1 と長さだけ違う** |

台は**診断のローカルで組む**（`EnemyCatalog.Columns` に足さない。第5期以来の方針）。

すべての組み合わせで突破度の相関を取り、**長さ由来の入れ替わりと構成由来の入れ替わりを分ける。**

### 4-4. 入れ替わりが構造的なら、何で予測できるか

台間で順位が動いた量（順位差）を、`power` の特徴量で説明できるか見る。**「どの編成がどの台で上がるか」が特徴量で予測できるなら、それが配分判断の素**になる。

n=31 なので、**単相関の一覧までにとどめる**（第12期と同じ方針。多変量は2変数まで）。

### 4-5. 判定

| 観測 | 結論 |
|---|---|
| 半割 ≫ 台間 で、入れ替わりが特徴量で予測できる | **配分判断の素が見つかった。** 「性格の違う列を複数用意し、どれにどの編成を当てるか」で成立する。次はその設計 |
| 半割 ≫ 台間 だが、入れ替わりが何とも相関しない | 入れ替わりは実在するが**予測できない**。プレイヤーには「試すしかない」ものになる。設計に使えるかは別途判断 |
| 半割 ≈ 台間 | **入れ替わりはノイズ。** 10期分の壁の解釈は変わらない。第12期 (5) の記述を訂正する |
| 長さと構成のどちらか一方だけが効く | どちらが効いたかを明示。**列の設計で何を振るべきかが決まる** |

### 4-6. 受け入れ条件

- 18モード差分ゼロ
- 半割の計算方法（割り方・相関の種類）を明記
- T1〜T4 の全組み合わせの相関行列

## 5. Phase DC — 記録と報告

### 5.1 README に書くこと

- **受け手側から測る、という測定手法**。毒・燃焼のように帰属を持たない削りがある以上、**編成単位の出力は受け手側から取るのが正しい**。今後の計測すべてに効くので独立した項で
- 第12期の分解のやり直し結果。**毒軸の残差が消えたか**、閾値仮説の検定はどうなったか
- **半割の相関（測定の信頼性の上限）**。これも今後の計測すべてに効く基礎値
- 台間の入れ替わりの判定（§4-5 のどの行か）。**ノイズだった場合は第12期 (5) の記述を訂正する**
- 長さ由来か構成由来か

### 5.2 「未解決の課題」

- **毒・燃焼の帰属**は「駒単位では諦め、編成単位で受け手側から測る」で解決。**解決済みへ移す**。ただし `docs/pulse.md` の毒軸の行は依然として過小のままなので、**`pulse` を読むときの注意として残す**
- 既存の課題はそのまま残す

### 5.3 報告してほしいこと

1. **第12期との対比。** 単相関の順位がどう動いたか、第一近似は変わったか
2. **毒軸の残差は消えたか。** 消えなければ、穴以外に何があるか
3. **与ダメ効率の位置と符号。** 閾値仮説は支持されたか（**今度は歪んでいない指標での検定**）
4. **半割の相関はいくつか。** 台間の 0.74 はノイズと区別できるか
5. **長さと構成のどちらが入れ替わりを生んでいるか。** 入れ替わりは特徴量で予測できるか
