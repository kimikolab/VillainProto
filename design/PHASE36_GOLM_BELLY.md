# 第36期 ゴルムの「まどろみ」と「還し」 —— 腹という通貨

指示書: `PHASE36_GOLM_BELLY_SPEC.md`（第35期 e8f04d9 以降 / `master`）

飲み込んだ量を **腹** という1つのカウンターにし、そこから2つの出口を作る。

- **まどろみ**: 腹が閾値に達すると次の手番を失う（`IdleTurn`）。号令・据えの既存経済圏へ売れる即時通貨への変換
- **還し**: ゴルムが倒れたとき、腹の残りの一部を生存味方へ回復として分配（1戦1回）

判定は勝率目標ではなく「機構が発火し、新しい相互作用が観測されるか」。壊れ検知にだけ数値基準を置く。

眠るには手番が回ってくる必要があるため。

### 導出 1: まどろみ閾値 **N = 60**（`ColossusTrait.SlumberThreshold`）

要件は「壁需要の高い行で1戦に1〜2回眠る／毎ターン眠るのは過剰／1度も眠らないのは死文」。
飲み込みの多い上位5行で比べると

| N | 上位5行の眠り回数 | 上位5行での「眠るターンの割合」 |
|--:|---|---|
| 40 | 1.32 〜 2.23（平均 1.91） | 28% 〜 **94%** |
| **60** | **1.09 〜 1.49（平均 1.26）** | 17% 〜 78% |
| 80 | 0.72 〜 1.05 | 12% 〜 62% |

- N=40 は上位行が帯の上端に張り付き、惨禍×死の連鎖では**生存Tの 94%**＝実質毎ターン眠る
- N=80 は上位5行のうち4行が 1.0 を割り、「1〜2回」に届かない
- **N=60 なら上位5行がちょうど 1.0〜1.5 回**に収まり、全18行の総平均でも
  1.28 回 / 生存T 5.2 ＝ ゴルムが手番の **約25%** を失う

**掃引はしていない**（指示書の明示的な禁止）。上の表は1つの実測分布から算術で引いた予測で、
盤面を1度も動かしていない。

### 導出 2: 還し率 **25%**（`ColossusTrait.RefundPercent`）

要件は「腹の残り × 率が『ノノの繕い1〜2回ぶん』程度の回復量」。`MenderTrait.Amount = 14` なので
狙いは **14〜28 点**。ゴルムが落ちた戦の腹は平均 **81**（中央値 76）なので

    81 × 25% ≒ 20 点 ＝ 繕い 1.4 回ぶん

17% で下端 14、35% で上端 28。**25% は帯のちょうど中央**。

**総量を分配する**（1体あたりに配るのではない）。生存味方の頭数で割るので、
編成の体数で回復総量が変わらない。指示書の「1〜2回ぶん」は総量の話と読んだ。

## Phase 0-2: 監査

| # | 確かめたこと | 結果 |
|--:|---|---|
| 1 | 腹に数えるのは肩代わり吸収のみか | **可。同じ場所で数えられる。** `BattleContext.ApplyDamage` の巨躯の分岐、`amount -= blocked` の直後に1行足すだけ（吐き戻しが `blocked` を使う場所と同一）。**大喰らい（`DrainTrait.OnTurnStart`）は構造的に混ざらない**——あちらは `ctx.ApplyDamage(ally, draw, self)` で **source がゴルム自身**、壁の候補は `u != source` で自分を外すので、ゴルムが自分の吸いを肩代わりすることはありえない。腹は「殴られた誰かを庇ったとき」にだけ増える |
| 2 | 味方側の `IdleTurn` を読む／売れるのは誰か | **買い手は2枚だけ。** ①**号令（ガン・`RallyTrait.OnTurnStart`）**: `idle == ctx.Turn - 1` かつ `Trait.SurrenderedTurn` の味方へ 攻撃 +8（`SupportTargets` 経由）。②**据え（バン・`ApplyDamage` の中）**: `IdleTurn >= Turn` かつ `SurrenderedTurn` の味方の被ダメージ −50%。③**責め苦（シガ・`TormentTrait.OnAfterAttack`）は買い手ではない**——読むのは **攻撃対象＝敵側**の `IdleTurn` で、味方のまどろみは1点も売れない。④**縛め（クグ・`BindTrait`）も買い手ではない**——`Stun` を**供給**する側（`IdleTurn` は engine が痺れの分岐で立てる） |
| 2b | まどろみは `SurrenderedTurn` を通るか | **通る。** `SurrenderedTurn` は「`CanAct` が false を返した特性のうち `SurrendersTurn == false` のものがあるか」で判定する。まどろみを **engine 側で `SetCounter(IdleTurn, turn)` して `continue`**（痺れと同じ形）にすれば `CanAct` を1つも false にしないので、判定は無条件に true になる。**`CanAct` のオーバーライドで実装してはいけない**——不動（カド）と同じ扱いになって号令・据えが買わなくなる |
| 3 | まどろみの意味論（壁機能は止まらないか） | **止まらない。** `OnTurnStart` は行動順ループの**外側**（`BattleEngine.Run` のターン頭）で全生存駒に回るので、大喰らいの吸いは眠っていても走る。肩代わり・吐き戻しは `ApplyDamage` の中なので手番と無関係。**眠りが壁機能を止めると自滅ループになる**という指示書の懸念は、既存の構造のまま自然に避けられる |
| 4 | 還しの経路（`ctx.Heal`） | **渇き（第三波）で封じられる**——`BattleContext.Heal` の入口で `TraitId.Drought` の保持者が生きていれば即 return（意図どおり）。**ガルドの `Stoic` も弾く**——`Heal` は `AcceptsSupport`（`!Traits.Any(t => t.BlocksSupport)`）を見るので、ガルドを含む行では還しのガルドの取り分が**構造的に消える**（`SupportTargets` を通さないので隣へも漏れない。吐き戻しとはここが違う）。**ウツ（逆しま）は無風**——`PerverseTrait` は `ModifyAttack` しか持たず `AtkBonus` しか読まないので、回復は素通りする（第23期の吐き戻しが逆しま3行を落としたのと**逆**） |
| 5 | 1戦1回の担保 | **腹を空にするだけでは足りない**（蘇生で戻った後に飲み込み直せば再発火する）。`ColossusTrait.RefundSpentKey` を別に立て、`OnDeath` の先頭で見る。腹・使用済み印はどちらも `ColossusTrait.OnCarryOver` で部隊戦の境界に捨てる（`StatusKeys.All` の一律掃除には載らないため）。**`InstanceId` は持たない**ので、ノミの執着（第30期）が踏んだ「前の戦闘の番号が次の戦闘の別人に当たる」問題は起きない |
| 6 | `TraitId` の置き場 | **新しい `TraitId` は切らない。腹・まどろみ・還しはすべて `ColossusTrait` / `ColossusRule` に置く。** 理由は2つ。(a) 3つとも**巨躯が飲み込んだ量**という1つの資源の出入口で、保持者も発火条件も巨躯と完全に一致する——`TraitId` を分けても付け替えができない（第35期に殉教を分けたのは「割合をガルドと別々に振りたい」という**分ける動機**があったからで、ここには無い）。(b) engine が書いて特性が読むカウンタは `RedirectGainTrait.PendingKey` / `ThornGuardTrait.PendingKey` が既に同じ形をしており、`StatusKeys` に載せるより**定義が1箇所に集まる**（`StatusKeys` は会戦の一律掃除の一覧を兼ねるので、そこへ入れると寿命規則が2箇所に分かれる） |

## Phase 0-3: 試験台（`腹×号令 (ゴルム×ガン×バン)`）

> **この行は Phase 4（採用手順）で `compare` から削除した。** まどろみの測定装置として
> 建てた行で、まどろみの棄却で目的を失ったため。以下は建てたときの記録。

    front1: ゴルム / front3: ムグ / center: バン / back1: ガン / back3: ドルガ

- 買い手を**両方**載せた唯一の行（号令＝ガン・据え＝バン）。ゴルムは前1でバン・ガン・ドルガを被覆する

### 配置は一度やり直した —— **買い手が生き残らない台では「売れるか」が測れない**

最初は `reseat` 6位（ガン 前3 / ムグ 後1・79.2%）を採った。理由は中間帯が3波
（87.5 / 71.0 / 37.5）残り、1位の 81.4% は第3波が 96.5% で中間帯が2波に減るからで、
「探索1位と狙いが食い違ったら狙いを優先」に沿った判断のつもりだった。

**Phase 3 でこの台がまどろみの売却を1件も観測できないことが分かった**（下記）。
原因は配置で、**ガンが前3＝ゴルムの被覆の外**にいる。号令の払いは編成全体で
**0.09 回/戦**しか出ておらず、ガンが早々に落ちていた。

`reseat` 1位（ガン 後1＝被覆の中）へ移すと:

| 配置 | 号令の払い（全体） | まどろみの換金率 | 全波平均 | 中間帯 |
|---|--:|--:|--:|--:|
| 6位（ガン 前3） | 0.09 回/戦 | **0%** | 79.2% | 3波 |
| **1位（ガン 後1・採用）** | **1.78 回/戦** | **67%** | 81.4% | 2波 |

**中間帯を1つ失うより、機構が1件も観測できないほうが致命的**なので、1位を採った。
`ablate` は入れ得を弾けるが、**買い手が生き残るかは弾けない**——測る対象が
「勝率」ではなく「機構の発火」であるときは、台の検査項目がもう1つ要る。

## Phase 1: 予測（実装前に固定）

版構成 —— **V0 現行 ／ V2 まどろみのみ ／ V3 還しのみ ／ V4 両方**。腹は共有カウンターで、
V4 では眠りが腹を N ずつ消費し、還しは残りを返す。

### 機構の非対称性（予測の土台）

1. **まどろみは、買い手のいない行では純粋な損。** ゴルムの素の攻撃は 10・速さ3・単体で、
   1戦あたり 1.28 回眠る＝およそ **12 点の与ダメが消えるだけ**。大喰らいの吸い（自傷）は
   `OnTurnStart` なので**眠っても止まらない**ので、代金だけが残る。
   **買い手を持つゴルム行は 18 行中 2 行しかない**——`追撃×据え (ハギ×バン)`（据えのみ）と
   `腹×号令`（号令＋据え）。残る 16 行では、まどろみは売り先の無い在庫になる。
2. **据えの買い取りは薄いはず。** 据えは `IdleTurn >= Turn` を見る＝**そのターンの中だけ**
   有効で、ゴルムは速さ3＝ほぼ最後に動く。眠りが立つ頃には、そのターンの敵の攻撃は
   ほとんど済んでいる。**号令（次のターンに 攻撃+8）のほうが取りこぼしが少ない。**
3. **還しは代金を持たない。** 発火するのはゴルムが倒れた瞬間で、そこから先ゴルムは何もしない
   ので、失うものが無い。したがって **V3 は全行が「上がるか不動」**。下がる行があれば、
   それは還しが**敵に有利な蘇生順序**（墓守の層・胞子）を触った副作用で、探すべき異常。
4. **V4 は V2 と V3 の単純な和にならない。** 眠るほど腹が減るので、還しの原資が痩せる。
   **眠りやすい行ほど V4 < V2 + V3**。

## 判定（Phase 3-5 への回答）

> **この判定はそのまま採用された（Phase 4）。** V3 を既定に昇格し、まどろみは対照として残置。

### **V4 の昇格は薦めない。V3（還しのみ）を薦める。**

- **還し（V3）は目的を果たしている。** 機構は発火し（発火率がゴルムの死亡率をそのまま追う）、
  **新しい相互作用が3つ観測できた** ——(a) 渇きが実際に課税する（第三波だけ発火最多・到達最少、
  17/18行が ±0.0、例外は祭司を先に倒した戦）、(b) ガルドの `Stoic` が取り分を食う、
  (c) 蘇生と組んでも1戦1回に収まる。逆しま軸を落とさないのも第23期の吐き戻しとの良い対照。
  壊れ検知は3つとも余裕がある（+2.5pt / 全波100%は不変 / 回帰0件）
- **まどろみ（V2）は薦めない。** 発火はするが売れない。理由は3段構えで、どれも
  係数では直せない:
  1. 買い手が2枚（号令・据え）しかなく、**そのうち据えは構造的に買えない**
     （ゴルムが遅すぎて、`IdleTurn >= Turn` の窓が実質閉じている）
  2. 号令は買えるが、**買い手がゴルムの被覆の中にいるという配置条件**が要る
  3. 売れても払い先がゴルム自身（`SupportTargets`）＝ **攻撃10の壁に +8**。
     代金（手番の25%・与ダメ 51→40）に届かない
- **V4 は V3 の劣化版**（18行中15行で V3 を下回る）。腹を眠りが食う経済は成立しているが、
  片側の値段がほぼゼロなので、プレイヤーには選択ではなく目減りとして見える

**もし採る場合の最小の形**は「`ColossusRule.Default` を `Refund: true` にするだけ」で、
まどろみは規則としてコードに残るが既定では不活性になる（第32期の逆位と同じ扱い）。

### まどろみを生かすなら（別期の材料）

- **払い先をゴルム自身から外す。** 号令の +8 が「守った相手」へ行けば、吐き戻し（第23期）と
