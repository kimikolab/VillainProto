置き場所: `design/CODEX_BRIEF_HUSH_SHATTER.md`。`design/CODEX_BRIEF_HISA_COMMAND.md` の追補。
触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。**台本の細部は `design/PHASE291_CODEX_MEMO.md`（§12 以降）を正とする。** このメモは「何をどう見せたいか」の意図。

## 0. 着手の順番

1. 粛の沈黙とひび
2. 砕ける瞬間（伝令の「報い」）
3. 止まっていた割り込みが一気に戻る
4. 騎士の斬り返し

確認は本編 第2波（巡礼騎士団）× 試遊・標 ボス台 ／ 標経済 ／ 三人組。

## 1. 粛の沈黙とひび ——「黙れ」

### 何が起きるか（第306期の規定）
- 粛の伝令が生きている間、**両陣営のターン外の行動**（仇討ち・羽・ヒサの声・庇い・騎士の斬り返し…）が止まる
- **止めるたびに、沈黙に「ひび」が1本入る**。15 本で砕ける
- 止められるのは味方の割り込みだけでなく、**巡礼騎士の斬り返し**も（騎士を殴るほど、ひびが入る）

### 欲しい絵
- 戦場全体にうっすら沈黙の膜（色が少し褪せる・音がこもる）
- 伝令の頭上か法具（鐘・聖印など）に**ひびのゲージ**。止めるたびに亀裂が1本走り、残りが読める（15 本）
- 止めた瞬間: 動こうとした駒に小さな「封」の印（既存の `Sealed`「粛」）→ そこから伝令の法具へ亀裂が1本伸びる
- 騎士の斬り返しが止められたとき: 騎士が剣を振り上げかけて**固まる**（怒りを封じられる）→ 亀裂

## 2. 砕ける瞬間 ——「報い」

### 何が起きるか
- 15 本目のひびで沈黙が砕ける（`HushState`「砕けた」）。伝令は生きたまま残る（ただの駒になる）

### 欲しい絵（ポンの決め）
- 法具が割れ、**鎧も法衣もろとも砕け散る**。伝令は**下着姿で真っ赤になってうずくまり、悲鳴を上げる**
- 皮肉: 沈黙を説いて回っていた伝令が、**戦場でいちばん大きな悲鳴を上げる**（「黙れ」と言っていた本人が、真っ先に黙れなくなる）
- トーンはコミカル（恥じらい・涙目・体を隠す）。それ以上の露出はしない
- 立ち絵は「通常」と「砕けた後」の2枚（アセットはポン側で用意）。砕けた後はその戦の間ずっと砕けた立ち絵のまま
- 戦場の沈黙の膜が一気に晴れる（色と音が戻る）

## 3. 止まっていた割り込みが一気に戻る

- 砕けた直後に、止められていた側の割り込みが**なだれ込む**（ザンの仇討ち → ヒサの叫び → ミサの羽…）
- 溜めていたものが解放される感じで、砕けた直後の数手は少しテンポを上げる、あるいは連続で畳みかける見せ方
- ヒサが「黙る」から声を取り戻す絵（吹き出しの「…」が、いつもの叫びに戻る）

## 4. 騎士の斬り返し

### 何が起きるか
- 巡礼騎士が攻撃を受けて生き残ると、**攻撃してきた駒へ斬り返す**（攻撃力の半分・1ターンに1回）
- 粛の下では止まる（§1 の「固まる」）。**砕けた後に解き放たれる**——砕いた瞬間に勝ちではなく、騎士の怒りが返ってくる

### 欲しい絵
- 受けた直後の短い反撃（剣の段の斬り返しに近い・単体）
- 砕けた後の最初の斬り返しは少し強調（「溜めていた怒り」）

## 5. 確認のしかた

- 本編 第2波 × 試遊・標 ボス台 ／ 標経済 ／ 三人組（台・seed は第306期報告と `PHASE291_CODEX_MEMO.md` §12 を見る）
- 2倍速で音が団子になる場合は、同じ瞬間の同じ種類の音をまとめて1発にしてよい（ひびの音は特に）

## 注記（第306期・Claude Code が実装と突き合わせて足した。本文は書き換えていない）

- **騎士の斬り返しのひびは、騎士1体につき1ターンに1本まで**（止められた機会もそのターンの1回を使う）。騎士を何度殴っても、1ターンに入る騎士のひびは最大2本。
- **ひびは開戦の瞬間（T0）から入りうる**（試遊・標 ボス台 seed 0 ではミサの開戦時の羽が止められて1本目）。ゲージは戦の頭から表示しておくのがよい。
- **砕けた後、伝令がすぐ倒れる戦が多い**。規定の第2波 × seed 0..49 で、ボス台は砕けるのが平均 T2.0・伝令が倒れるのが平均 T2.4（80% の戦で倒れる）、循環は T1.5 → T2.1。砕けた直後に戻った仇討ち ／ 羽が伝令にも当たるため。「砕けた後の立ち絵」が見える時間は数手しか無いことが多い——砕けた瞬間の絵（§2）に重みを置くのがよい。
- 台本の例（§5 の確認）は `design/PHASE291_CODEX_MEMO.md` §13（試遊・標 ボス台 seed 0 で、ひび 1〜15 → 砕けた → 仇討ち ／ 叫び ／ 羽 → 騎士の斬り返し が1本に揃う）。
