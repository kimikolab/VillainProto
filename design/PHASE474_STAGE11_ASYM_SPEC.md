## 1. 盤（1 章だけ・`ChapterRule.V474`・新しい `MapGraph`）

```
              北1 ─── 北2
             ／          ＼
   辺境の砦                 討伐隊の本陣
             ＼            ／
      南1 ── 南2 ── 南3 ── 南4
```

| | 北の道（山越えの近道） | 南の道（森と湿地の回り道） |
|---|---|---|
| 長さ | **2 マス** | **4 マス** |
| 敵 | 北1 物見の兵（軽い）→ 北2 **硬い部隊 1 つ**（盾の列の系統・手数が要る） | 南1 徴募兵（軽い）→ 南3 騎士の小隊（軽い・攻撃寄り）。南2・南4 は空 |
| 性格 | 早いが、主力の 5 枚でないと抜けない | 遅いが、小さい隊でも進める |
| 湧き | 敵の本陣から湧いた部隊は**近い北から先に来る**（拠点まで 3 歩） | 南は 5 歩かかる |

- 道の長さが違う盤は 1-3 の `MapGraph` と同じ作りで建てる。`Map11.RoadCells` の定数に頼っている所があれば、1 章の 1-1 だけ新しい盤を指すようにする（単発の 1-1 は触らない）
- 横の辺・中間拠点・門は**足さない**（1-2・1-3 で出す）。倍率 ×0.6・湧きの間隔・金・始めの 6 枚・呼べる駒は今のまま
- 教えたいこと: 「主力で近道を割るか、2 隊に分けて南からも押すか」「近道を空けると敵も近道で来る」

### ポンに渡す前に `--foe-weight` で帯に入れる（始めの 6 枚から・全員☆1）

| 場所 | 5 枚の隊 | 3 枚の隊 |
|---|---|---|
| 北1・南1（先頭） | 20／20・HP 85% 以上 | 18／20 以上 |
| **北2（硬い）** | **20／20・終わりの HP 55〜75%・決着 6 ターン以上** | **8／20 以下**（小さい隊では抜けない） |
| 南3 | 20／20・HP 80% 以上 | 15／20 以上 |
| 湧き（徴募兵・傭兵崩れ） | 20／20 | 15／20 以上 |

- 北2 は盾の列をそのまま置いて測り、帯に入らなければ今ある雑兵の部隊（`EnemyCatalog.MapSquads`・波ルールなし）から硬い順に替えて測り直す。それでも入らなければ、**北2 だけに掛ける倍率**（マスごとの倍率の口）を足してよい（足したら報告に書く）
- 第472期の報告のとおり、道具に「決着のターン」を出す列が無ければ足す
- 1-1 の全体: 器具の通しで、北だけ・南だけ・2 隊に分けるの 3 通りがどれも制圧まで届くこと（作戦ターンの数を並べて報告。**どれか 1 つが常に最短で無傷なら、盤が単純なまま**なので報告して止まる）

## 3. 3D の見た目（土台はポンが 3 本を触って決めた枝・報告 `design/MAP3D_STAGE11_COMPARE.md` §8）

盤が決まってから地形を置き直す。**§1 の門と `--foe-weight` が通るまで、地形には手を付けない。**

地形（新しい盤の位置の表）:
- 北: 砦から山すそを上がり、峠を越えて本陣へ。道は短くまっすぐ。北2 は峠の関（柵や盾の並ぶ狭い所に見えるように）
- 南: 森を抜け、湿地を回り、川を渡って本陣の裏へ。道は長く曲がる
- 上下で対称に見えないこと（川は斜めに・山は北に寄せる・森は南に寄せる）

直し（どの枝を土台にしても）:
1. カメラを引いて、盤の全体を 1 画面に入れる（Astra 版の構図を手本に）
2. 色を落ち着かせる（Astra 版の青灰と苔色を手本に。夕暮れは残す）
3. 「あと n」は**選んだ隊が行ける先だけ**に出す。マスの名前は常に出さない（選んだ時・重ねた時）
4. 道の上の木を減らし、道筋が切れずに見えるようにする
5. 隊の札は**使える隊だけ**出す（まだ開けていない第3隊・第4隊は小さなボタン 1 つに畳む）。下の UI は画面の 15% 以内
6. 題字から「敵 ×0.6」を外す（検証の層 F3 へ）
7. 名札が台・橋・旗と重ならないこと（3D 用のレイアウトの検査を 1 本足す）

Astra 版・Sol 版から部品を移すときは手で移す（枝どうしはマージしない）。master へ入れる前に、今の画面のファイルへの分岐の差分を報告に並べる。
