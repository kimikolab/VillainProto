## 0. 出発点

第7期で**代金の向きは両端そろった**。第1波 +8.7pt（範囲に安い）/ 第3波 −8.4pt（範囲に高い）。原理も1本に繋がった。

- **符号を決めるのは個体HP（対 味方の打点）** — 撒いた分が撃破に変換されるか。+8.7(16) → +5.8(32) → +1.8(60) → −2.5(90) の単調な軸
- **大きさを決めるのは体数** — 体数は符号を作らず**増幅する**。2体では範囲は単体と同じ挙動になるだけ
- **1体あたり攻撃は代金の水準を決める** — 高すぎると勝率0%の編成が出て打ち切りバイアスがかかる

ところが **Phase S の橋は架からなかった**。反転列と平坦列で編成の順位はほとんど動かず（同値塊を除いた値の相関 0.78、難度をそろえた対照では 0.89）、期待突破数の変化は範囲持ち −0.031 対 単体のみ −0.102 波。代金で ±8pt 開いたものが、結果では 1波の 0.4〜7% にしかならない。

Claude Code は「期待突破数に分解能が無い」（31編成中 17〜21 がちょうど 2.00 に張り付く）までを測定から言い、その先を **「8pt が足りないのか、指標が悪いのか」の2択**として未解決に残した。**この作業はその2択を decidable にする。**

### なぜ全員 2.00 に張り付くのか

推奨列の代金は 27 + 41 + 68 = 136%。部隊の容量は約 100%。**波1と波2を払った時点で残りは約 32% で、波3の 68% にはどう転んでも届かない。** ここで代金が 8pt 動いても 32% が 40% になるだけで、閾値（68%）を越えない。

つまり張り付きは指標の粗さだけでなく、**列の設計が「誰にとっても波3が買えない」形になっている**ことの帰結でもある。向きが結果に出るのは、**その波が「買えるか買えないかの境目」にある編成が多いときだけ**。

これは測定の問題であると同時に**ゲームの問題**でもある。実プレイでも結果は整数（何部隊抜いたか）なので、境目に無い波では代金の向きはプレイヤーに見えない。**同じことを測定側と設計側から二度言っている**ので、両方から潰す。

## 2. Phase U — 突破を連続量にする

### 2-1. 定義

**突破度 = 突破した部隊数 + 最後に負けた部隊戦での削り割合**（0.0 〜 列長）。

最後の部隊戦で敵の総最大HPのうち何割を削ったかを、部隊数の小数部として足す。全抜きした試行は列長ちょうど（小数部なし）。

計算は `FirstBattleAttrition`（`Engagement.cs:144-149`）と同じ形。**あれを最終戦に当てるだけ**で、新しい計測経路は要らない。

```csharp
/// <summary>最後の Battle で敵部隊の総 MaxHp のうち削った割合（0..1）。
/// 突破数が整数に潰れて向きの差を吸収してしまうため、部分点として足す（第8期）。</summary>
public required double LastBattleAttrition { get; init; }
```

**実装上の注意**:

- 分母は**その戦闘に投入された敵部隊の総 MaxHp**。持ち越された敵部隊なら、持ち越し前の定義値ではなく**その戦闘の開始時点の Hp 合計**を分母にするか、定義上の MaxHp 合計にするかで意味が変わる。**定義上の MaxHp 合計（`SquadEntry.DefMaxHpSum`）を使う**——「この部隊をどれだけ削ったか」を列全体で通した尺度にしたいので、持ち越しで目減りした分母は使わない。**この判断をコメントに残すこと**
- 全抜きした試行では最終戦も勝っているので、部分点は 0 ではなく**列長ちょうどに揃える**（1.0 を足さない）。突破度が列長を超えないこと
- `FirstBattleAttrition` は**そのまま残す**（第2期以来の特攻隊の指標）。列長1のときは両者が一致するはずで、これは検算に使える
- verbose 非依存で積む

### 2-2. 使う場所

`bridge` に突破度の列を足す。**期待突破数の列は残す**（第7期と比較するため）。

`engage`（`docs/engage.md`）にも足すか否かは実装者判断でよいが、**足すなら第7期までの数字が動かないことを確認する**（列の追加であって既存列の変更ではない）。迷うなら診断（`bridge`）だけに留めてよい。

### 2-3. 受け入れ条件

- `compare` / `chain` / `pulse` / `ablate` / `dump` / `engage` / `seats` / `handoff` / `cost` / `gradient` / `aim` / `flip` の差分 **ゼロ**
- `bridge` の期待突破数の列が第7期と**完全一致**（純粋な追加であることの検算。**一致しないまま先へ進まない**）
- 列長1の会戦で `LastBattleAttrition` == `FirstBattleAttrition` になること

## 3. Phase V — 合計代金を振る

### 3-1. 狙い

**波3を「ぎりぎり買える／買えない」の境目に置く。** 現在の 136% を下げて、境目の位置を探す。

列は3本以上。第1波・第2波は据え置き、**第3波の代金だけを振る**（交絡を減らす）。

| 列 | 構成 | 合計代金 | 狙い |
|---|---|--:|---|
| 反転列(現行) | H2 系 / 2b / R11(68%) | 約 136% | 第7期の値。対照 |
| 反転列(中) | H2 系 / 2b / 反転候補(約 50%) | 約 118% | 境目に近づける |
| 反転列(低) | H2 系 / 2b / 反転候補(約 40%) | 約 108% | 境目、あるいは全抜きが出始める |

- 第3波の安い版は、**第7期の原理で体数を減らして作る**（体数は符号を増幅するので、減らすと反転も小さくなる）。**反転の大きさが落ちること自体は許容**するが、各列の `単体 − 範囲` を必ず併記すること。**向きが消えた列で橋が架かっても意味が無い**
- 波2を削って合計を下げる案もあるが、**採らない**。第2波を固定しておかないと、第7期の対照と繋がらなくなる

各列について、平坦列（農兵 / 2b / 3a）と同じ物差しで測る:

- 期待突破数、**突破度**（Phase U）、突破率（1部隊・2部隊）
- 平坦列との**順位相関**（スピアマン。第7期と同じ計算方法を使う。**方法を変えない**）
- **ちょうど整数値に張り付いている編成の数**（分解能が効いているかの直接の指標）
- 群別の変化 Δ（範囲持ち / 単体のみ）— 第7期と同じ区分（`HasAoe`）

### 3-2. 判定

| 観測 | 結論 |
|---|---|
| 突破度で見ると相関が下がり、範囲持ちが反転列で上がる | **指標が悪かった。** 8pt は届いていた。勾配列の採用検討へ進める |
| 突破度でも相関が高いまま、しかし合計代金を下げた列では下がる | **境目の問題。** 向きは効くが、波が境目にあるときだけ。**列設計の原則として重要**（波の代金は編成の残容量の近くに置く） |
| 突破度でも、どの合計代金でも相関が高いまま | **8pt が足りない。** 攻撃パターンによる向きは代金には出るが結果には出ない。**自傷軸へ移る根拠が確定する** |
| 合計代金を下げたら全抜きが多発して分布が潰れた | 下げすぎ。**その列は判定に使えない**ので、間の値を1本足す |

### 3-3. 受け入れ条件

- `compare` ほか差分 **ゼロ**。`Columns` / `Stages` 不変
- 平坦列と反転列(現行)の値が第7期の `bridge` と一致（**検算**）
- 各列の `単体 − 範囲` を併記（向きが保たれているかの確認）

## 4. Phase W — 記録と報告

### 4.1 README に書くこと

- **第7期の2択（8pt が足りないのか、指標が悪いのか）の決着。** §3-2 のどの行だったか、数字ごと
- **突破度という指標**そのもの。整数の突破数では向きが吸収されること、部分点を足すと何が見えるようになるか。**今後の計測すべてに効く基礎**なので独立した項で書く
- **列設計の原則**として言えること: 波の代金は、その時点の編成の残容量の近くに置かないと、代金の差がプレイヤーにも計測にも見えない。**これは実プレイの体験設計にも同じく効く**（結果は整数なので、境目に無い波では編成の工夫が結果に出ない）

「未解決の課題」— **既存の4件（自傷軸の強化 / キャラのスキル・攻撃パターンの相談 / 第二波の司祭ダミー / 向きの大きさ）はそのまま残す。** 決着した2択の項は解決済みへ移す。

### 4.2 報告してほしいこと

1. **2択の決着。** §3-2 のどの行か、突破度と期待突破数を並べて
2. **整数に張り付いていた編成の数が、突破度でどう変わったか**（17〜21 → いくつか）
3. **合計代金と順位相関の関係。** 136% / 118% / 108% で相関がどう動いたか。**境目はどこにあるか**
4. **各列で向きが保たれていたか**（`単体 − 範囲`）。安くした第3波で反転がどれだけ落ちたか
5. **範囲持ちと単体のみの群で、突破度の差はどうなったか。** 第7期の −0.031 対 −0.102 波が、突破度ではどうなるか
