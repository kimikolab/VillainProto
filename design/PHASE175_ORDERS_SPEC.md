## 1. 行き先指定の操作（`Map11Main` と `Map11State` の命令の持ち方だけ）

### 1-1. 規則は変えず、命令の「持ち方」を変える

- 隊は**行き先（マス）**を1つ持つ。毎作戦ターン、行き先へ向かって**自動で1マス**進む（進む＝第174期の「進む」と同じ規則）
- 行き先が**拠点**なら戻る。拠点に着いて行き先が拠点のままなら、**自動で休む**（HP が満タンなら待つ）
- 敵のいるマスへ入れば戦闘（第174期と同じ）。**勝てば、行き先が先にある限り次のターンも進む**
- 行き先に着いたら止まる（待つ）
- **既定の行き先**: 未出撃の隊は**拠点**（＝待つ）。**一度でも出した隊は、行き先を変えるまで前へ進み続ける**

→ 第174期の「1ターン1命令」は、**行き先から毎ターン自動で作られる**だけになる。`Map11State` の1ターンの処理は変えない。

### 1-2. 画面

| 操作 | 中身 |
|---|---|
| 行き先を決める | **隊を押す → 盤のマス（または敵部隊）を押す**。2クリック。隊から行き先へ**矢印**を描く |
| 取り消す | 隊を押して拠点を押す（＝戻る） |
| 進める | 「▶ 進める」は、**何かが起きるまで作戦ターンを自動で回す**。止まるのは: 接敵・迎撃・隊が行き先に着いた・敵が前進して「あと1ターン」になった |
| 1ターンだけ | 「1ターン進める」も残す（慣れた人・検証用） |

- 左パネルの命令ボタン列（北へ進む／南へ進む／戻る／休む／待つ）は**消す**
- 組み直しは、行き先が拠点で、拠点にいる隊だけ（第172期と同じ）

### 1-3. 「あと n ターンで前進」を盤の上へ

- 盤の上の敵部隊の円の脇に、**大きめの数字 n と矢印（拠点の向き）**
- n = 1 のとき円が脈打つ。前進した瞬間は**円が1マス滑る**（瞬間移動させない）
- 右パネルの同じ文は**消す**（パネルの行を1つ減らす）

## 2. 待ちの抜け道を塞ぐ（規則の変更はこれ1つ）

**迎撃戦に勝った隊には、道中の回復（50%）を乗せない。**（第174期 Q0-3 の既定を反転。ノブ `InterceptRecover` を置き、既定 false）

- 理由: 拠点で待つと得な3つの理由（移動ですり減らない／迎撃にも回復が乗る／1部隊ずつ来る）のうち、**これだけが規則の1行で外せる**
- 休む（拠点で 25%）はそのまま残す。**待って受けるなら、休みに作戦ターンを払う**形になる
- `TimeOn = false` と `InterceptRecover = true` の組で第174期の値が再現すること（自己検査）

## 3. 器具（`--map11-time` に方針を足す）

| 方針 | 中身 |
|---|---|
| 貪欲・全快 | 第174期のまま |
| 籠城 | 1マスも動かない。**迎撃役は「まだ戦っていない隊」→「HP% の高い隊」の順に選ぶ**（番号順ではなく、人が選ぶ形に寄せる） |
| **即出し** | **1ターン目から3隊とも出す**（カド隊→南／かき回し隊→北／控え隊→北）。休まない |

K = 1 × 4方針 × `InterceptRecover` true / false × seed 800。

**量**: 踏破率／迎撃が起きた率／陥落率／作戦ターン数の中央値

**線（測る前に固定）**

| # | 線 |
|---|---|
| 対照 | `InterceptRecover = true` の貪欲・全快が第174期の値と一致（籠城は選び方を変えたので対照外） |
| 線1（待ちが弱くなった） | `false` で、**籠城の踏破率 ≤ 10%**（選び方を人に寄せた上で） |
| 線2（出せば通る） | `false` で、**即出しの踏破率 ≥ 85%** |

- 線1 が × なら、どの理由がまだ効いているかを表にして止まる（「1部隊ずつ来る」を外すのは次の期の判断）
- **即出しが4方針で最も高いのは想定どおり**。高すぎる（≥ 98%）なら報告だけする（難度は第176期の「配られた駒から組む」で上げる）
