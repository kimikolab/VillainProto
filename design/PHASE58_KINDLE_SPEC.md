## 0. この期の主題

第57期（燃焼の解剖）の実測から引く。**数字は報告書 `design/PHASE57_BURN.md` にある。**

| 実測 | 値 |
|---|---|
| 表E（9通貨 × 双方向） | **18セルすべて 0**。燃焼は他のどの通貨とも繋がっていない |
| 交互作用 | **−52.3pt**。火の粉と熾火は完全な AND ゲートで、片方を落とすと 20% 台（台が死んでいる値） |
| 味方側の着火 | **2.40/戦（敵 2.21 より多い）**。40セル中 27セルで味方の燃ダメが敵を上回る |
| 火の粉の帰属の符号 | **資産2 / 代金3 / ゼロ2**（別 seed 帯で 6/8 行が符号一致） |
| ホタの稼働 | **100%**（全5波1000戦）。初着火は例外なく第1ターン |

**燃焼は「供給が足りない軸」でも「読み手が足りない軸」でもなく、盤面のどこにも繋がっていない
閉じた2枚組である。** そして**誰も読んでいない在庫が既に盤上にある**——味方側の燃焼 2.40/戦は、
ボルグを含む8行のうち3行で純粋な代金（−3.8〜−7.9pt）として払われっぱなしになっている。

**この期に作るのは、その在庫を読んで別の通貨へ変換する駒1枚。**
変換先は**強化（`ctx.Whet`）**と**弱体（`ctx.Dull`）**——どちらも共通窓口が既にある
（強化は第56期、弱体は第42/43期）。

### なぜ強化なのか（他を採らなかった理由）

- **位置**（油案）は**ホタが既に担っている**。燃えている間の熾火は貫きに変わり、
  貫きはレーンを走るので、燃焼は敵側の「列」に既に接続している。ここへ重ねると
  ホタと軸が重複する（第12期にスィドをグザの下位互換にした失敗と同型）
- **`IdleTurn`** は「燃えている駒は手番を差し出す」の形になるが、ホタの手番は攻撃4倍＝
  **売値が高すぎて売れない**（第36期の「安い手番は売っても安い」の逆側）
- **強化**は積み残し1（**供給の 48.3% が吐き戻し1本で、編成が選べる供給が無い**）に
  そのまま刺さる。**1枚で2箇所に接続する**のはこの選択肢だけ

### 却下した代案（報告書のコメントに残すこと）

| 案 | 却下の理由 |
|---|---|
| **2枚目の書き手を兼ねる**（隣接味方に火を点けつつ強化も配る） | ボルグ独占は外れるが、**1つの駒で書きと読みを兼ねると自己完結**する。第57期の「捨て率35.5%」は対象飽和なので、同じ形の書き手を足すと捨て札が増えるだけ。**効いたら次期に単体で試す** |
| **手番（`Actions = [Skill]`）で配る** | 手番へ置くと痺れ・縛め・粛と交絡し、**接続の帰属が読めなくなる**。`OnTurnStart` は既に8体で厚いので移設の価値はあるが、**効いてから移す**（第36期のまどろみと同じ順序） |
| **`BurnRules` の定数（6 / 3）を触る** | 第57期 §9 で決めないことにした。非スタックを崩すと熾火の稼働100%が動く |

   - **配る先が「燃えている味方」なので、ホタは構造的に常に対象になる**（稼働100%）。
     つまり**この駒の強化はホタに対してだけ 4 倍で入る**

2. **強化の現況を測り直す**（第56期の `whet` モード）。供給の経路別の割合・死蔵率・
   `WhetRoutes` の本数。**48.3%（吐き戻し）と 6.2%（死蔵）が現在も同じかを確認する**

   `SupportTargets` を通す（吐き戻し・号令。ガルドへは届かず隣へ漏れる）と、
   自前で濾す（駆り立て。隣へ漏らさない）。

   ——駆り立て側に揃えるのが素直だが、**選んだ理由を必ず書くこと**。
   積み残し7（統一）はこの期では触らない
4. **試験行を先に決める。** 第57期でボルグを含む行は8行。**そのうち3行に入れる**（§2-3）
5. `docs/balance.md` の現在値を控える（56 行 × 5 波 = 280 セル）。回帰チェックの分母

## 2. 作るもの

### 2-1. 特性

**規則は1つ。プラスとマイナスはその表と裏にする**（縛め `Bind` と同じ形。
第56期の実測で `Bind` は強化の経路で単発量が最大だった）。

> **毎ターン、燃えている味方の攻撃力を上げる。
> 自分に隣接する味方のうち燃えていない者は、逆に腕が鈍る。**

- **プラス側**: `OnTurnStart` で、**燃えている味方全員**（自分を除く）に `ctx.Whet(t, Gain, WhetRoute.Kindle)`。
  **位置を問わない**
- **マイナス側**: 同じ `OnTurnStart` で、**隣接する味方のうち燃えていない者**に
  `ctx.Dull(t, Loss, DullRoute.Kindle)`。**位置で決まる**

**プラスを全体・マイナスを隣接にするのが要点。** 逆にすると「隣に火があるかどうか」だけの
二値になり、配置の判断が消える。この形なら
**「火を全体に回すか、自分の隣を空けるか」**という2つの解き方が同時に立つ。

`WhetRoute` と `DullRoute` に列挙子を1つずつ足す（`WhetRoutes.Names` / 弱体側の名前配列も）。
**既存の経路の値は動かさない**（末尾に足す。診断の表の配列長はそこから引かれている）。

既定値は **`Gain = 2` / `Loss = 2`**。**掃引は §4 で行う。**
版の切り替えは `Run` への引数（`KindleRule`）にすること。**書き換え可能な static のノブは置かない**
（Trait は共有シングルトン・`layout` は並列実行）。**既定は無効**で、
何も渡さない状態の `compare` が現行の `docs/balance.md` と一致することが検証になる。

### 2-2. 駒

| 項目 | 値 |
|---|---|
| 仮称 | **焚き付けのフイ**（名前は仮。ポン確認前でよいのでこのまま実装する） |
| HP / 攻 / 速 | **70 / 5 / 6**（支援型。攻5は「変換しても実出力を捨てない」帯の内側） |
| 攻撃型 | 単体 |
| プラス文 | 燃えている味方の攻撃力を毎ターン上げる |
| マイナス文 | 自分の隣で燃えていない味方は、逆に腕が鈍る |
| 捨てられた理由 | 火のそばにいる者しか目に入らない。えこひいきで隊を割った |

**攻撃力を低くするのは意図的。** 出力で効いてしまうと、接続が効いたのか体が効いたのかが
分からなくなる（第34期「1変数を振るときは、その変数が他に何を一緒に動かすかを先に数える」）。

### 2-3. 試験行

**1行だけに入れない。** 第57期が示した AND ゲートの再生産を避けるため、
**ボルグを含む8行のうち性格の違う3行**で、**1枠だけを差し替える**。

| # | 台 | 差し替える枠 | 狙い |
|--:|---|---|---|
| 1 | **燃焼 (ボルグ×ホタ)** | ノノ（前3・寄与 +37.0pt で5枠中最安） | **乗算が最大になる台。**ホタが常に燃えているので強化が4倍で入る |
| 2 | **火の粉が代金になっている行**（毒→被弾強化 / 縛め非収入型 / 鱗改 のいずれか1つ） | 火の粉の帰属が最も負の行を選ぶ | **代金が資産に反転するか。**この期の本命の問い |
| 3 | **火の粉がゼロの行**（逸らし / 止め改 のいずれか） | — | **無風の行が動くか**（動いてはいけない側の確認ではなく、接続の届く範囲の測定） |

**配置は仮置きでよい。** 採否を決める前に `reseat`（120通り全探索）→ `confirm`（別 seed 帯）を回す。
**`reseat` の120通りが 20% 台で並んだら台が死んでいる合図**なので、そのときは差し替える枠を変える。

## 4. 掃引

`Gain` / `Loss` を振る。**点の数だけ対照が要る**（第34期）。

| 版 | Gain | Loss | 見るもの |
|---|--:|--:|---|
| V0 | — | — | **既定無効。`docs/balance.md` と一致することの検証** |
| V1 | 2 | 2 | 既定 |
| V2 | 4 | 2 | プラスを厚く |
| V3 | 2 | 4 | マイナスを厚く |
| V4 | 4 | 4 | 両方 |

**各点に「規則を無効にした同数値の対照」を置くこと**——駒は入れるが特性を持たない素体
（HP70/攻5/速6・特性なし）に差し替えた版。**体の値段と機構の帰属を分ける。**
第34期は対照を置かなかったせいで、用量反応の 82% が体だったことに掃引の後まで気付かなかった。
