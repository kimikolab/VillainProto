指示書は `design/PHASE267_BOSS_GUARDED_HEALER_SPEC.md`。器具は `bosswave guard0 ／ guard ／ check267 ／ log267`（`BattleSim/Modes/BossWave.Guard.cs`）。

**結論: この形のままでは採らない。** 毒の問題は解けた（毒 0 → 100%・毒+ベニ+ラウ 0 → 31〜50.5%・癒し手は刻みで割る）が、毒以外の台は癒し手を範囲で T1〜2 に割り、以後は回復の無い勇者を D-40 より 1.6〜2.3 ターン早く倒す（指示書 §4 の条件3 ×）。癒し手を厚くすると先に崩れるのは毒のほう。`compare` 305 セル 0 件・再現系は全行一致。


## 1. Phase 0

### 0-1 庇いの実装点 —— `ApplyDamage` の段ではなく標的選択

- 殉教者（`MartyrTrait`）の庇いは**ダメージの分割ではなく主目標の差し替え**（`SelectTargetChain` の Single の段・75% で一撃まるごと殉教者へ・前列の殉教者だけ・肩代わりで攻撃力が育つ）。指示書の「75% を肩代わり」は「単体攻撃の 75% を勇者へ差し替える」と読んで実装した
- 新しい札 `HeroShield75` ／ `HeroShield100`（勇者の庇い）は殉教の段の**直後**に1段。違いは3つ: **列を問わない**（勇者は中央）・**守るのは癒し手（`HeroMend` の持ち主）だけ**・**育たない**（`RedirectGainTrait` を継がない）。100% の版は `Roll` を引かない。保持者のいない戦は `_heroShieldLive` の比較1つで抜ける
- `ApplyDamage` のどの段にも入らない。差し替わった一撃は**勇者への普通の一撃**になる——萎縮・破片・軛は「勇者が受ける一撃」として通常どおり乗る（分割しないので、肩代わりの `u != source` や中継の札の論点が無い）
- 差し替えの出来事は既存の `Intercept`（札は `InterceptLabels.HeroShield`）。**`InterceptLabels.All` には入れていない**ので `harm` の段別の内訳は動かない

### 0-2 刻みは庇いを通らない

毒・燃焼の刻み（`PoisonTickOnce` ／ `BurnTickOnce`）は `ApplyDamage` を直に呼び、`SelectTarget` を通らない。`check267` (d): 庇い 100 の盤面で癒し手に毒 10 を置いて `TickStatuses` を1回 → **癒し手 145 → 135・勇者 3,000 のまま**。中核規則の違反は無い。

**ただし毒を「付ける」一撃は単体なら庇われる**——毒を書く単体攻撃（グザ・ミオなど）は勇者へ差し替わり、毒は勇者に付く。癒し手に毒が届くのは、漏れた単体（75% の版の 1/4）・範囲・隣接への毒の広がりだけ。

### 0-4 片方が倒れた後

- 勇者が倒れた後の癒し手: `HeroMend` は「勇者の印の持ち主」を探して癒すだけなので、勇者がいなければ何もしない（重装兵の体で殴るだけ）
- 癒し手が倒れた後の勇者: 回復なし・天井 +11 の HP 3,000 の素の体

### 0-5 席替え・押し込み（R363）

庇いは**持ち主の札**（`HeroMend` ／ `HeroShield*`）で判定し、席を見ないので、バサの入れ替えで勇者と癒し手の席が動いても壊れない（勇者が前列に出れば、単体の主目標が勇者になるだけ）。

### 4-1 なぜ易しくなるか

- 庇いは**単体しか止めない**（中核規則どおり）。毒以外の台が癒し手を割るのは単体ではなく範囲（全体・薙ぎ・放電）で、**T1.1〜2.0 に 100% 割れる**。庇った単体は1戦 0〜2 回しか無い
- 癒し手が割れた後の勇者は回復なし。D-40 は**戦の終わりまで**自前で 40% 癒えるので、「回復を取り巻きに預ける」形は、取り巻きが割れる台にとって**常に D-40 より易しい**
- **厚くしても直らない**（§3-1）: ×8（1,160）でも範囲の台は T2〜3.8 に割り、倒しT は D-40 より短いまま（移動 T3.1・雷 T4.4・混ぜ T4.8）。**先に崩れるのは毒+ベニ+ラウ**（50.5 → 10.5 → 0 → 0%）——刻みで割る速さは厚みに比例して遅れるので、**癒し手の HP は毒から先に課金するノブ**
- G-庇75 と G-庇100 の差は毒の2台にしか出ない（毒+ベニ+ラウ 50.5 ／ 31.0%）。75% で漏れる単体（1戦 2.5 回）が、毒を付ける一撃として癒し手を早く割る（T4.4 ／ T5.0）

### 4-2 毒について分かったこと

- **「毒だけが癒し手に直接届く」は半分だけ正しい。** 刻みは庇いを通らない（`check267` (d)）が、**毒を付ける単体攻撃は庇われて勇者に付く**。癒し手に毒が入るのは、漏れた単体・範囲・隣接への広がりの分
- 毒は勇者より先に癒し手を割り（100%）、割ってから勇者を倒すまで 3〜5 ターン。毒+ベニ+ラウは割った後の T5〜T15 の殴り合いで半分負ける（崩れ始め T5.0・100%）——**負けているのは癒し手ではなく天井**
