## 0. 主題

### 0-1. 問い

> **傷は「使われていない」のか、「使うと損」なのか。**
> 前者なら接続の問題、後者なら軸の設計そのものの問題で、**直し方が逆になる。**

現況（Phase 0 で数え直すこと）:

| 事実 | 出どころ |
|---|---|
| **傷は味方に載る経路が1つも無い**（305 セル全数） | 第68期。`Traits.cs` の宣言にも同じ記述がある |
| **枚数効果の傾きが −15 前後**（1枚−0枚 −15.84 / 2枚−1枚 −15.30）。**集めるほど悪くなる** | 第71・72期（弱い波・Pw） |
| **理想61行でも符号が一致**（断ちのナタ −17.4。ただしキリは −3.4 で桁が違う） | 第71期 §9-4 |
| **保持者5枚**（キリ・エグ・ノミ・ナタ・ハリ）、compare には**15 行**に登場 | `UnitCatalog` / `CompareBuilds()` |
| 役は4つ揃っている | 裂き（書き手）／刻み（書き手＋読み手）／抉り（読み手）／断ち（消費型の読み手）／縫い（防御側の維持読み） |

**書き手が味方に届かず、読み手だけが5枚ロスターを占めている軸。**
**最後の1枠を足す前にここを直すほうが安い——枠を使わずに5枚が動く。**

### 0-2. 仮説（3つ。測って否定してよい）

- **H1（未接続説）**: 傷は**書かれる量が足りない**。読み手はいるが在庫が無いので発火しない。
  → 直し方は**書き手の追加または増量**
- **H2（消費競合説）**: 在庫はあるが、**読み手どうしが同じ在庫を食い合う**。
  断ち（すべて断つ）・縫い（1つ塞ぐ）は**消費型**、抉り・刻みは**維持型**。
  **消費型が在庫を消すので、集めるほど互いの前提を壊す**。→ 直し方は**消費と維持の分離**
- **H3（代金説）**: 傷を持つ駒の**マイナスが重すぎる**。
  キリ「与ダメは常に1」／エグ「倒すと次の手番を失う」／ノミ「一度狙った敵が倒れるまで他を見ない」／
  ナタ「傷が2つ開くまで手番を捨てる」／ハリ「繕うたび敵の傷が塞がる」——
  **傾き −15 は軸の失敗ではなく、5枚ぶんのマイナスの合計**。→ 直し方は**代金の引き下げ**

**H2 と H3 は両立する。H1 が正しければ H2 は成立しない**（在庫が無いなら食い合いも起きない）。

### 2-1. 数える量

| 量 | 定義 |
|---|---|
| **書き込み** | 1戦あたりの傷の書き込み回数（駒別・敵味方別） |
| **在庫** | ターン頭の敵側の傷の総数（平均・最大）と、**その分布の時間推移** |
| **消費** | 断ち・縫いが消した傷の数（駒別）。**書き込みに対する割合** |
| **読み** | 抉り・刻み・断ち・縫いが実際に読んだ傷の数と、**それが出力に変えた量**（上乗せ・繕い） |
| **空振り** | 読み手が発火したが在庫 0 だった回数／ナタが手番を捨てた回数／エグが手番を失った回数 |
| **代金** | 5枚のマイナスの実額（キリの与ダメ 1 固定で失った量＝素体との差、ほか） |

### 2-2. 測る台

**理想61行（傷を含む15行）とドラフト台の両方**で測る。

- 理想: 15 行 × 5波。**行は選ばない**
- ドラフト: 第72期の **Q1 を通した版**（S'・弱い波・中間帯 71.2%）。**規則も倍率もそのまま**

**両方で測る理由**: 第71期 §9-4 が「傷の −15 はドラフト台に固有か未確認」と書いている。
**第72期の地図は 10/11 キーで符号一致だったが、傷が例外の側かどうかを個別に確かめる。**

### 2-3. 対照

| 対照 | 中身 | 分かること |
|---|---|---|
| **消費型を落とす** | ナタ・ハリを同数値の素体に差し替え | **H2**。在庫が増え、維持型の出力が伸びるか |
| **代金を外す** | 5枚それぞれ、**マイナスだけを無効にした版**（`Traits.cs` は触らず、診断のローカルに `UnitDef` を置く） | **H3**。代金ごとの帰属 |

**3つとも「同数値・その1点だけ落とした/変えた版」。**素体差し替えの器具に統一（第69期）。
