## Phase 0（実装の前・コードを読んで答え、R0 の台を数えた）

### Q0-1 火勢の置き場所

- **燃焼の残りターン（`StatusKeys.Burn`）と並べて、私有カウンタ `fireLv` に置く。** `StatusKeys.All` には足さない
  ——足すとリリの口移し（`KissTrait.Moved` ＝ All − Excluded）・雷の種類数（`ThunderTrait` が数える状態異常）・`watch.md` の表・会戦の境界の一括消去がすべて動く。
- **読みは「燃えていれば max(1, fireLv)、燃えていなければ 0」の1本**（`FireLevelRule.Of`）。燃焼を書く口は `Ignite` の他に
  燃焼の刻みの減算（`TickStatuses`・残り 0 で消える）・焼け残り（`SetCounter(Burn, 0)`）・リリの口移し（`SetCounter` で残りターンを移す）・会戦の境界（`StatusKeys.All` の一括消去）がある。
  **読みを燃焼の有無に縛れば、どの口で燃焼が消えても火勢は 0 に読める**（口移しで燃焼だけが移っても受け手は 1 に読める）。
- **既存の着火はすべて `BattleContext.Ignite` の1箇所を通る**（Traits.cs の `ctx.Ignite` 9 箇所・engine の 4 箇所）。「保つ火」はここに1本足すだけで通る
  ——0 なら 1、1 以上なら残りターンを戻すだけ（今の点け直しと同じ）。
- 保持者（この期の札 7 枚のどれか）がいない陣営では何もしない（`_fireLvTeam` の比較1つで抜ける）。**R0 は第241期と台本ごと一致させる**（受け入れ 1）。

### Q0-2 萎む時機

- **行動順ループが終わった直後**（`BattleEngine.Run` の `foreach (UnitState actor in order)` の後・`NoteFoeStalled` の前）に1回。刻み（`TickStatuses`）は次のターンの頭なので、
  「萎む → 刻み（燃焼が切れれば消える）」の順になる。**会戦の持ち越しはこの後**（境界で燃焼が消えるので火勢も 0 に読める）。
- **育った印は私有カウンタ `fireGrewT` ＝ 育ったターンの番号**（ターンをまたいで戻す処理が要らない。据えの `IdleTurn` と同じ作法）。
  「育った」は火勢が上がった回と、**4 の駒への育ち（捨てた分）**も含む——含めないと 4 の駒が毎ターン萎んで上限に居続けられない（第240期の影の W1 と同じ）。

### Q0-3 ギフトの手番の差し込み

- **既存の「手番を丸ごと1回渡す」口は再行動（`EncoreRule`・第104期）**で、`TakeTurn(w)` を直に呼んでいる。`CanActOutOfTurn` を通らないので**粛に封じられない**。
  ギフトもこれと同じ形にする——ヒヨの `OnAction` は相手を控えるだけで、**ヒヨの `TakeTurn` が返った後**（手番の枠 `HandRecord` を閉じた後）に控えた順に `TakeTurn(相手)` を呼ぶ。
  手番の中身（痺れ・転倒・`CanAct`・周期）は通常の手番と同じ経路を通る。
- **号令のガンの叩き起こし（第180期・`ReveilleTrait`）は別物**: `CanActOutOfTurn(起こされる味方, OutOfTurnRoute.Reveille)` を通し、`Interrupt` の中で `PerformAttack` を直に呼ぶ
  ——**ターン外の行動なので粛に封じられる**（ルートの7本目）。尾灯のトモの譲渡（第110期）も `CanActOutOfTurn` を通る（5本目）。**粛に封じられない「手番を渡す」口は再行動だけ**だった。

### Q0-4 ホタの段の置き場所

- 型は `Trait.ModifyPattern`（今の熾火が燃えている間の貫きもここ）、倍率は `ModifyAttack`、5連撃は **`Trait.ModifyHitCount`（第178期・逆しまのウツの窓口）** をそのまま使う。
  `SwingTurn` が1発ずつ独立した `PerformAttack` を呼ぶので、**標的は毎発取り直され**（倒れたら次の敵へ）、脆さ・軛・庇い・反撃も1発ごとに走る（指示書 §2.3 のとおり）。
- 段は**手番の時点の火勢**。この期の育ち（燃え広がり・煽り）は**攻撃の枠の出口でまとめて入れる**ので、ホタの手番の間に火勢は動かない（萎むのはターンの終わりだけ）。
- 段2 の「当たった敵に着火」・段3 の「1回ごとに着火」は、攻撃の枠（`PerformAttackFramed`）の出口でその1回の攻撃が当てた敵に `Ignite`（保つ火）。

### Q0-5 火勢を読む既存の駒（燃焼を読む札の再点検）

**火勢（`fireLv`）を読む既存の札は 0**（新しい私有キー）。変わるのは**燃焼の量と相手**（火の粉・広で敵に火が点く数、火を保つでボルグが燃え続ける、ホタの段の着火）で、燃焼を読む札・規則は次のとおり:

| 読み手 | 何を読む | この期の変更で起きること |
|---|---|---|
| 燃焼の脆さ（F1・`EmberRule`・敵だけ +25%） | 敵が燃えているか | **火の粉・広で燃える敵が増えると、全員の攻撃が敵に +25%**（R1 から効く） |
| 火選り（ヒヨ・`Favor`） | 味方が燃えているか | 変わらない（味方の燃焼は今も隣全員に点く） |
| 熾火（ホタ・`Pyre`） | 自分が燃えているか | R2 から段に置き換わる |
| 焼き返し（ボルグ・`FireFeed`） | 主目標が殴る前から燃えていたか | **燃えている敵が増えるので回復と自火が増える** |
| 火の鎧・盾の配り・火の変換（ボルグ・ヒヨ） | 自分／味方が燃えているか | 火を保つでボルグは毎ターン燃えている＝**半減が常に掛かる** |
| 雷（カタ・`Thunder`） | 状態異常の種類数（燃焼も1種） | 雷＋ボルグの台で燃えている敵が増えれば1発が重くなる |
| 濃縮の寄せ先（ミオ） | 次の刻み（毒の層＋燃焼中なら 6） | 同上 |
| 呪い則（`SoakRule.Kinds`） | なまりの種類に燃焼 | 呪い持ち（ネル・ムド）はこの台にいない |
| 紅蓮（ベニ）・板の燃えやすさ（ツギ）・反転（ベニ）・起爆（カタ旧） | 燃焼の刻み | 雷＋ボルグの台でだけ関係する |
| 火勢の札 `Wildfire`（第133期） | 燃えている敵の数 | 保持者 0 枚 |

### 実装の方針（測る前に決めた・指示書に無いところ）

- **燃え広がりの判定は「その1回の攻撃で、その敵に最初に当たった瞬間」に、殴った本人が燃えているか・その敵が燃えているか**を控える（`PerformAttackBody` / `ResolvePierce` が `ApplyDamage` を呼ぶ直前の3箇所）。
  **育ちは攻撃の出口でまとめて入れる**（5連撃は手番の5発で1つの枠＝同じ敵は1回まで）。その攻撃の中で点いた火（火の粉・広・段の着火）は、控えが先なので数えない。
- **「攻撃」は `PerformAttack` を通る一振り**——手番の攻撃・反撃・割り込み・追い打ち・ギフトの手番。巻き込み・刻み・放電・味方の刃（混乱）は数えない。
- **ヒヨ自身の育ち（HS2）は、味方の燃え広がりの育ち1回につき +1（4 の駒の捨てた分も数える）**——第241期の影の HS2 と同じ数え方。ヒヨが燃えていなければ育たない。
- **4 の駒への育ちは捨てるが「育った」には数える**（萎まない）。
- 萎む・消える・点く・燃え広がり・煽り・ギフト・ホタの段は**台本に出来事として出す**（表示専用・`verbose` のときだけ）。
- 火を保つ（ボルグ）は `OnAfterAttack`（主目標に1度・攻撃1回ごと）で自分に `Ignite`。**札の並びで火の粉の後ろ**（燃え広がりの判定は攻撃の中で済んでいるので並びは効かない）。
