# 第215期 指示書 —— 雷の跳ね先の同点を「行き止まりを先に」へ

置き場所: `design/PHASE215_THUNDER_PATH_SPEC.md`。報告は `design/PHASE215_THUNDER_PATH.md`。
規模は小。触るのは `ThunderTrait.Heaviest` の同点の割り方だけ。

## 0. 目的

第214期の表E'で、敵が X字のとき**跳ねた雷の 48〜82% が生きている敵を1体だけ取り残した**（取り残すのは例外なく後1 か後3）。
原因は同点を席番号で割っていること。前の敵からまず中央（席2）へ跳び、中央から反対側の組へ入ると元の組の後ろへ戻れない。

敵の席はプレイヤーが選べないので、これは設計ではなく同点の割り方の癖。直す。

## 1. 今の決め（`ThunderTrait.Heaviest`）

候補のうち種類が最多の敵。同数は席番号の順。最初の一発も跳ねも同じ関数。

## 2. 新しい決め（T1）

候補の比べ方を3段にする:

1. **種類が多い**（今と同じ・第一の鍵）
2. **その先に跳べる相手が少ない**（新しい鍵）
   ＝ その候補の隣で、まだ当たっていない・生きている・状態異常を帯びた敵の数（候補自身とすでに当たった敵は数えない）
3. 席番号の順（今と同じ）

- 最初の一発にも同じ比べ方を使う（「当たった敵」は空として数える）
- 乱数は引かない
- 帯びた敵がいないときの通常の選び方（`SelectTarget`）は変えない

X字で5体すべてが同じ種類なら、前1 → 後1 → 中央 → 前3 → 後3 と一筆で全員を回るはず。

## 3. 版

| 版 | 同点の割り方 |
|---|---|
| T0 | 第214期のまま（種類 → 席番号） |
| **T1（規定の候補）** | 種類 → その先の数 → 席番号 |

札の差し替えで作る（例: `ThunderPath` を足すと T1）。`Run` の引数は増やさない。

## 4. Phase 0

- **Q0-1**: 第214期の表E'を T0 で再現できることを確認（同じ数字が出る）
- **Q0-2**: T1 でも取り残しが残りうる形を、X字・パターン3・召喚枠が立った X字で手で数える（種類の差が第一の鍵なので、種類がばらばらなら残りうる）

## 5. 予測（Phase 0 の後に数値を入れて実装前にコミット）

- **P1** カタのいない行は 0 セル（`compare` はカタ在席 0 枠なので全部）
- **P2** 敵が X字のとき、表E'の「1体だけ取り残した」が 48〜82% → 10% 未満
- **P3** 1回の雷で当たった数（表B）が X字の台で上がる。パターン3 はほぼ動かない（もともと全員に当たる）
- **P4** 敵の連鎖の大きさ（表C）も X字の台で上がる（感電した集合が大きくなるため）

## 6. 測定

第214期の `shock run` の台・席をそのまま使い、K1 に T0 / T1 を並べる。

| 表 | 内容 |
|---|---|
| A | 台1〜4 × X字・P2 × T0 / T1 の勝率・全員生存・決着ターン |
| B | 雷: 1回で当たった数の平均と分布・与ダメ/戦 |
| C | 敵の連鎖の大きさの平均と分布 |
| E' | 敵が X字・パターン3 のときの「全員に当たった／1体だけ取り残した」と取り残した席 |

## 7. 規定の決め方

P2 が当たれば T1 を規定にする。外れたら T0 のまま、理由を報告する。
