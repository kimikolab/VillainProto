## 1. 目的

第207期で置き去りのナラを継ぎ当てのツギ（`Id = "tsugi"`）に転生させた。手番で破片が最も薄い味方に板を貼る（最も強い敵の一撃ぶん・最低6＋背中の在庫）。
良かった点と弱点がはっきり出た。

**良かった点**: 在席の `分散回復` で全員生存勝ち 8.8 → 57.4%。板は支援拒否のガルドにも届き、`耐久` の第四波でガルドが倒れる戦 200 → 58。渇きの第三波ではリリより全員生存勝ちが高い（26.9 → 36.0%）

**弱点**
1. **殴らないので打点が1枚ぶん抜ける**。リリの席に置くと、勝率でリリを上回る行・波は 0
2. **カドの棘が鳴らず、`反撃改` の膠着が 2 → 378 / 800 戦**。板が一撃を吸い切ると、カドは殴られたことにならない（R155 の再発）
3. **分かち（ドハ）を守れない**。分かちは `ApplyDamage` の中で破片より前に4割を持っていくので、ドハの取り分は板を素通しする（第四波でドハが 200 / 200 倒れる）
4. **燃えやすい板（燃焼の持続を倍）は代金にならない**。ボルグは毎振り、ベニは周期3で点け直すので、延びた持続は使われない（R312）

### 1.1 ポンの案: 板を「撃ち返す盾」にする

ポンの参考: スターレイルの反射ビルドで、全員にバリアがあるとき、範囲攻撃してきた敵が複数の反射で消し飛ぶのが爽快だった。その感覚を持ち込みたい。

**板が砕けると、砕けた破片が殴った敵へ飛ぶ。**

- 弱点1への答え: 板が打点になる。範囲攻撃を受けるほど返す
- 弱点2への答え: カドの棘が鳴らない代わりに、板の破片が撃ち返す。膠着の原因（誰も殴り返さない）が消える

### 1.2 以前の「反射は採用しない」判断との関係

プロジェクトの設計メモに「反射（被ダメージ無しで返す）は採用しない」という判断がある。理由は (a) カドが既に正しく設計された反撃で、反射はその暴走版になる (b) 被ダメージに比例する反射は敵の火力に比例し、難易度の坂を平らにする (c) 被弾しないのでカドのHPの代金を踏み倒す。
今回の形はこの3つを避ける:

- **返るのは砕けた板の量まで**。敵がいくら強く殴っても、貼った板以上は返らない（b への答え）
- **板は砕けて消える**。守りを使い切って撃つ（c への答え）
- カドは「自分の攻撃力で返す・隣も巻き込む」、ツギは「貼った守りを弾に変える」。**源が違う**（a への答え）

### 1.3 絵

1. 敵の詠唱兵が味方全体へ大技を放つ
2. 全員に貼られた板が一斉に砕ける
3. 砕けた破片が全部、詠唱兵へ向かって飛び、詠唱兵が消し飛ぶ

## 2. 変更

### 2.1 反射: 砕けた破片が殴った敵へ飛ぶ（本体）

- **板の印（`plank`）を持つ味方**が、**敵を出どころとするダメージ**で破片を失ったとき、**失った破片の量だけのダメージを、その敵に返す**
  - 敵の攻撃（単体・薙ぎ・貫き・全体）も敵の術も含む。毒・燃焼の刻み、味方が出どころのダメージ（ボルグの巻き込み・カドの棘の巻き込み等）では返さない
  - 範囲攻撃なら、板を持つ味方ごとに1回ずつ返る（**板の枚数ぶん、殴った敵に集中する**）
  - 返すダメージは攻撃ではない（庇い・受け流し・反撃・割り込みの対象にならない。第204期のリリの吸い取りと同じ扱い）。ダメージ自体は通常の入口を通す（敵の破片・軛の上限などは効く）
  - 返す瞬間の順序は、カドの棘の反撃と同じ位置（Q0-2 で確かめる）。範囲攻撃の途中で殴った敵が倒れた場合の扱いも棘に揃える
- ヒビ・ササ・ウケの破片だけを持つ味方（板の印が無い）は返さない。**ツギのいない行は動かない**
- 板の印は第207期のまま（破片が 0 になると消える）。印がある間に失った破片は、出どころがツギの板か他の書き手かを問わず返す
- 背中の在庫（砕けた破片の50%を拾う）は**第207期のまま残す**（飛んだ破片と拾う破片の両方が起きる。二重取りになるが、今期は並べて見る）

### 2.2 燃えやすさの差し替え: 燃焼ダメージ倍

- 第207期の「板の印を持つ味方は、燃焼の持続が倍」を外し、代わりに**「板の印を持つ味方が受ける燃焼の刻みダメージが倍」**にする
- Q0-2（第207期）で燃焼の刻みは破片で止まると分かっている。つまり**燃えている味方の板は倍の速さで焼け落ちる**（火の書き手がいる編成では、板が長持ちしない）
- 燃焼の刻みで失った破片は反射しない（§2.1・敵が出どころではない）
- ベニの結界の内側で燃焼が回復に化ける場合、倍にするのは化ける前か後か（Q0-3 で確かめる）。**化けた回復も倍になる順**を規定にする（ベニの隣では板が燃えやすいほど癒える＝資産）
- ポンは「マイナスは要検討」としている。今期は版として並べて見るだけ

### 2.3 分かちの取り分も、ドハ自身の破片で受ける

- 分かち（ドハの `Sharer`）が肩代わりした取り分を、**ドハが受けるときにドハ自身の破片の段を通す**（今は破片より前に持っていくので、ドハの取り分は破片を素通しする）
- ツギのいない行でもドハが破片を持つ場面（ヒビ・ササ等と同席）があれば動く。**Q0-4 で影響範囲を数える**
- ドハが板の印を持っていれば、肩代わりの取り分で失った破片も反射する（出どころは元の敵）

### 2.4 変えないもの

- 板の厚さ（最も強い敵の一撃ぶん・最低6＋在庫）・板を貼る相手の選び方・在庫の拾い方
- HP62／攻9／速8・`Actions = [Skill]`（ツギ自身は殴らない）
