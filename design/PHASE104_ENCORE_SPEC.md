## 0. 主題

### 0-1. 傷軸は、13期かけても本人が弱いまま

| | 実測 |
|---|---|
| 敵の傷の在庫 | **0.47/T**（第85期。最大 0.96。ハリが塞ぐので天井1に張り付く） |

| エグの払い出し | **攻12→18**（傷2つ × 3点。第99期の画面） |
| 未読の傷 | **敵側 78%**（第85期。**投資の8割が、敵が倒れた瞬間に消える**） |

体と火力を優先すると**キリ（攻12→1・HP44）が押し出される**（第99期の画面） |

**読み手を繋ぐ試みは13期続けた。** 84期（棘→傷）不採用、85期（ハリの両側読み）採用、
86期（ノノ）採用、87期（ミオの着火）採用、90/91期（滲み則）採用、93期（深手）不採用。
**採用は5つ出たが、傷を刻む駒自身は攻1のまま前列に立っている。**

### 0-2. 精算を「数 × 係数」にしてはいけない

**分子が 1〜2 しかない**（§0-1）。**数に比例させると必ず単価の壁に当たる**——
第84・86・89期が3回落ちた場所である。

**13期で唯一天井を越えたのは第87期のミオの着火**で、あれは
**「傷があるかどうか」の二値の鍵**だった。深さを読まず、毒という別の通貨を開けた。

> **精算は二値の鍵にする。**

### 0-3. 何を作るか

**傷を刻まれた敵が倒れたら、その敵に傷を刻んだ駒が手番をもう一度得る。倒したのが誰かは問わない。**

- **傷は移らない。刻み手が動く。** 「深追いして次の獲物へ食いつく」——絵として一貫する
- **恩恵を受けるのが傷軸本人。** 強い駒に再行動権を渡す係にならない
- **キリは自分では倒せない**（`ThinBlade` で与ダメが常に1）ので、
  **キリが刻んで、ドルガが仕留めて、キリがまた刻む**という受け渡しになる。
  **1つの出来事で2枚が同時に立つ**——第99期の「爆発が1枚の中で閉じている」への答え
- **第103期のソムと直結。** **餌に刻む → 倒す → 本命に刻む。餌が刻み手の踏み台になる**

### 0-4. 上限を付けない（**判断**）

**刻み手が複数なら全員が再行動する。回数の上限も付けない。**

理由は構造で決まっているから:

- **傷を書けるのは 裂きのキリ と 刻みのノミ の2枚だけ。** 1体につき最大2枚
- **どちらも与ダメが 1〜2。** 再行動しても盤面がほとんど動かない
- **刻む対象がそもそも少ない**（在庫 0.47/T）

**上限は壊れてから付ける。** 先に付けると、効いているかどうかが分からなくなる
（第85期の巻き込み則・第96期の呪いも上限なしで測って、どこで止まるかを実測から知った）。

### 1-2. 刻み手の記録

**`BattleContext.Wound(target, amount, writer, route)`（第93期の窓口）は
`writer` を計数の帰属先としてしか使っていない**（doc に「**盤面には一切影響しない**」と明記）。
**そこに記録を1つ足す。**

- **`UnitState` に「この駒に傷を書いた駒」の記録を持たせる。** 挿入順の列で、重複は入れない
- **`Wound` が実際に傷を書いたときだけ記録する**（深手への上乗せ・書けなかった場合は記録しない）
- **傷が 0 になったら記録も消す。** 断ち（0 に戻す）・縫い（1 引く）・継ぎ当て（1 引く）で
  傷が消えたなら、**刻んだ事実も消える**
- **戦闘をまたがない。** 傷は境界で消えるので記録も消える（`CarryOver` に足す）
- **`ctx.PickOne` を使わない**（第89期 (h)。候補2個以上で `Roll` を消費する）

### 1-3. 再行動

**倒れたときに、記録された刻み手のうち生存していて敵陣にいる駒が、手番をもう一度得る。**

```
死亡の処理の中（OnAnyDeath の並びのどこか。Phase 0 で位置を決める）:
    if (!ctx.Encore.Enabled) return;
    if (再行動から生まれた死である) return;          // ★ 1ホップ
    foreach (刻み手 in 記録（スロット昇順）)
        if (刻み手.IsAlive && 刻み手.TeamId != dead.TeamId)
            その駒の手番を1回走らせる
```

- **手番まるごと。** 通常攻撃1回ではない。
  **現時点でキリ・ノミは `Actions` を持たないので実質は通常攻撃1回だが、
  「素の通常攻撃しか振らない駒を減らす」方針があるので、手番として実装する。**
  **この理由をコードのコメントに書くこと**——後から読んだときに「なぜ手番なのか」が分かるように。
- **★ 1ホップ。** **再行動の中で起きた撃破からは、さらに再行動しない。**
  `ThornsTrait` の `InReaction` と同じ形のガードを置く。
- **順序はスロット昇順。** 決定的にする。
- **傷は消費しない。** 倒れた敵の傷はどのみち消える。
- **敵側には効かせない**（敵に `Wound` を書く駒がいない想定。**Phase 0 で 0 件を確認する**）。

### 1-4. 手番の中身を切り出す（**先に、単独でコミットする**）

`BattleEngine.Run` の行動順ループ（`foreach (UnitState actor in order)` の中）に、
**痺れ／まどろみ／`CurrentAction`／`CanAct`／`PerformAttack`／`Charge`／`OnAction` の分岐が
インラインで書かれている。** 再行動から同じ分岐を呼ぶには**メソッドに切り出す必要がある。**

> **切り出しだけを先にコミットし、`compare` 305 セルが 0 件であることを示してから
> `EncoreRule` を足す。**（第90期の毒の窓口・第93期の傷の窓口と同じ作法。）

**`ActionIndex` の扱いを Phase 0 で確認する**——`ActionIndex++` は `CanAct` 通過後という規則があり、
**再行動で周期が二重に進まないか**を確かめる。

## 2. Phase 0

### 2-1. 事実の確定（**戦闘0回**）

1. **`Wound` を呼んでいる箇所の全数**と、それぞれの `WoundRoute`。
   **指示書の記述を信用せず数え直すこと**（手作り一覧のずれが第84・85・90・92・93・95・98期で **7例**）。
2. **傷を減算・上書きしている箇所の全数**（断ち＝0 に戻す／縫い＝1 引く／継ぎ当て＝1 引く）。
   **記録を消す位置をここに揃える。**
3. **敵側に `Wound` を書く駒がいないこと**（0 件）。
4. **`ActionIndex` の進み方**（§1-4）。
5. **死亡の処理の並び**——`OnKill → OnDeath → OnAnyDeath → OnAllyDeath` の順序が
   `SplitterTrait` の doc に書かれている。**再行動をどこに挟むか**を決めて理由を書く。
6. **`TraitKeyMap` / `TraitEntryMap` の更新**（`EncoreRule` は engine の規則なので `TraitId` は増えないが、
   **キリ・ノミが「撃破を読む」側に回る**）。**`derive scan`（第94期）の観測で照合する。手で書かない。**

### 2-2. 門（**鎖が繋がっているか。大きさではない**。規約 (G7)）

> 1. **傷を刻まれた敵が倒れた回数/戦**（波別）
> 2. **そのとき生存していた刻み手の数**（0 なら再行動は起きない）
> 3. **再行動が実際に行動した回数**——痺れ・まどろみ・`CanAct` 偽で潰れた回数も別に数える
>
> **3つとも 0 より大きいことを確認してから 2×2 を回す。**
> **どれかが 0 なら、そこが切れている場所を書いて閉じる。**

### 2-3. 紙のスループット（**門ではなく出力**。規約 (G7)）

    再行動由来の出力/戦 = 再行動の回数 × その駒の1手番あたりの平均出力

**分子について3つを先に書く**（規約 (G7)）——**線形か二次か／門ではなく出力／分母を削るか**。

> **キリは攻1、ノミも同格なので、紙は極めて小さく出るはず。**
> **それでも主判定が通るなら、「手番そのものに値段がある」ことになる**
> ——第103期の「代金は手番で払われる」の裏返しで、**同じ通貨を今度は払い出し側で見ることになる。**

### 予測（**測る前に書く。駒を数えて書くこと**）

- **意図した相手は「仕留める力を持つ駒」と「餌を供給する駒」。**
  **ドルガ（攻38・薙ぎ）／ハギ（追い打ち）／ボルグ（薙ぎ）／トメ（標を倍で殴る）／ソム（餌）の5枚。**
- **損の側は「傷を消す駒」。** **断ちのナタ（0 に戻す）／縫いのハリ（1 引く）／継ぎ当てのノノ（1 引く）。**
  **傷が消えると記録も消えるので、再行動の機会が奪われる。**
  **符号が負であること自体が、機構が意図どおり働いている証拠になる。**
- **ノミがキリより効く可能性がある。** 執着（`FixateTrait`）で1体に食いつくので、
  **同じ敵に刻み続けて仕留めやすい。** 第87期・第91期はどちらも「傷を持つかの二値」で
  キリが有利だったが、**この機構は「刻んだ敵が倒れる」ことを要求する**ので向きが変わりうる。
  **第93期に「深手はノミだけが作れる」と予測して外している**ので、**今度は実測で確かめる。**
- **紙は小さい。** キリ攻1・ノミ攻2 なので、再行動 3回/戦でも数点。**外れたら書く。**

## 7. 申し送り（**第105期の入口**）

- **手番の値段を測る器具が無い**（第103期の申し送り）。
  第103期は「代金は手番で払われる」、この期は「払い出しも手番」。
  **庇い・標・拘束・ターンギフトが全部この通貨に乗る**ので、1本あると以後ずっと効く
- **ムグ**: 「誰に倒されたかで湧く先が変わる」——敵に倒されたら敵陣（餌）、味方が処理したら味方陣（壁）。
  `OnDamaged` は `source` を持ち、**味方がムグを叩く経路は6本以上ある**（第85期の巻き込み則）
- **単発と会戦が逆を向く**（第98期以降4例目）。第103期のソムは
  2×2 で 1位 +21.95 なのに**会戦では突破波数 1.80 → 1.57・全滅勝ち 30.0 → 50.9%**。
  **代金が手番で払われ、会戦は損害を持ち越すため**
- **アセット**: **ロスター 52 枚が確定済み。** ムド・ノノ・ササ・ハリの4枚は役割が未確定、
  **残り48枚は名前・1文・捨てられた理由が確定**。`docs/units.md` が正
- **未着手**: 傷軸の (c)(d) ／泥仕合（爆発が1枚の中で閉じている）／
  複数部隊・可変サイズ・作戦層（`design/IDEAS_PENDING.md`）
