### 実装の形（測る前に固定）

- `InverseTrait.IncludesSelf`（`const bool`・**既定 true**）。`AdjacentHolder` に「保持者自身」を足す——
  **`h == u` かつ `IncludesSelf`** なら返す（隣接の判定は今までどおり）。反転と反転の裏の両方がこの1本を通る
- **第191期の版（`IncludesSelf = false`）は `const` なので、一度そのまま組んで回し（`beni run` / `ledger` / `check`）、戻して回す**
  ——受け入れ 1 の「偽で第191期の表と一致」はこのビルドで取る
- 離れた後の刻み（`NoteTaintPostBite` / `NoteKindlePostBurn`）はベニ自身を数えない（隣の味方の帳簿なので）
- 計数: ベニ自身が受けた反転の回復（毒・燃焼・起爆）と、反転の裏でベニ自身が受けたダメージ（出どころ別）を足す

## 実装（予測のコミットの後）

- `InverseTrait.IncludesSelf`（`const bool`・**既定 true**）。`AdjacentHolder` は「生きている・同じ陣営」の保持者について、
  **相手が保持者自身なら `IncludesSelf`、それ以外なら `AreAdjacent`** で返す。呼び出し口は反転（`InvertsTick`）と反転の裏（`Heal`）の2本だけで、
  **手番の配り先（`KindleTrait` / `TaintTrait`）は自前の `a != self` のまま**
- 計数だけ足した: ベニ自身が反転で癒えた量（毒・燃焼・起爆）／ベニ自身が反転の裏で受けたダメージ（保持者の側と、出どころの側）
- 離れた後の刻み（`NoteTaintPostBite` / `NoteKindlePostBurn`）は**書き換えていない**——ベニ自身は配り先に入らないので、
  「ベニが配った層・火」の印（`HeldKey`）を1度も持たない＝最初から数えられていない（Q0-1 に「除く」と書いたが、手を入れるまでもなかった）
- `units.md` の文面は指示書の案のまま（「自分と隣接する味方は…」）。`Run` の引数は増やしていない

### 第191期との一致（受け入れ 1）

**`IncludesSelf = false` で一度組んで回した**——`compare` は `docs/balance.md`（第191期）と **0 行差分**、`beni run` の出力は第191期の `beni run` と
**1文字も違わない**。そのビルドで第191期側の数字（下の表の「191」）を取り、`true` に戻して回した。
`beni check` の (b)（ベニを第190期の定義に戻す）は、`IncludesSelf` がビルド全体に効くので `true` のビルドでは意味を持たない（7 / 305 件ずれる）。
