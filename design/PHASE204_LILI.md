### Q0-2 吸い取りのダメージの入口

- 術のダメージの前例は **紅蓮の直撃（`GurenStrikeTrait`・`ctx.ApplyDamage(foe, share, self)`）** と破裂（ゾト）。どれも `PerformAttack` を通らず `ApplyDamage` を直に呼ぶ。吸い取りも同じ形にする（`source` = リリ、`pattern` = null）。
- **効かないもの**: 庇い・後備え・殉教・標的の横取り（どれも `SelectTarget` の段なので通らない）／ 受け流し（ガルドの味方側の段。敵には無い）／ 逸らし（`pattern == Single` のときだけ）／ **呪いの共有**（`singleHit` が偽なので起きない）／ 反撃（敵の反応札は断罪 `Condemn` だけで、`InReaction` のときしか動かない）。
- **効くもの**: 敵の破片（HP の前に削られる）・軛の上限（第四波は1回 25 まで）・§1 の敵の標の +50%（「相手陣営の出どころ・刻みでも徴収でもない」に当たる。ソラ・ザンの標が敵に載っている行だけ）。
- 撃破者はリリになる（`OnKill` はリリの札に無い）。

### Q0-3 状態キーの分類（`lili phase0`・`StatusKeys.All` 21 本を全部当てた・抜け 0 件）

- **移す 14 本**: 毒・標・痺・燃・破片・傷・深手・呪・転倒・混乱・竦み・萎縮・濃縮・痺れ毒。

  - `ward` / `debt`（保持者の内部の残高。持ち主と対でしか意味が無い・保持者 0 枚）
  - `ash` / `footing` / `guren`（保持者の内部の燃料・層。敵には載らない）
  - **`grappled`（組み付き）** —— ほどくのは組み付いたクグの記憶だけで、味方に移すと誰もほどけず永久に手番を失う

- **重ね方**: 量のキー（毒・傷・濃縮・破片）は足す。燃焼は残りターンの大きい方（**`Ignite` は通さない**——残りを 3 に上書きするので複製になる・第49期）。二値のキーは大きい方。

- 特性の内部カウンタ（`belly`・`goadTarget`・紅蓮の `gurenHeld` など）は `StatusKeys` に無いので最初から移さない。

### Q0-4 状態の「書き手」を読む箇所

- **毒と燃焼には駒の側に書き手の記録が無い**。書き手は書いた瞬間の計数（`SoakPoisonWrites` など）と台本の `StatusGain.ActorId` にしか残らず、刻みは出どころ null で走る。だから「書き手は元のまま」は構造的に成り立つ（移しても誰も書き手を読み直さない）。
- ベニの結界（反転・啜り・紅蓮）は「隣にベニがいるか」だけを見て書き手を見ない。ラウの伝染も層の数だけを見る。痺れ毒の印の値（1 吐き ／ 2 殴られ）は計数の帰属用で、大きい方を取るので残る。
- 紅蓮の計数用キー（`gurenHeld` など）は敵に残る（計数だけで規則は読まない）。

### Q0-5 呪いの攻撃力低下とウツ

- ネルの「呪い持ち全員 −4」は **`ctx.Dull`（`AtkBonus`）**で、状態キーではない。`Curse` キー（0/1）は呪いの共有（ムドの段）と「まだ呪われていない敵」の選別にしか使われない。
- ウツが読むのは受けた弱体（`Dull` の量）。**移すのは状態キーだけなので、ウツとの組み合わせは成立しない**（ウツが呪いを受け取っても攻撃力も手数も増えない）。

### Q0-6 `MostHurtAlly`

- 自分を除き、`AcceptsSupport` が偽の駒（ガルドの `Stoic`）を**飛ばし**、HP 割合が最小の味方を返す。同値は `PickOne`（候補 1 以下なら乱数を引かない）。**全員満タンなら null** → 指示書どおりリリ自身が受け取る。
- だから**リリ自身は、ほかの味方が全員満タンのときしか受け取らない**（自分がどれだけ傷ついていても）。

### Q0-7 粛と「祝福が還る」

- 粛が止めるのは `CanActOutOfTurn` を通る 8 本だけ。墓守（リィカ `OnAnyDeath`）・還し（ゴルム）など既存の「死亡時の回復」は通らず、粛に止められない。**祝福が還るもそれに揃え、粛では止めない**。渇きは `Heal` の入口で止まる（溢れにも数えない）。

### Q0-8 破片の上限・減衰が無い前提

- `StatusKeys.Armor` の doc は「供給源がヒビだけ」と書いているが、**実装では既に4本ある**——砕け（ヒビ `ShatterTrait`）・引き受け（ウケ・`Dull` の中）・身構え（ササ `BraceTrait`）・鱗（ウロ `ScaleTrait`・倒れた味方から）。消費する側は `ApplyDamage` の破片の段と、礫（ガレ `ShrapnelTrait`・最大保持者を砕いて 0 に）。**リリは5本目**になる（doc の文は第138期から古い・R151 の再発）。
- 上限を前提にした**コード**は無い（コメントだけ）。

### Q0-9 過去の類似

- 「サキュバス」「ドレイン」は `design/` に指示書以外 0 件。**状態を移す**前例は業のゴウ（第49期・棄却）——味方から自分へ状態のカウンタを 1 ずつ取り上げる。除外の作法（`Armor` / `IdleTurn` を外す）と「燃焼を `Ignite` に通さない」はここから引いた。
- 回復の余りを別の資源にする前例は啜り・紅蓮（第193・197期）。溢れの定義（`Healed` / `Full` のときだけ）はそこに揃える。

## 1. 予測（実装前に宣言）
