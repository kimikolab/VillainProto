# 第291期 指示書 —— 試遊の準備（感電軸・標軸）：入口・プリセット・演出用の台本

この指示書は自己完結している。リポジトリ（`design/` の過去報告・`docs/`・コード）以外は参照しないこと。

## 0. 目的

ポンが DemoApp で**感電軸と標軸（ミサを含む）を実際に触って**、改善点を探す。そのための準備をする。

1. **入口**: デモの波の選択に **ボス規定形・近衛・大隊** を足す（今は本編の波と検証の波しか選べない）
2. **試遊プリセット**: 第283〜290期で見つかった台を、デモのプリセットから一発で呼べるようにする
3. **演出用の台本**: 第279〜290期に足した機構の多くは `BattleEvent` を出していない（蓄電・割り込み・雷雲・羽・爪痕・標の層・糸）。**表示専用のイベントを足し**、Codex 向けの台本メモを書く

**盤面（勝敗・数値）は1ビットも変えない。** 規定の駒も変えない（段0 を除く）。

## 2. 段1 —— 入口：デモで選べる波

- デモの波の選択（`Main.cs` の `_stagePicker`）に3つ足す: **ボス規定形**（`EnemyCatalog.BossRegularWave`・第269期）／ **近衛** ／ **大隊**（第284期の精鋭・素の構成 × HP 1000% ／ 攻 300%）
- **定義は1箇所**: 近衛 ／ 大隊の定義はいま `BattleSim/Modes/Elite.cs` の中に閉じている。DemoApp から引けるよう `BattleCore` 側へ移し、`elite` 器具もそれを読む形にする（`TestStages` には足さない——`nine check` が「3本」を門にしているため。第284期の判断のまま）
- ボス規定形と精鋭は `Formation` ではなく `EnemyWave` ＋ スケールで回る。デモの戦闘の起動口が `Formation` 前提なら、`EnemyWave` を受ける口を足す（盤面の入口は `BattleEngine.MaterializeEnemy` ＋ `Run` の UnitState 版・第283期 `FightLite` と同じ）
- 名前の表示: 「ボス・勇者（規定形）」「精鋭・近衛」「精鋭・大隊」
- 門: `elite check` ／ `boss283 check` が移した後もバイト一致。デモでその3つを選んで戦えること（頭なしの起動口があればそれで1戦ずつ確かめる）

## 4. 段2 —— 演出用のイベント（表示専用）

### 4-1. 原則

- **表示専用**: 盤面に触らない・乱数を引かない。保持者がいない戦では1件も出ない（比較1つで抜ける）
- **新しい種類は `BattleEventKind` の末尾に足す**（既存の番号を動かさない・第214期と同じ）
- 既存のイベントで足りるものは足さない。**まず Phase 0 で「欲しい絵 → 今ある台本」の表を作る**

### 4-2. 欲しい絵と、要る情報（Codex 向けメモ `design/CODEX_BRIEF_SHOCK_MARK.md` と対）

| 駒・機構 | 欲しい絵 | 台本に要る情報 |
|---|---|---|
| シガ・蓄電 | 纏う電気が蓄電 0〜4 で段階的に増える | 蓄電が変わった瞬間（シガ・新しい値・増えた／使った） |
| シガ・割り込み | 感電が弾けた直後、シガが割り込んで鞭を振るう | 割り込みの始まり（シガ・主目標・合図になった連鎖）と、その鞭が割り込みであること（`Attack` に印か、前置きの1件） |
| シガ・怖気 | 怖気づく（既存なら不要） | 既存を確認 |
| カタ・雷雲 | 雷雲が育ち、落雷が太く大きくなる | 雷雲が変わった瞬間（カタ・新しい値）、`Thunder` の時点の雷雲 |
| トウ・粉 | 粉が主目標と隣の敵にふわっと舞う／隣の味方に漏れる | 既存の `StatusGain`（`shock`・書き手 トウ）に「主目標／隣の敵／漏れ」の区別 |
| クグ・糸（段0 を採った場合） | 組み付いた糸を電気が走る／ほどける瞬間に電気が駆け抜ける | 糸を伝った放電であること（`Discharge` に印）・ほどける一撃の中か |
| ミサ・羽 | 羽の枚数＝在庫が周りに浮く／標を追って1枚ずつ飛ぶ／倒したら次の標へ流れる／標が尽きると乱射／撃ち出した羽は戻らない（M-b） | 羽の枚数が変わった瞬間（増えた／失った）・連射の始まり（発数）・1発ごとに「追う／流れた／乱射」と何発目か |
| ミサ・爪痕 | 削った分だけ最大HPが恒久的に縮む（塞がらない傷） | 最大HP が変わった瞬間（対象・減った量・新しい最大HP） |
| 標の層 | 敵に付いた標の層（ロックオンの数）が見える | 層が変わった瞬間（対象・新しい層の数・書き手） |

### 4-3. 台本の指紋

表示専用のイベントを足すと、**その駒がいる台本の指紋は変わる**。
- 変わった指紋の本を一覧にし、**勝敗・数値が変わっていないこと**（`compare` 全セル 0 件・該当の器具の数値の出力が一致）を確かめてから封印し直す
- 無関係の台本（その駒がいない本）の指紋は一致すること
