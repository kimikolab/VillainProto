## 0. 主題

### 0-1. 3期が同じ形の式を出している

| 期 | 式 | 実測 |
|---|---|---|
| **第75期** | 帰属 = **解除率 × 単価** | 与ダメ/振 が解除率の完全な線形関数（予測 4.88 対 実測 4.893）。単価は接続先によらず 0.175〜0.190 pt/% |
| **第77期** | 帰属 = **在庫率 × 単価** | 0.326 × 3.24 = 1.06（実測 +1.05 / +1.06） |

> **帰属は「頻度 × 単価」に分解でき、単価は設計で動かしにくい。動かせるのは頻度のほう。**

### 0-2. 第76期の第1識別量に、この式を当てる

第76期: **勝敗を決めているのは数値ではない**（数値を ±5% で揃えても勝率は 30.7pt 散る）。
**上位25%と下位25%を分ける第1の量は「特性の総数 +1.24枚」**（以下 被弾 +0.80・移動 +0.57・相方あり率 +0.16）。

**仮説**: 特性が多い駒が強いのは、**入口が多いぶん在庫率が高いから**——
**第77期の分解（`AtkBonus` は入口2本・`WhetReceived` は入口1本で、在庫率 32.6% 対 100%）**がそのまま説明になる。

> **問い: 「特性の総数」は在庫率の代理変数か、それとも単価の話か。**

ロスターの分布（Phase 0 で検算すること）: **特性1つが 38 体・2つが 12 体・4つが 1 体。平均 1.29。**
**「+1.24枚」はこの分布の上ではとても大きい差**（平均の 96%）。

**数えるだけ。設計判断をしない。採否も無い。**

### 0-3. なぜ最後の1枠に直結するか

**在庫率なら「入口が多い駒」を作る。単価なら「単価の高い駒」を作る。仕様が正反対になる。**
第71期の対応表を壊した反省（**壊れた器具の出力で次期の仕様を決める表を書いた**）があるので、
**この期の判定が壊れた場合の分岐も先に書く**（§5-2）。

1. **ロスターの特性数の分布を数え直す**（51体）。**指示書の当たり（1つ38体・2つ12体・4つ1体・平均1.29）を検算する**
2. **「特性の総数」を分解できる形に定義し直す。** 少なくとも3つに分ける:
   - **発火口の数**（その特性が反応するイベントの種類。`OnTurnStart` / `OnAfterAttack` / `OnDamaged` / `OnDeath` / `OnMoved` / `ModifyXxx` / `OnAction` ほか）
   - **入口の数**（その駒の出力を成立させる**外部の供給**が何本あるか。第77期の `AtkBonus` = 2本 / `WhetReceived` = 1本）

   **どれかが 0.9 を超えるなら、それは「特性の総数」の言い換えなので、回帰に両方入れない**
4. **第76期の識別（上位25%/下位25%）を再現する**。**器具の検算**——再現しなければ以降は測らない
5. **N と M**: 第76期と同じ（11,000 標本 × 弱い波 × seed 8本・規則配置 H・Pw）。**同じ標本を使う**
6. `docs/balance.md` の現在値を控える（**61 行 × 5 波 = 305 セル**）

## 2. 作るもの（診断だけ）

診断 `traits`。**既存モードは書き換えない。engine も `Traits.cs` も駒も波も触らない。**

### 2-1. 駒ごとの3つの数え方（**測る前に定義を固定**）

| 量 | 数え方 |
|---|---|
| **発火口** | その駒の `Trait` が override している仮想メソッドの種類数（`OnTurnStart` / `OnAfterAttack` / `OnDamaged` / `OnDeath` / `OnMoved` / `OnAction` / `ModifyAttack` / `ModifyPattern` / `ModifyIncomingDamage` ほか）。**リフレクションで数えず、表を手で作って `TraitKeyMap` と同じ場所に置く**（第70期の集約と同じ理由——写しを増やさない） |
| **入口** | その駒の出力が**外部の供給に依存する場合の、その供給元の種類数**。依存しない駒は **0**。第77期の定義（`AtkBonus` は軋み＋Whet の2本）に揃える |
| **キー** | `TraitKeyMap.KeysOf`（第68期以来） |

**「入口 0 の駒」＝自足した駒。** 第77期でヨミは**自足ではなかった**（自分では動かない）ので、
**入口 0 が本当に何体いるかをここで初めて数える。**

### 2-2. 測り方

1. **回帰**（第76期の器具をそのまま使う）: 標本の勝率を、
   **特性の総数 / 発火口 / 入口 / キー** の4つ ＋ 第76期の数値群 で回帰し、**群を1つずつ落として R² の低下**を見る
2. **統制した比較**（§3 Q3 の本体）: 標本から**特性の総数が同じで入口の数が違う組**、
   および**入口の数が同じで特性の総数が違う組**を抽出し、勝率を比べる。
   **抽出できる組が 100 標本未満なら「測れなかった」と書く**（第64期の「測れない席」と同じ扱い）
3. **単価の分解**（§3 Q4）: 駒ごとに **在席時の帰属 ÷ その駒の入口の数**。
   **入口 0 の駒は分母 0 なので別扱い**（自己検査 (b)）

### 2-3. 台

**ドラフト台 Pw**（主）と**理想61行**（比較）。**第76期の標本・seed 帯をそのまま使い、再現を最初に確認する。**

## 3. 判定基準（**測る前に**報告書へ書く）

採否は無い。判定は「答えが出たか」だけ。

| # | 問い | 判定 |
|--:|---|---|
| **Q1** | **在庫率か単価か（主判定）** | 回帰で**入口の数の説明力が特性の総数を上回る**なら在庫率。**下回るなら単価または別の何か。** 両 seed 帯で順位が一致すること |
| **Q2** | 4つは別の量か | 相関行列。**0.9 を超える組があれば「同じ量」と書き、以降その組は片方だけを使う** |
| **Q3** | 統制した比較 | §2-2 の2種類の組。**特性の総数を揃えて入口だけ振ったときの勝率差が 3pt 以上**なら入口が効いている。**逆向きの組でも同じ差が出るなら、効いているのは両方** |
| **Q4** | 単価は一定か | 入口1本あたりの帰属の分布。**変動係数が 0.5 未満なら単価はほぼ一定**（＝設計で動かせるのは頻度だけ・第75/77期の再現）。**0.5 以上なら単価も設計対象** |
| **Q5** | 入口 0 の駒 | **何体いるか。**その駒たちの在席時勝率は上位か下位か。**0 体なら「このロスターに自足した駒は存在しない」と書く**（第77期の示唆の検証） |
| **Q6** | 台の比較 | ドラフト台と理想61行で順位が一致するか。**割れるなら「入口の数が効くのはドラフト台に固有」** |
| **Q7** | 無関係 | `compare` **305 セル 0 件**・`docs/` 差分 0 行（8ファイル全部を再生成して確認） |

### 判定式の自己検査（**7項目**・各判定に1行ずつ）

(a) 分母の割合／(a') 分布の上で確かめる（**0% の標本が多いので、回帰は 0% を含む版と除いた版の両方**）／
**(b) 条件が真になる盤面は存在するか、かつ その量は 0 以外を取りうるか**
（**Q4 の「入口1本あたり」は入口 0 の駒で定義できない。分母 0 を先に除外して分母を明示する**）／
(c) 実効レンジ／(d) 機構か台か／(e) 未固定の選択肢（**定義・台・標本・seed 帯は §1〜§2 で固定**）／
(f) 判定が壊れていた場合の分岐（§5-2）

## 7. 申し送り（**後の期で誤って引かないための固定**）

- **第66期の「自分で作れる値を条件にすると起動スイッチになる」は前提が誤り**（第77期）。
  **ヨミは自分では動かないので `AtkBonus` も外部供給。**測っていたのは**条件の入口の広さ**だった。
  **一般則として残るのは第67期の「粒度は値の時間分布が決める」だけ**
- **帰属 = 頻度 × 単価**（第75期は解除率・第77期は在庫率）。**単価は設計で動かしにくい**
- **外部供給は単価が高く在庫率が低い**（第77期。同席した 32.6% の中では外部が 1.5〜1.6 倍強い）
- **ヨミは第66・67・77期で3回棄却。以後提案しない**
- **勝敗を決めているのは数値ではない**（第76期。数値を ±5% で揃えても 30.7pt 散る）
- **代金の改修は解除率にしか効かない。形の良し悪しは値段に現れない**（第75期）
- **通貨は読み手の消費対象であると同時に書き手の前提条件でもある**（第75期）
- **`docs/` は8ファイルすべて再生成する**（第74期）／**器具の分割は過去の対照も壊す**（第74期）
- **帰属の標準器具は素体差し替え**（第69期）／**`reseat` は帰属の器具ではない**（第64期）
- **Phase 0 に紙の計算を必ず置く**（第71期）
- **判定式の自己検査は7項目**（(a)／(a')／(b) は「0 以外を取りうるか」まで／(c)／(d)／(e)／(f)）
