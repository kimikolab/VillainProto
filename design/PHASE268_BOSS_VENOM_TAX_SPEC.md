# 第268期 指示書 —— 勇者を D-40 で確定・毒の解答「蝕み」

読み手は Claude Code。第267期（癒し手・条件3で不採用）の続き。器具 `bosswave`・7台・seed 0..199 はそのまま。

## 0. 位置づけ

3期（265〜267）の結論:

- **癒し手構造は廃案**。2回試して2回同じ死に方（範囲で即割れ → 波ごと易化）。対照残置
- **D-40（勇者1体・全体・HP 3,000・天井 +11・速 14・動じない・自前回復40%）が毒以外の5台で成立している**。制御は守りと速攻の選択、燃焼は速攻、連続量は分化。一番単純な形が正解だった
- **毒の 0% はボスの欠陥ではなくロスターの既知課題**（第264期: 毒軸に削り勝ちの形が無い）。ボスの構造で駒の穴を埋めない

ただし駒を足さずに、**波側に毒の読み手を置く**手が残っている。毒の桁（出力 123〜273/窓）では回復 1,200/ターンを削りでは上回れないが、封じるなら層の数だけでよい:

**蝕み: 勇者の毎ターンの回復は、勇者に積まれた毒の層 × N だけ減る（下限 0）。**

毒軸の個性（層を積んで縛る）がそのまま解答になる。中核規則（庇い・標的は Single のみ）には触れない。フレーバーも立つ——勇者は剣では倒れないが、毒には少しずつ蝕まれる。

## 1. 決定

1. **勇者の規定形を D-40 で確定**（第266期の対照そのまま）。以後のノブはこの形への札の追加だけ
2. **蝕みを札1枚で足す**。勇者の回復（自前40%・`ctx.Heal` 経由）を、回復が入る直前に「毒の層 × N」だけ減らす。毒の層そのものは消費しない（刻みは従来どおり別に入る）
3. 癒し手・不屈は廃案で閉じる（問い1の決着）

## 2. Phase 0

1. **毒の層の仕様確認**: 層の積み方・上限・減衰の規則。勇者（1体・HP 3,000）に毒台・雷台が1戦で積める層数の実測（第266〜267期の計数から引けるはず）
2. **机上計算（R362 の4段）**: 層数の実測 × N 候補で、回復がどこまで減るか。**「回復ゼロに届く N」と「半減止まりの N」の2点**を先に出し、§3 の版の値をそこから決める（指示書の候補値 N=30/60 は目安。机上が別の値を出したらそちら）
3. **実装点**: `ctx.Heal` の手前で減算する窓口があるか（渇きの実装が同じ場所のはず）。蝕みが渇き（第三波）と同じ経路なら、既存の封じとの重複発火がないことを確認
4. **毒を持つ台の棚卸し**: 7台のうち毒の書き手がいる台（毒2台・雷のミオ・ほか見落としがないか）。蝕みの恩恵が及ぶ範囲を予測の前に確定する
5. 蝕みの減算がログ・計数（純実入り・回復量）にどう出るか（報告で「蝕みで減った回復量」を台ごとに出せること）

## 3. 版

| 版 | 蝕み N | 意味 |
|---|--:|---|
| V-0 | なし | D-40 そのまま（第266期の既測を併記・再測不要） |
| V-半 | 机上で「回復半減」に届く値 | 毒は補助（削りの底上げ） |
| V-封 | 机上で「回復ゼロ」に届く値 | 毒は解答（層を積み切れば封じられる） |

## 4. 測定と採否

- 7台 × 2版（V-半・V-封）。指標: 連続量＋**蝕みで減った回復量**・勇者に積まれた層の推移・勝率
- 採否:
  - **毒2台の勝率 > 0**（V-封 で）になり、勝ち筋が「層で回復を削いでからの長期戦」であること
  - **毒を持たない台（燃焼2・移動・混ぜ）が V-0 から動かない**こと（±0 の回帰。動いたら層の混入を疑う）
  - 雷（ミオ）が中間の恩恵を受けること（部分的な層で倒しTが縮む——蝕みが0/1でなく勾配で効いている証拠）
  - 既存5波 305 セル 0 件・再現系全行一致

## 5. 予測（Phase 0 の机上で数値を足す）

- **毒2台**: V-封 で 0% → 正。層を積み切るまでの序盤（回復が生きている間）を耐えられるかが勝敗線。「耐える毒」（毒+ベニ+ラウ）の方が序盤に強く、勝率も上のはず
- **雷**: ミオの層で回復が部分的に削がれ、倒しTが V-0 より縮む。勝率は元から高いので連続量にだけ出る
- **燃焼2・移動・混ぜ**: 完全に不変（毒の書き手ゼロ）
- V-半 で毒が 0% のままなら「蝕みは0/1でしか効かない」証拠として記録し、N の勾配設計を見直す
