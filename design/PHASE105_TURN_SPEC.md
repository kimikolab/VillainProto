# 第105期 —— 手番の値段を測る

起点: 第104期（刻み手の再行動を採用・傷軸8行中6行が動いた・
**A ＝ ノミでは機構が効きすぎて床が 7.42 に上がり主判定が届かなかった**・
**指示書の「キリもノミも与ダメ 1〜2」が誤りで、ノミの実測打点/振は 10〜21**）

**この期は盤面を1ビットも動かさない。** 駒・特性・数値・engine の判定・境界の規則に触らない。
**作るのは器具だけ。**

**この指示書は自己完結させてある。** リポジトリの外にある文書を参照しないこと。

## 0. 主題

### 0-1. 3期連続で同じ通貨が主題に出ている

| 期 | 何が起きたか |
|---|---|
| **第103期** | ソムの代金は「本物の敵に当たらない**手番**」。**支払者は通常攻撃を振る駒だけ**で、
上位3枚は**手番で殴らない駒**だった（ハギ `CanAct => false`／カド `Immobile`／ヒヨ `Actions = [Skill]`）。
該当5枚の順位は 1/2/3/13/16（一様なら平均26のところ 7.0） |
| **第104期** | 払い出しが**手番**。刻み手が再行動して傷軸8行中6行が動いた |
| **第104期** | 指示書が「キリもノミも与ダメ 1〜2」と書いたが、**ノミの実測打点/振は 10〜21**。
**上限を付けない根拠の1つが崩れていた**（手作りのずれの8例目） |

**そして手番の値段を測る道具が無いまま、採否を決めている。**

第86期の稼働率（発火 ÷ 決着T）が 35〜40% に張り付く、第93期は 70.6% でも拒否権が2本立った、
`TURN_SLOT_PLAN` の「味方46体中30体が素の通常攻撃しか振らない」——
**手番の話は何度も出てくるのに、駒ごとの値段が1度も出ていない。**

### 0-2. 作るもの

**駒ごとに、手番がいくつ回ってきて、何に使われて、いくら生んだかを出す。**

そして**駒を2つに分ける。**

| 型 | 意味 |
|---|---|
| **手番型** | 出力の大半が**自分の手番**から出る |
| **手番外型** | 出力の大半が**手番の外**（`OnTurnStart` / `OnDamaged` / `OnAnyDeath` / 反撃・割り込み）から出る |

**この分類が、そのまま機構の設計に効く。**

- **標的プールを増やす／減らす機構は、手番型にだけ課税する**（第103期）
- **再行動を配る機構は、手番型にだけ払い出す**（第104期）
- **ターンギフト・庇い・拘束・回避も、全部この通貨に乗る**（`design/IDEAS_PENDING.md`）

### 0-3. 通貨を1つに換算しない（**測る前に固定**）

**与ダメージ・回復・状態異常の書き込みを、1つの数に混ぜない。**
換算率を発明すると、その率が後から効いてくる。**通貨ごとに別の列で出す。**

「1手番あたり」も**通貨ごとに出す。**

## 1. 測るもの

### 1-1. 台

**`Presets.Compare` 61行 ＋ `Presets.Cross` 12行 × 5波 × seed 0..199。**
**約 73,000 戦。軽い。**

**規約 (G10) により、集計の分母は第2〜5波。第一波は「参考」として併記してよいが判定に使わない。**

### 1-2. 駒ごとに出す列

| 列 | 定義 |
|---|---|
| **手番数/戦** | その駒に手番が回ってきた回数（**再行動を含む**。第104期） |
| **稼働率** | 手番数 ÷ 決着ターン数。**第86期の 35〜40% 帯を再現するか** |
| **手番の内訳** | 通常攻撃 / 術（`Skill`）/ 溜め（`Charge`）/ **潰れた** の回数 |
| **潰れた内訳** | 痺れ / まどろみ / `CanAct` 偽 / 不動 |
| **売れた手番** | `Trait.SurrenderedTurn` が真になった回数（第103期の訂正どおり、生の counter ではなくここを数える） |
| **手番内の出力** | その駒の手番の中で生んだ 与ダメージ / 回復 / 状態異常の書き込み数 |
| **手番外の出力** | 手番の外で生んだ同じ3つ |
| **1手番あたりの出力** | 手番内の出力 ÷ 手番数（**通貨ごと**） |
| **手番外の割合** | 手番外の出力 ÷ 全出力（**通貨ごと**）。**§0-2 の分類はこれで決める** |

### 1-3. 分類の線（**測る前に固定**）

> **手番外の割合が 50% を超える駒を「手番外型」とする。**
> **通貨ごとに割合が割れる駒は「混合」として、どの通貨でどちらかを併記する。**

**線を引く前に、対照側の実測値を見ること**（規約 (G11)）——
**カド（`Immobile`・手番を全部捨てる）は手番外 100%、ドルガ（素の通常攻撃のみ）は 0% のはず。**
**この2枚が両端を作れなければ、器具か線のどちらかが間違っている。**

### 1-4. あわせて出す（**分類の材料**）

- **手番を1度も持たない駒**（ハギ `CanAct => false`）
- **手番の全部が潰れる駒**（カド `Immobile`）
- **手番で術しか撃たない駒**（`Actions = [Skill]` のみ）——現在3体のはず。**数え直すこと**
- **素の通常攻撃しか振らない駒**——`TURN_SLOT_PLAN` は **46体中30体**と書いている。
  **ロスターが52枚になったので数え直す**

## 2. Phase 0（**戦闘0回**）

1. **既存の計数（`UnitTally`）で何が取れるか**を全数で列挙する。
   **足りないものだけ足す。** 足した計数は**版に依らない**こと
   （`BetrayRule` / `EncoreRule` / `DeepRule` などの既定を変えても値が動かない）。
2. **手番の中と外をどこで切るか。**
   第104期に `TakeTurn` を切り出しているので、**その中が「手番の中」**。
   **`OnTurnStart` は行動順の外**（`BattleEngine.Run` のコメントに明記）なので**外**。
   **反撃・割り込み（`InReaction` / `InInterrupt`）も外。**
   **境界を決めて報告書に書くこと。**
3. **`ApplyDamage` の `source` で出力を帰属できるか。**
   帰属できない経路（毒・燃焼の刻み・共有・境界）を列挙し、**「誰のものでもない出力」として別に数える。**
4. **再行動（第104期）が手番数に入ること**の確認。
5. **`SurrenderedTurn` の読み方**（第103期の訂正）。

### 予測（**測る前に書く。駒を数えて書くこと**）

- **カドの手番外の割合は 100%、ドルガは 0%**（§1-3 の対照）。
- **手番外型は少数のはず。** `TURN_SLOT_PLAN` の「46体中30体が素の通常攻撃のみ」が正しければ、
  **ロスターの過半は手番型。** ただし**あの数字は第43期のもので、ロスターは52枚になっている。**
  **数え直した結果が違っても不思議ではない。**
- **1手番あたりの与ダメージは、ドルガ（攻38）とキリ（攻1）で 38 倍開く。**
  **ノミは 10〜21**（第104期の実測）。**この3枚が再現できなければ器具が間違っている。**
- **稼働率は 35〜40% 帯に集中する**（第86期）。**第104期の再行動で刻み手だけが上に外れるはず。**

## 3. 判定

**この期は機構ではないので、採否ではなく「器具として使えるか」を判定する。**

> **Q1（既知の値の再現）: 次の5つを再現すること。**
> **新しい器具は既知の値を再現できて初めて使える**（第94期の第一版は欠落 105 件のうち
> **78 件が器具自身の誤り**だった）。
>
> 1. **ノミの1手番あたりの与ダメージが 10〜21**（第104期）
> 2. **キリの与ダメージが常に 1**（`ThinBlade`）
> 3. **ハギの手番数が 0**（`CanAct => false`）
> 4. **カドの手番が全部潰れる**（`Immobile`）
> 5. **稼働率が 35〜40% 帯に集中する**（第86期）

> **Q2（両端）: カドの手番外の割合が 100%、ドルガが 0% になること**（§1-3）。

> **Q3（分類が使えるか）: 第103期の「上位3枚は手番で殴らない駒」を、この器具の分類が説明すること。**
> **ハギ・カド・ヒヨが手番外型に入り、薙ぎ持ち（ボルグ・ドルガ）が手番型に入ること。**
> **入らなければ、分類の線か通貨の切り方が間違っている。**

### 自己検査

- **(a)** **`compare` 305 セルが `docs/balance.md` と 0 件**（器具が盤面を動かしていない）。
- **(b)** **足した計数が版に依らない**こと（`EncoreRule` / `BetrayRule` の既定を反転させても
  計数が同じ値になる版で示す。**盤面が動かない台**を使う。第91期 (e) の直し方）。
- **(c)** **手番数の合計と、engine の行動順ループが回った回数が一致する**こと。
- **(d)** **手番内の出力 ＋ 手番外の出力 ＋ 誰のものでもない出力 ＝ 全出力**（取りこぼしが無い）。
- **(e)** `docs/` 10ファイルを再生成して差分 0 バイト。
- **(f)** `ctx.PickOne` の箇所数が第104期と同数。

## 6. 規約（**Q1〜Q3 が揃ったときだけ、`CLAUDE.md` に書く**）

> **(G14) 機構を設計するときは、その機構が課税する／払い出す相手が手番型か手番外型かを先に見る。**
>
> - **標的プールを増やす／減らす機構**（召喚・庇い・標・拘束）は**手番型にだけ課税する**（第103期）
> - **再行動・追加行動を配る機構**は**手番型にだけ払い出す**（第104期）
> - **被弾・撃破・死亡で発火する機構**は**手番外型にだけ払い出す**
>
> **予測を書くときは、意図した相手をこの分類で数えること。**

## 8. 申し送り（**第106期の入口**）

- **ノイズ床が2例目**（第96期 11.87・第104期 7.42）。
  **同じ実験の中の意図しない相手の 95 パーセンタイル**という定義は、
  **効果が広い機構ほど不利**になる。**第104期は A ＝ キリで通ったので採否は揺らがなかった**が、
  **3例目が出たら定義を見直す**
- **状態を消す駒が損になるかどうかは、消す前に読む機会があるかで決まる**（第104期。
  `SeverTrait` は `ApplyDamage` を先に走らせてから傷を 0 に戻すので、**記録が消える前に死が来る**）。
  **実行順序を先に読む**
- **分子が 1〜2 しか積まない通貨は、数を読ませず二値の鍵として読ませる**（第87期・第104期の**2例**）
- **単発と会戦が逆を向く**（第98期以降4例目）
- **アセット**: ロスター 52 枚が確定済み。ムド・ノノ・ササ・ハリの4枚は役割が未確定、
  **残り48枚は確定**。`docs/units.md` が正
- **未着手**: ムグの分裂／傷軸の (c)(d)／泥仕合（爆発が1枚の中で閉じている）／
  複数部隊・可変サイズ・作戦層
