## 0. Phase 0（実装前・盤面は第215期のまま）

`shock phase216`（4 秒）。Phase 0 のために足したのは**計数だけ**（`UnitTally` の `ThunderCastsT1` / `ThunderHitsT1` / `ThunderKindsT1` ＝ 1ターン目の雷、
`DeathTurnHist` ＝ 倒れたターンの分布）。`compare` は `docs/balance.md` と 305 セル全文一致。
あわせて**台本の指紋**（`shockdigest t216`・台A・台B・台C 参考 2 陣形・台1・台3 × 5波 × seed 0..19）をこの時点で取った——受け入れ 1 の「O0・S0 は第215期と台本が一致」の比較の相手。

### Q0-1 毒1の寿命・燃焼1

- **毒は刻みで減らない。** `TickStatuses` の毒のループは層を読むだけで、`SetCounter(StatusKeys.Poison…)` を書くのは
  窓口（`Poison`・加算）／ミオの旧濃縮（`AmplifierTrait`・上書きで増やす）／澱み喰いのヴィオ（味方の毒を 0 に）の3つだけ。
  **開戦の毒1は、倒れるまで毎ターン 1（× 濃縮の印の回数）刻み続ける**——2ターン目以降の雷の道にもそのままなる。
- **燃焼は量を持たない。** `Ignite` は残りターンを `BurnRules.Turns` = 3 に**設定**する（1回の刻み 6）。
  **O4 の「燃焼 1」は着火1回（残り 3 ターン・刻み 3 回）として実装する**——1ターン目から3ターン目の頭までの雷で種類 +1、4ターン目には消える。

### Q0-2 開戦時の順番

- 開戦の通知（`OnBattleStart`）は**速さの降順**、同速の群だけ `ctx.Shuffle` で混ぜる（行動順と同じ・乱数はこの撒きの有無に依らず同じだけ引く）。
- ベニは速 6。台と §5.3 に出る味方で開戦時に働く札は**クグの組み付き（速 10）とネルの呪い（速 9）だけ**（台A・B・C には出ない）で、どちらもベニより先に走る。
  同速 6 はカタだけで、カタは開戦時に何もしない。**撒きは誰の開戦時の効果とも前後で結果が変わらない**（毒を読んで分岐する開戦時の札が無い）。
- 敵の開戦時の札は 渇きの祭司（速 7・第3波）・粛の伝令（速 6・第2波）・軛の重装兵（速 3・第4波）で、どれもログを出すだけ（盤面ルールの判定は engine 側）。
- **グザの瘴気は `OnTurnStart`（グザは `Actions` を持たない）**——1ターン目の頭、行動順ループの前に敵全体へ毒 +2 を撒いている。
  **グザのいる台A・B では、開戦の撒きが無くても1ターン目の雷の前に敵は全員毒を帯びている**（下の表で 1T目の当たり/雷 5.00 / 4.50）。

### Q0-3 痺れの付き方

- 書く札は6枚（トウの痺れ・ザンの仇討ち・シガの責め苦・深追い・断罪・縛め）で、全部 `SetCounter(StatusKeys.Stun, 1)`。**二値で重ならない**（既に痺れている駒に付けても何も増えない）。
- 消費は engine の1箇所（`TakeTurnCore` の頭）: 痺れていれば手番を失い（`IdleTurn` を立てる）、0 に戻す。**痺れている間は `CanActOutOfTurn` も閉じる**（反撃・割り込みも止まる）。
- **手番を既に終えた駒に付いた痺れは、次のターンの手番で消費される**（ターンの頭で消えない）——同じターンにまだ動いていない駒なら、そのターンの手番を失う。
- 痺れを engine 以外で 0 に戻す札・弾く札は **0 本**（粛もガルドの不動も痺れには触らない）。**`OnTurnStart` で働く札は痺れても止まらない**——グザの瘴気は痺れていても撒かれる（止まるのはグザの通常攻撃だけ）。
- 読み手は責め苦・縛め・尾灯の3枚（台には出ない）。雷の数える種類（16 本）に痺は入っている。

### Q0-4 過去の測定

`design/` を「開戦時に毒」「全体に毒」「痺れの連鎖」で grep した。**開戦時に毒を撒く機構は過去に1つも無い**。全体に毒は第61期の瘴気（グザの `OnTurnStart` ＝ 手番へ降ろす案は採らなかった）と第197期の紅蓮だけ。
**感電や連鎖で痺れる機構も 0 件**（第214期の感電は放電だけ）。
