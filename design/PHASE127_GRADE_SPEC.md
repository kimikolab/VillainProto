## 0. この期の性格

**HEAD は第126期**（時間を買う3案とも不採用。盤面は1ビットも動いていない）。
`docs/quality.md` が新設され、**全61行の通算で 完全勝利 6.7% ／ 全滅勝ち 18.7%**。

### 0-1. 第126期のあとにポンが見たこと（この期の出発点）

完全勝利率の上位4行を第三波で見てもらった。**結論は「爽快感のある完全勝利とは言えない」。**

| 行 | 完全勝利 | ポンの評 |
|---|--:|---|
| 逆しま改 (クビ×ウツ) | 76.1% | 1体だけ落ちて勝ち。安定感はある。**ただし耐久3枚（ガルド・ゴルム・クビ）が要る。** 開幕でウツの攻撃力が90超になり、あとは**通常攻撃で1体ずつ削る絵**。爽快感は無い |
| 刻み×断ち (ノミ×ナタ) | 25.6% | 辛勝・全滅が多い。**ノミ90・ナタ90に対し、通常攻撃でも70〜80は出る。シナジーを生んでいる感が無い** |
| 突き出し (セロ×ヨミ) | 43.2% | 辛勝。期待どおり動かないパターンが多い |
| 移動改 (バサ×ヨミ×シオ) | 23.0% | 辛勝。耐久不足。ヨミが落ちたら終わり |

> **完全勝利率を主目標に据える案はここで消えた。** 76.1% の行を見ても爽快ではなかった。

### 0-2. 「爽快感」の正体は3期分の言葉で一致している

- 「ちまちま通常攻撃で1体ずつ削る絵面」（今回）
- 「デバフを貰いながら1体ずつ倒していくのは爽快感に欠ける」（第124期・ウツ）
- 「薙ぎやゾトの全体攻撃は**一斉に入った**ほうが爽快感ある」（第123期）
- 「爆発も感じない」（第125期）

> **盤面が一度に大きく動くこと。**

そして構造がそれを許していない。**味方52枚の常時の攻撃型は 単体48 / 薙ぎ4 / 貫き0 / 全体0**
（`AttackPattern.Pierce` と `All` は `EnemyCatalog` 側にしかない）。
ポンが唯一 ○ を付けた「一斉に入る絵」は**敵の詠唱兵・審問官の全体攻撃**だった。

### 0-3. シナジーが出力になっていない ——2度目の確認

- 第125期: ボルグ **254**・ドルガ **201** に対し、軸の駒はトメ60・ノミ122・ウツ110・セロ124
- 今回: ノミ90・ナタ90 に対し、**通常攻撃でも70〜80**。上乗せは **+15% 程度**

さらに、唯一シナジーが効いた逆しま改の効き方が問題である。
クビの弱体 → ゴルムが反射 → ウツが倍強化 → **開幕で攻撃力90超**。
第124期にもポンは同じことを書いている——「ウツの火力が開幕で決まってしまってその後変動しない」。

> **シナジーが戦闘中に積み上がるのではなく、開幕に一度決まって固定される。**
> だから絵は「強い駒が通常攻撃で1体ずつ削る」になる。**攻撃力90でも単体攻撃。**

### 0-4. **この期の機構は新規ではない。既に6枚に入っている**

`TraitId.Overload`（第116期・据えのバン）:

> `AtkBonus >= ReaderRule.Threshold`（既定 5）なら `ModifyPattern` が **単体 → 薙ぎ** を返す。
> **量ではなく二値で読む。** 自分では1点も積めないので、点くかどうかは同席する供給者が決める。

第116期に採用され、**主判定19行が6期ぶりに動いた**（`縛め収入型` +15.5pt）。当時の知見:

- **強化の価値は積んだ量ではなく、受け手がそれを振る回数で決まる**（第114・117期。第65期の再発見）
- **閾値の当落は量ではなく席（その隣が読み手か）で決まる。強化は段で来る**（第115・116期。薙ぎ率は 0% か 100%）

| 尾灯のトモ | とどめを刺すたび | 攻撃力上昇 ＋ 薙ぎの**範囲が両隣へ** |

## 2. 予測（実装の前にここに書いてある。後から書き換えない）

### P0 —— 段1・段2 は台本も勝敗も変えない

ローカル台で測るだけなので、**`compare` の 305 セルは `docs/balance.md` と 0 件差分。**
1件でも動いたら止めて報告する。

### P1 —— 段の価値は線形ではない。**単体→薙ぎ より 薙ぎ→貫き のほうが小さい**

薙ぎは「標的と同じ列の全員＋中央」、貫きは「横列の経路を前から後ろへ」。
敵が5体X字なら、**薙ぎの巻き込みは前列狙いで2、貫きの命中は3**だが、
**貫きは前列を抜けないと後列に届かない**ので、実効の差は小さいはず。
**全体だけが段として大きく飛ぶ**（P2）。

### P2 —— 全体は強すぎる。ただし壊れ方が予測できる

`All` は介入（庇い・標的・後備え・棘守り・殉教）を**全部素通りする**（Q0-4）。
つまり全体化した駒は**敵の防御機構を丸ごと無効化する**。
第五波の殉教者（庇い75%）と第三波の祭司が効かなくなるので、**波の性格が消える。**
**「全体は段として置くが、閾値を高くするか、1戦に1回に絞る」**方向になるはず。

### P3 —— 読み手を増やしても、条件の供給が無い駒は点かない

第116期の知見「**閾値の当落は量ではなく席（その隣が読み手か）で決まる**」がそのまま効く。
Q0-5 で供給が薄いキー（`Burn` / `Armor` / `Marked` / `Stun`）に読み手を足しても、
**発火率がほぼ 0% になる**はず。**発火率を必ず測る**（薙ぎ率は 0% か 100% で来る＝第116期）。

### P4 —— 爽快感は勝率と相関しない

段を足しても `compare` の勝率は大きく動かないはず（第126期の案Aと同じ）。
**この期の採否は数値だけでは決まらない**（§6-2）。

### 3-1. 段0 —— 持ち越しの小物（外してよい）

第126期に積み残した2つ。どちらも小さく、独立している。

1. **駒の説明を「手番 / プラス特性 / マイナス特性」に分ける**（`DemoApp`）。
   前提の数字は第126期に測ってある——**`Actions` を持つのは52枚中5枚**なので、
   「アクティブスキル」欄を作ると47枚が空欄になる。**欄の名前は「手番」にして常に埋める**
   （47枚には「通常攻撃（単体）」と出る）。**文を書き足さず、`Pattern` ＋ `Actions` ＋
   `Sluggish`/`Immobile`/`Pursuer`/`Displaced` から生成する。`PlusText`/`MinusText` は1文字も変えない**
2. **`docs/quality.md` に波別の完全勝利率を足す**（`BattleSim`）。
   現在は第2〜5波の通算しかなく、**ポンが第三波だけを見たときに 76.1% がその戦の確率だと読めてしまう**。
   **`docs/balance.md` は1文字も触らない**（第126期の判断を踏襲）

### 3-2. 段1 —— 段をローカル台で測る（`BattleCore`）

**台**: 第117・126期の台は使わない——あれは「育つ駒 × 死なない駒」の台で、
**第126期に「埋め草の規則が入力を 0 にする」穴を踏んでいる**（`AtkBonus` が一度も動かなかった）。
**この期の台は「条件が確実に供給される台」にする。** 具体的には:

- **供給者を1枚固定で置く**（`AtkBonus` を積む駒、または燃焼を撒くボルグ）。**全版で同一**
- **読み手1枚**を替えて版を作る
- **供給が実際に届いているかを毎版で計数する**（閾値超のターンの割合。0.0% なら測定不能として止める）
  —— **第126期の案Cはここで落ちた。同じ穴を二度踏まない**

**測る版**:

| 版 | 内容 |
|---|---|
| V0（対照） | 格上げなし |
| V1 | 単体 → **薙ぎ**（＝現行の `Overload` と同じ。**器具の再現性の確認を兼ねる**） |
| V2 | 単体 → **貫き** |
| V3 | 単体 → **全体** |
| V4 | **段で上がる**（閾値を2つ持ち、低い側で薙ぎ・高い側で全体） |

**測るもの**:

- **発火率**（閾値を超えていたターンの割合。0% か 100% で来るはず＝第116期）
- **与ダメージ**（敵／味方）と**決着T**
- **残存・圧勝率・完全勝利**（第126期に作った `quality` の定義をそのまま使う）
- **介入の素通り**（Q0-4。`Intercept` の件数が V3 で減るはず。**第125期に足した `BattleEventKind.Intercept` がそのまま使える**）

**閾値は掃引しない**（第115期と同じ。低く固定して二値で読む）。掃引するなら理由を報告書に書く。

**代金を付けない。** 第118・126期の教訓——素の効き方を先に測る。代金の設計は採用が決まってからの仕事。

### 3-3. 段2 —— 載せるなら既存駒に1枚（載せなくてよい）

段1 で効いた形を、**既存駒1枚**に載せて `compare` を回す。

- **載せ先は Q0-5・Q0-6 の結果から選ぶ。** 「条件の供給が編成に実在する駒」でなければ点かない（P3）
- **下読みの候補**: **逆しまのウツ**（開幕に攻撃力90超まで積むのに単体のまま。
  §0-3 で名指しされた「強い駒が通常攻撃で1体ずつ削る」の当事者そのもの）。
  ただし **ウツは強化されると攻撃力が半減する**（`Perverse`）ので、読む通貨は `AtkBonus` ではない。
  **弱体の総量を読む形になるはず**。Q0-6 の結果しだいで変える
- **1枚だけ。2案以上を同時に採らない**
- **明確に効かなければ載せない。** 測って採らなかった機構は**削除せず対照として残置する**

## 5. 採否

### 5-2. **主判定はポンの目視**（この期は数値では決まらない）

問いは1つだけ:

> **盤面が一度に動く瞬間があったか。あったなら、それは「爆発」と呼べるか。**

**「呼べる」なら採用。「呼べない」なら、段は爽快感の答えではなかったことになる**——
その場合は §8-2 の被弾/T の側へ移る。

第125期に**同時着弾（薙ぎ・全体・貫きの巻き込みを一斉に落とす）は既に実装済み**なので、
**型が変われば絵はもう用意されている。**
