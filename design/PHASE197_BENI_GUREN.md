- **敵の保持者は 0 体**——第2〜5波の敵に、毒・燃焼を読む札は1枚も無い（敵が「燃えたら強くなる」経路は無い）
- 味方側で敵の毒・燃焼を読むのは: **ミオ**（`Concentrate`＝毒のある敵に +4・次の刻みが最大の敵とその隣に印）、**ラウ**（`Touch`＝毒を持つ標的の隣の敵へ写す・`Contagion`）、
  **スィド**（`Numb` は engine 側 `PerformAttackBody` で**毒の層 × 3%**・上限 60%）、**カタ**（起爆・毒と燃焼の両方持ちに ×2＝engine 側 `Detonate`）。
  ヒヨ（`Favor`）は**燃えている味方**を読むので敵の火には反応しない。ホタ（`Pyre`）は自分の燃焼だけ。ヴィオ（`Blightfed`）は味方の毒
- **再着火**（`Ignite`）: 既に燃えている相手は残りターンを `BurnRules.Turns`（3）に**戻すだけ**でダメージは増えない（`BurnRelit` に数える）。傷のある相手は滲み則で 4（`Soak.Burn` は既定 false なので盤面では 3）
- **毒の窓口**（`Poison`）: 傷・深手のある相手には滲み則で +1 / +2（巻き込み則を降ろした盤面では敵に傷を書く経路はノミ・刻みの行だけ）

### Q0-4 手番の頭で放つ入口

- `TakeTurnCore` の `Skill` の枝は `EmitSkill` の後に `actor.Traits` を**並び順に** `OnAction` へ回す。ベニの札は `Inverse → Kindle → Taint → InverseLeak`
- → **紅蓮の札を `Kindle` の前に置けば、火・毒の拍より先に放てる**（engine に入口を足さない）。`ActionIndex` はその前に進んでいるので周期はいつもどおり続く
- 手番を失った手番（痺れ・竦み・組み付き・転倒）は `Skill` の枝に来ないので**放たない**（溜まったまま）

## 実装（予測のコミット 0171e98 の後）

- **溜める口**: `BattleContext.InverseSip`（第193期の啜り）の中。ベニへの流し込み（`Heal(beni, over, beni, inverted: true)`）の結果が `Healed` / `Full` のときだけ、
  **溢れ − ベニが実際に増えた HP** を `StatusKeys.Guren`（新しい状態キー・`All` に入れた・札は「紅」）に足す。**紅蓮の札を持つベニだけ**（`GurenTrait.Holds`）。
  渇き・支援拒否で止められた回復は、第193期と同じくそもそも啜りに来ない（隣への回復が `Drought` / `Blocked` なら `InverseSip` が先に抜ける）。ベニ自身の刻みの反転も流さない（第193期のまま）
- **放つ口**: 札 `Guren`（`GurenTrait.OnAction`）。ベニの札の並びを `Inverse → Guren → Kindle → Taint → InverseLeak` にしたので、**周期の火・毒の拍より先**に走る（engine に入口を足していない）。
  紅蓮 ≥ 12 なら (1) 生きている敵全員に `Ignite(foe, false, ベニ)` → (2) 紅蓮 ÷ 敵の数（切り捨て）の層を `ctx.Poison`（新しい経路 `PoisonRoute.Guren`）→ (3) 紅蓮を 0。手番を失った手番では `Skill` の枝に来ないので放たない
- **版は札で切り替える**（第196期 `SpewFixed` と同じ作法・保持者 0 枚の対照の札）: `GurenStrike`（等分を `ApplyDamage(foe, 等分, ベニ)` で）／ `GurenLow`（閾値 `const GurenTrait.LowThreshold = 6`）／ `GurenFull`（等分せず満額）。
  閾値は `const GurenTrait.Threshold = 12`。**`Run` の引数は増やしていない**
- **毒の経路を1本足したので `SoakRouteCount` 11 → 12・燃焼の添字 10 → 11**
- 計数（どの規則も読まない）: `UnitTally.Guren*`（溜めた・放った・初回T・新／既・層・刻みの帰属）と、敵の側の私有カウンタ `gurenHeld` / `gurenMio` / `gurenBurn`（奔流の層・奔流の毒しか無い敵へのミオの +4・奔流の火）。ミオの +4 の帰属は `AmplifierTrait.Thicken` に1行（`NoteGurenThicken`）
- 台本（**表示専用**）: `BattleEventKind.GurenGain`（溜まった瞬間・`ActorId` = ベニ・`TargetId` = 溢れた隣・`Amount` = 足した量・**`StatusRemaining` = 足した後の紅蓮**）と
  `BattleEventKind.GurenRelease`（**見出し**＝`TargetId` null・`Amount` = 放った紅蓮・`Slot` = 敵の数、続いて敵全員の着火の `StatusGain`、そのあと**敵ごと**＝`TargetId` = 敵・`Amount` = 積んだ層、とその毒の `StatusGain`〈経路 `Guren`〉）。
  ターン頭の `StatusSnapshot` にも「紅」が載る（`StatusKeys.All` に入れたので自動）
- `checkup` の分類表・`TraitKeyMap` / `TraitHookMap` に4枚ずつ足した。`units.md` の文面は指示書 §6 のまま

## 読み

1. **紅蓮は「既に勝っている波」でしか溜まらない。** 溜まるのは第二波と第四波（放った戦 61〜100%）で、**第三波（渇き）では構造的に 0**（回復が1点も通らないので溢れも無い）、
   **第五波ではベニが 3〜4 ターン目で倒れるか隣が満タンにならず 0〜30%**。その第二波・第四波は無の版で既に 93〜100% 勝っている（`毒→被弾強化` の第四波 48.0 → 73.5 と `追撃×毒` の第二波 80.0 → 98.0 が例外）。
   **溢れは「隣が満タン ＝ 隣が殴られていない」ときにしか出ないので、紅蓮はもともと押している戦の余りである**（R304）
2. **1発目はほぼ台本どおりに第2ターンに出る**。第四波の初回T は 2.00 ちょうど——ベニが第1ターンに「火を分けた」隣の2体（満タン）が、第2ターン頭の燃焼の反転（6 ＋ 6）でそのまま溢れ、毒の反転と合わせて 12 を越える（`replay` で 1・2・6・6 ＝ 15）。
   **紅蓮の燃料の大半はベニ自身が第1ターンに撒いた火**で、「隣の毒と火が薬に裏返り、満ちた余りが溜まる」という絵コンテの順序どおりには来ていない
3. **勝率には出ないが、勝ち方には出る**（`docs/` の差分）: `毒+ベニ+ラウ` の圧勝率 52.0 → **77.6%**、`毒+耐久` 6.6 → **26.8%**、最大同時撃破 2.76 → 2.90 ／ 2.08 → 2.36、
   第四波の決着T 10.54 → **8.99** ／ 7.97 → **6.00**。**「たまに出る大技」は、押している戦を早く・きれいに終わらせる形で効いている**
4. **毒と直撃はほぼ同じ**（在席 +0.8 ／ +1.0、主表S 平均 77.4 ／ 76.9）。1回の奔流で積む層は敵全員の合計で約 24〜26 層（在席 34.4 ÷ 1.33・主表S 21.9 ÷ 0.91）＝ 1体あたり 5 層前後で、直撃の実額は1戦 18〜27（名目の 85〜90%）。
   毒の層の刻みは1戦 34〜52（印の2回目以降を足すと 38〜61）と直撃より多いが、**どちらも既に勝つ戦に入るので勝率の差にならない**
5. **ミオの +4 による増分は 0.0〜0.2 層／戦**（P5 ○）——奔流が来る時点で敵はほぼ毒を持っている。**印（濃縮）による増分は効いている**（在席 毒の刻み 51.6 に対し印の分 9.1）
6. **スィドは倒れにくくなる**（主表S の倒れ 無 → 毒: `毒爆弾` 96.6 → 82.8%、`澱み喰い` 87.9 → 72.2%）。ただしこれも第四波の戦で、勝率は動かない
7. **低閾（6）はほとんど変わらない**: 放った回数 1.33 → 1.41（在席）・0.91 → 1.08（主表S）。溢れは1回の刻みでまとめて来るので、12 を 6 にしても1回が早まるだけ（初回T 3.02 → 2.92）
