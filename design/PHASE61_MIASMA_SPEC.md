## 0. 主題

### 0-1. 移設（本題）

第60期でヒヨの移設が通り、型（`OnAction` + `ActsOnPattern` の分岐）と測り方が揃った。
**ただしヒヨで効いた理由は「供給が `OnAfterAttack` にあった」ことなので、同じ利益は出ない。**
グザの移設は**別の量**を動かす。

現況（Phase 0 で数え直すこと）:

| 項目 | 把握 |
|---|---|
| 瘴気（`MiasmaTrait`） | `OnTurnStart` で**敵全体に毒 +2 / 味方全体に毒 +1**。味方には自分も含む |
| グザ | HP58 / **攻2** / **速5** |
| ターンの順序 | `TickStatuses`（毒 → 燃焼）→ `OnTurnStart`（全員・**席順の昇順**）→ 行動順 |
| グザを含む行 | **8 行**。うち **`毒+耐久 (ベニ×トウ)` は主判定19行の #12** |

**移設が動かす一番大きい量は、ヴィオとの順序である。**

澱み喰い（`BlightfedTrait`・ヴィオ）も `OnTurnStart` で発火し、**味方の毒を全部吸い上げて
攻撃力に変える。** どちらもターン頭なので、**今はどちらが先かが席順で決まる**——
グザの席がヴィオより前なら、撒いた毒はその場でヴィオに吸われて**味方は1点も払わない**。
後ろなら、毒は次の `TickStatuses` まで残って**味方が刻まれる。**

**移設すると、この判断が消える。** ヴィオの吸い上げはターン頭のままで、グザの散布は
行動順（速5）へ降りるので、**必ずヴィオが先**になる。味方は毎ターン必ず1回刻まれ、
ヴィオの取り分は1ターン遅れる。

> **これは移設の副産物ではなく、移設の主たる効果である。**
> 判定はここを正面から測る（§3 Q1）。**判断が消えるなら、それは代金として記録する。**

### 0-2. 周期版（`[撒く, 溜める]`）を同時に測る

1要素の `[Skill]` は「毎ターン撒く」を変えないので、供給量そのものは動かない。
**2要素の周期 `[Skill, Attack]` は供給を半分にする。**

ここに**符号が編成で反転する見込み**がある:

| 行の型 | 毒漏れが減ると | 理由 |
|---|---|---|
| **ヴィオ行**（`澱み喰い` / `毒爆弾`） | **損** | 味方の毒はヴィオの餌。減らすと攻撃力が伸びない |
| **ベニ行**（`毒+耐久` / `毒+ベニ+ラウ`） | **得** | 毒喰らいは**味方の毒をより深く効かせる**倍率なので、漏れは代金として重い |

**同じ駒が編成で別物になるかどうか**が、この期の面白さの判定。

### 0-3. 係数の確定（第60期の持ち越し）

`FavorRule` を `(4,2)` → `(6,2)` に上げるかを決める。第60期の実測では4行とも上回る
（+10.1 / +4.7 / +0.1 / +1.6pt）が、**`Gain` がホタ専用のノブになっている疑い**がある
——第58期の `2→4` は 行1 +5.6 / 行2 +4.1 でほぼ同じだったのに、
移設後の `4→6` は 行1 +10.1 / 行2 +4.7 と差が開いた。
ホタの乗算（燃焼中ちょうど4倍・貫き込みで実効7.4倍）が `Gain` に乗るため。

**主判定19行に火選りの行も `死軸×ヒヨ` も入っていないので、歯止めの分母は動かない。**
（Phase 0 で検算すること。）

## 4. 係数の確定（`FavorRule`）

**火選り4行だけで閉じる。** グザの8行と重ならないので、移設とは独立に測ってよい。

| 版 | Gain | Loss |
|---|--:|--:|
| 現行 | 4 | 2 |
| b | 6 | 2 |

**判定を1つ足す——乗算の比。**

    比 = （乗算持ちのいる行の伸び） ÷ （乗算持ちのいない行の伸び）

第58期の `2→4` は **5.6 / 4.1 = 1.37**、第60期の `4→6` は **10.1 / 4.7 = 2.15**。

- **比が 2.0 未満**なら `(6,2)` を採る
- **比が 2.0 以上**なら **`Gain` はホタ専用のノブになっている**と判定し、**上げない**。
  その場合、**乗算を通らない経路で強化を厚くする案**を次期の候補として1行書く（設計はしない）

**別 seed 帯で比を取り直すこと。** 1帯の比で桁の判断をしない。
