# 第33期 実装指示書 —— 第五波に庇う持ちの敵を置く（介入の試験）

対象ブランチ: `master`
狙い: 第五波に固有の敗者を作る。課金する資源は**対単体攻撃への依存**——庇うは Single だけを吸うので、単体打点に寄った編成が高く付き、薙ぎ・貫き・全体は素通りする。この資源はどの波もまだ課金していない。副次目的として、引き継ぎ残件「ノミの執着を庇うで引き剥がす対抗が製品の波で一度も発火しない」を解消する。

この指示書は自己完結している。リポジトリ外の文書への参照は無い。

## Phase 1: 事前監査（実装前。結果を報告書に表で残す)

Web 側で確認済みの下記4点を、行番号込みで裏取りすること。1つでも食い違ったら設計が変わるので、**食い違いを見つけた時点で停止して報告**。

1. **介入の鎖は陣営非依存。** `BattleEngine.SelectTarget` 周辺（494行〜）の 標的(Marked)→後備え(RearGuard)→庇う(Guardian)→棘守り の鎖は `foes`（守る側）から引いており、敵味方を固定していない。敵に `Guardian` を持たせれば味方の単体攻撃に対してそのまま働くはず
2. **庇うの席条件は `Row.Front`。** `f.Row == Row.Front` のフィルタがある（607行付近）。盤面の Row 対応は front1/front3 = `Front`、**center = `Mid`**、back = `Back`（`Models.cs` 244行付近）。**したがって庇う持ちは前1か前3にしか置けない。中央は不可。**
3. **庇うは肩代わりで育つ。** `GuardianTrait.OnDamaged` が肩代わり被弾 2 につき攻撃+1（`DamagePerGain`）。敵が持てば**単体攻撃を撃ち込むほど敵が育つ**。この成長も試験の一部として意図的に持ち込む（殺すなら範囲で、単体で削るなら育つ前に）
4. **執着は介入の鎖を通った後の相手を覚える**（517行付近のコメント）。庇われたノミは次の手番から庇い手を狙う＝引き剥がしが製品の波で発火する

追加で確認すること:

5. **反撃・仇討ち・軋み・追い打ちの標的決定が介入の鎖を通るか。** ターン外・反応系は攻撃者を直接狙う実装のはずで、通らないなら**カウンター軸はこの試験に課税されない**（波の役割分担として望ましい。粛=W2 がカウンターを、庇う=W5 が単体依存を課税する棲み分け）。通る場合は影響範囲を報告
6. 庇うの確率は 50%（`RedirectPercent`）。乱数は `Roll` 経由でシード再現性が保たれること
7. 味方側ガルドの庇うと同一 TraitId を共有して副作用が無いこと（ガルドは `Stoic` 等を別 TraitId で持つ。`Guardian` 単体を敵に載せて漏れる前提が無いか）

## Phase 2: 設計と予測（実装前に書き切る）

### 2-1. 配置と数値

- **保持者は前1 の戦斧兵と差し替える。** 数値・型・速さを完全同一（52/11/速5・薙ぎ）にし、`Guardian` を1つ足した新定義とする（第32期で検証した「差分を特性だけに閉じる」方法）。Id 案 `axeman_g`、名前候補: **殉教者**（デフォルト）／聖盾兵／庇いの戦斧兵
- 前3 の勇者候補に載せない理由: 波の最大打点と断罪と介入が1枚に重なって試験が濁る。断罪の担い手数（勇者候補＋審問官の2）も動かさない
- 中央に置けないことは Phase 1-2 のとおり構造的制約（`Row.Mid`）。報告書に明記する

### 2-2. 型の在庫表（予測の前に作る。第32期の教訓「型を見る」）

味方ロスター全駒について、攻撃型（単体／薙ぎ／貫き／全体／攻撃しない）と、その攻撃が Single 判定を通るかの表を作る。行動パターンで型が変わる駒（ミオ・グザ等）は型ごとに記載。その上で compare 42行それぞれの**単体依存度**（手数のうち Single が占める割合の見積もり）を出す。

### 2-3. 42行の予測表

第五波の勝率について 上がる／下がる／不動 の3値予測。主判定17行＋単体依存度が高い行は駒名・型・速さで根拠を書く。少なくとも以下を織り込むこと:

- **下がる候補**: 単体打点に寄った行。庇い50%で手数の半分が殉教者に吸われ、吸われた分だけ薙ぎ（3枠）が育つ二重払い
- **無風〜上がる候補**: 範囲主体の行（ボルグ・ドルガ・ヒビ等）。庇うは素通り
- **カウンター軸**: Phase 1-5 の結果次第。反応系が鎖を通らないなら無風と予測
- **ノミ（執着）**: 引き剥がしで殉教者に狙いが固定される。ノミの +2/傷 が殉教者に集中する＝**引き剥がしが罰かご褒美かは自明でない**。どちらに出るか事前に立場を書く
- **ヒサ（標的）**: 味方側の Marked は鎖の先頭で、庇うより優先されるか要確認（Phase 1 で順序確認済みのはず）。標的で庇いを迂回できるなら、ヒサに新しい使い道が生まれる——予測に書く

外れたら何が言えるかも事前に書く（第32期の形式を踏襲）。
