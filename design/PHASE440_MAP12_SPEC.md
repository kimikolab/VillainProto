## 2. 1-2 の盤

### 2-1. 形

```
        N0 ── N1 ── N2 ──┐
       /      |          │
Home ─── C0 ── C1 ── C2 ─┼── Portal
       \      |          │
        S0 ── S1 ── S2 ──┘
```

- 経路 3 本: 北 [N0,N1,N2]・中 [C0,C1,C2]・南 [S0,S1,S2]。拠点はそれぞれの 0 と繋がる（1-1 と同じ形）
- **横の辺 2 本: N1–C1・C1–S1**。隊は拠点に戻らずに経路を移れる。敵はこの辺を使わない（経路に沿って拠点へ向かうだけ）
- 敵の拠点は 3 経路の奥で合流（1-1 と同じ）
- `Pos` は 1-1 の座標の並びを 3 段にする（北を上・南を下・中を今の中央）。カメラは必要なら少し引く（第177期の `_labelScale` の作法）

### 2-2. 敵

| 経路 | 1 戦目（マス 1） | 2 戦目（マス 2） | 湧き |
|---|---|---|---|
| 北 | 第二波・先遣（4 体） | 第三波 ／ 討伐隊本隊 | 第二波・先遣 |
| 中 | **第一波 ／ 物見の兵（3 体）** | **第二波・先遣（4 体）** | 第一波 ／ 物見の兵 |
| 南 | 第四波・先遣（4 体） | 第五波 ／ 異端審問団 | 第四波・先遣 |

北と南は 1-1 のまま。中は**軽い列**（第二の隊が歩く道。重い道と軽い道があると「どの隊をどこへ」に幅が出る）。
新しい敵は作らない（すべて `EnemyCatalog.Stages`／`Vanguards` の写し）。

### 2-3. 規則の値

- 時間 K=1・休む 25%・道中の回復 50%（1-1 と同じ）
- 湧き **S=4**・ワープ R=3（第177期の S=8 は効いていなかった。制圧前に 1 度は湧く値）。湧く経路は北→中→南の順に回す
- 勝ち＝制圧＋盤上の敵 0（1-1 と同じ）
- 手札は 1-1 と同じ 15 枚（配布は段B）

### 2-4. 読んでおく注意（この期では直さない）

- `Via`: 敵の拠点から出るとき入ってきた経路へ戻る。1-2 でも同じ。「取った拠点から別の経路へ直行」は段B で見直す
- `Advance` の癖（脇を抜けた敵へ引き返す）: 横の辺で経路を移った隊が、元の経路の敵を追う形になりうる。起きたら報告だけ

## 3. 仕組み

### 3-1. `MapStage`（新しいファイル・Godot の型なし）

```
MapStage { Name, Graph (portalOn → MapGraph), Lanes[ lane → RoadNode[] ], Spawn(lane) → (Formation, Name, StageIndex), Portal: PortalRule, Time: TimeRule }
```

- `Stage11` ＝ 今の `Map11.Roads`／`SpawnEnemy`／`AdoptedPortal`／`AdoptedTime` をそのまま写す
- `Stage12` ＝ §2
- `Map11State` は `MapStage` を受けて `Nodes`／`Graph`／経路数／湧きを引く。`Map11.RoadCount`・`RoadNames` などの static は `Stage11` へ移し、`Map11State` から読む側は `Stage` 経由にする
- `Map11Session.Reset(seed, draft, stage)`。既定は `Stage11`（**器具と門はすべて 1-1 のまま**）

### 3-2. 画面

- 編成画面の「作戦マップへ」の隣に **1-1 ／ 1-2** の選択（既定 1-1）。結果画面にステージ名

- 行き先の札は盤のマス全部（横の辺の先も）
- **敵の経路の矢印**: 各経路の先頭の敵（`FrontFoe`）から `TowardHome` の 1 マスへ短い矢印（敵の色）。湧いた部隊も同じ。
