この期は**道具と候補の絵**。規則・盤・駒・BattleCore は触らない。push はしない。

## 0. なぜ

- ポンの OpenAI の API 枠が毎月付与されるようになった。Claude Code の作業の流れの中で素材を作れるようにしたい
- 今、絵が足りなくて困っている所:
  - 敵の顔が仮の字（「敵側はほぼプレースホルダーの絵なので違いがわからない」）
  - 会話の画面に聖女の絵が無い（名札と本文だけ）
  - 立ち絵が待機の 1 枚きり（ガンが静かな行でも吠えて指を差している）
- 主役級の立ち絵（勇者など）は、今までどおりポンが Codex で詰める。この道具は**数の要る脇の絵**と**差分**のためのもの

## 1. 決まり（必ず守る）

1. **API キーをコミットしない。** キーは環境変数 `OPENAI_API_KEY` から読むだけ。ファイルに書かない・ログに出さない・報告に写さない。
   リポジトリは Public。`.gitignore` に `.env` と候補の置き場を足す。キーが無ければ、何も作らずにその旨を言って止まる
2. **枚数に上限。** 1 回の実行で作るのは既定 4 枚まで・この期の合計は **40 枚まで**。超えそうなら止まって報告
3. **採用はポンが決める。** 作った絵は候補の置き場に出すだけ。ゲームが読む場所へは、ポンが選んだ後に移す
4. **使った文を残す。** 絵 1 枚ごとに、文・参照に使った絵・モデル・設定・日付を横の JSON に保存
5. **購入アセット（Bukkbeek）を参照画像に使わない・送らない。** 参照に使ってよいのは、このリポジトリの自作の立ち絵だけ
6. **文に、実在の作品名・作家名・他作のキャラ名を書かない。** 絵柄は言葉で書く（§3）
7. API が断った絵（安全の理由など）は、言い換えて 1 回だけ試す。それでも断られたら、作らずに報告

## 2. Phase 0 —— 調べるだけ（報告 `design/PHASE482_ART_TOOL.md`）

1. OpenAI の公式の資料で、**今の画像生成の API** を確かめる: 使えるモデル名・生成と編集（参照画像つき）の口・透過の背景が出せるか・
   出せる大きさ・1 枚あたりのおおよその料金・枚数や速さの制限。私（Web 側）の知識は古い可能性があるので、資料の方を正とする
2. この機械で動かせる道具の言語（Python ／ Node ／ dotnet のどれが入っているか）。いちばん手間の無いもので書く
3. 今ゲームが絵を読んでいる場所と決まり: 味方の立ち絵（`assets/portraits/battle/`）・顔の切り出し（`UnitFaceIcon`）・
   勇者の絵（`design/art/enemies/hero/`）・敵の顔の仮の字が出ている所
4. 今ある敵の部隊の一覧（1 章で出るもの）と、その中身の駒

料金が資料から読めない・口が使えない場合は、ここで止まって報告。

## 3. 道具（`tools/artgen/`）

口は 3 つ。

| 口 | 中身 |
|---|---|
| `gen` | 文から作る。`--job 名前 --n 枚数 --size 大きさ --transparent` |
| `edit` | 参照の絵を渡して、変える所だけ文で指定する（表情・腕・傷など）。`--ref 絵のパス` |
| `sheet` | 候補を 1 枚に並べた見比べの絵を作る。既存の味方の立ち絵（リィカ・ドルガなど）を両端に置き、下段に 40px 相当の顔も並べる |

- **絵柄の文は 1 つのファイルに固定**: `design/art/prompts/_style.md`。どの依頼にも頭に付ける。叩き台:
  「中世ファンタジー・アニメ調だが重さと厚みのある塗り・くっきりした輪郭・落ち着いた色・全身または腰から上・無地の背景・光は左上から」
  既存の立ち絵 2〜3 枚を見て、言葉を合わせる
- 依頼ごとの文は `design/art/prompts/<job>.md`（コミットする）
- 出力は `design/art/_candidates/<job>/`（**コミットしない**・`.gitignore`）。絵と同じ名前の `.json` に §1-4 の記録
- 実行のたびに 1 行: 何枚作ったか・この期の合計・おおよその料金
- 透過が API で出せないなら、無地の背景で作って道具の側で抜く（縁のにじみを見て、だめなら無地のまま出して報告）

## 4. 自分で見て選り分ける

作った絵は Claude Code が自分で見て、次に当たるものを候補から外す（外した数と理由を報告に）。

- 顔や手が崩れている・武器が体を貫いている・文字やロゴが入っている
- 向きが違う（敵は**左向き**が基本）・全身のはずが切れている
- 既存の味方の絵と並べて、塗りや頭身が明らかに違う
- 味方の誰かと見分けがつかない（髪の色と形が同じ）

外した後に 2 枚以上残らなければ、文を直して 1 回だけ作り直す。

## 6. ゲーム側の受け口（採用の後に絵を置くだけで出るように）

- 敵の顔: `assets/portraits/enemy/<敵の駒の id>_face.png` があれば、仮の字の代わりにそれを使う（盤の旗・会戦の台・戦闘の記録）。無ければ今のまま
