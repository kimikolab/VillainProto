## Phase 0（実装前・戦闘0回・`form2 phase202`）
### Q0-1 貫きの2レーンを選ぶ入口

- 入口は `BattleContext.SelectPierceEntry(foes, out lane)` の `DeterministicPierce` の枝（○ 在る）。呼び口は `SelectTargetChain` の1箇所（○）で、そこでは `attacker` が手元にある——**引数を1本足せば撃つ敵の席が取れる**
- 撃つ敵の席のレーンは `FormationShape.GridLane(attacker.Slot)`（9マスの格子のレーン・陣形に依らない）。敵は X 字なので:

| 敵の席 | 格子のレーン | 新しい規則で抜ける2レーン |
|---|--:|---|
| 前1 | 1 | 1-2 |
| 前3 | 3 | 2-3 |
| 中央 | 2 | 多い方（同数なら交互・最初は 1-2） |
| 後1 | 1 | 1-2 |
| 後3 | 3 | 2-3 |
| ○中1 | 1 | 1-2 |
| ○中3 | 3 | 2-3 |
| ○前2 | 2 | 多い方（同数なら交互・最初は 1-2） |
| ○後2 | 2 | 多い方（同数なら交互・最初は 1-2） |

- パターン2の経路は `BuildGrid` の `lanes = { Path(1, 2), Path(2, 3) }`——添字 0 ＝ 1-2、添字 1 ＝ 2-3
- X 字は `DeterministicPierce` が偽なのでこの枝を通らない（`Roll` の引き方は1ビットも変わらない）
