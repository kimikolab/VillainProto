## 2. 移した／残した／判定できなかった

指示書 §2-2 は「期が特定できない散文は `CLAUDE.md` に残す」としていたが、
**そのとおりにすると 53,264 字（散文の 29%）が残って Q1 に届かない。**
実際に採ったのは §1-2 の側の規則——**期の明示が無い散文は直前のブロックの期を引き継ぐ**。

| 分類 | 字 | 割合 |
|---|--:|--:|
| 移した（`（…第nn期…）` が見出しの外にある） | 110,303 | 59.8% |
| **移した（期の明示が無く、直前から引き継いだ）** | **53,264** | **28.9%** |
| 残した（規約・判定規約・一般則・現状値） | 20,788 | 11.3% |
| 合計 | 184,355 | 100% |

**引き継ぎの中身はほぼ全部が「続きの段落」と「字下げした表」である**
——指示書 §2-2 は「期が特定できない散文は則の可能性が高い」と見込んでいたが、
実測では**則ではなく、直前の則の証拠の続き**だった。
1つの段落が字下げの表で分断されている箇所（`CLAUDE.md` L3293-3296 の
「書込 2.42 → 4.89 …」の表と「しか動かさない。**空振り率を…**」）があり、
**文が表をまたいで続く**ので、期で切ると文の途中で切れる。

**帰属の規則（実装）**は次の3段で、これも測る前に固定した:

    1. ブロック全体が字下げ（表）なら → 直前の期を引き継ぐ
    2. 太字（`**…**`）の中を除いた先頭 260 字に `（…第nn期…）` があれば → その期（範囲は最大値）
    3. 無ければ → 直前の期を引き継ぐ

**(2) が「太字の中を除く」なのが要**——`**着火（IgniteRule・第89期）は … 走っている**（第109期）`
のように、見出しの中に別の期が入っている行が多い。
除かないと 第89期 に落ちる。**手で 32 ブロックだけ上書きした**（`OVR`。継続段落が別の期を先に引くもの）。

## 7. 分割の形

### 7-1. 時系列で割った理由（指示書 §0-3 のとおり）

軸（傷／毒／弱体…）で割ると軸の定義が変わるたびに文書ごと引っ越しが要る。
時系列なら**追記は常に末尾の1本**（`LESSONS_101_.md`）で、割り方が機械的に決まる。
軸で引きたい要求は `CLAUDE.md` の**知見の索引 §主題別**が受け持つ——索引の1行なら軸が変わっても書き換えが安い。

### 7-2. `LESSONS_*.md` の中身

各ファイルは **`description:` 1行 → 前書き3行 → 期 × 診断名の目次 → `### 第nn期 — 診断名` ごとの本文**。
**見出しがこの期に足した唯一のテキスト**で、本文は1文字も書き換えていない。
**診断名は手で書いていない**——`CLAUDE.md` のコマンド索引の行
（`… -c Release 0 <mode> … （第nn期）`）から機械で引いた。

### 7-3. `CLAUDE.md` 側のコマンド行

指示書 §2-1 の 4. のとおり、期が読めるコマンド行の末尾に **`→ LESSONS_081_100.md`** の形で行き先を書いた
（**+516 字**）。期が読めない行には書いていない。
