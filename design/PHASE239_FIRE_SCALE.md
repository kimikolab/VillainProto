### 影の火勢の数え方（§3.2・測る前に固定）

- **1周回 ＝ 1ターン**（台本の `TurnStart` から次の `TurnStart` まで）。開戦時（ターン 0）の着火（くすぶり・開戦の撒き）は第1ターンに入れる
- **着火 ＝ 台本の `StatusGain`（burn）1件**（Q0-2 で `Ignite` の全件と一致）。出どころを問わない（ボルグの火の粉・火の鎧・くすぶり・焼き返し、ベニの火・開戦の撒き・紅蓮、ホタの火、ゾトの破裂ほか）
- K1: 着火のたび 影 0 → 1、影 ≥ 1 → +1（上限 4）。**ターンの終わりに、そのターン一度も点かなかった駒は −1**
- K2: そのターンの最初の着火だけ +1（2回目以降は数えない）。萎み方は K1 と同じ
- K3: 育ち方は K1、**2ターン続けて点かなかったら −1**（数え直し）
- 影は倒れたら消える。**燃焼の残りターンとは別に数える**（萎む前に燃焼が切れる／燃焼が残っているのに影が 0、の両方を数える＝表A'）
- 分布はターンの終わり（そのターンの着火の後・萎む前）の生きている駒で取る
- §3.4 は手番の頭の影で数える。ボルグの「放つ」は影 4 の手番の頭で数え、**影の中だけ**ボルグの火勢を 1 に戻す（別の写しで数える・ほかの駒の影には触らない）。ヒヨの「大焚き」は手番の頭の味方の影の合計の分布だけ（閾値は決めない）

### 手番の絵の数え方（§3.3・測る前に固定）

- **絵 ＝ 手番の種類（攻撃／術／溜め／何もしない）／攻撃型（その手番の本人の最初の `Attack`・無ければ —）／その手番の枠の中で起きた出来事の種類の集合**
- 出来事の種類は台本の種類そのまま。ただし `StatusGain` burn → 着火、ほかの `StatusGain` → 付与:（状態の名前）、`Heal` → 回復、`Move` → 移動、`Death` → 撃破、`FireArmor` → 札（燃え移る・半減・燃える巻き込み・火の変換 ほか）。**`Attack` / `Damage` / 写し（`StatusSnapshot` / `StatSnapshot`）は数えない**（どの手番にもある／表示用）
- **骨格 ＝ 種類／攻撃型だけ**（出来事を落とした絵）も並べる
- 1戦ごとに、駒ごとの 絵の種類数・同じ絵が続いた最長・最も多い絵の占める割合 を取り、戦で平均する

## 報告の終わりに

### 火勢の規則はどれが「育つ・萎む」を画面で感じられる形か

- **隣の駒は K1 ＝ K2 ＝ K3**（T3・雷＋ボルグ）——ボルグの1振りが隣全員に1回ずつ点けるので、どの規則でも「毎ターン1段」。**育つは見えるが、萎むは見えない**（書き手が毎ターン点け直す・R342）
- **割れるのはボルグ自身**: K1 ではボルグは殴られた回数だけ跳ね（T1〜T2 で 4）、**1段ずつ育つ様子が見えない**。**K2 はボルグも1ターン1段**で、4 に届くのが T3〜T4（本編 T3 の届4 58.8%）
- **萎むが見えるのは隣り合いが崩れる台だけ**（T3-1 でシオが組み替え・燃えているのに影 0 が 9〜15%）。K3 はそれを消す（0.5〜0.8%）
- **Claude Code の読み**: 画面で「育つ・萎む」を両方見せたいなら **K2**（全員が1ターン1段で揃い、ボルグが1ターン目に最大に張り付かない）。ただし K2 だと「放つ」が 0.2〜0.8 回/戦に減る。萎むを見せるには規則ではなく**点け直しの途切れる盤面**（移動・痺れ・ボルグが倒れる）が要る

### 3体の手番の単調さの実態と、§3.4 の候補のどれが一番割れそうか

- **骨格（種類／攻撃型）は3体とも 100% 1種類**。ボルグは毎手番 攻撃／薙ぎ、ホタは 攻撃／貫き、ヒヨは 術。絵の違いは周りの出来事（撃破・回復・火の変換）だけ
- **いちばん単調なのはヒヨ**（強化だけの絵 86〜100%）。ボルグは出来事が多いので絵は最も変わるが、手の形は変わらない
- **§3.4 で骨格そのものを割れるのはホタ**: 手番の頭の影が T3 で段1〜4 に均等（27 / 27 / 27 / 18%）——ホタの手番は毎戦「単体 → 貫き → 貫き＋着火 → 全体」と必ず一巡する。**ただしターン数の時計なので、毎戦同じ順**（割れるが、選択にはならない）
- **ボルグの「放つ」は台で割れる**: 最良の席 T3 では 0 回（殴られない）、T3-1・本編では K1 で 1.3〜2.0 回/戦（育てる → 放つ → また育てる の波が1戦に1〜2周）。K2 では 0.2〜0.8 回
- **ヒヨの「大焚き」は閾値しだいで毎手番になる**: 手番の頭の味方の影の合計は平均 8〜11（10 以上が 23〜68% の手番）
- **Claude Code の読み**: 絵を割るのに一番効くのは**ヒヨ**（単調さの本体・大焚きなら手番の絵が「強化」と「大焚き」に割れる）、波を作るのは**ボルグの放つ**。ただし最良の席ではボルグが殴られないので、放つには自分の火勢を育てる別の口（例えば隣の火勢を吸う形）が要る
