## 2. 新しい盤（1 章だけ・`ChapterRule.V477`・`MapGraph.Build12F477`）

```
                      ┌─ 北1 ─ 北2 ─[見張り台]─ 北4 ─┐
                      │              ║               │
辺境の砦 ── 分かれ道 ──┼─ 中1 ─[関所]─ 中3 ───────────┼── 門 ── 砦（敵の本陣）
                      │                              │
                      └─ 南1 ─ 南2 ─ 南3 ─[渡し場]─ 南5 ─ 南6 ┘
```

| | 北の山道 | 中の街道 | 南の湿地の道 |
|---|---|---|---|
| 長さ（分かれ道から門まで） | 4 マス | **3 マス（最短）** | **6 マス（遠回り）** |
| 中間拠点 | 見張り台（3 マス目） | 関所（2 マス目） | 渡し場（4 マス目） |
| 敵 | 少ないが、見張り台に**帯 B の硬い部隊**（火の魔術師の部隊か毒霧の司祭の部隊） | **敵の主力が歩いてくる道**。先頭と予備隊はここを拠点へ進む | 軽い部隊が 2 つ・待ち構える（`Hold`） |
| 取った見返り | **レリックの候補**（今の「初めて取った中間拠点」の規則を、見張り台に固定） | **金 ＋8** と、ここに隊がいれば歩いてくる敵をここで受けられる（拠点まで来させない） | **金 ＋12** |
| 性格 | 硬いが見返りが大きい | 早いが、取らないと敵が拠点へ来る | 安全で金になるが遅い・**留守を狙われる** |

- **門は中間拠点 2 つで開く**（今の規則のまま）。**どの 2 つを取るか**が 1-2 の選択になる（中＋北／中＋南／北＋南）
- **横の辺は 関所 ⇔ 見張り台 の 1 本だけ**。南はつながらない（南へ出した隊は戻るのに時間がかかる）
- 拠点と 3 本の道のあいだに「分かれ道」を 1 マス（1-3 と同じ形）。拠点から最寄りの中間拠点まで: 関所 3 歩・見張り台 4 歩・渡し場 5 歩
- **予備隊**: 今の規則（最初の接敵の後、手薄な経路へ）を、「**隊のいない道を通って拠点へ歩く**」として使う。全員で南へ行けば中から来る
- 門番の勇者・本陣の守り → 勇者の連戦・湧き・金の規則・倍率 ×0.9・加入の表は今のまま
- 期限は道が伸びたぶん見直す（§3 の通しで決める。今は 12）
- 中間拠点ごとの見返りの口（`RoadNode.Gold` と同じ作り）が無ければ足してよい

名前は仮。物語（`claude/STORY_PLAN.md` 1-2「砦を取れ。居場所は取るものだ」・人間の追放者が流れ着く）に合わせ、敵の本陣は「討伐隊の砦」。

## 3. 渡す前に数字で確かめる（止まる線つき）

### 3-1. `--foe-weight`
1-1 から持ち越した隊（第476期の通しの終わりの写し・☆1〜2 が混ざる）で、新しい盤の敵部隊の全部に当て、今の帯（`design/weights/BANDS.md`）に入れる。見張り台の硬い部隊は「主力 5 枚で勝てるが 1 枚は倒れる・3 枚では抜けない」。

### 3-2. 通し（100 seed・戦闘は器具・組み方は第476期の組 A ／ 組 B を 1-2 に伸ばす）
方針:
1. 中＋北（関所 → 横の辺 → 見張り台）
2. 中＋南（2 隊に分ける）
3. 北＋南（中を空ける＝敵が歩いてくる・留守番が要る）
4. 3 つとも取る
それぞれ「留守番あり（2 枚以上）／なし」。

並べる列: 勝ち・陥落・制圧の刻・失った枚数・金の余り・レリックを取ったか・**拠点か関所での迎撃の回数**・勇者に勝った隊の数。

**線**:
- 方針 1〜3 のどれも、留守番ありで勝ち 70% 以上（組 B）
- **迎撃が勝ち筋の通しで起きる**: 方針 2・3 では拠点か関所での迎撃が平均 1 回以上
- **留守番の枚数が判断になる**: 留守番なしは陥落 30% 以上・留守番 2 枚で陥落 10% 以下・留守番 3 枚以上は勝ちが下がる（攻めが足りなくなる）——1-1 の「3 枚なら全勝・1 枚なら全敗」にならないこと
- **どれか 1 つの方針が全部の列で勝っていたら、止めて報告**（見返りの額・敵の重さ・期限を振った表を付ける）
- 既定の組み方で始めた人が、1 刻目〜3 刻目に陥落しない

### 3-3. Claude Code が自分で遊ぶ（`--map3d-play` を 1-2 に広げる）
線が通ったら、方針 1〜3 を 1 回ずつ。第476期と同じ形のレビュー（`design/PHASE477_PLAY_REVIEW.md`）。迎撃の窓・門が開く所・勇者の所は早回しにせず写しを撮る。

## 4. 3D の 1-2（盤が §3 を通ってから）

### 4-1. 大きさとカメラ
- 盤は**横に 1 画面半〜2 画面ぶん**。開始時は拠点と分かれ道が見える位置。右へ動かすと砦が見える
- カメラの寄りは 1-1 より近く（駒と建物を大きく見せる）。横移動と拡大は今の操作のまま・Home で拠点へ戻る
- **画面の外で起きることを知らせる**:
  - 敵が歩き出した・拠点へ向かっている・湧いた・門が開いた・勇者が現れた → 画面の端に矢印の印（押すとそこへ動く）
  - 出来事で時計が止まるときは、その場所へカメラを寄せる（今の「出来事で止まる」に合わせる）
- 右上か左下に**小さな全体図**（道と拠点と隊と敵の点だけ・押すとそこへ動く）

### 4-2. 地形（位置の表に 1-2 を足す）
- 西: 辺境の砦（1-1 と同じ建物）と墓地。1-1 で越えた峠が奥に見えると繋がりが出る
- 北の山道: 尾根沿い。見張り台は崖の上の塔
- 中の街道: 石畳のまっすぐな道。関所は道をふさぐ柵と小屋
- 南の湿地の道: 沼と葦の中を曲がりくねる。渡し場は川べりの桟橋と小舟
- 東: 討伐隊の砦（石の城壁・門）。門が閉じている間は扉が閉まり、開くと開く
- 上下で対称に見えないこと。色と光は 1-1（第474期の値）と同じ系統
- 素材は今と同じ買ったアセット（リポジトリには入れない）。建物は仮の箱でよいが、**3 つの中間拠点が一目で別の場所と分かる**こと

### 4-3. 見せ方
- 中間拠点の名札に見返りを出す（「関所　金 ＋8」「見張り台　レリック」「渡し場　金 ＋12」）
- 門の札に「中間拠点 n ／ 2」
- 歩いてくる敵の進路を、道の上の赤い点線で出す（選んだ隊の金の点線と同じ作り）
- 行き先に触れたとき、留守になるなら「※ 拠点が空になります」（1-2 では出す。次に着く敵がいれば「あと n 刻で着く」も）
- 頭の札: 勝ち方（中間拠点を 2 つ取ると門が開く・門番を倒して砦を制圧）・3 つの中間拠点の違い・「敵は中の街道を歩いてくる」
