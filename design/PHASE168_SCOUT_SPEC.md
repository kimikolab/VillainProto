## 0. なぜ測るか

第167期の全部の表が同じ1点を指していた:

> **今の第二〜五波は、新品の5枚が勝っても 1.5〜2.5 枚を失う相手である**（カド隊×第四波 100% 勝ち・残り 3.50 枚／ハネ隊×第二波 76.5%・残り 2.67 枚）。
> 回復は HP には効くが枚数には効かない。主力級に2連戦すれば、5枚の隊は枚数の計算で保たない。

ポンの構想は最初から「**第一波＝斥候、第二波以降＝主力**」で、1部隊が 2〜3 戦するなら、そのうち 1〜2 戦は斥候級のはずである。
ところが今あるのは **教習波（第一波・3体・全編成 100%・駒の出力に何も足さない）と主力級4本**だけで、**あいだが無い**。

**ポンの決定**: 「倒れた駒を道中で戻す」（第167期 Q-1）は主軸にしない。**死亡した駒はそのステージではリタイア**のまま。
足りないものは敵の側に作る。

## 1. 部A —— 体数の曲線（斥候級を探す）

### 1-1. 候補（既存の第二〜五波から駒を抜くだけ。数値は1つも変えない）

波ごとに4形。席は元の席のまま（抜いた席は空ける）。

| 形 | 残す席 | ねらい |
|---|---|---|
| **M5**（対照） | 5席すべて | 現行の主力級 |
| **S4** | 前1・前3・中央・後3（後1 を抜く） | 支援役を1体減らす |
| **S3r** | 前1・前3・中央 | **波ルールの保持者（中央）を残す**斥候 |
| **S3n** | 前1・前3・後3 | **波ルールを持たない**斥候 |

- 第二〜五波 × 4形 ＝ **16 編成**。参考として**第一波（現行のまま）**も同じ表に載せる
- Phase 0 で、各形から**誰が抜けたか**と、**波ルールの保持者がどの席にいるか**を表にする
  （中央に保持者がいない波があれば、S3r / S3n の定義を「保持者を残す／残さない」で取り直して報告書の冒頭に書く）
- 第五波は殉教者（前1）と断罪の2枚がルールを持つ。S3n でも殉教者は残る。そのまま測って、表に注記する

### 1-2. 測る量（`compare` 61 行 × 17 編成 × seed 200。新品どうしの単発戦）

| 量 | 定義 |
|---|---|
| 勝率 | 61 行の中央値・平均・最小 |
| **残り枚数** | **勝った試行の**平均生存枚数。61 行の中央値 |
| 残り HP 割合 | 勝った試行の、定義上の総最大 HP に対する割合。61 行の中央値 |
| 情報セル | 勝率が 5〜95% に入る行の数（教習波は 0 のはず） |
| 残り枚数の幅 | 61 行の 残り枚数 の 10〜90 パーセンタイル幅（**編成によって消耗が違うか**） |

### 1-3. 斥候級の線（測る前に固定）

| 点 | 中身 |
|---|---|
| 量 | 61 行の**勝率の中央値**と**残り枚数の中央値**の組 |
| 単位 | %・枚 |
| 対照 | M5（現行）と第一波。**M5 の残り枚数の中央値が 2.5〜3.5 枚に入ること**を先に確かめる（第167期の 3.50 / 2.67 と整合するか） |
| 依存変数 | 波（4本を別々に判定）／波ルールの有無（S3r と S3n を別々に判定） |

> **斥候級 ＝ 勝率の中央値 ≥ 90%、かつ残り枚数の中央値が 4.0〜4.7 枚**
> （5.0 に張り付くのは教習波と同じで、1戦ぶんが無駄になる・第165期 §4）

- **線A: 4波のうち 2波以上で、斥候級の形が1つ以上ある**
- 線A が × なら部B に進まず、「残り枚数の中央値が 4.0 に最も近い形」を波ごとに挙げて止まる

## 2. 部B —— マップを「斥候 → 主力」で回し直す

### 2-1. 道

| 道 | 1戦目 | 2戦目 |
|---|---|---|
| 北 | **第二波の斥候級** | 第三波（M5） |
| 南 | **第四波の斥候級** | 第五波（M5） |

- 斥候級の形は部A で線を通ったものを使う。**S3r と S3n の両方が通った波は、両方で回す**
  （北の S3r は粛を持つので カド×粛 が残る。S3n では消える。**この差が部B でいちばん見たいもの**）
- 第二波・第四波に斥候級が無い場合は、通った波で組み直し、組み直した旨を冒頭に書く

### 2-2. 隊

- カド隊 ＝ `反撃 (ヒサ×カド)`、ハネ隊 ＝ `突き返し (ハネ×ウツ)`。重なるのはガルド1枚（第167期 Q0-1）
- **第167期はガルド → ガンでハネ隊が大きく弱くなった**（95.5/96.5/98.5/54.0 → 76.5/73.0/57.5/30.0）。
  今回は**埋める駒を「どこでも同じ」群の `checkup` 単独 上位5枚で試し、ハネ隊の第2〜5波の単発勝率の平均が最も高い1枚**を採る。
  5枚の結果を表にする
- 第3隊（控え）は第167期と同じ `死軸×ヒヨ (ゾト×火選り)`。出す規則も同じ

### 2-3. 回復

**道中の回復は 50% に固定**（第167期: 50% で飽和）。対照として 0% を1回だけ回す。

### 2-4. 線（第167期と同じ量・同じ線。動かさない）

| # | 線 |
|---|---|
| 線1 | 正の割り当てで、**2隊それぞれの2本抜き率が 30〜70%** |
| 線2 | **対比（正 − 逆 の部分点）≥ 0.5 点、かつノイズの 3 倍以上** |
| 線3 | **逆の割り当ての挽回率が 20〜80%** |
| **本丸** | **同じ設定で 線1・線2・線3 が同時に ○** |

片方の隊だけが帯に入った場合は △ とし、外れた隊と向きを書く。
