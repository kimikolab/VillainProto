### 0-2 「源」化の実装点

- **勇者の札にした**（`HeroCrest`・勇者の印）。`BlocksControl => true` で第261期の速い経路（`UnitState.ControlProof`）に乗り、
  入口 `UnitState.SetCounter` で新しい問い `Trait.BlocksControlNow(self)` を引く——勇者の印だけが「同じ陣営に支え（`HeroWard`）が生きているか」を返す。
  **勇者以外の駒は問われない**（`ControlProof` が偽なら bool 1つで抜ける。第261期の `BossSteadfast` は既定 `=> BlocksControl` で常に塞ぐ）。
- 支え側の札（`HeroWard`）は印だけ。支え側に置いて「勇者を探して塞ぐ」形にすると、`SetCounter`（全駒の熱い経路）で全駒が盤面を引くことになるので採らなかった。
- **倒れた瞬間に既に付いていた転倒等: 存在しない。** 支えが生きている間は入口で付かないので、倒れたときに解くものが無い。**倒れたその場から**（同じ手番の次の一撃から）付く。
- 癒し手（`HeroMend`）は `PartyMendPctTrait`（W3-割合）と同じ席（ターン頭・刻みの後）・同じ式（最大HPの 40%）で、対象を勇者の印の持ち主だけにした。1,200 ／ ターン。

### 0-3 取り巻きの席と到達手段（`FormationRules` の表で確認）

前列が空の波なので、**単体は中列（＝勇者）が倒れるまで後列に届かない**。勇者が生きている間に取り巻きへ届く経路は:

| 経路 | 後1（席 3）| ○後2（席 8）|
|---|---|---|
| 単体・執着など | 届かない（中列が生きている）| 届かない |
| 薙ぎ | 届かない（中央を薙ぐと巻き込むのは ○中1・○中3 だけ）| 届かない |
| 貫き | **届く**（レーン 0 = 前1 → 中央 → ○中1 → 後1。勇者の次の 75%）| **届かない**（どのレーンにも属さない）|
| 全体 | 届く | 届く |
| 隣接に広がるもの（放電・延焼・毒漏れ）| 届く（中央と隣接）| 届く（中央と隣接）|

- 指示書 §3 の「（貫き以外届かない）」は「貫き**だけが**届かない」の意で、表と一致する。**席の課税は「貫きを持つ台」にだけ効く**
- 勇者が倒れた後は、取り巻き2体は後列で単体でも届く（○後2 は後1 と同じ後列）

## 2. 予測（測る前に固定）

勇者の回復は 1,200 ／ ターン（B3-桁 は全快）、取り巻きは 145 × 2。

- **燃焼**（全体 ×4・延焼）: 取り巻きは全体と延焼で**巻き添えに**割れる（T2〜3）。順は「癒・支 → 勇」が最多。2版の差はほぼ無い。倒しT は B3-桁（T3.0 ／ T4.0）以下
- **雷**: 勇者への放電が隣接の取り巻き2体に等しく届くので、取り巻きが先に割れる。倒しT は B3-桁（T5.4）より縮む。2版の差は小さい
- **移動**（単体・1発が重い）: **取り巻きに届かない**（貫きが無い限り）。順は「勇 → …」がほぼ全部。支えが最後まで生きるので転倒は最後まで通らない（指示書の予測「支えを先に割る」は外れると予測）。回復が全快 → 40% になるぶん、倒しT は B3-桁（T7.4）より縮む
- **混ぜ**: 取り巻きが増えたぶん、全体への被弾反応で手数が伸びる——倒しT は B3-桁（T7.5）より縮む
- **毒・毒+ベニ+ラウ**: 1,200 ／ ターンを上回れず、癒し手にも届かないので **0%**（毒台は許容）
- **5-1（割る順序の分化）**: 「取り巻き先」（燃焼・雷・混ぜ）と「勇者先」（移動）の **2 通り** → ○。ただし分かれる理由は軸の意図ではなく**到達手段**（全体・放電を持つか）
- **5-2（倒しT の順位の入れ替わり）**: 席の違いが効くのは貫きの台だけなので **0〜1 台** → × 寄り
- **5-3（全軸が勝てる）**: 毒以外に 0% は出ない → ○

### 4-1 なぜ分かれなかったか

1. **取り巻きは T1.2〜T3.0 に、全台で、勇者より先に割れる。** 145 の体は、全体（燃焼）・放電（雷）・貫き（移動のセロ）・**敵陣の席替え**（移動のバサが癒し手と勇者を入れ替え、勇者を後ろへ押し下げる）・毒の広がりのどれでも1〜2ターンで落ちる。
   Phase 0-3 の到達表（「単体は勇者が倒れるまで後列に届かない」）は**移動軸の席替えと乱れ撃ちを数えていなかった**——表の上では届かない席に、移動は T1 に届いている（`bosswave log 移動 H-制御税 0`）
2. **順は席で決まる。** 後1 は貫き・隣接・席替えのどれでも届き、○後2 は貫きが届かないぶん1手遅い。だから後1 にいる役が先に割れ、2版で順が**役ごと入れ替わるだけ**になった（表2 の割合が2版で鏡写し: 燃焼 T3-244 61.0 ／ 39.0 ↔ 39.0 ／ 61.0）
3. **厚くしても変わらない**（§3-1）。×8（1,160）でも全台が「後1 → ○後2 → 勇者」のまま。×2 以上で異なる順が 2 になるのは、毒+ベニ+ラウが勇者を倒せなくなった（「癒→支」で止まる）だけで、軸の分化ではない
4. **オートバトラーでは「割る順序」は選べない。** 順を決めるのは編成の到達手段と標的の規則で、プレイヤーの選択ではない。軸ごとに順が分かれるには、**軸ごとに到達手段が違う席**（ある軸にしか届かない席）が要る——今の盤面では、後列の2席はどちらも「全体・隣接・席替え・乱れ撃ち」のどれかで全軸から届く

### 4-2 副次の観察

- **2版とも B3-桁 よりずっと易しい。** 取り巻きが T2 前後に落ちると、勇者は回復も動じないも失った HP 3,000 の的になる。毒（B3-桁 0%）が 100%（倒しT T6.0）、毒+ベニ+ラウ（0%）が 89.0%（T13.9）、移動（82.0%）が 100%（T3.5）。純実入りは毒の2台以外 ±0 前後
- **勇者が振れた手番**: 支えが T1.5〜T2.0 に割れた後は、移動 36〜56%・混ぜ 38〜61%・雷 61〜66% まで削れている（B3-桁 は 81〜93%）。**「支えを割れば制御が通る」は機構としては働いている**——ただ、全台が T2 までに割るので差にならない
- **速 5 → 14 の効き目**（B3-桁 → B3-速14）: 移動 82.0 → 71.0%（倒しT T7.4 → T6.8）・雷 T5.4 → T6.1・燃焼 T3-255 T4.0 → T3.0。速さは移動にだけ勝率で効く
