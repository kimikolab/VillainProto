## 0. 前提の訂正（指示書とリポジトリの食い違い・4件）

**止めずに進めた。**

1. **§5-1 の「`MarkPullPercent = 75` が確率なのか重みなのか」は確率だが、実効値は 75% ではない。**
   `marked != target` のときしか引かないので、**標持ちが pool にいれば `1/n + (1 − 1/n) × 0.75`**。
   実測の「効き・味方」は **81.9% / 85.8%**（予測 75〜87.5% の範囲内）。
2. **§3-1 の手順は「敵に付けた標を消す」を含まない**ので、**敵の標は戦闘が終わるまで溜まる。**
   指示書は `TargetCount` を「焦点の鋭さ」と書いているが、
   **`TargetCount = 1` でも焦点数は 1.16〜1.68（最大4）まで自然に増える。**
   仕様どおり実装し、`焦点数` の列で測った（§6）。
3. **§3-2 の「`TargetCount` を増やすと分散して効果が薄れる」は半分だけ正しい。**
   **総量は増える**（味方の単体振りのうち標持ちに当たる割合 81.9% → 95.4%）。
   1体あたりが薄まるのと打ち消し合って勝率が動かない。**指示書の予測も私の Phase 0-2 の分析も
   ここを外した**（§7 に訂正の全文）。
4. **§4 の「自傷: 標が原因で引いた分の推定」は推定を作らずに済んだ。**
   engine の鎖に計数を1つ置けば「敵の単体振りのうち標持ちの味方に当たった割合」が直に取れる。

### 1-2. `MarkPullPercent` の実装（**この駒の設計の前提**）

```csharp
UnitState? marked = PickOne(foes.Where(f => f.Counter(StatusKeys.Marked) > 0).ToList());
if (marked is not null && marked != target && Roll(100) < MarkPullPercent) { ... return marked; }
```

1. **75 は確率だが、実効の被狙撃率はそれより高い**（`marked != target` の但し書きのため）。
2. **`foes` から選んでいる（`pool` ではない）。** ⇒ **標は「前列が生きている限り後列は
   狙われない」という盤面の中核規則を破る**——ロスターで**標だけが持つ性質**
   （執着・断ちの選好は `pool` から選ぶので破らない）。**この期の効き目の正体はここだった。**
3. **標持ちが複数いると `PickOne` で1体に絞ってから引く。**（§7 で訂正）
4. **鎖の順序は 標 → 後備え → 庇う → 殉教 → 棘守り で、標がいちばん先。**
   引いた瞬間に `return` するので、**標は庇い・後備え・殉教をすべて飛び越す。**
5. **単体攻撃にしか効かない。** 薙ぎ・全体・貫きは標を1ビットも見ない。
6. **両陣営で対称**（陣営に依存する分岐が1つも無い）。

### 1-3. 標を消す経路は 0 件 ／ 敵に標が付く経路も 0 件

`StatusKeys.Marked` の全出現は 5 箇所で、書き手は `Traits.cs:1374`（囃し立て）**1つだけ**。
**`SetCounter(StatusKeys.Marked, 0)` は grep で 0 件。**
`Stages` に出る敵で `Marker` を持つ駒も **0 体**。
⇒ **「消す」も「敵に付ける」も、この期が初めて。**

——`marked != target` のときしかログを出さないので、たまたま標持ちが先に選ばれた回は入らない。

### 4-2. 符号反転はカド固有（**§6-7 の答え**）

**カド無しの台では符号が反転しない**——第3〜5波すべて +。
探索段階でも **カド入り・ヒサ無し**の候補（カド/ガルド/ノノ/ソラ/ネル）は帰属 **+0.1** で、
**カドとヒサの両方が要る**ことが分かっている。

⇒ **この駒は「カドの相方」ではない。** 符号反転のほうがカドの性質で、
**逸らしそのものは一様に強いプラス**だった。

### 4-3. なぜカド台で符号が反転するか（機構の実測）

| 行 | 版 | カド寿命 | カド干渉 | 第4波 | 第5波 |
|---|---|--:|--:|--:|--:|
| 逸らし (ソラ×カド) | T1 | 3.62 | 12.31 | 78.0% | 50.5% |
| | 素体 | 2.66 | 14.47 | 99.5% | 20.0% |
| | **差** | **+0.96** | **−2.16** | **−21.5** | **+30.5** |

**カドは標を手放すと長生きするが、振る回数が減る。**
（`干渉` は反撃を含む「盤面を動かした回数」。カドは不動なので、これがほぼ丸ごと反撃。）

- **第四波**（城塞守備隊・単体攻撃ばかり・断罪なし）: 殴られ続けることが**収入**。
  標を外すと反撃が回らなくなって **−21.5pt**
- **第五波**（異端審問団・断罪2体・範囲3枚）: 殴られ続けると**先に潰される**。
  標を身代わりが持ち去ると **+30.5pt**

> **反撃役にとって標は「収入」でもあり「死因」でもある。**
> どちらに振れるかは**波の攻撃型の構成**（単体が多いか、範囲と断罪があるか）で決まる。

## 5. 「代金」は代金ではなかった（受け入れ基準9）

対照2（`SelfMark = false`＝自分に標を付けない版）との差:

| 行 | T1 | 代金なし | **代金の値段（T1 − 代金なし）** |
|---|--:|--:|--:|
| 逸らし (ソラ×カド) | 65.0% | 61.1% | **+3.9**（第5波だけで **+27.5**） |
| 逸らし改 (ソラ×ノミ) | 79.3% | 46.0% | **+33.3** |

**自分に標を付けるのを止めると、両方の台で弱くなる。**
指示書は「引き剥がした視線は自分に刺さる」をマイナス側として設計していたが、
**実測では最大のプラス**だった。

理由は2つ:

1. **味方から標を外しただけでは、敵の攻撃は散るだけで減らない。**
   ソラが引き受けると**1体に集める**ことができ、そこを守れば全体の被害が減る
2. **`逸らし改` ではソラ（後3）が大喰らいゴルム（前3）の巨躯の被覆に入っている。**
   実測で敵の単体振りの **73.2%** がソラへ向き、その大半をゴルムが肩代わりする
   ——**代金を肩代わり役に払わせるのが正当な配置解**（第41期の「ハネの隣をガルドで固める」と同型）

> **「矢面に立つ」は、肩代わり役と組んだ瞬間にプラスへ反転する。**
> ロスターには肩代わりが5種（庇う・分かち・巨躯・後備え・棘守り）あるので、
> **標を集める駒は肩代わり役の数だけ組み合わせを持つ。**

ソラの寿命は **2.12T（カド台）/ 5.28T（カド無し台）** で、**2.5 倍違う**
——予測4（3〜4T で落ちる）を外したのは、**被覆の有無を計算に入れなかったから。**

## 7. 掃引（受け入れ基準11）と、**私が Phase 0 で立てた式の訂正**

| 行 | TC1 | TC2 | TC3 | 全幅 | 効き・味方（TC1 → TC3） |
|---|--:|--:|--:|--:|---|
| 逸らし (ソラ×カド) | 65.0% | 66.0% | 64.4% | **1.6pt** | 81.9% → **95.4%** |
| 逸らし改 (ソラ×ノミ) | 79.3% | 79.5% | 80.5% | **1.2pt** | 85.8% → **97.4%** |

**Phase 0-2 で「標を n 体に付けても標の集合が引く合計は 75% のまま」と書いたのは誤り。**
正しくは、標持ちの集合に当たる確率は

    p_t + (1 − p_t) × 0.75      （p_t = 無作為の主目標が既に標持ちである確率）

で、**n が増えると `p_t` が上がるので総量は増える**（実測 81.9% → 95.4%）。
1体あたりの取り分は逆に薄まる。

> **`TargetCount` は「集中」と「被覆」を取り替えるノブ**であって、
> 総量のノブでも純粋な分散のノブでもない。**勝率の全幅が 1.2〜1.6pt なのは
> 2つが打ち消し合うから**で、ノブが機構を動かしていないからではない
> ——第41期（比が全点 2.30 で不動）・第47期（纏い率 35.8 → 40.1%）とはここが違う。

第41・47・49期に続く**4期連続の全幅 3pt 未満**だが、
**機構の計数が動いた度合いは 4 期で最大**（81.9 → 95.4pt の 13.5pt 差）。
**「掃引の全幅が小さい」は3通りの意味を持つ**——(a) ノブが機構を動かさない（41・47期）／
(b) ノブは動かすが機構の出力が小さい（49期）／
(c) **ノブは動かすが、動かした2つの量が打ち消し合う（今期）**。
**全幅だけを見て診断してはいけない。**

どちらも**採用閾値 5.0pt に届かない**。

**§1 の新しい作法（発火が 0 になっていないか）も確認した**——
`confirm` に出た全候補で発火 **1.56〜4.61 回/戦**、**0 の席が1つも無い。**
第49期の業改（配置探索が引き取りを 0.00 回/戦にする席を選んだ）とは対照的で、
**逸らしは全席で発火する**（外しと焦点が隣接も列も条件にしないため）。

| 行 | ソラの最適席 | 次数 | 上位5の席（3値） | 最頻率 |
|---|---|--:|---|--:|
| 逸らし (ソラ×カド) | 後3 | 2 | 前角0 / 中央2 / 後角3 | **60%** |
| 逸らし改 (ソラ×ノミ) | 後3 | 2 | 前角0 / 中央0 / 後角5 | **100%** |

**ソラ1枚だけを振ると席は決定的に効く**（`逸らし`: 前1 32.1% / 前3 30.4% / 中央 61.7% /
後1 63.6% / 後3 65.0%。`逸らし改`: 前列 58.8〜60.7% / 中央・後列 78.1〜79.9%）。
**動かしているのは列**で、前列に置くと素の被弾と標の被弾が重なって寿命が
**2.12 → 1.80T（カド台）/ 5.28 → 2.60T（カド無し台）**まで縮む。

> **3値（前角 / 中央 / 後角）は「列で決まる駒」の固定度を過小評価する。**
> `逸らし` のソラは上位5通りで**前角 0**（中央2 + 後角3）＝「前列以外」に完全に固定されているのに、
> 中央と後角が別の箱なので最頻率は 60% にしか出ない。
> **列で決まる駒には 2値（前列 / それ以外）を併記すべき**——第45期の3値は
> 「隣接を読む駒」を測るための分割で、列を読む駒には粒度が合っていない。

## 11. 残件

### A. **標の3枚目**（指示書 §9 は「測ってから判断する」としていた）

**まだ要らない。** 書き手が2枚（ヒサ＝味方に1回・ソラ＝毎ターン敵と自分）になったことで、
標は「操作可能な通貨」の最低条件を満たした。**ザン（読み手）の燃料も消えていない**
——ソラが味方の標を全部剥がしても、**ソラ自身が毎ターン確実に殴られる**ので
ザンの発火先がソラに移るだけ。**ヒサ⇔ザン の相互唯一ペアは、ソラが3枚目として
両方に接続したことで解消に近づいた**（ヒサを切ってもソラが標を供給する）。

### B. **3値の粒度**（§8）

**列で決まる駒には 2値（前列 / それ以外）を併記する。**
第45期の3値は隣接を読む駒のための分割で、`逸らし` のソラのように
「前列以外なら中央でも後列でもよい」駒では固定度を過小評価する。
**`seats2` に列の2値を足すのは独立した作業**なので、この期では診断のローカルに留めた。

### C. **敵の標を消す経路**（仕様の帰結）

外すのは味方の標だけなので、**敵の標は溜まる**（焦点数 最大 4）。
`TargetCount` の掃引が平らなのは総量と取り分が打ち消し合うためで、
**焦点を鋭く保ちたければ「付け直す前に前回の焦点を消す」版が要る。**
測っていない。**`DivertRule` にフィールドを増やす形になるので、
1変数を振る作法（第46期）と衝突する**——やるなら独立した期で。

### D. **engine の窓口一覧を棚卸しの雛形にする**（§1-1）

第48期・第49期の残件Bをここで固定した。**次に通貨の厚みを数えるときは、
駒の `Trait` と engine の窓口を必ず両方数える。**
`census` に engine 側の窓口の列を足すのが自然だが、**あの表は grep と目視で作る**という
作法があるので、`divert phase0` の表を手で写す形にしてある。

### E. この期で触っていない持ち越し

幅の供給側（第49期の業の再挑戦）／敵側の読み手（第48期）／
`ScaleRule` のノブの付け替え（第47期）／`AcceptsSupport` の統一（第42期）／
`reseat` +2.0pt で採った配置換えの洗い直し（第45期）。

## 12. 実装のメモ

- **`DivertTrait` は engine に規則を1つも足していない。** 標の窓口
  （`SelectTargetChain` の `MarkPullPercent`）は元からあり、**書き手と消し手を駒側に作っただけ。**
  engine に足したのは計数のフック4箇所（標の引き／単体振りの着地点／敵の撃破ターン／`Add` の検出）で、
  **すべて `DivertActive` で短絡**する。
- **`DivertRule(TargetCount, SelfMark, Audit)`。** ノブは `TargetCount` だけ。
  `SelfMark` は**代金を分離するための対照**、`Audit` は**素体の対照でも同じ切り方で数えるための
  計数スイッチ**で、どちらもノブではない（第49期の `ScapegoatRule.Audit` と同型）。
  **監査が盤面を動かさないことは診断 §0 が 260 セルで毎回検算する。**
- **敵の選択は決定的**（現在HP最大から順に `TargetCount` 体・同値のみ `PickOne`）。
  `foes.Remove(pick)` で同じ相手に2回付けない。
- **味方に標が1つも無くても発火は止めない**（外す対象が無いだけ）。
  止めると「味方が綺麗なら何も起きない」駒になり、代金だけが残る局面が作れなくなる。
- **`逸らし (ソラ×カド)` の中央はグザ(58)でなければならない。**
  ヒサ（後1）の隣接最大HPが カド(96) になる条件で、ソラ(96)を中央に置くと同値になって
  `PickOne` が 50/50 に割り、**残件Aの再現条件が汚れる**（実測で帰属が 1/4 に落ちる）。
