## 5. Codex への依頼の下書き（`design/CODEX_BRIEF_KARZ.md` の骨子・ポンが見てから回す）

1. 対象は DemoApp だけ（`BattleCore` ／ `BattleSim` ／ `docs/` は触らない・Claude Code のコミットと分ける）。
2. 祟りのカーズの手番「呪いを刻む」の見せ方: 刻む相手（印を付けた敵）へ短い刻印の演出を出す。
3. 刻まれた敵が殴るたびの −4 を、その敵の頭上に「−4」と呪いの色で出す（同じ敵に重なるたび濃くなる）。
4. 読むのは台本の既存の出来事だけ: 手番の `Action` 名札「呪いを刻む」、`StatusGain`（弱体 `dull`・書き手 ＝ カーズ・量 4）。足りなければ表示専用の出来事を足す相談をする（engine 側は Claude Code）。
5. 刻める敵がいない手番はふつうに殴る（既存の攻撃の演出のまま）。
6. 立ち絵はポンが後で作る。`DemoApp/assets/` の素材は既存のものを先に探す（`CONTRIBUTING.md` の背景・演出の手順）。
7. 確かめ: 「試遊・カーズ 呪い」の単発の再生（ボス `--demo-playtest-stage=0` ／ 本編 第4波 `--demo-stage=3`）が最後まで通り、`compare` に差が無いこと。
