# 第445期 指示書 —— 駒の売買（ゴールド・小さく）＋ 勝ちの条件を対称に ＋ 記録の HP の分母

前提: 第444期（`801355a6`）・観察ログ `design/PHASE444_WATCH_LOG.md`。
第444期で分かったこと: 見返りの増援 5 枚は序盤で尽きて「気づいたら増えていた」／中間拠点は敵の拠点の隣で使う意義が無い／
「こちらは拠点を落とされたら負けなのに、相手は落とされても続く」は怠い。

ポンの決定（2026-11-03）:
- **増援はゴールドで「呼ぶ」。小さく作る**（店・値段差・リロール・持ち越しの経済は作らない）
- **同じキャラは盤上に 1 体まで**（複数運用は無し。被りは将来 ☆ の重ねにする——この期では被りが出ない母集団にして保留）
- 勝ちは制圧で対称に

## 0. 作るもの（すべて `Stage12` の値で切れる）

### 0-1. ゴールド

| 項目 | 値（仮・ポンが遊んで決める） |
|---|---|
| 開始 | 0 |
| 敵部隊を 1 つ抜く | **+6**（湧いた部隊は +3） |
| 中間拠点を取る | **+8** |
| 使い道 1: **呼ぶ** | 候補 3 枚から 1 枚・**10**。値段は全部同じ |
| 使い道 2: **3 隊目の枠** | **12**（`SquadCap` は 2 で始まり、買うと 3） |
| 使い道 3: **売る** | 控えの駒を手放して **+3**（盤上の隊からは売れない） |
| ステージをまたぐ持ち越し | 無し |

- 第444期の「見返りで駒が届く」は**切る**（`ArrivalRule.Off`）。駒の供給はゴールドだけ
- **呼べる場所**: 味方の拠点・取った中間拠点・第2拠点にいる隊の組み直しの窓（第443期の迎撃の合間も含む）。呼んだ駒はその場の手札に入る
- **候補 3 枚**: 母集団は**現役 52 枚のうち、盤上と手札にいない駒**（＝被りが出ない）。seed で決めた列から 3 枚を見せ、買うと列の次の 1 枚が補充される。リロールは無い。候補は窓を閉じても変わらない
- 開始の 10 枚は第441期の保証つきの引きのまま
- 画面: 盤の上の行に「金 n」。組み直しの窓に「呼ぶ（10）」の 3 枚と「3 隊目の枠（12）」「売る（+3）」。トースト「＋6（第三波を抜いた）」

### 0-2. 勝ちの条件を対称に

- `Stage12`: **敵の拠点を制圧したら勝ち**（残った敵部隊は退く）。`Map11State.Won` を盤ごとの値（`WinOnCapture`）で切れる形に。`Stage11`・`Stage12H440〜H444` は今の「制圧＋盤上の敵 0」のまま
- 結果画面に「退いた敵部隊 n」を出す（掃除をしなかったことが見える）
- 勇者の予告: 上限 **14 → 12**（仮）。制圧の刻の分布（器具）を報告に並べる

### 0-3. 記録の HP の分母

`Map11Session.CompleteBattle` の HP の割合を「いまのロスターの最大 HP」に（第174期の `SquadHpPercent` と同じ）。表示だけ。

### 0-4. 中間拠点はそのまま

評価は盤を長くしてから（第444期の宿題 3）。この期では触らない。
