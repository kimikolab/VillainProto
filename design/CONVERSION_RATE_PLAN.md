## 0. この作業の位置づけ

**測定の締めくくり。** 第4期以降ずっと「編成の序列を動かす軸」を探してきたが、「予測できない」が5期連続で変わっていない。

| 期 | 試したこと | 説明力 |
|---|---|--:|
| 第13期 | 台をまたぐ入れ替わりを編成側特徴量で | r² 0.19 |
| 第15期 | 波ごとの勝率、効き方の一致度 | r 0.16 |
| 第16期 | 敵側特徴量との積（`総攻` 材料） | r² 0.003 |
| 第17期 | 積の材料を実効出力 (A)(B)(C) に差し替え | r² 0.002 |

**第17期で「特徴量が悪い」説はほぼ否定された。** (A) は `総攻` と ρ −0.44 の**別物**（符号すら逆）なのに、積にしても 1ミリも動かない。

**ただし1つだけ、17期分ずっと主役だったのに単独で振っていない軸がある——個体HP。**

- 第6〜7期: 「符号を決めるのは個体HP、大きさを決めるのは体数」
- 第16期: 甲乙の軸は「個体HP と総攻」
- 第17期: 甲乙の軸は「育つか」ではなく**「撃破に変換されるか」**。毒は (B) 16.97 で最大なのに乙群

**「撃破に変換されるか」は、味方の打点と敵の個体HP の関係で決まる。** これを測らずに終わるのは惜しい。**この作業でそれを測り、動かなければ測定を打ち切って設計に移る。**

## 2. Phase IA — 変換率

### 2-1. 測るもの

**同じ出力が、敵の個体HP によってどれだけ撃破に変換されるか。**

参照台を**個体HP だけ変えて**複数用意し、各編成の (A) 実効打点/ターン がどう変わるかを見る。

- **打点が個体HP に依存しない編成** → 変換の問題を持たない（オーバーキルしない、あるいは撃破と無関係に削る）
- **個体HP が上がると打点が落ちる編成** → 撃破に依存する出力（撃破ごとに何かが起きる、敵が減ることで被弾が減り生存時間が伸びる、など）
- **個体HP が上がると打点が上がる編成** → 積み上げ型（毒・燃焼。的が長生きするほど段が乗る）

**変換率 = 個体HP を振ったときの (A) の変化率。** 表し方は実装者判断でよいが、**明記すること**（例: 低HP台と高HP台の (A) の比、あるいは log(個体HP) に対する回帰の傾き）。

### 2-2. 台の系列

第17期の主台 `ZealotPorter`（重甲の荷駄兵 90/7/5）を基準に、**個体HP だけを振る**。

**守る要件（第17期 HA で確立したもの）:**

- **1体あたり攻 > `CurseTrait.EnemyDebuff`（= 6）。** 呪詛（ネル）が敵全体の攻撃を −6 するので、攻 6 以下の的は `ApplyDamage` の `if (amount <= 0) return;` に落ち、**1ダメージも通らず `OnDamaged` が呼ばれない**（反撃・被弾強化が走らない）。第17期で巡礼6（攻4）が却下された理由
- **攻撃力・速度・パターンは全刻みで固定。** 振るのは個体HP だけ
- **総HP は揃えるか、揃えないかを選ぶ**——ここは設計判断。**どちらにしたか、なぜかを書く**
  - 総HP を揃える（体数で調整）と、**体数が同時に動く**。第17期で体数の辺は余地 0.08〜0.15 と小さかったので、影響は限定的なはず
  - 総HP を揃えない（体数固定）と、**戦闘長が同時に動く**
  - **両方作って比べるのが理想**。時間が許すなら両系列を測る

刻みは**最低4点**。味方の実測打点（第6期で `pulse.md` から出た 中央値 10.6 / IQR 4.4〜20.4 / p90 51.1）を跨ぐように取る。目安: 30 / 60 / 90 / 145 / 220 あたり。

**新しい `UnitDef` は、刻みを作るためだけなら作ってよい。** 新 Id・理由コメント必須。既存 def（`Levy` 30 / `ZealotPlate` 60 / `ZealotPorter` 90 / `Warden` 145）で足りるならそれを使う。

### 2-3. 出すもの

1. **編成 × 個体HP の (A) 表**（31編成 × 刻み数）
2. **変換率**（編成ごと1つの数字）と、その順位
3. **変換率の上位・下位5編成**。第17期の (C) 手番外% と並べる
4. **変換率と、既存の分析の突き合わせ**:
   - **第16期の甲乙の12事例と一致するか**（甲乙の軸が「撃破に変換されるか」なら、変換率で分離できるはず）
   - **交互作用成分の説明力**。変換率を材料にした積で上がるか。**第16期 r² 0.003 / 第17期 r² 0.002 と並べる**
   - 波ごとの勝率の第一近似が替わるか（第15期・第17期と並べる）

### 2-4. 積の作り方

**第16期・第17期と同じ制約。10個以内、総当たり禁止。**

変換率を使う積は理屈で決める。例:

- `変換率 × 敵の個体HP中央値`（変換に敏感な編成が、硬い敵でどうなるか）
- `変換率 × 敵体数`
- `(A) × 変換率`（出力と変換の両方を持つか）

**選んだ理由を全部書く。**

### 2-5. 受け入れ条件

- 26モードすべての差分 **ゼロ**
- 台の系列の定義と、総HP を揃えたか否かの判断理由
- 変換率の定義（表し方）
- 第16期・第17期との対比表

## 3. Phase IB — 記録と総括

### 3-1. 判定

| 観測 | 結論 |
|---|---|
| 変換率で甲乙が分離でき、積で交互作用成分の説明力が上がる | **17期分の壁が解けた。** 変換率が探していた量。**設計に直接使える** |
| 変換率で甲乙は分離できるが、交互作用成分は上がらない | **甲乙は実在するが、交互作用の説明ではない。** 分類としては使える（キャラの役割設計に） |
| どちらも動かない | **測定は打ち切り。** 交互作用は実在するが数値では読めない、で確定 |

**どの行でも、この作業で測定を終える。** 3行目でも失敗ではない——「読めない」ことが確定すれば、設計側で**読める交互作用を作りにいく**という方針が定まる。

### 3-2. README に書くこと

**測定の総括を独立した項で書く。** 第4期から第18期までの15期分で、何が分かって何が分からなかったか。少なくとも:

**分かったこと**

- 交互作用は実在する（第15期。寄与する7波の21ペア全部が ρ < 0.90）
- 交互作用成分は全分散の 28.3%（第16期）
- **片側だけの特徴量は交互作用成分と構造的に相関しえない**（第16期。恒等式）
- 骨格は2つの時計（第16期）。軸は「撃破に変換されるか」（第17期）
- `総攻` は出力ではない（第17期。(A) と ρ −0.44）
- 参照台という手法と、中立性の確認の仕方（第17期）
- 半割 0.99 という信頼性の上限（第13期）
- 呪詛の崖: **敵の1体あたり攻は 6 より大きくないと、呪詛で無効化される**（第17期）。**今後の敵設計の要件として明文化する**

**分からなかったこと**

- どの編成がどの波に強いかを、数値で予測すること（5期連続）

### 3-3. 「未解決の課題」

- 会戦側の残件はそのまま
- **測定の打ち切りを明記する。** 「これ以上の特徴量探索は行わない。設計側で読める交互作用を作る方針に移る」

### 3-4. 報告してほしいこと

1. **変換率をどう定義したか。** 台の系列と、総HP を揃えたか否か
2. **変換率の上位・下位5編成。** 直感と合うか（毒軸・反撃軸・速攻はどこに来るか）
3. **甲乙は分離できたか。** 第16期の12事例と照合
4. **交互作用成分の説明力。** 第16期 0.003 / 第17期 0.002 と並べて。§3-1 のどの行か
5. **測定の総括として、設計に持っていける知見はどれか。** ポン氏が次にキャラクター設計をするときに使えるもの

## 4. 作業ルール

1. IA → IB の順。**フェーズを跨いで1コミットにしない**（IB は文書のみ）
2. コミットメッセージに「動いた docs/ の行」を書く。**全フェーズ差分ゼロのはず**
3. コード・コメント・ログは日本語。既存の文体（**却下した案とその理由も書く**）に揃える
4. CONTRIBUTING.md のチェックリストを通す
5. 長時間ジョブは前景で待ち切る。`layout` は走らせない
6. **何も直さない。** `BattleCore` に触れる必要が出たら方法が間違っているサイン
7. **判定が出たら止める。** §3-1 の3行目でも、追加の測定を提案せずに終える
8. 以下を見つけたら**実装前に止まって報告する**:
   - 個体HP を振ると、第17期で確立した中立性の要件が満たせなくなる場合
   - 刻みの一部で決着してしまい、(A) が比較できない場合
   - `docs/` が動いた場合
