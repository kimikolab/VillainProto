# 第118期 —— 時間を買う機構（自己回復タンク）を作って測る

起点: 第117期。**ボスの土台は立たなかった。**

> 傾き（後半3T ÷ 前半3T の与ダメ/T）は 16 組すべて **0.06〜0.30**。1.0 超えは **0 組**。
> 敵HP ×4 の長期戦でも 0.03〜0.18 と**むしろ下がる**——落ちているのは味方の側。
> **育ちは本物**（ムド 3.0 → 36.1 ＝ 12.0 倍）。足りないのは項ではなく**ターン数**で、
> 育つ駒の生存Tが 3.3〜7.5T しかなく**後半3T には盤上にいない。**
>
> **Q3 が落ちた。「死なない」4枚のうち時間を買っているのはゴルム1枚**（+1.30T）。ヴェルは **−0.14T** で符号が負。

**壁3つのうち「時間を買う手段が薄い」が、実測で「1枚しかない」に確定した。**
被害で育つ側を何本足しても、**振る回数が生存で切られる**（第114期「積んだ量ではなく振った回数」の3つ目の顔）。

**この期は時間を買う機構を1つ作る。** ただし——

> **第115期の形を踏襲する**: 機構を作って**ローカル台で測るだけ**。
> **`UnitCatalog.All` に入れない。`Presets` を触らない。`compare` は 305 セル 0 件。**
> **差し替え先の判断は次の期**（第117期 §8-3 のとおり、いまは1枚も名指しできない）。

**この指示書は自己完結させてある。** 規約は `CLAUDE.md` の規約節（(G1)〜(G16)）。

## 0. 作るもの

### 0-1. 2 つの特性（**別々に実装する。将来それぞれ単独で配れるように**）

| 特性 | 内容 |
|---|---|
| **`TraitId.Regen`（プラス）** | 毎ターン、自分の HP を**固定値 15** 回復する。`OnTurnStart`。**`ctx.Heal` 経由**。最大HPを超えない |
| **`TraitId.Nourish`（マイナス）** | **自分にダメージが通ったとき、与えた者の攻撃力 +2**（戦闘中は恒久）。**陣営を問わない** |

**`ctx.Heal` 経由は必須。** `Heal` は回復の**単一窓口**で、渇き（`DroughtTrait`）がそこ1箇所で止めている
（実装のコメントで確認済み）。ここを通さないと**第三波で符号が反転しない＝この駒の面白さの半分が消える。**

**回復は割合ではなく固定値。** 回復 15/T と敵の攻撃力の単調増加が必ず交差するので、
**別途タイマー機構を作らずにマイナスが制限時間として閉じる。**交差点をプレイヤーが暗算できることが価値。

**成長はダメージ量に比例させない**（+2/hit の固定）。比例にすると**強い駒しか育たず**、
「捨てられた弱い駒が育つ」筋が消える。攻2のヒサでも殴り続ければ育つ形を守る。

### 0-2. 対照を機構の中に持たせる（**第117期 §8-1 の推奨**）

`NourishRule(Gain)` を `readonly record struct` で足し、**`Gain = 0` を「回復タンクだけ」の対照にする。**
符号の違う2つの効果を1つの駒に持たせるときの既存の作法（第41期の突き返し・第59期の着火）と同じ。

    NourishRule(Gain: 2)   採用候補
    NourishRule(Gain: 0)   対照（回復のみ）
    Regen なし             対照（素体）

**`ReaderRule(0)` の対照も必ず並べる**（第117期 §8-2）——`Overload` を載せた直後なので、
**`Nourish` が積む強化がバンの薙ぎ化を起こすと、どちらが効いたか読めない。**

### 0-3. 駒（**仮の器。`All` には入れない**）

| 項目 | 値 |
|---|---|
| HP | **160** |
| 攻撃力 | **3** |
| 速さ | **3** |
| 攻撃型 | 単体（常時） |
| 特性 | `Regen` ＋ `Nourish` |
| 名前 | **仮名で可**。既存の命名に倣う（候補: 糧の〜／肥やしの〜） |

**この期では名前・フレーバーを決めない**（第119期以降、差し替え先が決まってから）。

### 0-4. 触らないもの

- **`UnitCatalog.All`（52枚）／`Presets` / `EnemyCatalog.Stages`**
- **`Overload` の閾値 5**・バン・`ReaderRule` の既定
- **ボスの敵側**（数値も波も作らない）
- **会戦持ち越し**（`Nourish` の上昇は**会戦をまたがずリセット**。**切り替えのフラグだけ用意して、実装は将来の期**）

## 1. Phase 0

### 1-A. ダメージ経路の切り分け（**最重要。仕様の前提**）

1. **`ApplyDamage` で `source` が取れるか**、発火点で誰が与えたかを特定できるか
2. **「攻撃によるダメージ」と「コスト徴収・スリップ」を区別できるか。**区別できないなら**引数かフラグを足す**
   - **除外**: 毒・燃焼の `TickStatuses`／リィカの生贄／ゴルムの吸い／`RaiseCost` 系
   - **含める**: 通常攻撃／薙ぎ・貫き・全体の巻き込み／カドの反撃
3. **通ったダメージが 0 のとき `ApplyDamage` を通るのか手前で止まるのか**（破片で受け切った被弾は
   `ApplyDamage` を呼ばない旨のコメントが `Traits.cs` にある。**実装で確認する**）
4. **肩代わり経路の誤発火**（前例あり——リィカの `RaiseCost` 8 のうち本人が払ったのは 1 で、前列のゴルムが肩代わりしていた）:
   **ゴルムの巨躯／ドハ `Sharer`／セッキ `RearGuard`** が `source` を保持したまま `ApplyDamage` していないか
5. **`AtkBonus` に相乗りできるか**（新しいカウンタを作らない）。上がった値が
   **カドの反撃（自分の攻撃力の2倍）**・**敵の詠唱兵の `Charge`**・**カド `Havoc` の適用順**にどう乗るか

### 1-B. ヨミ・ウツ・ヴェルの再測定（**第117期の器具の穴。この期で閉じる**）

第117期の土台の選定規則 (c)（「被弾・移動・弱体の供給者を土台に入れない」）が、
**ヨミ（移動）とウツ（弱体）の入力を1枚残らず台から除いていた。**帰属 0.0pt は**駒の性質ではなく台の性質**（第56期）。
ヴェルも同じ形で、**継ぎ接ぎは味方が倒れて初めて働く**のに土台3枚が攻撃役だった。

> **規則 (c) を緩めた台を組み、3枚を測り直す。**
> ヨミ = 移動の供給者（バサ／ハネ／シオ）を土台に入れる。
> ウツ = 弱体の供給者（グザの呪詛など）を土台に入れる。
> ヴェル = 倒れても出力が消えない土台にする。
> **供給者を入れた版と入れない版の両方を出す**（差が台の性質であることを示す）。

**これは本体とは別の判定**（§3 の Q5）。**本体の台には持ち込まない。**

### 1-C. その他

6. **波ルールの現況を実装から引く**（第三波が渇き・第四波が軛・単発上限がいくつか）。**指示書の記述を信用しない**
7. **`design/` を grep**——「被弾で攻撃者を強化する」「自己回復」に類する機構を過去に測っていないか
8. **実装から引く走査は、引けた件数を必ず出力する。0 件を異常として扱う**
   （第117期の穴——走査が空になって土台が静かに化けた）

## 2. 測り方

### 2-1. 台

**第117期の 16 組の台をそのまま使い、「死なない」側をタンクに置き換える。**
比較の基準が既にある——**ゴルムの +1.30T が唯一の物差し。**

| 台 | 内容 |
|---|---|
| **T1〜T4** | 被害で育つ 4 枚（ムド／カド／ヨミ／ウツ）× **タンク** |
| **G1〜G4** | 同じ4枚 × **ゴルム**（第117期の実測。**再現すること**） |
| **対照** | 各台で `Gain = 0`（回復のみ）／タンクを素体に置換／`ReaderRule(0)` |

**土台3枚は第117期と同一**（規則 (a)〜(d)）。**ただし §1-B の再測定台は別枠。**

### 2-2. 門

| 門 | 内容 |
|---|---|
| **門1 生存** | **タンク自身の生存T**、および**味方全体の生存T**（対照との差） |
| 門2 交差点 | タンクの HP が回復を上回って減り始めたターン |
| 門3 育ち | `Nourish` で上がった攻撃力（**敵側／味方側を別々に**） |
| **傾き** | 第117期と同じ定義（後半3T ÷ 前半3T の与ダメ/T） |
| 誤発火 | §1-A の経路ごとの発火回数（**表にして 1 つずつ検証**） |

### 2-3. 判定

| | 内容 | 線 |
|---|---|---|
| **Q1** | **時間を買えたか**: 味方全体の生存Tが素体比で **+1.30T 以上**（ゴルム超え） | 4 台中 **2 台以上** |
| **Q2** | **傾きが 1.0 を超えるか**（第117期が 0 組だったもの） | **1 組以上** |
| **Q3** | **波で符号が反転するか**: 第三波（渇き）と第四波（軛）で**帰属の符号が逆** | 二値。**同じ顔なら定数型に潰れている** |
| **Q4** | **`Gain = 0` との差**（マイナスが機構として効いているか） | 帰属の差が **5pt 以上**。差が無いなら**マイナスは飾り** |
| **Q5** | **§1-B の再測定**: ヨミ・ウツ・ヴェルが供給者ありの台で **0.0pt でなくなる** | 3 枚中 **2 枚以上** |
| **Q6** | **回帰**: `compare` 305 セル **0 件**（`All` に入れていない） | 1 セルでも動けば事故 |

**Q3 がこの駒の合否である。**どの波でも同じ顔なら可変コスト型として成立していない。

### 2-4. 予測

1. **Q1 は通る**（HP160・回復15/T は既存のどの駒より厚い）。ただし**タンク自身の生存Tほど味方全体は伸びない**——
   前列に単独で置いても、**範囲・貫きは素通りする**
2. **Q2 は通らない**——生存が延びても、育つ側が**振る回数**を増やせるかは別。第117期の教訓がここでも出る
3. **交差点は 6〜10T**（敵5体が全員殴ると 1T あたり合計 +10、回復 15 と交差する）
4. **第三波（渇き）で最悪、第四波（軛・単発上限）でほぼ無料** → **Q3 は通る**
5. **味方側の育ちは1本に集中する**（ボルグの薙ぎ巻き込みなど毎ターン1回）。**敵側は薄く広く**。この非対称が編成の判断になる

**外れた項目は「何を数えていなかったか」の形で書く。**

### 自己検査

**必須4項目**: `compare` 305 セル **0 件**／`docs/` 10ファイル再生成（**`rules.md` に `NourishRule` の行が増えるだけ**）／

**この期固有**:

- **(a)** `Regen` が **`ctx.Heal` を通っている**（第三波で回復量が 0 になることを実測で示す）
- **(b)** `Nourish` が §3 の経路表どおり（**1 行ずつ実測で検証**）

## 4. 結論と分岐

報告書 `design/PHASE118_TANK.md` の冒頭に、**1つの引用ブロック**で Q1〜Q6 の○×と、採るか否か。

- **Q1・Q3・Q4 を通る**: **機構は採る。**第119期は**差し替え先を決める期**——
  第117期 §8-3 のとおり **第82期の健康診断（`checkup`）を 52 枚で回し直す**のが先（当時 51 枚で、ソム・トモが入っていない）
- **Q1 は通るが Q2 が落ちる**（時間は買えたが傾きが立たない）: **想定内。**
  **時間を買う機構は成立したが、ボスにはもう1本要る**——壁の残り2つ（倍率／防御無効化）へ移る。
  **この駒は「ボス用」ではなく「編成の器」として採る**
- **Q3 が落ちる**（どの波でも同じ顔）: **定数型に潰れている。**回復量か `Nourish` の形を変えて測り直す。
  **HP と回復量だけを触り、+2/hit は動かさない**（プレイヤーが読める単位であることが価値）
- **Q4 が落ちる**（`Gain = 0` と差が無い）: **マイナスが飾り。**この形では「殴られるほど殴った者が強くなる」が
  盤面に出ていないので、**発火経路が細すぎないか §3 の経路表で確認**してから再設計
- **Q5 が落ちる**（供給者を入れてもヨミ・ウツが動かない）: **第117期の 0.0pt は台の性質ではなかった**ことになる。
  **その場合は3枚とも差し替え候補として名指しできる**——第119期の材料になる
