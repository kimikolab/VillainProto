## 0. 主題

### 0-1. 埋めるもの（1行で）

> **強化の行き先を、編成が選べるようにする。**

積み残し1（第56期から未解決）: 強化の供給の **48.3% が吐き戻し1本**で、
行き先は「ゴルムが庇った相手」＝**編成が選んでいない。**
号令は味方全体、縛めは縛った相手、火選りは燃えている相手——いずれも**行き先は機構が決める。**

**強化を増やす駒は作らない。** 増やすだけなら吐き戻しの2本目になり、偏りは薄まっても判断は増えない。
作るのは**来た強化を別の相手へ回す駒**——**engine の `Whet` 窓口は既にその席を空けている**:

    // 横取りはまだ無い。Dull はちょうどここに集約（ウケ）と転嫁（ワタ）を置いている——
    // 読み手を作る期が来たら receiver を差し替える形で同じ位置に立てられる。

### 0-2. 規則（1文）

> **自分と隣の味方に来た強化を、すべて自分の隣で一番遅い味方へ横流しする。自分は育たない。**

| 側 | 中身 |
|---|---|
| プラス | 隣接する味方（自分を含む）に配られた強化を、**隣接する味方のうち最も遅い1体**へ集める。**量は減らさない**（加算。乗算にしない） |
| マイナス | **横取りされた味方は育たない。自分も育たない。**さらに、一番遅い隣が振らない駒なら**全部が死蔵になる** |

**選択子を「一番遅い」にする理由:**

- **駆り立て（カリ）の「隣接する攻撃力最大」の逆側**なので重ならない
- 遅い駒は**手番が後ろ**なので、そのターンに配られた強化を**振る前に受け取れる**（速さの順序と噛む）
- 「強い。ただ遅い。それだけの理由で外された」（ドルガ）／「動かない者を守ることしかできない」（バン）
  ——**遅さで捨てられた層に力を回す**駒として、フレーバーがそのまま立つ
- **罠が盤上に既にある**: 一番遅い隣が**不動のカド**なら100%死蔵、**ゴルム（速3）**なら
  吐き戻しの出どころへ戻る自己循環、**ガルド**は受け取らない、**ホタ**なら燃焼中ちょうど4倍。
  **同じ1点が行き先で 0倍にも4倍にもなる。**配置の判断はここから生まれる

## 2. 作るもの

### 2-1. 実装（engine の `Whet` 窓口）

`Dull` の横取りと**同じ位置・同じ形**で `receiver` を差し替える。

```
receiver = target
if (target が横流し役でない  または  target 自身が横流し役)   ← 自分に来た分も回す
    funnel = target に隣接する横流し役（居れば）
    if (funnel is not null)
        dest = funnel に隣接する味方のうち
               { u != funnel, u.AcceptsSupport, !u.HasTrait(Funnel) }   ← 横流し役どうしは回さない
               の中で Speed 最小（同速は PickOne）
        if (dest is not null && dest != target)
            receiver = dest
            計数: FunnelTaken += amount / FunnelFrom[target] / FunnelTo[dest]
```

**守ること:**

- **1ホップ。** 回した先がさらに回さない（呪いの伝播と同じ）。横流し役を候補から除くことで担保する
- **候補が 0 / 1 個なら `Roll` を消費しない**（第43期と同じ）。**ヌキを含まない行の乱数列を動かさない**
  ——受け入れ基準2の検算がこれ
- **量は加算のまま**。減衰も倍率も付けない
- `WhetRoute` は**足さない**（供給ではなく横取りなので）。代わりに
  `FunnelTaken` / `FunnelByRoute[]`（どの経路を横取りしたか）／`FunnelDead`（回した先が
  `IdleTurn`・不動などで振らなかった量）を `BattleContext` に置く。**どれも誰も読んで分岐しない**
- 既存の `WhetToPerverse` / `WhetPerverseFlips` は **`receiver` に対して**数えること
  （回した先がウツなら逆しまが読む）
