## 0. Phase 0（W0 ＝ 規定で数えた・敵上げの札は判定を持たない段階）

### Q0-1 上げの置き場所

第254期の爆炎の上げは2か所に分かれている——**敵の分は `BigMove` の爆炎の `PerformAttack` の直後**（当てた敵＝`_unleashHits` を席番号の順に `BlazeSurge`）、
**味方の分は `BlazeAllies` の中**（味方ごとの燃焼ダメージの後に `BlazeSurge`）。量は `SurgeOf(ボルグ)` の1本が両方に渡している。
→ **敵だけに絞るのは、敵の側に渡す量を別の1本（`FoeSurgeOf`）にするだけで済む**（`BlazeAllies` には今の `SurgeOf` ＝ 0 のまま渡る）。
上げそのもの（`BlazeSurge` ＝ `GrowFire` を +1 ずつ／4 まで1回）は第254期のまま使う＝**敵の火勢の今の規則の「育ち」**（上限4・萎み方も今のまま・延焼も今のまま）。
台本は第254期の「爆炎・上げ」と分けて、新しいラベル「爆炎・敵上げ」（敵ごとに前後の火勢）を出す。

## 1. 予測（Phase 0 の後・実装の前に置く）

- **P1** W0 の台本は実装の前（`foesurge digest W0`・834,087 行）と全行一致する。第254期の器具の台本（`blazesurge digest V0 / V2 / V4`）も一致する。
- **P2** 九体の波（九/新兵・九/農兵 × 200/200・400/300）では W2・W4 と W0 の差は全員生存 ±1.5pt・決着T ±0.05 以内。爆炎の後の被弾の燃焼の差は +30 HP/戦 未満（例外は混ぜ-255 × 九/新兵 400/300 で +20〜+60）。
- **P3** 爆炎の後の被弾の燃焼（HP/戦）は本編 400/300 で 5 台すべて W4 ＞ W2 ＞ W0、W2 は W0 の +25〜+60%、W4 は +40〜+100%。重い波では混ぜ-255 と雷＋ボルグだけが増え（W4 で +30% 以上）、T3 の3台は ±15 HP 以内。
  **的・一では T3 の3台と混ぜ-255 は W0 ＝ W2 ＝ W4 が全セル一致**（的は爆炎の瞬間に既に火勢4・R277）。動くのは雷＋ボルグだけで、W2 と W4 はほぼ同じ（3 → 4 はどちらも1段）。
- **P4** 本編 400/300 で、爆炎の後の直＋燃の伸び（W4 − W0 を W0 で割った率）は、手数の駒（ノミ・ヨミ・ハネ）がホタより大きい（率で 1.5 倍以上）。**ただし伸びの絶対量はホタ（とボルグ）が大きい**。
- **P5** 味方の火勢4 の張り付き（周回の頭の火勢4 の味方の数・爆炎の次の周回）は W2・W4 が W0 と ±0.05 以内、ref は W0 より +0.3 以上大きい。
- **P6** 勝率は本編・九体・重い波の全セルで ±1.0pt 以内（W0 がほぼ 100%）。全員生存は ±3pt 以内。決着T は本編 400/300 で W4 が W0 より 0.02〜0.15 短い。
