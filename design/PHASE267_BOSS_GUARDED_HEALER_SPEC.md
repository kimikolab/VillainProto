# 第267期 指示書 —— 動じないに戻し、勇者が癒し手を庇う

読み手は Claude Code。第266期（不屈・棄却）の続き。器具 `bosswave`・7台・seed 0..199 はそのまま。

## 0. 位置づけ

第266期の発見で、設計の前提が2つ入れ替わった:

1. **制御の代金は追加装置なしで既に存在する**。全体攻撃の勇者は毎ターン5体に被弾イベントを配る＝移動・混ぜの燃料なので、完封は守りにしかならず倒しTが伸びる（F-0 T8.5 vs D-40 T5.3）。不屈のような代金装置は不要
2. **完全無効は制御軸の解答を取り上げていない**（第261期以来の懸念の解消）。制御の解答は「止めて安全に行く／燃料にして速攻する」の選択に既に化けており、D-40 で移動は 80.5% で成立している

→ **動じない（完全無効）に戻す**。残る問題は毒2台の 0%（自前回復40%で「回復を断つ」道が無い）だけ。これを構造で解く:

**回復を癒し手に戻し、勇者が癒し手を庇う**（癒し手への Single 攻撃の75%を勇者が肩代わり）。

- 第265期の失敗（取り巻き即割れ→波ごと易化）が消える: 癒し手に撃った分も勇者へ入るので、割る行為と削る行為が同じになる。R363 の到達問題も消える（攻撃はどの席からでも勇者へ行く）
- **毒だけが癒し手に直接届く**: 「庇い・標的の介入は Single にしか効かない」（設計の中核規則）により、毒・燃焼の刻みは肩代わりを通らない。毒軸の解答＝癒し手を層で割って回復を断つ、が中核規則から自然に生まれる

## 1. 決定

1. 勇者: 全体攻撃・HP 3,000・天井 +11・攻 12・速 14・**動じない（第261期の完全無効の札に戻す）**・自前回復なし
2. 癒し手: 既存の敵と同数値＋特性1枚（城塞の重装兵 145/12/3 ベース）・毎ターン勇者を最大HPの40%回復（W3-割合 の式・対象は勇者のみ）
3. **勇者の庇い**: 癒し手への Single 攻撃の75%を勇者が肩代わり（殉教者の既存機構の向き替え・肩代わりで成長する性質は持たない）。薙ぎ・貫き・全体と状態の刻みは中核規則どおり介入しない
4. 不屈は廃案・対照残置。第266期の問い3（規定の N）は「N 不要」で閉じる

## 2. Phase 0

1. **殉教者の庇い機構の向き替え**: 庇う側をボス（勇者）にする最小の実装。肩代わりが `ApplyDamage` のどの段に入るか、萎縮・破片・軛が肩代わり分にどう乗るかを書く
2. **刻みが庇いを通らないことの確認**: 毒・燃焼の `TickStatuses` が Single の介入窓を通らない（＝癒し手へ直接入る）ことをコードで確認。通るなら中核規則の違反なので設計ごと見直し（その場合は実装せず報告）
3. **机上計算（R362 の4段を最後まで）**: 毒2台が癒し手（145）を層で割るのに何ターンか（毒の配分込み）。割った後の長期戦で勇者（回復なし・天井+11）に勝てるか。**「割れるが、割った後に天井で死ぬ」なら数値ノブ（癒し手のHP・回復率）の出番**なので、そこまで見積もる
4. 勇者が倒れた後の癒し手（回復先喪失）と、癒し手が倒れた後の勇者（素のHP勝負）の挙動確認
5. バサの入れ替え・ハネの押し込みが勇者↔癒し手の位置を動かしたとき、庇い（対象指定）が壊れないか（R363）

## 4. 測定と採否

- 7台 × 2版。指標: 連続量＋**癒し手を割ったT・割った手段の内訳（攻撃経由/刻み経由）**・勝率
- 採否:
  - **毒2台の勝率 > 0** になり、その勝ち筋が「刻みで癒し手を割る」経由であること（ログで確認）
  - **癒し手を割った手段が軸で分かれる**こと（毒は刻み・他は肩代わり越しの攻撃か、割らずに勇者ごと削る）
  - 移動・雷・燃焼・混ぜの成績が D-40 から大きく歪まないこと（回復の出どころが変わっただけなので、方向は「少し硬くなる」まで）
  - 既存5波 305 セル 0 件・再現系全行一致

## 5. 予測（Phase 0 の机上計算で数値を足す）

- **毒2台**: 癒し手を刻みで割り、回復を断ってから長期戦で勝つ。0% → 有意に正。2台のうち「耐える毒」（毒+ベニ+ラウ）の方が割った後の長期戦に強い
- **燃焼**: 癒し手を無視して T3〜4 で勇者ごと削り切る。2版で不変
- **移動・雷**: D-40 とほぼ同形（守りか速攻かの選択）。G-庇100 では癒し手に攻撃が1も入らないので、割る選択肢が消えて勇者一点になる
- **混ぜ**: 全体への被弾反応で中位。癒し手の扱いが攻撃経由と刻み経由の混合になる唯一の台のはず
