# Codex 向け発注メモ（追補）—— ソムの召喚獣を「雷の精霊」に

置き場所: `design/CODEX_BRIEF_SOM_SPIRIT.md`。`CODEX_BRIEF_SOM_SPARK.md` ／ `SWARM.md` ／ `STANCE.md` ／ `RESONANCE.md` の見た目の部分を**この追補で置き換える**（拍の構成・分岐はそのまま）。
触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。

## 0. なぜ変えるか（ポンの判断）

いまの獣は猫に見える。ボス戦では1戦に 50〜100 体弾け、味方がそれを殴る場面もあるので、**猫を使い捨てている・駆除している**と受け取られかねない。

**実在の動物に見えない「雷の精霊（電気の塊）」にする**。弾けても「生き物が死んだ」ではなく「雷が散った」と読めるようにする。仕組みは何も変わらない。

## 1. 姿

- **身体は電気の塊**: 芯に明るい光の核があり、そのまわりを稲妻の弧がうねって輪郭を作る。輪郭は常にちらつき、半透明
- **形は小さく、四足の気配だけ**: 稲妻の弧がときどき脚や耳のような形を作っては崩れる程度。猫・犬・狐と特定できる顔や毛並みは描かない
- **目は光の点（2つ、または1つ）**だけ。口や牙は描かない（威嚇は光と弧の形で見せる）
- **首輪はやめる**。代わりに、**核の前に契約の紋（ソムの魔導書と同じ意匠の小さな魔法陣）**が浮かんでいる。「飼われている」ではなく「召喚の契約で縛られている」と読める
- 色: 喚ばれた直後はソムの色（菫 ／ 白）を帯びた雷。背いた瞬間に**色が反転して黄白 ／ 赤みの雷**になる（敵になった合図）

## 2. 拍ごとの見せ方（拍の構成は STANCE ／ RESONANCE のまま）

| 拍 | いまの絵 | 精霊の絵 |
|---|---|---|
| 寝返り | 獣が走り込む | 光の塊が弧を引きながら敵陣へ**飛ぶ**（走らない） |
| 牙を剥く | 振り返って威嚇 | 振り返った瞬間に**契約の紋がひび割れ、色が反転**する。弧が逆立つように尖る |
| 臨戦態勢 | 雷を纏う | 核が膨らみ、弧が増えて激しくなる |
| 投げる | 雷を投げる | 自分の身体の一部を**稲妻の槍**にしてこちらへ放つ（身体が少し縮む） |
| 暴発 ／ 弾ける | 小さな体で雷を纏いきれず弾ける | 核が割れて**光の粒と火花に散る**。血・肉片・亡骸は出さない |
| 光 | 魔導書を経由して降る | 散った光の粒がソムの魔導書に吸い込まれてから降る（いまと同じ） |

- 群れ（2〜5体）: 光の塊が群れて飛び、まとめて振り返る
- 共鳴返し: 跳ね返った雷が精霊の核を貫いて散らす。走る雷は、散る直前に核から枝分かれする
- 打ち返し: シガの鞭が精霊を薙ぎ、精霊が火花になって散る

## 3. 名前（ポンと Claude Code に確認）

画面に出る名前「背いた獣」は `BattleCore` の定義なので、Codex は変えない。候補は「背いた雷精」など。決まったら Claude Code が定義を変え、Codex は表示を合わせる。

## 4. 試遊で見たいこと（ポンが画面で確かめる）

- 動物に見えないか（猫を連想しないか）
- 散る絵が「雷が散った」に見えるか
- 敵に寝返った瞬間（色の反転・紋のひび）が一目で分かるか
