# ゴルムの精気吸収・吐き捨て・腕の演出

実装日: 2026-10-15。仕様: `CODEX_BRIEF_GOLM_ARM.md` と `PHASE291_CODEX_MEMO.md` §38〜40。捕獲後の投げ返しとパンチの着弾強化は、同日のユーザーからの追加指示を反映。

チャット指示「投げ捨てた体に色が残り、そのまま残り続ける」を採用。捕獲した敵は吸気中・投げ返し中・着地後も元の色を保ち、戦闘中は倒れた姿を残す。指示書にある灰色化・着地後の消去より、この追加指示を優先する。さらに、攻撃時に右を向いて右手をロケットパンチで放つ差分を追加した。

## 追加した動き

- 規定の `Swallow`「呑む」で、敵から腹の渦へ光の糸が流れる。敵は灰色になり、上から細片へ崩れる。吸気では HP を変更せず、対応する `Death` で HP バーと本体を消す。通常の倒れ込みは重ねない。
- 「吐く:毒…,火…,雷…,濃…,標…」を読み、紫の霧・橙の煙・雷球・黒い印を指定された敵へ運ぶ。量が多い成分ほど大きい。到着時に毒・火・雷・標の表示を更新する。HP は変更しない。
- RP-a / RP-b の `GolmArm`「飛ばす」で右向きの発射差分に切り替え、手前の右腕を伸ばして拳を後列まで噴射させる。手首ソケットに拳を0.09秒構え、0.23秒で飛ばす。対応する `Attack` を専用の打撃で再生し、通常の踏み込み・斬撃は重ねない。敵側は左右反転して相手を向く。
- 「掴む」の Slot=0 は開いた手を飛ばして捕獲、Slot=1 は殴った場所から捕獲する。開いた手から拳へ形を補間し、敵の代理絵を持ち帰り、手元で精気を吸う。その後、手を開いてぽいっと元の場所へ投げ返す。敵は小さく弾んでへたり込み、元の色・不透明さのまま体の姿を残す。敵の戦闘上の席は変更しない。
- 捕獲へ続かないパンチは、接触点に短い放射状の閃光、広がる衝撃波、火花を重ね、画面を揺らす。後続の「掴む」通知を台本から結び、捕獲へ続く一撃は小さい着弾にする。ダメージ表示までの間隔は既存の0.10秒を維持する。
- 「戻る」で右腕のソケットへ帰還し、最後の0.07秒で拳を接続してから待機姿へ戻る。捕獲・持ち帰り・吸気・投げ返しの間は同じ右向き差分を保つ。パンチで倒して「戻る」が出ない場合も、死亡通知後に手を帰す。中断・所有者の死亡・再戦でも差分を解除する。
- GA-a の「踏み潰す」は足と地面の輪で再生する。余波のダメージ表示は既存の台本処理が担当する。

`BattleCore`・プリセット・勝率・台本は変更していない。`GolmPresentation` は通知と対応する一撃・死亡の添字を結ぶだけで、捕獲の条件や標的を決めない。

## 確認方法

リポジトリ直下の PowerShell:

```powershell
./DemoApp/RunGolmCheck.ps1
```

「精気を呑む・吐く」「殴る→捕獲→呑む」「殴らず捕獲」「後列へパンチ・帰還」「パンチで撃破」「踏み潰し」を選べる。一時停止・0.5/1/2/4倍速・もう一度を用意した。通常の戦闘では、試遊の既存プリセットから出撃する。
