## 1. 札が働いたことを見せる（表示専用）

- **`BattleEventKind.Relic`**（新）を台本に積む——`BattleContext.NoteRelic(持ち主, 札, 相手)` の 1 箇所。**札をレリックとして持っている駒（`UnitState.Relic`）だけ**（素の札として弾き返しを持つハネでは積まない）。verbose でなければ何もしない
- 札ごとの「働いた」の数え方:

| 札 | 働いた ＝ |
|---|---|
| 軋む足 | 動かされて攻撃が上がった回数 |
| 火付けの矢 | 火を点けた回数 |
| 毒の足跡 | 向かいの敵に毒を残した回数（敵 1 体ごと） |
| 弾性 | 殴った敵を弾こうとした回数（弾き返しの割り込みに入った回数・弾けたかは問わない） |
| 萎える心 | 攻撃が下がった回数 |
| 痺れる足 | 転んだ回数 |
| 身を固める | 身を固めた回数（1 戦 1 回） |
| 帯電の足 | 感電を移した回数 |
| 押し毒 | 敵を押した回数 |
| 溢れの刃 | 溢れた回復を攻撃に変えた回数 |
| 勢い余り | 入れ替わった回数 |
| 毒を招く | 受けた毒が 2 倍になった回数 |

- **作戦マップ**: 1 戦ごとに戦闘の記録の行の下に「◆札（駒）: n 回」、結果画面に「レリックが働いた: ◆札（駒）n 回 ／ …」（通しの計）
- **戦闘中の頭上の印は入れていない**——戦闘の再生（`BattlePawn3D*` ／ `BattlefieldView3D*`）は作業中の弱体の演出（Codex）と同じファイルなので、`BattleEventKind.Relic` を読む印は Codex に回す（再生側は知らない種類を素通りするので、いまの再生は動く）
- **候補の 1 枚目の散らし**: 両端を**軸の語だけ**で見る（`RelicRule.AxisOnly`・役割の語の端は「誰でも」扱い）。1 枚目の札の分布は §3 の器具の表の後ろ

## 2. 勇者（`MapStage.Hero`・遊ぶ 1-2 ＝ `Stage12`・第453期の盤は `Stage12H453`）

| 項目 | 作り |
|---|---|
| 現れ方 | **門が初めて開いた刻の 2 刻後**、敵の拠点のマスに**予告なしで**（札も「あと n」も出さない）。現れた刻に止まって「勇者が現れた（敵の拠点から ○の道へ向かう・2 刻に 1 マス）」 |
| 進み方 | **2 刻に 1 マス**味方の拠点へ。経路は予備隊と同じ選び方（`ReserveTarget`・味方のいない経路 → 生存の少ない経路）。湧いた部隊の列に入る（前が詰まれば待つ） |
| 戦闘 | 勇者のいるマスへ隊が入れば戦闘・味方の拠点に着けば迎撃（出せる隊が無ければ陥落）。**HP は戦闘をまたいで持ち越す**（敵部隊と同じ規則） |
| 勝ち | 制圧のまま（着く前に制圧すれば逃げ切り）。倒しても勝ちではない・倒せば金 **＋20** |
| 形（版 B） | `EnemyCatalog.HeroMap`: 1 体・全体・**HP 2,400**・攻 12・速 14・天井 +11・動じない・**毎ターン頭に固定 300 回復**（新しい札 `BossMend300`・`docs/units.md` の特性の表に 1 行）・蝕み無し。`Id` は規定形と同じ（「勇者には効かない」の判定がそのまま効く）。**器具のボス（`bosswave`）は触らない** |
| 版 A | `EnemyCatalog.HeroMapA`（回復は規定形と同じ最大HPの 40%）・`HeroRule.V454A` で切り替え。遊ぶのは版 B |
| 画面 | 敵の顔の札の見出しは「勇者」・丸の印は「勇」。結果画面に「勇者: 作戦ターン n に現れた・倒した ／ 逃げ切った（着く前に制圧）／ 着かれた（拠点が陥落）（戦った n 回・当てた隊 n）」。**金色の縁・太い矢印は入れていない**（Codex） |

- 勇者は**敵の拠点のマスに現れる**ので、現れた刻から動き出すまで（2 刻）は、敵の拠点に入ると勇者と当たり、勇者が出て行くまで制圧はできない（制圧は敵の拠点のマスに敵がいないことが条件）
