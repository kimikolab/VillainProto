# Codex 向け発注メモ —— 「隣の刃を受け止める」「悲鳴で周りが竦む」を絵で見せる

置き場所: `design/CODEX_BRIEF_SHIELD_COWED.md`。触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。
台本に足りないデータは §3 のとおり Claude Code 側で先に足す。**§3 が入る前に着手しないこと。**
台本に依存しない下準備（素材・エフェクトの試作）は先に進めてよい。

## 1. 何が起きているか（第185期）

### 1-1. 据えのバン —— 範囲の盾

- 薙ぎ・貫き・全体の攻撃が、**バンとバンに隣接する味方に同時に当たる**とき、
  **隣の味方の分をバンが代わりに受ける**（半分にしてから受ける）
- バンは手番で**踏みしめて層を積む**（1層ごとに被ダメ −10%・最大3層）。層は状態アイコンの仕組みで見える想定
- 今の画面では、ログ1行と「ダメージの受け手がバンに変わる」だけ。**何が起きたか分からない**

### 1-2. 責め苦のシガ —— 見せしめ

- 動けない敵（組み付かれた・痺れた・竦んだ敵）を責めると、**その敵に隣接する敵全員が竦み、次の手番を失う**
- 竦みは `StatusKeys.Cowed`。竦んだ瞬間に `StatusGain` が出ている（`ActorId` = シガ）
- 今の画面では、竦んだ敵がただ動かないだけ。**シガの一撃との因果が見えない**

## 2. 欲しい絵

### 2-1. バンが隣の刃を受け止める

- 範囲攻撃が走った瞬間、隣の味方に向かった刃（エフェクト）が**途中で折れ曲がってバンへ吸い寄せられる**。
  バンが**盾・体で受け止めて、地面を踏みしめる**（足元に小さな衝撃）
- 守られた味方は無傷で立っている（ダメージ表示はバンにだけ出る）
- 1回の範囲攻撃で複数人分を受けたときは、**複数の刃が一斉にバンへ集まる**のが見えるとよい
- 既存の「庇う（ガルド）」の割り込み演出があればそれを土台にしてよい。ただし**色か形でガルドと区別**する
  （ガルド＝単体を前に出て受ける／バン＝範囲を据わったまま引き寄せて受ける）

### 2-2. シガの悲鳴で周りが竦む

- シガが動けない敵を責めた瞬間、**責められた敵から波紋（悲鳴）が広がり**、
  届いた隣の敵が**びくっと縮こまる**（竦みのアイコンが付く）
- 竦んだ敵は手番が来ても**震えて何もしない**（手番を失ったことが分かる）
- 狙いは「縛る（クグ）→ 責める（シガ）→ 周りが竦む」の3拍が2倍速で読めること

**まず 2-1 と 2-2 を1つずつ作って、ポンが見てから調整する。**

## 3. 前提 —— Claude Code 側で台本に足すもの（表示専用・盤面は1ビットも動かさない）

1. **範囲の盾**: `BattleEngine.ShieldRecv` で受け止めた瞬間に、既存の割り込みの表示イベント
   （`EmitIntercept`・第125期）を出す。ラベルは `InterceptLabels` に「範囲の盾」を1本足す。
   載せるもの: 盾の持ち主（バン）・守られた味方・受け止めた量（半分にした後）
2. **竦み**: 竦みの `StatusGain` に、**悲鳴の出どころ（シガに責められた敵）の InstanceId** を載せる
   （飛沫・波紋の始点。ラウの伝染で足した「元の敵」と同じ形でよい）

受け入れ: `compare` 0件差分・`audit` ずれ0件・台本にイベントが並ぶこと。
終わったら Codex が使うフィールド名を短くまとめる。

## 4. 守ってほしいこと

- **文字を足さない**（2倍速で読めない・第171期）
- 良し悪しは言わない。起きたことを見せるだけ
- 既存の演出と混ぜない: 呪いの泥の筋（ムド）・毒の紫の飛沫（ラウ）・ヒサの守りの標
- クグの組み付き（糸が敵に伸びて巻き付く）の演出はこのメモの対象外。必要なら別に頼む
