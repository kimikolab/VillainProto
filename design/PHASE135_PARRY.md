指示書は `design/PHASE135_PARRY_SPEC.md`。**段1（診断）と段2（受け流しをローカル台で測る）まで進み、段3 へは進まなかった。**

## 0. 結論を先に

1. **ガルドは範囲で死んでいない。単体で殴られ続けて死んでいる。**
   総量の **63.0%** が単体で、**致命打も 57.1%** が単体。**ずれは −5.9pt しかない**
   ——「総数では区別できない」は、この駒については**起きなかった**（P1 の後半が外れた）。
2. **一文「その傷のぶん強くなる」は死文ではない。** 指示書 §0-1 の前提が誤っていた
   ——あの記述は `GatherRule`（傷の引き取り）についてのもので、**一文の実装は
   `RedirectGainTrait.OnDamaged` の `self.AtkBonus += dmg / 2`**。
   実測で**庇いのたびに発火し、1戦あたり攻撃力 +7.98 を積んでいる。**
   死文なのは**引き取りのほう**（実測 0.00 回/戦・P2 の前半は当たり）。
3. **受け流しは効く。ただし線に届かない。** 8 版すべてでガルドの生存T は上がり
   （最大 +0.67T）、台A の V2 N=2 は**勝率 67.6% → 82.2%（+14.6pt）**。
   だが §5-2 の条件1（**+1.0T 以上**）は8版すべて ×。**条件1 と 2 の両方が要るので段3 へは進まない。**
4. **N の決め方と線が、同じ器具の中で両立していなかった。** 紙で引くと +1.0T に要るのは
   **N ≈ 2.2**（台A）で、§3-2 の決め方（中央値 1 を上限に 1 / 中央値 / 中央値×2）が許すのは **N ≤ 2**。
   **線のすぐ外に上限が置かれていた**——(G16)「線を引く条件と、採る条件は同じ集合で書く」の別の形。
5. **支援拒否（`Stoic`）を外すと勝率が下がる**（−2.0pt）。代金だと思っていた札が、
   少なくとも現行のロスターでは**そう単純ではない。**

### Q0-6 —— `ModifyIncomingDamage` の作法と、受け流しを置いた段

`ModifyIncomingDamage` を上書きしている札は **2 枚**（`Frail` / `Tempered`）、呼び出し口は **1 箇所**。
`ApplyDamageBody` の段の並びを走査で引いた（**14 段が単調増加であることを機械で確かめた**）:

| # | 段 | # | 段 |
|---:|---|---:|---|
| 1 | 棘守りの上限 | 8 | 分かち（肩代わり） |
| 2 | **入口**（`ModifyIncomingDamage`） | 9 | 破片（`Armor`） |
| 3 | 惨禍 +50% | 10 | `lethal: false` のクランプ |
| 4 | 据え | **10.5** | **受け流し（この期に足した）** |
| 5 | 散開 | 11 | 猶予（HP1 で耐える） |
| 6 | 萎縮 | 12 | 不死（器具） |
| 7 | 巨躯（肩代わり） | 13 | 軛（1発の上限） |
| | | 14 | **HP を引く** |

**受け流しは `lethal: false` のクランプの直後・猶予の直前。** 順序の理由（受け入れ条件 A9）:

| 相手 | 順序 | 理由 |
|---|---|---|
| 惨禍（+50%）・脆弱（×1.5） | **受け流しが後** | 入口に置くと増幅が 0 にしたつもりの量を押し戻す（第25期・第126期） |
| 破片（`Armor`） | **受け流しが後** | 破片は別資源。破片が全額吸った一撃では、そこで `amount <= 0` になり発火しない |
| 肩代わり（巨躯・分かち） | **受け流しが後** | 分割された各段は別の `ApplyDamage`。弾くのは**自分に残ったぶん**だけ |
| 軛（1発 25 上限） | **受け流しが前** | どちらも「1発を切る」制約。先に弾けば軛は素通り（結果は同じ） |

**二値の制約は出口にしか置けない**（第25期の軛・第126期の猶予）という既存の則に、
**3例目として素直に載った。**

### P3 の △ —— 「機会」が3通りに読める

    庇いの成立            1.47 回/戦   ← 予測の 2〜4 に**届かない**
    庇いの判定を振られた  2.92 回/戦   ← 予測の帯に**入る**
    判定 ＋ 範囲で消えた  5.71 回/戦   ← 予測の帯を**超える**

**第121期の則がそのまま当たった**——「判定の線は、計数の**名前**ではなく実装が数えている出来事に当てる」。
指示書は「庇いの成立は 2〜4回/戦のはず」と書いているので**成立で読めば ×**、
「これがパリィの機会数の上限」（Q0-3）と書いているので**機会で読めば ○**。
**N の決め方（§3-2）は「成立回数の中央値」を名指ししている**ので、そちらを正とした（中央値 **1**）。

### P6 の △ —— 台の選定規則が、予測の主語を消した

段2 の台からは**肩代わり役（ゴルム・ドハ・カド）を1枚も入れなかった**
——`ApplyDamage` の層で先に量を取られると「ガルドに残ったぶん」が台ごとに変わり、
受け流しが弾く量の意味が動くため。**その判断が、P6 が比べたかった相手を台から消した。**
第117期・第126期の「台の選定規則が、測る対象の入力を 0 にしていないかを Phase 0 で数える」の、
**入力ではなく述語の側で同じ形が出た**（§5 の則へ）。

**実装の順序からは言える**（Q0-6 の表）: ドハ（40%）もクビ（−30%）も**受け流しより前の段**にいるので、
受け流しが弾くのは**それらを通り抜けて残ったぶん**である。**乗算的には重ならない。**
ただし**弾ける量が減るぶん、受け流しの価値も一緒に下がる**（弾いた量/戦は台A 15.2・台H 9.3 と、
被弾の大きさでそのまま動いている）。
