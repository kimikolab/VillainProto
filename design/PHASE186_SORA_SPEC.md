## §0. 背景

逸らしのソラ（HP96・攻6・速8・`Divert`）:
- 毎ターン頭、味方に付いた標をすべて剥がし、自分に標を付け（代金）、現在HPが最も高い敵に標を付ける
- 第184期から、敵の標持ちは被ダメージ +50%

ポンの評価:「意味不明」→ 説明を受けて「タンクだったのは驚き。**一瞬で落ちるからその認識が無かった**」。
自分に標が付いて敵の単体攻撃の 75% を集めるのに、**軽減が何も無い**のが原因。

ポンの方針:「逸らしのソラというくらいだから、**敵の自分への攻撃を逸らす**」。

## §1. 変えるもの

### 1-1. 逸らし（新特性 `TraitId.Deflect` として足す）

- ソラへの**単体攻撃**のダメージを、**半分だけソラが受け、残り半分は「ソラが標を付けた敵」へ逸らす**
  （`DeflectPercent = 50`・測る前に固定）
- 逸らした分は**攻撃ではなくダメージの受け渡し**として入れる（呪いの共有・ヒサの逃げ回るとは別の段）。
  出どころ（`source`）は元の攻撃者のまま（同士討ちとして数える）
- 逸らした先は敵の標持ちなので、第184期の **+50%** が乗る（乗せる段は Phase 0 で決める）
- **逸らす先がいない**とき（ソラの標持ちが倒れている等）は、ソラが全部受ける
- 範囲攻撃（薙ぎ・貫き・全体）は逸らさない（ソラは単体の視線を集める駒）

**以前の判断との関係**: 反射（被ダメージ無しで攻撃者に返す）は採用しない方針がある
（敵の火力に比例して伸びる／被弾しないのでHPの代金を踏み倒す）。この案は
**半分は必ずソラが受ける**（代金は払う）・**返す先は攻撃者ではなくソラが指差した敵**なので反射とは別物として扱う。
敵の火力に比例して伸びる点は残るが、ポンの判断で採る。

### 1-2. ヒサの標との関係（相乗効果の方向）

ポンの判断:「標の競合は**ソラが優先**」「ただし、**ソラの半減とヒサの半減で、めちゃ硬いタンクにできそう**」。

- ソラは毎ターン頭、**自分以外の味方**の標を剥がす（現行どおり。ヒサが他の味方に付けた守りの標も剥がす）
- ただし**ヒサがソラ自身に付けた守りの標は剥がさない**（ソラは自分の標を剥がさないので、既に成立しているはず。Phase 0 で確認）
- ヒサの守りの標（被ダメ半減）が付いたソラは: 単体攻撃を半分逸らし、残りをさらに半減 → **1/4 だけ受ける**
- ヒサは「隣接で現在HPが最も多い味方」に標を付けるので、HP96のソラの隣にヒサを置くと自然に成立する

### 1-3. 文案（仮）

プラス「毎ターン、味方への狙いを自分に引き受け、代わりに一番手強い敵を指差す。自分への一撃は半分をその敵へ逸らす」
／マイナス「引き受けた視線は自分に刺さり、毎ターン狙われ続ける」

## 予測（実装前に宣言・コミット。**編成表の実駒を数えて書くこと**）

方向のみ:
- ソラ在席行はソラの生存ターンが伸び、上がる
- 敵の単体攻撃が多い波ほど逸らしが増える
- ヒサ×ソラが同席する行（あれば）は大きく上がる
- ソラを含まない行は ±0.0

## 測定・受け入れ

1. `compare` 61行×第2〜5波。**ソラを含まない行は前期版と0件差分**（比較先は `git show` で固定）
2. 対照: 逸らしなし（現行ソラ）を並べる
3. 帳簿（1戦あたり）: 逸らした回数と量・逸らした先で出たダメージ（+50%込み）・逸らしで倒した敵の数・
   ソラの生存ターン・ソラが受けた量・**ヒサの半減が重なった被弾の数**
4. **診断台**（`Presets` には足さない）: ヒサ×ソラ×ザン（ソラの隣にヒサ）。ソラの生存ターンとザンの倍返し回数
5. `chain` の残存・全滅勝ちを併記。(G2) の「壊れ／制約」を分解（61行分母・報告のみ）
6. 回帰: `ctx.PickOne` 総数不変（増やさない）／`docs/` 再生成・`audit` ずれ0件／
   再生側で「逸らした」のログが読めること（台本に逸らしの表示イベントを出すかは Phase 0 で提案。演出は Codex 側）
