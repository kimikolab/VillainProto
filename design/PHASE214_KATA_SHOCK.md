## 1. 実装の決め（Phase 0 で決めた・指示書に無かったもの）

| 項目 | 決め | 理由 |
|---|---|---|
| 起爆の場所 | `ApplyDamageBody` の **HP を引いて死亡処理（`HandleDeath`）を通した直後** | 「倒れても放電」を1箇所で満たす。破片が受け切った一撃・受け流し・`lethal: false` で 0 になった一撃はそこへ届かない |
| 刻みの見分け | 刻み（毒の刻み・燃焼の刻み `burnTick`・旧カタの起爆）は**1回の呼び出しにだけ効く札**で渡す | 毒の刻みは `source == null` だけでは他の出どころ無しの削りと区別できない |
| 雷の見分け | 同じく1回の呼び出しにだけ効く札 | 雷が倒した駒の死亡トリガー（破裂など）は別の呼び出しなので、そちらは起爆できる |
| 幅優先 | 連鎖の中で起爆が起きたら**起爆せずに列へ積む**。外側の1回だけが列を回す | 入れ子の呼び出しのまま起爆すると深さ優先になる |
| 放電の相手 | 放電した駒と**同じ陣営の生きている隣全員**（席番号の順）。倒れた駒も自分の席から放電する | 指示書 §1 |
| 放電の扱い | `ApplyDamage(隣, 8, 放電した駒, isFriendlyFire: true)`。軛・破片・身構え・受け流し（同じ陣営なので掛からない）は通常どおり | 「状態異常のダメージ」。棘は同じ陣営の出どころに返さない・板の反射は相手陣営の一撃だけ（**実装で確かめる**） |
| 最初の一発 | 主目標の候補（`TargetPool`）の中で種類が最多・同数は席番号。**介入の鎖（庇い・殉教）を通らない** | 止め（トメ）と同じ扱い。帯びた敵がいなければ `SelectTarget`（乱数と介入の鎖を含む通常の選び方）で1発 |
| 雷の1発 | `ApplyDamage(敵, 攻 ×(1＋種類), カタ)`——`PerformAttack` を通さない（反撃・萎縮・鈍り・`OnAfterAttack` は起きない） | 術（リリの吸い取りと同じ入口）。§1 の +50%・軛・破片は効く |
| マイナス | 雷を落とした後、カタの隣の生きている味方全員に感電（帯びた敵がいなくても落とせば付く） | 指示書 §2 |
| K2 | 刻みでも起爆する札（`ShockTick`）を**持つ駒が戦闘に1体でも出ていれば**その戦闘の刻みが起爆する | 札の差し替えで版を作る（`Run` の引数を増やさない） |
