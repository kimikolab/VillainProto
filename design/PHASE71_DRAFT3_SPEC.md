## 0. 主題

### 0-1. 第70期が見つけたこと

> **選択ありドラフトの編成は、静的な数値の上で理想編成と見分けが付かない**
> （総攻 48.9 対 48.6・総HP 376 対 372）**のに、既存5波では 32.09% 対 67.2%。**

**差は数値ではない。35pt はまるごとシナジーである。**

そして第70期の選択規則（素朴）は**攻撃力と HP しか見ていない**——**シナジーを一切狙わないプレイヤー**の値。
実際のプレイヤーは組み合わせを狙って引く。

> **その差がどれだけ回収できるかが、ドラフトでこのゲームの中心ループが生き残るかどうかそのもの。**

### 0-2. この期で答える問い

**選択規則をシナジー志向にすると、35pt のうち何 pt が戻るか。**

**数えるだけ。設計判断をしない。採否も無い。**

### 0-3. 物差しの確定（**第70期の訂正を反映**）

- **中間帯は第2〜5波で数える。第一波は実行して除外する**（compare の従来の作法へ戻す）。
  第70期の Q1 は5波集計で数えたため、**「第一波しか勝てない編成」が 1/5 = 20.0% で中間帯のど真ん中に落ち**、
  最強の版が中間帯最下位という逆向きが出た。**飽和している波を、分布の帯を数える指標に混ぜない**
- **Q1 の線は 60% のまま据え置く**（第70期の最大は D の 57.1%）
- **寄与の器具は素体差し替えに統一**（第69期）。1枚抜きと混ぜない
- **勝率と中間帯の両方を併記する。** 第70期は物差しで主因が割れた（3つのうち2つが「波」）ので、
  **どの物差しでも同じ結論かを毎回確認する**

## 2. 作るもの

### 2-1. 3つの選択規則（**測る前に固定**）

いずれも「まだ選ばれていない駒から無作為に3枚提示 → 1枚選ぶ」を5回。**選択に乱数を引かない**（提示のみ乱数）。

| 規則 | 選び方 |
|---|---|
| **N（無作為）** | 提示の中から**乱数で1枚**。**下限**。※この規則だけは選択にも乱数を使う |
| **P（素朴）** | 第70期の C/D と同一——すでに選んだ駒に攻7以上が2枚未満なら提示の最大攻撃力、そうでなければ最大HP。同値は `Def.Id` 辞書順 |
| **S（シナジー志向）** | 下記 |

**S の規則（3行。これ以上増やさない）:**

1. **すでに選んだ駒と共有するキーの数**（`TraitKeyMap.KeysOf` の積集合の大きさ）が最大の駒
2. **同数なら攻撃力が最大の駒**
3. **同値は `Def.Id` の辞書順**

**S が最適である必要はない。**必要なのは**決定的で、素人が「噛みそうな駒を選ぶ」程度**であること。
**規則を強くすると回収量が過大に出る。**とくに **1枚目は共有キーが必ず 0 なので攻撃力で決まる**——
**それでよい**（実際のプレイヤーも1枚目は方向を決めていない）。

### 2-2. 版

**3規則 × 2波（既存 / 弱い波 = 敵 `MaxHp` 0.6 倍・診断のローカル・第70期と同一）= 6版。**
配置は**規則配置（H）のみ**（第69期の4行規則）。seed 帯は2本。

**`Stages` は書き換えない。弱い波は測定台であって、ゲームの波の変更提案ではない。**

### 2-3. 数える量

| 量 | 定義 |
|---|---|
| **中間帯**（主） | **第2〜5波**で 5〜95% の標本の割合 |
| **平均勝率** | 第2〜5波。**第一波は実行して除外**。参考として5波版も併記 |
| **編成の中身** | 攻7以上の枚数／総攻／総HP／**共有キーの組数**（Phase 0 の紙と照合） |
| **回収量** | **S − P**（中間帯・平均勝率の両方で） |
| **枚数効果** | キーごとに 1 / 2 / 3 枚同席の勝率。**第70期の「弱い波では燃が3本目」の再現** |
| **駒ごとの在席時勝率と寄与** | **Q1 を満たした版でのみ**。寄与は素体差し替え |
