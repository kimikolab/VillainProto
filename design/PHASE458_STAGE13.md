  `Pos = Graph.Lanes[road][1]`（1-3 では F の次 ＝ 各経路の 1 マス目 N0 ／ C0 ／ S0）・`road` は「味方の拠点に一番近い経路」の選び方（たとえば `ReserveTarget` と同じ「隊のいない経路 → 生存の少ない経路」、または拠点にいちばん近い敵のいる経路）に置けば、
  あとは今の前進の規則（`AdvanceFoes` の湧きの列・`StepEvery`）で拠点へ向かう。**`Lanes[road][0]` は分かれ道 F（3 本で共有）なので、1 マス目は添字 1**
- **「拠点が落ちても負けにしない」の分岐**: `Fallen = true` を書くのは 2 箇所——敵の前進で拠点に着いたのに出せる隊がいない（`AdvanceFoes` の `Step` の中・`if (NextInterceptor(n) < 0) { Fallen = true; …}`）と、迎撃の後（`CloseIntercept` の `Fallen = true;`）。
  負けにするのは `Finished`（`… || Fallen || …`）と `Won`（`&& !Fallen`）が読むから。「拠点は使えなくなる（代金）」にするなら、この 2 箇所を `HomeLost = true`（新しい状態）に分け、`Finished` ／ `Won` は読まず、
  拠点を読む口（`CanReform` の `s.Road < 0` ／ `Rest` の `s.Pos != Graph.Home` ／ `NextInterceptor` ／ 届いた駒・呼ぶの `CanTrade`）が `HomeLost` を見る形になる
- 1-3 の盤は第459期もそのまま使える（`Stage13` を第459期に作り替えるときは今の姿を `Stage13H458` に固定する）
