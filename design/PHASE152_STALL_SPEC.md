## 0. なぜこれをやるか

### いま `docs/balance.md` で起きていること

```
反撃 (ヒサ×カド)    100.0 /  0.0 /   0.0 / 100.0 / 81.0
反撃改 (ドハ×カド)  100.0 /  0.0 / 100.0 / 100.0 / 82.5
反撃改2 (ガン×カド) 100.0 /  0.0 / 100.0 /  95.0 / 74.0
反撃改3 (カド×ハギ) 100.0 /  0.0 / 100.0 / 100.0 / 96.0
```

**カドを含む4行すべてが第二波で 0.0%。** そして `反撃 (ヒサ×カド)` は**第三波も 0.0%**。
これは**第136期から 15 期あいだ持ち越されている**。

### 第三波の 0.0 は原因が特定済み（第136期の報告書）

> ヒサが落ちたあと**殴れる駒が盤上に1枚も無く**（ノノは術・カドは不動・ガルドは構え）、
> 残った戦斧兵の薙ぎをガルドが毎ターン受け流して**30 ターンの膠着で負ける**。
> **受け流しはカドの反撃の機会も消す**——被弾が起きないので棘が刺し返さない。

**膠着の条件も特定されている**:

> **味方に殴り手が残っていない ∧ 敵の1ターンの攻撃回数 ≤ 在庫 N**

**`AdoptedUses` を 4 → 2 に下げても消えない**（第136期の追加で確認済み）。

### これは「相性が悪い」ではなく「決着しない」

**カドとガルドが噛み合わないこと自体は設計として正しい。**
両方が「庇う」駒で、しかもガルドの受け流しが**カドの反撃の燃料（被弾）を消す**。
役割が重なったうえに片方が片方を無力化する——**組み合わせを考えさせる**という狙いそのもの。
**同席の是非はこの期では直さない。**

塞ぐのは結果のほう。**30 ターン何も起きない絵が流れ、勝敗が上限ターンというメタルールで決まる。**

そして**膠着の条件にカドは出てこない**。「無効化で耐える壁 ＋ 殴り手が全滅」なら
**将来どの組み合わせでも再現する**。いまカド軸で露出しているだけである。

### 直し方は第136期が既に書いている（が、測っていない）

> **在庫が満タンの手番は殴る**（`CanAct(Attack)` を在庫で分岐）なら、
> 膠着の局面（在庫が減らない＝殴られていない）でこそガルドが殴る。
> **膠着を解く候補としてはこれが筋**だが、この追加では触っていない（指示書の外）。
> ただし**受け流しと中継はどちらも「殴らない手番」を資源にしている**ので、殴らせると両方が薄まる。

**最後の懸念は実測されていない。** 在庫が満タン＝殴られていないターンなので、
**薄まる量は小さいはず**だが、それを確かめるのがこの期の仕事。

## 3. 予測（**Q0-3 / Q0-4 が出てから確定させる。実装前に書き切り、外れても消さない**）

1. **第二波の 0.0 は第136期より前からある**（粛 × カドの構造的な詰み）。
   **ガルドとは無関係**と予測する
2. **第三波の膠着は `SwingWhenFull` で解ける**。0.0 → 50 以上
3. **受け流しと中継が薄まる量は小さい**。在庫が満タン＝殴られていないターンなので、

   ——第148期の「攻撃しない駒には号令の市場が成立しない」の裏返しで、
   **ガルドが殴るようになると号令が初めて換金される**。この行だけ別の理由で動く可能性がある

## 5. 採否

### 採用の条件
1. **膠着が解ける**（`反撃 (ヒサ×カド)` 第三波が 0.0 から上がる）
2. **受け流しと中継が薄まらない**——殴り手が十分いる行で、受け流しの発火が **−10% 以内**
3. **拒否権が立たない**（主判定19行の第五波が歯止めを下回らない・いずれの波も −10pt 以上のセルが出ない）
4. **特異性**: ガルドを含まない行が ±0.0
5. **情報セルが減らない**（第151期に 30% を落とした理由と同じ基準）

**膠着が解けるなら、勝率が多少上下しても採る。** これは強度の話ではなく**盤面が成立するかどうか**の話。

### 解けなかったとき
**`SwingWhenFull` は残置**し、報告書に「**なぜ解けなかったか**」を書く。
条件（殴り手が残っていない ∧ 敵の攻撃回数 ≤ 在庫）のどちらが外れなかったかを分けて書く。

**次の候補**（この期では測らない）:
- 上限ターンに近づいたら受け流しが効かなくなる（消耗）
- 在庫の上限を敵の攻撃回数より小さくする
- **カドとガルドを `compare` の行から分ける**（器具の話。膠着そのものは解けない）
