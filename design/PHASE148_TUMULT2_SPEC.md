## 0. なぜこれをやるか

### 段0 —— 情報セルが減っている

第147期で **140 → 138（主判定 45 → 44）**。混乱で3行が上振れして天井に近づいたのが原因。
申し送りで `突き返し (ハネ×ウツ)` が第五波で **+26.5pt** 動いており、**席の寿命が切れている疑い**がある。
**測る分解能が落ちた状態で次の駒の期に入りたくない。**

### 本線 —— バサは戦闘の後半、ほぼ何もしていない

第147期で混乱は採用したが、2つの穴が残った。**どちらも同じ1つの問題**である。

**(1) `ConfuseUses = 3` を使い切った後。** 第144期 段A（入れ替えだけ）の帰属は
**読み手なし +4.3 ／ 肩代わり −3.1 ／ ササ同席 −7.5** ——**符号が台で割れて平均はほぼゼロ**。
「脆い敵を前に出す」と「硬い敵を後ろに隠す」を同時にやるため。
戦闘は 8〜10 ターンなので、**3ターン目以降はずっとこの状態。**

**(2) 手番が素の通常攻撃（攻7）のまま。**
**手番が「ただの通常攻撃」だけの駒は無くしていく**のが方針。転生の機会にここを埋める。

> **手番で混乱を撃てば両方が解ける。** 在庫（`ConfuseUses`）ではなく**手番が上限**になるので
> 外付けの数え方が要らなくなり、後半も仕事が残る。

### 順序の厚み（**欠点ではない**）

`StatusKeys.Confused` は**ターン頭の一括消去に入っていない**。消えるのは
`ConsumeConfusion`（その駒が次に攻撃したとき）だけなので、**混乱は無駄にならず遅れるだけ**:

| 状況 | 起きること |
|---|---|
| バサが先に動く | その敵は**そのターンのうちに**自軍を殴る |
| 敵が先に動いた後にバサが撃つ | その敵は**次のターンの手番で**自軍を殴る |

**バサは速8。** 敵は 勇者候補14／槍騎兵12／狙撃手11 が速く、詠唱兵5／城塞の重装兵3 が遅い。

- **速い敵を狙うと1ターン遅れる**
- **遅い敵を狙うとそのターン効く**——**詠唱兵が溜めているターンに撃てば、その場で大技が敵に向く**

**速さを読む判断が手番に乗る**のはいまのロスターに無い形なので、これは厚みとして残す。
**バサの速さはこの期では触らない**（触ると変数が2つになる）。**遅延の実害は計数で出す**（§4-2）。

### Q0-1. 段0 —— 寿命の切れた席の洗い出し

`docs/reseat.md` を再生成した上で:

超えなければ差し替えない。**粗順の1位が落ちたら2位・3位を順に見る**（第143期の前例）。

### Q0-2. 本線 —— `Actions` を持たせたときの周期の穴

`ActionIndex++` は `CanAct` 通過後なので、**その駒が永久に実行できない種別を周期に混ぜると
そこで止まって二度と進まない**。

- バサの `Actions` は **`[Skill]` 1要素**にする（周期にしない）
- **`CanAct(Skill)` が偽になる条件**（そのターン前に出た敵がいない）で `IdleTurn` が立つか。
  立つなら**号令（ガン）・据え（バン）・責め苦（シガ）が買い取れる**形になっているかを確認する
- `SurrendersTurn` 相当の扱い（カドで一度踏んだ穴）

### Q0-3. 手番の混乱と、ターン頭の混乱の二重掛けを避ける

現行は `ShuffleStagger.Confuse` が**ターン頭（`ShufflerTrait.Settle`）で**混乱を立てている。
**手番に移すなら、ターン頭側は落とす。** 二重になると、どちらが効いたか測れない。

**新しい列挙の値**を足す（`Advanced` / `Both` / `Confuse` は**残置**）:

```
ShuffleStagger { None, Advanced, Both, Confuse, ConfuseOnAction }
```

- `ConfuseOnAction` のとき、**ターン頭では混乱を立てず、手番で1体だけ立てる**
- `ConfuseUses` は `ConfuseOnAction` では**無視する**（手番が上限）。
  **無視することを doc に書く**——ノブが効かない組み合わせを黙って作らない

### Q0-4. 手番で狙う相手の選び方

**「そのターン前に出た敵」**から1体。**いなければ撃てない**（`CanAct` 偽）。

- ターン頭の入れ替えで**行が前に変わった敵**を覚えておく必要がある。
  現行の `Confuse` が同じ判定（`FormationRules.DepthOf` の比較）をしているので、**その結果を1つ持つだけ**
- **複数いたら `Roll` で1体**（`PickOne` を新たに使わない・必須4）
- **その敵が既に混乱しているなら立て直さない**（重ねても意味が無い）。
  その場合**他の候補を見るか、撃たずに `IdleTurn` にするか**を決めて理由を書く

### Q0-5. 攻7 を捨てる影響

`Skill` は攻撃を消費するので、**バサの与ダメが 0 になる**。

第143期のササ（攻7・`[Skill]` で身構え）は**与ダメ0にしたのに4台すべてで上がった**。
条件が近いので同じ形になる見込みだが、**ササは上限7で耐久に変えた**のに対し
**バサは供給の安定に変える**ので、出方は違いうる。**予測に書く。**

### Q0-6. 測定台

第147期の4台をそのまま使う（`confuse dir` の土台）。**V0 は現行の `Default`**
（`(true, Confuse, ConfuseUses: 3)`）——**この期の問いは「手番に移して良くなるか」**であって
「混乱を足して良くなるか」ではない。

| 台 | 見るもの |
|---|---|
| 被弾変換が厚い | 餌が減る損と、供給が安定する得の差し引き |
| 被弾変換が薄い | 純粋な得 |
| ササ同席 | 混乱は敵→敵なのでササの供給には化けないはず |
| **手番市場**（バサ ＋ ガン または バン ＋ 3） | **撃てないターンの `IdleTurn` が買われるか**（新しく足す台） |

- 各台の V0 が 40〜95%・情報セル 3 以上であることを先に確認する
- 埋め草は**敵の数値に触る駒（呪詛官ネル・萎縮のクビ）を外す**（第143期の則）
- **土台の駒が「自分で動き出せるか」「その席から動けるか」まで数える**（第146期の則）

### Q0-7. 過去に「ターン頭の効果を手番へ移した」期が無いか
`design/*.md` に限定して走査する。**移設は出力を下げる方向に出る**（撃たれる回数が減る）という
一般則が既にあるはずなので、あれば引く。

## 3. 予測（**Q0-6 の台が決まってから確定させる。実装前に書き切り、外れても消さない**）

1. **供給が増える。** 在庫3回から「毎ターン1回（撃てるとき）」になるので、
   **混乱の発火回数は 3 → 5〜7 回/戦**に伸びる。ただし**撃てないターンがある**ので
   ターン数ぶんには届かない
2. **与ダメ0の影響は小さい。** 第143期のササと同じ形（攻7を捨てて全台で上がった）
3. **被弾変換が厚い台が最も伸びない**——敵の攻撃が敵に向くと餌が減るので、
   混乱が増えるほど損も増える。**負に転じる可能性もある**
4. **手番市場の台で `IdleTurn` が買われる。** 撃てないターンが号令・据えの収入になる
5. **遅延が計数に出る。** 速い敵（勇者候補14・槍騎兵12・狙撃手11）を狙ったときは
   **次のターンに持ち越す**ので、「立てた回数 > そのターンに発火した回数」になる
6. **ササ同席で供給に化けない**（混乱は敵→敵）。化けたら味方も混乱している＝実装の穴
7. **バサを含まない行は ±0.0**（段0 で差し替えた行を除く）

攻7 か、供給の安定か、順序の遅延か。**3つのうちどれが効いたかを分けて書く。**
