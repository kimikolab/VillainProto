## 0. 目的

第369期の返り毒は「味方の毒の半分 → 殴った敵へ」で、1戦 5〜18 層しか動かなかった。理由は2つ:

1. **矢印の向き**: 味方の毒（噴き出しの 58 層）は小さな池で、敵の毒（数百〜1,600 層）は大きな池。小さな池から大きな池へ流しても増幅しない。**大きな池（敵の毒）からこちらへ戻る矢印**が要る
2. **触媒の倍がすべてを飲み込む**: 勇者へ書いた層の 9 割以上が倍で、足し算の仕組み（噴き出し・返り毒・瘴気）が誤差になる（増幅は掛け算ではなく足し算に、という設計の原則にも反する）

この期は次の2つを入れて、**本当に増幅するループ**になるかを見る（ポンの判断 2026-10-21）:

```
敵の毒が深い → 毒の敵が味方を殴る → 敵の毒の一部が殴られた味方に跳ねる（返り毒）
  → スィドの衣が厚くなる → 殴ってきた敵へ衣の厚さぶん浴びせる
  → ヴィオが吸って攻撃力が上がる → 殴るたびに攻撃力ぶんの毒を乗せる
  → 敵の毒がさらに深くなる → 跳ねる毒も増える
```

あわせて、第369期に理由を調べなかった「毒+ベニ+ラウが Z1 ／ Z2 で勇者 100 → 0%」を切り分ける（数えるだけ）。

### 2-1. グザ（版 `GuzaW`・第369期の `GuzaZ` からの変更点だけ）

| | 中身 |
|---|---|
| 手番 | 今のまま（集まる瘴気） |
| マイナス（ターンの頭） | 噴き出し（第369期と同じ表・相手はランダム・味方全体への漏れは無い） |
| 段 | 敵に書かれた毒の層の累計が **50 ／ 150 ／ 400** を越えるたびに上がる（第369期の 30 ／ 80 ／ 200 は勇者戦の T1〜T3 で段 3 に届き、段の意味が無かった。触媒の倍が無くなる分も見込んで上げる） |
| プラス | **返り毒（向きを戻す）**: グザが生きている間、**毒を持つ敵が味方を殴ると、その敵の毒の 1 割（切り捨て）・1回 5 層までが、殴られた味方に跳ねる**（敵の層は減らない）。全体攻撃なら当たった味方ごと。第369期の「味方の毒の半分が敵へ移る」は外す |

- 跳ねた毒は毒の窓口（`ctx.Poison`）を通す（経路名は第369期の `Backlash` を流用してよい）
- 毒に強くない味方は跳ねた毒の刻みで削られる（マイナスが外に出る）
- 文面（叩き台）: プラス「手番で、敵全体へ瘴気を撒く（敵が少ないほど濃い）。毒に侵された敵が仲間を殴ると、その毒が仲間に跳ねる。毒に蝕まれない」

### 2-2. ヴィオ（版 `VioW`）

| | 中身 |
|---|---|
| 手番 | **ふつうに殴る**。当たった敵に、**その一撃の攻撃力と同じだけ毒を乗せる**（ダメージも今どおり入る）。攻撃力は増減（軛 ／ 軽減など）を入れる前の今の攻撃力（素の値 ＋ 上昇分） |
| プラス | ターンの頭に味方の毒を吸い、1層につき攻撃力 +4（元の澱み喰い `BlightfedTrait` のまま・毒の衣を持つ駒からは吸わない ＝ 第368期の吸い分け） |
| マイナス | 味方が汚れていなければ、ただの攻6 |

- 触媒（倍 ／ 注ぎ）と吐き戻しは持たない
- 毒は毒の窓口を通す（経路名は新しく足す）。**毒を乗せる量は軛に切られない**（一撃のダメージだけが切られる）
- 他の駒の攻撃力の上昇（号令など）もそのまま毒の量になる——これが狙いの1つ
- 文面（叩き台）: プラス「仲間が負った毒を吸い取り、その層の分だけ攻撃力が上がる。攻撃した敵に、攻撃力と同じだけ毒を乗せる。毒に蝕まれない」／ マイナス「仲間が汚れていなければ、ただの穀潰し」
