# 第178期 報告 —— B群の転生 1枚目・2枚目（熾のホタ／逆しまのウツ）

指示書は design/PHASE178_REBIRTH_B1_SPEC.md。器具は `BattleSim/Modes/Rebirth.cs`（`0 rebirth …`）。

**数値の線は1本も置いていない**（指示書 §0）。この文書は**何が動いたかの記録**で、
採否はポンが遊んで決める。

> **ウツは2段階で決まった。** 最初に指示書どおり「攻撃力 → 手数」へ**移し**（初版）、
> **ポンの判断で「攻撃力も上がり、かつ手数も増える」両取りに変えた**（採用版）。
> **両方の数字を残す**——初版でしか見えなかったことがあるからである（§3 と §4）。

## 0. 何をしたか

| | 変更 | 窓口 |
|---|---|---|
| 熾のホタ | **火には焼かれない**（燃焼の刻みで HP を削られない。燃えている判定・攻 ×4・貫きはそのまま） | `TickStatuses` の燃焼ループに枝1つ（`EmberRule.Fireproof`・**既定 true**） |
| | ノブ `TickHeal`（燃焼の刻みで回復する版）**既定 0 ＝ 何もしない** | `EmberRule.TickHeal` |
| 逆しまのウツ（**採用版**） | **弱体化されるほど攻撃力が上がり（下げ幅の 1 倍）、かつ手数が増える**（下げ幅 3 ごとに +1 発・上限 5 発） | `ModifyAttack`（`AttackPerDull = 1`）＋ `Trait.ModifyHitCount`（Modify 系の**4本目**）＋ `BattleContext.SwingTurn` |
| （初版・不採用） | 攻撃力は素の 9 のまま・手数だけ増える | 同上（`AttackPerDull` が無い形） |

- **倍率を 3 ではなく 1 にしてある**——両方 3 にすると `(9 + 3d) × (1 + d/3)` ＝ **旧版の二乗**になる。
- **`BattleEngine.Run` の引数は1本も増やしていない**（第154期の作法）。熾火の窓口は
  `EmberRule` 1つに寄せ、ウツ側はノブを持たない（§5）。
- **ウツの1発は通常攻撃と同じ扱い。** 標的は毎発取り直し、傷・毒・燃焼・上限（軛）・
  庇い・反撃は1発ごとに走る。**台本にも `Attack` / `Damage` が1発ずつ並ぶ**（束ねない）。
- **連撃は手番の中だけ。** 反撃・割り込み・追い打ち・再行動は `PerformAttack` を直接呼ぶので
  1発のまま（`ModifyHitCount` を通らない）。

## 5. ノブと、置かなかったノブ

- **`EmberRule` に2つ足した**: `Fireproof`（既定 **true** ＝ 採用した版）と `TickHeal`（既定 **0**）。
  **`EmberRule.Charred` ＝ `Fireproof = false`** が第177期の盤面をそのまま再現する（自己検査 (a')）。
- **ウツ側にはノブを置いていない。** `AttackPerDull = 1` / `HitsPerDull = 3` / `MaxHits = 5` は
  `PerverseTrait` の `const` で、**掃引するには `Run` の引数か規則の struct が要る**。
  **3つを振った表が要るときは、次に触る期で窓口を1つ作ること**
  （`PerverseTrait` はいま規則を1つも読んでいないので、置き場所が無い）。
  紙の格子は `0 rebirth phase0` の Q0-2 が出す。
- **`EmberRule` は `= default(T)` でなくなった**（`docs/rules.md` の5列目が ○ → 空）
  ——**採用した版が「全部 0」ではない初めてのノブ**である。
  規則を足した期が既定を `false` / `0` に置く作法（第130・133・137期…）は「測って採らなかった」ときのもので、
  **採った版を既定にするとこの列は落ちる。列の意味は変わっていない。**

### (e) 再生側

```
Godot_console.exe --path DemoApp --headless --quit-after 120000 -- \
  --demo-autoplay --demo-quit --demo-fast --demo-preset=逆しま改 --demo-stage=3 --demo-seed=0
```

- 終了コードは 29（`--quit-after` の経路）。**合否は `DEMO_SMOKE_COMPLETE` の行で読む**
  ——map11 の通しと同じ作法。
