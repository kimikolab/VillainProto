## §2. 触媒のカタ

### 2-1. 能力

- **手番（起爆）**: 攻撃しない。**敵全体の毒と燃焼を、その場でもう1回働かせる**（層は減らさない）
  - 1回分の働き＝通常のターン頭の刻み（`TickStatuses` の毒・燃焼）と同じ量・同じ計算
- **プラス**: 毒と燃焼を**両方**帯びた敵には、起爆のダメージが **2倍**（`DualMultiplier = 2`）
- **マイナス**: 起爆は味方にも届く——**味方の毒と燃焼も1回余分に働く**（倍率は掛けない）
- 毒・燃焼が1つも無い手番は何も起きない（手番を空振り）

### 2-2. 狙い

- 毒・燃焼の「溜まるまで遅い」を、溜めてから毎ターン起爆することで前倒しする
- **毒×燃焼の掛け合わせ**（グザ＋ボルグ、ラウ＋ゾトなど）に初めて明確な理由ができる
- マイナスで味方も削れる → 倒れた駒がリィカの層の燃料になる
- グザの漏れ・ボルグの火移り・ベニの「味方の毒2倍」を抱えた編成ほど味方の被害も大きく、
  **起爆するか、味方を守るか**が編成の判断になる

### 2-3. 数値（測る前に固定）

| 項目 | 値 | 理由 |
|---|--:|---|
| HP | 48 | 後列の支援駒並み（ミオ・グザ帯） |
| 攻撃 | 3 | 殴らない駒。強化の受け皿にならない値 |
| 速さ | 6 | グザ（毒を撒く）より遅く、ヴィオ・ベニの手番の前後に来る程度。Phase 0 で行動順を確認 |
| 前に出るか | 出ない（`Advances = false`） | |

### 2-4. 文案（仮）

- プラス「手番で敵全体の毒と燃焼をその場で弾けさせる。両方を帯びた敵には倍で効く」
- マイナス「触媒は敵味方を選ばない。味方の毒と燃焼も一緒に弾ける」
- フレーバー（仮）「混ぜれば燃え、燃やせば腐る。何を混ぜたかは本人にも分からない」

## 予測（実装前に宣言・コミット。**編成表の実駒を数えて書くこと**）

方向のみ（診断台で見る）:
- 毒と燃焼を両方持つ編成が一番伸びる
- グザ（味方に毒が漏れる）・ベニ（味方の毒2倍）を含む編成は、味方の被害も大きく伸びる
- リィカ軸の台では、味方の倒れる数が増え、層の最大値が伸びる
- カタを含まない行は ±0.0（差し替えだけでは動かない）

## 測定・受け入れ

1. `compare` 61行×第2〜5波。**カタを含まない行は前期版と0件差分**（ナタは `Presets` に残るので全行が一致するはず）
2. **診断台を3つ**（`Presets` には足さない）: 毒の台（グザ・ミオ・ヴィオ・ベニ等＋カタ）／
   毒×燃焼の台（グザ＋ボルグ等＋カタ）／リィカの台（リィカ・ゾト・ムグ等＋カタ）。各台でカタあり・なしを並べる
3. 帳簿（1戦あたり）: 起爆の回数・敵へのダメージ（両方持ちの倍の分を分けて）・**味方への被害**・
   起爆で倒れた敵／味方の数・リィカの層の最大値
4. `chain` の残存・全滅勝ちを併記
5. 回帰: `ctx.PickOne` 総数不変（増やさない）／`docs/` 再生成・`audit` ずれ0件・`roster audit` 再生成／
   再生側で「起爆」のログが読めること（演出は Codex 側。台本に起爆の表示イベントを出すかは Phase 0 で提案）
