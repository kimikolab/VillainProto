## 0. 主題

### 0-1. 埋めるもの

第65期の結論: **強化は供給 16（窓口 7 ＋ 自己強化 9）対 読み手 1（ウツ・符号だけ）の通貨**で、
偏っているのは供給の内訳ではなく読み手の側（積み残し1'）。
供給は 39/61 行にあり、価値は帰属 +2.0〜+19.1pt と実在する。**読む駒だけが無い。**

> **`AtkBonus` を読んで攻撃の型が変わる駒を1枚作る。**
> ただし量の閾値を「駒の存在条件」にしない——供給量は該当行で 5.6〜23.2 と散る（第65期）ので、
> 読みだけで立つ駒は行ごとに死ぬ。**自分で `AtkBonus` を作れる駒に載せて、外の供給は加速として効かせる。**

### 0-2. 対象: 軋みのヨミ（**選定はここで固定。Phase 0 の結果で変えない**）

| 項目 | 現況 |
|---|---|
| 軋みのヨミ | HP92 / 攻6 / 速5 / **単体**。`Displaced`: 隊列を動かされるたび `AtkBonus += 9`（前へ突き出されると `+22`）、その場で割り込んで攻撃。自分では動かない |
| 含む行 | **3 行**（隊列崩し／突き出し／移動改）。**うち隊列崩しは主判定 #1・突き出しは #17** |
| 出どころ | `TURN_SLOT_PLAN.md` §4-3 段1の第一候補（「一定以上乱されたら攻撃が薙ぎになる」は1行で、**`AtkBonus` という既存の値を条件に使えるので新しいカウンタも要らない**） |

**選んだ理由（資格基準 `TURN_SLOT_PLAN.md` §2-4 の適用）:**

1. **既存の1文に「攻撃力が上がる」が既に入っている。** 変質はその文の続きで書ける（軋みが響く）
2. **自分で `AtkBonus` を作る**ので、外の供給（吐き戻し・号令・縛め）が無い行でも死なない——**AND ゲートにならない**（第57期の燃焼、第62〜64期のヌキが落ちた形を避ける）
3. **外の供給は同じ `AtkBonus` に積まれる**ので、ヨミをゴルムの前に置けば吐き戻しで早く響く——**強化の読み手として働く**
4. 常時単体 43 体の1枚。**画面の単調さ（`TURN_SLOT_PLAN.md` §1-4）と読み手不足を同時に埋める**位置

### 0-3. 規則（1文の続きとして）

> 隊列を動かされるたび攻撃力が上がり、その場で割り込んで攻撃する。**上がりきると攻撃が薙ぎになる。**自分では動かない。

- `ModifyPattern`: `AtkBonus >= Threshold` のとき `Single → Sweep`。**それ以外は触らない**（乗算も追加ダメージも無し）
- **割り込み（`OnMoved` の攻撃）にも同じ規則が乗る**（`PerformAttack` を通るなら自動。Phase 0 で確認）
- `Threshold` は `Run` への引数（`CreakRule`）。**既定は無効**（引数なしの `compare` は 305 セル一致）。
  採用時に既定を採った値へ

**薙ぎにする理由（貫きにしない）**: 常時薙ぎはボルグ／ハギ／ドルガの3枚で貫きは 0 枚だが、
貫きは横列の経路設計（2 標的攻撃・レーン）が未着手で、**先に貫きの駒を増やすと後の設計を縛る**。
薙ぎは巻き込み表が確定している。**「軋みが盤面全体に響く」のフレーバーも薙ぎ側。**
