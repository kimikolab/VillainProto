# 第35期 指示書 —— 介入の密度（RedirectPercent）の掃引。介入試験の最終判定

対象ブランチ: `master`（第34期 37b9239 以降）
背景: 第34期で「介入の試験は体（窓の長さ）では立たない」が確定した。律速は勇者候補の生存ターン数で、殉教者の体はそこに効かない（生存T 2.1倍に対し発火1.5倍）。残る交絡の無いノブは**窓の密度（`RedirectPercent`）**のみ。物理的上限の p=100 まで振ってもW5に新規の固有の敗者が湧かなければ、**この盤面で介入の試験は立たない**ことが窓の長さ・密度の両面から確定する。本期はその最終判定。これで結果がどちらでも、W5×介入の糸は閉じる。

---

## Phase 0: 事前計算（到達可能性。第34期の規則「目で数えずに計算する」の適用）

掃引の前に、第34期の `guard` の数表（HP52・p50）から次を計算して固定する:

1. **候補行の特定**: `他波最小 > 10` かつ `W5（庇うあり・HP52） ≤ 25` の全行を列挙。各行について `庇うなし52` との差（現行の介入分）を併記
2. **線形外挿**: 介入分が p に比例すると仮定した p=75 / p=100 での W5 予測値。閾値10を割る行に印
   - Web側の暫定計算では 裂き（11.5・介入分−3.0 → p100 で 8.5 前後）が第一候補、仇討ち×砕けが縁。これを検算し、見落としが無いか**全行で**機械的に出すこと
3. **発火の上限**: 発火/戦の理論上限 ≒ 勇者候補の平均生存T ×（単体攻撃の頻度）× p。p50 実測 1.12 から p100 の期待発火を外挿し、実測と照合する準備をする
4. 線形仮定が崩れる要因を事前に列挙（p=100 は判定が決定的になり seed 間分散が変わる／発火増→殉教者の成長加速→勇者候補より先に殉教者が割れて窓の閉じ方が (i) に戻る、等）

## Phase 1: 実装（今回は BattleCore に最小の変更が入る）

### 1-1. 敵側の割合の分離

`GuardianTrait.RedirectPercent` は**味方ガルドと共有**なので、そのまま振るとガルドを含む行が全部動いて交絡が戻る。分離する:

- `TraitId.Martyr`（殉教）を新設し、殉教者の `Guardian` を `Martyr` に差し替える
- `MartyrTrait` は `GuardianTrait` と挙動同一（肩代わり成長・`PendingKey` の作法・`OnCarryOver` 含む）で、割合定数だけ自前に持つ。**ロジックの重複は共通の基底かヘルパーに寄せ、「定義は1箇所」を保つ**
- `BattleEngine` の介入の鎖に Martyr の段を足す（Guardian の段の直後・同じ `Row.Front` 条件・`f != target` 条件）。ガルドの段は1文字も触らない
- 割合は掃引のために BattleSim から差し込める形にする（診断専用の setter 等。既定値 50）

### 1-2. 同値検証（実装の受け入れ条件）

**p=50 で compare 全42行 × 全5波が現行 `docs/balance.md` と完全一致**すること（差し替えが挙動を1bitも変えていない証明）。乱数消費の順序が変わって seed がずれる場合はそこで停止して報告（鎖に段を足すと `Roll` の呼び出し回数が変わり得る。Guardian が不在の盤面では Roll を消費しない実装になっているかを確認——`PickOne` が空リストで Roll を呼ばない等、既存の作法に合わせる）。

## Phase 2: 掃引（`guard` 診断を拡張・コミット対象外の測定）

- HP は 52 固定。p ∈ {50（検算点）, 75, 100}
- 対照は第34期の `庇うなし・HP52`（=戦斧兵、54.8）をそのまま使う。**HPを動かさないので対照は1本でよい**（第34期の交絡はHPが原因。今回は割合しか動かない）
- 各点で記録: W5分布一式／発火/戦・殉教者の最終攻・生存T・**勇者候補の生存T**（律速の直接観測）／全42行の勝率と介入分／固有の敗者（新規・かつ対照で敗者でないもの）／カナリア2行（毒+耐久・毒+ベニ+ラウ）
- Phase 0 の外挿との照合。特に**発火が外挿どおり伸びたか**（伸びていなければ 0-4 のどの要因かを切り分ける）

## Phase 3: 判定

**採用基準:**

1. **庇うが作った**新規の固有の敗者 ≥1（同HPの対照では敗者でない行。第34期の帰属条件を正式化）
2. 停止条件に触れない（W5平均 35〜75・0%行 ≤15）
3. カナリア2行が両方 0% に張り付かない
4. 満たす**最小の p** を採る

**採用点がある場合**: その p を `MartyrTrait` の既定値としてコミット → compare 全波・docs再生成 → 回帰チェック（第一〜第四波168セル ±0.0。ガルド行が動いていないことの証明でもある）→ 報告。

**どの p でも湧かない場合（コミットせず停止）**: 「この盤面で介入の試験は窓の長さでも密度でも立たない」を README の知見として記録する準備だけして戻る。**殉教者そのものを戦斧兵に戻すかは決めない**——介入分が正になる行（刻み×抉り +2.5・毒+耐久 +4.0 等、庇うを資産に変換する行）が実測されており、試験としては立たなくても手触りとして残す価値の判断はこちらで行う。
