## 1. 足したもの

**engine 側**（`BattleCore`）。**どれも観測専用で、どの規則もこれを読まない。**

### 1-1. `TakeTurn` を「枠」と「中身」に割った（**中身は1文字も触っていない**）

第104期 §1-4 が `BattleEngine.Run` の行動順ループから切り出した `TakeTurn` を、
さらに**枠**（`TakeTurn`）と**中身**（`TakeTurnCore`）に割った。枠がやるのは3つだけ:

    TurnActor を立てる（**退避して戻す**。再行動は HandleDeath 経由で入れ子になるため）
    TurnsTaken を +1 して、帰ってきた TurnOutcome を数える
    潰れた手番についてだけ Trait.SurrenderedTurn を1回問う

### 1-2. 「手番の中」の定義は `BattleContext.InOwnTurn` の1箇所（**3つの積**）

1. `TakeTurn` の枠の中であること
2. **出どころがその枠の主であること**
3. `InReaction` / `InInterrupt` の中でないこと

**(2) が本体である。** 棘の反撃は「殴った側の `TakeTurn` の中」で走るので (1)(3) だけでは中に落ちるが、
出どころはカドなので (2) で外れる。逆に責め苦の追撃（`OnAfterAttack`）は
自分の手番の中で自分が出どころなので中に残る。**`OnTurnStart` は行動順ループの外側なので (1) で外れる**
——第61期「`OnTurnStart` は speed = ∞ の席」を、そのまま境界として採った。

### 1-3. 出力の帰属

| 通貨 | 帰属の手掛かり | 置いた場所 |
|---|---|---|
| 与ダメージ | `ApplyDamage` の `source` | `DamageToEnemy` を加算する隣 |
| 回復 | 第94期 (T2) の印（`Mark.Owner`） | `Heal` の中。**配り手の側に載せる**（受け手側の `Healed` はそのまま） |
| 状態異常（**回数**） | 同上 | `NoteCarry` の中。7キー（毒・燃・痺・標・破片・傷・手番）だけ |

**状態異常を「量」ではなく「回数」で数えたのは、キーごとに単位が違って足せないから**
（第68期 `CarryUnits` ＝ 層／残T／回／量）。

**`Heal` は源を引数で受け取らない**ので、印（`Mark.Owner`）が唯一の手掛かりになる。
印が立っていない箇所からの回復・状態異常は**誰のものでもない出力**として別の桶へ入れ、
`In + Off + None == All` を自己検査 (d) で突き合わせた（3通貨とも ○）。

### 1-4. `SurrenderedTurn` を問うときにログを黙らせた

engine は `CanAct` が偽の駒にも **`IdleTurn` を無条件に立てる**ので、
生の counter を見ると必ず「売れた」になる（第103期の訂正）。数えるのは**買い手が通す判定**のほう。

**問い合わせが観測を汚さないように、印を落としてログを黙らせてから呼ぶ**
——`CanAct` は Sluggish / Sever がログを出し、Sever は counter を読む。
そのために `BattleContext` に `_quiet` を1本足して `Log` の先頭で見ている。
**乱数は1つも引かない**（`CanAct` の4つの実装のどれも `Roll` を呼ばない）ので、
`compare` 305 セルが 0 件で通ることがそのまま検算になる。

### 1-5. `UnitTally` に 17 本 ／ `BattleContext`・`BattleResult` に 13 本

    TurnsTaken / TurnAttacks / TurnSkills / TurnCharges / TurnStalls
    StallStun / StallSlumber / StallImmobile / StallCanAct / TurnsSurrendered
    DmgOutInTurn / DmgOutOffTurn / HealOutInTurn / HealOutOffTurn
    StatusOutInTurn / StatusOutOffTurn
    （ctx 側）TurnLoopCalls / TurnDmg{All,In,Off,None} / TurnHeal{...} / TurnStatus{...}

**`BattleResult` の側は `required` にしていない**——既存の生成箇所を1つも触らないため。

### 3-1. Q1-4 —— **カドは `Actions = [Skill]` を持っている**（手作りのずれの9例目）

`ImmobileTrait.CanAct` は **`kind != ActionKind.Attack`** を返す。
カドの `Actions` は `Skill` 1要素なので、**問われる種別が `Skill` になり、不動は一度も拒まない。**
実測でカドの手番 26,868 のうち**術が 22,388・痺れで潰れたのが 4,480・不動は 0**。

> **「振らない駒」と「手番が潰れる駒」は別である。**
> カドは毎ターン手番を使って術を撃っている——**ただしその術は出力を1点も生まない**
> （`与ダメ外% 100.0%`）。**出力は全部、殴られたときの棘から出ている。**

**この誤りはコードから検算できる**（`ImmobileTrait.CanAct` の1行）。
**器具はむしろ正しく答えた**——「潰れた」ではなく「潰れていない」と言い、内訳まで出した。

### 3-2. Q1-5 —— 第86期の 35〜40% は別の量（**Phase 0 で予告した**）

第86期の稼働率は「**特性の発火** ÷ 決着T」で、この期が測るのは「**手番** ÷ 決着T」。
生き残った駒は毎ターン手番を持つので、分子が大きくなるのは構造的である。

    ロスター全体（第2〜5波）  最小 24.1% ／ 中央 50.7% ／ 最大 89.3%
    35〜40% に入る駒          **4 / 50 枚**

**予測4の後半（「再行動で刻み手だけが上に外れる」）は当たった**
——**最大の 89.3% は刻みのノミ**（再行動 2.11 回/戦）で、2位以下を大きく引き離す。

## 6. この期の本題 —— 手番はどの通貨を運んでいるか

| 通貨 | 手番の中 | 手番の外 | 誰のものでもない |
|---|--:|--:|--:|
| 与ダメージ | **75.3%** | 18.5% | 6.2% |
| 回復 | 9.7% | **90.3%** | 0.0% |
| 状態異常（回数） | 17.6% | **76.0%** | 6.4% |

> **手番は与ダメージの通貨である。盤面を書き換える通貨ではない。**

**回復の 90.3% は `OnTurnStart`（大喰らいの吸い・墓守・置き去り）と `OnDamaged`（継ぎ当て）から出ていて、
手番を1つも使っていない。** 状態異常も同じで、書き込みの 4 分の 3 が手番の外にある。

**「誰のものでもない」6.2% は毒・燃焼の刻み**（`ApplyDamage` の `source` が null・第13期）。
**回復の側は 0.0%**——`Heal` の呼び出しは1件残らず特性の印の中にある。

### 6-1. 手番を1つも使わずに出す出力（`外ダメ/戦` の上位）

| 駒 | 外ダメ/戦 | 内ダメ/手番 | 出どころ |
|---|--:|--:|---|
| **棘鎧のカド** | **294.0** | **0.0** | 棘の反撃（`OnDamaged`） |
| 爆ぜるゾト | 114.0 | 5.1 | 破裂（`OnDeath`） |
| 仇討ちのザン | 89.0 | 9.1 | 仇討ち（ターン外） |
| 軋みのヨミ | 78.0 | 26.3 | 割り込み（`OnMoved`） |
| 追い打ちのハギ | 50.4 | **0.0** | 追い打ち（`CanAct => false`） |

**カドはロスターで最大の手番外の出力を持ち、手番の中では1点も出さない。**
毎ターン術を撃っているのに（1.87 回/戦）、その術は出力の通貨を1つも動かしていない。

> **第52期・第63期の「カドは振らない駒だが死蔵の捨て場ではない」を、
> 出力の側から言い直すとこうなる——カドは手番を持っていて、その手番を出力に使っていない。**

### 6-2. これが第103期・第104期に何を意味するか

**第103期の代金（餌に手番を1つ捨てること）は、与ダメージにしか課金していない。**
上位3枚のうち2枚（ハギ・カド）は与ダメを手番の外で出すので、捨てても失うものが無い。
**ヒヨが3位だったのは「手番外型だから」ではなく「そもそも与ダメを出さないから」である**
——ヒヨの通貨（強化・弱体）は餌に振っても減らない。

**第104期の払い出し（手番をもう一度渡すこと）も同じ側にしか届かない。**
実測でノミの稼働率 89.3% はロスター最大で、その上積みは全部が与ダメージ。
**回復役・状態異常役に再行動を配っても、彼らの出力の 8 割は手番の外にあるので増えない。**
