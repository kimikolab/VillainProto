## 2. 振るつまみ —— 戦闘の間の回復

**勝った隊が次の戦闘に入る前に、生存者の HP を `MaxHp` の割合ぶん戻す**（`RecoverRule(HpPercent, ReviveDead: false)`）。
死者は戻さない。状態異常・`AtkBonus` は持ち越さない（第165期: 要らない）。敵側には適用しない（現行どおり）。

    HpPercent ＝ 0 / 25 / 50 / 75 / 100      （0 は第166期の再現＝対照）

`CrossBoundary` が `RecoverRule` を受けられない形なら、受けられるようにするのは**やらずに報告して止まる**
（`BattleCore` に触るため。Q0-3）。

## 3. 量と線（R238 の4点セット）

### 3-1. 量

| 量 | 定義 | 単位 |
|---|---|---|
| **2本抜き率** | 1隊が同じ道の2部隊を**続けて**抜いた割合（第3隊の加勢なし） | %（seed 800 本） |
| **部分点** | 抜いた敵部隊の数（0〜4）＋ 残った敵部隊の削り（失った HP ÷ 定義上の総最大 HP）の合計 | 点（0〜4 の連続量） |
| **対比** | 正の割り当ての部分点 − 逆の割り当ての部分点 | 点 |
| **挽回率** | 第3隊が出た seed のうち、第3隊がその道を抜き切った割合 | % |

- **対照（ノイズ）**: 同じ割り当て・同じ回復量を seed 帯2本（0..799 / 800..1599）で回した部分点の差
- **依存変数**: 回復量（5点を別々に判定。混ぜない）／第3隊の選び方（第2候補の行でも向きが同じか、帯に入った回復量で1回だけ確かめる）

### 3-2. 線（測る前に固定）

| # | 問い | 線 |
|---|---|---|
| **線1（難度帯）** | 遊べる難度になる回復量はあるか | **正の割り当てで、2隊それぞれの2本抜き率が 30〜70% に入る**回復量が1つ以上 |
| **線2（対比）** | その回復量で送り先は効くか | 線1 を通った回復量で、**対比 ≥ 0.5 点、かつノイズの 3 倍以上** |
| **線3（挽回）** | 2部隊目で勝つ形は起きるか | 線1 を通った回復量で、**逆の割り当ての挽回率が 20〜80%**（0 なら間違いが即詰み、100 なら間違いが無料） |
| **本丸** | 回復だけで検証用マップは立つか | **同じ回復量で線1・線2・線3 が同時に ○** |

- 2隊のうち片方だけが 30〜70% に入る場合は「△」として、どちらの隊がどちらへ外れたかを書く
- **本丸が × でも、線を動かさない**。§5 の表をそのまま次の判断の材料にする
