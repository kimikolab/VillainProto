## §0. 背景

- 第187期で敵の数値が ×1.15（`EnemyScaleRule(115,115)`）になり、敵の攻撃を下げる・手番を奪う駒の価値が上がった
- ところが既存のデバッファー3枚は、どれも「**開幕の1回きり、または受け身**」で手番に仕事が無い
  - ネル「開幕にデバフを撒くだけの装置」／クビ「開幕以外仕事しない」／ハネ「デバフをばらまくだけ」
- 3枚の役割を分ける: **ネル＝攻撃力を削る（呪いで広がる）／クビ＝次の一撃を弱める／ハネ＝手番を奪い、隊列を動かす**

---

## §1. 呪詛官ネル —— 呪いを広げ、呪われた全員を削る

### 1-1. 変えるもの

現行: 開幕に敵全体の攻撃を下げる（`Curse`・味方全体にも漏れる）。以降は通常攻撃。

**足すもの（新特性、例 `TraitId.Hexer`。現行 `Curse` は開幕の全体呪いとして残す）:**

1. **手番**（攻撃しない）: **まだ呪われていない敵**のうち現在攻撃力が最も高い1体に、ムドと同じ**呪い**
   （`StatusKeys.Curse`・第96期の `HexTrait` と同じ状態。呪われた者同士は単体攻撃の痛みを 50% 分け合う）を付ける。
   全員呪われていれば付与はしない（同値はスロットの小さい方）
2. **呪いの伝播**: 呪うたび（全員呪われていて付与しなかった手番も含む）、**呪われている敵全員**の攻撃力を −4（恒久・重なる）
3. **マイナス**: 呪うたび、**ネルに隣接する味方**の攻撃力を −2（恒久・重なる。ウツの燃料）
4. 開幕の全体呪い（現行 `Curse`）と、その味方への漏れは**現行どおり**

- 呪い持ちが増えるほど1回の下げが広く効き、痛みの共有も広がる（2つの効果が同じ方向に伸びる）
- ムドがいなくても呪いが盤面に積もる。ムドと組めば配り手が2枚

### 1-2. 数値（測る前に固定）

`HexAtkDown = 4`／`LeakAtkDown = 2`

## §2. 萎縮のクビ —— 萎縮は伝染る

### 2-1. 変えるもの

現行 `Cower`: 味方全体の被ダメ −30%（常時）／味方全体の攻撃 −9（常時）。画面では何も起きない。

**新しい動き:**

1. **手番**（攻撃しない）: 敵のうち現在攻撃力が最も高い1体と、**その敵に隣接する敵全員**を萎縮させる——
   萎縮した敵は**次の1回の攻撃のダメージが半分**（`CowerPercent = 50`・1回使えば消える）
   （ポンの懸念「攻撃力の高い敵が複数いたら1体半減では厳しい」への対応。隣へ伝染る）
2. **プラス**: 味方全体の被ダメ −30%（現行どおり）
3. **マイナス（差し替え）**: 萎縮は敵味方を選ばない——クビが萎縮させるたび、**クビに隣接する味方も次の1回の攻撃が半分**。
   現行の「味方全体の攻撃 −9」は外す
4. 萎縮は既存の竦み（`Cowed`・手番を失う）とは別の状態にする（鍵の名前は Phase 0 で決める）

- **ウツとは相性が悪い**（ウツは攻撃力の数値の低下だけを反転する。半減は反転しない）
- 隣に**殴らない駒**（ヒサ・カタ・クグ・バン・ヴェル）や、**毒で仕事をする駒**（グザ・ラウ・スィド）を置けば代金はゼロ
- 味方全体の被ダメ −30% は、毒の軸の「溜まるまでの間の耐久が無い」に直接効く（**クビ＝毒の軸の盾**）

## §3. 突き返しのハネ —— バネ

### 3-1. 変えるもの

現行 `Shove`: 味方が押しのけられるたび、敵の隊列を突き崩す。マイナスは隣の味方の体勢を崩し攻撃を下げる。

**新しい動き:**

1. **手番**（攻撃しない）: **前列で現在攻撃力が最も高い敵を、後ろへ突き返す**（その敵の真後ろの敵と入れ替え。
   後ろがいなければ空いた後ろの席へ）。突き返された敵は**転倒し、次の手番を失う**（既存の `Stagger`）
2. **プラス**: 味方が押しのけられたときの突き崩しは**残す**
3. **マイナス（差し替え）**: 勢い余って、**ハネ自身が隣接する味方1体と場所を入れ替える**（決定的に選ぶ）。
   現行の「隣の味方の体勢を崩す・攻撃を下げる」は外す
4. バンは入れ替えを受け付けない（第185期）。入れ替え相手がバンしかいなければ空振り

- 移動軸では、ハネが手番ごとに味方を動かすので**ヨミ（動かされると割り込む）・シオ・ヒサ**の燃料になる
- 移動軸以外では、後列に置きたい駒が前に引きずり出される「配置を崩される損」
- 突き返された敵（手番を失う）は**シガの見せしめ**の対象になる

## 予測（実装前に宣言・コミット。**編成表の実駒を数えて書くこと**）

方向のみ:
- ネル在席行は長期戦で上がる。ウツ・ムド同席行はさらに上がる
- クビ在席行は隣が殴らない駒なら上がり、隣がアタッカーなら下がりうる
- ハネ在席行は移動軸なら上がり、それ以外は配置が崩れて下がりうる
- 3枚を含まない行は ±0.0

## 測定・受け入れ

1. `compare` 61行×第2〜5波。**3枚を含まない行は前期版と0件差分**（比較先は `git show` で固定）
2. 1枚ずつの対照と、各駒の**マイナスだけ0**の対照（マイナスの代金を新しいプラスの上で測る）
3. 帳簿（1戦あたり）:
   - ネル: 呪った回数・呪い持ちの最大数・呪い持ちへの攻撃ダウン総量・痛みの共有の総量・隣への漏れ
   - クビ: 萎縮させた敵の数・萎縮で防いだ量・隣の味方の萎縮で失った量
   - ハネ: 突き返した回数・奪った敵の手番数・ハネの入れ替えの回数と、それで発火した移動の読み手
4. **診断台を3つ**（`Presets` には足さない）: ネル×ウツ（×ムド）／クビ×毒（グザ・ラウ・カタ等）／ハネ×移動軸（ヨミ・シオ・バサ等）
5. `chain` の残存・全滅勝ちを併記。(G2) の「壊れ／制約」を分解（61行分母・報告のみ）
6. 回帰: `ctx.PickOne` 総数不変（増やさない）／`docs/` 再生成・`audit` ずれ0件／再生側で呪い・萎縮・突き返しのログが読めること
