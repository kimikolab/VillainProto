# 第120期 —— 傷という通貨の棚卸し（**測定だけ。機構は1つも作らない**）

起点: 第119期。**見直し対象は実質5体で、うち3体（ノノ +0.28／ナタ +0.59／エグ +0.66）が傷軸。**
第82期でも差し替え候補6体のうち3体が傷の読み手で、**37期越しに同じ場所が出た。**
第73〜75期が3期かけて代金を直しても値段が動いていない。

> **したがって問題は駒ではなく通貨の側にある。**
> ただし**どう直すかを決める前に、在庫がどこにあるかを知らない。**

**この期は測るだけ。** 新機構ゼロ・駒ゼロ・`Presets` ゼロ・`UnitCatalog` ゼロ・engine は計数のみ。
**`docs/` は全ファイル 0 バイト差**（第82期・第119期と同じ性格の調査の期）。

**採否の判断はこの期でしない。** 出すのは**選択肢を選ぶための材料**である。

**この指示書は自己完結させてある。** 規約は `CLAUDE.md` の規約節（(G1)〜(G16)）。

## 0. 何を知りたいか

### 0-1. 4 つの問い

| | 問い | なぜ要るか |
|---|---|---|
| **W1 在庫** | 傷は**どちら側に・誰に・何個**書かれるか | 第107期の実測「傷の 90.5% は味方側・敵から糸を引く回数 0.53 → 0.00」が**今も成り立つか**。読み手を寄せる先が決まる |
| **W2 消滅** | 書かれた傷は**どの経路で消えるか**（読まれて消費／断ち／繕い／会戦の掃除／駒の死） | 読み手が消費型だと在庫が競合する（第93期）。**読まれる前に消えているなら値段の問題ではない** |
| **W3 実効単価** | 傷1つが**実際に何点に化けているか**（定数 3 との差） | 単価が定数どおりなら「安い」は設計値。下回るなら**空振りしている** |
| **W4 判断** | 傷は**プレイヤーの判断を1つでも生んでいるか** | ポンが「面白さや醍醐味を見いだせない」と言っている核心。**ここが 0 なら、直すのではなく畳む選択肢が立つ** |

### 0-2. この期は「畳む」も選択肢として生かす

第119期までの流れは「傷を直す」前提で来たが、**37期で同じ場所に出続けている以上、通貨を1本減らすのも正しい判断になりうる。**

> **したがって W4 と、**「**傷を丸ごと外したら何が壊れるか**」**を必ず測る**（§2-4）。
> 直す案の材料だけを出すと、畳む選択肢が**測られないまま消える。**

### 0-3. この期で触らないもの

- **機構・駒・`Presets` ・ノブの既定**（計数だけ足す）
- **庇いの対象選択**（案A）——**実装しない。**この期は「実装したら効くか」の材料を出すだけ
- **傷の単価・巻き込み則・断ち・繕い・縫いの仕様**

## 2. 測るもの

### 2-1. 台

**`compare` 61 行 ＋ 交差帯 12 行**（第2〜5波・seed 0..199）。**`Presets` をそのまま使う**——
在庫は編成に依るので、**ローカル台では在庫の分布が測れない**（第117期の穴＝台の性質を駒の性質と取り違える、の逆側）。

**傷を含まない行も分母に入れる**（(G4)）。「61 行のうち何行で傷が1個でも書かれるか」自体が結果である。

### 2-2. W1 在庫

| 計数 | 内訳 |
|---|---|
| 書かれた傷の総数/戦 | **`WoundRoute` の経路別 × 味方/敵別** |
| 傷を持つ駒の同時存在数 | **ターンごと**の平均・最大（味方/敵別） |
| 傷を持つ駒がいたターンの割合 | 決着Tに対する比（味方/敵別） |
| 深さの分布 | 1 / 2 / 3 以上の傷を持つ駒の割合 |

**第107期の 90.5% と 0.53 → 0.00 を再掲し、今の値と並べる**（(G14) と同じ作法——**過去の値は定義を実装から取り直す**）。

### 2-3. W2 消滅 / W3 実効単価

| 計数 | 内訳 |
|---|---|
| 消えた経路の内訳 | **読まれて消費／断ち／繕い／駒の死／会戦の掃除／決着**（合計が書かれた総数と一致すること） |
| **読まれずに消えた割合** | ↑から算出。**これが高いなら値段ではなく到達の問題** |
| 傷が書かれてから読まれるまでのターン数 | 平均・分布 |
| **実効単価** | 傷1つあたりの実際の与ダメ増分。**定数 3 との差** |
| 読み手ごとの稼ぎ | エグ／ナタ／ノノ（／ハリは `Presets` に不在なので**参考として台を1つ組む**） |

### 2-4. W4 判断 と「畳んだら何が壊れるか」

| 計数 | 内訳 |
|---|---|
| **傷が1個でも書かれた行の数** | 61 行のうち何行か |
| **傷の読み手を含む行の数** | 同上 |
| **その両方を含む行の数** | **鎖が繋がっている行の数。これが W4 の実体** |
| **傷を丸ごと無効化した版**（`WoundRule(Enabled: false)` を計数用に足す） | **61 行の帰属**。**−1.5pt 以上落ちる行が何行あるか** |
| 傷の量の**行ごとの分散** | 同じ駒が編成で別物になっているか（第115期 Q2 と同じ問い） |

> **「傷を丸ごと外しても 61 行がほとんど動かない」なら、畳む選択肢が実測で立つ。**
> **逆に大きく落ちる行があるなら、その行が傷軸の実体である。名前を出す。**

**`WoundRule(Enabled: false)` は計数と対照のためだけのノブで、既定は現行。**
**`compare` の既定経路は 305 セル 0 件でなければならない。**

### 2-5. 案A（庇いが傷を読む）の材料

**実装しない。**次の3つを数えるだけ:

- **庇い・肩代わりの発火回数/戦**（ガルド／ドハ／セッキ／ゴルムの4枚それぞれ）
- **その発火の瞬間に、傷を持つ味方が盤上に何体いたか**（0 なら対象選択を変える余地が無い）
- **現在の対象選択で選ばれた相手が、傷を持っていた割合**（偶然どれだけ一致しているか）

> **3つ目が既に高いなら、案Aを入れても盤面はほとんど変わらない。**

## 3. 判定（**採否ではなく、材料が揃ったかの判定**）

| | 内容 | 線 |
|---|---|---|
| **Q1** | 書かれた傷の総数と、消えた経路の内訳の**合計が一致** | **完全一致**。合わないなら経路の抜け |
| **Q2** | 第107期の 90.5%／0.53 を**今の実装で再現できる**（定義を取り直したうえで） | 方向が一致すれば可。**ずれたら定義の差を書く** |
| **Q3** | W4 の「鎖が繋がっている行」の数 | 数える。**0 行なら傷軸は盤面に存在しない** |
| **Q4** | 傷を無効化したとき **−1.5pt 以上落ちる行**の数と名前 | 数える |
| **Q5** | 案Aの材料 3 つが揃った | 二値 |
| **Q6** | **回帰**: `compare` 305 セル 0 件・`docs/` 全ファイル 0 バイト差・`PickOne` 26 箇所 | 調査の期 |

### 3-1. 予測（**測る前に書く**）

1. **味方側の比率は 90.5% から下がっている**——第111期に交差帯のハリがノミへ替わり、**刻み（敵に書く）が1本増えた**
2. **読まれずに消えた割合が 5 割を超える**——読み手3枚のうち2枚（ナタ・ノノ）は**消す側**で、
   **消費が読解より先に走る**（第104期「状態を消す駒が損になるかは、消す前に読む機会があるかで決まる」）
3. **実効単価は定数 3 を下回る**——エグの抉りは「傷持ちを殴ると +3」なので、**傷持ちを殴れなければ 0**
4. **傷を無効化しても −1.5pt 以上落ちる行は 3 行以下**。61 行のうち鎖が繋がっているのは **5〜10 行**
5. **案Aの3つ目（偶然の一致率）は 3 割前後**——庇いは席と型で選ぶので、傷とは独立に近いはず

**外れた項目は「何を数えていなかったか」の形で書く。**

## 5. 結論の書き方

報告書 `design/PHASE120_WOUND_STOCK.md` の冒頭に、**1つの引用ブロック**で:
在庫の陣営比・読まれずに消えた割合・実効単価・**鎖が繋がっている行の数と名前**・傷を無効化したときの最大の落差。

**§6 に「選択肢の一覧」を書く**（**採否は書かない。ポンが選ぶ**）。各案について、**この期の実測がどう効くか**を1〜3行:

| 案 | 内容 | この期の実測との関係 |
|---|---|---|
| **A** | 庇い・肩代わりの対象選択が傷を読む（傷ついた仲間ほど庇われる） | 在庫が味方側なら噛む。**§2-5 の偶然の一致率が高いと効かない** |
| **B** | 傷持ちを庇った駒が育つ（払いと戻りを1組に） | ゴルムの吐き戻しに前例あり。Aの上に乗る |
| **C** | 傷は塞がりにくい（回復の通りが悪い） | 渇き（第三波）と機構が重なる。副作用が広い |
| **D** | **畳む**（傷をやめて他通貨に統合） | **Q4 の落差が小さければ実測で立つ** |

**A・B には共通の落とし穴があるので必ず書くこと**:

> **傷が「庇われる資格」になると、味方を自分で刻んで庇いを誘導するのが最適手になりうる。**
> ボルグの巻き込みが「損」から「資産」へ反転し、第119期の右上象限（マイナスが実質プラス・現在1体）が増える。
> 対策候補は2つ——**(1) 庇い手が余分に払う**／**(2) 自分で書いた傷は読まない**（`WoundWriters` で区別。§1 の 2 で実装可能性を確認する）。
