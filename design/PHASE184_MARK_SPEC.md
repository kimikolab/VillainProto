## §0. 前提 —— 標は2種類ある

- **敵に付いた標**: 味方の単体攻撃が標持ちを最優先で狙う（`SelectTargetChain` の1段目。前列の壁・庇いを越える）。
  書き手はソラ（一番硬い敵）、読み手はトメ（標持ちを倍で殴る）
- **味方に付いた標**: 敵の攻撃がその味方に集まる（挑発）。書き手はヒサ・カリ、読み手はザン

ポンの評価:
- ヒサ「入れてよかったと思ったことがない」／ザン「機能しているところを見たことがない」
- 「標が攻撃を集めるだけだと、標が無くても他の駒で落とせる。**被ダメージが増えるなら貢献している感が出る**」
- 「ヒサが標を付けた味方に**被ダメージカットのような明確なメリット**があれば使う気が起きる。
  攻撃20が飛んできたらムドは暴発があっても速攻で落ちる」
- 「ヒサは攻撃せず**動きまくっていたほうが絵になる**。移動軸としてもありがたい」
- 「ザンは**標がある状態で他のアタッカー以上の火力が出るか**が重要」

この期は3つを入れる。狙う連鎖:
**ヒサが守り役に攻撃を集める（被ダメ半減）→ 殴ってきた敵にザンが倍返し＋標 →
味方全員がその敵を狙い、被ダメージ +50% → トメが仕留める**

ハギはこの期から外す（標に絡めても足手まといのまま、というポンの判断）。

## §1. 規則: 敵の標に被ダメージ増（`MarkRule`）

- **敵陣営の標持ち**が受けるダメージを **+50%**（`MarkVulnerablePercent = 50`・測る前に固定）
- **味方陣営の標には付けない**（挑発された味方がさらに痛くなると、ヒサの半減と打ち消し合って読めなくなる）
- 対象は全ダメージか単体攻撃だけかは Phase 0 で既存の倍率の段（軛・呪いの共有・破片）との順序を見て決める。
  **既定は「攻撃によるダメージのみ（毒・燃焼の刻みは除く）」**を推奨
- 影響する既存駒: ソラ・トメ（得をする）。Phase 0 で敵の標の書き手を全列挙すること

## §2. 囃し立てのヒサ —— 「守りの挑発」＋「逃げ回る」

### 2-1. 変えるもの

現行 `MarkerTrait`: 開戦時に1回、隣接で最大HPが最大の味方に標（乱数で割る）。以後何もしない。

**新しい動き:**

1. **手番**（攻撃しない）: 隣接する味方のうち **現在HPが最も多い1体** に標を付ける。
   ヒサの標は1つだけ——前の相手の標は外す（同値はスロットの小さい方。`PickOne` を使わない）
2. **プラス**: ヒサの標を持つ味方は**被ダメージ半減**（`GuardPercent = 50`）
3. **マイナス**: 標を付けた直後、ヒサは**逃げる**——標を付けた相手以外の隣接味方と場所を入れ替える
   （`SwapSlots` 経由。入れ替わる相手は決定的に選ぶ。いなければ動かない）。**毎手番**動く
4. 開戦時の1回の標付けは残すか消すかを Phase 0 で決める（初手の手番より前に敵が動く波があるため）

### 2-2. 狙い

- **ムドと噛み合う**: 暴発は被弾の**回数**で溜まるので、痛みを半分にしても暴発は減らない
- 逃げる移動は ヨミ（動かされると割り込む）・バサ・シオの**移動軸の燃料**。入れ替わった味方は前に押し出される
- 画面では「ヒサが指差して、逃げ回る」絵になる

### 2-3. 文案（仮）

プラス「手番で隣のいちばん元気な味方を矢面に立たせる。立たされた者は受ける痛みが半分になる」
／マイナス「自分は何もせず、指差したら隣の味方と入れ替わって逃げる」

## §3. 仇討ちのザン —— 「仇を指差す」

### 3-1. 変えるもの

現行 `AvengeTrait`: 標の付いた味方が殴られるたび、殴った者へ割り込んで一撃（粛で止まる）。
マイナス: 自分が殴られると痺れ（次の手番と刺し返しを失う）。

**新しい動き:**

1. **プラス（強化）**: 割り込みの一撃を**倍の力**で撃ち（`AvengeMultiplier = 2`）、**殴った敵に標を付ける**
   （ヒサの守りの標とは別。敵側の標なので §1 の +50% と トメ の読みに乗る）
2. **マイナス（差し替え）**: 怯み（痺れ）をやめ、**刃を返すたび自分が `AvengeCost` 傷つく**（`= 3`・`lethal: false`）
3. 手番は普通に攻撃（変えない）

### 3-2. 狙い

攻10でも「倍返し」＋「標で +50%」で、標が立っている間は他のアタッカーを上回る場面を作る。
**味方の標（挑発）のイベントを、敵の標に変換する**駒になり、2種類の標が1本の鎖で繋がる。

### 3-3. 文案（仮）

プラス「標を付けられた味方が殴られるたび、殴った者へ倍の刃を返し、仇として指差す」
／マイナス「刃を返すたびに自分も傷つく」

## 予測（実装前に宣言。編成表の実駒を数えて書くこと）

方向のみ:
- ソラ・トメ在席行は §1 だけで上がる
- ヒサ在席行は、標を付けられる味方がタンク系（ムド・ゴルム・カド・ガルド）なら上がる
