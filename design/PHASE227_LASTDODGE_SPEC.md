## 1. 目的

目標は第226期と同じ: **ガルド抜きの移動軸で、9体の波（敵 HP200%／攻200%）を完全勝利（全員生存）する。**

第226期で分かったこと:
- バサとハネの対（＋突風）で全員生存 60.0 → 80.5%
- **残りの失敗はほぼ1つ: セロが一撃で倒れる**。敵の一撃 22 はセロの HP42 の4割（16.8）より大きいので、「4割を切ったら下げる」緊急退避を経ずに倒れる（R332）
- 回避盾（挑発）は、隊にとって最良の席がセロを後列に置くので、ほとんど働かなかった（前列にいた時間 6%・R333）。前列に置いた席の最良は 75.5% で、総当たりの1位（80.5%）に届かなかった

→ **一撃死を防ぐ**。防げれば、回避盾（セロを前列に置く席）と緊急退避が回り出すはず。

## 2. 必死の逃げ足

| 項目 | 内容 |
|---|---|
| 条件 | セロが**敵の攻撃による被弾**で倒れる（HP が 0 以下になる）とき——回避の判定に外れた後で |
| 効果 | **その一撃を必ずかわす**。通常の回避と同じに扱う（撃ち返し・入れ替え・成長・移動の段・状態の矢がすべて起きる） |
| 回数 | 1戦に、段0〜1: 1回／段2: 2回／段3: 3回（段は今の移動回数の段） |
| 対象外 | 状態異常のダメージ（毒・燃焼の刻み・放電・澱みの爆発）・味方からのダメージ（巻き込みほか）。これらで倒れるときは発動しない（今の「かわせないもの」と揃える） |
| 文面 | プラスに「倒れる一撃だけは、死ぬ気で必ずかわす（1戦に1回・身軽になるほど増える）」を足す |
| フレーバー | 今のまま（「逃げ足だけは誰にも負けない。撃ち返す暇まであるくらいに。」） |

- 挑発と組むと「敵の単体攻撃を集めて、避け損ねても死ぬ一撃だけは避ける」形になる
- 会戦で次の戦に入るときは回数を戻す

## 4. 席の見方（第226期 R333 への対策）

各版について、次の2つの席を出す:
- **総当たりの1位**（主判定の全員生存で選ぶ。同値は落ちた駒の数・決着ターンの順）
- **セロを前列に置いた席の中の1位**（回避盾が働く席）

回避盾の価値は「セロを前列に置いた席の1位が、総当たりの1位に並ぶか・超えるか」で読む。

## 5. Phase 0

- **Q0-1 一撃死の実数**: 前段の盤面・主判定で、セロが倒れた一撃のうち、その直前に HP が4割以上あった割合（＝緊急退避の外で倒れた割合）。倒れた一撃の出どころ（単体・薙ぎ・貫き・全体・反撃）
- **Q0-2 倒れ方の残り**: セロ以外で倒れる駒と原因（第226期で「K2 以後に倒れるのはほぼセロだけ」の確認）
- **Q0-3 発動の口**: 「倒れる一撃」を回避の判定の後・ダメージの確定前に判定できる場所（第223期の回避の判定 `ApplyDamageBody` の頭との関係）。破片・軛・身構えより前か後か（**破片で受け切れる一撃は倒れないので発動しない**ように、軽減の後で判定する）
- **Q0-4 過去の測定**: `design/` を grep（致命の一撃を防ぐ・根性・一度だけ生き残る機構。ガルドの `LastStandHold` との違いを一文で）
- **Q0-5 台**: §6 の台の駒を数えて予測を書く
