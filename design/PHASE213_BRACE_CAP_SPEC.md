# 第213期 指示書 —— ササの身構え：上限だけ破片より前に（受け切った一撃では弾かない）

置き場所: `design/PHASE213_BRACE_CAP_SPEC.md`。報告は `design/PHASE213_BRACE_CAP.md`。
規模は小。触るのはササの札と engine の破片の段だけ。

## 0. 目的

第212期の Z3（`BraceArmored`）は外すと決まった。ただし Z3 には良いところと悪いところが混ざっていた。

| Z3 がしたこと | 結果 |
|---|---|
| 身を固めている間、**破片より先に上限（7）で切る** | 良い。板が余計に割れない・ササの被ダメが減る・切り落としが増える |
| **破片が受け切った一撃でも弾く（錯乱）** | 悪い。弾きが2〜3倍になり、X字の `継ぎ当て×分散回復` でセロ（HP42）が弾かれて倒れる戦が 0 → 18.5% |

この期は**良い方だけを残す版**を作って、Z2（札を外した姿）と並べる。

- 上限は破片より前に掛ける（Z3 と同じ）
- 破片が受け切った一撃では**弾かない**
- 配り（切り落とした分を破片として渡す）を、受け切った一撃でも行うかは版で分ける

## 1. 背景（第212期の数字・この期の基準）

仕組みの確認（第212期 Q0-3）:
- 身構えの上限は `ApplyDamageBody` の**破片の段の後ろ**（軛の直前）にある。破片は切られる前の一撃を丸ごと受ける
- 破片が一撃を受け切ると `OnDamaged` が鳴らないので、弾き（錯乱）も配りも起きない
- 弾きは1ターン1回。配りは「そのターンに弾いた相手（宛先）」がいるときだけ起きる（`BraceTrait.Deliver`）。宛先の無い保留はターンが変わると消える

第212期の Z2 と Z3（この期の比較の基準）:

|---|--:|---|--:|--:|--:|--:|---|
| 継ぎ当て×分散回復 | 2 | Z2 | 91.5 | 0.52 | 13.2 | 8.6 | ツギ 4.5%・ガルド 4.0% |
| | | Z3 | 71.5 | 1.76 | 45.0 | 6.8 | セロ 18.5%・ツギ 5.0% |

## 2. Phase 0（実装前・盤面は第212期の Z2）

計数だけを足して数える。盤面は動かさない。

- **Q0-1 W で消える弾き**: Z2 で、身を固めているササへの敵の一撃のうち
  「上限を超える」かつ「破片が一部だけ吸って残りが HP に届いた」かつ「**破片が上限（7）以上あった**」もの
  ＝ W では破片が受け切るので HP に届かなくなる一撃を数える。そのうち**そのターン最初の HP 被弾で、実際に弾きを起こしたもの**も数える。
  これが「W で Z2 より弾きが減る分」の見当になる。2台・第2〜5波で。
- **Q0-2 宛先の無い保留**: Z3 で、破片より先に切った分のうち、そのターンに宛先が無いまま消えた量（`BraceLost` の内訳）。
  W1 で配られずに消える量の見当になる。
- **Q0-3 過去の測定**: `design/PHASE143_BRACE*.md` と第143期のコメントに、上限と破片の順番・受け切りの扱いを測った記録が無いか grep。あれば結論を報告に引く。
- **Q0-4 他の破片の出どころ**: W の条件（破片を纏った身構え）に当たる行が、1節の1行以外に無いことを再確認（ヒビ・ドハ・バンほか、破片の書き手を `derive scan` で）。

## 3. 版

版は札の差し替えだけで作る（`Run` の引数は増やさない）。

| 版 | ササの札 | 中身 |
|---|---|---|
| **Z2** | `Brace` | 第211期の姿（Z3 外し）。**この期の新しい規定** |
| **W1** | `Brace` ＋ `BraceCapFirst` | 身を固めている間、破片があれば**上限を破片より前に**掛ける（切り落とした分は保留へ）。破片が受け切った一撃では**何も起こさない**（弾かない・配らない） |
| **W2** | `Brace` ＋ `BraceCapFirst` ＋ `BraceHeldDeliver` | W1 ＋ 破片が受け切った一撃でも、**そのターン既に宛先がいれば保留を配る**（弾きはしない。新しい宛先も作らない） |
| Z3 | `Brace` ＋ `BraceArmored` | 第212期の規定（対照・残置） |

- 破片が一部だけ吸って残りが HP に届いた一撃は、どの版も今までどおり `OnDamaged` → 弾き・配り
- 破片の無い一撃は、どの版も第211期と同じ道
- `BraceArmored` は**削除しない**（対照）。`UnitCatalog.Sasa.Traits` から外すだけ

## 4. 予測（実装前に宣言してコミット）

Phase 0 の数字を見てから、下の方向に数値を入れて書き直すこと。

- **P1** ササに破片が乗らない行は W1・W2 で Z2 と台本が一致（0 セル）。Z2 は第212期の Z2 列と一致
- **P2** 弾き/戦は **W1 ＝ W2 ≦ Z2**（2台・各波）。受け切りで弾かないうえ、Q0-1 の分だけ HP に届く被弾が減る
- **P3** セロの倒れは Z2 並み（分散回復 第二波 18.5% に戻らない）
- **P4** 板が余計に割れる量は W1・W2 で 0（Z3 と同じく上限が先）。ササの被ダメは Z2 より減る
- **P5** 配った/戦は **Z2 ≦ W1 ＜ W2 ＜ Z3**の見当。W1 は宛先が無くて消える保留が多い（Q0-2）
- **P6** 全員生存は W1・W2 とも Z2 −2pt 以内（分散回復の平均 97.4・ポンの編成 第五波 95.0）
- **P7** ササの板から出る反射/戦は W1・W2 で Z2 より減る（上限で切った分だけ破片が吸う量が減る）。板は長持ちする

## 5. 実装

- 札2枚: `BraceCapFirst`・`BraceHeldDeliver`（札そのものは何もしない。engine が読む。`BraceArmoredTrait` と同じ作法）
- engine の破片の段: いまの「破片より先に上限で切る」門を `BraceArmored` **または** `BraceCapFirst` で通す
- engine の `ArmorOnlyHit`:
  - `BraceArmored` → 今までどおり `BraceTrait.Struck`（弾きと配り）
  - `BraceHeldDeliver` → `BraceTrait.Deliver` だけを呼ぶ（`internal` にする）。弾きは起こさない
- 乱数を新しく引かない
- 計数: 版ごとに 弾き／配った／宛先が無くて消えた保留／破片より先に切った回数と量／ササの板からの反射 を `UnitTally` に（既存の欄で足りるものは流用）
- 札の分類表（`checkup` の `hcLabel`・`Program.cs` の2表）に最初から2枚を足す（第211期に `roster audit` が止まった件の再発防止）
- 作戦マップの関係の門（`--map11-phase172`）が落ちたら `Map11Relations.Unresolved` に1行足す

## 7. 規定の決め方

まず Z2 を規定にする（決定済み）。そのうえで:

- **W2 を規定にする条件**（すべて満たす）:
  (a) 分散回復の全員生存の平均 ≧ Z2 −2.0pt
  (b) ポンの編成 第五波の全員生存 ≧ Z2 −2.0pt
  (c) 弾き/戦 ≦ Z2（2台・各波）
- W2 が満たさず W1 が満たすなら W1。どちらも満たさなければ Z2 のまま
- 最終の採否はポンが遊んで決める
