# 第264期 指示書 —— チェック波の採用確定（連続量の物差し・毒台の追加・まとめ）

読み手は Claude Code。第260〜263期の締めの期。新しい機構は作らない。

## 0. 決定

1. **連続量の物差し（`checkwave ranks`）を検証器具として正式採用する**。採用根拠は第263期の主判定（75 組み合わせすべてで軸をまたぐ順位逆転・燃焼と雷が3期のどの版でも反対に並ぶ）
2. 勝率は副の物差しに格下げ。桁合わせ版（B3-桁・W3-割合）は「移動を割る下敷き」として残置
3. **R362 の知見を採用の一部として記録する**: 受けた量に比例して癒える台は打点の桁上げでは割れず、割るには回復そのものへの課税（渇き系）が要る。本編ボスを設計するときの前提になる
4. **毒台は差し替えず追加する**（旧「毒 (グザ×ミオ×ラウ)」は土台負けの対照として残置・7台目を足す）

## 1. 作業

### 1.1 規定の版を固定する

- 以後チェック波を物差しとして使うときの**規定の組**を決めて `checkwave` の既定にする。推奨: ボス側 **B3-桁**・手数側 **W3-割合**（どちらも逆算済みで、連続量に加えて勝率の情報も唯一出る版）。`ranks` は従来どおり全版を併記できる器具のまま残す
- 規定の組で取る正式な指標を1箇所に書く: 倒しT（倒せない台は打ち切りTと総与ダメ）／回復を上回ったターンの割合・窓あたり出力・癒し手を割ったT／純実入り（R362 の4段）

### 1.2 毒台の追加（7台目）

- 選定基準: `compare` の毒の行のうち、**素の 400/300 第四波で勝率が 50% を超える行**。候補の筆頭は「毒+ベニ+ラウ」（第263期 Phase 0 の切り分けで挙がっていればそれに従う）。該当が複数なら実績値が最も高い1つ
- 新台で `ranks` を回し、毒軸の連続量順位を初めて取る。予測: 手数側は回復超過率で雷に次ぐ上位（毒の刻みは軛に切られない）、ボス側は中位〜下位（層が育つ前に燃焼・雷が倒す帯）。ベニの結界が入る行なら、R362 の「受けるほど癒える台」に該当して桁合わせ版でも割れない可能性がある——割れなくても失敗ではなく R362 の追認として書く
- 旧毒台と新毒台の両方を `ranks` に残す（「同じ軸の台でも土台に耐えるかで物差しに乗れるかが決まる」の実例として）

### 1.3 まとめの文書

- `design/CHECK_WAVE_SUMMARY.md` を書く（`FIRE_AXIS_SUMMARY.md` と同じ役割）。中身: 4期の経緯の要約（何が壊れ、何で直したか: 手番→動じない／誰に入るか→全体攻撃／土台→400/300／物差し→連続量）・規定の組と指標・6＋1台の連続量順位表・R361/R362・本編に載せるときの既知の論点（動じないの回避手段・回復課税・毒台の土台負け）
- `design/HANDOFF_NEXT_SESSION.md` 相当の引き継ぎを更新（または新規）: チェック波は採用で一区切り、残っている本線候補を列挙
