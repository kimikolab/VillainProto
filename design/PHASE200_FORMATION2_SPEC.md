## 1. 目的

今の味方の陣形は X 字だけで、**前衛が2枚**ある。タンクを片方に置いても、もう片方の前衛が狙われる。
「もう片方の前衛も守れる」のがガルドだけなので、ガルドがどの軸からも引っ張りだこになっている（`compare` 61行中35枠）。
第199期でガルドの剣の段が入り、ガルドはさらに強くなった。

今期は、**前衛が1枚の陣形「パターン2（ひし形）」を味方の選択肢として足す**。
- 前衛1枚なら、HP の高い駒なら誰でも隊全体の盾になれる。ガルド以外のタンクが同じ土俵に立てる
- 毒パの形（前衛スィド＋中央ベニ）が、そのまま盤面の標準になる
- 代わりに、薙ぎ・貫通で4枚が巻き込まれる。**範囲攻撃に弱い形**（ポンのメモ）

敵の陣形（パターン3・勇者パーティー）は次の期。**今期は味方だけ**。

## 2. 盤面の座標

3レーン（上から 1・2・3）× 3列（後衛・中衛・前衛）。**右が前（敵に近い側）**。
今の9マスとの対応:

|---|---|---|---|
| 1レーン | 後1（3） | ○中1（5） | 前1（0） |
| 2レーン | ○後2（8） | 中央（2） | ○前2（7） |
| 3レーン | 後3（4） | ○中3（6） | 前3（1） |

### 2.2 パターン2の規則（**X 字の規則は1文字も変えない**）

ポンの表（`design/` に画像で置いてもらう前提。無ければこの表を正とする）:

| 位置 | 隣接 |
|---|---|
| A | B, C, D |
| B | A, C, E |
| C | A, B, D, E |
| D | A, C, E |
| E | B, C, D |

| 攻撃 | 当たる駒 |
|---|---|
| D に薙ぎ | D, A, C, E |
| 1-2 レーンへの貫通 | A, B, C, D |
| 2-3 レーンへの貫通 | B, C, D, E |

一般化した規則（新しい形はすべてこれで表を作る。パターン3でも同じ規則を使う）:

1. **隣接**: 縦横斜めの8方向で隣り合う駒は隣接。**同じ列で、間のレーンが空いていれば、その先の駒とも隣接**
2. **狙い**: 生きている駒がいる**一番前の列**が狙いの対象（今の「前列が生きている限り後列は狙われない」の一般化）。D が落ちれば中衛の3枚が前になる
3. **薙ぎ**: 標的の列の全員＋**その1つ後ろの列**の全員。標的以外は副次の倍率（`SecondaryPercent = 60`・今と同じ）
4. **貫通**: 2レーン（1-2 か 2-3）の全員に、前の列から後ろの列の順に当たる。1体抜くごとに減衰（`PierceDecayPercent = 25`・今と同じ）。同じ列に2体いるときの順番は、レーン番号の小さい方から
   - どちらの2レーンを選ぶか: **生きている駒が多い方**。同数なら 1-2
5. 全体攻撃は今と同じ（全員）

### 2.3 実装の形

- **陣形は隊（味方）ごとに1つ**。X 字（パターン1）が既定。パターン2は選んだ隊だけ
- 規則の表（隣接・薙ぎ・貫通の経路・行・レーン）を**陣形ごとに持つ**形にする。X 字の表は今のまま、パターン2の表は §2.2 の規則から作る
- 今の `FormationRules` の静的な表を直接読んでいる箇所が、陣形を知っている入口を通るようにする。**X 字の隊では、今と1ビットも違わない**こと
- 編成（`Formation`）は今のまま5枠。パターン2では、5枠を A〜E に対応させる（枠0＝A … 枠4＝E など、Phase 0 で決める）
- 敵は X 字のまま

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0 と表の実駒を数えてから入れる。

- `compare` は ±0.0
- 表A: P2 は「X・スィド」より上。前衛1枚にスィドが立ち、単体攻撃が集まって痺れ毒の印が増える
- 表B: P2 ではガルドと他のタンクの差が、X 字のときより縮む
- 薙ぎ・貫通を多く持つ敵の波（Phase 0 で数える）では、P2 は X 字より下がる
