# Codex 向け発注メモ（追補）—— 背きの雷・共鳴返し・シガの打ち返し

置き場所: `design/CODEX_BRIEF_SOM_RESONANCE.md`。`design/CODEX_BRIEF_SOM_STANCE.md`（臨戦態勢の4拍）の追補。
触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。出来事の並びと名前は `design/PHASE291_CODEX_MEMO.md` §14-12 を正とする。

## 0. 何が変わったか（第319期から規定・第320期に分岐 C を確定）

背いた獣は、**隣の敵が帯電していなければ、その場で弾けずに敵として立ち、こちらへ雷を投げる**ようになった。投げた雷の行き先で結末が分かれる。
**第320期に「投げて暴発」（WS-b）を規定にした**——どの分岐でも、立った獣は**投げた手番の中で必ず盤から消える**（立ち続ける獣はもういない）。

いま DemoApp は `BeastThrow` を知らずに素通りしているので、この分岐の絵がまだ無い。

## 1. 共通の頭（STANCE の1〜3拍のまま）

1. **寝返り**: 獣がソムの側から敵陣へ走り込む
2. **牙を剥く**: 振り返ってこちらと向き合い、威嚇する
3. **臨戦態勢**: 雷を纏う

隣の敵が帯電していれば、ここで4拍目（暴発）へ（いまの規定と同じ・変更なし）。

## 2. 新しい拍: 投げる（`BeastThrow`）

3拍目の後、**纏った雷をこちらの味方へ投げる**。狙われた味方へ雷の弧が飛ぶ。ソムは驚きの顔（「おまえまで…」）。

そこから分岐する。

### 分岐 A: 共鳴返し（`BeastThrow 共鳴` → 必要なら `走る` → `BeastBurst 共鳴返し`）

狙われた味方が**すでに帯電していた**とき。感電軸の台ではこれがいちばん多い（光の盾 系で 8 割）。

1. 雷が味方の身体に触れた瞬間、**味方の帯電と共鳴して強く光る**（味方の体表の電気が一瞬膨らむ・音が重なる）
2. 雷が**来た道を逆向きに跳ね返る**（増幅して太くなる）
3. `走る` がある場合: 跳ね返った雷が獣に届く直前に、**獣のまわりの敵へ枝分かれして走る**（隣の敵に小さな帯電の印が付く）
4. 獣に当たって**弾ける**（4拍目）。そこから連鎖が広がる

見せたいこと: **裏切りの雷が、こちらの雷で倍返しになる**。「投げたものが、投げた本人に返ってくる」が一目で分かること。味方は勝ち誇っても、ソムは得意げでもよい。

### 分岐 B: シガの打ち返し（`BeastThrow 打ち返し`）

狙われたのが**帯電していないシガ**のとき。

1. 雷がシガに当たり、シガが帯電する（蓄電の印が1つ増える）
2. シガが**その場で鞭を振り返す**（割り込みの鞭と同じ構え・素早く）
3. 鞭が獣を打ち、獣が倒れて弾ける。薙ぎなので隣の敵にも鞭が入り、シガの身体の電気が敵へ移る（シガの帯電が消える）

見せたいこと: 臆病者のシガが、**雷に打たれた瞬間だけ怖さを忘れて打ち返す**（フレーバー「雷に打たれている間だけは、怖さも痺れて感じない」）。

### 分岐 C: 誰も受け止めない（`BeastThrow 投げた` ／ `糸`）

狙われた味方が帯電していない（シガ以外）、またはクグ（糸を伝って糸の先の敵へ流れる）のとき。

- 雷が味方に当たって、味方が帯電する（クグなら糸を光が走り、糸の先の敵が帯電する）
- 続けて獣は**投げた雷の残りで暴発する（4拍目へ）**——**第320期に確定**（`BeastBurst 投げて暴発`・`ActorId` ＝ ソム・この行で獣を盤から消す。並びは `design/PHASE291_CODEX_MEMO.md` §14-13）
- 「投げた後に立ち続ける」部品は**要らなくなった**（粛で止まったときも暴発する・下の段）。立った獣が次の手番まで盤に残ることは規定では起きない

### 粛で止まったとき（`BeastThrow 共鳴が止まった`）

分岐 A の1で光りかけて、**粛の札に押さえられて消える**。続けて獣は**投げた雷の残りで暴発する（4拍目へ）**——分岐 C と同じ結末（第320期に規定の実装で確かめた: `Sealed 粛` → `BeastThrow 共鳴が止まった` → `BeastBurst 投げて暴発`・`som320 check` (b)）。シガが粛 ／ 痺れで打ち返せなかったときも同じく暴発する。

## 3. 弾けた後（規定・第318期から）

獣が弾けたら「敵を倒した」に数える。台にいれば続けて:

- **ハギ**: 追い打ちで踏み込む（既存の追い打ちの演出のまま）
- **ツギ**: 弾けた獣の欠片を瓦礫として拾う（`Plank 瓦礫を拾った`・`TargetId` ＝ 弾けた獣）

## 4. 気をつけること

- 群れで2〜5体が同時に立つと、投げる → 分岐が体数ぶん続く。**群れは投げる拍をまとめて**（一斉に投げ、分岐 A ／ B ／ C をそれぞれ同時に）見せると短い（台本の並びは立った順に1体ずつ「投げる → 受け止め ／ 暴発」——1体目が消えてから2体目が投げる・§14-13）
- 毎ターン起きるので、分岐 A の共鳴と跳ね返りは一瞬で読めれば十分
- 「処刑」に見せない方針は STANCE と同じ（獣が自分の雷で弾ける ／ 返された雷で弾ける）

## 5. 試遊で見たいこと（ポンが画面で確かめる）

- 「裏切った下僕の雷が、帯電した仲間に当たって跳ね返り、下僕自身を吹き飛ばす」と読めるか
- シガの打ち返しが「臆病者が雷で目覚める」瞬間に見えるか
- 群れが立ったときに、画面が長すぎないか
