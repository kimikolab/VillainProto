### Q0-4. `sweep` の形

- **`BattleSim` のモード**（`BattleSim/Sweep.cs`・`static class SweepDiag`・`Program.cs` 側は振り分けの数行）。
  `CLAUDE.md` のコマンド表を自分で読む——表が増えれば追従する
- 抽出規則: 行頭が `    dotnet run --project BattleSim -c Release `（**連結で組む**・第123期）の行から
  ` #` 以降と ` > ` 以降を落とし、`<...>` を含む行は飛ばし（必須の穴）、`[...]` は落とし（任意の穴）、
  ` / ` は末尾トークンの変種として展開、先頭が `0` の行だけ、`sweep` 自身は除く、重複は1本に
- **CRLF の穴**: 行を `TrimEnd('\r')` してトークンに割り、`ProcessStartInfo.ArgumentList` に1つずつ渡す。
  文字列の連結も shell も通らないので `\r` が引数に紛れる経路が無い
- 上限は既定 90 秒（引数で変えられる）。**exit 124（上限）は失敗に数えない**が一覧に出し、
  **`KnownLong`（第140期の 10 本）を器具の中に持って「既知／新規」を分ける**。
  既知が上限に当たらなくなったらそれも出す（速くなった合図）
- **合格 = 異常終了（0 でも 124 でもない exit）が 0 本**。それ以外の非 0 は一覧にして報告する
- 標準出力は捨てる・ファイルは1つも書かない（`> docs/*.md` の向き先も落としてあるので `docs/` に触れない）
- 運用: **毎期は回さない（80 分前後）。`UnitCatalog.All` ／ `Retired` ／ `Presets` に触る期の受け入れ条件に入れる**
  （`CLAUDE.md` の (G8) の隣に (G17) として1行）
