## 4. 作ったもの

### 4-1. V3（`Dull` 窓口の分岐）

`Whet` 側（第62期）と `Dull` 側（第63期）の宛先の選び方を**共通のヘルパ
`BattleContext.FunnelThrough` 1本**に寄せた。**V1 と V3 で選び方が1ビットも違わない**ことを
コードの形で担保する（呼び出し側は `whet` フラグを渡すだけで、計数の宛先が変わる）。

- **候補プールは集約・渡しと共有**（第43期）。`Funnel.Both` が偽なら述語ごと元の形に畳まれる
- **非対称は1点**: 横流し役自身に来た弱体は横流し役自身が起点（§1-5）
- `AcceptsSupport` は**強化側と弱体側で同じく自前で濾す**（隣へ漏らさない）
- 計数: `FunnelDullTaken` / `FunnelDullByRoute[]`（**`DullRoutes` の長さ**）/ `FunnelDullDead` /
  `FunnelDullFrom` / `FunnelDullTo`。**どれも誰も読んで分岐しない**
- `FunnelRule(bool Slowest, bool Both)`。**既定は `Both = false`（V1）**

**`FunnelDullDead` は強化側と符号の意味が逆。** 押し付けた弱体が一度も振られなければ
盤面に1点も出ない＝**捨て場として成功している**量（死蔵(強)は失敗の量）。

## 11. 分かったこと（後の期が引くもの）

### 11-1. **器具を直すと、前の期の「割れた」が取り消されることがある**（第63期）

第62期は4行すべてで「席ごとの帰属の符号が割れる」と読んだが、**床の規則を足すと行2 が落ちる**
——負だった2席（後1 −2.3 / 後3 −2.7）は**素体が 22.4 / 22.9% の床**で、
そこの帰属は「差が無い」ではなく**「測っていない」**（第61期）。
**両 seed 帯で同じ判定。**

> **「前の期は割れていた」を根拠に器具を直すと、直した器具で落ちることがある。**
> 第62期が事後に器具を差し替えて採否を出さなかったのは正しく、
> **この期の結論はその判断が正しかったことの実証**でもある（差し替えていたら誤って採っていた）。

### 11-2. **`Attacks == 0` は「その駒に配った量が無駄になる」の指標にならない**（第63期・第56期の但し書きの実害）

罠行の宛先である**棘鎧のカドは一度も `PerformAttack` を通らない**が、
**棘の反撃量は `ThornsTrait.OnDamaged` が自分の `CurrentAttack` で決める**ので、弱体は満額効く。
実測で、宛先がカドの2席は V3 − V1 が **−1.5 / −2.2**、宛先が据えのバン（普通に振る駒）の2席は
**+1.3 / +1.9** と**符号が逆になる。**

> **「振らない駒は弱体の捨て場になる」は誤り。** 第56期が死蔵の表に付けた但し書き
> （「反応型の駒が出たら『死蔵』ではなく『振らずに干渉している』」）は、
> **強化側では読み違いで済むが、弱体側では符号を逆に読ませる。**
> `FunnelDullDead` の doc はこの実測に合わせて書き直した。

### 11-3. **弱体を横流しすると、弱体を資産に変える駒から燃料を取り上げる**（第63期）

逆しま（ウツ）は `AtkBonus` が負のとき攻撃力が下げ幅の3倍になるので、**弱体がこの駒の燃料**である。
横流し役をウツの隣に置くと、ウツに向いた弱体を**別の駒へ回してしまう**——
実測で `ウツの被弾弱体 14.0 → 0.0` になった2席だけが **−73.0 / −60.9pt**、
取り上げていない3席は **0.0 / +4.4 / 0.0**。

> **通貨を「移す」機構は、その通貨の読み手にとっては「奪う」機構である。**
> 第43期の渡し（弱体を敵へ流す）は**味方側の読み手と同席していなかった**のでこれが見えなかった。
> **新しく「移す」機構を作るときは、移す通貨の読み手が同席する行を試験行に必ず1本入れること。**

### 11-4. **床の規則はあるが天井の規則が無い**（第63期・器具の残る穴）

`測れる席 = 素体の5波平均が 40% 以上` は床を外すが、**天井は外さない。**
第63期に足した「弱体が厚い行」は素体が **93.0〜100.0%** で、
**採用席（100.0%）では帰属も V3−V1 も定義上 0 にしかならない**（第24期「天井・床のセルでは
誰に注入しても 0 に潰れる」）。実際 Q9(iii) はそこで測れなかった。

> **試験行を「ある量が最大の行」で選ぶときは、その行が天井にいないかを同時に見ること。**
> 次の器具は `40% ≤ 素体の5波平均 ≤ 95%` の両側で切るべきである（この期は変えていない
> ——**測る前に書いた判定式を測った後に変えない**）。

### 11-5. **「取り上げる相手が構造的に存在しない」ことは実装前に机上で出せる**（第63期・P4）

火選り行の V3 − V1 が ±0.0 になることは、**Phase 0-2 の宛先の地図だけで測る前に確定していた**
——採用席の宛先は熾のホタで、ヒヨが鈍らせる相手（ホタとムド）のうち
**ホタは宛先そのもの**（`dest == target` で何もしない）、**ムドはヌキの隣ではない**。
実測の押し付け量はきっかり **0.00 量/戦**。

> **在庫を数えるだけでは足りず、宛先とヌキの隣接を掛け合わせること。**

### 11-6. **第58期 Q6 の「多峰」は3行中1行しか機構の証拠になっていなかった**（§10）
