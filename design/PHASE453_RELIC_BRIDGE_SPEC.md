# 第453期 指示書 —— レリックを「繋ぎ」として働かせる（一覧・両端を結ぶ候補・つまんで持たせる）

前提: 第452期（`42a0c9c7`・観察ログ `649a232f`）。
ポン: 「今の編成のつなぎになるレリックが無かったので消去法で」「他にどのレリックがあるのか分からない」「**機能しない駒同士がつながる体験をしたい**」「装備方法が最初わからなかった」。
レリックの採用時の狙い（第270期・軸をまたぐ繋ぎ）がマップでまだ起きていない。この期はその 3 つを小さく。

## 0. 作るもの（すべて `DemoApp` と `Stage12` の値・札の中身は触らない）

### 0-1. 札の「両端」の表（`Relics` の隣・表示と候補の規則が読む・手で書く）

12 枚それぞれに **引き金のタグ**（何が起きると）と **効果のタグ**（何になる）を 1 つずつ。第450期のタグの語（燃焼・毒・感電・呪い・移動・標・生贄・破片・自傷・手番）で書く。
例（Claude Code が `RELIC_SUMMARY.md` の文から埋めて報告・ポンが直す）:

| 札 | 引き金 | 効果 |
|---|---|---|
| 火付けの矢 | 攻撃（タグ無し＝誰でも） | 燃焼 |
| 毒の足跡 | 移動 | 毒 |
| 帯電の足 | 移動 | 感電 |
| 押し毒 | 毒 | 移動 |
| 身を固める | 回復（ヒーラー） | 破片 |
| 勢い余り | 移動 | （火力・タグ無し） |
| … | | |

タグ無しの端は「誰でも」と書く。`docs/relics.md`（無ければ新設・あれば列を足す）に出す。

### 0-2. 候補の規則（`Stage12` の値で切れる）

中間拠点を取ったときの候補 3 枚のうち **1 枚目**を:
1. **両端が手持ちにある札**（引き金のタグの駒と効果のタグの駒が、盤上か手札にいる）から引く
2. 無ければ**片端がある札**
3. 無ければ今までどおり

残り 2 枚は今までどおり。**噛むかどうかは画面に出さない**（第449期の候補の 1 枚目と同じ作法）。

### 0-3. 一覧

- 手札の「レリック」の段と候補の窓に「**一覧**」ボタン。12 枚の名前・1 行の文・引き金 → 効果（タグの小札 2 つで）を並べる。まだ出ていない札も見える（「このマップで出た」に印）
- 候補の窓の札にも引き金 → 効果の小札 2 つ

### 0-4. 持たせ方

- 手札のレリックの札を**押すとつまむ**（駒の入れ替えと同じ作法）→ 駒の札（隊の 5 席・手札）を押すと持たせる。もう一度押すと外す
- 「持たせる」ボタンは残してよいが、説明の**上**に出す

### 0-5. やらないこと

- 札の追加・数値・持ち越し・「取りに行く理由」（第452期の宿題 4 は門と別の置き場が要るので 1-3 で）
