## 1. 決めたこと（指示書に書いていない判断）

1. **PB-a の量 8 ×（1 ＋ n）は、PB-a の版のすべての爆発に掛かる**——印だけ（濃さ 0）の敵は 8、濃さ n ≧ 1 の駒（味方を含む）は規定の 8 × n から 8 ×（1 ＋ n）へ上がる（指示書 §2「量は 8 ×（1 ＋ n）」をそのまま読んだ）。
2. **「敵の側」＝ トウの陣営でない駒**（背いた召喚獣 ／ 糸玉は敵の陣営にいるので入る）。印のある味方は濃さ 0 なら爆ぜない（規定のトウは `PowderMarkFoeOnly` で味方に印が付かないので、実際に起きるのは自己検査の盤だけ）。
3. **PB-b の印は、爆発がベニの結界で回復に反転した駒にも付ける**（粉は浴びた）。糸玉は爆発の飛ぶ先に入らないので対象外（指示書のとおり）。**印を付けるのは爆発1つの隣の `Damage` がすべて並び終えた後**（ループの中で付けても盤面は同じ——爆発のダメージは感電を弾けさせず放電を呼ばない。後にしたのは、Codex の `DustBurstPresentation` が「`粉塵爆発` → 隣の `Damage` の並び」を `ShockGauge` で切るため。§4-3）。
4. **PB-c の「2歩目」は、1歩目の生きている駒を橋にする**（空いた席は橋にしない）: 主目標の生きている隣（1歩目）のどれかの隣で、主目標とも1歩目とも違う生きている敵。経路は `Spread` のまま（`MarkShock` の `spreadFrom` は橋の駒・`LivingMembers` の順で最初の橋）。乱数は引かない。
5. **爆発の条件は `BattleContext.DustK` の1箇所に寄せた**（`Discharge` ／ `ThreadDischarge` ／ `SilkBallDischarge` の3口が呼ぶ）。規定（PB-a の札が無い）は濃さ n をそのまま返すので第328期と同じ。`DustExplode` に倍率 k の引数を足した（表示の `Slot` は濃さ n のまま・`Amount` ＝ 8 × k）。
6. **計数を3箇所に足した**（トウの手番の頭・`PowderPop`・連鎖の外側の1回の後）。規定の戦でも走るが盤面は読むだけ（`compare` 0 セル・`docs/balance.md` 差分 0 で確かめた）。
7. **Phase 0 の「主目標の隣の敵の数」は、舞う先に落ちた数 ÷ 主目標に落ちた数**（舞う先は主目標の生きている隣すべてに1回ずつ落ちる）。主目標がトウの一撃で倒れた手番は主目標の側に数えないので、わずかに大きめに出る。
8. **`settle328 check` の試遊の台の項目を、`Presets.Versions` の1行目（ポンの台）だけを見る形に緩めた**（後ろの行は「版・」で始まること・第327期の「版・DX」の台は無いこと）。期ごとに「版・」の台を入れ替える作法と、第328期の「1台だけ」の確かめがぶつかるため。見出しの文は第328期のままなので、`settle328 check` の出力（台本の指紋）は変わらない。
9. **`docs/` は再生成していない**（指示書 §8）。いま `dump` を回すと `units.md` の札の表に3行（`PowderBurstMarked` ／ `PowderBurstFall` ／ `PowderSpreadFar`・保持者 −）が足されるだけ（`rules.md` は差分 0）。次に `docs/` を作り直す期に入る。
