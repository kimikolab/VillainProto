## 0. 目的

### 段0

ポンの判断で **R4（CR-b ＋ SG）を規定にする**。感電 行 × ボス 15.5 → 99.0・近衛 68.5 → 89.0、近衛の格子でソムが初めてツギを超えた（1.17 倍）。

### 本体

代金が本編 第2波に残っている（感電 行 −26.5・ハギの台 −9.5）。原因は粛ではなく、**第2波は T3.5 で決着する短い戦で、味方がまだ帯電していないので、獣が跳ね返らずに立って壁になる**こと（R412）。ソムが倒れる割合が 4.5% → 28〜30% に上がる。

これを消す版を2つ並べる:

- **WS-a（序盤は立たない）**: Claude Code の案。T1〜2 は獣が立たない
- **WS-b（投げて暴発）**: ポンと合意した推し。**誰も受け止めなかった獣は、投げた後に自分で暴発する**。雷は帯電していない味方に付く（次の共鳴の燃料になる）。獣はその場で弾けるので、壁が立たない。絵は「振り返る → 投げる → 暴発」で、どの分岐でも4拍が完結する

あわせて、ソム対ツギの残り1波（**大隊**）の格子を回す。

## 3. 版（新しい規定 ＝ CR-b ＋ SG の上に札を足す）

### 3-1. WS-a（序盤は立たない）

- **戦の T1〜T2**（戦のターン数で数える）の喚び出しでは、獣は立たない。隣に帯電した敵がいなくても、E2 のまま席で弾ける（投げない）
- T3 以降はいまの規定のまま
- 「T2 まで」の境は Phase 0 で第2波の決着ターンと味方の帯電の立ち上がりを見て、**T2 で足りなければ T3 も並べる**（WS-a3）

### 3-2. WS-b（投げて暴発）

立った獣が投げた雷を、**誰も受け止めなかったとき**（共鳴返しにも打ち返しにもならなかったとき）:

1. 雷は今のまま処理する（帯電していない味方に感電が付く・クグなら糸を伝って糸の先の敵へ・粛で止まった共鳴返しは何もしない）
2. **その直後に、投げた獣が自分で暴発する**: その場で弾ける（E2 の「席で弾ける」と同じ・起こし手はソム・光になる・獣の死として数える）
3. 立った獣は、投げた手番の中で必ず盤から消える（壁は立たない）

- 同じ手番に複数立った場合は、投げた順に「投げる → 受け止め ／ 暴発」を1体ずつ
- 文面（叩き台・MinusText の末尾）:「受け止める者がいなければ、獣は投げた雷の残りで暴発する」

## 4. Phase 0（実装の前に調べ、報告書に書く）

新しい規定（CR-b ＋ SG）で:

1. **立った獣の行方**（代表台 × 波・1戦あたり）: 跳ね返り ／ 打ち返し ／ 誰も受け止めず立った ／ 粛で止まって立った。立った獣がその後どうなったか（味方の一撃で倒された ／ 弾けた ／ 戦の終わりまで残った）と、立っていたターン数
2. **第2波の時間の形**: 決着ターンの分布・T1 ／ T2 ／ T3 に雷が向かった味方が帯電していた割合・立った獣の数（ターンごと）。WS-a の境（T2 ／ T3）の見込み
3. **立った獣が無いと困る所はあるか**: 規定で、立った獣が後で味方の一撃で弾けて起きた連鎖（1戦あたりの数と大きさ）。WS-b ではそれが「投げた直後の暴発」に置き換わる——連鎖を失う台があるか
