# 第412期 報告 —— 【軽い期・版だけ】ムドの見直し①: 呪いの一撃で怒る（M-u）／ 殴り返しが敵を弱らせる（M-d）

指示書 `design/PHASE412_MUDO_LOOP_SPEC.md`。前期は `design/PHASE411_KARZ_SETTLE.md`（§6 にムドの下見）。**規定は動かさない**——版はどれも規定のムド（M1＋M2）の写しで、`Id` は同じ・`All` の外・保持者 0 枚。`compare` は 0 セル。

## 1. 決めたこと

- **M-u（`MudoStrikeRage`・札は印・判定は engine の `MudoStrike412`）**
  - 呪われた敵（`StatusKeys.Curse > 0`）に味方の単体の一撃が入るたび、ムドの怒り +1（`EruptTrait.StrikeRagePerHit`）。殴られた回数と同じ帳簿（`eruptRage`）に積み、閾 3 を越えたら M1 と同じ門（`TryFire`）でその場で暴発する。割り込み ／ 反撃の最中は暴発を持ち越す（M1 と同じ）。
  - **燃料の読み方で迷った所**:
    - 「入った」＝ HP が減った一撃（`amount > 0`）にした。回避 ／ 0 点は数えない。
    - 鎖の口（`HexShareHits`）と同じ場所に置いた（`ApplyDamage` の、HP を引いて死亡判定をした後）。条件は 単体（`singleHit`）・鎖で届いた分ではない（`!hexShare`）・陣営が違う・相手が呪われている。**`CurseRule.Enabled` には依らない**（鎖を止める版でも怒る）。
    - その一撃で相手が倒れても数える（鎖と同じく「入った」出来事への反応）。
    - ムド自身の一撃は数えない。保持者が2体いても、それぞれが自分以外の一撃で +1。
  - 名指ししない（ウツの発に限らない）。実測では燃料の 97〜100% がウツの発で、残りはワタ。
  - 文面: プラスの末尾に「。呪われた者が刻まれるたび、泥が揺れて怒りが溜まる（味方の一撃 1 につき 1）」。
- **M-d（`MudoMireDull`・`OnAfterAttack`）**
  - 暴発の1発（`eruptBurst` が立っている間）が敵に入るたび、その主目標の攻撃力 −1（`MudoMireDullTrait.PerSwing`）。窓口は `Dull`、経路は `DullRoute.Other`（カーズの印・UK-c と同じ）、書き手はムド、恒久＝その戦の間。
  - HP が減らなかった発（`dealt <= 0`）と、手番のふつうの攻撃では下げない。累計（`DullReceived353`）に乗るので、カーズの印は累計の深い順に付く。
  - 文面: 「。殴り返しの泥は相手の得物を鈍らせる（1発につき攻撃力 -1）」。
- **M-ud**: 両方（`UnitCatalog.MudoMud`）。
- 数値（+1 ／ −1）は掃引していない。`Smear`（塗り）には触っていない。「倒れると不発」も残した。乱数を引く処理は足していない（`ctx.PickOne` 0）。
- **試遊の台**: 「版・M-ud 呪い」（`Presets.MudoLoop412`・「試遊・カーズ 呪い」のムドを M-ud に）を `Presets.Versions` の末尾に足した。過去の器具の一覧の鎖の終端（`Common.VersionsH407`）では `VersionRows412` として外す。
- **作法の則**: R426（転生・規定の切替のとき、現役網の外の器具は固定せず封印する）が無かったので、`RULES_243_.md` ／ `RULES_INDEX.md` に足した。`CLAUDE.md` には (G17) の末尾に「変わった規則」の1文だけ足した。

## 5. 読み（§4 の順）

1. **M-u でムドは「倒れる前に暴発する」どころか「倒れない」駒になった。**
   - 強4 の暴発は 4.4 → 12.5 回。ムドが倒れる割合は 98%（T3.5）→ 3%（試遊・呪い）／ 64% → 0%（カーズ台）。
   - 理由: 暴発の1発ごとの回復（+2）と、敵が早く倒れること。怒りの半分強は一撃から（強4 で 21.3 ／ 38.3）。
   - ボスでも働く。勇者1体にウツの発が毎ターン入るので、一撃からの怒りが 22〜25 ／戦。ボスの倒しT は 9.0 → 6.0（試遊・呪い）／ 10.0 → 7.0（カーズ台）。
2. **尻尾の直 ／T が 125 を越えたのはボスだけ**（336 → 515 ／ 302 → 431）。
   - 雑魚の波では、ムドの暴発が尻尾の前に敵を減らす。尻尾そのものが 3.3T → 1.6T に短くなり、直 ／T は下がった（62 → 54〜61）。
   - 「軛の天井を越える口」の形はボスで見えた。強4 の詰まりは、天井の前に解けてしまった。
   - 試遊・呪いの強4 は 79 → 100、カーズ台の強4 は 100 のまま（倒しT 10.1 → 6.2）。
3. **M-d とカーズの印はよく噛む**（ボス 90%・強4 72%）。
   - ムドを殴った敵へ返すので、前に出てくる敵、つまりカーズが印を付けた累計の深い敵と重なる。精鋭（近衛 46% ／ 大隊 26%）は敵の数が多く、重なりが薄い。
   - M-d だけでも、試遊・呪いの強4 は +20。理由: 殴り返しで前の敵の手が鈍る → ムド・ネルが倒れにくい（ムドの倒れ 98% → 30%・ネル 81% → 15%）→ 暴発が増える（4.4 → 6.5）。
4. **寄せ集めで壊れる行は無い。**
   - M-u の落ちは最大で −4.0（速攻 (ボルグ×ムド) 近衛）。
   - M-d はムドの殴り返しの相手が弱るだけ。それでも、速攻 (ボルグ×ムド) の近衛は 13.5 → 47.0 と大きく上がった（前に出たムドを殴る精鋭の手が鈍る）。
   - 呪いの書き手のいない行でも、M-u は少し鳴る（敵側の呪いの書き手 ／ 開戦のネル）。
5. **新しく考えることが増えるか**
   - **M-u**: 「ムドの横にウツ」ではなく、「ウツが呪われた敵を殴るほどムドが暴れる」形の、手数の結びつきになる。ムドを前に出す理由が「殴られる」と「呪いの一撃」の2本になる。ワタ台とカーズ台で燃え方は似ている（燃料はどちらもウツの発 3〜4 ／T）。
