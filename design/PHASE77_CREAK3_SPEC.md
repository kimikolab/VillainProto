### 0-2. 問いは V9 の採否ではない

**本題は一般則のほう:**

> **条件を自分で作る駒と、外から供給される駒。ドラフト台ではどちらが強いか。**

- **V9**（第66期）= `AtkBonus` を読む。**軋み（自分の移動）で自分で満たせる**。
  理想台の帰属 +17.1 / +10.8 / +13.5 だが、**Q4（情報セル）で落ちた**——96.5〜99.2% だった第五波を

  号令の鬨が**開戦時に一括で 8.0 届く**ので閾値が2値に潰れた

**理想台では両方落ちている。ドラフト台では一度も測っていない。**
ドラフト台は**相方が保証されない**ので、**外部供給を前提とする V67 は構造的に不利**なはず。
**その差の大きさが、この期の主判定。**

## 2. 作るもの（診断だけ）

### 2-1. 供給元の選択子

```
CreakRule(int Threshold, CreakSource Source)
CreakSource = Whet（現行・第67期）| Bonus（第66期の V9）| Both（AtkBonus + WhetReceived の合計）
既定 = (0, Whet) ＝ 完全に不活性
```

`DisplacedTrait.ModifyPattern` が読む値を選択子で切り替えるだけ。**engine には何も足さない。**
**`Threshold <= 0` で素通りする現行の作法を保つ。**

**`Both` を入れる理由**: V9 と V67 の中間で、**「自足しているが外の供給も乗る」形**。
**3点あると「自足の効き」と「外部供給の効き」を分けられる**（V9 と Both の差が外部供給の上積み）。

## 7. 申し送り（**後の期で誤って引かないための固定**）

- **勝敗を決めているのは数値ではない**（第76期。数値を ±5% で揃えても勝率は 30.7pt 散る／
  72pt 違う2群の総攻の差は 0.09）。**上位/下位を分ける第1の量は「特性の総数」**

- **傷の機構そのものは +2.2 の正**（第74期）。**傷軸の改修は第75期で終了**
- **粒度を決めるのは値の時間分布**（第67期）。**開戦時一括は閾値を2値に潰す**
- **自分で作れる値を条件にすると、条件の粒度はその駒自身の上昇量が決める**（第66期。軋みは 9 / 22 の2段）
- **`docs/` は8ファイルすべて再生成する**（第74期）／**器具の分割は過去の対照も壊す**（第74期）

- **判定式の自己検査は7項目**（(a)／(a')／**(b) は「0 以外を取りうるか」まで**／(c)／(d)／(e)／(f)）
