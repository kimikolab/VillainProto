## 1. 目的

移動軸の中で**循環**を作る。ポンと話して分かったこと:

- 移り木の回復は動かされた駒の最大HPの割合なので、HP42 のセロは1回 8〜12 しか回復しない。満タンの駒では溢れて無駄になる → **溢れた回復に意味を持たせる**。シオは「攻撃を配るヒーラー」なので、溢れを攻撃力に変える
- ヨミは移動を受け取るだけで、ほかの駒へ何も返さない → **撃破をきっかけに移動を返す**
- **敵の移動は、敵が減るほど起きなくなる**（前衛を倒しても後ろに敵がいなければ押せない）。敵に依存する循環は序盤の加速向きで、終盤まで回る循環は味方側に作る必要がある
- 第229期 G4 で主判定が下がった原因: **追い風で一番前へ押し出されるのが後1 のシオ**（自分では殴らない）で、前に出た直後に倒れる → **踏み込むのは戦う者にする**

## 2. 追い風の踏み込み先（修正）

| | 今（第229期） | 新 |
|---|---|---|
| 踏み込む味方 | 同じ経路の味方のうち、**最も後ろの行にいる**味方1体 | 同じ経路の味方のうち、**最も前にいない味方の中で攻撃力が最も高い**1体（同値は後ろの行が先・次に席番号の順） |
| 入れ替わる相手 | その経路で1つ前の席の味方 | 同じ |
| 除外 | HP 4割未満は踏み込まない | 同じ |

- 「最も前にいない」＝その経路で自分より前の席に味方がいる駒（1つ前の席の味方と入れ替われる駒）
- 前へ出た側は「前へ突き出された」扱い（ヨミなら +22）

## 3. ヨミの撃破の衝撃

ヨミの攻撃（手番・割り込み・薙ぎ）で敵を倒したとき、倒した敵1体ごとに:

| 場合 | 効果 |
|---|---|
| **倒した敵と同じ経路で、その後ろに敵がいる** | その敵（すぐ後ろの1体）を**1つ後ろへ吹き飛ばす**（後ろの席と入れ替え。後ろに席が無ければ吹き飛ばさず転倒だけ）。吹き飛ばした敵は**転ぶ**。敵の移動として数える（バサ・ハネの段・追い風・前に出た敵の混乱が既存の規則どおり反応する） |
| **後ろに敵がいない**（または倒した敵が経路に属さない席） | **勢い余って、ヨミが隣の味方1体（乱数）と入れ替わる**。入れ替わった2体は「隊列を動かされた」扱い（ヨミ自身の +9 と割り込み・移り木・セロの段ほかが反応する） |

- 味方側の入れ替え（勢い余って）は **1ターンに2回まで**（撃破 → 入れ替え → 割り込みで撃破 → 入れ替え… の暴走を止める）。敵側の吹き飛ばしに上限は置かない
- ヨミの「自分では動かない」は、文面を「自分から動くことはない（勢いで転がされるだけ）」に寄せる（候補の文面は報告に）
- 序盤は敵側（吹き飛ばし → 追い風・段・転倒）、敵が減った終盤は味方側（入れ替え → 移り木・段・割り込み）に自然に切り替わることを狙う

## 4. シオの溢れを攻撃力に

| 項目 | 内容 |
|---|---|
| 条件 | シオの移り木・手当ての回復が、相手の減っている HP を超えたとき（溢れ） |
| 効果 | **溢れた量の半分（切り捨て）を、その駒の攻撃力に**足す（戦のあいだ残る） |
| 上限 | 1体につき1戦で **+15**（仮） |
| 対象外 | 移り木が自分を癒さないのは今のまま。手当てはシオ自身にも入るので、シオ自身の溢れも攻撃力になる（シオは殴らないので実質無い） |

- 「強弱」の欄に入る（他人の強化として既存の数え方のまま）
- HP の低いセロほど溢れやすいので、回復がそのまま火力になる
