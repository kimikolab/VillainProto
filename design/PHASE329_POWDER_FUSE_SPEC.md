この指示書は自己完結している。リポジトリ（`design/` の過去報告・`docs/`・コード）以外は参照しないこと。
前期の報告は `design/PHASE328_DUST_BATTERY_SETTLE.md`（粉塵爆発 ＋ 電池が規定）。作法は `design/MEASURE_LIGHT.md`（軽い期）。

## 0. 目的

ポンの試遊:

- ボス: 5.0T でも速すぎるとは感じなかった（このままでよい）
- **精鋭・大隊: トウの粉が1〜2体にしか付かず、爆竹感がなかった**

コードから読めること（Phase 0 で確かめる）:

- 爆発は「濃さ n ≧ 1 の受け手」でしか起きない（`DustExplode`）。濃さが上がるのは、**トウの手番の頭に帯電していた駒**に粉が落ちたときだけ（`PowderFell`）。初めて粉が付いた敵は帯電しても濃さ 0
- 精鋭は 3〜4T で決着し、敵はすぐ弾けて倒れるので、濃さが育つ前に戦が終わる。ボスは勇者が残り続けるので濃さが育つ

ポンと合意した方向: **粉が付いた駒は、濃さ 0 でも爆ぜる。爆発は隣に粉を降らせ、爆竹の束に火が回るように広がる**。トウ自身はほぼ火力がないまま、撒いた粉が導火線になる。

## 2. 版（規定の上に札を足す・4 つ）

| 版 | 中身 |
|---|---|
| **PB-a** | 粉が付いていれば爆ぜる |
| **PB-a ＋ b** | PB-a ＋ 爆ぜた粉が隣に降る |
| **PB-c** | 粉の舞う範囲を広げる（爆発の条件は今の規定のまま） |
| **PB-a ＋ b ＋ c** | 全部 |

### PB-a: 粉が付いていれば爆ぜる

- 爆発の条件を「濃さ n ≧ 1」から「**粉の印がある、または濃さ n ≧ 1**」に広げる
- 量は **8 ×（1 ＋ n）**（受け手の隣すべて・DR-a と同じ形）。それ以外（受け手自身に入れない・感電を弾けさせない・爆発が爆発を呼ばない・1本の放電につき1回）は今の規定のまま
- 粉の印は、いまの規定どおり敵の側（背いた召喚獣・糸玉を含む）にだけ付く。味方は濃さ ≧ 1 のときだけ爆ぜる（今のまま）
- **粉の印は倒れるまで残る**こと（弾けても消えない）。いまの挙動が違うなら Phase 0 に書き、この版では倒れるまで残す

### PB-b: 爆ぜた粉が隣に降る

- 爆発を浴びた**敵の側の駒**（生きている・糸玉は爆発の飛ぶ先に入らないので対象外）に**粉の印**を付ける。帯電はさせない・濃さは上げない
- 印が付いた駒は、次に放電が届けば PB-a で爆ぜる。弾ければ伝染（第324期）の出どころにもなる
- 同じ連鎖の中で、印が付いたばかりの駒が爆ぜてよいか: **よい**（爆発が爆発を呼ばない規則は変えない——印が付いても、同じ放電で二度目の爆発は起きない。次の放電が届いたときに爆ぜる）

### PB-c: 粉の舞う範囲を広げる

- トウの粉が主目標の隣に舞うとき、**さらにその隣の敵**（主目標から2歩・主目標と1歩目の駒を除く）にも舞う。帯電 ／ 濃さ ／ 印は1歩目と同じ規則（経路は `Spread` のままでよい・分けるなら任せる）
- 糸玉への粉（第327期）は1歩目の範囲のままでよい

- 文面（叩き台・トウの PlusText の粉塵爆発の句を差し替える）:
  - PB-a: 「粉の付いた駒に雷が届くと、粉が爆ぜて隣にも飛び火する（濃いほど激しい）」
  - PB-b: 「…飛び火した先にも粉が降りかかる」
  - PB-c: 「攻撃した相手とその周り2歩の敵に帯電の粉を付ける…」

## 3. Phase 0（短く・規定・ポンの台）

1. 近衛 ／ 大隊で、トウの1手番あたり粉が落ちた敵の数（主目標 ／ 舞う先）と、そのうち新しく帯電した数・すでに帯電していた数。**主目標の隣の敵が平均何体いるか**（ポンの「1〜2体にしか付かない」の裏付け）
2. 近衛 ／ 大隊で、弾けた敵の濃さの分布と、1戦の爆発の回数（いまの規定）
3. 粉の印は、弾けたあとも残るか（`_pwTouched` の扱い）

## 4. 予測（3〜5行・`.tmp/p329/predict.md`・本測定の前に）

下敷き（方向だけ）: PB-a で精鋭の爆発が 1戦 数回 → 10〜20 回。a ＋ b でさらに増え、決着T が 0.5T ほど縮む。PB-c は粉の付く敵が増えるだけで爆発はあまり増えない。ボスは a で 5.0T → 4.5T 前後（糸玉と召喚獣が濃さ 0 から爆ぜる）。
