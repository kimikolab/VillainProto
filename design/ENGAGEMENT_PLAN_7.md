## 0. 出発点

第6期で**代金の向きが作れる**ことが確定した。H2（低HP・高攻撃の雑兵）で `単体 − 範囲` が +8.7pt まで開き、向きの正体は「1手で何体落ちるか」だと分かった（攻撃16 固定で HP を 16→24→32 と厚くすると +8.7→+8.4→+5.8pt と単調に減る）。H1（長い戦闘）は効かないどころか**符号が反転**した（`単体 − 範囲` × ターン数 の相関 r = −0.97）。

### それでもまだ配分判断にはなっていない

2つ足りない。

**(1) 大きさが編成の地力と同程度でしかない。** +8.7pt は第5期で測った編成間の標準偏差（約 9pt）とほぼ同じ。3波列の合計代金 130% の中で 8pt 動くだけで、全波に効く編成の主効果（9.4pt）に対して優位に立っていない。**この作業では大きさの上積みは狙わない**（下記 (2) が先）。

**(2) 向きが片方向しかない。** いま作れたのは「範囲に安い波」だけ。列全体が範囲編成に有利へ一様に傾いただけなら、それは**難度が下がったのと同じ**で、送り先の判断は生まれない。

配分判断が立つのは、**同じ列の中で符号が反転するとき**だけ。

| 位置 | 狙う向き | 現状 |
|---|---|---|
| 第1波（安い） | **範囲に安い** | 確認済み（H2d で +7.4pt） |
| 第3波（高い） | **単体に安い** | 第5期は「3a が符号の出た唯一の候補」と書いたが**大きさを測っていない** |

第3波の反転が +2pt しか無ければ、勾配列は「範囲有利に一様に傾いた列」でしかない。**同じ物差しで測らないと、勾配列を採用してよいか判断できない。**

### さらにその先の罠

代金に向きが出ても、**突破数の序列が動くとは限らない**。第4期の逆順列がまさにそれで、指標は大きく動いたのに中身は「第五波の独立勝率の測り直し」だった。**代金の向き → 序列の入れ替え、の橋を渡ったことを別途確認する**。それが Phase S。

## 2. Phase R — 第3波の反転を測る

### 2-1. 鏡像の原理

第6期の結論（向き = 1手で何体落ちるか）から、反転の作り方が導ける。

- **体数を減らす**（範囲が撒く先が無い）
- **個体HPを範囲攻撃の一撃圏の外に置く**（撒いても撃破に変換できない）
- **1体あたりの攻撃を上げる**（単体火力で1体落とすと減る量が大きい）

素材は揃っている。`Champion`（聖騎士長 130/22/9・処刑）と `Warden`（城塞の重装兵 145/12/3）は既にこの形。H1（人足 45/6）が `単体 − 範囲` −2.4pt だったのも同じ向きなので、**少数高HPの波は自然に長くなる分だけ反転が上乗せされる**はず。

**打点の実測に注意。** 第6期で `docs/pulse.md` から出た味方の実測打点は中央値 10.6 / IQR 4.4〜20.4 / p90 51.1。既存コメントの「14〜20」は成り立たない。**一撃圏の外に置く**とは p90（51.1）より十分上、という意味で読むこと。130〜145 は明確に外だが、**中間の刻み（60〜90 あたり）を測ると閾値が見える**——第6期で HP 16/24/32 の3点を取ったのが有効だったのと同じ理由。

### 2-2. 候補

第3波の位置に、既存の 3a/3b/3c（第5期）を**対照として残し**、鏡像の原理で組んだ候補を数点足す。

軸は **体数 × 個体HP**。少なくとも4点:

- 3体・高HP（3a に相当）
- 2体・高HP（3c に相当）
- 3〜4体・中HP（60〜90 あたり。**新 def が要るはず**）
- 中間点1つ

制約（第5期・第6期と同じ）:

- 1波あたり最大6体（前3・中1・後2）
- 貫きは1波に1枚まで / 全体攻撃は1波に1枚まで
- `AttackPattern` を追加しない
- **新候補に範囲持ちの敵を入れない**（測定の交絡を避ける。第6期と同じ規則）
- 新 `UnitDef` は新 Id で追加してよい。既存 def は触らない。**なぜその数値かをコメントで残す**（特に「一撃圏の外」をどの打点分位で判断したか）

### 2-3. 測ること

`aim` の物差しをそのまま使う。**符号を逆に読むだけ**なので、指標の定義は変えない（第6期の値と直接比べられるようにするため）。

| 候補 | 体数 | 総HP | 総攻/T | 代金平均 | 代金SD | **単体 − 範囲** | 平均ターン数 | 勝率0%の編成数 |
|---|--:|--:|--:|--:|--:|--:|--:|--:|

**成功条件: `単体 − 範囲` が −8pt 以下**（＝範囲のほうが 8pt 以上高くつく）。第1波の +8.7pt と対称の大きさ。

帯は **代金平均 50〜70%**（第5期 §3-1 の第3波の狙い）。**帯と反転が両立しない場合は反転を優先し、その旨を報告する**（第6期と同じ判断。帯は体数で後から戻せるが、向きは戻せない）。

### 2-4. 追加で見たいこと

- **範囲持ちの枚数**（0枚 / 1枚 / 2枚以上）で代金が**単調に上がる**か。第6期は下がる方向で単調性を確認したので、同じ表を逆向きで
- **`Champion` の処刑**が反転に効いているか。処刑持ちを外した対照を1点入れる（処刑は「HPが減った敵を優先して仕留める」性質なので、少数高HPの波の性格に影響しうる）

### 2-5. 受け入れ条件

- `compare` / `chain` / `pulse` / `ablate` / `dump` / `engage` / `seats` / `handoff` / `cost` / `gradient` / `aim` の差分 **ゼロ**
- `EnemyCatalog.Stages` / `Columns` が不変
- 対照（3a/3b/3c）の代金が第5期の `gradient` と一致（61.0% / 52.5% / 44.3%）。**一致しないまま先へ進まない**
- 候補の全数値が報告かコメントで読めること

### 2-6. 反転が取れなかった場合

**Phase S を実行せず、Phase T へ進む。** 「攻撃パターンによる向きは片方向しか作れない」と結論として記録する。これは失敗ではなく、自傷軸へ移る根拠が確定するということ。**取れなかった理由の説明を1つ**（推測は推測と明記）。

## 3. Phase S — 向きは序列を動かすか（条件付き）

**Phase R で反転（−8pt 以下）が取れたときだけ実行する。**

### 3-1. 何を確かめるか

代金に向きが出ても、突破数の序列が動くとは限らない。**第4期の逆順列がまさにそれ**で、指標は大きく動いたのに実体は「第五波の独立勝率の測り直し」だった。同じ轍を踏まないために、**列として組んだときに編成の順位が実際に入れ替わるか**を測る。

### 3-2. 測り方

3波列を2本組み、`engage` と同じ物差し（期待突破数・突破率、1部隊・2部隊）で全編成を測る。

| 列 | 第1波 | 第2波 | 第3波 | 性格 |
|---|---|---|---|---|
| **平坦列** | 農兵（1b） | 2b | 3a | 向きがほぼ無い（第5期の推奨列） |
| **反転列** | H2 系（+8pt 級） | 2b | Phase R の反転候補（−8pt 級） | 列の中で符号が反転する |

第2波は**両列で同じもの**にする（交絡を減らす。2b 固定）。

出すもの:

1. 各列での編成の**期待突破数**と順位
2. **2列間の順位相関**（スピアマン。実装が面倒なら順位差の絶対値の平均でもよい。**使った指標を明記する**）
3. **順位が最も動いた編成 上位5つ**と、その動いた方向。**範囲持ちの編成が反転列で上がっているか**（狙いどおりの向きに動いたか）

### 3-3. 判定

| 観測 | 結論 |
|---|---|
| 順位相関が低く（目安 0.7 未満）、範囲持ちが反転列で上がっている | **橋が架かった。** 向きは序列に届いている。勾配列の採用を検討してよい段階 |
| 順位相関が高いまま（0.9 以上） | **代金には出たが結果には出ていない。** 第4期の逆順列と同じ形。8pt では足りないか、突破数という指標が向きを吸収している |
| 相関は低いが、動いた編成が範囲/単体と無関係 | 向きではなく別の要因（地力・自傷の固定費など）が動いている。**何が動かしたかを報告する** |

### 3-4. 受け入れ条件

- `compare` ほか差分 **ゼロ**。`Columns` / `Stages` 不変
- 平坦列の値が、第5期の推奨列（1b/2b/3a）の値と一致すること（**検算**。第5期は期待突破数(1) = 2.05・突破率(1) = 6.4%）
- 順位相関の計算方法を明記

## 4. Phase T — 記録と報告

### 4.1 README に書くこと

- **第3波の反転が取れたか。** 数字と、取れた（取れなかった）理由
- **Phase S を走らせた場合はその結果。** 特に「代金の向き → 序列の入れ替え」の橋が架かったかどうか。**架からなかった場合こそ重要な記録**（第4期の逆順列と同じ形が再現したことになる）
- 一撃圏の閾値（第3波側の HP はどこから範囲が効かなくなるか）。**第6期の 16〜24 と対になる基礎データ**なので、数値ごと残す

「未解決の課題」— **既存の3件（自傷軸の強化 / キャラのスキル・攻撃パターンの相談 / 第二波の司祭ダミー）はそのまま残す。** 加えて:

- 向きの**大きさ**が編成の地力と同程度でしかない件（+8.7pt vs SD 9pt）。上積みを試すかどうかは未定

### 4.2 報告してほしいこと

1. **反転は取れたか。** 候補ごとの `単体 − 範囲` を、第1波の H2 系（+8.7 / +8.4 / +7.4pt）と並べて
2. **一撃圏の閾値はどこか。** 体数と個体HPのどちらがより効いたか
3. **処刑の有無で反転が変わったか**（§2-4）
4. **（Phase S を走らせた場合）順位相関と、動いた編成 上位5つ。** §3-3 のどの行に当たったか
5. **反転が取れなかった / 橋が架からなかった場合**: 説明として最も確からしいものを1つ。**推測は推測と明記する**

## 5. 作業ルール

1. Phase R → S（条件付き）→ T の順。**フェーズを跨いで1コミットにしない**（T は文書のみ）
2. コミットメッセージに「動いた docs/ の行」を書く。動いていないなら「compare 差分ゼロ」と明記
3. コード・コメント・ログは日本語。既存の文体（**却下した案とその理由も書く**）に揃える
4. CONTRIBUTING.md のチェックリストを通す
5. 長時間ジョブは前景で待ち切る。`layout` は走らせない
6. **採用を決めない。** `Columns` への追加も `Stages` の変更もしない
7. 以下を見つけたら**実装前に止まって報告する**:
   - 対照（3a/3b/3c）の値が第5期と一致しなかった場合
   - 一撃圏の外に置こうとした結果、勝率が 0% になる編成が半数を超えた場合（**それは「高い波」ではなく「勝てない波」なので、役割の設計から見直す必要がある**）
   - Phase S の平坦列の値が第5期の推奨列と一致しなかった場合
