**肩代わりされた駒（HP が1点も減っていない）には積まれない**（指示書 Q0-4 の決定どおり）。

> **ここで指示書に無い答えが1つ出た。**
> **ガルド（`Stoic`）には預かりが積まれるが、1点も返らない。**
> 積むのはカウンタの直接の書き込みだが、返すのは `ctx.Heal` で、あの窓口は
> `AcceptsSupport` が偽なら入口で弾く。**ロスターで最も殴られる駒が、預けた分を全部
> 没収か残額にしかできない**——これは欠陥ではなく、条件4（符号が編成で反転するか）の
> いちばん濃い標本なので、**台4 として独立に立てた。**

### Q0-5. `Forfeit` の宛先

`ctx.Heal` を通す（指示書の要件）。`by` には**ノチ自身**を渡す。
`Heal` の帰属は `Mark.Owner`（いま実行中の特性の持ち主）で決まり、
`OnAllyDeath` は `BeginTrait(t.Id, ally)` の印の中で呼ばれるので、
**没収で敵に入った回復はノチの `HealOutOffTurn` に載る**。これは正しい——ノチの代金だからである。

## 2. 予測（**実装前に書き切った**。外れても消さない）

**Phase 0 の答えが出てから、`UnitCatalog` と台の編成表を開いて数えて書いた。**

1. **`Burst` は `Drip` より時間を買う。** 返る量が同じでも、返るタイミングが被弾の山に同期するから。
   線は「4台中3台以上で `Burst` の味方生存T が `Drip` を上回る」。
2. **第三波（渇き）でこの駒は負ける。** 積むだけ積んで1点も返らない。
   線は「第三波の帰属が、その台の4波の中で最小か負」。**4台中3台以上**で成り立つ。
   （第118期の回復系3台が −58.0 / −20.0 / −10.5 だったのと同じ向き。）
3. **タンクと同席すると `Burst` の閾値到達が早い。**
   台1 のゴルム（巨躯・自分より後ろの列への攻撃を型を問わず肩代わり）は
   **5枚中1枚に被弾を集める**ので、台2（肩代わり 0 枚・被弾が5枚に散る）より
   **閾値到達回数／戦が多い**。線は「台1 の到達回数 ≥ 台2 の 1.3 倍」。
4. **`Forfeit` は台3（リィカ）でいちばん大きく出る。**
   リィカは `Sacrifice`（開戦時に隣接する味方を削る）＋ `Necro`（味方が倒れるたび育つ）で、
   **味方が倒れることが仕事**。没収量／戦は 台3 > 台1・台2。
   **符号は台1（タンク）で正・台3（死軸）で負**——これが条件4（この期の本丸）。
5. **台5（ノチ非在席）は5波すべて ±0.0。** `Burst` / `Drip` / `Threshold` を何に振っても動かない。
6. **`Percent` を上げても比は動かない**（第118期 §1-2 の再現）。掃引するのは `Threshold`。
7. **台4（ガルド）では返った量が 0 に近い。** `Stoic` が `ctx.Heal` を入口で弾くので、
   ガルドに積んだ預かりは**没収か残額にしかならない**。
   線は「台4 の `返した量 ÷ 積んだ量` が、台1〜3 の半分以下」。

### 5-2. `Threshold` は「届くか届かないか」の崖である

`Burst` は閾値を上げると**ある点で突然 0 になる**（返却率 0.0%）。
台2 は `Threshold 60` で 25.5%、`90` で **0.0%**（そこから先は 130 まで1ビットも動かない）。
台3 は `60` で、台4 も `60` で 0.0%。**その点より上では預かりは「敵への回復装置」でしかない**
（台3 `Threshold 60` の帰属は **−30.0**）。

**二値の鍵の閾値は、格子の到達率を見てから置く**（第128期）が、ここでも同じ形で出た
——閾値が供給の届かない側にあると、**その版は死に札ではなく「代金だけの札」になる。**

| 台4 | −2.3 | +5.0 | +24.1 | +26.1 |

**積んだ量は `Percent` に比例する**（台1 で 107 → 509）が、**返却率も一緒に上がる**（29.9% → 71.2%）
——`Percent` を下げると**閾値に届かなくなる**ので、`Percent 25` は3台で返却率 0.0% ＝ 純粋な代金になる。

**第118期 §1-2 の「代金は係数で薄まらない」はここへ持ち越せなかった。**
あちらは**供給が自分の生存に比例する**（回復を厚くする → 生きる → 殴られる → 供給が増える）ので比が動かなかったが、
**預かりの供給は被弾であって、ノブを動かしても被弾は増えない。**
`Percent` と `Threshold` は独立なノブではなく、**効いているのは「供給 ÷ 閾値」1つ**である。

## 8. この期に出た知見

### 8-1. 「時間を買ったか」を生の生存Tで測ると、決着Tの短縮に食われる

条件1（味方生存T +1.0T）は4台中1台しか通らない。ところが
**`生存T ÷ 決着T` で見ると4台すべてで +0.080〜+0.276 動いている**——
台4 に至っては**生の生存Tが −0.42T なのに比は +0.253**である。

理由は分母にある。**生存者の `LastActiveTurn` は決着Tそのもの**なので、
機構が決着を縮めると（台1 10.08 → 8.86T・台4 13.77 → 9.36T）
**生存Tは上がりようがない。** 買った時間が「早く勝つ」に化けている。

**第137期の則「`LastActiveTurn` を版どうしで比べるときは決着T で割る」が、
そのまま採否の条件に当たった。** 規約 (G12)（割合を版をまたいで比べるときは分母の変化を先に出す）の
**時間側の版**で、**分母が版で動く量を採否の線にしてはいけない。**

### 8-2. 「返らない預かり」がいちばん重い代金になる —— 支援拒否のタンクが最悪の預け先

没収の代金は**死軸台（−4.0）ではなく支援拒否台（−9.0）で最大**だった。
しかも**没収された量そのものは台4 が最小**（34.73 対 52.60）である。
効いているのは量ではなく**束の大きさ**——台4 は返却率が 17.4% しか無いので
預かりが大きな塊のまま溜まり、保持者が倒れた瞬間に**生存している敵全員へ満額**入る
（敵の回復 **27.64/戦**・台1 の 2.2 倍）。

> **`ctx.Heal` を通す資源を「積むだけ積んで返せない駒」に預けると、
> 積んだ量ではなく<u>返せなかった比率</u>が代金の大きさを決める。**

第43期「隣に置きたい駒は『弱体を受ける駒』」の回復側の版だが、
こちらは**受け取れない駒**が効く（第115期の `Stoic` と同じ位置）。

### 8-3. 積む窓口と返す窓口が違うと、盤面ルールが片側だけに効く

預かりは**積むときは `ctx.Heal` を通らず、返すときだけ通る**。
渇き（第三波）の下では空振りが 4.80〜15.55 回/戦 出て、そのぶんプールが膨らむ
——**祭司を割ると一気に戻る**ので、第三波の取り分だけが他の波の 1/5〜1/10 に落ちる（予測2）。
**engine には1行も足していない。** 窓口を片側だけ通す設計が、そのまま波との相互作用になった。

**逆に、`Stoic`（ガルド）では窓口が永久に閉じたまま**なので、
同じ構造が「積まれ続けて一度も返らない」という別の顔を見せる（8-2）。
**「窓口を通す／通さない」を積む側と返す側で分けると、
盤面ルールと支援拒否という<u>別々の機構</u>が同じ札の上で同じ形に見える。**

### 8-4. 「代金は係数で薄まらない」は、供給が自分の生存に比例する機構の話である

第118期 §1-2 を持ち越そうとして外した（予測6）。
あちらの供給は「殴られる回数」で、**回復を厚くすると生存が伸びて供給が増える**ので比が動かなかった。
**預かりの供給も被弾だが、ノブ（`Percent`）は被弾の量を1ビットも動かさない**ので素直に効く。

> **他の期の「係数では動かない」を持ち込む前に、
> その機構の供給がノブに対して内生か外生かを見ること。**

### 8-5. 閾値は届くか届かないかの崖で、届かない側では「代金だけの札」になる

`Threshold` を上げると返却率がある点で **0.0%** に落ち、そこから先は何を入れても値が動かない
（台2 は 90 と 130 が1ビットも違わない）。その版の帰属は **−30.0**——
**プラスが 0 になるだけでなく、マイナス（没収）が満額残る。**
第128期「二値の鍵の閾値は、格子の到達率を見てから置く」の**代金つきの版**で、
**死に札ではなく「代金だけの札」になるぶん、こちらのほうが危ない。**

## 10. この期で決めなかったこと・次期への申し送り

- **キリを外す（§5-1）は実行していない。** 採用が決まってからの手順なので、
  **傷軸を畳む方針そのものは生きている**が、その差し替え先は預かりではない。
- **代金を作り直すなら、「編成によって符号が反転する」形を先に決めてから札を書くこと。**
  いまの没収は**どの編成でも定数の損**で、`Forfeit` を外した版（`V1p`）が
  4台すべてで本物より強い。候補は2つ:
  (i) 没収の宛先を「倒した敵1体」にする（撃破の読み手が資産に変わる）、
  (ii) 返すときにノチ自身の HP を払う（代金を保持者の生存に結ぶ＝供給を内生にする）。
- **`Threshold` と `Percent` は独立なノブではない**（5-3）。次に触るなら
  **「供給 ÷ 閾値」1本のノブ**にするか、`Percent` を固定して `Threshold` だけを振ること。
- **`生存T ÷ 決着T` を採否の物差しに昇格させるかは決めていない**（8-1）。
  第137期の則は「版どうしを比べるとき」までしか言っていないが、
  **採否の線に生の生存Tを使った期は第118期・第126期・第135期と3つある。**
