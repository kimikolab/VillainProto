## 0. 目的

ポンの観察: **敵への毒と雷はダメージやトリガーになるが、燃焼はほとんど機能していない。状態異常ダメージのちょっとしたかさ増しになっている。**

原因は、燃焼を読む駒がすべて**味方側の燃焼**を読んでいること（ホタ・ヒヨ・ベニの反転・ツギの板）。**敵の燃焼を読む駒は0体**で、敵に付いた燃焼には「その先」が無い。

そこで燃焼という状態に**燃焼にしかない役割**を1つ足す:

> **燃えている駒は、受けるダメージが増える（焼けて脆くなる）。状態異常ダメージも含む。**

- 毒＝深く削る／感電＝連鎖と痺れ／燃焼＝**ほかの全部を伸ばす掛け算役**
- ベニの O4（開戦で敵全体に毒1＋燃焼1）と直結し、開戦から敵全体が脆い状態で始まる

## 1. 前段: ミオを M5 に規定化（ポンの判断）

- `UnitCatalog.Mio.Traits` を第218期の M5 の札構成に（叩きつけ・通電・澱みのデバフ〈敵だけ〉・放電で印を運ぶ・倒れたら印が移る）
- `units.md` のミオを、第218期の報告「候補の文面」を元に次の芯で書く:
  - 手番: 毒を帯びた敵全体を濃くし、最も濁った敵とその周りに印を重ね、澱みを叩きつける（感電していれば、澱みを伝って印の敵すべてへ雷が走る）
  - プラス: 印の敵は刻みが増え、与えるダメージが軽くなる。**印は消えずに流れる**（弾ければ放電に乗って隣へ、倒れれば隣へ移る）
  - マイナス: 印を重ねるたび、隣の味方にも印が重なる
  - フレーバー: 「濁った水ほど、雷をよく通す。」（今のフレーバーと差し替えるかはポンが決める。報告に両方を並べる）

- この規定化で動く行を `compare` の差分として報告する（燃焼の測定の基準はこの規定化の後の盤面）

## 2. 燃焼の脆さ（新しい規則）

| 項目 | 決め |
|---|---|
| 条件 | 燃焼が付いている間（残りターン 1 以上） |
| 効果 | **受けるダメージ** × (100 + X) / 100（切り上げ） |
| 対象のダメージ | 通常攻撃・薙ぎ／貫き／全体・雷・叩きつけ・放電・反撃・反射・**毒の刻み・燃焼の刻み**——受けるダメージすべて |
| 掛ける位置 | 攻め手側の増減（萎縮・鈍・澱みのデバフ・呪いほか）の**後**、受け手側の軽減（破片・軛・身構え・庇いの肩代わり）の**前**＝一撃の重さそのものが上がる |
| 刻みの回数 | ミオの印で刻みが 1+n 回なら、1回ごとに掛ける |

- 燃焼の中身（6ダメージ・3ターン・再付与で3に戻る）は変えない
- 版の切り替えは既存の作法（札か規則の器）から Claude Code が選ぶ。`Run` の引数は増やさない

### 味方側に掛ける版の扱い

- 味方も燃えている間は脆くなる
- **ベニの反転は、伸びた量をそのまま回復に反転する**（結界の中では、燃焼が回復を増やす）
- ホタ（燃えて強くなる）は、燃えている間は脆くもなる
- ツギの板（燃焼で倍）とは掛け算になる

## 4. Phase 0

- **Q0-1 掛ける場所**: 被ダメが通る口を洗い出し、§2 の「掛ける位置」を1箇所で満たせるか。通らない口（`ApplyDamage` を経由しない量）があれば一覧にする

- **Q0-5 過去の測定**: `design/` を grep（被ダメ増加・脆さ・燃焼の性質を変えた実験）
- **Q0-6 台**: §6 の台の席を決め、駒を数えて予測を書く

## 5. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** F0 はミオ M5 規定化後の盤面と台本が一致
- **P2** 燃焼の書き手がいない行は、F1〜F4 で 0 セル（燃焼が1度も付かない戦は変わらない）
- **P3** F1・F2 で最も上がるのは、敵に燃焼を書く駒（ベニ・ボルグ）と、刻みを積む駒（ミオ・グザ）が同居する行

- **P5** 第二波の1ターン目の初撃は、F1・F2 では変わらない（敵の初撃は味方が受けるもので、敵の脆さとは無関係）
