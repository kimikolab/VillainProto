# 第235期 指示書 —— ボルグを前に出す理由を揃える（燃える巻き込み・くすぶり・火の癒し）

置き場所: `design/PHASE235_BORG_FRONT_SPEC.md`。報告は `design/PHASE235_BORG_FRONT.md`。
**線は置かない**（採否はポンが遊んで決める）。

## 1. 目的

燃焼の軸のコンセプトは **「耐えて、燃え上がり、焼き尽くす」**。ボルグは「耐える」＝前で殴られて火を返す盾（ブロッカー兼アタッカー・薙ぎは残す）。

第234期で分かったこと:

- 火の鎧（殴られると殴った敵と自分に火・燃えている間は被ダメ半分・火に焼かれない）自体は働く。燃える敵 0.6 → 1.6〜2.7 体/T、ヒヨの +4 がボルグに乗る、本編の勝率 45.1 → 64.1%
- **ただし総当たりは一度もボルグを前に置かなかった**。理由は2つ:
  1. **自分の巻き込みが隣を焼く**——ボルグを前に出すと死の8割がボルグの巻き込み
  2. **1ターン目は燃えていない**——燃える前の集中を素で受けて落ちる。HP100 で上位が 39/40 に並ぶ
- 焼け残り（HP1 で踏みとどまる・火が消える）はほぼ延命にならない（R339）

→ この期は、**ボルグが前にいることが隊の最良になる**ように、2つの穴と「瀕死から戻れない」を1本ずつ埋める。

## 3. 足す札（1本ずつ）

| 札 | 名前（仮） | 内容 | 当たる穴 |
|---|---|---|---|
| **S** | 燃える巻き込み | ボルグの巻き込み（主目標に与えた量の半分・隣の味方全員）を、**燃焼ダメージとして与える**。量は同じ | 隣を焼く |
| **O** | くすぶり | **開戦時に自分に火が点く**（残り 3・通常の着火と同じ） | 1ターン目の集中 |
| **H1** | 火の癒し | 「火に焼かれない」を置き換え、**燃焼の刻みがボルグには回復になる**（刻みの量と同じ） | 瀕死から戻れない（受け身） |
| **H2** | 焼き返し | **殴る前から燃えていた敵**を主目標として殴ると、**与えた量の半分を回復し、自分に火が点く** | 瀕死から戻れない（能動） |

細部:

- **S**: 燃焼ダメージとして扱う＝①熾火（ホタ）は受けない（火に焼かれない）②ベニの結界の中では回復に反転する ③脆さは敵だけなので味方には掛からない ④「ダメージを受けたら」で動く札（被弾強化・肩代わりほか）には今まで通り反応する（受けた量が 0 なら反応しない、は既存の規則どおり）。**着火（`Cinder`）は今まで通り別に起きる**
- **O**: 開戦時の順序（速さ順の `OnBattleStart`）の中で点く。ヒヨの贔屓の第1手番に間に合うかを報告
- **H1**: 回復は「火の回復」として扱い、**ベニの「回復を受けるとかえって傷つく」は対象外**（ベニの反転と同じ向きなので、ベニの隣で二重にも逆にもならない）。**渇き（第三波）に封じられるか**は版を分けて第三波だけで測る（H1a 封じられない／H1b 封じられる）。主の版は H1a
- **H2**: 「燃えていた」は**ボルグの火の粉が主目標に点く前**の状態で判定する（後で判定すると常に満たす）。薙ぎで巻き込んだ敵は数えない（攻撃1回につき特性は1度）。回復の扱いは H1 と同じ。自分への着火は通常の着火（点け直しは残り 3 に戻す）
- H1 と H2 の回復は、HP 上限を超えない

## 5. Phase 0

- **Q0-1 燃焼ダメージの経路**: engine に「単発の一撃を燃焼ダメージとして与える」経路があるか。無ければ最小の足し方（刻みと同じ扱いで、ベニの反転 `InverseHeal` と熾火の免除が通るように）。脆さ・巨躯・分かち・破片・身構え・軛との順序を報告
- **Q0-2 熾火の免除とベニの反転**: 今のホタは刻みそのものを飛ばしているので、**ベニの結界の中でホタに反転の回復が届いているか**を確認（届いていなくても直さない。事実だけ報告）
