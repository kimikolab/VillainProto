## 0. 前提の訂正

指示書とリポジトリが食い違っていた点を先に書く。**どれも作業は止めていない。**

### 訂正1: 席番号のタイブレークの偏りは既に潰されている（§6-1）

指示書は「エンジンにスロット番号順のタイブレークが2箇所あり、**後退先が常に 後1 に寄る**。
引きずり出しはこの偏りを初めて表に出す可能性がある」と書いているが、これは
**2026-08-30 に修正済み**（README「席番号のタイブレークを乱数化した」）。

`FindBackSlotFor` は `occupied[Roll(occupied.Count)]` で候補から乱数で選び、ターン順も
`.ThenBy(u => u.Slot)` を捨てて同速・同陣営の中を毎ターンシャッフルしている。指示書が
引いている「鏡像ペア253組」の表は**修正前**の値で、修正後は 平均 1.32 → 0.67 /
最大 24.1 → 8.0pt まで落ちている。

したがって §6-1 の切り分け（「出された駒の分布が 後1 側に偏っていたらバグの可視化」）は
**そのままでは成立しない**。曝きは `SwapSlots` を直接呼ぶので `FindBackSlotFor` を通らず、
`SwapSlots` の中の `PickOne` も乱数窓口。**代わりに「後1 と 後3 の被引き出し回数が
偏っていないか」を `expose` の出力で見る**——偏りが出たら、それは席バイアスではなく
「編成が後1 と後3 に置いている駒のHPが非対称」という編成側の事実になる。

未解決として残っている非対称（ゴルム＋セロ同居の鏡像差 -10.3pt）はスロット順ではなく
原因未特定のもので、こちらは今も残っている。

### 訂正2: 傷軸は「6行すべてが巨躯を土台に持つ」ではなく 6行中5行（§4-3）

傷軸6行のうち `裂き×責め苦 (キリ×エグ×シガ)` は **ゴルムを含まない**
（シガ／キリ／ヴェル／リィカ／エグ）。土台が死の連鎖（リィカ×ヴェル）側なので巨躯がいない。
残る5行（裂き・刻み・刻み×抉り・刻み×断ち・刻み×縫い）はすべてゴルムを持つ。

### 訂正3: 第五波の現況値が指示書の数字と違う（§5-3 / §5-7 / §5-8）

指示書は「第五波の平均は 53.6 / 中間帯 22 / SD 40.1」と書くが、現在の `docs/balance.md`
（44編成）から引くと **平均 53.8 / 中間帯（開区間 (0,100)）30 / SD 39.2**。
指示書の数字は 42編成世代（第36期 `spread` の表）のもの。

**一致した数字**: 第3波×第5波 の相関 **+0.58**、第五波の固有の勝者 **0** / 敗者 **5**
（厳密版 =100/=0・第一波を比較から外す定義）。歯止め（40.0% 下限）は 53.8 を基準に読む。

## 2. 予測（実装前に書いた）

### 2-1. 窓口を通る駒の在庫

曝きの窓口は「**味方（＝保持者から見た敵陣）の後列の生存駒**」と
「**味方の前列の生存駒**」の2つ。

**44行すべてが後1・後3 に2枚ずつ置いている**（`Formation.Build` の5引数を全行が埋めている）。
**後列0枚の行は 0行**なので、「初期状態で空振り確定 ＝ ±0.0 になる行」の予測値は **0**。

ただし床・天井で潰れて ±0.0 に見える行は別にある——第五波が 0.0% の **6行** と
100.0% の **8行**、計 **14行**。これらは規則が効いても勝率としては動きにくい。

空振りが起きるのは戦闘の途中（後列2枚が両方落ちた後、または前列2枚が両方落ちた後）だけで、
**`空振り` 列は 0 にはならず、決着の遅い編成ほど大きくなる**と読む。

### 2-2. 読み手3枚（セロ・ヨミ・シオ）を含む行

**11行**（うち2枚以上を持つのは3行）。

| 読み手 | 行数 | 行 |
|---|--:|---|
| セロ（後衛特化） | 11 | 速攻 / 惨禍×被弾強化 / 耐久 / 毒→被弾強化 / 隊列崩し / 突き出し / 移動改 / 逆しま / 後衛特化+後備え / 縛め非収入型 / 置き去り×分散回復 |
| ヨミ（軋み） | 3 | 隊列崩し / 突き出し / 移動改 |
| シオ（移り木） | 1 | 移動改 |

指示書が「確実に当事者」と名指しした2行（`隊列崩し` / `突き出し`）はここに含まれる。
**`移動改 (バサ×ヨミ×シオ)` が3枚すべてを持つ唯一の行。**

### 2-3. 巨躯（ゴルム）を含む行

**19行**。傷軸は 6行中5行（訂正2）。巨躯の被覆は `DepthOf(wall) < DepthOf(target)` なので、
**引き出された駒は被覆から抜け、押し下げられた駒は被覆に入る**——ゴルムが前列にいる行では
**入れ替えが被覆の出入りを同時に起こす**。

### 2-4. 後備え（セッキ）を含む行

**3行**（死の連鎖+後備え / 後衛特化+後備え / 逆しま+後備え）。**3行とも現在 100.0%。**
後備えは保持者が `Row.Back` でないと働かないので、セッキ自身が引き出されれば窓は完全に閉じる。
3行とも天井なので、**下がる方向にしか動けない**＝符号反転の「損」側の観測に向く。

### 2-5. 符号が反転する行の名指し

**得をする行: `移動改 (バサ×ヨミ×シオ)`（現在 49.5%）**

初手の入れ替えは決定的に読める。後列は ヨミ(92) / バサ(56) で最高HPは **ヨミ**、
前列は セロ(42) / ガルド(100) で最低HPは **セロ**。よって **ヨミ↔セロ**。

- セロが後1へ**押し下げられる** → `HasFallenBack` が立ち、かつ `Row.Back`
  → **後衛特化（攻撃2倍＋貫き化）が開幕から起動する**。本来セロは自分で削られて逃げるまで
  待つ必要があるのに、敵が無償で条件を満たしてくれる
- ヨミが前1へ出される → 軋みが `DepthOf(to) < DepthOf(from)` を満たして**割り込み攻撃 ＋ 強化**
- シオ（中央）は `OnAllyMoved` で**2体とも**癒し強化する

**3枚の読み手が1回の入れ替えで全部起動する。** この行が上がらなければ、
指示書 §5-4（読み手の発火が増えていること）は成立しない。

**損をする行: `逆しま (ネル×ウツ)`（現在 34.5%）**

後列は ネル(45) / ウツ(66) で最高HPは **ウツ**、前列は ゴルム(150) / ガルド(100) で
最低HPは **ガルド**。よって **ウツ↔ガルド**。

- ガルドが後3へ下がる → **庇う（`f.Row == Row.Front`）が完全に死ぬ**。しかもガルドは
  `Stoic` なので回復も強化も受けられず、下がっても取り返しがない
- ウツ(66) が前3へ出る → 逆しまは「強化されると弱くなる」機構で、**移動そのものは
  何の見返りも生まない**。素の66が矢面に立つだけ

天井の3行（セッキ行）も同じ理由で下がる側だが、100.0% からの低下は
**天井が壊れたのか規則が効いたのかの切り分けに追試が要る**ので、中間帯にある
`逆しま` を主な観測対象に置く。

### 2-6. 全体としての予測

1. 第五波の平均は **下がる**（読み手を持つ11行より、庇う・後備え・巨躯の列条件を
   崩される行の方が多い）。**40.0% は割らない**——入れ替えは1回あたり駒を2体動かすだけで
   HP も攻撃力も1点も動かさないため、崖にはならない
2. 中間帯は **増える**（天井の8行のうち、セッキ3行と耐久系が下へ落ちるため）
3. 第3波×第5波 の相関は **下がる**（第三波は渇き＝回復への課金で、列条件とは共有資源が無い）
4. `空振り` は決着の遅い編成（反撃軸・耐久軸）で大きく、速攻軸で小さい
5. **後1 と 後3 の被引き出しは非対称になる**が、原因は席バイアスではなく
   「編成が置いた駒のHPが非対称」（訂正1）

### 3-2. 盤面ルールにはしていない

逆位・渇き・軛・粛は両陣営に等しくかかるので engine 側に判定を置くが、曝きは
**敵陣の駒だけを動かす一方向の効果**なので、殉教・断罪・施しと同じ「敵側の語彙の
プラス特性」として `Traits.cs` に置いた。判定も engine には1行も置いていない。

### 3-3. 召喚枠は**含めた**（指示書 §6-4 の明記要求）

`Row.Back` には ○後2（スロット8）も入る。**含める**方を採った——実態があるなら
盤面の一部として扱う、という既存の判断（貫きのレーン経路・巨躯の被覆）に揃えた。

### 3-4. 上限の回数は戦闘単位（保持者ごとではない）

`BattleContext.ExposeCount` に持つ。駒の `Counters` に置くと保持者が複数いたときに
合算にならない。**空振り（`ExposeMissed`）は上限を消費しない。**

## 4. 測定

### 4-1. 受け入れ基準 1・2（対照の成立）

| 基準 | 結果 |
|---|---|
| 1. 既定（`ExposeRule(0)`）で `compare` が差し替え前の `docs/balance.md` と完全一致 | **220 セル中 食い違い 0 件** |
| 2. `Accuser` を `Knight2` に戻すと、規則を有効（無制限）にしても盤面が完全に元へ戻る | **44 行中 食い違い 0 件** |

**保持者を波に置いた状態で基準1が成立している**ので、差分は規則だけに閉じている。
`expose` の陽性対照（`ExposeRule(0)` での 曝き）も **0.00 回/戦**。

### 4-2. 計数（`expose` §1・第五波 × seed 0..199・1戦あたり）

44行の平均。左が対照（`ExposeRule(0)`）、右が有効（無制限）。

| 曝き | 空振り | 戻り | 後退 | 軋み | 移り木 | 後衛特化 | 後衛特化/T | 決着T |
|--:|--:|--:|--:|--:|--:|--:|--:|--:|
| 2.05 | 0.50 | +0.79 | 0.26 → **2.15** | 0.11 → **0.21** | 0.08 → **0.13** | 0.53 → 0.40 | 0.09 → 0.07 | 5.7 → 5.3 |

**発火は確かに走っている**（2.05 回/戦・空振り 0.50 回/戦）。`後退`（`HasFallenBack` が
新たに立った回数）は **0.26 → 2.15 と 8.3倍**——引きずり出しは1回につき必ず1体を
後ろへ押し下げるので、これがこの機構のいちばん太い出力になる。

### 4-3. 受け入れ基準 4（読み手3枚の発火）—— **3枚中2枚で達成、1枚は未達**

| 読み手 | 対照 → 有効 | 判定 |
|---|--:|:--|
| 軋み（ヨミ・`OnMoved` 起点の割り込み） | 0.11 → **0.21**（+91%） | **達成** |
| 移り木（シオ・`OnAllyMoved` 起点の回復） | 0.08 → **0.13**（+63%） | **達成** |
| 後衛特化（セロ・「後退済み かつ 後列」のターン数） | 0.53 → 0.40 / T で 0.09 → 0.07 | **未達** |

ヨミを持つ3行はすべて増えた（隊列崩し 2.31→3.14 / 突き出し 0.51→**2.92** /
移動改 2.22→3.12）。シオを持つ唯一の行も 3.68→**5.63**。

**後衛特化が増えないのは、窓の開け方と閉め方を同じ規則が同時にやっているから。**
後衛特化の条件は「`HasFallenBack` **かつ** `Row.Back`」の2つで、
引きずり出しは前者を無償で立てるが、**後者を壊す**——セロが後列にいる限り、
セロ自身が「後列でいちばん無傷な駒」に選ばれて前へ出されうる。実測でも
セロは `逆しま` 1行だけで 113 回引きずり出されている。

セロを持つ 11 行を割ると符号がきれいに分かれる。

| セロの初期席 | 行数 | 後衛特化/T |
|---|--:|---|
| **前列・中央**（自力では後退実績を持ちにくい） | 4 | **全行で増**（速攻 0.00→0.04 / 惨禍×被弾強化 0.00→0.10 / 隊列崩し 0.12→0.25 / 移動改 0.11→0.28） |

**曝きは後衛特化を「持っていない編成に配り、持っている編成から取り上げる」。**
`後退` が 8.3倍になっているので**供給そのものは増えている**——止めているのは供給ではなく、
同じ規則が後列という席を奪うこと。この非対称は基準4の趣旨（「移動を選んだ根拠＝
読み手の在庫が最も多い」）を否定しない——3枚のうち2枚は明確に増え、3枚目も
**編成によって符号が反転している**（それ自体がこの期の主眼）ので、**止めずに進めた。**

CLAUDE.md の「**固有の勝者・敗者が波の個性の実体で、ここが空の波は独立した波として
存在していない**」に照らすと、これが採用の主たる根拠になる。

### 外した 5b —— 見落としていたのは「**入れ替えは往復する**」

予測は**初手の1回だけをモデル化していた。** `逆しま` の初手は
後列最高HP ウツ(66) ↔ 前列最低HP ガルド(100) で、ここまでは実測どおり。
「ガルドが後3へ下がって庇うが死ぬ」まで書いた。

**書かなかったのは、その次の発火で何が起きるか。** ガルドは後3へ移った時点で
**後列でいちばんHPの高い駒**になる（ガルド100 > ネル45）。だから次の発火で
**ガルド自身が前へ引き戻される。** 実測の「出された駒」がそれを直接示している——
`逆しま` 単独で **ウツ 245 回 / ガルド 240 回**。曝き 3.58 回/戦・`戻り` +2.55 回/戦。

> **入れ替えは、押し下げた駒を次の引き出し候補にする。**
> 前列が後列より硬い編成では、規則が**自己反転して振り子になる**——庇う手は
> 死なず、往復するだけになる。`ガルド前列 ＋ ゴルム前列` の組は前列 100/150 に対して
> 後列 45/66 なので、この振り子が最も強く出る形だった。

**指示書 §6-3 は「後列は空かない」と警告していたが、その系（押し下げた駒が
次の最高HP後列駒になりうる）までは書いていない。** 予測もそこで止まった。
見落としていた量は「**入れ替え後の後列のHP分布**」で、初期配置だけからは読めない。

### 外した 6d —— 空振りは「長さ」ではなく「片列が全滅したか」で決まる

空振りの条件は「後列 0 体 **または** 前列 0 体」なので、測っているのは
決着の遅さではなく**片方の列が先に消えたか**。実測の上位は
`追撃×据え (ハギ×バン)` 1.45 / `裂き (キリ×エグ)` 1.43 / `刻み×断ち` 1.38 で、
どれも**負ける編成**——味方が削られ切る過程で片列が空く。
決着 11.2T の `逆しま` が 0.20 と低いのは、**勝つ編成は列が空かない**から。

## 6. 採否 —— **採用する**（`ExposeRule.Default = new(3)`）

### 採った理由

1. **§5-5（この期の主眼）が出た。** 同じ規則で 8 行が上がり 29 行が下がる。
   最大 +49.5pt / −68.0pt で、**得をした上位3行は移動の読み手を2枚以上持つ3行そのもの**
2. **第五波が初めて固有の勝者を持った。** 厳密版で 0 → 1、緩い版で 0 → 3。
   緩い版の3行は読み手編成そのもので、**波が課金する資源と、その資源への回答が
   両方名指しできる**（CLAUDE.md「ここが空の波は独立した波として存在していない」）
3. **3×5 相関が +0.58 → +0.46。** 狙いどおりの向き
4. **対照が完璧に成立した**（220/220 と 44/44）。差分は規則だけに閉じている

### 上限を 3 にした理由

固有の勝者（厳密版）が出るのは **3 以上でだけ**。無制限との差は平均 0.2pt しかないが、
**上限は「読める天井」として残す**——曝きの実測が 2.05 回/戦なので 3 が縛るのは
長引いた戦闘だけで、そこは振り子（§5）が最も強く回る局面と一致する。

### 残す懸念（次期への持ち越し）

- **第五波の平均が 40.5% と歯止め（40.0）の 0.5pt 上にある。**
  この波に次に何かを足すときは、平均を先に見ること
- **第4波 × 第5波 の相関が +0.30 → +0.44 と上がった。** 軛（1発の重さ）と曝き
  （列条件の破壊）が、どちらも積み上げ系に課金しているため。第四波か第五波の
  どちらかを触るときの材料になる
- **後衛特化は「持っていない編成に配り、持っている編成から取り上げる」**（§4-3）。
  窓の条件が2つある機構は、片方を配る規則が同時にもう片方を奪いうる
  （第34・35期「窓を閉じる条件が2つ以上あると片方だけ伸ばしても伸びない」の裏返し）
- **`Knight2`（巡礼騎士）は削除していない**（対照として残置。逆位・まどろみと同じ扱い）
