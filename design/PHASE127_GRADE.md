### Q0-3 —— `ModifyPattern` の合成規則

`UnitState.CurrentPattern` は `Traits` を順に畳み込む（fold）。各実装は条件が成立すれば
引数の `p` を**無視して**自分の型を返すので、**「段の高いほうが勝つ」のではなく「後ろの札が勝つ」**
——**順序依存**である。ただし **`ModifyPattern` を2本以上持つ味方は 0 枚**なので、
**現行の盤面では一度も顕在化しない**（段2 で載せた `GradeStep` も バンの唯一の型の札）。

### Q0-4 —— 味方が `All` を持ったときに通る経路

`SelectTargetChain`（L3222）の **`if (pattern != AttackPattern.Single)` の早期リターン（L3283）**が全部を決めている。

| 段 | `EmitIntercept` の位置 | 単体 | 薙ぎ・全体 |
|---|---|:-:|:-:|
| 標的 | L3331 | ○ | **× 素通り** |
| 後備え | L3294 / L3342 | ○ | **○**（範囲にも割り込む。呼び出し口が2つ） |
| 庇う | L3355 | ○ | **× 素通り** |
| 殉教 | L3379 | ○ | **× 素通り** |
| 棘守り | L3404 | ○ | **× 素通り** |

- `SecondaryTargets` の `All` は `=> foes`（生存する敵**全員**）。倍率は `SecondaryPercent` = **60%**
- 副次目標にも `ApplyDamage` が1体ずつ走るので、**巻き込み則・反撃・棘は通る**
- 特性の発動（`OnAfterAttack`）は**主目標に1度だけ**（範囲でも増えない）

**帰結（実装前に書いた）**: 全体化した駒は敵の防御機構を丸ごと無効化する。
**ただし素通りは全体に固有ではない**——**薙ぎも同じ早期リターンを通る**ので、
「全体にすると介入が効かなくなる」は**すでに薙ぎで起きている**（段1 の表D が実測で裏を取った）。

**介入を持つ敵がいるのは第五波（殉教者）だけ。** 第1〜4波は 0 体
——指示書 P2 の「第三波の祭司が効かなくなる」は**祭司が介入を持たない**ので成立しない。

## 7. この期に気づいたが手を付けなかったこと（§8 に足す）

1. **格上げの一覧は3期に1度は落ちる。** 第98期は墓守リィカ、第127期の指示書は
   軋みのヨミと鱗のウロを落とし、**持っていないトモを数えていた**（5枚中3枚が誤り）。
   **`grade phase0` の Q0-1 がこの一覧の正本になる。**
2. **貫きは「与ダメが増えて勝率が下がる」唯一の段。** 減衰 25%/体 で後ろへ薄く配るので
   撃破が落ちる（1.46 → 1.26）。**貫きを持つ味方は常時 0 枚・条件付き 3 枚（セロ・ホタ・ウロ）**で、
   **3枚とも「条件が立つと貫きになる」型**——この3枚の値段は打点ではなく撃破で測り直す価値がある。
3. **味方の常時の攻撃型は 単体 49 / 薙ぎ 3 / 貫き 0 / 全体 0。** 指示書の 48/4 は誤り。
   **全体に到達する経路は段2 の バン1枚が初めて。**
4. **`AtkBonus` を読む札は 6 本あるが、盤上にいるのは 2 枚（バン・ウツ）。**
   §8-1（支援・耐久の格上げ）を「盤面全体の状態」で書くなら、
   **Q0-5 の表で読み手が薄い鍵（手番・深手は駒の書き手が 0、呪は1枚きり）**が候補になる。
5. **`CLAUDE.md` の「`AtkBonus +=` は 14箇所」は古い**（実測 12 箇所）。
6. **`GradeTrait` は1クラスで3つの `TraitId` を持つ初めての札。**
   `Traits.cs` を走査する診断は `TraitId Id => TraitId.X` の宣言だけを見ているものが多いので、
   **登録（`new XTrait(TraitId.X`）の側からも引く必要がある**（`grade phase0` はそうしてある）。
   **他の診断が同じ穴を踏んでいないかは数えていない。**
