### 第101期 — `recover`

**同じ回復が、第2波では代金の 72% を返し、列全体では 9% しか返さない**（第101期）。
単発の第2波は 66.7%・会戦の R0 は 33.8% で代金は 33.0pt。**HP はそのうち 23.7pt（72%）を返す**が、
突破率では 51.1pt の隙間のうち **4.8pt（9%）**しか返さない。
**第2波は「削られた体で入る」ので HP が効き、第3波は「減った頭数で入る」ので効かない。**
**波が進むほど、代金の中身が HP から体へ移る。**

**死が恒久であるあいだ突破率は「残存」に付き、死者が戻ると「勝率」に乗り換える**（第101期・ピアソン）。
r(残存) は R0〜R100 で 0.415〜0.496 対 r(勝率) 0.141〜0.313 だが、**RFull で 0.114 対 0.879 と入れ替わる。**
**ただしスピアマンは R100 で逆を言う**（0.304 対 0.446）——**46/73 行が 0% の同値塊**なので、
順位相関が測っているのはほぼ「0 かどうか」だけ。**同値塊がある版では順位相関を読まない**
（第22・54期「天井は同値塊を作る」の床側）。

**育つ駒の不利は「二重」ではなく、ほぼ全部が体の側だった**（第101期。第100期の申し送りへの部分的な回答）。
ムド・カド・ヨミ・リィカを含む 36 行と含まない 37 行の突破率の**比**は
R0 0.00 → R100 0.06 → **RFull 0.82** で、**単発の連勝率の比 0.65 を上回る。**
**pt の差を版のあいだで比べてはいけない**（分母が 1.9% から 57.2% まで 30 倍動く）。
**この分割は統制されていない**ので、`AtkBonus` の持ち越しの値段はここからは読めない。

**抜けた試行の上でしか定義できない量を、抜けた試行の数が動く比較に使ってはいけない**（第101期・器具の反省）。
Q2（圧勝率が R0 より下がらない）は**下回りようがない線だった**——R0 の圧勝率は **0%** ＝ 下限。
しかも観測された 82 → 50 → 26 → 14% の単調減少は、分母が 241 → 7601 と 32 倍に増えるので
**「泥仕合になった」と「選抜が緩んだ」を区別できない。**
第59期「判定式の条件節が分母の何割を選ぶかを実装前に数える」の**下限側**の再発。

**`RFull` は「各波が単発と同じ条件」ではない。「HP と体だけを単発と同じにした版」である**（第101期）。
73行を持ち越される資源で分けると、単発の連勝率とのずれは完全に説明が付く:

    リィカ            3行  +26.7pt  ← 墓守の層を OnCarryOver が再構成する（単発より強い）
    移動（セロ/バサ/ヨミ） 17行   +5.9pt  ← HasFallenBack と Slot が持ち越される（単発より強い）
    **どれも無い**      **38行**  **−0.8pt**（最大 |差| 6.6pt ＝ 200 seed の 2SE の内側）
    **ヴェル**          **6行** **−36.9pt** ← 継ぎ接ぎの charges / sewn / **MaxHp 半減が会戦スコープ**

**駆動因を1つも持たない 38 行では `RFull` が単発の連勝率を厳密に再現する**
——**ノブも器具も間違っていない**ことの証拠であり、
**指示書 §4-3 が測る前に列挙した 5 つの持ち越しがそのまま出た**（第94期「既知の値を再現できて初めて器具」の裏返し）。
`刻み×断ち (ノミ×ナタ)` は 単発 95.0% に対し RFull **34.0%**（ヴェルの `MaxHp` が 46 → 11 に縮んでいる）、
`駆り立て改 (カリ×死軸)` は 単発 27.0% に対し RFull **98.5%**（リィカの層）。

**境界の回復に `ctx.Heal` を通さない**（第101期の設計判断）。渇き（第三波の波ルール）も
`AcceptsSupport`（支援拒否）も**「戦闘中に味方が配るもの」に対する規則**であって、
**境界の手当ては誰かが配っているのではない**（`Hp` を直接足す。理由はコード側にも書いた）。
**敵側には一切適用しない**——敵は 1 部隊を抜くたび `Materialize` で新品が投入されるので元から全快。
**`ReviveDead` は `current`（その戦闘へ投入した駒）だけを見るので、召喚された駒は復帰しない。**

### 第102期 — `choice`

**主判定 Q1（最良だった選択肢の分布が1つに 60% 以上偏らない）は通った**（**49.3%**）。
**Q2（帯）は落ちた**（中央値 0.5%・線 5〜50%）。**Q3（選ばせる価値）は +5.78pt で通る**（固定最良の 2.0 倍）。

**偏りが割れる軸は2本ある。合計で通ったのは打ち消しではなく、境界ごとに違う答えが出たから**（第102期）。

    第1戦の後  回復 **75.3%** / 蘇生 17.1% / 持ち越し 7.6%   ← 死者0体が **82%**（選択肢2つ）

**境界ごとに見ればどちらも線を超えている。**「選択肢が何個あるか」自体が境界の位置で変わる
——第2波で 4.75 → 2.22 体まで落ちるので、**第1境界には返す体がほとんど無い。**
**編成でも割れる**——固定3方策のうち唯一の最良は **蘇生 7 行 / 回復 21 行 / 持ち越し 6 行**
（1つでも突破率 > 0 の 35 行が分母・同点1）。`後衛特化+後備え` は回復 91.5% で蘇生・持ち越しが **0.0%**、
`死の連鎖 (リィカ軸)` は蘇生 32.0% で回復が **0.0%**、`縛め収入型` は持ち越し 42.0%。

**「列全体で体が効く」と「この境界で体が返せる」は別の量**（第102期。予測を2つ外した原因）。
第101期の「帯までの距離の 91% を死者の側が持っている」を境界ごとの話に持ち込んで
「最良は蘇生に偏る」と予測したが、実測は**第1境界では蘇生 17.1%**。
**Q1 を通したのは「第1波の後は回復が最良」という副次の予測1本だけ**だった。

**「負も一緒に持ち越せば可変コストになる」は成り立たなかった**（第102期）。
`Carry` が現行より**悪くなった試行は 1.88%、良くなった試行は 18.68%** で**10 倍近く得に偏る。**
`Carry` が選ばれない（5.7%）のは災厄だからではなく**回復・蘇生に負けるから**である。
**しかも拾われるのは育つ駒を含む行ではない**——含む行 5.7% 対 **含まない行 9.3%（予測と逆）**。
味方に載る状態異常は 4 種＋巻き込み則の傷しか無く、**盤面に幅が無い**（第49期）のがそのまま出た。

**Q2 は境界のノブでは通らない**（第102期の申し送り）。`RFull`（第101期の上限）で中央値 53.0%、

`BattleResult.Events` からは取れない（診断は verbose=false で数万戦回す）。

**会戦の持ち越しの代金は HP ではなく体だった —— 境界に回復を置いて掃引した**
（第101期・調査。**触ったのは会戦の境界の規則 1 つ（`RecoverRule`）だけ**。駒・特性・数値・engine の判定・

### 第103期 — `betray`

**「盤の形が天井を決める」は成立した。決めた天井が 1 だっただけだった**（第103期・Phase 0 の門）。
指示書の擬似コードをそのまま写すと**餌は 1戦に1体しか湧かない**——
**`BattleContext.Summon` の空き判定は生死を問わない**（死者の枠を空きと見なすと蘇生と衝突するため）ので、
**餌の死体が ○前2 を永久に塞ぐ**（塞 3.47 回/戦）。`PlusText` の「毎ターン」が嘘になるので、
**餌にだけ「死者は席を塞がない」を許した**（`BetrayRule.Respawn`。餌は `Ephemeral` で蘇生されないので
元の規則が避けている衝突は起きず、**席を読む箇所は全部 `LivingMembers` で濾している**）。
**湧きは 1.00 → 3.37 回/戦。** `Respawn = false` は対照として残置。
**次に召喚枠へ湧かせる機構を作るときは、湧いた駒の死体がその枠を塞ぎ続けることを実装前に数えること。**

**餌の代金は「敵が1体増えること」ではなく「手番を1つ捨てること」だった**（第103期）。
**ロスター 52 枚のうち、自分の手番で `PerformAttack` を1度も通らない駒は 5 枚しかない**
——ハギ（`CanAct => false`）／カド（`Immobile`）／ヒヨ・ノノ・ミオ（`Actions = [Skill]`）。
**その5枚の Δ相乗の順位は 1 / 2 / 3 / 13 / 16 で全部が正**（一様なら平均順位 26 のところ **7.0**）。

> **手番を持たない駒は代金の払いようが無いので、増えた敵の体（＝伸びた決着ターン）だけを受け取る。**

**逆に「ついで」の読み手として見込んだ薙ぎ持ちは、読み手ではなく最大の支払者だった**
——餌の撃破の内訳は **ボルグ 24.2%（Δ −1.49・32位）／ ドルガ 22.3%（−6.08・46位）／
ソム自身 19.5%** で、**この2枚だけで 46.5%**。
**餌 HP 12 は巻き込み（ボルグ 60% ＝ 10）では落ちない**ので、
**倒すには主目標にするしかない**——「ついでに倒す」が構造的に成立しない設計が、そのとおり働いた。
**ハギの撃破は全体の 3.2% しかないのに Δ相乗は1位。餌を倒す駒と餌で得をする駒は別である。**

**供給者は自分の餌を食べる**（第103期。第96期「ムドは読まないのに最大の受益者」の符号違い）。
ソムは餌を1つも読まないのに**餌の撃破の 19.5% を自分で持っている**——
**単体で殴る駒である以上、自分の置いた餌が自分の標的候補に入る。**
**攻撃型と成長経路を確認しても防げない**（ソムは単体・攻7・育たないので受益者の輪郭には入らなかった）。
**次に「盤面に物を置く」機構を作るときは、置いた物が置いた駒の標的候補に入るかを先に見ること。**

**「単体高倍率は下がる」は正しいが、理由は単体だからではない**（第103期・Q3）。
損の側5枚の実測は **ザン +5.59（4位）／ キリ +5.22（5位）／ ナタ −0.02 ／ ノミ −0.98 ／ トメ −1.95**。
**上がった2枚は「自分の手番を餌に使わない駒」**——ザンはターン外に振る（`CanActOutOfTurn`）、
キリは薄刃で打点が常に 1 ＝ **捨てる手番の値段がロスター最小**。
**傷の書き手が下がるのも、傷が無駄になるからではなく手番が高いから**
（打点 1 のキリが上がり、打点 12 のノミが下がる）。
**「手番を買う駒」は「手番を持つ駒」なので、代金を先に払う**——
号令のガンは 49 位（−8.23）で、指示書の「エグの失った手番をガン・バンが買い取る」を最も強く否定した。

**単発で払える代金でも、持ち越す台では払えない**（第103期・Q4）。
会戦（地点3波）ではソムを含む5行とも突破率 0.00% のまま**突破波数が 1.80 → 1.57 / 1.97 → 1.51 と下がり、
全滅勝ちが 30.0 → 50.9% / 3.6 → 10.7% と上がる**（勝ち方が悪くなる）。
**境界は HP を1点も返さない**（第101期）ので、**餌に使った手番のぶんだけ削られた体で次の波へ入る。**

**紙の「分母を削るか」は、増える側に倒れるとも限らない**（第103期・規約 (G7) の3点目を外した）。
「餌は敵の体を1つ増やすので決着ターンは伸びる ＝ 紙は下限」と先に書いたが、
**20 セルのうち伸びたのは 7・縮んだのは 7・同値が 6。**
`ソム×追い打ち` の第4波は **10.1 → 8.7T と縮み、そこが勝率も 81.0 → 96.0% と最も伸びた波**
——**追い打ちの連鎖が敵の本体まで届く行では、餌が決着を早める。**

**供給側の稼働率は「読み手の 35〜40%」の帯を上回る**（第103期）。
湧き ÷ 決着T は 20 セルで **31〜78%**——供給が `OnTurnStart` にあり、
条件が「席が空いているか」1つしか無いため（第86期の読み手側の帯とは律速が違う）。

### 第104期 — `encore`

**13期かけて供給も単価も動かなかった傷軸が、精算を二値の鍵にした瞬間に動いた**（第104期）。
`刻み (ノミ単騎)` 75.9 → **97.9** ／ `刻み×抉り` 66.0 → **86.5** ／ `止め` 34.5 → **47.0** ／
`逸らし改` 74.1 → **84.5** ／ `刻み×断ち` 75.2 → **81.9** ／ `刻み×縫い` 69.4 → **74.9**（第2〜5波平均）。
**第74期は傷軸の代金の最大の1枚が「読めない間ずっと突っ立っていること」＝手番だと突き止めた。
この期の払い出しはその裏返しで、同じ通貨を返している。**
**第103期（代金は手番で払われる）と合わせて、手番は3期連続で主題に出ている。**

**効くほど測れなくなる**（第104期）。**同じ機構・同じ意図した相手（ドルガ）で、
Δ相乗は キリ +1.59 / ノミ +5.25、ノイズ床は 1.57 / 7.42。**
ノミの表は上位5枚が +3.7〜+5.3 に密集していて、1位でも「他の 46 体より大きく動いた」とは言えない
——第96期の「特異性の物差しは、大きい機構ほど自動的に厳しくなる」が、
**同じ機構を供給者違いで2回測ったときにそのまま出た。**
**床の高さは機構の大きさの関数なので、A を変えると同じ機構が通ったり落ちたりする**
——**A を複数持つ機構では Q1-1 を「A のどちらかで」と書くこと。**

**規約 (G5) の「供給の過半を持つ駒」は「その機構が実際に使う入力の供給者」で読む**（第104期）。
傷の供給の **92.3% は engine の巻き込み則**だが、**巻き込み則は味方にしか傷を書かない**
（`isFriendlyFire` かつ `source` が同陣営）ので、**その 18,172 の傷は1つも再行動を生まない**
（刻み手と死者が同じ陣営になる）。**A をキリ・ノミに固定したのが正しい。**
第93期は供給の 95% を持つ engine の規則を無視して A を選んで落ちたが、
**「過半を持つのは誰か」ではなく「機構の入力になるのは誰の供給か」を数えること。**

    縫いのハリ     A=ノミで **−6.32（48位）**   毎ターン味方の傷を1つ塞ぐだけ。敵を1体も倒さない  ← 予測どおり
    継ぎ当てのノノ A=ノミで −1.66              同上                                            ← 予測どおり
    **断ちのナタ   両 A とも正（+3.54 / +2.86 ＝ キリの表の1位）**                              ← **逆**
