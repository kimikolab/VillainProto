## 1. 目的

第210期で、継ぎ当てのツギ（`Id = "tsugi"`）はポンの第一目標にほぼ届いた。リリの席に置いた第五波で勝率 98.8（リリ 99.8）・全員生存勝ち 70.6（リリ 57.6）。効いたのはほぼ応急処置。

残った課題は3つ。

### 1.1 板が殴られない駒に積もる（ポンが遊んで気づいた）

ポンが `継ぎ当て×分散回復` の第五波（seed 6）を遊んだところ、**ツギ自身が破片 55 を纏ったまま、前衛のササが倒れた**。

- 手番の板は「**破片が最も薄い味方**」に貼る。ササは自分の身構えで破片を持つので選ばれにくく、殴られない後衛（ツギ自身など）に板が積もる
- 応急処置は「**破片の無い味方**」が条件なので、ササのように自前の破片を持つ駒は拾えない
- 第210期の帳簿でも、**応急処置の約4割はツギ自身**に貼られていた

→ 貼る相手も応急処置の条件も、**実質の残り体力（HP＋破片）**で見る。

### 1.2 カドの棘が飢える（ポンの判断: 板で受けても棘は鳴る）

第210期で板が厚くなり（約7.5 → 約25）、板が一撃を吸い切るので**カドは殴られたことにならず、棘が鳴らなくなった**（`反撃` 第四波 98.0 → 75.5・棘 274 → 201）。第204・207期に続いて3度目（R155）。

ポンの判断: **棘鎧は「殴られたこと」に反応する**。破片で受けた一撃でも棘は鳴る。カドとツギが並ぶと、棘と破片の両方で撃ち返す要塞になる。

### 1.3 ツギの仕事が戦績表から読めない（ポンが遊んで気づいた）

- 反射のダメージは**板を持っていた駒の与ダメ**に付いている（第208期の実装）。ツギの仕事がほかの駒の欄に散る
- 「付与」の欄は状態を書いた**回数**で、配った破片の**量**が無い

## 2. 変更

### 2.1 手番の板を貼る相手: 実質の残り体力が最も低い味方

- **(HP ＋ 破片) ÷ 最大HP が最も低い味方**に貼る（ツギ自身を含む。同値は既存の同値割りの窓口）
- 板の厚さの式（基本×腕＋在庫）は変えない

### 2.2 応急処置の条件: 実質の残り体力が4割を切ったら

- 「破片が 0 の味方」の条件を外し、**ダメージを受けた後の (HP ＋ 破片) が最大HPの 40% 未満**の味方に出す
- 第210期の判断（跨いだ一撃に限らず「その一撃の後に 40% 未満なら」出す）はそのまま
- 1ターン1回・粛で止まる・倒れた味方には貼らない・連鎖しない、は変えない
- 同時に複数が条件を満たしたときの順は第210期の作法のまま

### 2.3 板（破片）で受けても、カドの棘は鳴る

- カドの棘の反撃（`ThornGuard` / `Thorns`。Q0-1 で特定）が、**破片で受けてHPが減らなかった一撃にも反応する**ようにする
  - 棘の量（カド自身の攻撃力の2倍など）・隣の味方を巻き込む点・`Immobile` / `Havoc` は変えない
  - 「殴られた」の判定を、HPの減りではなく**攻撃を受けた（破片で止まった分も含む）**にする、という読み替え
- **カドだけ**を変える。ムド（殴られた回数）・ドハ・ザン・ガルドなど、ほかの「被弾で動く駒」は変えない（§8）
- ツギのいない行でも、カドが破片を持つ場面（ヒビ・ササ等と同席）があれば動く。**Q0-2 で影響範囲を数える**

### 2.4 戦績表に2つの欄（盤面は動かない）

DemoApp の戦績表（「戦績 —— 誰が何をしたか」）に欄を足す:

- **破片(与)**: その駒が味方に書いた破片の**量**（ツギの板・応急処置、ヒビ・ササ・ウケ等の破片も同じ欄で）
- **反射**: ツギの板から返った反射のダメージの合計を、**ツギの行に**載せる（板の印を付けた書き手に帰属させる）
  - 既存の「与(敵)」の数え方は変えない（反射は今までどおり板を持っていた駒の与ダメにも入る）。欄の注記にその旨を1行書く
- 計数の足し方は `UnitTally` 等の既存の作法に揃える。表の注記の文面は Claude Code の判断でよい
- この変更は盤面を動かさない。**§2.1〜2.3 より先に単独でコミット**してよい

### 2.5 変えないもの

- 板の厚さ（基本＝ツギの最大HPの40%×腕＋在庫）・反射（失った破片＋残り×50%）・燃えやすさ（燃焼ダメージ倍）・分かちを破片の後ろへ（R313）
- 腕（効きは小さかったが、今期は触らない）
- HP62／攻9／速8・ツギ自身は殴らない

- ツギを含まない行は Y0〜Y2 で ±0.0。Y0 は第210期 W3 の表と一致

### `units.md` の文面（案・Y3）

**ツギ**
- 特性: 手番で、最も危ない味方（HPと破片を合わせて最も少ない者）に板を貼る（自分の最大HPの4割の破片）。回復ではないので渇きでも止まらず、回復を受け付けない味方にも届く / 味方のHPと破片の合計が4割を切ると、手番の外で駆け込んで板を貼る（1ターンに1回） / 板が敵に砕かれると、破片がその敵へ飛ぶ（砕けた量に、残った板の厚さの半分を足したダメージ） / 味方の破片が砕けたり誰かが倒れたりすると瓦礫を拾い、次の板を厚くする。板が砕かれ続けるほど腕が上がり、板そのものが厚くなる
- マイナス・フレーバーは第210期のまま

**カド**: 特性の文面に「破片で受けた一撃にも棘は返る」を足す（言い回しは Claude Code の判断でよい）
