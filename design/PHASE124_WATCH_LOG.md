行・波・seed は1つも変えていない（`docs/watch.md` の「推奨の見る順」も第123期と同一であることを確認済み）。

> **`docs/watch.md` の後半の盲点表を先に見ること。**
> **第124期 段2 で埋まったもの**: `ActorId` を持たない出来事の種類は **9 → 4**
> （残るのは `TurnStart` / `Status` / `StatusSnapshot` / `StatSnapshot` で、

> **まだ埋まっていないもの**: 痺・標・破片の `StatusGain`（窓口が無い）と、**減算の窓口**
> （止めが標を食う・断ちが傷を食う、は1件も残らない）。

**手順**: `DemoApp` を起動 → ヘッダの「編成プリセット」で行名を選ぶ →
「敵ウェーブ」で波 →「戦闘 seed」に seed を入れる →「この配置で出撃」。

**コマンドラインからも指定できる**（第124期に足した。画面から選ぶ手順は今までどおり）:

```
Godot --path DemoApp -- --demo-preset="刻み×抉り (ノミ×エグ)" --demo-stage=4 --demo-seed=0
```

（`--demo-stage` は 0 始まり ＝ 第1波が 0。`--demo-preset` は行名の部分一致。）

**この期に画面へ足したもの**:

- **戦績パネル**（段1）—— footer の「戦績 (T)」か **T キー**。戦闘終了時は自動で開く。
  `振 / 干渉 / 与(敵) / 与(味) / 被 / 被(味) / 回復(受) / 回復(与) / 強弱 / 付与 / 大技 / 撃破 / 庇い / 落ちた`。
  **`—` は「計数が無い」で、`0`（やっていない）とは違う。**
- **書き手 → 対象の細い線**（段2・3-h）—— 回復・蘇生・召喚・移動・見せ場・状態。
  **攻撃の太い線とは別の形**（細線＋足元の輪）にしてある。
- **同時着弾**（3-a）・**ダメージポップの拡大**（3-b）・**寄りと密度**（3-c）・
  **貫き / 薙ぎの描き分け**（3-d）・**見せ場に駒名**（3-e）・**巻き込みの紫の輪**（3-f）・
  **傷の量と書き手**（3-g）。

記号: **○** 画面の動きから1文が読める ／ **△** 読めるが弱い ／ **×** 読めない ／
**−** そもそも画面に出ない（＝盲点表に該当）

`〔第123期: …〕` は前回ポンが付けた評（**駒ごと**の記録で、戦ごとではない）。
空欄はそのとき評が付かなかった駒。
