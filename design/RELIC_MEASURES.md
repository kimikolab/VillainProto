# レリックの物差し（確定版・第273期）

description: レリック（編成で駒の枠に付ける札・`RelicCatalog`）を測る4つの物差しと、その分母・線・手続き。**札を足す期・作り替える期は毎回これで測る。** 第270〜272期の判定を経て、第273期にポンの決定で札種別に確定した。

**線を変えるときは、変える期の指示書で事前に書くこと（第64期）。結果を見た後に変えた場合は、その旨と理由とポンの承認を報告書に書き、過去の期の判定は書き換えない。**

## 1. 測りの共通の手続き

- **台**: `compare` 61 行（`CompareBuilds()`）× 本編第2〜5波（`EnemyCatalog.Stages[1..4]`・倍率 115/115・`compare` と同じ呼び方）。**ボスは使わない**（札1枚で割れない設計の最終試験・付録としてだけ当てる）。
- **部隊に札1枚**（どの枠に付けるかを総当たり）。器の仕様（1枠1枚）とは別に、測りの範囲として絞る。
- **帯**: 帯A（選抜と主の値）・帯B（追試）とも 200 seed。**期ごとに使ったことの無い帯を選ぶ**（第271期 0..199 ／ 第272期 200..399・400..599 ／ 第273期 600..799・800..999）。
- **主指標は勝率と倒しT（勝った戦の平均ターン）。与ダメ系は使わない**（R364）。
- **回帰**: レリック無しの全既存測定（`compare` ／ `bosswave run` ／ `checkwave run` ／ `bosswave compare`）が 0 差分。前の期の器具の再実行が前の期の出力と一致。

## 2. 四つの物差し

### 2.1 固有の勝者

- **分母**: 帯A で素が負けるセル（行 × 波・勝率 < 100%）。
- **件** ＝ セル × 札 r で、r の最良の枠（帯A・勝率 → 倒しT）が**帯A と帯B の両方**で素に対し片側フィッシャー p < 0.05。
- **行** ＝ 件を持つ行（重複なし）。
- 線は期の指示書で決める（第272期: ≧ 3 行・火付けの矢以外 ≧ 1 行／第273期: 新札5枚中 ≧ 3 枚が各1行以上）。

### 2.2 混成の成立（橋）

- **件** ＝ 固有の勝者の件のうち、**札が持ち込む軸の資源が、行の軸タグに無い**もの。
- **軸タグ**は第264期の核リスト（燃焼: ボルグ・ホタ・ヒヨ ／ 移動: バサ・セロ・ヨミ・シオ・ハネ ／ 雷: シガ・ツギ・カタ ／ 毒: グザ・ミオ・ラウ）。両属の駒は数えない。
- **札が持ち込む軸**（札を足したらここに1行足す）:

| 札 | 持ち込む軸 | 備考 |
|---|---|---|
| 火付けの矢（・3 ／ ・5） | 燃焼 | |
| 毒の足跡 | 毒 | |
| 弾性 | 移動 | 敵を動かす |
| 軋む足 | — | 移動を**読む**札（持ち込まない） |
| 萎える心 ／ 痺れる足 ／ 身を固める | — | |
| 帯電の足（第273期） | 雷 | 感電を持ち込む |
| 押し毒（第273期） | 移動 | 敵を動かす（毒を読む） |
| 勢い余り（第273期） | 移動 | 自分と味方を動かす（撃破を読む） |
| 溢れの刃（第273期） | — | 回復を火力に変える（軸を持ち込まない） |
| 毒を招く（第273期） | — | 読み手はヴィオ（第274期に訂正・§2.3） |

**橋渡しする資源**（第273期の「毒・感電・回復の持ち込み」の数え方・行の構成は問わない）: 毒の足跡 → 毒 ／ 押し毒 → 毒 ／ 帯電の足 → 感電 ／ 溢れの刃 → 回復。燃焼（火付けの矢）・移動（弾性・勢い余り・軋む足）は数えない。

- 内訳（どの軸を持ち込んだか）を必ず併記する（第273期の主題は燃焼一極の緩和）。
- **発見**（第274期に足した分類）: 札が、既存の機構の**書かれていない資源**を掘り当てた件。**橋（持ち主の行に無い軸の資源の持ち込み）には数えず、別に数える。**
  - 例: 溢れの刃 × 大喰らいゴルム（第273期・12 件中 10 件）——溢れの源は味方の癒し手ではなく、ゴルム自身の大食い（味方から吸う HP）が最大HPで切られた分。持ち主1体の中で完結する。
  - 見分け方: 件の札を付けた駒の発火の直前の出来事をログで見て、資源の出どころが**札の持ち主自身の素の札**なら発見。`relic logrow` で確かめる。
  - 発見は外れ値監視の候補でもある（`RELIC_SUMMARY.md` の監視欄）。

### 2.3 ゴミの成立

- 読み手の行 × ゴミの札 × 全枠 × 本編4波で、セルが「付けた方が強い」＝ 勝率 +1pt 以上、または勝率が同じ（勝ちあり）で倒しT が 0.1T 以上速い。
- **成立** ＝ 読み手の行の割合が対照（読み手のいない行に同じ札）の 5 倍を超え、かつ強いセルの 2/3 以上が読み手本人（または読み手が読む駒）に付けたセル。
- 線は期の指示書で決める（第272期: 再現すること／第273期: 毒を招く × ベニの行で強いセルがあること）。
- **読み手は「その札のマイナスを得に変える駒」**（第270期の原則3）。読み手の行が素で勝ち切っていて倒しT にも伸びしろが無いと、強いセルは立ちようが無い（R365 の再発・第273期）——**線を引く前に、読み手の行の素の勝率と倒しT を見ること。**
- 現在の組: 萎える心 → **ウツ**（第271〜273期で3帯とも成立）／ 毒を招く → **ヴィオ**（第274期に訂正。第273期の帯A で 7 ／ 40・対照 0.2%）／ 痺れる足 → ガン（第271期に不成立・作り替え待ち）

### 2.4 個性の保存（**札種別**・第273期に確定）

| 札種 | 物差し | 線 |
|---|---|---|
| **繋ぎ** | 固有の勝者の全件で、札を付けた駒の「元の役割の量」（素の版で最も大きい量: 与ダメ ／ 回復 ／ 状態の付与 ／ 受けたダメ〈重み 1/4〉・20 ターンまで・帯A）が札ありで半分以上残る | **全件 ○** |
| **ゴミ** | 同上 | **全件 ○** |
| **変換** | 個性の保存は**適用しない**（役割が変わることが設計意図）。代わりに**符号反転の成立**: (正) 固有の勝者の件が ≧ 1 **かつ** (負) 帯A で、付け先の規則「攻」（素の攻撃力が最大の枠）に付けたとき素より片側フィッシャー p < 0.05 で下がる行 × 波が ≧ 1 | **両方あること** |
| **機構** | 繋ぎ・ゴミの札で個性が消えた件（＝ 器・橋が駒の個性を消した件） | **0 件** |

## 3. 実装（器具）

- `relic grid [帯の頭]`（第271期の4物差し・ボスを含む）／ `relic rejudge`（第272期・弾数制の3版）／ `relic expand`（第273期・この文書の確定版）。本体は `BattleSim/Modes/Relic*.cs`。
- 札の一覧は `RelicCatalog.All`、版（数値違いの対照）は `RelicCatalog.Versions`（`All` に入れない）。

## 4. 書き戻さないもの

レリックの測定結果は**転生の評価（`roster_audit`・転生候補の棚）に書き戻さない**。固有の勝者に ✕・△ の駒が含まれても評価は変えない——素の個性は不変（第270期・ポンの条件）。

## 5. 札の区分（第274期）

| 区分 | 意味 | 札 |
|---|---|---|
| **現役** | 物差しで測り続ける | 帯電の足以外の11枚（痺れる足の作り替えは引き継ぎの論点・`HANDOFF_AFTER_RELIC.md`） |
| **供給待ち** | 札は動く（検証台で確認）が、`compare` 61 行に**その札が読む資源の供給が無い**ので本編で測れない。**文面は作り替えない**。**供給の行が `compare` に立った時点で再測する** | 帯電の足（自分が感電していることが条件。感電を味方に漏らすカタが 61 行に居ない。自前で撒く形にすると「カタの漏れを裏返す」設計が死ぬ）。**第276期**: 感電の行（62 行目・カタ入り）が立ったので再測し 0 件——**もう1つの条件「動かされる」の供給が、感電の行に無い**（`design/PHASE276_SOM_REBIRTH.md` §9）。**第277期に区分を「感電と移動の交差待ち」に改めた**——待っているのは感電の行でも移動の行でもなく、**両方の供給が同じ行に立つ行**（下の注） |

供給待ちの札も `RelicCatalog.All` に残す（測りの器具は全札を回し、件が 0 であることを記録する）。

**AND 引き金の札（第277期に追記）**: 条件が2つの資源の**かつ**で書かれた札（帯電の足 ＝「動かされたとき」**かつ**「自分が感電していれば」）は、**両方の資源が同じ行に供給されている行が `compare` に無いと測れない**。片方の資源の行が立っても再測の契機にならない（第276期に感電の行で再測して 0 件だったのはこれ）。**再測の契機は「交差する行」が立ったとき**——区分の欄には待っている資源を「A と B の交差待ち」と両方書く。
