| Q0-2 | ネルの呪いと共有 | **区別は要らない**。共有の判定（`ApplyDamage` の末尾）は `Curse.Enabled && singleHit && target.RawCounter(StatusKeys.Curse) > 0` だけで、**誰が付けたかを1ビットも見ない**（ムドの保持も問わない）。ネルは `HexTrait` と同じく `StatusKeys.Curse = 1` を立てるだけにする。**`ctx.Curse.Enabled` が偽の版では付与しない**（ムドの付与と同じ門・第96期の対照がそのまま使える）。二値で重ねない |
| Q0-3 | 攻撃ダウンの経路と敵の倍率 | **`ctx.Dull`（新しい経路の札を足す）**。第187期の倍率は `Materialize` で `Def` の写し（素の攻撃力）に掛かり、`Dull` は `AtkBonus` を引くので、**−4 は倍率の後に素のまま効く**（`CurrentAttack` ＝ `ModifyAttack(Def.Attack(×1.15) + AtkBonus)`）。**敵の `AcceptsSupport` が偽の駒は開幕の呪詛と同じく飛ばす**。味方への −2 は突き返しの効果Bと同じく**支援拒否（ガルド）を弾き、隣へ流さない**。`Dull` の中の横取り（ウケ・ワタ）は今までどおり掛かる |
| Q0-4 | 萎縮の段 | **攻撃1回＝`PerformAttack` 1回**。`atk` を作り終えた直後（突き・止め・薄刃の払い直しの**後**、`Attack` を打つ前）で **`atk −= atk × 50 / 100`**（萎縮の既存の式と同じ切り捨て。攻1 は 1 のまま）して、その場で消す。したがって**半減は一撃の全段より前**——§1 の +50%・萎縮 −30%・ヒサの半減・バンの層・軛・呪いの共有は、**半分になった量に今までどおり掛かる**。連撃（ウツ）は1発目だけ・薙ぎは主目標と巻き込みの両方・貫きは列の全段が半分。**起爆（カタ）・毒と燃焼の刻み・棘の反射・仇指しの返しは `PerformAttack` を通らないので掛からない**。反撃・割り込み・追い打ちは `PerformAttack` を通るので**そこで消費される**。**保持者がいなければ比較1つで抜ける**（`_dauntLive`） |
| Q0-5 | 萎縮の鍵 | **`StatusKeys.Daunted`（`"daunted"`・表示名「萎」）**。二値。竦み（`Cowed`・次の手番を失う）・痺れ（`Stun`）・転倒（`Stagger`）はどれも**手番そのもの**を消すが、萎縮は**手番は残して一撃だけを軽くする**ので別のキー。`StatusKeys.All` に足す（会戦の境界で消える）。手番を失う状態に重ねても消費されない（次に振ったときまで残る） |
| Q0-6 | ハネの突き返しの経路 | **`ctx.SwapSlots(敵, 後ろの席, by: ハネ)`**（曝き・喧噪と同じ窓口）。**真後ろ＝同じ側の後列の席**（前1 → 後1・前3 → 後3）。中央は両方のレーンに属して「どちらかの真後ろ」ではないので使わない。**○前2（召喚枠）の敵は対象外**。突き返された敵は `StatusKeys.Stagger`（第143期の転倒・`TakeTurnCore` が読む）。**バサの「前に出た敵は混乱」は反応しない**——あれは喧噪自身の入れ替え（`ShufflerTrait.Stir`）の中の枝で、`SwapSlots` の中には無い（`ConfusionRule` は既定 `Active = false`）。**反応させない（今の仕組みのまま）**と決めた。前へ出てきた敵（真後ろにいた敵）は何も受けない |
| Q0-7 | ハネ自身の入れ替え | `SwapSlots(ハネ, 相手の席, by: ハネ)`。`Notify` がハネと相手の両方に `OnMoved`、同じ陣営の全員に `OnAllyMoved` を流すので、**ヨミ（`Displaced`・自分が動いたとき）・シオ（`Drifter`・味方が動いたとき）はそのまま発火**、セロは後ろへ動けば `HasFallenBack` が立つ。**バン（据えた足）は `SwapSlots` の入口で空振り**（相手の候補から除き、バンしかいないときだけバンへ振って空振りを数える）。**ハネ自身の「押しのけられたら突き崩す」はこの入れ替えでは発火させない**（`ctx.Shoving` の再入ガードの中で入れ替える）——発火させると毎手番自動で曝きと同じ選び方の突き崩しが走り、**いま突き返した敵をそのまま前へ引き戻しうる**（後列で現在HP最大の敵を前へ出す規則なので）。相手の選び方は**隣接する生存味方のうちスロット番号が最小**（乱数なし・測る前に固定） |
| Q0-8 | 過去の類似測定 | **手番での呪い付与は無い**（第96期の呪いは被弾で付く）。**「次の一撃を弱める」も無い**——近いのは第146/147期の混乱（次の1回の攻撃を自軍へ向ける・`PerformAttack` の出口で消費）と第185期の竦み（次の手番を失う）。**敵を後ろへ押し返す機構も無い**——第40期の曝き・第41期の突き返し（効果A）は**後列の敵を前へ引きずり出す**向き、第144期のバサは「前へ出た敵が転ぶ」。**初出**: ネルは最初のコミット（呪詛・開戦時1回）、クビは初期ロスター（萎縮）、ハネは第41期（突き返し）。**第172期 部C** でかき回し隊の後3（ハネの枠）を萎縮のクビに替えると 2 本抜きが +34.5pt（R266）・**ウツを育てたのはハネの供給ではなく生存時間**（R267）。**第177期**の観察ログで次の転生候補の1枚目がハネ。`LESSONS_101_` の移動の読み手の台では**ハネ −0.8pt（敵陣しか動かさないので味方側の移動を読む口が無い）** |

### 実装の形（測る前に固定）

- **札は割る**（第74期の作法。マイナスを外せば `yP`）。旧の札（`Curse` の開戦時の呪詛は新ネルもそのまま持つ／`Cower`・`Shove` は**定義だけ残す・保持者 0 枚**＝回帰の対照）
  - ネル: `Curse`（開戦時・現行どおり）＋ **`Hexer`**（手番で呪い・呪い持ち全員 −4）＋ **`HexLeak`**（隣の味方 −2）。`Actions = [Skill]`（攻撃しない）
  - クビ: **`Huddle`**（味方全体の被ダメ −30%・engine の萎縮の段の条件に足す）＋ **`Daunt`**（手番で萎縮）＋ **`DauntLeak`**（隣の味方も萎縮）。`Actions = [Skill]`
  - ハネ: **`Rebound`**（手番で突き返し＋押しのけられたときの突き崩し＝旧効果A）＋ **`Overrun`**（自分が隣の味方と入れ替わる）。`Actions = [Skill]`
- 数値は `HexAtkDown = 4` ／ `LeakAtkDown = 2` ／ `CowerPercent = 50`（指示書のまま）。HP・攻・速は据え置き
- 同値の割り方はすべて**スロットの小さい方**（乱数を引かない。`PickOne` は増やさない）
- ハネのマイナスは**突き返しが成立したときだけ**（「勢い余って」）。前列に敵がいない手番は何もしない
