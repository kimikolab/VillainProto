## 1. なぜこれをやるか

第13期で穴を塞いだ結果、**第一近似が `撃破/戦` r²=0.90 になったが、これは同語反復だった**。

> 部隊を全滅させることがその部隊を突破すること。味方1部隊なら `部隊戦数 = 突破数 + 1` で、チャージ台（駒数 5+4+4=13）で全抜きした編成の `撃破/戦` は例外なく 13÷3 = 4.33。これは算術。

これを自力で見つけて `power` に注記したのは正しい。**そして結果として、第12期の解釈もひっくり返っている。**

- 第12期の r² 0.41 は「地力の説明力が4割」ではなく、**「言い換えのはずの量が、穴のせいで4割まで落ちていた」**
- つまり「地力は単一の量ではない」という第12期の結論は**根拠を失っている**
- **地力の分解は、まだ何も分かっていない状態に戻った**

**同語反復の量を候補から外して、やり直す。** これが Phase EA。

もう1つ、**穴を塞いだ後も残った唯一の本物の残差**が反撃軸（惨禍×被弾強化 −0.307 / 反撃改2 −0.297）。反撃は `ctx.ApplyDamage(source, back, self)` と source 付きなので新旧で 1pt も動かない。**与ダメも撃破も出ているのに突破度に届いていない。** これを追うのが Phase EB。

## 3. Phase EA — 同語反復を除いた分解

### 3-1. 何を除外するか

**「突破度と算術的に結びつく量」を候補から外す。** 判断基準は「盤面の性質ではなく、突破という結果の言い換えになっていないか」。

明らかに該当:

- **`撃破/戦`** — 部隊の全滅＝突破なので、突破度の言い換え
- **`与ダメ/戦`** — 敵の総HPを削り切ることが突破なので、同じ構造を持つ（第13期で `撃破/戦` に次ぐ2位）

判断が要るもの（**除外するかどうかを自分で判断し、理由を報告する**）:

- **`被ダメ/戦`** — 突破の結果ではないが、戦闘数で割っている以上「長く戦うほど薄まる」構造がある
- **`与ダメ効率`** — 分子分母とも同語反復の量。ただし比なので打ち消し合う可能性がある
- **`干渉/戦`** — 第13期で「受け手側に対応物が無い」と記録された量。**毒軸で過小のまま**なので、そもそも信頼できない

**除外の判断そのものが今回の成果物**なので、「なぜ除外した / しなかった」を必ず書く。

**除外しても残るのは「戦闘数で割っていない量」と「静的な量」。** そこに地力があるなら、それが本来の答え。

### 3-2. やること

第12期・第13期と**同じ手順・同じ計算方法**で、候補集合だけ変えてやり直す。

1. 除外後の候補で単相関の全一覧
2. 第一近似とその r / r²
3. 残差と、残差の上位・下位5編成
4. **静的だけの説明力**（静的な量は同語反復ではないので、ここが今回いちばん意味を持つ）
5. **第12期・第13期との対比表**

### 3-3. 説明力が落ちることは失敗ではない

同語反復を外せば r² は下がる。**下がった値が本当の説明力**なので、低くてもそのまま報告する。数値を上げるために候補を戻さないこと。

**もし除外後の最良が r² 0.3 を下回るなら、「地力は既存の特徴量では表せない」という結論になる。** それも成果として記録する（次に何を測るべきかが変わる）。

### 3-4. 受け入れ条件

- 18モードすべての差分 **ゼロ**（`power` の候補集合の変更のみ。**他が動いたら触っている**）
- 除外の判断と理由が全項目について書かれていること
- 第12期・第13期との対比表

## 4. Phase EB — 反撃軸の残差

### 4-1. 仮説

**反撃軸は出力を HP で買っている。** 第9期 `bill` の自傷率は 反撃改 65.6% / 逆しま改 61.6% / 逆しま 59.6% が最上位だった。反撃の出力は「殴られること」で発生するので、出力と被弾が構造的に結びつく。

HP は**会戦を跨ぐ唯一の持ち越し資源**なので、出力を HP で買う編成は、**単発戦の額面ほど会戦では価値が無い**——というのが仮説。

### 4-2. 測ること

**`bill`（第9期）と `power`（第13期）の出力を突き合わせるだけ。** 新しい計測は要らない。

1. **自傷率と、Phase EA の残差の相関。** 仮説が正しければ負の相関（自傷率が高いほど予測より弱い）
2. **反撃軸の編成を名指しで並べる**: 自傷率 / 被ダメ/戦 / 残差 / 突破度。**惨禍×被弾強化・反撃改2・反撃・反撃改** の4編成は必ず含める
3. **単発戦と会戦の差**: 反撃軸が `docs/balance.md`（独立5戦）で強く、突破度で弱いか。**両方の順位を並べる**
4. **反撃軸以外で自傷率が高い編成**（逆しま系 59〜62%）が、同じように残差で沈んでいるか。**沈んでいなければ、原因は自傷率ではなく反撃そのもの**にある

### 4-3. 4 が重要

第9期で「逆しま改は自傷率 61.6% で上位」と分かっている。**逆しま改は強い編成**（第7期までの測定で突破度上位）なので、**自傷率が高いこと自体は弱さの原因ではない**。

反撃軸だけが沈んでいるなら、仮説は「HP で買っているから」ではなく、**「反撃という出力の出し方に固有の何か」**を指していることになる。候補としては:

- 反撃は**受動的**なので、敵の攻撃回数に出力が縛られる（敵が減ると出力も減る＝畳みかけられない）
- 反撃のダメージが**敵を仕留めきれない**（オーバーキルではなく、アンダーキル側の問題）

**どちらが効いているかは、既存の出力から見当が付くはず。推測は推測と明記して書く。**

### 4-4. 受け入れ条件

- 18モード差分ゼロ
- 4編成の名指しの表
- §4-2 の4（逆しま系との対比）に必ず答えること
