### 6-2. 敵からプレイヤーへ状態を書く経路——燃焼・毒・感電を書く敵は 0 体

- 既にあるのは **痺れ**（Condemn ／ Hero2 ・ Seer ・ Reverser・第五波）・**移動**（告発人の Expose）・**反撃 ／ 庇う**（KnightRiposte ・ Martyr）だけ。燃焼・毒・感電を書く敵は 0 体、ボスの札（BossRise11 ほか）にも無い
- **engine 側の非対称が 1 つある: 燃焼の脆さ**（燃えている駒への被ダメ ＋25%）は `BrittleApplies => Ember.BrittleAllies || u.TeamId != PlayerTeam`（`BattleEngine.cs:6251`）で、既定は `BrittleAllies = false`——**敵がプレイヤーを焼いても、燃えたプレイヤーには脆さが乗らない**。第449期の火の魔術師 ・ 火矢の射手で「焼いて脆くする」を狙うならここが要る（片側だけ 0 にする対照と一緒に）
- 毒の刻み（`PoisonTickOnce` ／ `TickStatuses`）と感電（MarkShock）は陣営に依らない（陣営で分けているのは計数だけ）
- 経路の陣営固定: `Materialize` は敵陣営のときだけ敵の倍率（115 ／ 115）を掛ける（作戦マップは `Map11.EnemyScale = None` で掛けない）・`MaterializeEnemy` は X 字固定でレリックは付かない・`Summon` は敵が敵陣に呼んだときだけ倍率

### 6-3. マップ専用の敵部隊を足しても `compare` ／ `docs/` は動かない——確かめ方

- `compare`（balance ／ quality）と、ablate ・ chain ・ cross ・ derive ・ layout ・ pulse ・ watch ほかは **`EnemyCatalog.Stages` だけ**を回す（`Compare.cs:52`）。`EnemyCatalog.Vanguards` を読むのは診断だけで、docs を出すモードには無い
- `dump`（`docs/units.md`）の駒の表と特性の持ち主は **`UnitCatalog.All` だけ**（`Dump.cs:49` ／ `:59`）・ステージ節は `Stages` だけ（`:113`）で、**`PlusText` は出さない**。特性の表は `TraitId` の全行——**既存の `TraitId` を使い回す限り行は増えない**（新しい `TraitId` を足すと 1 行増える）
- **よって**: `EnemyCatalog.MapSquads` のような新しい一覧と新しい敵の `UnitDef` は docs に出ない・既存の敵に `PlusText` を足しても docs は変わらない。**ただし `Stages` に入っている `UnitDef` の特性・数値を触ると `compare` と `dump` が動く**——新しい部隊は別の `UnitDef`（別の `Id`）で作るのが安全
- 確かめ方: 変更の前後で `0 compare > docs/balance.md`・`0 compare quality > docs/quality.md`・`0 dump > docs/units.md` を回して `git diff docs/` が 0 行、`0 audit` でずれ 0 件
