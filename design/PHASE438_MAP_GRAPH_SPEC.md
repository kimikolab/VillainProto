## 2. 盤の定義 —— `MapGraph`（新しいファイル・Godot の型を使わない）

`Map11.cs` と同じ扱い（頭なしの門が同じクラスを回す）。

### 2-1. マス

```
Cell { Id, Name, Kind, Neighbors (Id の列), Lane, Pos }
Kind = Home（味方の拠点） / Open（野原） / Portal（敵の拠点）
Lane = その マスが属する敵の経路の番号（経路に属さなければ -1）
Pos  = 画面に置く座標（float の組・データとして持つだけ。Godot の Vector3 にしない）
```

- 隣り合うマスは両方向に繋がる。
- **拠点（Home／Portal）は通り抜けられない**——入って止まることはできるが、経路の途中には使わない。
  これは今の 1-1 の挙動（北から南へ移るときは拠点までいったん戻る・`Map11Orders.Plan` の
  「別の道ならいったん拠点まで戻る」）をそのまま守るための規則で、製品でも「拠点は目的地」で自然。
- 最短路は幅優先で引く（辺の重さは全部 1）。

### 2-2. 敵の経路（Lane）

敵は決められた経路に沿って味方の拠点へ向かう。経路は **マス Id の列**（拠点の隣 → … → 敵の拠点の手前）。
今の `Map11.Roads`（道ごとの敵部隊の初期位置）は「経路の番号 ＋ 経路上の位置」で書き直す。

### 2-3. 1-1 の盤 `MapGraph.Build11(bool portalOn)`

今の 1-1 を**そのまま**写す（新しいマスは足さない）:

```
Home ── N0 ── N1 ── N2 ──┐
                          ├── Portal   （portalOn のときだけ存在）
Home ── S0 ── S1 ── S2 ──┘
```

- 経路 0（北）＝ [N0, N1, N2]・経路 1（南）＝ [S0, S1, S2]。敵部隊の初期位置は今の `StartCellOf`（N1・N2 ／ S1・S2）。
- `Pos` は **今の `Map11Main.NodePos`／`CellPos`／`PortalPos`／`BasePos` と同じ値**を入れる。画面は1ピクセルも動かない。
- `portalOn` が偽なら Portal のマスは作らない（今の `MaxCell` の挙動）。

## 3. `Map11State` の読み替え

### 3-1. 位置

- 隊の位置は **マス Id 1つ**（`Pos`）。拠点にいる ＝ `Pos == Home`。
  今の `Road`／`Cell` は **派生値として残す**（`Road` ＝ 今のマスの `Lane`、`Cell` ＝ 経路上の位置・拠点なら -1）。
  読み替えで済む読み手はそのまま動く。**書き手は `Pos` だけ**にする。
- 敵部隊（`Node`）の位置も **マス Id**。`Def.Road` ＝ 経路の番号はそのまま（2本抜きの分子と湧きの交互が読む）。
- `Squad.Home`（最初に送り出された経路）と `Cleared` は **1ビットも動かさない**（第168期の分子）。

### 3-2. 規則の写し（意味は今のまま・書き方だけグラフに）

| 今の規則 | グラフでの書き方 |
|---|---|
| `Advance`: 道を1マス奥へ。先頭の敵より奥へは行けない。敵と同じマスに入ればその場で戦闘 | 行き先への最短路の次のマスへ1歩。**次のマスに敵部隊がいれば、そこへ入って戦闘**（＝今の `FoeFacing`）。敵のいるマスを通り越すことはできない |
| `StepBack`: 拠点へ1マス | Home への最短路を1歩 |
| `Send`: 拠点から道の先頭のマス（空きマス）へ | Home から経路の最初のマスへ1歩（`Advance` の特別な場合） |
| `Warp`: 拠点 ⇔ 敵の拠点（制圧後） | 同じ。`Pos` を Home／Portal に差し替える |
| `AdvanceFoes`: 各経路の先頭の固定部隊が1マス拠点へ近づく。湧いた部隊は列になって進み、前が詰まれば待つ。拠点に着けば迎撃（出せる隊が無ければ陥落）。前進先に味方がいれば戦闘 | 経路上の**1つ手前のマス**へ1歩。「詰まり」はそのマスに他の敵部隊がいること。Home に入れば迎撃 |
| `TryCapture`: 敵の拠点のマスに味方がいて敵がいなければ制圧 | `Pos == Portal` の隊がいて `PortalFoe()` が null |
| `SquadAt(road, cell)` | `SquadAt(cellId)` |
| `PortalFoe()`（道をまたいで数える） | `Pos == Portal` の敵部隊 |
| `Map11Orders.Plan`: 別の道ならいったん拠点へ戻る | 最短路が拠点を通り抜けない（§2-1）ので**自然に同じ**になる。別の規則を書かない |

### 3-3. `Dest`

`Dest` は **マス Id** に変える。`Dest.Home`／`Dest.Portal`／`Dest.Deep(lane)`（経路のいちばん奥）は残す。
画面の行き先の札（`Map11Orders.Where`・`CellName`）は、1-1 では**今と同じ文字列**を出す
（「北の道 2 戦目の地点」など。マスに名前を持たせ、1-1 の名前は今の `CellName` と同じにする）。

### 3-4. 画面（`Map11Main`）

`CellPos`／`NodePos`／`PortalPos` は `MapGraph` の `Pos` を読む1本にまとめる。
盤の線（`AddStrip`）と行き先の札（`Add(Dest, ...)`）は**グラフの辺とマス**から引く。
1-1 では今と同じ絵になること（スクリーンショットで見比べる・段の最後に1枚残す）。
