## 3. 予測（実装の前にここに書いてある。後から書き換えない）

### P0 —— 段0 は盤面を動かさない

一文から死文を落とすだけ。**`compare` の 305 セルは 0 件差分。**

### P1 —— 庇い100%で、庇いは **1.47 → 2.92回/戦**、引き受けは **21.4 → 約43/戦**

判定回数がそのまま成立になる（Q0-5 の 2.92 が上限）。
**ガルドの被弾は 100.8 → 約122/戦 に増える**。
**生存Tは下がるか、良くて横ばい**のはず——**庇うほど自分が削られる**ので。

**生存Tが上がったら、庇いが「他人の被弾を引き受ける」以上のことをしている**ので理由を調べる。

### P2 —— 庇い100%だけでは勝率は上がらない。**むしろ下がる行が出る**

ガルドが早く落ちると、**それ以降は誰も庇わない**。
**引き受けが増えるぶん、ガルドの寿命が縮んで総量では損をする**可能性がある。
**これが「受け流しが要る」ことの実測になる。**

### P3 —— ゴルムに並ぶのに要る N は **3〜4**

`harm.md` の実測から: ガルドは 3.48T で 100.8 受ける ＝ **1ターンあたり約29点**。
ゴルムとの差 **1.46T** を買うには **約42点**を消す必要がある。
**致命打の 57.1% が単体**で、第四・五波の敵の単体は 12〜24 なので **1回あたり平均15点前後**。
**42 ÷ 15 ≒ 3回。** 庇い100%で被弾が増えるので、**実際にはもう少し要る**。

**ただし N は §5-2 の決め方で段1 の実測から決める。この予測は当否を見るだけで、線には使わない。**

### P4 —— **群A（34行）と群C（2行）で符号が分かれる**

- **群A（34行）** —— 受け流しの効果だけ。**ガルドの生存Tと死亡率が動く**
- **群B（5行）** —— ガンは `Stoic` が横流しするので**ガルドは強くならない。隣のアタッカーが強くなる**
- **群C（2行）** —— 上に加えて**構えたターンの被ダメ半減がガルドに乗る。ここだけ跳ねる**

**群Aが動かずに群Cだけ跳ねたら、受け流しは効いておらず中継だけが効いている。** 逆も然り。
**行の内訳が答えを持っている。**

### P5 —— **ゴルムと同じ生存Tになっても、性格は別物のまま**

ゴルムは **HP150 ＋ 回復 61.1/戦**（外部補充）、ガルドは **HP100 ＋ 回数だけ**（`Stoic` で外部補充が永久に無い）。
**同じ生存Tに並んでも、ゴルムは編成が支えれば伸び、ガルドは天井がある。**
**ガルドの回復が 0.0 のままであることを確認する**（受け流しは回復ではない）。

### 4-3. 段2 —— 受け流し ＋ 構え ＋ 振り替え

3. **攻撃力アップを受け流しの回数に振り替える。** `RedirectGainTrait` の

   **Q0-7 のとおり基底クラスなので、敵の殉教者に及ばないことを確認する**

**受け流しが消費される順序を明記する**——庇った一撃も、素で狙われた一撃も、
**どちらも受け流せる**（第135期の V2 の形。**V1 では死因に届かない**ことが実測で出ている

- 強み「味方への攻撃を肩代わりし、その傷のぶん強くなる」
- 欠点「味方全体に配られる強化も弱体も自分には乗らず、隣接する味方へそのまま流れる
  （1体を選ぶ回復・強化は受け取れない）」

**「その傷のぶん強くなる」を受け流しに置き換える。**
**「自分からは攻撃しない」を欠点に足すかはポンに確認する**（カドの `Immobile` と同じ形になる）。
