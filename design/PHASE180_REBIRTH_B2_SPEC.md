## §1. 泥人形ムド —— 「暴発」（怒りの連撃カウンター）

### 1-1. 何に変えるか

現行: `Rage`（被弾**量**→攻上昇・上限なし）＋ `Hex`（殴った敵に呪い）。
ポンの評価は「死に際で攻40強・薙ぎ化しても次ターンに落ちる・守ると育たない」。
HPが燃料と寿命を兼ねる構造が原因なので、**量ではなく回数を溜め、手番を待たず吐き出す**形に変える。

**新特性 `TraitId.Erupt`（暴発）:**

1. ムドが**被弾を1回受けるたび**、怒りカウンタ +1（数える集合は 1-3）
2. カウンタが**閾値に達した瞬間、その場で割り込んで暴発**する:
   カウンタと同数の**単体攻撃を連続で放つ**（1発＝素攻＋上乗せ）
3. 暴発の**1発ごとに固定量を回復**する（`ctx.Heal` 経由 ＝ 渇きに封じられる。これは仕様）
4. 暴発したらカウンタは 0 に戻り、再び溜め始める
5. **倒れたら不発**（溜めた怒りは消える。死体は暴れない）

6. **マイナスも差し替える**: 被弾を1回受けるたび（数える集合は 1-3 と同一）、**泥が散って
   隣接する味方の攻撃力が −`SmearPerHit`**（恒久累積）。現行の「素の攻撃力がほぼ無い」は
   定数型で判断を生まないため、被弾駆動の近隣加害へ変える。狙いは**ウツが読み手になる**こと
   ——泥は被弾のたび細かく累積するので、ハネの一括−2（1発に届かない）と違いウツの発数へ届く。
   ネルの漏れ（開幕・全体一括）とも供給の形が違う。下げは `AtkBonus` を直接減らし、
   ウツの下げ幅と**同じ帳簿に合流させる**こと（Phase 0 Q0-9）。ムド自身には効かせない

- **`Rage` はムドから外す**（攻上昇は廃止）。`RageTrait` / `RageRule` は対照として残置
- **`Hex` は1文字も触らない。** 暴発の各発は独立した単体攻撃なので、
  呪い共有（`singleHit` のみ反応）が既存実装のまま1発ごとに走る——
  「殴った敵から順に呪われ、暴発が呪いで染みる」はこの期の狙いの絵
- カドとの対比が説明の軸:「**カドは殴られるたび返す（範囲・即時・定額）。
  ムドは溜め込んで爆ぜる（単体・満期・一括）**」

### 1-2. ノブ（`EruptRule`・測る前に固定）

| ノブ | 初期値 | 意味 |
|---|--:|---|
| `Threshold` | **3** | 何回の被弾で暴発するか（ポンの指定:「跨いだ瞬間即暴発・細かく」） |
| `SwingBonus` | **5** | 1発＝素攻(3)＋この値＝**8**。3発で24・上限まで溜めても軛(25)を1発も跨がない |
| `HealPerSwing` | **2** | 暴発1発ごとの回復。3発で6 |
| `SmearPerHit` | **1** | 被弾1回ごとの隣接味方の攻低下（泥散り）。第106期実測の被弾 7回/戦なら隣は −7 前後 ＝ ウツなら発数+2、普通の駒なら純損 |

較正の根拠（紙・戦闘0回）: 第106期 Phase 0 の実測はムドの被弾 **7.03回/戦**。
`Threshold = 3` なら1戦あたり暴発 **2回強**＝計 6〜7発 × 8 ＝ 48〜56点＋回復 12〜14。
現行の「死に際の一撃 攻40前後」と同じ桁を、死なずに分割して吐く設計。
**この3値の掃引はこの期ではやらない**（第106期 P5 と同じ穴に落ちない。振りたくなったら次の期）。

### 1-3. 「1回の被弾」に数える集合（ここが第106期との差分）

`RageMode.Count`（回数→**攻上昇**）は第106期に測定済み: Gain=3 は棄却（拒否権3行）、
Gain=5 は保留のまま閉じていない。今回は変換先が攻上昇ではなく**発数**なので別機構だが、
当時の懸念「**毒の刻みと一撃30が等価になり、細かい被弾を稼ぐのが最適解化する**」
（`RageTrait` の doc コメント）はそのまま効く。よって:

- **数える**: 敵の攻撃・**味方の刃**（ボルグの巻き込み・カドの反撃巻き込み等）。
  後者を数えることで「加害型マイナスの隣がムドの餌」という同席理由を作る
- **数えない**: 毒・燃焼の**刻み**（tick）と自傷。刻みは時計であって出来事ではなく、
  数えるとメトロノーム式に勝手に育つ
- 判定は `HexTrait.OnDamaged` の既存の弾き方（`source is null / ReferenceEquals(source, self)`
  で刻み・自傷を外す）と**同じ式**を使うこと。ムドの2特性で「1発」の定義が割れると読めなくなる
- Phase 0 で既存の計数（`RageFiresNoSource / FromAlly / FromFoe`）から内訳を出し、
  刻みを外すと1戦の被弾が何回になるかを**実装前に**書く

### 1-4. 実装の置き場所

- 暴発は `OnDamaged` の中から `ctx.PerformAttack(self, …)` を**カウンタ回数ぶんループ**する。
  ヨミ（`DisplacedTrait` の割り込み）と同じ経路で、**`SwingTurn` にも engine にも触らない。**
  ウツの `ModifyHitCount` は手番専用なので使わない
- **再入禁止**: 暴発の連撃中にムドがさらに被弾しても（呪い共有の跳ね返り等）、
  カウンタは積むが**入れ子の暴発は起こさない**（フラグ1本）。暴発を抜けた時点で
  閾値以上なら…も**発火しない**（次の被弾まで待つ。「被弾が引き金」を崩さない）
- 標的は1発ごとに取り直し（ウツと同じ）。傷・毒・上限（軛）・庇い・反撃も1発ごと
- 台本には `Attack` / `Damage` が1発ずつ並ぶこと（束ねない）。再生側は maxRun の計数で確認
- `UnitCatalog.Mudo`: Traits `{ Erupt, Hex }`、PlusText/MinusText/Flavor を書き替え。
  文案（ポン確認前提の仮）: プラス「殴られた回数を溜め、閾を越えた瞬間その場で同じ回数だけ殴り返す」
  ／マイナス「殴られるたび泥が散り、隣の味方の得物が鈍る（攻撃力低下）」
  （素攻の低さは差し替え後もステータスが語る。速さ低下は読み手が盤面に0なので採らない——
  逆位が二度棄却済みで、速さを読む機構が無い）

## §2. 澱み喰いのヴィオ —— 「吐き戻し」（毒の運び屋）

### 2-1. 何を足すか

現行 `Blightfed`: `OnTurnStart` に味方全員の毒を吸い上げ、層×4 を攻上昇（恒久）。
chain-in（グザ・スィドの漏れ）は既にあるが chain-out が無く、「強くなって殴るだけ」。

**足すのは1つ**: 吸った層を**腹（在庫カウンタ）**にも記帳し、
**手番の攻撃が命中したとき、腹から最大 `SpitMax` 層を標的に毒として移す**（在庫を消費）。

- 攻上昇の現行式は**触らない**（変数を1つに絞る。吸う→攻、は据え置きで、吐く経路だけ足す）
- 敵に付いた毒はミオ（増幅）・ラウ（死亡時飛散）・ベニ（喰って回復）の餌 ＝ 連鎖の輪
- ノブ: `SpitMax` 初期値 **3**（`BlightRule` として持つ）
- 腹は会戦を跨いで持ち越さない（`OnCarryOver` 対象外。Phase 0 で持ち越し系の作法を確認）

### 2-2. 既にある隠れた判断を壊さないこと

`MiasmaTrait` のコメントに記録済み: グザは**手番で撒く**（第61期移設済み）、ヴィオの吸い上げは
`OnTurnStart`。**グザとヴィオの席順で「毒の代金を誰が払うか」が切り替わる**判断が既にある。
吐き戻しはこの順序に**読み手を1人足すだけ**で、吸い上げの発火位置は動かさないこと。

## §3. 鬨の号令ガン —— 「叩き起こし」

### 3-1. 何を足すか

現行 `Rally`: 開戦+4全体／前ターンに手番を差し出した味方に+8（`SurrenderedTurn` 判定・
カドの不動は対象外）。手番は攻4の通常攻撃で空回り。

**足すのは1つ**: **ガンの手番の攻撃が終わった直後**、前ターンに手番を差し出した味方
（Rally の支払い条件 `SurrenderedTurn` と**同じ判定**を使う）のうち**1体**が、
その場で割り込んで1回攻撃する（`ctx.PerformAttack`・ヨミと同じ経路）。

- 選び方は決定的: **現在攻撃力が最も高い1体、同値はスロット番号の小さい方**（`PickOne` 禁止）
- 発火はガンの手番1回につき最大1体（ガンが痺れ・まどろみで振れなかったターンは発火しない
  ——号令は声を出せる者の仕事）
- Rally が同ターン頭に払った +8 が、その一撃でそのまま使われる ＝ 号令の絵が完成する
- 連鎖: クグ（縛め）・バン（まどろみ）が「ガンで回収できる資源」になり、
  溜め改 (クグ×バン×ガン) の絵が変わる
- ノブは置かない（発数1・固定）。カドが無償で発火しないことは自己検査に入れる

## 予測（実装前に宣言。編成表の実駒を数えて書くこと——軸名で書かない）

方向のみ指定する。Claude Code は `Presets.Compare` の該当行を数えて具体化すること:

- ムド在席行は「勝ち方」が動く（残存・全滅勝ち）。第4波（軛）は1発8が上限に切られないため下がらない
- 泥散りは、ムドの隣が火力駒の行を下げ、ウツ・号令等の攻上昇供給が厚い行では相殺されて小さく出る（隣接の実駒を数えて書くこと）
- 庇い持ち（ガルド・セッキ）同席のムド行は暴発回数が減る＝上がり幅が小さいか下がる
- ヴィオ在席行は敵の毒総量が増え、ベニ・ミオ・ラウ同席行だけ二次的に動く
- ガン在席行のうち IdleTurn 供給（クグ・バン・トウ）がいる行だけ動き、いない行は動かない
- 3枚のどれも含まない行は **±0.0**
