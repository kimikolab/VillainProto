## 0. 目的

カタの代金（隣の味方に感電）を**読んで使う駒**を増やす。最初の1体として、転生候補の責め苦のシガを作り直す。

シガは今のままでも雷の編成と噛み合う形をしている:
- 速3でカタ（速6）より遅い＝カタが付けた感電をその手番のうちに弾かせられる（R317）
- 動けない敵を狙う＝S2 で痺れた敵が獲物になる

そこに3つを足す・整える:
1. **鞭＝常時薙ぎ**（1振りで複数の感電を同時に弾かせる）
2. **追い打ちを「2倍の1発」にまとめる**（火力は変えず、演出を1発にする）
3. **電気鞭**: 感電している間は怖気づかず、打った敵に感電を移して自分の感電を使い切る

## 1. 今のシガ（第216期）

- HP52・攻9・速3・単体。札 `Torment`（責め苦）・`Shame`（見せしめ）
- 責め苦: 動けない敵（痺れ／その手番を失った／組み付き／竦み・二重条件）を殴ると**同じ重さの追い打ち**をもう1発（加算）。動ける敵を殴ると自分が1ターン動けない
- 見せしめ: 動けない敵を優先して狙う。追い打ちが出たとき、その敵に隣接する敵全員が竦む（次の手番を1回失う）。ハメ防止あり（竦みが明けた駒は次の自分の手番まで竦まない）

## 2. 新しいシガ

| 項目 | 内容 |
|---|---|
| 数値 | HP52・攻9・速3（変えない） |
| 手番 | 動けない敵を優先して**鞭で薙ぐ**（攻撃型は常時 `Sweep`） |
| プラス1 | **動けない敵には2倍で入る**（薙ぎで当たった敵ごとに判定。今の追い打ちの分をまとめたもの・加算で「攻撃力＋攻撃力」） |
| プラス2 | 動けない敵を打つと、悲鳴でその敵の隣の敵が竦む（**1手番に1回**。主目標が動けないならその敵、でなければ当たった動けない敵のうち席番号の最小）。ハメ防止は今のまま |
| プラス3 | **電気鞭**: 手番の頭で感電していれば、その一撃は怖気づかない。一撃を打ち終えたら（弾けた連鎖の処理の後）、**当たって生きている敵すべてに感電**を付け、**シガ自身の感電を消す**（弾けさせずに消す・放電しない） |
| マイナス | 感電していないときに、**主目標が動ける敵**だと怖気づいて1ターン動けない（薙ぎで巻き込んだ敵は数えない） |
| フレーバー案 | 「縛られた的しか殴れない臆病者。雷に打たれている間だけは、怖さも痺れて感じない。」 |

- 旧札（`Torment` / `Shame`）は**削除しない**（対照）
- 薙ぎの巻き込み先は既存の表どおり（標的と同じ列の全員＋中央）
- 2倍は「強化を受けた攻撃力」を2回足す形（第29期以降の「増幅は加算」の作法のまま）

## 4. Phase 0

- **Q0-1 標的選び**: 見せしめの「動けない敵を優先」が薙ぎの主目標の選び方にも効くか（今は単体攻撃の段にある）。効かないなら薙ぎにも通す
- **Q0-2 2倍と追い打ちの差**: 追い打ち（2発）と2倍（1発）で結果が変わる所を列挙する——破片・軛（単発上限25）・身構え・庇い・受け流し・感電の起爆（2発なら1発目で弾けて2発目は弾けた後）・棘の反撃（2回鳴るか1回か）。G1 の測定で差が出たらこの一覧で説明する
- **Q0-3 電気鞭の判定の時点**: 「手番の頭で感電している」を、シガの手番の中のどこで読むか。自分の一撃で自分の感電が弾けることは無い（同じ陣営の一撃ではない）ことの確認
- **Q0-4 感電の痺れの連続**: G3 で、同じ敵が何ターン続けて手番を失いうるか（感電 → 弾けて痺れ → 電気鞭でまた感電 → 次の一撃でまた痺れ）。手で1例を追う
- **Q0-5 過去の測定**: `design/` を grep（シガ・責め苦・見せしめ・薙ぎ化の過去の実験。第185期の報告の結論を引く）
- **Q0-6 台**: §6 の台の席を決め、駒を数えて予測を書く

## 5. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** シガのいない行は 0 セル。G0 は規定化後の盤面と台本が一致
- **P2** G1 は G0 と勝率 ±2pt 以内（火力は同じ）。差が出るならQ0-2 の一覧のどれか
- **P3** G2 で「1振りで弾かせた感電の数」が増え、敵の痺れ・失った手番が増える
- **P4** G3 で怖気づいた回数が減り、シガが敵に移した感電から次の連鎖が起きる。**味方側に残る感電（カタの代金）が減る**
- **P5** G3 で同じ敵が2ターン以上続けて手番を失う戦が出る。G3H で減る
- **P6** シガが前列の席では、敵に殴られて感電が弾け、自分が痺れる代金が大きい（最良の席は後列に寄る）
