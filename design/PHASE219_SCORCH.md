## 実装の形（測る前に固定）

- **器**: `EmberRule`（熾火の窓口）に `Brittle`（%）と `BrittleAllies`（味方にも掛けるか）を足す。**既定 0 ＝ F0**。版は `EmberRule.Scorched("F1".."F4")`。**`Run` の引数は増やさない**（第154期・第178期の作法）。
  `docs/rules.md` の `EmberRule` の既定値の列が変わる（`Brittle = 0, BrittleAllies = False` が足される）——**値は脆さなしで、盤面は動かない**。
- **判定**: `ApplyDamageBody` の §1 の直後に1箇所。条件は「脆さ > 0 ／ 中継でも共有でもない ／ 陣営が対象（F1・F2 は敵だけ）／ 燃焼の残りターン ≥ 1 か、燃焼の刻みそのもの」。量は `amount + ⌈amount × X / 100⌉`（**加算・切り上げ**）。
- **反転**: `InverseHeal` の入口に1箇所（F3・F4 で味方が燃えていれば、伸びた量をそのまま回復に）。
- **乱数を引かない**。脆さ 0 なら比較1つで抜ける。
- **台本**: `Damage` に表示専用の欄 `BrittleExtra`（脆さで足した名目・破片や軛で削られる前）。`shockdigest` は後から足した欄（`SkipProps`）を指紋から外すので、F0 の台本は第218期の M5 と比べられる。
- **計数**: `BattleResult.Brittle`（`BrittleLedger`）——脆さの前の量・足した量・回数を [陣営, 経路] で。経路は 攻撃 ／ 雷 ／ 叩きつけ ／ 放電 ／ 反撃・反射 ／ 毒の刻み ／ 燃焼の刻み ／ その他。反転・板との重なり・ホタの分。燃焼の在り方（上の Q0-3 の表の出どころ）は Phase 0 で既に足した（計数のみ・`compare` 305 セルが前段と全文一致）。

## 実装（予測のコミットの後）

- **器**: `EmberRule` に `Brittle`（%）と `BrittleAllies`。既定 0（F0）。版は `EmberRule.Scorched("F1".."F4")`。`Run` の引数は増やしていない。
- **判定は2箇所**: `ApplyDamageBody` の §1 の直後（入口の族の最後）と `InverseHeal` の入口。量は `amount + ⌈amount × X / 100⌉`。**中継（巨躯・分かち）と呪いの共有には掛けない**。
- **燃焼の刻みそのものは「燃えている」と数える**（`_burnTickSelf`・1回の呼び出しにだけ効く札）——最後の刻みは残りターンを 0 にしてから刻むため。
- **乱数を引かない**。脆さ 0 なら比較1つで抜ける。
- 表示専用: `Damage` の `BrittleExtra`（破片・軛で削られる前の名目）。計数専用: `BattleResult.Brittle`（[陣営, 経路] の前の量・足した量・回数／反転／板との重なり／ホタ／軛に切られた分の見積もり）。
- 診断: `scorch phase0 / run [a|b|p5|yoke] / check`。**`shockdigest` は後の期に足した種類と欄（`SkipKinds` / `SkipProps`）を指紋から外す**。

## 判断の材料（ポン向け・線は置かない）

1. **ポンの観察「燃焼はかさ増しになっている」への答え**: 敵だけの脆さ（F1・F2）は**燃焼を読む駒のいない行で最も効く**——`compare` で上がったのはゾトの死軸とボルグの行（+17〜+33pt）で、**燃焼の書き手自身の価値が上がる**。
   ベニ・ミオ・カタの雷の編成では、脆さはほぼ全部が **雷・放電・毒の刻み**の上に乗り（攻撃は 1%）、**1戦 213〜224 点**足される——ただし台は倍率 150 で天井なので、**勝率ではなく決着の短さ**（4.0 → 3.3 ターン）として出る。
2. **敵味方の両方（F3・F4）は `compare` の火の付く行で純損**（−4.0 ／ −4.9pt）。燃焼の書き手3枚が3枚とも味方にも火を書くから（R324）。
   ベニの結界の内側は回復が増える（H2 P2 で +86 /戦）が、**火を分けられた味方は敵の一撃でも脆くなる**ので、H2 X字は F4 で全員生存 45.0 → 24.4%。ホタの行は F3 で倍率 150 の勝率が 41.2 → 27.6。
3. **第四波が最も動く**（F2 +20.8）——死軸の行が軛の重装兵を倒せるようになる。脆さの半分以上は軛に切られているのに、残りで境目を越える（R325）。
4. **切り上げで小さい刻みが大きく伸びる**: 毒 1 は F1 でも 2（O4 の毒）、燃焼 6 は F1 で 8。**F1 は名目 25% だが刻みには 29〜33% で効く**。
5. **情報セルは F1 −5・F2 −10**（天井へ寄る）。F3・F4 は +3〜+4。
6. **ツギの燃えやすい板との掛け算はほとんど起きない**（1戦 0.1〜0.8 回）——ベニ・ボルグ・ゾトは持続より早く点け直す（R312 のまま）。
7. ミオのフレーバーは2案（前段の節）。**`units.md` は今のフレーバーのまま**。
