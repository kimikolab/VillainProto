# 逸らし（divert）

`dotnet run --project BattleSim -c Release 0 divert [絞り込み]` の出力。
**docs/ には置かない**（標準出力で読むだけ）。seed 0..199。数字は特記なければ**1戦あたりの平均**。

`Stages` / `Columns` は触っていない。`CompareBuilds()` には**2行足した**（カドの有無で分けた対）。

| 列 | 中身 |
|---|---|
| 発火 | 逸らしの発火回数/戦。**0 になっていないことが受け入れ基準4**（配置探索が機構を無効化していないか） |
| 外し | 味方から外した標の回数/戦・**外した相手の内訳** |
| 焦点 | 敵に付けた回数/戦（`新規` は新しく標が付いた回数）・**付けた敵の内訳** |
| 焦点数 | 発火時点で**標を持っている敵の数**の平均/最大。**敵の標は消えないので焦点は自分で溶ける** |
| **焦点の効き** | **味方の単体振りのうち標持ちの敵に当たった割合**（`引き` は engine の鎖が実際に差し替えた回数） |
| **代金の効き** | **敵の単体振りのうち標持ちの味方に当たった割合**（同上） |
| 自傷 / 寿命 | ソラが受けた被弾/戦 ／ ソラが最後に盤上にいたターン |
| カド | カドの生存ターンと干渉回数（＝反撃を含む「盤面を動かした回数」）。カド入り台のみ |

> **「焦点」と「焦点の効き」は別の列。** 標を付けた回数は成果ではない
> ——味方がそちらを殴らなければ意味がない。**撃破順（§2）が本命の指標。**

## 1. 主表（`TargetCount = 1` と陽性対照3本）

`素体` = ソラと**数値・型・速さが1つも違わず特性だけを持たない駒**（対照1）。
**これが機構の帰属を取る唯一の窓口**——`TargetCount` を下げても外しと自分への標は止まらない。
`代金なし` = `DivertRule.SelfMark = false`（対照2）。**自分に標を付けない版**で、
「味方の標を外す」＋「敵に焦点を作る」だけが残る——**代金の分離**。
`4体` = ソラを外した4体版（対照3。**第21期の飽和検査**も兼ねる）。

**標に依存しない切り方**で数えているので素体とそのまま引き算できる。

## 4. 掃引（`TargetCount` 1 / 2 / 3）

**`TargetCount` は「集中」と「被覆」を取り替えるノブ。** 標持ちが増えると
`p_t`（無作為の主目標が既に標持ちである確率）が上がるので**総量は増える**が、
1体あたりの取り分は薄まる。**勝率が動かないのは2つが打ち消し合うから**で、
ノブが機構を動かしていないからではない（`効き・味方` の列で確かめる）。
