# 業（scapegoat）

`dotnet run --project BattleSim -c Release 0 scapegoat [絞り込み]` の出力。
**docs/ には置かない**（標準出力で読むだけ）。seed 0..199。数字は特記なければ**1戦あたりの平均**。

`Stages` / `Columns` / `CompareBuilds()` は触っていない。**業は測って採用しなかった**ので、
測った2編成はこの診断のローカル（`SgRows()`）にある（`overbear` の `ObRows()` と同型）。

| 列 | 中身 |
|---|---|
| 引き取り | 移した延べ量/戦・**種類ごとの内訳**・取った相手の内訳 |
| 空振り | 引き取れる種類が盤面に無くて何もしなかった回数/戦（`満杯` は全種類を既に背負っていた回数） |
| 種類数 | ゴウが背負っている種類数の 平均 / 最大（引き取りの**後**に数える） |
| **到達** | **閾値に初めて達したターン**（達した試行だけの平均）。`未達` が一度も達しなかった試行の割合 |
| 成立率 | 閾値を満たしていたターン数 ÷ ゴウが生きてターン頭を迎えた回数 |
| 転写 | 発揮した回数/戦・**付けた種類の内訳** |
| **転写の効き** | **毒燃**＝業が書いたぶんに帰属する継続ダメージ ／ **痺**＝飛ばした敵の手番 ／ **標**＝味方の単体攻撃が引かれた回数 |
| 自傷 | ゴウが継続ダメージで受けた量 / 痺れで失った手番。**寿命**はゴウが最後に盤上にいたターン |
| 味方 | **ゴウ以外の味方**が継続ダメージで受けた量 / 失った手番。**救済は素体との差で読む** |

> **「転写」と「転写の効き」は別の列。** 付けた回数は成果ではない
> ——敵が次のターンに死ぬなら毒を付けても意味がない。

> **「自傷」と「味方」は絶対値では帰属が取れない。** 瘴気の毒はゴウが引き取らなくても
> 味方全員に載るので、**素体版との差**でしか機構のぶんは割れない。

## 0. 検算 —— 差分は業だけに閉じているか（受け入れ基準2）

- **基準2**（ゴウを含まない 63 行が `ScapegoatRule` の値に対して不変）: **315 セル中 0 件の食い違い**（63 行 × 5 波・`Threshold` 1 対 9）
- **監査は盤面を動かさない**（`Audit` の有無で `compare` が変わらない）: **315 セル中 0 件の食い違い**（63 行 × 5 波）
- **基準1**（新駒を編成に入れない状態で `compare` が `docs/balance.md` と完全一致）は
  `compare` の全文で確認済み（**250 セル中 0 件**・業は `UnitCatalog.All` にも
  `CompareBuilds()` にも載っていないので、`docs/balance.md` は1バイトも動かない）。
  engine に足した計数のフック（`TickStatuses` の2箇所・行動順ループの痺れ分岐・
  標の引き）は**すべて `ScapegoatActive` で短絡**し、控えのカウンタは誰も読んで分岐しない。

## 4. 痺のある台（§7-3 の観測。`CompareBuilds()` には入れていない）

採用2行はどちらも痺の供給を持たない。**痺を足すと台が 20.0% に潰れる**ので、
「痺を引き取ると手番が飛んで転写できない」は診断のローカルでしか測れない。
