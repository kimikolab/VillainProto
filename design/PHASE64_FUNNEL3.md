## 3. 判定基準（**測る前に書いた**）と自己検査

### 3-1. 主判定の式を変えた（**理由つき**）

第62期の式（`reseat` の帯の峰）は**台**を測っていた。第63期の式（測れる席で符号が割れる）は
機構を測っているが、**「判断がある」ではなく「罰の席がある」を測っている**——
第63期の行2 は測れる3席が **+13.6 / +2.6 / +14.8** で、**席の選び方で 12.2pt 動く**のに
「割れない」と判定された。**置き場所で 12pt 動く駒に配置の判断が無いとは言えない。**

> **Q2''（幅・主判定）: 測れる席の帰属の最大と最小の差が 5.0pt 以上。**
> **閾値 5.0 は第46期の配置の採否閾値**（席を1つ動かして 5.0pt 上がるなら動かす価値がある、の同じ数字）。
> 素体を引いてあるので台の配置感度は消えている。

**符号が割れるか（第63期の式）は副判定として併記する。採否には使わない。**

**第63期の値をこの式に通すと**（seed 600..999 の測れる席）:
吐き戻し **9.2** / 縛め **12.2** / 火選り **16.0** / 罠（カド版）**7.3** ——**4行とも通る。**
**これは予測であって証拠ではない。** 条件は **seed 1000..1399 で3行とも 5.0 以上、かつ 0..199 で再現**。

#### Q2'' に対する (b) の詳細（**通らない可能性が実在することを示す**）

**第63期の4行はすべて 7.3pt 以上**なので、そこには「幅 5.0 未満」の例が無い。

どの席に置いても帰属は体の値段だけになり、幅は 0 付近に潰れる。**

### 3-4. 採る席の決め方（**測る前に固定**）

**選定規則で決まるのは行とヌキに差し替える枠までで、席は決まらない。**
第62・63期と同じ作法で決める（**帰属を見てから選ばない**）:

> `funnel reseat` の粗探索（seed 1000..1049 の120通り）で**上位5通り**を取り、
> その中から**横流し（強化の横取り量 ÷ 総強化量）がいちばん多い席**を採る。
>
> **【測った後の追記・§4-1】この §3-4 は実際には使わなかった。** `reseat` は120通り＝
> **他の4枚も入れ替える**ので、選定規則（§1-6）が保証した「測れる席が3つ以上」が壊れる
> ——行1では選定規則の族が 素体 54.3〜63.6%（測れる席5）なのに、`reseat` 粗2位の族は
> **全席が床**（24.6〜28.8%）だった。**採ったのは選定規則が決めた形そのまま
> （差し替えた枠の席）で、席の選択の自由度はゼロ。** 経緯と実測は §4-1。

> 理由は第50期と第53期——**`reseat` は勝つ席を探す道具であって機構を活かす席を探す道具ではない。**
> 勝率だけの1位を採ると、配置探索が機構を無効化した席（第49期の業改は引き取りが 0.00 回/戦になった）を
> 選んでしまい、**Q1 の分子が消える。** 上位5の内部差は第45期の実測で中央値 2.15pt なので、
> その帯の中で機構が最も発火する席を採るのは配置の最適化を壊さない。

**罠行と陰性対照は `reseat` を回さない**（どちらも手で組む行で、勝率で採らない）。

§3-4 に書いた「`reseat` の上位5通りから横流しが最多の席を採る」を実際に回したところ、
**選定規則が保証した『測れる席が3つ以上』が壊れる**ことが分かった。

`reseat` は **120通り＝他の4枚も入れ替える**ので、`funnel pick` が測ったのとは**別の配置族**になる。
行1（号令）で実際に起きたことは決定的だった:

| 配置族 | 素体の5波平均（前1 / 前3 / 中央 / 後1 / 後3） | 測れる席 |
|---|---|--:|
| **選定規則の族**（他の4枚は元のスロット） | 59.5 / 63.6 / 62.7 / 58.9 / 54.3 | **5** |
| `reseat` 粗2位の族 | 27.3 / 25.8 / 24.6 / 26.9 / 28.8 | **0（全席が床）** |

`reseat` の粗2位は **V1 で 67.4% / 素体で 25.8%（帰属 +41.6pt）** という席だが、
**それは「横流しが無いと台が死ぬ配置」を探し当てただけ**で、
帰属が測っているのは配置の判断ではなく**台が生き返ったこと**である。

> **`reseat` は「勝つ配置」を探す道具なので、素体を床に落とす配置を平気で選ぶ。**
> 素体を引いて機構を測る器具とは**目的が逆を向いている。**
> **席は選定規則が決めた形のまま（差し替えた枠の席）を採った**——選ぶ自由度がゼロで、
> 第62・63期の「席の選び方で結果が動く」余地もここで消える。

> 追い打ちは `ctx.PerformAttack` を通るので、`Attacks == 0` のハギは**本当に一度も発火していない**
> （新定義でも 0.03 のまま）。**「ターン外に振る」で一括りにせず、経路が `PerformAttack` を通るかで分けること。**

### 9-2. **`reseat` は「素体を床に落とす配置」を平気で選ぶ**（第64期）

`reseat` の粗2位は行1で **V1 67.4% / 素体 25.8%（帰属 +41.6pt）** を出したが、
**その配置族は5席とも素体が床**（24.6〜28.8%）だった。同じ5枚でも、
選定規則の族（他の4枚を元のスロットに残す）では素体 54.3〜63.6% で**5席とも測れる**。

> **`reseat` は勝つ配置を探す道具で、素体を引いて機構を測る器具とは目的が逆を向いている。**
> **素体を引く器具を使う期では `reseat` を配置の決定に使わないこと**——
> 使うと「機構が無いと死ぬ配置」が選ばれ、帰属が測るのは**台が生き返ったこと**になる。
> 第50期「`reseat` は勝つ席を探す道具であって機構を活かす席を探す道具ではない」の**逆側**である。

### 9-3. **自由度を規則で潰すと符号が反転した**（第64期・この期の本体）

第62期（+1.8 / +12.2 / +8.9）・第63期（+1.7 / +13.6 / +5.2）は**3行とも正**だったのに、
**行・枠・席の選び方を測る前の規則で固定すると 3行とも負**（−3.8 / −8.8 / −18.4・両帯で再現）。
自由度は3つあった:

    どの行を試験行にするか      第62期「供給が大きい行」→ 第64期「供給が大きく、かつ測れる席が3つ以上」
    どの枠をヌキに差し替えるか  第62期「寄与最小。ただし主題が壊れるなら2番目」→ 第64期「寄与最小」
    どの席を採るか              第62期「reseat 上位5の中で発火が最多」→ 第64期「差し替えた枠の席」

**3つとも「もっともらしい理由」で第62期は緩めていた**（とくに枠の2番目選択は
「クグを抜くと縛めが消える」という**正しい**理由だった）。
**正しい理由でも、結果を見てから緩めれば同じことになる。**

> **系: 3回測って通らなかった機構では、緩めた条件を1つずつ数えること。**
> この期に潰した3つの自由度は、どれも**第62期の時点では自覚されていなかった。**

### 9-4. **同じ規則が、移す通貨の符号で正反対に働く**（第63・64期）

逆しま（ウツ）は `AtkBonus` の**符号だけ**を読み、負なら3倍・正なら半減する。

    弱体を横流しすると  ウツから**燃料**を奪う   → **−73.0 / −60.9pt**（第63期 §11-3）
    強化を横流しすると  ウツから**毒**を奪う     → **+19.3 / +10.3 / +16.4pt**（第64期 Q5）

**符号は宛先がウツかどうかだけで決まる**——ウツが宛先の席だけが −7.8 / −7.1 で、他の3席は正。
**「通貨を移す機構」は読み手にとって奪う機構だが、その読み手にとって通貨が資産か負債かで符号が決まる。**

### 9-5. **陰性対照は「判定式が何でも通すわけではない」を1行で示す**（第64期）

強化の在庫が 0 の行にヌキを置くと、**5席 × 5波 × 400 seed が素体と1セルも違わない**（幅 0.0pt）。
横流しは**量を1点も増やさず行き先だけを動かす**機構なので、動かすものが無ければ何も起きない。

> **主判定を新しく作った期は、その判定式が落とす行を1本、同じ表に並べること。**
> 「通った」だけを並べた表からは、判定式の厳しさが読めない。
