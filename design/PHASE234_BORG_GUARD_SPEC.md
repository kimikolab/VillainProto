## 1. 目的

燃焼の軸のコンセプトは **「耐えて、燃え上がり、焼き尽くす」**（ポンの判断）。

| 段階 | 駒 | 役割 |
|---|---|---|
| 耐える | ボルグ | 前で殴られ、火の入口になる（**この期**） |
| 燃え上がる | ヒヨ | 燃えている味方を毎ターン育てる |
| 焼き尽くす | ホタ | 育った火力を4倍の貫きで叩き込む |

第233期で分かったこと:

- 3体 ＋ シオ＋ササ で主判定（九 / 新兵 × 200/200）の全員生存 97.5%。**ササ（一撃を7に切る）とシオ（崩れかけを下げる）で耐久を外付けしていた**
- 3体だけでは前列が1ターン目に落ちる（前列に1ターン約200）。**穴は耐久**
- **ボルグは上位10組中9組で後3に置かれ、被弾0**。「耐える」役が空席
- ボルグの火は敵に 4.2 回・味方に 9.6 回/戦。**燃えている敵は1ターン 0.6〜0.8 体**しかいない
- 与ダメの 82% はホタ。火力と味方側の火は足りている

→ **ボルグを、前で殴られて火を点ける盾にする**。ササの役割を燃焼の3体の中に持たせ、同時に「燃える敵が少ない」を直す。
**薙ぎは残す**（大剣持ち・ブロッカー兼アタッカー）。

## 2. 版

すべての版で、ボルグの巻き込み（`Splash`）・火の粉（`Cinder`）・攻撃力・速さ・薙ぎはそのまま。札の差し替えで作り、`Run` の引数は増やさない。

| 版 | 追加 | 内容 |
|---|---|---|
| G0 | なし | 第233期の規定（対照） |
| **G1** | **火の鎧** | ① 敵の攻撃を受けると（種別を問わない・攻撃1回ごと）、**被弾の後に**、殴った敵と自分に火が点く ② **燃えている間、受けるダメージが半分**（切り上げ） ③ **ボルグは火に焼かれない**（ホタと同じ・燃焼の刻みで HP が減らない） |
| G2 | G1 ＋ **焼け残り** | 燃えている間、倒れる一撃を受けても **HP1 で踏みとどまり、火が消える**。**1戦1回**。この被弾では ① の自分への着火をしない（殴った敵には点く） |
| G3 | G1 ＋ HP | HP 60 → **100** |
| G4 | G1 ＋ G2 ＋ G3 | 全部 |

細部:

- ① の「敵の攻撃」は敵の手番の攻撃と割り込みの攻撃。巻き込み・燃焼の刻み・毒・味方の攻撃では点かない
- ① の殴った敵への着火は、薙ぎ・貫き・全体の巻き込みで当たった場合も、**殴った敵1体**に1回
- ② の半減は、燃焼の脆さ（敵だけ）とは別。順序は既存の被ダメの族の中で、Phase 0 で置き場所を決めて報告（ササの身構えとの前後を明記）
- ③ は `EmberRule.Fireproof` が `Pyre` を見ている箇所（`BattleEngine` 2箇所）を、新しい札でも通るようにする
- ヒヨの −2（隣の燃えていない味方）は、ボルグが燃えていれば当たらなくなる（既存の規則のまま・予測で数える）

## 3. Phase 0

- **Q0-1 置き場所**: ② の半減を被ダメの族のどこに置くか（脆さ・標 +50%・据え・矢面・巨躯・破片・身構え・軛との順序）。候補の順序と理由
- **Q0-2 焼け残りの判定**: 倒れる一撃の判定を、既存の「倒れる一撃だけかわす」（セロの必死の逃げ足）と同じ箇所で取れるか。取れない場合の代替
- **Q0-3 G0 の確認**: ボルグが燃えている割合（第233期は 0%）・ボルグの被弾（第233期の B3-1 は 0）
- **Q0-4 台**: §5 の台の駒を数えて予測（§4）に数値を入れる
- **Q0-5 過去の実験**: 被弾で攻撃者に状態を付ける札・燃えている間の被ダメ軽減を過去に測っていないか `design/` を grep

## 4. 予測（Phase 0 の後に数値を入れて、実装前にコミット）

- **P1** ボルグのいない行は 0 セル。G0 は第233期の盤面と台本が一致
- **P2** G1 以降、**総当たりの1位でボルグが前列に来る**（第233期は後3）
- **P3** 燃えている敵/T が G0 の 0.6〜0.8 体から大きく増える（ボルグを殴った敵が燃えるので）
- **P4** 3体 ＋ 2枠（**シオ・ササ抜き**）の最良の全員生存が G0 から大きく上がる。上位の相方がシオ・ササに偏らなくなる
- **P5** G2 の焼け残りは主判定ではほぼ発火しない（一撃死は第233期で主判定 0〜26%）。本編の波で効く
- **P6** G3（HP）単独より G1（火の鎧）の差が大きい
