## 1. 目的

次の本線は燃焼の軸（焼け残りのボルグ・熾のホタ・火選りのヒヨ）。インフレに飲まれたが、ポンのお気に入りで、このゲームの顔にしたい駒たち。

- **目標**（移動軸と同じ）: **ガルド抜き**で、検証・九 / 新兵 × 敵 200/200 の**全員生存**。400/300 は負荷試験
- **ポンの方針**: **ボルグ・ホタ・ヒヨの3体だけで、燃焼に必要な要素が循環する形**にしたい（雷の編成のベニ・ミオ・カタのように）。ベニを足すとさらに強い、は可
- **ポンの懸念**: 燃焼だけでは回復が伸びる見込みが無く、耐久が微妙（3体とも HP が高くない）

この期は、**次の期でどの繋ぎを足すかを決める材料**を集める。

### 1.1 移動軸（第222〜232期）で分かった作り方（この期の見方）

- ステータスや強いスキルを盛るのではなく、**今の編成に少し足りない繋ぎ（引き金 → 効果）を1本ずつ足す**
- **循環を作る**: A が起こしたことが B の燃料になり、B の結果が A に返る
- **敵に依存する循環は序盤向き、終盤まで回る循環は味方側に作る**（敵は減る）
- **一撃死は退避や回復では防げない**（R332）。別の答えが要る
- 一撃の大きさを条件にすると、敵を重くした盤面では絞りにならない（R338）
- 席を総当たりで選ぶと、最良の席が「その仕組みを使わない席」になることがある（R333）

### 1.2 今の流れ（読み）

```
ボルグが振る → 斬った敵1体と隣の味方に火 → ヒヨが燃えている味方を育てる／ホタが4倍＋貫き → 敵を倒す → （何も返らない）
```

戻る矢印が無い。敵の燃焼を読むのは脆さ（+25%）だけ。味方の燃焼の代金（毎ターン固定）を得に変えるのはベニだけ
（第130期にホタが味方へ火を配る案は、この代金が見返りを圧倒して拒否権3で落ちた・`EmberRule` の doc）。

## 4. 相方の総当たり

- **段1**: B3 の全ての2枚の組・B4 の全ての1枚。席は組ごとに総当たりし、主判定（九 / 新兵 × 200/200 の全員生存）で選ぶ（同値は落ちた駒の数・決着ターンの順）。
  所要時間が大きすぎれば、段1 は seed を減らしてよい（何に絞ったかを報告に書く）
- **段2**: B3 の上位10組・B4 の上位5枚を、seed 0..199・§5 の全ての波と倍率で測り直す
- **R333 の対策**: 段2 の各組で、総当たりの1位に加えて**ボルグとホタが隣り合う席の最良**も並べる（燃焼の仕組みを使う席）
- **相方の役割**: 札から機械的に分ける（`derive` の結果を使う）。回復／守り（庇い・肩代わり・後備え）／火の書き手／火・脆さの読み手／状態異常の書き手／移動／その他。重なる駒は複数に入れてよい
- 表: 役割別の最良の組・上位の組に何の役割が入っているか

**読み方**: 上位に回復・守りが並べば**耐久が穴**、火の書き手が並べば**供給が穴**、どちらでもなければ**火力**が穴。
