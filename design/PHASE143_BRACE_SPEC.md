> 抑えきれなかった分を破片にして、そのターンに突き飛ばした隣の味方に付ける。**

## 0. なぜこれをやるか

### 転生の理由

- 現行のササ（散開）は `compare` 61 行のうち**在席1行**（`置き去り×分散回復`）。第106期に弾きを足して以降、
  「−35% の係数 ＋ 被弾で隣を弾く」の2文で、**弾きの受け皿（移動軸）が無い編成では −35% しか働かない**
- **破片の書き手は3枚**（ヒビ・ウケ・ウロ）で、供給の主役ヒビは **3.24T しか生きず 94.2% の戦で死ぬ**（第137期）。
  第138期の礫のガレ（最大保持者1体を砕く）は**1体に厚く積まれる供給**を求めるが、ヒビは全員に薄く配る
- **移動軸の書き手はバサ1枚に集中**していて、そのバサは次期に敵陣を掻き回す駒へ転生する予定。
  味方を動かす役をササに移す

### 体だけでは壁にならない（第136期の実測）

ガルドは HP100 で「一瞬で落ちた」。受け流し（回数制の無効化）が入って初めて **生存 7.96T・死亡 42%** になった。
ササは弾きで**前列を自分だけにする**（弾く先は「保持者に隣接しない席」優先）ので、ガルドより集中砲火を受ける。
**空いている手番を耐久に変える機構が要る。**

### 耐久と供給が同じ在庫を食い合わない形

「手番で自分に破片を纏い、弾いた味方に分ける」案は、**配ると自分が薄くなり、殴られた後は渡す分が残らない**ので落とした。
採るのは、**供給を「自分が受けなかったダメージ」から取る**形:

> 手番で身を固める → 次のターンまで一撃は N まで → **N を超えて切り落とした分**が、そのターンに突き飛ばした隣の味方に破片として付く。

- 耐久（上限）は配っても減らない
- 供給は**集中砲火を受けるほど太る**。壁として働いている場面と供給が出る場面が一致する
- タンク3枚が別々の耐え方になる: **ガルド＝回数／ゴルム＝総量／ササ＝単発**

### 弾きと切り落としの関係（**設計の要**）

```
そのターンの1回目の被弾:   N まで受ける → 超過分を切り落とす → 隣を弾く（1T1回・現行どおり）
                           → 弾いた味方に超過分が付く
同じターンの2回目以降:      N まで受ける → 超過分を切り落とす → もう弾かない
                           → 超過分は「そのターンに弾いた味方」に付く
隣に弾ける味方がいないターン: 切り落とした分は消える（自分には付けない）
```

**宛先はターンごとに1体。** 薙ぎ・貫き・全体が飛んでくるターンほど1体に厚く積まれる。

### Q0-1. `ApplyDamage` の中の順序（**最優先。ここが違うと設計が成立しない**）

Web 側が読んだ順序（**行番号は動くので確認すること**）:

1. 棘守り（カド）の肩代わり上限（`ThornGuardTrait.AbsorbCap` で**入力の段階で**切る）
2. `ModifyIncomingDamage`（脆弱ほか）
3. 庇い・肩代わり・巻き込み則
4. **破片（`StatusKeys.Armor`）が HP の前に削られる**（4798 行付近）
5. **軛（`Yoke.Cap`）の切り落とし**（4939 行付近・**破片の後**）
6. HP を減らす
7. `OnDamaged`（ここで `LooseTrait` の弾きが走る。**`dmg <= 0` なら鳴らない**）

確認すること:

- **ササの上限（`Brace`）をどこに差し込むか。** 推奨は**軛の直前**（5 の手前）。理由: 第四波では軛が 25 で先に切るので、
  ササの上限を軛の後ろに置くと**第四波でだけササの供給が消える**（波間相関に変な穴が開く）。
  軛の前に置けば「駒の上限が先、波の上限はその後」で、第四波でもササは自分の切り落とし分を拾える。
  **ただし軛の計数（`YokeCutLost` ほか）がササ在席行で減る**ことを報告書に書く（`docs/` に出るなら差分として現れる）
- **`OnDamaged` に渡る `dmg` は上限で切った後の値**か。上限 N > 0 なら `dmg ≥ min(amount, N) > 0` で必ず鳴る——
  **ただし他の駒（ヒビ）から破片を受け取っていて、それが全部吸ったときは `dmg = 0` で弾きが鳴らない**。
  この穴は現行の散開にも既にある（破片は現行でもササに付きうる）ので、**この期では塞がない**。発生回数だけ数える
- 軛のコメント「肩代わりの分割は上限を回避する経路になる」がササの上限にもそのまま当てはまる。
  **ゴルム・ドハがササより前で吸うと、ササには小さい一撃しか届かず、切り落としが出ない**。これは設計どおりの相互作用（肩代わり駒とは噛まない）で、**予測に書く**

### Q0-3. 手番喪失（転倒）の実装をどの鍵で書くか

弾かれた味方が「次の手番を失う」——`IdleTurn` が立つ経路は現状 **痺れ／まどろみ／`CanAct` 偽** の3本。

- **`StatusKeys.Stun`（痺れ）を流用しない**。痺れには読み手（シガ「縛られた敵しか殴れない」ほか）がいて、

- **まどろみ（ゴルム・第36期）と同じ形で新しい鍵を1つ足す**（`Stagger` など）。`IdleTurn` が立ち、
  号令（ガン）・据え（バン）・責め苦（シガ）が**買い取れる**ことを確認する
- **`SurrendersTurn` 相当の扱い**——買い取れる形にする（据え・号令の収入にすることがこの代金の狙い）
- ヨミ（動かされるとその場で割り込む）は**割り込みは即時なので失わず、次の通常の手番だけ失う**。この順序を確認する

### 1-2. `BraceTrait`（`TraitId.Brace`）

| 経路 | 内容 |
|---|---|
| `OnAction`（手番） | 「身を固めた」の印を立てる（**次のターン頭まで有効**）。攻撃は消費される |
| `ApplyDamage` 内（Q0-1 の位置） | 印が立っていて `amount > Cap` なら `refused = amount − Cap`、`amount = Cap`。`refused` をこのターンの保留に足す |
| `OnDamaged` | 現行の弾き（Q0-4 の共有ヘルパ）。**弾いたらこのターンの宛先を記録**し、保留を全部その味方の `Armor` に付ける。同じターンの2回目以降は弾かず、宛先へ直接付ける |
| ターン頭 | 印・宛先・保留を消す。**宛先が無いまま残った保留は消える**（自分には付けない） |
| 転倒 | 弾いた味方に `Stagger`（Q0-3）を1ターン立てる |

**`BraceRule`**（`ScaleRule` / `BearRule` / `ShatterRule` / `ShrapnelRule` と同じ作法・static にしない）:

```csharp
public readonly record struct BraceRule(int Cap, bool Refuse, bool Stagger)
```

- `Cap = 0` は上限なし（段A の対照）
- `Refuse = false` なら切り落とした分は消える（段B）
- `Stagger = false` なら転倒しない（段C）
- **既定は最終的に採用した値**（第136期の受け流し N=2 と同じ扱い）。回帰は「ササを含まない行が ±0.0」で取る

## 3. 予測（**実装前に書き切って報告書に残す。外れたら消さずに残す**）

**予測が読む量が実装のどこから来るかを1回たどること**（第130期の則）。

1. **段A では壁にならない。** HP96 だけでは第136期のガルド HP100 と同じで、生存Tは現行と大差ない
2. **段B で生存Tが大きく伸びる**。最下点の N で最大、ただし**最下点は供給を殺す**（段C で切り落としが太るのは高い N ではなく**中〜低の N**）
3. **段C の切り落とし供給は、単体高倍率の波（勇者候補・巡礼騎士）で太り、9体薄波・小さい一撃の波で細る**。
   ヒビ（範囲被弾に比例）とは**逆の波で光る**。この差が「1体に厚く」と合わせて、ガレ台で**ヒビより大きく**出る
4. **肩代わり台（ゴルム）では切り落としがほぼ出ない**（Q0-1 の分割回避の帰結）。この台のササは供給役ではなく、ただの前衛
5. **段D は読み手なしの台で明確に下がり、手番市場の台で上がる**（符号反転）。ヨミは割り込みが残るので損が小さい
6. **第四波（軛）でササの供給が消えない**（上限を軛の前に置くなら）。後ろに置いたなら消える——**どちらにしたかで予測を書き分ける**
7. **ササを含まない 60 行 ＋ 交差帯は ±0.0**

## 5. 採否

### 採用の条件
1. **段B で壁として立つ**: 壁だけの台でササの生存Tが現行を大きく上回る（線は Q0-5 の現行値から。**紙から引かない**）
2. **段C で供給が出口に届く**: ガレ台で符号がプラス、かつ `ShrapnelShards`（ガレが砕いた量）が現行ササ版より増えている
3. **段D が可変コスト型として働く**: 読み手なしで下がり、手番市場で上がる。**両方で上がるなら代金になっていない**
4. **特異性**: ササを含まない行が ±0.0

**壊れ気味は許容する**（この段階の優先順位は「新しい編成が生まれるか」）。ただし**肩代わり台と壁だけの台が両方とも天井に張り付く**なら強すぎる側の壊れとして掃引を1点下げる。

### 不採用のとき
`BraceTrait` / `BraceRule` は**残置**。ササの定義は**段A の状態で戻さず**——どこまで戻すかは結果を見て決める
（−35% を戻すか、HP96 だけ残すか）。**報告書に3案を書いて次期に持ち越す。**
