# 導火線のチリ — 本編への演出接続

2026-11-01。作成済み素材をDemoAppの実台本再生へ接続した。BattleCoreの規則・乱数・台本は変更しない。
素材の原本・プロンプトは `design/art/chiri/presentation-assets-v1/`、採用衣装は `design/art/chiri/game-portraits-v2/`。

## 本編での表示

| 出来事 | 表示 |
|---|---|
| Skill「仕掛ける」 | 手を差し出す差分を0.18秒保持。設置通知のある手番では次の通知を待つ |
| bomb_plant | 手を離す差分、手元から対象へ飛ぶ爆弾、頭上の印。最後の設置が届いてから待機へ戻す |
| bomb_fuse | 台本のAmountの3→2→1→0を表示。直前の該当Damageの後隙を詰め、導火線の先で火花を出す |
| bomb_blast | 持ち主で閃光・火炎・爆風の輪と軽い画面揺れ。続くDamageに書かれた対象にも小さい爆発。次の誘爆は0.12秒ずらす |
| bomb_mirror | 持ち主からFromIdへ0.48秒の火球。到達してからそこで爆発と揺れを出し、直後の確定Damageを通常経路で表示 |
| bomb_dud | 死亡後に印の火を消し、暗く落として消す。爆発は出さない |

爆弾5種はStatusGainの汎用枝へ渡さない。汎用アイコン、状態付与音、`＋3 bomb_plant`などの浮き文字は出ない。
爆発直後にengineが出すHighlightも、専用爆発と重なる中央バナーにせずログへ残す。
手番表示と既存の出来事の読み取りを通した後で専用演出へ分岐する。

## 接続

- `ChiriPresentation.cs`: 最終的な再生用イベント列を索引化。爆弾の通知、直後の見出し、続く直のDamageを結ぶ。ログ本文・席・隣接・HP・威力から標的を推測しない。
- `Main.Chiri.cs`: 5つのStatusGainとSkillを処理する。既存のDamage表示・HP更新はそのまま使う。
- `BattlefieldView3D.Chiri.cs`: 素材キットの呼び出し、InstanceIdから印への対応、持ち主の移動への追従、差分復帰を管理する。
- `BattlePawn3D.Chiri.cs`: 仕掛ける／手を離すの静止差分。独立した復帰Tweenを持たず、本編の時計で戻す。
- `assets/fx/chiri/chiri_material_kit.gd`: 素材初版を再利用。縮小した印の火花位置をToGlobalで合わせ、一時素材が消え切るまで待てる窓口を追加した。

火球はFromIdが無い場合に別の敵を選び直さない。巻き込みもDamageに登場した対象だけ。
巻き込み先の音は鳴らさず、爆弾1個につき1回。音・粒子・待ち手はSetDeathClockと同じ停止・速度を使う。
同じ戦闘の再生、編成へ戻る、シーン退場では世代を進め、古い非同期処理が次の盤面へ描画しない。
終戦時は短い爆発・不発・音の余韻を待ち、未起爆の印をすべて片付ける。

## 購入素材

着手時にローカルのEffectBlocks v4の実ファイルを確認した。
爆発感の補強では`explosion_heavy.tscn`を確認し、火炎と煙だけを採用。
従来の`explosion_light.tscn`の薄い炎より塊のある火炎が適していたため切り替えた。
破片・破片煙などは停止・非表示にし、火炎32粒と煙6粒だけを複製したProcessMaterialで調整する。
転送の尾には引き続き`fire_light.tscn`を使用する。
花火化で採用した`other/sparkles.tscn`由来の星形テクスチャは、現在の爆発から外した。
独自の火炎の塊と短く飛ぶ丸い火の粉を重ね、起爆時刻に勢いを集中させる。
作者の反復・音・ライトのスクリプトは配置前に外し、ProcessMaterialは複製する。
購入原本の編集・購入素材のGit追加は行わない。導入手順は `GodotApp/ASSET_RESEARCH_AND_PLAN.md`。

## 爆発を花火状に強化（2026-11-01・最初の調整）

草原では従来の小さな芯と薄い輪が埋もれたため、起爆時の閃光・拡大する輪に、
外周32本の尾と約0.15秒遅れて開く内側16粒の星を追加した。
金・オレンジを中心に一部をピンク・紫とし、尾を引いて広がった後、粒ごとに瞬いて落ちて消える。
面で覆う大きな白玉にはせず、放射の間に立ち絵が見えるようにした。

主爆発のサイズ係数は0.90→1.20、巻き込みは0.58→0.80、余韻は0.82→1.18秒。
これは表示だけの値で、Damage・転送先・命中時刻・起爆の件数は変えない。
尾と星は爆発1個につき2枚のImmediateMeshへまとめ、既存の時計から毎フレーム描く。
シェーダーのTIMEや乱数を使わず、一時停止・倍速・中断に従う。炎と煙の購入原本は変更しない。

## 爆弾らしい破裂感の補強（2026-11-01・火炎の調整）

花火化は線香花火のように弱く見えるとのフィードバックを受け、星形の48粒を外した。
最初の約0.1秒に強い閃光と高速の圧力輪を出し、約0.4秒で膨張・消失する火炎の塊を追加。
火炎の輪郭は7個の丸い膨らみを重ね、内部を黄白・橙・赤に揺らす。短い煤煙は約0.8秒で消える。
28本の太い火の粉が従来より速く外へ飛び、星形に瞬き続けず短く落ちて消える。
爆発音は-13→-9dB。巻き込み先では鳴らさない。全画面の揺れや追加の停止時間は足していない。

立ち絵を一瞬覆う火炎を意図して使い、顔を隠す時間を短くする。
購入素材の火炎・煙と独自の火炎の塊は同じ本編時計に従い、独立したTIMEや乱数を持たない。
本番の対象・件数・命中時刻・ダメージはそのまま。C#・BattleCoreへの変更なし。

- 素材検査は`CHIRI_MATERIAL_VERIFY_COMPLETE`。
- 本番3台本の再戦、最終HP・イベント列・対象一致、停止・倍速・中断・消去は`CHIRI_CHECK_COMPLETE ok=True`。
- 草原の実表示を録画・目視確認。動画は`output/chiri-blast/explosion.mp4`、
  静止画は同フォルダの`blast.png`・`mirror.png`、ログは`.tmp/chiri-blast/`。
- 終了時の資源保持メッセージは引き続き残る。

## 起爆時の軽い画面揺れ（2026-11-01・現在）

起爆の瞬間に0.18秒、横0.045・縦0.025程度のワールド座標変位で揺らし、二乗の包絡で減衰させる。
通常視点では数ピクセル程度。爆弾1個につき1回で、巻き込み先の小爆発では追加しない。
転送は火球の到達先でのみ揺れる。誘爆が重なっても振幅は加算せず、短い衝撃を更新する。

`BattlefieldView3D.Chiri.cs`が本編の停止・倍速時計で進める。
カメラの親ノードだけを平行移動し、カメラ自身の位置・FOVのTweenや、集束砲が使うHOffset/VOffsetを上書きしない。
2Dのメニュー・操作ボタンは固定。駒のHUDは揺れたカメラで投影して追従する。
視点調整、再戦、編成へ戻る、退場では即座に変位を0へ戻す。
購入済み重爆発のスクリプトも確認したがカメラ揺れは持たないため、既存の火炎素材に専用の平行移動を組み合わせた。
