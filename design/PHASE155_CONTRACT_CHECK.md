## 0. 何を疑っているか

第155期は `Contracts = 1` ＋ `All` で **代金が正**（+6.8 / +4.8 / +2.0）になった。
報告書はこれを「契約を絞ると燃料が太るから」と読んでいるが、**別の説明が成り立つ。**

> **`Contracts = 1` で `Toll` を外すと、契約枠が永久に塞がるのではないか。**
> 負債が回収されないので、アガは最初に貸した1体に張り付いたまま、
> 戦闘が終わるまで他の味方を癒せない。
> つまり `Vp` は「マイナスを外したアガ」ではなく**「1体しか癒せない壊れたヒーラー」**であり、
> そこと比べれば取り立てがあるほうが強く出る——**取り立てが枠を開けているから。**

この読みは第155期の表の単調さと一致する（報告書 §7「`Contracts`」）。

| Contracts | 台2 | 台3 | 台4 |
|---|--:|--:|--:|
| 1（枠が塞がる） | **+6.8** | **+4.8** | **+2.0** |
| 2 | −1.9 | −2.5 | −0.8 |
| 0（枠が塞がらない） | −4.8 | −2.0 | −1.9 |

**枠が塞がりにくいほど代金が負に戻っている。**
「契約を絞ると燃料が太る」だけではこの単調さは説明できない——**無制限でも燃料は溜まる**からである。

もしこの読みが正しければ、`Toll` は**代金であると同時に「枠を開ける」というプラス機能を持っている**
＝プラスとマイナスが分離できていない。`checkup` が (ii) と呼ぶ症状で、
**`Vp` が測っているものが「マイナスを外した版」ではなくなっている。**

**これは採否に直結する。** 「マイナスが実質プラス」は `checkup` の52枚で**0体の象限**であり、
そこに1枚目を入れるなら、根拠が器具の副作用でないことを先に確かめる必要がある。

## 1. 検証（実装の変更なし・計数だけ）

### 1-1. 数えるもの

**`Vp`（`Toll` を外した版）で、アガが前借りを撃った<u>相手の延べ人数</u>と<u>異なる人数</u>。**

`Contracts` の3点（1 / 2 / 0）× 台2・台3・台4 で取る。出口は `All` に固定
（代金が正になった条件を再現する）。seed・台・その他のノブは第155期の段C と完全に同一にすること。

| 版 | 前借りの回数/戦 | **貸した相手の異なり数/戦** | 枠が埋まって撃てなかった回数/戦 |
|---|---|---|---|
| `Vp` `Contracts = 1` | | | |
| `Vp` `Contracts = 2` | | | |
| `Vp` `Contracts = 0` | | | |
| `V1` `Contracts = 1` | | | |
| `V1` `Contracts = 2` | | | |
| `V1` `Contracts = 0` | | | |

**「枠が埋まって撃てなかった回数」が肝である。** アガの手番が来たのに
契約枠が満杯で前借りを撃てず、手番が空振りしているなら、それが `Vp` を壊している実体である。

> **その手番に `IdleTurn` が立っているかも記録すること。** 立っているなら
> 号令（ガン）・据え（バン）が買い取れることになり、帳簿の読みが変わる。

### 1-2. 判定

**artifact の確定条件（どれか1つでも満たせば確定）:**

- `Vp` `Contracts = 1` の**異なり数がほぼ 1.0**（1体に張り付いている）
- `Vp` `Contracts = 1` の**前借り回数が `V1` より有意に少ない**（枠が塞がって撃てていない）
- **「枠が埋まって撃てなかった回数」が `Vp` `Contracts = 1` で突出**している

**artifact ではない条件:**

- `Vp` `Contracts = 1` でも異なり数・前借り回数が `V1` とほぼ同じ
  （＝枠は実際には回っていて、代金が正なのは燃料の太さで説明できる）

### 1-3. 副次的に確認すること

**同じ理屈が `Contracts = 0`（無制限）でも働いていないか。**
無制限でも「その味方が既に負債を抱えている間は上乗せするだけ」なのか、
「負債持ちには撃てない」のか——**実装がどちらになっているかを読んで報告すること。**
前者なら枠の概念は `Contracts = 1` のときだけ効く。

## 2. artifact だった場合の直し方（**この追補では実装しない。報告のみ**）

どちらが筋かを**実装を読んで**判断し、意見を書くこと。ポンが決める。

**(a) 枠の開放を `Indulgence` 側に移す。**
負債の清算に関わらず、一定の条件（借り手が倒れた／負債が一定以下になった／N ターン経過）で枠が空く。
`Toll` は純粋に「取り立てる」だけの札に戻る。

**(b) `Vp` の作り方を変える。**
`Toll` を外すのではなく、**取り立ての量を 0 にする**（枠は開くが HP は減らない）。
`checkup` の `yP` の作法として妥当かを検討すること——
第74期の切り出し（`ThinBlade` / `Await` / `Seal`）は
「挙動は同じまま札だけ分ける」形だったので、**量を 0 にするのは別の器具**になる。

**(c) `Contracts` を捨てて無制限に固定する。**
代金は −4.8 / −2.0 / −1.9 と負のままだが、**器具としては素直**。
その上で改めて「代金の符号を何が割るか」を探す。
