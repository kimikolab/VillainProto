### Q0-2 焼き尽くすの与ダメ（表D・爆炎の直後か）

- **九体の波の T3-244 では「爆炎の直後の焼き尽くす」が 0 回**（ボルグが後なので）。それ以外の焼き尽くすは1回 813〜1,691・倒した 4.4〜8.1 体/回（ほぼ全滅）。
- T3-238 N1 では爆炎の直後の焼き尽くすが 0.27〜0.43/戦あり、**与ダメ/回は直後でないものの約半分**（868 対 1,459 など）——爆炎が先に削った敵には入る余地が少ない（与ダメは実際に HP が減った分）。**脆さの名目は本編で直後のほうが 3 倍前後大きい**（1,565 対 502）が、名目は削り切った敵の上にも乗る。

## 3. 予測（版の測定の前に書く）

- **P1**（N0 ＝ 規定・N1 ≒ M1+）: N0 は規定と台本が全行一致（**既に ○**）。N1 と ref（M1+）は九体の波・本編とも表C・D・爆炎の数が小数第2位まで同じか ±0.02 以内（Phase 0 の表のとおり。放熱で育つは焼き尽くすの後にしか働かず、九体の波は焼き尽くすで終わる）。
- **P2**（九体の波の爆炎）: N2 の T3-244 の九体の波（4セル）の爆炎は **0.85〜1.00/戦**（N0 0.00・N1 0.01）。T3-238 は **0.85〜1.00/戦**（N1 0.43〜0.52）。初めて撃つ周回は T2。
- **P3**（焼き尽くすの数）: N2 の九体の波で、ホタの焼き尽くすは N1 より **0.00〜0.10/戦だけ減る**（爆炎だけで戦が終わるのは、敵 400/300 の9体ではまれ）。決着ターンは N1 と ±0.05 ターン（同じ周回2 で終わる）。
- **P4**（爆炎の後の焼き尽くす）: 爆炎の直後の焼き尽くすは、**脆さの名目が1回あたりで直後でないものより大きい**（○の見込み）が、**実際に HP を減らした与ダメ/回は小さい**（爆炎が先に削っているので・指示書の P4 の文言「与ダメが大きい」は × の見込み）。2体のギフトで倒れる敵の合計（1体目 ＋ 2体目）は N1 とほぼ同じ（どちらでも全滅に近い）。
- **P5**（勝率）: N2 の本編 400/300 の勝率は T3-244 で N0 と ±0.5pt、T3-238 で N0 より +8〜+10pt（N1 の分）。N2 と N1 の差は ±1.0pt 以内。
- **P6**（ヒヨの回復）: 爆炎は味方への燃焼ダメージをヒヨの火の変換で回復に変える（R354）ので、N2 の九体の波で回復が初めて入る周回は N1 より早いか同じ、回復の量は増える。
- **線の見込み**: N2 は線1・線2 を両方の台で通し、**N2 を規定にする**（線2 は Phase 0 のとおり N1 でも通るので、参考の「N2 > N1」が ○ になるかを報告に書く）。
