## 1. 目的

ポンの思いつき: 「印を持つ敵が弾けたら隣に追加のダメージが入り、上手くいけば弾けが連鎖する——敵が爆弾のように連鎖して消えていく絵が見たい」

ミオの印（濃縮の印・第218〜219期で「消えずに流れる」になった）を**爆弾**にする:

> **澱みが爆ぜる**: 印を持つ駒が倒れると、澱みが爆ぜて**隣の駒へダメージ**を与える。それで隣が倒れれば、その駒の澱みも爆ぜる。

- 感電との違い: 雷は**生きている敵**を一撃で繋いで弾けさせ痺れさせる／澱みは**倒れた敵**から隣へ爆ぜて広がる
- 印は倒れると隣へ流れる（M5）ので、爆発のたびに生き残った隣の印が増え、**次の爆発が大きくなる**（育つ連鎖）
- 爆発は状態異常ダメージなので、燃焼の脆さ（F1）も乗る

あわせて、**疫みのラウを雷の編成に入れた台**を測る。ラウは「毒の敵を殴ると隣にうつる／毒の駒が倒れると残りの敵へ毒が飛ぶ（味方の死骸からも）」の駒で、
- 殴る＝カタの感電を弾く役になる
- 毒をうつす＝カタの雷の道を広げる
- 死骸から毒が飛ぶ＝ミオの「印が流れる」と並んで、倒れるたびに加速する

ミオに毒の移動まで持たせるとラウの居場所が消えるので、**毒の移動はラウの仕事のまま**にする（ポンと合意）。

## 2. 澱みが爆ぜる（新しい規則）

| 項目 | 決め |
|---|---|
| 条件 | 印（`StatusKeys.Concentrated`）が 1 以上の駒が倒れたとき |
| 相手 | 倒れた駒と**同じ陣営の隣の生きている駒すべて**（`FormationRules.AreAdjacent`） |
| 量 | 版で決める（§3）。倒れた瞬間の毒の層と印の数から |
| 扱い | **状態異常ダメージ**（行動でも攻撃でもない）。燃焼の脆さが乗る。棘・反射は鳴らない。粛で止まらない |
| 出どころ | 倒れた駒（同じ陣営・同士討ち）。撃破の帰属は「最初に倒れた駒を倒した一撃の主」 |
| 連鎖 | 爆発で倒れた駒も、印があれば爆ぜる。**1つの駒は1回しか爆ぜない** |
| 順番 | 倒れた駒ごとに ①爆ぜる → ②印が隣へ移る（M5・爆発の後に生き残った隣へ）。爆発で倒れた駒は席番号の順に同じ手順。乱数は引かない |
| 感電との重なり | 爆発で HP に届いた隣が感電していれば弾ける（既存の規則のまま）。雷と澱みの連鎖が交互に起きうる |

- 倒れた駒の毒は、爆発で消費しない（倒れた駒の毒の飛び方はラウの規則のまま）
- 味方側の版では、爆発を受けた味方がベニの結界の内側なら**回復に反転**する（放電と同じ口）

## 3. 版

| 版 | 量 | 相手の陣営 |
|---|---|---|
| B0 | —— | 爆ぜない（前段の盤面） |
| B1 | 倒れた駒の**毒の層 ÷ 2**（切り捨て。印の数に依らない） | 敵だけ |
| **B2（規定の候補）** | 倒れた駒の**毒の層 ÷ 4 ×（1 ＋ 印の数）**（切り捨て） | 敵だけ |
| B2x | B2 と同じ | **敵味方の両方**（ミオのマイナスで味方にも印が乗るので、印の味方が倒れると味方側で爆ぜる） |

- B2 は「印が増えるほど爆発が大きい」の形。印は流れて集まるので、連鎖の後ろほど大きくなるはず
- 参考: ラウの特性（`ContagionTrait`）のコメントに、終盤の敵は1体あたり毒 20〜60 層まで積むとある（拡散の却下理由の節）。B1 なら 1 発 10〜30、B2 は印次第
- 札の差し替え（または `EmberRule` と同じ規則の器）で作る。`Run` の引数は増やさない

## 4. Phase 0

- **Q0-1 倒れた瞬間の在庫**: 前段の盤面で、印を持って倒れた敵の割合・その時の毒の層と印の数の分布（台ごと・波ごと）
- **Q0-2 死の処理の順番**: 倒れた駒の処理（死亡トリガー・ラウの毒の拡散・ミオの印の移り・リィカの層・ヴェルの蘇生ほか）の既存の順番と、爆発をどこに挟むか
- **Q0-3 敵の隣接**: 敵の陣形（X字・パターン3の写し）ごとに、1体が倒れたとき隣の生きている敵の数の分布
- **Q0-4 ラウ**: ラウの「殴ると隣にうつる」「死骸から飛ぶ」が、今の盤面（O4・S2・F1・ミオ M5）でどれだけ起きているか。ラウが弾いた感電の数
- **Q0-5 過去の測定**: `design/` を grep（死亡時の爆発・敵の死で連鎖する機構・ラウの拡散の過去の版）
- **Q0-6 台**: §6 の台の席を決め、駒を数えて予測を書く

## 5. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** B0 は前段の盤面と台本が一致。印を持つ駒が1度も倒れない戦は B1〜B2x で変わらない
- **P2** B1・B2 で決着が早まる（勝率は天井の台が多いので、決着ターン・倍率 150/200 の勝率で読む）
- **P3** B2 の爆発は連鎖の後ろほど大きい（連鎖の段ごとの平均量が上がる）
- **P4** ラウの台で、ミオの印の移りとラウの毒の拡散が同じ死で両方起き、次の爆発が大きくなる
- **P5** B2x は、ミオの隣の味方が倒れたときに味方側で爆ぜ、勝率を下げる台が出る（ベニの結界の内側は回復）
