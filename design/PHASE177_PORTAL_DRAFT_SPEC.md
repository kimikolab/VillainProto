# 第177期 指示書 —— ポータル＋リキャスト＋15枚から組む（マップ検証の一区切り）

置き場所: `design/PHASE177_PORTAL_DRAFT_SPEC.md`。報告書は `design/PHASE177_PORTAL_DRAFT.md`。
前提: `design/PHASE176_PORTAL.md`・`design/PHASE175_WATCH_LOG.md`・R259・R271・R276。

**`BattleCore` には触らない。**

## 0. この期の性格（第176期までと変える）

- **器具で線を引いてから画面に出す形はやめる。** 規則はポンの構想どおりの値で画面に直接入れ、遊んで直す。
  残す検算は**回帰確認だけ**（`PortalOn = false` で第175期と一致／`TimeOn = false` で第169期と 0.0pt）
- 線・予測・掃引は**書かない**。数値（S・R・K）は仮置きで、ノブとして残すだけ
- **ターン制の UI は磨かない。** 行き先指定（第175期）以上のことはしない。停止条件や命令の見せ方の改善は入れない
- このマップ検証は、**キャラ性能の検討に必要だったから**始めたもの。この期で一区切りし、
  次の期は**転生候補の洗い出し**（ロスター側）に戻る。報告書の末尾に、そのための材料を出す（§4）

## 1. ポータルとリキャスト（規則）

第176期 §1 の規則をそのまま画面に載せ、次を足す。

| 項目 | 中身 |
|---|---|
| 湧きのリキャスト `S` | 既定 **8**。ポータルは使うたびに S ターン使えない（連続使用不可） |
| 制圧後 | 湧きが止まり、味方の第2拠点になる（休む・組み直し可）。**味方のワープも同じポータルを使う**ので、同じリキャスト `R`（既定 **3**）が掛かる |
| 空の拠点 | **隊が1つもいなければ即占領**（味方・敵とも。防壁などは置かない） |
| K | 1 のまま |
| 勝ち負け | 第176期 §1-4 のまま |

## 2. 画面

- 第176期 §3（ポータルの表示・制圧・ワープ・停止条件・結果画面）と §3-1（矢印を途中の敵で止める／選択中の隊を盤の上で光らせる）
- ポータルの札に**リキャストの残りターン**を出す（敵側・味方側とも同じ表示）
- 左右のパネルの行は増やさない

## 3. 15枚から自分で組む（案A）

- 開始時、**3隊の15枚をばらして手札にする**（今の3隊の駒そのまま。控えの7枚は**この期では配らない**）
- プレイヤーが拠点で**隊を自由に組む**（1〜5枚、隊の数は1〜3。4隊にはしない）。既存の組み直し画面を「最初は全席空」で開くだけ
- 「既定の3隊で始める」ボタンも残す（回帰確認と、面倒なときの逃げ道）
- 開始時の編成は結果画面と `WATCH_LOG` に残す（**誰と誰を組んだか**が次の期の材料）

## 4. 報告書に欲しいもの（転生候補の洗い出しに向けて）

この期の測定はしないが、**既にある数字を1つの表に集める**。手書きは0行、走査で出す。

52枚それぞれについて:

| 列 | 出どころ |
|---|---|
| `checkup` 単独勝率 | 既存 |
| 素体差し替えの寄与（第164期） | 既存 |
| `compare` の在席枠数／固有の勝者になっている行数 | 既存 |
| マップ1-1 での送り先の反応（第164期の3群: 化ける／どこでも同じ／読めない） | 既存 |
| 第172期 部C 型の「枠の値段」があるなら値 | 既存（ハネのみ。無い駒は空欄） |
| 第164期の分類（転生候補など） | 既存 |

これを **`docs/roster_audit.md`** として生成物に置く（再生成で差分0の門に載せる）。並びは素体差し替えの寄与の昇順。
**判断は書かない**（候補の選定は次の期）。ただし「素体より弱い駒の枚数」だけ冒頭に1行。
