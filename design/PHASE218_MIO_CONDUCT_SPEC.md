# 第218期 指示書 —— 澱みのミオ：叩きつけ・通電・澱みのデバフ・印を運ぶ

置き場所: `design/PHASE218_MIO_CONDUCT_SPEC.md`。報告は `design/PHASE218_MIO_CONDUCT.md`。
**線は置かない**（採否はポンが遊んで決める）。盤面は第217期のあとにシガを G3K へ規定化したもの（O4・S2 規定）。シガの規定化が未コミットなら先に済ませて報告に書く。

## 0. 目的

ポンがベニ・ミオ・カタの編成を遊んで感じたこと:

1. **毎ターン貯めるだけで同じ絵が続く**。ダメージの数は増えるが、ミオの動きや爽快感に繋がっていない
2. **途中で失速する**。印を重ねた敵が倒れると、次の敵に一から重ね直すまどろっこしさ
3. **カタの感電を弾く駒がいない**。ベニ・ミオ・カタの3体はだれも直接殴らないので、殴る駒を別に入れる必要がある
4. **暗いキャラなのでデバフもしてほしい**。前衛1枚で持たないことへの手助けが欲しい（ベニは付与と回復を両方している）
5. ミオには**感電から得るものが何も無い**

鍵はミオの速さ（8）。カタ（6）より速いので、**次のターンの前のほうで、前のターンにカタが付けた感電を弾ける**（敵の感電は味方が殴らない限り残る）。
しかも S2 で弾けた敵は痺れるので、**速8で弾けば、ミオより遅い敵は動く前に止まる**＝守りになる。

## 1. 今のミオ（第216期）

- HP42・攻2・速8。札 `Concentrate`・`ConcentrateLeak`。手番は `Skill`「水を濁らせている」（攻撃しない）
- 手番: (1) 毒のある敵全員に +4 層（傷のある敵は毒が回り始める）、(2) **次の刻みが最も大きい敵とその隣**に濃縮の印 +1（印が n の駒は毒と燃焼の刻みを 1+n 回受ける・戦闘中消えない）
- マイナス: (2) のたび、ミオの隣の味方にも印 +1。攻撃はしない

## 2. 足すもの（4つ）

### 2.1 叩きつけ（起爆役）

手番の最後に、**澱みを叩きつける**: 寄せ先の敵（(2) で印を置いた中心の敵。**感電している敵が候補にいればそれを優先**）に小さな一撃。
- 量は ミオの現在攻撃力（今は 2）。HP に届けば感電を弾く（破片が受け切ったら弾かない＝既存の規則のまま）
- ミオの攻撃による被弾として扱う（撃破の帰属はミオ）。攻撃型は単体

### 2.2 通電（感電した敵を叩くときの特別な叩きつけ）

叩きつける相手が**感電していたら**、澱みの水が雷を通す: 一撃が**印を持つ敵すべて**へ走る（それぞれに同じ小さな一撃）。
- 隣接していない敵にも届く（X字が2組に割れた後の取り残しも弾ける）
- 1手番に1回。印を持つ敵が1体だけなら通常の叩きつけと同じ
- フレーバーの芯: 「濁った水ほど、雷をよく通す」

### 2.3 澱みのデバフ

**印を持つ駒は、与えるダメージが軽くなる**（印1つにつき −10%・上限 −40%。割合なので敵の倍率を上げても効く）。
- 敵だけに効く版と、**敵味方の両方に効く版**を並べる（今のマイナスで味方にも印が乗るので、両方に効くと「印の規則が1つ」で読める。代わりにカタ・シガなど殴る駒をミオの隣に置けなくなる）
- 軽くなるのは与ダメージ（通常攻撃・雷・放電・反撃）。刻み（毒・燃焼）は対象外

### 2.4 印を運ぶ（失速の解消・感電から得るもの）

- **放電で運ぶ**: 印が1以上の駒が弾けたとき、その駒の放電を受けた隣に印 +1（放電1本につき +1）
- **倒れたら移る**（別の版）: 印を持つ敵が倒れたとき、その印を隣の生きている敵へ移す（全部を、次の刻みが最も大きい隣へ。同値は席番号の順）

## 4. Phase 0

- **Q0-1 感電の残り方**: ベニ・ミオ・カタ＋殴らない2枚（クビ・トウほか）で、カタが付けた敵の感電が次のターンのミオの手番まで残っている割合。殴る駒（トウ）がいると同じターンのうちに弾かれて、ミオの番には残っていないはず（R317）
- **Q0-2 ミオより遅い敵**: 各波で、速8より遅い敵の割合（ミオが弾いて痺れさせれば、その敵は動く前に止まる）
- **Q0-3 与ダメージの窓口**: 与ダメを割合で下げる既存の口（萎縮・鈍・ネルの呪いほか）の場所と重ね方。デバフをどこに挟むか
- **Q0-4 失速の実測**: M0 で、寄せ先に印が 0 の敵を選んだ手番の割合（＝一から重ね直した手番）と、印を持ったまま倒れた敵の印の総数
- **Q0-5 過去の測定**: `design/` を grep（第194期のミオ転生の報告の結論・叩きつけや通電に近い実験）
- **Q0-6 台**: §6 の台の席を決め、駒を数えて予測を書く

## 5. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** ミオのいない行は 0 セル。M0 はシガ G3K 規定化後の盤面と台本が一致
- **P2** M1 で、殴る駒のいない台（M台1）の敵の感電が弾かれる回数が増え、痺れた敵が動く前に止まる回数が増える
- **P3** M2 の通電は、X字が割れた後（中央が倒れた後）に多く出る
- **P4** M3 で味方の被ダメが下がる。第二波の1ターン目は変わらない（ミオが印を置く前の初撃）
- **P5** M3x は、ミオの隣のカタの雷が軽くなり、勝率は M3 より下がる台が出る
- **P6** M4・M5 で「一から重ね直した手番」が減り、ミオの刻みの総量が終盤まで落ちない
