## 1. 目的

第227期で、ガルド抜きの移動軸は9体の波（敵 HP200%／攻200%）で全員生存 97.5% に届いた。残りは本編の第二波（粛）・第三波（渇き）と、移動軸の中での**ハネの役割の薄さ**。

ポンのハネの像は**バネ**:
- **手番: 吹っ飛ばし**。前の敵を押すのではなく、経路の最後尾まで吹っ飛ばす。吹っ飛んだ軌跡にいる敵もまとめて傷つき、1つずつ前へ詰める
  - 例: ハネ → A B C と並ぶ経路で A を吹っ飛ばすと、ハネ → B C A になる。A・B・C に貫きのダメージ。B と C は前進扱いで、バサの対により混乱する
- **殴られたら: 弾き返す**。敵からの被弾も「押された」と見なし、殴ってきた敵を後ろへ弾き、ハネ自身も隣の味方と入れ替わる

「後ろへ飛ばされた敵は転び、前へ詰めた敵は混乱する」を1回の動作で見せる。移動軸の芯「被弾を移動に変える」にハネも加わる。

## 2. 今のハネ（前段の後）

- HP56・攻11・速8。札 `Rebound`・`Overrun`・`Disarray`
- 手番: 前列で最も攻撃力の高い敵を後ろへ突き返して転ばせる（次の手番を失う）。敵の乱れの段2 で2体
- 味方が押しのけられるたび、敵の隊列を突き崩す
- マイナス: 突き返すたび自分が隣の味方1体と場所を入れ替える／自分では攻撃しない

## 3. 吹っ飛ばし（手番）

| 項目 | 内容 |
|---|---|
| 狙い | 前列の敵のうち、**貫きの経路に属する**敵（前1・前3）で攻撃力が最も高い1体（A）。同値は席番号の順 |
| 経路 | Aのいる経路（前1なら 前1→中央→○中1→後1、前3なら 前3→中央→○中3→後3） |
| 動き | 経路の上で**駒のいる席の並びはそのまま**、中の駒の順番を「Aを最後尾へ回した順」に並べ替える（例: A・B・Cが 席1・席2・席4 にいれば、B→席1・C→席2・A→席4。空席の位置は変えない） |
| ダメージ | A と、経路でAより後ろにいた敵すべてに**貫き**のダメージ（ハネの現在の攻撃力・既存の貫きの規則どおり） |
| 転倒 | A は転ぶ（次の手番を失う・今の突き返しと同じ） |
| 混乱 | **行が前に変わった敵**は、バサがいれば混乱する（第226期の対の規則のまま・上限も同じ）。同じ行の中で詰めただけの敵（中央 ↔ ○中）は混乱しない |
| 敵の乱れ | 動いた敵1体につき、敵の移動の累計 +1（バサ・ハネの段に入る） |
| マイナス | 吹っ飛ばすたび、ハネ自身が隣の味方1体と入れ替わる（今と同じ） |
| 狙えないとき | 経路に属する前列の敵がいなければ（9体の波の ○前2 だけが前列に残るときなど）、今の突き返しを行う |

- 「自分では攻撃しない」は文面から外す（吹っ飛ばしがダメージを持つため）
- 軌跡の敵が感電していれば、貫きの被弾で弾ける（既存の規則のまま）

## 4. 弾き返し（被弾時）

| 項目 | 内容 |
|---|---|
| 条件 | ハネが**敵の攻撃による被弾**を受けたとき（HP に届いた一撃。状態異常のダメージ・味方からのダメージは除く） |
| 効果 | 殴ってきた敵を、その敵のいる経路で**1つ後ろへ**弾く（後ろの席の敵と入れ替え。後ろに席が無ければ弾かない）。弾かれた敵は転ぶ。入れ替えで前へ出た敵は、バサがいれば混乱する |
| マイナス | 弾き返すたび、ハネ自身が隣の味方1体と入れ替わる（吹っ飛ばしと同じ） |
| 回数 | 1ターンに **1 ＋ 敵の乱れの段** 回まで |
| 止まる波 | 粛（第二波）ではターン外の行動なので止まる |

- 殴ってきた敵が経路に属さない席（○前2・○後2）にいれば弾かない（回数も使わない）
- 殴ってきた敵がすでに倒れていれば弾かない

## 6. Phase 0

- **Q0-1 経路の並べ替え**: X字・9体の波で、吹っ飛ばしの前後の席の表を手で3例作る（空席がある経路・中央を共有する経路・Aの後ろに誰もいない経路）

- **Q0-6 過去の測定**: `design/` を grep（第148期のハネ・経路を並べ替える機構・被弾で相手を押す機構）

## 7. 予測（Phase 0 の後に数値を入れて実装前にコミット）

- **P1** ハネのいない行は 0 セル。H0 は前段の盤面と台本が一致
