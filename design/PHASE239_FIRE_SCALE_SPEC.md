# 第239期 指示書 —— 規定化と、火勢の棚卸し（手番の絵の単調さも測る）

置き場所: `design/PHASE239_FIRE_SCALE_SPEC.md`。報告は `design/PHASE239_FIRE_SCALE.md`。
**この期は新しい機構を足さない**（規定化を除く）。火勢は**影の計算**（盤面に影響しない計数）だけで見積もる。

## 1. 目的

燃焼の軸のコンセプトは **「耐えて、燃え上がり、焼き尽くす」**。第233〜238期で「耐える」（ボルグ）と、燃えている味方を守る循環（ボルグの盾の配り × ヒヨの火の変換）が閉じた。次は「燃え上がる」。

ポンの方針:

- **燃焼に「育つ」要素を入れる**。火が大きくなり、敵には災害、味方には大きな力になる
- **火勢（火の大きさ）を4段**にする。点け直すと育ち、**燃やし続けないと萎む**（将来、敵の鎮火で下げられるようにする）
- **味方の火の大きさ＝戦力の大きさ**が画面で一目で分かるようにする
- **勝率が上がっても、ボルグ・ヒヨ・ホタが毎ターン同じことを繰り返すと絵が単調になる。火の演出だけ豪華にしても意味がない**

この期は、火勢を入れる前に **(1) 火勢が実際にどう育つか** と **(2) 今の3体の手番がどれだけ単調か** を測る。

## 3. 測るもの

### 3.1 燃焼の書き手・読み手の一覧（`derive` から機械的に）

| 列 | 内容 |
|---|---|
| 駒・札 | 味方・敵の両方 |
| 書く | どこに・いつ火を点けるか（主目標・隣・開戦・被弾・死亡ほか） |
| 読む | 何を条件にするか（燃えている／燃えていない・数・種類数ほか） |
| 燃焼ダメージの扱い | ダメージ／回復（ヒヨ・ベニ・ボルグ）／無効（ホタ） |

火勢を入れたとき**意味が変わりうる読み手**（例: カタの雷の種類数、ツギの板、ヒヨの贔屓）に印を付ける。

### 3.2 火勢の影の計算（盤面に影響させない）

燃焼の残りターンと別に、各駒に影の火勢を持たせて数える。規則の候補を3つ並べる。

| 規則 | 育つ | 萎む |
|---|---|---|
| **K1** | 燃えている駒に火が点くたび +1（上限4） | そのターンに一度も点け直されなければ −1（0で消える＝今の燃焼の終わりと別に数える） |
| K2 | 1ターンに一度でも点け直されれば +1（上限4） | 同上 |
| K3 | K1 と同じ | 2ターン点け直されなければ −1 |

- 火勢1 は今の燃焼と同じ（初めて火が点いた状態）
- ボルグの火の鎧・くすぶり・焼き返し、ベニの配り、ボルグの火の粉ほか、**既存の着火すべて**が点け直しに数える
- 表: 駒ごと（ボルグ・ホタ・ヒヨ・相方・敵）に、ターンごとの影の火勢の分布（平均・火勢3以上／4に届いた割合・届いたターン）

### 3.3 手番の絵の単調さ

各駒の手番を「絵」として記録し、単調さを数える。

- **絵** ＝（手番の種類［攻撃／術／溜め／何もしない］, 攻撃型［単体／薙ぎ／貫き／全体］, その手番で起きた出来事の種類の集合［着火・回復・半減・弾く・移動ほか］）
- 表: 駒ごとに、1戦あたりの**絵の種類数**・**同じ絵が続いた最長の回数**・**最も多い絵が占める割合**
- 比べる相手: 移動軸（第232期の規定）・雷の組（ポンの席）

### 3.4 火勢で手番を変える候補の発火見込み（影の火勢で数えるだけ）

次の期の候補（**この期は実装しない**）。影の火勢で、各段にいた手番の数を数える。

| 駒 | 火勢で変わる手番（案） |
|---|---|
| ホタ | 火勢1 単体 → 2 貫き → 3 貫き＋着火 → 4 全体（焼き尽くす） |
| ボルグ | 火勢4で**火を放つ**大振り（溜めた火を大剣に乗せて放ち、自分の火勢は1に戻る） |
| ヒヨ | 火勢の合計が一定を超えると**大焚き**（燃えている味方全員の火勢 +1） |

「育てる → 放つ → また育てる」の波が絵の単調さを割れるかを、段ごとの手番の数と、放つ手番が1戦に何回起きうるかで見る。

## 7. Codex 向けの演出メモ（報告に転記。この期は実装しない）

- **色 ＝ 火勢**: 1 暗い赤（くすぶる）／2 赤〜橙（焚き火）／3 黄〜白（燃え盛る）／4 青白（最大）
- **大きさ ＝ 残りターン**（萎むまでの余裕。小さくなる＝次に点け直さないと1段下がる）
- **演出の種類**: 燃焼がダメージになる駒は「焼かれる」（体が燃え、焦げる）、ダメージにならない駒（回復・無効）は「オーラ」（体の周りに炎が立つ）。刻みごとに台本の「ダメージ／回復／無効」で選び、混ざる場合は差し引きで決める
- ヒヨが倒れると、味方のオーラが「焼かれる」に戻る
- ベニの紅蓮は、隣の火勢に合わせて鮮やかになる
