**線は置かない**（採否はポンが遊んで決める）。規定は第215期のまま。新しい仕組みは札で足し、保持者は版の中だけ。

## 0. 目的

ポンが雷の編成（ベニ・ミオ・カタ＋グザ＋1枠）を組んで分かったこと:

- 第二波では1ターン目に前衛が必ず落ちる（パターン2 のスィドは「落ちた ＝ 1」）。守りがベニの反転（刻みが回復になる）だけで、刻みは2ターン目の頭からしか来ないため
- クビ（被ダメ −30%・最強の敵を萎縮）を入れた X字でようやく完全勝利。敵の倍率を上げると持たない見込み
- グザが必須なのは、**敵全体に状態異常を書く駒がグザしかいない**から（雷の道を敷く役）

そこで2つの仕組みを試す:

1. **ベニの開戦の撒き**: 開戦時に敵（と味方）へ毒を撒き、1ターン目からカタの雷が全員に跳ねるようにする。ベニ・ミオ・カタの3体で基本の形が完結し、残り2枠に守りの駒を入れる余地を作る
2. **感電で痺れる**: 弾けた駒が痺れる。連鎖が大きいほど敵が一斉に止まる＝密度の軸のまま守りにもなる

あわせて、雷の編成の2枠を比べる。

## 1. ベニの開戦の撒き

開戦時（行動順より前・会戦で次の戦に入るときも）に、ベニが全体へ撒く。

| 版 | 撒く相手 | 撒く中身 |
|---|---|---|
| O0 | —— | 撒かない（第215期と同じ） |
| O1 | 敵全体 | 毒 1 |
| O2 | **敵味方の全体**（ベニ自身を含む） | 毒 1 |
| O3 | 敵味方の全体 | 毒 3 |
| O4 | 敵全体 | 毒 1 ＋ 燃焼 1 |

- O2・O3 の味方への毒は、ベニの結界（ベニと隣の味方）の中では刻みが回復になる。**結界の外の味方だけが削られる**
- O4 はポンの比較用: 敵の種類が開戦から2つ（毒・燃）になり、ミオの濃を足すと1ターン目の雷は ×4
- 札は `GurenOpening`（O1）ほか版ごとに1枚。版は札の差し替えで作る

## 2. 感電で痺れる

感電が弾けたとき（起爆・連鎖の放電で弾けたとき）、その駒に**痺れ**（既存の `StatusKeys.Stun`・1ターン動けない）を付ける。

| 版 | 痺れる駒 |
|---|---|
| S0 | —— （第215期と同じ） |
| S1 | 連鎖の**起点だけ**（その一撃で弾けた1体） |
| S2 | その連鎖で**弾けた駒すべて** |
| S3 | 弾けた駒それぞれ **50%** で |

- 敵味方を問わない（味方側の連鎖では味方が痺れる）
- 痺れの中身・消え方は既存の痺れと同じ（トウの痺れと区別しない）。**痺は数える状態異常に入る**ので、次の雷の種類が+1になる。シガ（痺れた敵を狙う）の餌にもなる
- 倒れた駒には付けない
- S3 だけ乱数を引く。S0〜S2 は乱数を引かない
- 札は `ShockStun` ほか版ごとに1枚

## 3. Phase 0（実装前）

- **Q0-1 毒1の寿命**: 毒1が刻みで減るか・何ターン残るか。2ターン目の雷の道になるか。燃焼1も同じく
- **Q0-2 開戦の順番**: 開戦時の効果（クグの大縛り・ツギの出撃前の板・ヒサ・バン・ネルの呪いほか）とベニの撒きの前後。同速のシャッフルで順番が揺れるか
- **Q0-3 痺れの付き方**: 既存の痺れ（トウ）の付与口・重ねがけ・「その手番を既に終えた駒に付いたら次の手番を失う」の扱い。痺れを弾く・無効にする特性（粛・ガルドの不動ほか）の一覧
- **Q0-4 過去の測定**: `design/` を grep（開戦の毒・全体に毒・痺れの連鎖）
- **Q0-5 台**: §5 の台の席を決め、駒を数えて予測を書く

## 4. 予測（Phase 0 の後に数値を入れて実装前にコミット）

方向だけ:

- **P1** 版の札を持たない行は 0 セル（`compare` の全行）
- **P2** O1〜O4 で1ターン目の雷の当たり数が 5 に近づく（台A・B）。O4 は1発が一番重い
- **P3** O2・O3 の味方への毒は、ベニの結界の外の駒の被ダメとして出る。X字の中央ベニならほぼ全部が回復に変わる
- **P4** 毒1が1ターンで消えるなら（Q0-1）、O1・O2 の効果は1ターン目に偏り、O3 が上回る
- **P5** S1〜S3 で敵の手番の喪失が増え、第二波の全員生存が上がる。ただし**1ターン目の初撃は防げない**（カタは速6で、速い敵の後に動く）
- **P6** S2 は味方側の連鎖でも味方が止まり、カタの隣の駒の手番が減る
