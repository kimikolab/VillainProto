## 0. なぜこれをやるか

第138期でガレは**採用されたのに `UnitCatalog.All` に入っていない**。
52枚＝トランプ1組の上限（第103期に確定）に触るため、差し替え先の決定が次期送りになっていた。
**ここを閉じないと第138期は未完了のまま残る。**

### 切る駒をエグにする根拠

**第126期の全52枚のプラス値**（マイナスを外したときの伸び）で、
**線（+1.5）に届かなかったのは3体だけ**だった:

| 駒 | プラス値 |
|---|--:|
| 継ぎ当てのノノ | +0.28 |
| 断ちのナタ | +0.59 |
| **抉りのエグ** | **+0.66** |

**3体とも傷軸**で、結論は「**マイナスのせいで組めないのではなく、プラスの側が薄い**」。
エグは代金（深追い・倒すと次の手番を失う）を外してもほとんど伸びない。
さらに第126期は「**エグの失った手番をガン・バンが買い取る**」という想定を
**52枚中49位（−8.23）で最も強く否定している**——救済の当ても外れている。

**ノミは切らない。** 第126期でノミの代金は **−1.13**（執着を外すと**弱くなる**）で、
「マイナスが実質プラス」に入る2体の片方。象限では「素で有能」の側にいる。

### 傷軸を差し替えの供給源にする理由

書き手2（キリ・ノミ）＋読み手2（エグ・ナタ）で**52枚のうち4枠**を占めているのに、
軸の劣化が複数回記録されている:

- 第108期にハリ（読み手3枚目）を外して以降、`Presets` の傷読みは減り続けている
- 第120期以降、**味方の傷が構造的に 0** になり、スィド・グザ・ラウの一文
  「傷を負った味方には深く入る」が**到達不能**（報告書が「この期では直していない」と明記したまま）
- 「傷を丸ごと外すと +58.5」が2回、0.1pt も違わずに再現している

**この期はエグ1枚だけを切る。** ナタも同じ帯にいるが、
**書き手を切ると読み手が即死し、読み手を切ると書き手が空回りする**ので、
1枚切った後の帳簿を見てから次を決める（§5）。

## Phase 0（実装前に必ず全部答える。答えを報告書に転記する）

### Q0-0. `git fetch` して origin から behind でないことを確認する
**毎期の最初の項目。** 第138期が記録した未コミットの札の状況も確認する。

### Q0-1. **`BattleEngine.Run` の引数をこの期で1本も増やさない**（最優先の制約）
第138期が踏んだ事故:

> `Run` は既に **47 本**の引数を持っていて、その1段下で `ApplyDamage` が数千段の再帰をしている。
> 引数を1本増やすと `Run` のフレームが太り、**再帰に残るスタックがそのぶん減る。
> 1本なら通り、2本で踏み抜いた**——余裕はもう1本ぶんしか無かった。

第138期は `ArmorRule` を `ShrapnelRule.ArmorCensus` に畳んで1本に収めている。
**したがって現在の余裕は 0〜1本。** §3 の傷の帳簿は
**新しい引数を1本も足さずに書けるか**を Phase 0 で確定させること。
足さずに書けないなら、**既存のノブに1ビット畳む**か、**この期では帳簿を諦めて差し替えだけをやる**。

**`shard check` が通っても `compare` が落ちることがある**（第138期。呼び出し口でフレーム量が違う）。
**必ず `docs/` の再生成まで通して確認する。**

### Q0-2. `UnitCatalog.All` から外すと何が壊れるか
**エグは `Presets` に 6 箇所で参照されている**（Web 側が grep して数えた。**数え直すこと**）:

| 帯 | 行 | エグの席 |
|---|---|---|
| `compare` | `刻み×抉り (ノミ×エグ)` | 前1 |
| `compare` | `逸らし改 (ソラ×ノミ)` | 前1（**埋め草**） |
| `compare` | `止め (トメ×ソラ)` | 前1（**埋め草**） |
| `compare` | （319行目付近・行名を確認） | 後3 |
| `compare` | （343行目付近・行名を確認） | 後3 |
| 交差帯 | `傷×被弾 (カド×ノミ×ノノ)` | 後3 |

**`All` は「編成に選べる52枚」の定義であって、`Presets` が参照できる集合ではない**
（第108期にハリを `All` から外したときも `Presets.Cross` には残した）。
**したがって `All` から外しても `compare` 305 セルは構造的に 0 件差分のはず。** これを検算する。

**行からエグを抜くことはしない。** 第108期が「**計測器と測定対象を同時に動かさない**」と書いた通り。
特に `刻み×抉り` → `逸らし改` → `止め` は**1枚ずつしか違わない鎖**になっていて、
エグは鎖の土台の一部である（`Presets.cs` のコメントに明記）。

### Q0-3. ガレを載せる行をどう作るか（**この期で唯一、盤面が動く場所**）
ガレが `All` に入っても、`Presets` のどの行にも居なければ**主判定の帯で一度も測られない**
（セッキ3行・ヒビ5行と同じ露出不足の形）。

**61 行を維持したまま1行を差し替える**のが既定。**行数を増やさない**理由:
`BattleSim/Program.cs` に「`compare` 61 行」を文字列や本数で書いている箇所が複数ある
（1074 / 1162 / 1164 / 1186 行目付近）。**何が 61 に依存しているかを走査して報告する。**
増やすほうが安全だと分かったならそれでよいが、**依存を数え上げてから決めること。**

差し替える行の候補と根拠:

| 候補 | 根拠 | 懸念 |
|---|---|---|
| **`刻み×澱み (ノミ×ミオ)`** | **第109期が「傷軸の読み手を測る行として機能していない」と明記**（ミオの機構の帰属 −0.8pt。`ablate` の −4.0pt は「体 +5.8 ／ 機構 0」の合成だった）。同期が「**この期では行を変えていない**」と持ち越している | ミオが `compare` から消えるなら、他の行に居るかを確認する |
| `刻み×抉り (ノミ×エグ)` | 切る駒の行そのもの。第109期が「`刻み×断ち` と5枚組が一文字も違わない」と記録 | **`逸らし改`・`止め` の鎖の土台**。外すと鎖が切れる。**推奨しない** |

**推奨は `刻み×澱み` の差し替え。** ただし Phase 0 で
「ミオが他の `compare` 行に在席しているか」「第109期以降にこの行を使った期が無いか」を
`design/*.md` に走査を当てて確認すること（走査は `design/*.md` のみ。第134期に3回踏んだ穴）。

**新しい行の構成は第138期の台A をそのまま使う。**
**ガレ ＋ ヒビ ＋ ウロ ＋ ガルド ＋ ドルガ**（M=3 で 82.1%・V0 は 48.5%）。
第138期が42組を走査して「帯（40〜95%）に入るのは2通りだけで、どちらも**壁＋大打点**の組」と
結論した組そのものなので、**床にも天井にも落ちないことが既に測ってある**。
行名は `礫 (ガレ×ヒビ×ウロ)` を仮案とする。

### Q0-4. 傷の帳簿に必要な計数は既にあるか
§3 で取りたいのは次の4つ。**既にある計数で出せるものは新しく足さない**（第135期の則）。

1. キリ・ノミが**書いた傷**の総量／戦
2. そのうち**エグ・ナタ・ミオ・ノノが読んだ**量（読み手ごと）
3. **読まれずに消えた在庫**（敵が倒れた時点で残っていた傷）
4. ナタの「**傷が2つ開くまで刃が下りない**」で**待った手番**の回数

3 と 4 が次期のナタ判断の核心になる。**無ければ足すが、Q0-1 の制約を先に満たすこと。**

## 7. この期では決めないこと

- **ナタを切るか**（この期の帳簿を見てから。傷の在庫が読まれずに消えているなら次期の第一候補）
- **傷軸を作り直すか**（切るのではなく直す道もある。帳簿が出てから）
- **バサの入れ替えの範囲を絞る**（無差別に2体を入れ替えるので、初期配置の情報が数ターンで消える。
  **ササ転生の前提条件**なので、その前にやる）
- **ササの転生**（散開の35%軽減を落とし、「被弾すると隣接する味方を弾き、同時に破片を付与する」へ。
  第138期の「**破片は読み手に集まる通貨ではない。生き延びた駒に溜まる**」＝
  砕けが等量を配るせいで在庫が散り、ガレは最大保持者1体しか砕けないので**残りが死蔵される**、
  への直接の答えになる。HPを上げるかは別途。**鍵が「自分の被弾」なので前衛前提**）
- **場の回復を破片に変える対称ルール**（礫の敵側分岐のイネーブラ。
  第138期の **`ShrapnelFoeTargets` = 0 が点灯確認の回帰値**。
  現状、敵側に回るのは**第二波の施しの司祭長の毎ターン14 だけ**）
- **`SelfDamagePercent` を振る／`lethal: true`** ／ **礫を周期（`[Attack, Skill]`）にするか**
- **号令 × 全体攻撃 × 軛の3者**（第138期に見つけた穴。通し率 100% → 39.8%）
- **膠着**（`反撃 (ヒサ×カド)` 第3波 100→0。第136期からの持ち越し）
