### Q0-2 「味方が 0 体」の判定の入口

- 死ぬ経路は `ApplyDamage` の `HandleDeath` 1箇所だけ（第135期の帳簿のコメント）。`HandleDeath` の通知の順は **killer の `OnKill` → 本人の `OnDeath`（ムグの分裂＝胞子の召喚）→ 全員の `OnAnyDeath` → 味方の `OnAllyDeath`（ヴェルの蘇生）**。
- **ガルドの `OnAllyDeath` で「自分以外の生きている味方が 0」を数える。** 分裂の胞子は `OnDeath` で既に湧いているので数に入る（庇いの対象と同じく `LivingMembers` で数える）。
- ヴェルの蘇生はヴェル自身が生きていないと走らない（`ReviverTrait.OnAllyDeath` の頭）ので、**ヴェルが生きている間はガルドの数えは 0 にならない**——`OnAllyDeath` 同士の順（席番号順）に依らない。ヴェルが最後に倒れた時は蘇生は起きない。
- **リィカは召喚も蘇生もしない**（墓守の層は `OnAnyDeath` で積むだけ）。
- 一度剣の段に入ったら戻らない（`Counters` の印・指示書 §2.1）。蘇生で味方が戻っても剣の段のまま。

### Q0-3 受け流しを捨てて構え直さない

- 在庫は3箇所で書かれる——開戦時（`ParryTrait.OnBattleStart`）・毎ターン頭の構え（`ParryTrait.OnTurnStart`）・庇いの見返り（`GuardianTrait.Reward`）。engine の受け流しの出口は `在庫 > 0` を見るだけ。
- 剣の段に入った瞬間に在庫を 0 にし、**構え（`OnTurnStart`）と見返り（`Reward`）は剣の段の印を見て止める**。見返りは蘇生で味方が戻った後に庇ったときだけ起きうるので、止めたぶんは計数（`ParryRefillGuardWasted` と別に数える）。
- 攻撃しない面（`ParryTrait.CanAct`）も剣の段の印を見て、攻撃を常に通す。
- **盾剣の版は在庫に触らない**（構えも見返りもそのまま）。`CanAct` だけ常に通す。

### Q0-4 持ち越し

- 剣の段の印は `Counters` の私有キーで、`StatusKeys` ではない。**`OnCarryOver` で 0 に戻し、`OnBattleStart` でも 0 に戻す**（受け流しの在庫と同じ作法）。会戦（`EngagementEngine.Run`）も作戦マップ（`CrossBoundary`）も `OnCarryOver` を通る（`Engagement.cs` の境界の1箇所）。

**在庫が 0 に届く（敵が2回以上殴る）盤面では殴らないまま**なので、上の打ち切り 38.4% はその残り。

### Q0-6 被弾後に反撃する入口と、倒れる一撃

- 反撃の既存の入口は `Trait.OnDamaged`（棘＝`ThornsTrait`・仇討ち系）で、**`ApplyDamage` は `OnDamaged` を `HandleDeath` より前に呼ぶ**——倒れる一撃でも `OnDamaged` は鳴る。
- ただし棘・仇討ちは `ctx.CanActOutOfTurn` を通り、その門は `IsAlive` を見るので、**倒れる一撃には返さない**。相打ちを書くには門を「生きている」以外は同じまま通す必要がある（下の実装判断）。
- 反撃は `ctx.Reaction(...)` の中で `ApplyDamage(source, 量, self)` を直に呼ぶ——**標的選択（`SelectTargetChain`）を通らない**ので、**敵の殉教者の庇いは斬り返しを横取りしない**（棘・仇討ちと同じ）。
- 「刻み・敵以外の出どころ」は、`source` が null（毒・燃焼の刻み）／同じ陣営／`ctx.Hit` の `Levy`・`FriendlyFire`・`Relayed` で弾く。

### 実装の判断（指示書に無かったもの）

- **斬り返しは粛の窓口を通す**（`OutOfTurnRoute` に8本目 `LastStand` を足す）。斬り返しはターン外の行動で、棘・仇討ちと同じ族。
  倒れる一撃では「生きている」だけを外して同じ門を問う（`CanActOutOfTurn` に `dying` を足す。既存の呼び出しは答えが1ビットも変わらない）。
  **第二波（粛）では伝令が生きている間、斬り返しは出ない。**
- 斬り返しは `Reaction` の中で撃つので、反撃の中で受けた一撃には返さない（棘と同じ）。

## 追加の指示（実装中・ポン）: 剣＋傷を規定の版に

> 剣の段に移る瞬間、その戦でガルドが庇いで身に受けたダメージの累計（受け流しで無かったことにした分は含めない）の 10%

> 加えた量は `ModifyAttack` の系統で持ち、他者の強化ではない（支援拒否に止められない）。
> 帳簿に「剣を抜いたときの累計の傷」と「加えた攻撃力」を足すこと。

- 札 `TraitId.LastStandScar`（`LastStandScarTrait`）をガルドに載せ、**剣の版（`LastStand`）は保持者 0 枚の対照**に回した。

  **受け流した一撃は `OnDamaged` まで届かない**ので入らない（破片が全部吸った一撃も入らない）。開戦時と会戦の境界で 0 に戻す。
- 加えた量は `Counters` の私有キー（`ScarAtkKey`）で持ち、`ModifyAttack` が読む（`AtkBonus` を触らない＝支援拒否の外）。
- **決めたこと: 剣の段の攻撃力は（素の攻撃力 ＋ 加えた量）× 2。** 「攻撃力に加える」と「剣の段は攻撃力 ×2」を字義どおり重ねたので、加えた量にも倍が乗る。
  逆の読み（素の ×2 ＋ 加えた量）にするなら `LastStandTrait.ModifyAttack` の1行。
- 帳簿: `UnitTally.LastStandScarTaken`（抜いたときの累計・版に依らず）／ `LastStandScarAtk`（加えた攻撃力・剣＋傷だけ）。

## 実装

- 札4枚（`Traits.cs`）: `LastStandScar`（規定）／ `LastStand`（剣・対照）／ `LastStandPlain`（返しなし・対照）／ `LastStandShield`（盾剣・参考）。本体は `LastStandTrait` 1クラスで、版は3つの仮想プロパティ（盾を捨てる・×2と薙ぎ・斬り返す）と傷の換算。
- **入る口**: `OnAllyDeath` と、**最後の1体のまま入った次の戦の `OnBattleStart`**（会戦・作戦マップ。味方が倒れる瞬間が二度と来ないので、ここで数えないと受け流しで耐えるだけの戦に戻る）。**指示書に無かったので足した。**
- **受け流しを捨てる**: 入った瞬間に在庫を 0 に。`ParryTrait.OnTurnStart`（構え）と `GuardianTrait.Reward`（見返り）が `LastStandTrait.ShieldDropped` を見て止まる。`ParryTrait.CanAct` は剣の段なら（盾剣も）攻撃を通す。
- **斬り返し**: `OnDamaged` から `Reaction` の中で `ApplyDamage(敵, 攻撃力, ガルド)`。弾くのは 出どころ無し（刻み）・同じ陣営・`Hit.Levy`／`FriendlyFire`／`Relayed`・反撃の中。**粛の窓口を通す**（`OutOfTurnRoute.LastStand`・8 本目）。倒れる一撃では `CanActOutOfTurn(…, dying: true)`——「生きている」だけを外した同じ門。**既存の呼び出しは答えが1ビットも変わらない。**
- **engine に足したのは**: `CanActOutOfTurn` の `dying`、`OutOfTurnRoute.LastStand`、表示専用の `BattleEventKind.LastStand` / `LastStandRiposte`（`Slot = 1` が相打ち）、受け流しの出口の計数1行（剣の段に入った後に受け流した回数）。**判定・乱数は0**。`Run` の引数は増やしていない。
- **両者が倒れた戦は負け**（`playerWon` は「味方が残り、敵がいない」）。相打ちで最後の敵を倒しても勝ちにはならない。

### 読み

1. **30 ターンの打ち切りは消えた**（入った戦で 38.4% → 0.0%・在席行全体で 6.5 → 1.4%・決着T 9.16 → 7.91）。ポンの観察「最後の一人でただ耐えて 30 ターン」は構造的に起きなくなった。
2. **ただし打ち切りは勝ちではなく負けへ移った**（R305）。抜いた時点で HP 40%・敵 2.57 体で、**毎ターン 2 回の無効化を捨てると平均 0.9 ターンで倒れる**。勝ちに移ったのは 7.5pt（18.3 → 25.8%）。
3. **盾剣は同じ戦で勝率 62.1%**——受け流しを残したまま毎手番 ×1・単体で振るだけで、打ち切りも 4.5% まで減る。**勝ち負けの数字だけなら盾剣のほうがはるかに強い**（在席行 +5.7pt 対 +1.0pt）。第152期の `WhenStocked` は「在庫が残る手番だけ殴る」なので、敵が2回以上殴ると殴らないまま——盾剣はそこを「在庫に関わらず毎手番殴る」にした版で、それだけで打ち切りの大半が解ける。
4. **斬り返しと相打ちが剣の段のダメージの 3 分の 2**（予測 6 は ○）。返しなしの版は剣より勝率が 7.2pt 低い——斬り返しは効いている。相打ちは入った戦の 64% で起きる（絵としては毎回に近い頻度で出る）。
5. **剣＋傷の上乗せは小さい**（平均 +1.25、×2 で1発 +2.5）。庇って身に受けた傷の累計が平均 16.1 しかない——**庇った一撃の大半は受け流しが消していて、身に受けていない**（在庫 2 ＋ 庇うたび 1 戻る）。傷が溜まる行（`引き受け`・`渡し`・`分かち×逆しま` の 23.5 前後）でも +2 に届かない。剣＋傷 − 剣 は在席行で +0.3pt・入った戦の勝率で +2.1pt。

### 台本（§6-6）

- **剣を抜いた瞬間**: `BattleEventKind.LastStand`（`ActorId` = `TargetId` = ガルド、`Amount` = 抜いた後の攻撃力、`SourceTrait` = 版）。最後の味方の `Death` の直後に並ぶ（会戦で最後の1体のまま入った戦は開戦時）。
- **剣の段の手番**: 通常の `Attack`（剣の版は薙ぎ・巻き込みの `Damage` が並ぶ）。**「剣の段の一撃」を示す専用の印は無い**——`LastStand` の後のガルドの `Attack` がすべてそれ。
- **斬り返し**: `BattleEventKind.LastStandRiposte`（`ActorId` = ガルド、`TargetId` = 殴ってきた敵、`Reaction = true`）→ 斬り返しの `Damage`。**`Slot = 1` なら相打ち**で、その後にガルドの `Death` が並ぶ。
- DemoApp は未知のイベントを素通りするので、再生は完走する（`礫` 第五波 seed 9・`燃焼` 第五波 seed 3 で `DEMO_SMOKE_COMPLETE`）。**演出は Codex 側。**
  例: `礫 (ガレ×ヒビ×ウロ)` 第五波 seed 9 は、第8ターンにウロが倒れて抜き（傷 49 → +4）、2回斬り返し、第9ターンに審問官と相打ちで倒れる（負け）。
