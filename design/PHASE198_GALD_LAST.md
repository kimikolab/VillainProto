### Q0-2 「味方が 0 体」の判定の入口

- 死ぬ経路は `ApplyDamage` の `HandleDeath` 1箇所だけ（第135期の帳簿のコメント）。`HandleDeath` の通知の順は **killer の `OnKill` → 本人の `OnDeath`（ムグの分裂＝胞子の召喚）→ 全員の `OnAnyDeath` → 味方の `OnAllyDeath`（ヴェルの蘇生）**。
- **ガルドの `OnAllyDeath` で「自分以外の生きている味方が 0」を数える。** 分裂の胞子は `OnDeath` で既に湧いているので数に入る（庇いの対象と同じく `LivingMembers` で数える）。
- ヴェルの蘇生はヴェル自身が生きていないと走らない（`ReviverTrait.OnAllyDeath` の頭）ので、**ヴェルが生きている間はガルドの数えは 0 にならない**——`OnAllyDeath` 同士の順（席番号順）に依らない。ヴェルが最後に倒れた時は蘇生は起きない。
- **リィカは召喚も蘇生もしない**（墓守の層は `OnAnyDeath` で積むだけ）。
- 一度剣の段に入ったら戻らない（`Counters` の印・指示書 §2.1）。蘇生で味方が戻っても剣の段のまま。

### Q0-3 受け流しを捨てて構え直さない

- 在庫は3箇所で書かれる——開戦時（`ParryTrait.OnBattleStart`）・毎ターン頭の構え（`ParryTrait.OnTurnStart`）・庇いの見返り（`GuardianTrait.Reward`）。engine の受け流しの出口は `在庫 > 0` を見るだけ。
- 剣の段に入った瞬間に在庫を 0 にし、**構え（`OnTurnStart`）と見返り（`Reward`）は剣の段の印を見て止める**。見返りは蘇生で味方が戻った後に庇ったときだけ起きうるので、止めたぶんは計数（`ParryRefillGuardWasted` と別に数える）。
- 攻撃しない面（`ParryTrait.CanAct`）も剣の段の印を見て、攻撃を常に通す。
- **盾剣の版は在庫に触らない**（構えも見返りもそのまま）。`CanAct` だけ常に通す。

### Q0-4 持ち越し

- 剣の段の印は `Counters` の私有キーで、`StatusKeys` ではない。**`OnCarryOver` で 0 に戻し、`OnBattleStart` でも 0 に戻す**（受け流しの在庫と同じ作法）。会戦（`EngagementEngine.Run`）も作戦マップ（`CrossBoundary`）も `OnCarryOver` を通る（`Engagement.cs` の境界の1箇所）。

### Q0-5 過去の類似測定

`design/` を「最後の一人」「最後の1体」「last stand」「孤立」で grep。**該当は 0 件**（「孤立」は第80期の組の相乗の用語で、別の話）。
近いのは第152期（膠着を塞ぐ・`ParrySwing.WhenStocked`）——あの期は「在庫が残っている手番は殴る」で `反撃 (ヒサ×カド)` 第三波の膠着を消したが、
**在庫が 0 に届く（敵が2回以上殴る）盤面では殴らないまま**なので、上の打ち切り 38.4% はその残り。

### Q0-6 被弾後に反撃する入口と、倒れる一撃

- 反撃の既存の入口は `Trait.OnDamaged`（棘＝`ThornsTrait`・仇討ち系）で、**`ApplyDamage` は `OnDamaged` を `HandleDeath` より前に呼ぶ**——倒れる一撃でも `OnDamaged` は鳴る。
- ただし棘・仇討ちは `ctx.CanActOutOfTurn` を通り、その門は `IsAlive` を見るので、**倒れる一撃には返さない**。相打ちを書くには門を「生きている」以外は同じまま通す必要がある（下の実装判断）。
- 反撃は `ctx.Reaction(...)` の中で `ApplyDamage(source, 量, self)` を直に呼ぶ——**標的選択（`SelectTargetChain`）を通らない**ので、**敵の殉教者の庇いは斬り返しを横取りしない**（棘・仇討ちと同じ）。
- 「刻み・敵以外の出どころ」は、`source` が null（毒・燃焼の刻み）／同じ陣営／`ctx.Hit` の `Levy`・`FriendlyFire`・`Relayed` で弾く。

### 実装の判断（指示書に無かったもの）

- **斬り返しは粛の窓口を通す**（`OutOfTurnRoute` に8本目 `LastStand` を足す）。斬り返しはターン外の行動で、棘・仇討ちと同じ族。
  倒れる一撃では「生きている」だけを外して同じ門を問う（`CanActOutOfTurn` に `dying` を足す。既存の呼び出しは答えが1ビットも変わらない）。
  **第二波（粛）では伝令が生きている間、斬り返しは出ない。**
- 斬り返しは `Reaction` の中で撃つので、反撃の中で受けた一撃には返さない（棘と同じ）。

## 予測（実装前に宣言）

1. **ガルドを含まない 26 行 × 5 波 ＝ 130 セルは ±0.0**。「無」の版は第197期の表と 305 セル一致。
2. **剣の段に入る戦は Q0-1 の「最後の1体」とちょうど同じ 13.0%**（入るまでの盤面は版に依らず1ビットも違わない）。入るターンも同じ 5.9。
3. 在席行の勝率の動きは小さい——**+1〜+3pt**（13.0% × 最後の1体の戦の勝率の伸び）。動くのはほぼ第五波。
4. 剣の段に入った戦では、**打ち切り 38.4% → 5% 以下**、残りT 11.6 → 半分以下。勝率は 18.3% → **25〜35%**（打ち切りの多くは倒れる側へ移る）。
5. **剣は盾剣より早く倒れるが、勝ちも多い**。盾剣は打ち切りが無より減るが、剣ほどは減らない（在庫がある分だけ耐えて殴るので長引く）。
6. **剣の段のダメージは、手番の薙ぎより斬り返しのほうが多い**（残り 2.57 体がそれぞれ毎ターン殴るので、1ターンに薙ぎ1回に対し斬り返し 2 回以上）。
7. 返しなしの版は剣より勝ちが少なく、倒れるまでのターンは同じくらい。
8. 第二波は粛で斬り返しが止まるので、剣の段の斬り返しの割合が他の波より低い。
