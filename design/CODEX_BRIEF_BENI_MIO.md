# Codex 向け発注メモ —— 「隣で毒が薬になる」「刻みが濃くなっていく」を絵で見せる

置き場所: `design/CODEX_BRIEF_BENI_MIO.md`。触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。
台本に足りないデータは §3 のとおり Claude Code 側で先に足す。**§3 が入る前に、§3 に依存する部分へ着手しないこと。**
台本に依存しない下準備（素材・エフェクトの試作）は先に進めてよい。

## 1. 何が起きているか（第190〜194期）

### 1-1. 毒喰らいのベニ —— 反転の結界

- **ベニ自身とベニに隣接する味方**は、毒と燃焼で削られる代わりに**回復する**（カタの起爆の味方側も同じ）
- その代わり、ベニ自身と隣の味方が**回復を受けるとダメージになる**（ノノ・ヴェルなどの回復が味方を傷つける）
- ベニは攻撃しない。手番は **火 → 毒 → 毒** の周期で、隣の味方全員に火を点けるか、毒を1層積む
- 隣で満タンのため溢れた回復は、**ベニに流れ込む**（啜り）
- 今の画面では、隣の味方に毒のエフェクトが出た直後に回復の数字が出るだけで、**なぜ癒えたのかが分からない**。
  反転の裏は**回復役が味方を殴ったように見える**

### 1-2. 澱みのミオ —— 濃縮の印

- ミオは攻撃しない。手番で、(1) 毒のある敵全員の毒を +4 層、(2) **次の刻みが最も大きい敵とその隣の敵に「濃縮の印」を +1** する
- 代金として、**ミオに隣接する味方にも印が +1** される
- 印が n の駒は、毒と燃焼の刻みを**同じ量で 1+n 回**受ける（起爆も 1+n 回）。印は戦闘中は消えず、重なっていく
- 今の画面では、ミオが何をしたかが見えず、ある時から刻みの数字が何度も出るようになるだけ。**ポンの感想: 動きが画面上でよくわからない**

## 2. 欲しい絵

### 2-1. ベニ: 結界の範囲

- ベニと隣の味方を包む、**薄い紅紫の結界**（足元の光の輪や、駒どうしを結ぶ淡い帯）を常時出す
- 入れ替え・ベニの死亡で範囲が変わったら、即座に付け替える／消す
- 狙い: 「誰が内側にいるか」が一目で分かること。**ベニが倒れた瞬間に結界が消え、隣の火と毒が本物のダメージに戻る**のが見えること

### 2-2. ベニ: 手番の火と毒を描き分ける

- **火の拍**: ベニから隣の味方全員へ、**紅い火の粉**が流れて小さく燃え移る
- **毒の拍**: ベニから隣の味方全員へ、**紫の澱みがしたたる**
- 周期が「火 → 毒 → 毒」と画面で読めること。手番の見分けは `Skill` の `Label`（火＝`KindleTrait.Label`「火を分けた」／毒＝「澱みを分けた」）

### 2-3. ベニ: 反転の刻み（毒・燃焼が薬になる）

- 結界の内側の駒の刻みは、**いつもの毒・燃焼のエフェクトで始まり、途中で回復の色（緑や白金）へ裏返って**癒える
- 「削られるはずが癒えた」ことが、エフェクトの**色の反転**で分かるのが狙い。数字は回復の色

### 2-4. ベニ: 反転の裏（回復がダメージになる）

- 回復役の光はいつもどおり相手に届くが、**届いた瞬間に濁った紫黒へ裏返って**ダメージになる
- **攻撃の刃とは違う絵**にすること（回復役が殴ったように見せない）
- 台本: `HealInverted`（`ActorId` = 回復させた駒・`TargetId` = 受けた駒・`Amount` = 量・`Text` = ベニの名前）の直後に `Damage` が1件並ぶ

### 2-5. ベニ: 啜り

- 溢れた隣の味方から、**紅い雫がベニへ吸い寄せられて**ベニが癒える（手番の火の粉の逆向きの流れ）
- 台本: `InverseSip`（`ActorId` = ベニ・`TargetId` = 溢れた味方・`Amount` = 溢れの量）の直後に、ベニ → ベニの `Heal` が1件並ぶ

### 2-6. ミオ: 濃縮（+4層）

- ミオの手番で、毒のある敵全員に**濁った水滴が落ち**、毒のアイコンがどくんと脈打つ
- ※ 今の台本にはこの瞬間のイベントが無い（§3-2）

### 2-7. ミオ: 印を付ける

- 中心の敵に**濃い渦**が落ち、そこから**波紋が隣の敵へ広がって**同じ渦が付く（「周りまで濃くなる」が見える）
- **同じ波紋が、ミオから隣の味方にも広がる**（代金が見える）
- 印は**状態アイコンとして残し、数 n を点や輪の数で見せる**（文字を足さない）。回を重ねるほど渦が濃く・大きくなるとよい
- 台本: `ConcentrateMark`（`ActorId` = ミオ・`TargetId` = 付いた駒・`Amount` = 足した後の n・`Text` = 「中心」「周り」「漏れ」）

### 2-8. ミオ: 刻みが 1+n 回来る

- 印のある駒の刻みは、**同じエフェクトが続けて 1+n 回**弾ける。回数が増えるほど**間隔が詰まり、最後の1回が強く光る**
- 数字は重ねて積み上がるように出す（「×n」の文字は出さない）
- 2倍速で間延びしないよう、**1駒の刻み全体の尺に上限**を置く（回数が多いほど1回あたりを短くする）
- 狙い: 戦闘が進むにつれて、**刻みの回数が目に見えて増えていく**こと

**まず 2-3（反転の刻み）と 2-8（刻みの回数）を1つずつ作って、ポンが見てから調整する。** 次に 2-7、2-1、残りの順。

## 3. 前提 —— Claude Code 側で台本に足すもの（表示専用・盤面は1ビットも動かさない）

1. **反転の刻みの印**: 反転した刻みの `Status` イベント（`BattleEngine.PoisonTickOnce` ほか、燃焼・起爆の味方側の反転の枝）に、
   `SourceTrait = TraitId.Inverse` と**反転させたベニの InstanceId**（`ActorId`）を載せる。今は反転しない刻みと見分けが付かない
2. **濃縮（+4層）の瞬間**: `AmplifierTrait.Thicken` で層を足した瞬間に、表示専用のイベントを出す
   （`ActorId` = ミオ・`TargetId` = 敵・`Amount` = 足した後の層）。傷口への着火も同じ形でよい（`Text` で区別）
3. **刻みの何回目か**: 印による刻みの繰り返しで、各 `Status` に「何回目か／全部で何回か」を載せる
   （既存のフィールドで足りなければ最小限で足す）。尺の圧縮と「最後の1回を強く」に使う
4. **印の残量**: ターン頭の状態の残量（`Status` とは別の「残量」イベント）に `StatusKeys.Concentrated` が含まれているか確認し、無ければ足す。アイコンの n に使う

受け入れ: `compare` 0件差分・`audit` ずれ0件・台本にイベントが並ぶこと。
終わったら Codex が使うフィールド名を短くまとめる。

### 3-A. 入ったもの（Claude Code・済み）

**盤面は1ビットも動いていない**（`compare` 305 セルは `docs/balance.md` と完全一致・`audit` ずれ 0 件。
`docs/` で動いたのは `watch.md` の3行＝新しい種類1つと印の表示名だけ）。`BattleEvent` を直接読めば足りる
（`replay` の JSON にも `inverter` / `tickIndex` / `tickCount` を足した）。

| 用途 | 読むもの |
|---|---|
| 2-3 反転の刻み | `Kind == Status` かつ **`SourceTrait == TraitId.Inverse`**。**`InverterId`** = 反転させたベニ。直後に `HealInverted` ではなく**回復**（`Heal`）が並ぶ。毒・燃焼の刻みと起爆（カタ）の味方側の3箇所すべて。**起爆では `ActorId` はカタのまま**なので、ベニは必ず `InverterId` から引く（指示書の「`ActorId` に載せる」から変えた） |
| 2-6 濃縮（+4層） | 新しい種類 **`BattleEventKind.PoisonThicken`**。`ActorId` = ミオ・`TargetId` = 敵・`Amount` = 足した**後**の層・`Text` = `ThickenLabels.Thicken`（「濃縮」）／ `ThickenLabels.Ignite`（「着火」・既定では出ない）・`SourceTrait` = `Amplifier`。ミオの `Skill` の後、`ConcentrateMark` より前に並ぶ |
| 2-8 刻みが 1+n 回 | `Status` の **`TickIndex`**（何回目か・1 始まり）と **`TickCount`**（全部で何回の予定か＝1+n）。**印の無い刻みは両方 `null`**。途中で倒れた駒は `TickIndex == TickCount` まで届かない（最後の1回を強く光らせるなら「その駒の次の件が無い」でも判定すること）。毒・燃焼の刻みと起爆に載る |
| 2-7 印の残量 | ターン頭の `StatusSnapshot` に元から載っていた。**表示名が生のキー `concentrated` だったので「濃」にした**（`StatusKeys.LabelOf`）。`Text == "濃"`・`Amount` = n。付いた瞬間は従来どおり `ConcentrateMark` |

## 4. 守ってほしいこと

- **文字を足さない**（2倍速で読めない・第171期）
- 良し悪しは言わない。起きたことを見せるだけ
- 既存の演出と混ぜない: 呪いの泥の筋（ムド）・毒の紫の飛沫（ラウ）・ヒサの守りの標・範囲の盾（バン）
- ベニの色は**紅**、ミオの色は**濁った水（深緑〜黒紫）**を軸にして、2枚を見分けられるようにする
- ベニの立ち絵は鬼娘版が入ったばかり。結界や火の粉の色味は立ち絵に合わせてよい
