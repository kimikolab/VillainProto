# 毒軸のまとめ（第366〜375期）

第366〜375期の毒軸の立て直し（グザ ／ ヴィオ ／ スィド）で決まったことを短くまとめる。詳しい数字は各期の報告（`design/PHASE366_*.md` 〜 `design/PHASE375_POISON_CLOSE.md`）。代表の台の数字は `sh375 summary`（`.tmp/p375/summary.md`）。

## 1. 像

**「敵はピンピンしているのに、もう死んでいる」**——時間差のダメージ。毒は書いた瞬間には何も起きず、ターンの頭の刻みで層の分だけ削る。だから毒の軸の強さは「いつ積み始めるか」と「どれだけ速く積むか」で決まる。

## 3. ループの図

    グザの噴き出し ──→ 味方の毒 ──┐
                                    ├→ ヴィオが吸う ─→ 攻撃力 ─→ 攻撃力ぶんの毒（× 連撃）─→ 敵の毒 ─┐
    敵が味方を殴る ─→ 返り毒 ──────┘                                                                  │
         ↑                                                                                           │
         └──────────────────────── 敵の毒（大きな池）←─────────────────────────────────────────────┘
                                         ↑                         │
    スィドの開戦の衣 → 殴られる → 衣の返し ┘                         └→ 敵に書かれた毒の累計 → グザの段が上がる → 噴き出しが増える

- **大きな池は敵の毒**。返り毒はその池から味方へ戻る矢印で、ヴィオがそれを攻撃力に変えて池へ返す——ここで増幅する。
- スィドは別の口から池に注ぐ（殴られるたびに層と同じだけ）。開戦の衣で T1 から注げる。ヴィオは衣の持ち主から吸わないので取り合わない。

## 6. 分かった原則（設計の原則に足す候補）

1. **増幅は大きな池からこちらへ戻る矢印で作る**——小さな池（味方の毒）から敵へ流しても増えない（第369期 → 第370期）。
2. **資源の立ち上がりが遅い軸は精鋭に負ける。開戦から立つ形で答える**——精鋭は前から崩れるので、T4 から育つ資源は間に合わない（第373期）。開戦の衣で近衛 59 → 100%（第374期）。
3. **効き目は「立つ時間」ではなく「出力」で測る**——開戦の衣でスィドが立つ時間は 1T 弱しか延びなかったが、返しの量が 5 倍になって敵が先に崩れた（第374期）。
4. **掛け算（倍）は使わず、加算の段で育てる**——倍は他の駒の工夫を埋もれさせ、層が際限なく伸びる（第367〜372期）。
5. **「相方がいないと無能」の駒のマイナスは、相方のいる台では起きないのが正しい**——相方のいない台での働きは別に数える（第374〜375期）。

## 7. 残っている点

- **紅の台の倍々**: 紅は毎ターン放つ（数万は1ターンの溜まり）。倒れない敵で 30T まで回すと敵の毒が 10 億（int の上限の 47%）——30T の打ち切りの中ではあふれない。長期戦（30T を超える本編）を作るときは注意（第373期）。DemoApp の数字は 5 桁以上の幅を確かめていない。
- **前のガルドが精鋭で T1〜2 に倒れる**（近衛 T2.1 ／ 大隊 T1.3・開戦の衣でも変わらない）。試遊・毒の大隊は 14%。
- **ガンの攻撃力の上乗せが吸いに埋もれる**（攻撃力の台で段が 0.1〜0.3T 早まるだけ・第372期）。
- **ヴィオの飢えの挙動**（第375期 §4）: 毒の台では起きない。毒の外の台では、自傷 ＋ ヴィオ（ボルグ → ヴィオ）は毎ターン飢えて攻撃力が T5 に 65 まで育つが、ボルグを抜いた台そのものが崩れる（勇者 ／ 精鋭 0%）。台 B ＋ ヴィオ（ボルグ → ヴィオ）では C で勇者 0 → 60%（4.7T）・精鋭は台 B のままより下がる（近衛 100 → 56%）。
- **台 B の勇者は第368期の H1（ヒサ）から 0%**（第367期の報告どおり・毒軸の外の話）。
