# 第151期 —— バサの手番を「突風」にする（薙ぎ化 ＋ 確率で転倒）

指示書は `design/PHASE151_GUST_SPEC.md`。**HEAD は第150期 `21135d2`。**

**この期の一文**: バサの通常攻撃を**攻7・単体 → 攻N・薙ぎ ＋ 確率で転倒**に変える。**手番は捨てない。形だけ変える。**

### 出力の勘定は、指示書の §0 と違った

**指示書 §0 は `SecondaryPercent` を勘定に入れていない。** 引き直すと結論が変わる:

| | 指示書 §0 | 実装から引き直した |
|---|---|---|
| 前1 を薙いだときの体数 | 「2〜3体。3体はほとんど出ない」 | **全5波で 3 体**（`SweepTargets(前1)` = 前3 / 中央 / ○前2） |
| 巻き込みの倍率 | （書かれていない） | **60%・整数切り捨て・床 1** |
| 攻3 × 薙ぎの出力 | 6〜9（現行 7 に近い） | **5**（3 + 1 + 1）＝ **現行を下回る** |
| 出力中立の攻撃力 | 攻3 | **攻4**（4 + 2 + 2 = 8） |

**攻3 の巻き込みが 1 点になる**（`3 * 60 / 100 = 1`）のが効いている。
**だから段A の掃引は 2 / 3 / 4 / 5 にした**——指示書が挙げた 2・3 を含み、引き直した中立点の両側を足す。

> **掃引点を分布から引いたのに、勘定を実装から引かないと予測が全部同じ向きに外れる**（第143期）。
> 今回は**実装から引き直したのが Phase 0 の中**だったので、予測（§2）はこの表の後で書いた。

### 決め

| 項目 | 決め | 理由 |
|---|---|---|
| 型 | **`Def.Pattern = Sweep`**（`ModifyPattern` は使わない） | 無条件なら窓口を使う意味が無い。`docs/units.md` の型の分布に出る |
| 攻撃力 | **`Def.Attack` を下げる**（`ModifyAttack` で減らさない） | 減らすと「素は7だが実際は3」の二重帳簿になり、`CurrentAttack` を読む側（駆り立ての選択・転嫁の流し先・`StatSnapshot`）が素の値で並べ替える（第75期） |
| 転倒の特性 | **`ShufflerTrait` に足す。新しい `TraitId` を作らない** | 同じ駒の効果は1つにまとめる（第147期） |
| 転倒のフック | **`OnAfterAttack`**（巻き込み先は `ctx.SecondaryTargets` を特性側で引き直す） | engine の呼び口は「攻撃1回につき1度・主目標のみ」。`extras` ループの**後**で呼ばれるので、その振りで倒れた相手は `IsAlive` で自然に落ちる |
| ノブ | **`GustPercent` / `GustSecondary` を `ShufflerRule` に足す** | `ShuffleStagger` の枝は増やさない（→ 次項） |

### **`ShuffleStagger` の枝を1つも足さない**

第147期は「**同じトリガーに転倒と混乱を両方は載せない**」を理由に、直交するノブではなく列挙の枝にした。
**この期の突風はその軸に乗っていない**——

    混乱     トリガー ＝ ターン頭に行が前へ変わったこと
    突風     トリガー ＝ 攻撃が当たったこと

**だから直交するノブでよく、転倒と混乱は同居する。**

### **1回の薙ぎは 3 体ではなく 2 体だった**

Phase 0 は `SweepTargets` と**開幕の占有**から「全5波で 3 体」と引いたが、**実測は 1.95〜2.07 体**
（`gust gale` の表F。4台 × 第2〜5波）。**敵が削れると薙ぎが痩せる**
——`SweepTargets` は席で引くので、その席の駒が倒れていれば巻き込みは消える。

| 攻撃力 | 紙（3体） | **実測（1振りあたり）** |
|--:|--:|--:|
| 2 | 4 | 2.89〜3.10 |
| 3 | 5 | 3.90〜4.10 |
| 4 | 8 | 5.84〜6.18 |
| **5** | **11** | **7.85〜8.27** |
| 7（現行は単体） | 15 | 6.94〜7.00（＝単体の 7） |

> **出力中立は 攻4（紙）ではなく 攻5（実測）だった。**
> 紙は「開幕の占有」、実測は「戦闘中の平均の占有」で、**前者は上限である。**
> 指示書 §0（倍率なし・攻3 が中立）→ Phase 0（倍率あり・攻4 が中立）→ 実測（攻5 が中立）と
> **2 回引き直して 2 回とも上へ動いた。**

**採ったのは 攻5。** 1振りあたり 7.85〜8.27 対 現行 6.94〜7.00 で、**出力がほぼ並ぶ最小の値**である。
攻6・攻7 は素の強化になる（攻7薙ぎは4台とも正で +3.1〜+5.0）ので採らない
——**この期の一文は「形だけ変える」**であって「強くする」ではない。

——**中央の盤面ルール持ち（軛・渇き・粛）が 4 分の 1 を占める**のは、
**巻き込みが中央へ届く唯一の経路だから**（主目標は `pool` の前列優先を通る）。

### 段C —— **巻き込みを外す絞り方は、確率で絞るより高くつく**

段C（30%・主のみ）は供給 1.11〜1.77 で、**段B 10%（0.77〜1.17）と 20%（1.47〜2.38）の間**にある。
ところが帰属は **+2.8 / +3.4 / +5.3 / +3.1** で、**同じ供給量の段B に 0.3〜1.4pt 負ける**。

**転倒の相手の列の分布は段B とほとんど同じ**（23.4〜30.6% 対 24.9〜28.8%）なので、
**巻き込みは「届く先」を変えていない。量を倍にしているだけ**である。
それでも段C が負けるのは、**1回の振りで 2 体を同時に転ばせるのと、2 回の振りで 1 体ずつ転ばせるのが
同じ量でも違う**から——前者は**同じラウンドから 2 手番を抜く。**

> **第147期の「同じ供給量でも置き場所で値段が違う」の 2 例目。**
> あちらは**時間軸**（確率は一様に撒く／回数制は前半に寄る）、こちらは**1ターンの中の束ね方**である。
