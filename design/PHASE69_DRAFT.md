## 2. 測る前に決めたこと（判定式の全文）

### 2-1. N と M を決める規則（Phase 0）

**M は 8 に固定**（パイロットで動かさない）。1標本の勝率が 4波 × 8 seed = **32 戦**で決まる（刻み 3.1pt）。

    半幅 = 1.96 × s_u / √K_u ≤ 1.5pt      s_u = 駒 u の寄与の標本間標準偏差
    K_u  = N × 5 / 51                      51 体から無作為5体。1駒あたりの在席標本数
    ⇒ N ≥ (51 / 5) × (1.96 × s_max / 1.5)²

**`s_max`（最悪の駒）で決める**——Q2 が「対象駒すべてで ±1.5pt 未満」を要求するので、
平均の s で決めると必ず半分の駒が落ちる。

パイロット（N = 800 / M = 8 / 253,200 戦・12.2 秒・20,739 戦/秒）の実測:

    s_max = 19.57pt（呪詛官ネル）
    K ≥ (1.96 × 19.57 / 1.5)² = 654
    N ≥ (51 / 5) × 654 = 6670        ⇒ **採用 N = 11,000**（上へ丸めた）

主表1帯の見積もりは **3,468,235 戦 ≒ 2.8 分**（A 帯 + B 帯で倍）で、指示書 §2-1 の 30 分の内側。
**対象駒を絞る必要は無かった**ので 30 体のまま回した。実測は A 帯 223.7 秒 / B 帯 225.4 秒。

### 9-1. **器具を揃えないと Q4 を 0.21 で読むところだった**

### 9-2. 器具の差はどこから来るか

`理想·素体` と `理想·抜き` は同じ 61 行の同じ駒を測っているのに、**最大 41.8pt 違う**。

「`ablate` は駒を1体減らすので寄与に『5体目の体そのもの』が必ず混ざる」と書いたとおり。

差が大きいのは **責め苦のシガ（素体 +2.1 対 抜き +34.2）・抉りのエグ（−0.4 対 +33.5）・
断ちのナタ（−17.4 対 +24.4）・縫いのハリ（+3.8 対 +35.8）**——
**傷・痺の4枚に集中している。** この4枚は**特性を外しても体としては十分に働く**ので、

**断ちのナタは理想編成でも素体差し替えでは −17.4pt**（＝**特性を外したほうが強い**）。
第37・38期が2期かけて周期を作り込んだ駒だが、**5体編成の枠として見ると
「手番を放棄する」代金が特性の利得を上回っている。**

### 9-3. P6 は当たった（r < 0.5）

**ドラフト台は理想編成の言い換えではない。** 指示書 §5 の分岐表でいう **r < 0.7** の側で、

## 12. 読めること

0. **精度の条件は、台が床に落ちているほど楽に通る。**
   Q2（30 駒すべてで ±1.5pt 未満）は**通ったが、通った理由の半分は Q1 が落ちたこと**である
   ——標本の 78.9% でフルも素体も勝率 0% になり、寄与が定義上 0・分散も 0 になる。
   **次に信頼区間を判定式に使うときは、「分散が小さいのは測れているからか、動いていないからか」を
   一緒に数えること**（例: 寄与が厳密に 0 の標本の割合）。第68期 Q1 と同じ形の**5例目。**

1. **無作為に5体を引くと、8割が「第2〜5波を1つも勝てない」編成になる。**
   平均 6.58%・中間帯 17.9%・**天井の標本は 11,000 中 0 件**。
   **理想編成 61 行の平均（第2〜5波で 59.4%）との差は 9 倍。**
   60 期分の採否が乗ってきた台は、**この分布の上位 0.1% に相当する場所である。**

2. **配置の価値は波ごとに符号が割れる**（この期でいちばん再現性の高い信号）。
   規則配置（硬い2枚を前・攻撃力の高い2枚を後）は
   **第3波 +1.48 / 第4波 +1.33 / 第5波 −1.02**（両 seed 帯で再現）。
   全体の +0.52pt は**打ち消しの残りかす**で、第52期の分類でいう **(c) 型**である。
   **「配置は価値を持たない」ではなく「ひとつの規則では波ごとに符号が逆を向く」。**
   ただし Q1 が落ちているので、この読みは**床に落ちていない 21.1% の標本の上での話。**

3. **相方の有無で寄与が動く 12 体は、12 体とも「相方がいないと弱い」側**
   ——判定式は符号を要求していないのに、片側にしか出なかった。
   **第68期の理想編成では正3体（ソラ +28.9 / ボルグ +12.4 / カド +10.2）が出ていた**が、
   **その3体はいずれも相方なし行が 1 行しか無かった。**
   **「相方がいないほうが強い」は、n = 1 の行が作った像だった可能性が高い。**

4. **相方なしの寄与が「ちょうど +0.0」になる駒が 8 体**（ホタ・ベニ・ワタ・ヴィオ・ミオ・ウツ・ウケ・ハネ）。
   これは丸めではなく**床**である。**Q5 の「相方は要るか ○」は、
   正確には「相方がいないと寄与が測れない ○」。**

5. **枚数を増やして良くなるキーは 11 本中 2 本（移動・被弾）しかない。**
   残り9キーは**1枚目でまず勝率が下がる**（毒 −2.39 / 傷 −2.80 / 燃 −2.85）。
   下がるのは**枠を1つ使う機会費用**（そのキーを持たない殴り役が1枚減る）で、
   **移動と被弾だけがその費用を1枚目から取り返している。**
   **第68期の「時間に分布する2本（被弾・強化）」とは1本しか重ならない**——強化はここでは単調に下がる。

6. **移動軸は優加法**（+6.42 → +9.29 → +10.16）。**被弾はほぼ線形**（+4.89 → +4.88 → +6.61）。
   第67期の「移動は2枚で一人前以下・3枚で 74.5 / 77.0%」が、無作為編成の上でも同じ形で出た。

7. **`ablate`（1枚抜き）と素体差し替えは、同じ台・同じ駒でも r = 0.782 までしか一致しない**（最大差 41.8pt）。
   食い違いは**傷・痺の4枚**（シガ +2.1 対 +34.2 / エグ −0.4 対 +33.5 / ナタ −17.4 対 +24.4 /
   ハリ +3.8 対 +35.8）に集中する——**特性を外しても体としては働く駒**では、
   「抜くと弱い」と「特性が効いている」がまったく別の話になる。
   **第21期 swap の「`ablate` は 5体目の体そのものを寄与に混ぜる」の定量版。**

8. **断ちのナタは理想編成でも素体差し替えで −17.4pt**（特性を外したほうが強い）。
   第37・38期が2期かけて周期を作り込んだ駒だが、**5体編成の枠として見ると
   「手番を放棄する」代金が特性の利得を上回っている。**
   `ablate` では +24.4pt に見えるので、**この符号は素体差し替えでしか見えない。**

9. **呪詛官ネルはドラフト台で単独首位（+8.3・2位の 2.2 倍）で、相方なしでも +6.7pt。**
   呪詛は**開戦時に敵全体の攻撃力を −6** するので、**味方が誰であっても、
   自分の手番も生存時間もほとんど要らない。** 理想編成の同じ器具では +24.6pt（30 体中 **12 位**）。

10. **台で順位がいちばん上がった3枚は、3枚とも「被弾」キーを持つ**（器具を揃えた 30 体の順位）。

       泥人形ムド 20位 → **4位**（+16）／ 毒吐きのスィド 22位 → **6位**（+16）／
       後備えのセッキ 23位 → **8位**（+15）  ← いずれも被弾
       呪詛官ネル 12位 → **1位**（+11）      ← 開戦時に敵全体へ

   **下がったほうの上位は 萎縮のクビ 5位 → 27位 / 澱み喰いのヴィオ 1位 → 14位 /
   仇討ちのザン 15位 → 25位 / 爆ぜるゾト 13位 → 21位。**
   **表E で枚数効果が正だった2本（移動・被弾）のうち、被弾が順位表の上でも同じ向きに出ている。**

11. **第一波はドラフト台では 100% ではない**（92.16%・5.4% が 0%）が、**88.9% が天井**なので
    情報セルの意味では第2〜5波と同じく飽和している。**除外の指示は結論を変えていない。**
