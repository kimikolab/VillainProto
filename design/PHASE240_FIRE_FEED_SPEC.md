# 第240期 指示書 —— 火勢の影の計算 その2（保つ火と育てる火を分ける）

置き場所: `design/PHASE240_FIRE_FEED_SPEC.md`。報告は `design/PHASE240_FIRE_FEED.md`。
**盤面は変えない**。第239期の影の計算の器具（`FireScale*`）を広げて数えるだけ。

## 1. 目的

第239期で分かったこと:

- **火勢が時計になっていた**。ボルグが毎ターン隣全員に火を点け直すので、隣の火勢はターン t の終わりにちょうど t。萎む瞬間が来ず、規則（K1〜K3）を替えても値は変わらない（R342）
- ホタの段も毎戦同じ順に回るだけ
- **手番の単調さの本体はヒヨ**（強化だけの絵が 86〜100%）。3体とも手番の種類と攻撃型は 100% 同じ
- ボルグの「放つ」は最良の席で 0 回/戦（中央で守られて殴られず、自分の火勢が育たない）

ポンの方針（燃焼の軸のコンセプト「耐えて、燃え上がり、焼き尽くす」）:

- 火勢は4段。**育つ・萎む**が画面で見えること。火の大きさ＝戦力の大きさ
- **火勢を削り合って4段目に届かなくなる形は避ける**
- **ヒヨのスペシャルはターンギフト**（火勢4の味方へ手番を渡す）。得た手番は粛に封じられない（ターンを得ているのでターン外の行動ではない）
- 1ターン1手番の燃焼の軸は、**手数ではなく育てた火を一気に叩き込む**（割り込みは移動軸の色）

→ この期は、**「保つ火」と「育てる火」を分けた規則**で、火勢が時計でなくなるか、ヒヨの手番に選択が生まれるか、絵が割れるかを影で数える。

## 2. 影の規則

### 2.1 保つ火と育てる火

| 役 | 誰が | 影の火勢への効果 |
|---|---|---|
| **保つ** | 既存の着火すべて（ボルグの火の粉・火の鎧・くすぶり・焼き返し・ベニの配りほか） | 火勢0 なら 1 にする。**火勢1以上なら上げない** |
| **育てる①** | **ヒヨの煽り**（ヒヨの手番） | 燃えている味方1体の火勢 +1 |
| **育てる②** | **ボルグの余熱** | 盾の配り（D2）と火の鎧の半減で**切った量**が溜まり、閾値ごとにボルグ自身の火勢 +1 |
| 消える | 燃焼が切れた（残りターン 0） | 火勢 0 |

- 火勢の上限は4。**火勢4 の駒への育ちは「余熱」として別に数える**
- 敵の影の火勢は第239期の K1 のまま（比較用）

### 2.2 萎み方（3通り）

| 規則 | 内容 |
|---|---|
| W1 | そのターンに育たなければ −1（燃えている間は 1 未満にしない） |
| W2 | 2ターン続けて育たなければ −1 |
| W0 | 萎まない（対照） |

### 2.3 ヒヨの煽りの選び方（4通り）

| 方針 | 選ぶ相手 |
|---|---|
| Y1 集中 | 燃えている味方のうち火勢が最も高い（4 は除く） |
| Y2 均し | 最も低い |
| Y3 ホタ優先 | ホタ → ボルグ → その他の順 |
| Y4 火力 | 攻撃力が最も高い |

同値は席の番号順（乱数を引かない）。

### 2.4 ボルグの余熱の閾値（3通り）

切った量の累計が **20／30／50** ごとに +1。火の鎧で自分に火が点いたときに育つ版（B+）と育たない版（B0）も並べる。

### 2.5 影の大技（数えるだけ・盤面は変えない）

| 駒 | 影の大技 | 影の火勢への効果 |
|---|---|---|
| ボルグ | 火勢4 の手番で**放つ** | 放ったら自分の火勢を 1 に戻す |
| ヒヨ | 手番の時点で火勢4 の味方がいれば、煽りの代わりに**ターンギフト**（その味方に手番を渡す） | 渡した相手の火勢は変えない（門の型） |
| ホタ | 手番の型が火勢で変わる | 1 単体 → 2 貫き → 3 貫き＋着火 → 4 全体 |

ヒヨがターンギフトを選んだ手番は、煽りをしない（影の火勢が育たない）。

## 3. 測るもの

| 表 | 内容 |
|---|---|
| A | 駒ごと（ボルグ・ホタ・ヒヨ・相方）の影の火勢の分布（平均・4 にいた割合・4 に届いたターン） |
| B | **時計でなくなったか**: 影の火勢とターン数の相関（第239期の隣4体は完全一致）。戦ごとのばらつき |
| C | ヒヨ: 煽りの相手の内訳・ターンギフトの機会（手番の時点で火勢4 の味方がいた回数） |
| D | ボルグ: 余熱の溜まり方・放つの回数/戦（最良の席と T3-1・本編で） |
| E | ホタ: 段ごとの手番数・同じ段が続いた最長 |
| F | **影の絵の単調さ**: 影の大技を入れた想定で、各駒の絵の種類数・同じ絵が続いた最長・最も多い絵の割合（第239期の定義。影の型・影の大技を絵に含める） |
| G | 余熱の量（4 の駒への育ち） |

規則の組は W × Y × 閾値 × B± で多くなるので、段1 は主判定の台で全組、段2 は報告で良さそうな上位の組だけ全台・全波で。

## 5. 予測（Phase 0 の後に数値を入れて、測定の前にコミット）

- **P1** 盤面は動かない（台本が影の計算の有無で全行一致）
- **P2** W1・W2 では影の火勢とターン数の相関が第239期より大きく下がる
- **P3** ヒヨは1ターン1体しか煽れないので、火勢4 に同時にいる味方は多くて1〜2体
- **P4** ボルグの余熱で、最良の席でも放つが 1 回/戦以上起きる（閾値 30 で）
- **P5** ヒヨの絵が煽り（相手違い）とターンギフトに割れ、最も多い絵の割合が 86〜100% から大きく下がる
