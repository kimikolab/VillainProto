# Codex 向け発注メモ —— 「呪いで痛みが渡る」を絵で見せる

置き場所: `design/CODEX_BRIEF_HEX.md`。触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。
台本に足りないデータが2つあるので、**先に Claude Code 側で §3 を入れてから**着手すること。

## 1. 何が起きているか（第182期で既定オン）

泥人形ムドを殴った敵に**呪い**が付く。呪われた敵に**単体攻撃**が入ると、
**他の呪われた敵全員に、その一撃の半分**が入る（1回だけ。受け渡しがさらに受け渡しを呼ぶことはない）。

- ムドが呪いを配り、隣の逆しまのウツが連撃で広げるのが狙いの形
  （ムド×ウツの台では受け渡しが **1戦 116 点**、うち 68% がウツの連撃から）
- 味方同士でも起きる（味方の刃がムドを殴ったとき）。頻度は低い

## 2. いまの画面の問題

- 受け渡しが**普通のダメージ表示**にしかならない。どこから来た痛みか分からない
- 呪いの印は `StatusSnapshot` 経由なので、**付いた次のターンから**しか出ない
- 結果、ポンが狙っている「泥仕合感（敵同士に痛みが渡っていく絵）」が読めない

## 3. 前提 —— Claude Code 側で台本に足すもの（表示専用・盤面は1ビットも動かさない）

1. **呪いが付いた瞬間**に `BattleEventKind.StatusGain` を1件出す
   （`ActorId` = ムド、`TargetId` = 呪われた駒、`Text` = `StatusKeys.Curse`）。
   付与口は `HexTrait.OnDamaged` の1箇所だけ
2. **受け渡しのダメージを区別できる印**を付ける。`ApplyDamage` の共有の段（`hexShare: true`）から出る
   `Damage` イベントに、元の被弾者（痛みの出どころ）の Id と「受け渡し」であることが分かる情報を載せる
   （新しい種類を作るか、既存の `Damage` に目印を足すかは Claude Code の判断）

受け入れ: `compare` 0件差分（`verbose`/台本限定であること）。

## 4. 欲しい絵

1. **呪いが付く瞬間**: ムドから殴った相手へ、泥が**べちゃっと跳ねて貼り付く**。
   以後、呪われた駒には薄い泥のしみ（既存の `StatusIconArt` の呪いアイコンの色 `#bd9aed` 系でよい）が残る
2. **痛みが渡る瞬間（本命）**: 殴られた呪い持ちから、他の呪い持ちへ**泥の筋が同時に走り**、
   届いた先で小さく弾けてダメージが出る。**1本の攻撃が複数に分かれて広がる**のが一目で分かることが要点
3. 2倍速で見ても「殴った → 散った」の順が読める間合いにする（受け渡しは元のダメージのすぐ後）

**まず 1 と 2 だけ作って、ポンが見てから調整する。**

## 5. 守ってほしいこと

- **文字を足さない。** 2倍速で読めないことが分かっている（第171期）
- 良し悪しは言わない。**起きたことを見せるだけ**
- 泥の筋は受け渡しのたびに出るので、ウツの連撃（5発）と重なると煩くなりうる。
  煩ければ筋を細く・短くして、**弾ける側で見せる**方向に寄せてよい
- 味方同士の受け渡しも同じ絵でよい（色で陣営を分けない）
- 暴発の連撃・泥散り（ムドの隣の味方に泥がかかる）の演出とは別物。混ぜない
