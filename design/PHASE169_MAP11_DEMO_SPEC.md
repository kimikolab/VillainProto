## 0. 写す設定（第168期 部B の `S4/S4` × 回復 50%）

| 項目 | 中身 |
|---|---|
| 北の道 | **第二波 `S4`**（前1・前3・中央＝粛の伝令・後3。後1 の施しの司祭長を抜く）→ **第三波（5体）** |
| 南の道 | **第四波 `S4`**（前1・前3・中央＝軛の重装兵・後3。後1 の詠唱兵を抜く）→ **第五波（5体）** |
| カド隊 | `反撃 (ヒサ×カド)`：前1 ヒサ／前3 ガルド／中央 ネル／後1 カド／後3 ノノ |
| ハネ隊 | `突き返し (ハネ×ウツ)` の前3 をヨミに：前1 バサ／前3 ヨミ／中央 ウツ／後1 ドルガ／後3 ハネ |
| 控え | `死軸×ヒヨ (ゾト×火選り)`：前1 ゴルム／前3 ゾト／中央 ヴェル／後1 ヒヨ／後3 リィカ |
| 道中の回復 | **勝った隊は、次の戦闘の前に生存者の HP を `MaxHp` の 50% ぶん戻す**。死者は戻らない |
| 持ち越し | HP と死亡のみ（R0）。状態異常・`AtkBonus` は消える。**敵も同じ**（抜けなかった敵部隊は削れたまま残る） |
| 負け | **隊は全滅して消える**（R252。生存者が残る稀な場合は HP そのままで拠点へ戻す） |

器具の実測（seed 800）: 正の割り当て（カド隊→南／ハネ隊→北）で踏破 **95.6%**、逆で **32.0%**。
2本抜き率は カド隊×南 40.4%／ハネ隊×北 38.0%。逆の割り当ての挽回率 38.5%。

## 2. `DemoApp` に足すもの

| 項目 | 中身 |
|---|---|
| 状態 | `CampaignSession` に、部隊ごとの `UnitState` のリスト（味方3・敵4）を持つ。`ResetCampaign` で初期化 |
| マップ | 拠点1つ・道2本・道ごとに敵部隊2つ（1つ目を抜かないと2つ目に当たれない）。敵は動かない |
| 出撃 | **どの隊をどの道へ送るかはプレイヤーが決める。** 控えも最初から拠点にいて、**いつ・どこへ出すかはプレイヤーが決める**（器具の「全滅したら自動で同じ道へ」は写さない） |
| 戦闘 | 接敵したら、持っているリストをそのまま `BattleEngine.Run(players, enemies, …)` に渡す。終わったら `EngagementEngine.CrossBoundary` を通して書き戻す（回復 50% は勝った味方にだけ） |
| 同じ道に2隊 | 先に着いた隊が戦う。後から着いた隊は、前の隊が抜くか全滅するまで待つ（同時に2隊で1部隊と戦わない） |
| 編成 | **この期では組み直しなし。** 3隊は §0 の固定。編成画面は「中身を見るだけ」で開ける（HP の現在値・死者は灰色） |
| 敵の表示 | マップ上の敵部隊に **名前／波ルール1行（粛・渇き・軛・断罪）／体数／残り HP 割合** |
| 隊の表示 | マップ上の味方部隊に **生存枚数／残り HP 割合** |
| 駒の一行 | 編成画面の駒カードに §3 の一行 |
| 終了 | 4部隊すべて抜けば勝ち。3隊とも消えれば負け。結果画面に **抜いた敵部隊数／生存枚数／戦闘回数／どの隊をどの道へ何番目に出したか**。「もう一度」ボタン |
| seed | 1回の通しごとに乱数。結果画面に seed を出す（再現用） |

- 見た目は最小でよい（ラベルと数字）。演出・アセットは Codex の担当なので `DemoApp/assets/` には触らない
- 既存の単発の戦闘デモ（編成 → 戦闘の確認）は壊さない。作戦マップの既存の4部隊（灰狼隊ほか）は、この 1-1 に置き換えてよい
- **ポンの作業中の差分が `BattleCore` / `DemoApp` にある。着手前に `git status` と差分の要約を報告し、
  `CampaignMain.cs` / `CampaignSession.cs` / `Main.cs` に未コミット差分があれば、止まってポンに聞く**

## 6. ポンが遊んだ後に答える問い（`design/PHASE169_WATCH_LOG.md` に雛形を作る）

3. 送り先を間違えたとき、間違えたと分かったか。いつ・何を見て分かったか
4. 控えを「いつ・どこへ出すか」は判断になったか。自明だったか
5. 1戦目を抜いた隊を、そのまま2戦目へ進めるか迷ったか（待って別の隊を先に当てる、など）
6. 2回目を別の割り当てで試したくなったか
7. 3隊が固定で物足りなかったか。組み直したくなったのはどの場面か
