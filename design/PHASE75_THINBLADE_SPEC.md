## 0. 主題

### 0-1. 位置づけ

第74期の3段分解の残り:

```
+5.4  第75期以降にできることの上限
  −3.2  キリの薄刃（59%）    ← この期
  −0.8  エグの深追い
  −0.4  ナタの刃待ちの残り
  −0.1  ハリの塞ぎ ／ +0.1 ノミの執着 ／ −1.0 交互作用
```

**エグ以下は誤差の範囲**なので、**キリが終われば傷軸の代金側は打ち止め**になる。
残るのは体の **−7.2**（傾きの 46%）で、**それは傷の問題ではない**（ドラフト台の体の経済）。

> **この期をもって傷軸の改修は事実上終わる。** 次期は「凍結・転用・続行」ではなく
> **「傷軸は終わった。次に何を測るか」**の判断になる（§5-3）。

### 0-2. 何を変えるか

**代金を消さない。払い方を変える。**（第74期のナタと同じ方針。あれは +5.15pt を回収した）

薄刃（`ThinBladeTrait.ModifyAttack => 1`）は**打点という一番高い通貨を、常時・無条件で払っている。**
ナタが「手番を捨てる」→「殴ってから待つ」で回収できたのは、**払う場面を条件で絞った**から。
薄刃にも同じ余地がある——**「いつ 1 になるか」を条件にする。**

### 0-3. 既知の制約（**第29期・第74期の記録。守ること**）

- **`ModifyAttack` が `atk` を読まないことが「上流に何が乗っても動かない」を保証している。**
  号令の +4 も呪詛の −6 も 1 に潰れる——**床も天井も要らない設計。**
  **条件付きにするときも、条件が真の側では `atk` を読まないこと**（読むと上流の全機構と相互作用が生える）
- **0 を返してはいけない。** `ApplyDamage` が早期 return して被弾強化も反撃も走らなくなり、
  **傷だけが刻まれ続ける説明のつかない駒**になる
- **第29期はキリ1枠を出力役に戻して +0.1pt しか動かなかった**（理想台）。
  **打点を返すだけでは台は生き返らない。**ドラフト台の帰属 +19.04 と矛盾はしない（別の台・別の物差し）
- **キリは速12**（ロスター上位）。**手番が早いので、条件が「攻撃の後」に成立する形は次のターンまで効かない**

## 1. 版（**測る前に固定**）

いずれも**マイナスを消していない**。キリは依然「まともなダメージを出せない駒」である。

| 版 | 払い方 | 狙い |
|---|---|---|
| **V0** | 現行。常時 1 | 基準 |
| **V1** | **傷の無い相手には 1。傷のある相手には素の打点** | **自分で開けた傷に自分で入る。**1手番目は 1、2手番目から通る（キリ速12・単体なので同じ相手を殴り続ける） |
| **V2** | **傷を刻んだ攻撃だけ 1。**（刻めなかった攻撃＝相手が死んでいる等では素の打点） | ほぼ常時 1 のまま。**V1 との差で「条件の効き」を分ける対照** |
| **V3** | **自分より遅い相手には 1、速い相手には素の打点** | **代金を「誰を殴るか」に紐づける。**条件が盤面の別の軸（速さ）へ接続する |

**V1 が主。** V2 は「効いたのは条件そのものか、条件が緩んだ量か」を分ける対照（第74期の V2 と同じ役割）。
V3 は**接続先を変えた版**——**通れば「代金は条件付きにできる」だけでなく「条件は他軸に繋げられる」まで言える。**

**どの版も条件が真の側で `atk` を読まない**（§0-3）。**V1 は `target.Counter(StatusKeys.Wound)` を読む。**

**切り替えは `Run` への引数（`ThinBladeRule`）。既定は V0。**
**引数なしの `compare` が `docs/balance.md` と 305 セル 0 件で一致すること**を検算に使う。
