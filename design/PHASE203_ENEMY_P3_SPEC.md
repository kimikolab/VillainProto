## 2. パターン3（前衛1枚・中衛2・後衛2）

右が前（敵から見ても自陣の前が右）。3レーン × 後衛・中衛・前衛。

| | 後衛 | 中衛 | 前衛 |
|---|---|---|---|
| 1レーン | A | B | |
| 2レーン | | | C |
| 3レーン | D | E | |

今の9マスとの対応: A＝後1（3）、B＝○中1（5）、C＝○前2（7）、D＝後3（4）、E＝○中3（6）。

規則は第200期で作った一般規則（`FormationShape` の生成関数）をそのまま使う。ポンの表と一致すること:

| 位置 | 隣接 |
|---|---|
| A | B, D |
| B | A, C, E |
| C | B, E |
| D | A, E |
| E | B, C, D |

| 攻撃 | 当たる駒 |
|---|---|
| C に薙ぎ | C, B, E |
| 1-2 レーンへの貫通 | A, B, C |
| 2-3 レーンへの貫通 | D, E, C |

- **狙い**: 生きている駒がいる一番前の列。C が生きている間、味方の単体・薙ぎ・全体の主目標は C だけ
- **貫き**: 第202期の規則（撃つ側のレーンの2レーン・中央は多い方で同数なら交互・空なら反対側）。**味方が撃つ側**になるので、撃つ味方の席のレーンで選ぶ（X 字の前1・後1＝1レーン、前3・後3＝3レーン、中央＝2レーン。パターン2は図の座標）
- どちらの2レーンにも C が入るので、**貫きは開幕から C の後ろまで届く**。単体・薙ぎは C を剥がすまで後ろに触れない

## 5. 診断

### 5.1 主表 —— `compare` 61行 × 元の波／写し

- 列: 第三波（元）／ P3-三 ／ 第五波（元）／ P3-五
- 行ごとの差（写し − 元）、元と写しの相関 r と max|Δ| を併記（陣形が波の性格を変えたかを見る。r が高く差が小さければ、陣形は波を変えていない）
- **新しく生まれた固有の勝者・敗者**（写しでだけ 100% ／ 0% になった行）を数える

### 5.2 攻撃の型で分けた読み

行を「常時の貫きを持つ駒がいる」「条件付きの貫きだけ」「薙ぎ・全体を持つ」「単体だけ」に分けて、写し − 元 の平均を出す。
予測（§6）の向きが合っているかを見る。

### 5.3 帳簿（写しの戦・1戦あたり）

- C（前衛）が倒れたターン、倒れるまでに受けた攻撃の内訳（単体／薙ぎ／貫き／全体）
- 貫きが C の後ろに届いた回数
- 殉教者（P3-五）の庇いの発動回数（元の波と比べる）

### 5.4 `compare`

元の5波は変えないので **0 セル差分**。

診断台は回さない。

## 6. 予測（実装前に宣言してコミット）

方向だけ。数は Q0-4 を数えてから入れる。

- `compare` は ±0.0
- 貫き（常時・条件付き）を持つ行は、写しで**相対的に上がる**。単体だけの行は下がる
- 薙ぎ・全体の行は、巻き込みが減って（C の後ろは1列だけ）下がる
- P3-五 は P3-三 より下がり幅が大きい（唯一の前衛が庇い持ち）
- 元と写しの r は低めで、固有の勝者・敗者が新しく生まれる（陣形が波の解答を変える）
