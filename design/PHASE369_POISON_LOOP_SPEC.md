## 0. 目的

うまく回っている軸（標・燃焼）は、出たものが次の入力になる**ループ**を持っていた。今の毒軸は一方通行（書く → 倍 → 刻む → 終わり）で、敵に溜まった毒がこちらの資源に戻る矢印が無い。グザも「毎ターン敵 +2 ／ 味方 +1 を撒くだけの装置」になっている（第368期: 漏れはどこにも噛み合っていない）。

ポンの方針（2026-10-21）: **グザをバサのような形に転生する**（ターンの頭のランダムなマイナス ＋ 溜まるほど上がる段 ＋ 特性での活躍）。ヴィオとスィドはそれに合わせて作り直す。狙う1ターンの流れ:

```
ターンの頭   グザの袋から瘴気が噴き出し、ランダムな味方と敵に毒が付く
敵の手番     敵が殴る → 返り毒で、殴られた味方の毒が殴った敵へ移る
             スィドを殴れば、まとった毒と同じだけ浴びる
ヴィオ（速7） 味方に残った毒を啜り、最も毒の深い敵を倍にして注ぐ
グザ（速5）   袋を振り回して敵全体へ瘴気 → 敵の毒が増えて段が上がる → 次の噴き出しが濃く広くなる
```

味方の毒の使い道が「味方に残して地雷にする（返り毒）／ヴィオに啜らせる（触媒）／スィドにまとわせる（守り）」の3つに分かれ、**誰に毒を持たせるか・誰をどこに置くか**が配置の悩みになるか——これを確かめる。

## 2. 版の駒

3枚とも**毒に強い**（第368期の `PoisonProof`・刻みで HP が減らない・層は持つ・ベニの反転が先）を持つ。

### 2-1. グザ（転生・版 `GuzaZ`）

| | 中身 |
|---|---|
| 手番 | 今のまま（集まる瘴気: 敵全体へ 2 × max(1, 5 ÷ 生きている敵の数)） |
| マイナス（ターンの頭） | **噴き出し**: 袋から瘴気が噴き出し、**ランダムな敵 k 体とランダムな味方 k 体**（グザ自身を含む生きている味方から）に毒が付く。k 体に満たなければ全員。相手は選べない。**今の「味方全体に +1」の漏れは外す** |
| 段 | **この戦で敵に書かれた毒の層の累計**（誰が書いても・倒れた敵の分も含む）が 30 ／ 80 ／ 200 を越えるたびに段が上がる（下がらない） |
| プラス | **返り毒**: グザが生きている間、毒を持つ味方が敵に殴られると、**その味方の毒の半分（切り捨て）が殴った敵へ移る**（味方の層は減る）。1層のときは移らない。毒の衣を持つ駒からは移らない |

噴き出しの段:

| 段 | k（敵 ／ 味方） | 敵へ | 味方へ |
|---|---|---|---|
| 0 | 2 ／ 2 | +2 | +1 |
| 1 | 3 ／ 3 | +3 | +1 |
| 2 | 4 ／ 4 | +4 | +2 |
| 3 | 全員 | +6 | +3 |

- 噴き出し ／ 返り毒の毒はすべて毒の窓口（`ctx.Poison`）を通す（経路名は新しく足す）。滲み則は今どおり乗る
- 噴き出しの相手は乱数で選ぶ（バサの入れ替えと同じ引き方・新しい乱数の引き方を作らない）。`PickOne` ／ `Roll(` の数が増えることは報告に書く
- 返り毒は殴られた一撃ごと（全体攻撃なら当たった味方ごと）に起きる
- 文面（叩き台・最終はポン）:
  - プラス: 「手番で、敵全体へ瘴気を撒く（敵が少ないほど濃い）。瘴気を浴びた仲間が殴られると、その毒の半分が殴った敵へ移る。毒に蝕まれない」
  - マイナス: 「袋の口がゆるく、毎ターンのはじめに瘴気が噴き出して、敵味方の誰かに毒が付く。敵が毒に染まるほど瘴気は濃くなり、噴き出す相手も増える」

### 2-2. ヴィオ（版 `VioZ`）

| | 中身 |
|---|---|
| 手番 | **啜って注ぐ**: 味方に残った毒を啜り（自分と毒の衣を持つ駒は除く・啜った味方の層は 0 に）、最も毒の深い敵の毒を倍にし、啜った分もその敵へ注ぐ（同じ層なら席番号の小さい方・毒の敵がいなければ啜った分だけを席番号の最も小さい敵へ） |
| 変える点 | **ターンの頭の吸い（`BlightfedTrait.OnTurnStart`）をやめ、手番に移す**——ターンの頭に吸うと返り毒の地雷が敵の攻撃の前に消える。速7 なので勇者（速14）の後に啜る。攻撃力の上昇は付けない（殴らない） |
| マイナス | 自分では攻撃しない。味方が汚れていなければ倍だけ |

- 倍と注ぎは今の触媒（`BlightCatalyst`）と同じく毒の窓口を通す
- 文面（叩き台）: プラス「手番で、仲間に残った毒を啜り、最も毒の深い敵の毒を倍にして、啜った毒も注ぎ込む。毒に蝕まれない」／ マイナス「自分では攻撃しない。仲間が汚れていなければ注ぐ毒が無い」

### 2-3. スィド（版 `SidZ`）

| | 中身 |
|---|---|
| 手番 | **毒を引き受ける**: 隣接する味方の毒をすべて自分へ移す（移した味方の層は 0 に・自分の層に足す） |
| プラス | **毒の衣**（第368期と同じ: 自分の層 1 につき受ける傷 −3%・最大 60%）。殴られると自分に毒 +2、**続けて殴ってきた敵へ自分の層と同じだけ毒を浴びせる**（衣は減らない・今の +8 固定から置き換え）。痺れ毒の印は今どおり殴ってきた敵に付く。衣は返り毒で剥がれない |
| マイナス | 自分からは敵に毒を書かない（今の手番の「毒を吐きかける」をやめる）。殴られると隣の味方にも毒 +1 が漏れる（今どおり） |

- 文面（叩き台）: プラス「手番で、隣の仲間の毒を引き受けてまとう。まとった毒が深いほど受ける傷が減り（最大6割）、殴ってきた敵にはまとった毒と同じだけ浴びせる。毒に蝕まれない」／ マイナス「自分からは毒を吐かない。殴られると隣の仲間にも毒が漏れる」
