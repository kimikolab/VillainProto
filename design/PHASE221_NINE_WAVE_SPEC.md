# 第221期 指示書 —— 9体の検証波（敵専用の9枠の入口）

置き場所: `design/PHASE221_NINE_WAVE_SPEC.md`。報告は `design/PHASE221_NINE_WAVE.md`。
**線は置かない**。本編の5つの波（`EnemyCatalog.Stages`）は**触らない**。検証用の波を別に足す。

**前提**: ミオの B2（`MireBurstStack`）の規定化が済んでいること（別作業で指示済み）。

## 0. 目的

ポンの要望: **検証用に、第一波くらいの難度の敵が数だけいる9体の波が欲しい**。

狙い:
- 感電の連鎖（隣が多いほど大きい）・澱みの爆発（第220期: 倒れる瞬間の隣が平均 1.2 体しかいないので誘爆が続かなかった）・薙ぎ・全体攻撃・撃破の読み手が、**敵の密度でどう変わるか**を触って確かめる
- 「体数」を波の軸として持つ構想（3体の城塞／5体／9体の薄い波）の最初の器具

## 1. 敵専用の9枠の入口

- プレイヤー側の `Formation`（5枠固定・意図的）は**触らない**
- 敵だけが使える9枠の入口を別に作る（例: 席番号 0–8 を直接指定して `Materialize` する経路）。プレイヤー側からは到達できないこと
- 敵の席は波の定義に明示する。X字に丸めない
- 盤面の表（行・貫きの経路・薙ぎの巻き込み・隣接）は**一切触らない**——9体はすべて既存の席

9マスの席（確認用）:

| 席 | slot | 行 | 貫きの経路 |
|---|--:|---|---|
| 前1 / 前3 | 0 / 1 | 前 | 1 / 3 |
| 中央 | 2 | 中 | 1 と 3 |
| 後1 / 後3 | 3 / 4 | 後 | 1 / 3 |
| ○中1 / ○中3 | 5 / 6 | 中 | 1 / 3 |
| ○前2 | 7 | 前 | なし |
| ○後2 | 8 | 後 | なし |

9体では前列が3体（前1・前3・○前2）。○前2・○後2 には貫きが届かない。

## 2. 検証の波（`EnemyCatalog.TestStages` など別の一覧に）

| 波 | 敵 | 席 |
|---|---|---|
| **検証・九 / 新兵** | 討伐隊の新兵（45/11/6・特性なし）× 9 | 9マス全部 |
| 検証・九 / 農兵 | 駆り出された農兵（30/8/6・特性なし）× 9 | 9マス全部 |
| 検証・五 / 新兵（対照） | 討伐隊の新兵 × 5 | X字（0–4） |

- 新しい数値の駒は作らない（既存の駒をそのまま並べる）
- 新兵9体は総攻撃 99/T（第一波の 34/T の約3倍）・総HP 405。農兵9体は 72/T・270。**「1体は第一波並み・数が多い」**の2段
- 検証・五は、同じ駒で「5体と9体の差」を切り分けるための対照
- 本編の `Stages` には足さない（`compare` と各診断が本編の5波を回しているため）

## 3. Phase 0（実装前）

9体で初めて踏む道がある。実装の前に確かめる:

- **Q0-1 貫きの行き止まり**: 両方の経路に生存者が 0 で、○前2・○後2 だけが生きている局面で貫きがどうなるか（`SelectPierceEntry` が null を返して手番を捨てるのか、単体に落ちるのか）。**9体の終盤で必ず起きる**
- **Q0-2 敵側の特性が席を読むか**: 敵の特性（処刑人・断罪・殉教者・中傷・暴き・押し・逸らし・盗みほか）が `RowOf`・`LanesOf`・`IsLanePredecessor`・隣接表を読んでいないか
- **Q0-3 味方の特性が敵の席を読む所**: カタの雷の跳ね・感電の放電・ミオの寄せ先と印の移り・澱みの爆発・薙ぎ（シガ・ボルグ・ハギ・ドルガ）・全体攻撃・ヒサの標ほか。**slot 5–8 の敵で壊れないか**
- **Q0-4 会戦**: `Engagement` が敵の Slot を 0–4 と決め打ちしていないか（`(TeamId, Slot)` で同定している）。検証の波は会戦に入れないが、落ちないことを確認
- **Q0-5 診断**: BattleSim の各診断（`compare`・`chain`・`route`・`life` ほか）が敵の Slot を 0–4 と決め打ちしていないか。今期の測定で使う診断だけ直し、ほかは一覧にする
- **Q0-6 召喚**: 9枠が埋まった敵側に召喚が起きるか（敵に召喚持ちがいなければ無し）。味方の召喚（胞子・亡者）は味方側なので無関係のはず
- **Q0-7 過去の測定**: `design/` を grep（第5期の勾配列の農兵の波〈6体〉・体数を変えた実験）。6体をどう置いたかと結論を引く
- **Q0-8 DemoApp の描画**: 敵側の描画が5席固定でないか（BattleCore からは直さない。落ちるか・描けるかだけ確認して報告）

## 4. 予測（Phase 0 の後に駒を数えて数値を入れ、実装前にコミット）

方向だけ:

- **P1** 本編の5波は 0 セル（`compare` 305 セル一致）
- **P2** 9体では、薙ぎ・全体・撃破の読み手（ハギ・エグ・死亡トリガー）・毒撒き（グザ）を含む行が上がり、単体高倍率（ドルガ）と被弾で稼ぐ耐久の行は敵の手数が増えて下がる
- **P3** 感電の連鎖の大きさは5体より大きく、澱みの爆発の「1本の連鎖で2体以上」の割合が上がる（倒れる瞬間の隣が増える）
- **P4** 検証・五との差が、体数の効き目。新兵9体は多くの行で第一波より明確に難しい

## 5. 測定

- `compare` の 61 行を、検証の3波 × seed 0..199 × 倍率 115 で回す（本編の表には混ぜない・別の表）
- 雷の台（第216〜220期の R1〜R4・ポンの X字）を同じ3波で
- 表:
  - A: 61 行 × 3波の勝率・全員生存・決着ターン。9体でだけ勝てる／負ける行
  - B: 雷の台の感電の連鎖の大きさ・澱みの爆発の連鎖の長さ・1本で2体以上の割合（5体 ↔ 9体）
  - C: 貫きが行き止まりに当たった回数（Q0-1 の局面）
  - D: 敵の手番の総数と、味方の被ダメ（5体 ↔ 9体）
