### Q0-1 「味方が失った HP」の窓口

- **HP が減る口は `ApplyDamage` の `target.Hp -= amount` の1箇所だけ**（ほかは旧ノノの繕いの代価 `self.Hp -= paid` だけで、リリの行には居ない）。
  そこに第120期の `HpRemoved`（過剰分を除いた実額）が既にあるので、**同じ実額を陣営ごとに足す**形にした。
- **破片で受けた分は入らない**——破片は `ApplyDamage` の中で HP を引く前に削られ、ここへ届くのは残りだけ。
- **肩代わりは二重にならない**——中継（分かち・巨躯・庇うなど）は肩代わりした駒への**別の `ApplyDamage` 呼び出し**で、
  元の被弾者に残った分と肩代わりした駒の分がそれぞれ1回ずつ入る。ドハが引き受けた分は「ドハが失った HP」として数える。
- 毒・火の刻み（`burnTick`）・コスト徴収（`levy`＝生贄・吸い・置き去り）・巻き込み・棘の反射も同じ口を通るので**全部入る**。
- `DamageTaken`（既存）は**過剰分を含む**ので痛みとは別物。痛みは過剰分を除く。

### Q0-4 攻撃力の上げ下げの構造

- **1つの値**（`UnitState.AtkBonus`）。強化（`Whet` の8経路・自己強化の9本）も弱体（`Dull` の経路・ネルの呪い広げ）も同じ値に足し引きする。
  帳簿（`WhetReceived`）は窓口を通った強化の累計で、正味ではない。
- だから移すのは**差し引きを丸ごと**。窓口（`Whet` / `Dull`）は**通さない**——通すと引き受け（ウケ）・渡し（ワタ）が移した弱体を横取りし、
  `WhetReceived` に「外から押された」が載る。移すのは強化でも弱体でもなく持ち替えなので、尾灯の消灯と同じく**直に足し引きする**。
- **ウツ（逆しま）は `AtkBonus` を直に読む**（`PerverseTrait.ModifyAttack` / `ModifyHitCount`）ので、移した弱体はそのまま攻撃力と手数に届く。

- **弱体を移す場面は3行にあり、うち2行（ネルの行）は大きい**——ネルの呪い広げで敵は平均 −19〜−28 を背負っていて、
  リリが吸った敵は**ほぼ毎回**それを持っている。V4 ではそれを受け取った**味方**（ウツではない）が −19〜−28 を背負い、敵は攻撃力を取り戻す。

### Q0-6 段の持ち越し

- 「その戦のあいだ溜まる」札は、会戦の境界で私有のカウンタを `OnCarryOver` で 0 に戻すのが既存の作法（紅蓮は状態キーなので境界で消える・
  リィカの層・剣の段の記憶・突きの溜めなど 20 本以上が同じ形）。`AtkBonus` も境界で消える。
- **段（施した累計）と痛みの印は境界で 0 に戻す。** 痛みは戦ごとに `PainLostOf` が 0 から数え直すので、印も合わせて戻す。

### Q0-7 1手番で複数体を吸うときの順序

- 吸い取り（`ApplyDamage`）で敵が倒れると、その場で `HandleDeath` → 全員の `OnAnyDeath` → 「祝福が還る」が走る（第204期と同じ）。
  そのあと受け取り手を選ぶ（`MostHurtAlly` は還るで癒えた後の状態を見る）。
- **吸う体数は手番の頭の段で決める**（手番の途中で累計が段を越えても、増えるのは次の手番から）。
- 1体ごとに「生きていて聖痕の無い敵」を選び直す。途中で聖痕の無い敵がいなくなったら、そこで止める。**儀式は次の手番の頭で判定する**
  ——第204期と同じ入口なので壊れない（全員に聖痕が付いた状態で手番が終わるだけ）。

### 診断専用の行（§4.3）

`分かち×逆しま (ドハ×ウツ)` を土台に、ウツ（前1）の1枠をネルに替える。

**予測を書いた時点の規則（「ウツに隣接し、リリ・ドハでない最小の席」）は実装で空になった**——X 字では前1 に隣接するのは中央（リリ）と後1（ドハ）だけ。
**「ウツ・リリ・ドハでない最小の席」**に直した——前3 のガルド → ネル。ネルはウツの隣にいないので呪いの漏れはウツに届かず、
**ウツが弱体を受け取る経路はリリの強弱の移しだけ**になる（測りたい経路が1本に絞れる）。行名は `診断: 分かち×逆しま＋ネル`（`Presets.Compare` には入れない）。

## 実装

- **痛み**（`TraitId.KissPain`）: リリの手番の頭に `BattleContext.PainLostOf(自陣) − 印` を測り、吸う量 ＝ max(`PainFloor` 8, 痛み × `PainPercent` 50%)。
  印（`KissTrait.PainMarkKey`）は**手番の終わり**に控える——リリ自身の手番の中で起きた減りは次の痛みに入らない（指示書 §2.1 の「前の手番の終わりから」）。
  痛みは**版に依らず測る**（V0 でも帳簿に載る。Phase 0 の数字はこれで取った）。
- **溢れを捨てる**（`KissVoid`）: `KissTrait.Give` の中で、破片に足す代わりに帳簿（`KissVoided`）にだけ数える。吸い取り・儀式・還るの3場面が1本を通る。
- **段**（`KissTier`）: `Give` で HP が実際に増えた分を私有キー `kissHealSum` に積み、40 ごとに `kissTier` を上げる（下げない）。
  **1手番に吸う体数は手番の頭の段で決める**（1 ＋ 段）。1体ごとに「生きていて聖痕の無い敵」を選び直し、いなければそこで止める（Q0-7）。
- **強弱を移す**（`KissSteal`）: 1体ずつ吸うとき、状態を移した直後に敵の `AtkBonus` を丸ごと受け取った味方へ足す（`Whet` / `Dull` は通さない・Q0-4）。儀式では移さない。
- 会戦の境界で印・累計・段を 0 に戻す（`OnCarryOver`・Q0-6）。**版は札の差し替えだけ**（`Run` の引数は増やしていない）。
  **乱数を引くのは既存の2つ（聖痕の相手の同値割り `PickOne` と `MostHurtAlly`）だけ**——新しい処理は引かない。
- エンジンで足したのは `PainLostOf` の計数（`ApplyDamage` の `HpRemoved` の隣）だけ。読むのは `KissTrait` だけ。
- 台本（表示専用・`BattleEventKind.Kiss` の新しいラベル4つ）: **痛み**（`Amount` = 痛み・`StatusRemaining` = 1体あたりの吸う量・`Slot` = この手番に吸う体数）／
  **段**（`Slot` = 新しい段・`Amount` = 1手番に吸う体数・`StatusRemaining` = 施した累計）／ **溢れ**（`Amount` = 捨てた量・破片の代わりに並ぶ）／
  **強弱**（`SpreadFromId` = 元の敵・`TargetId` = 受け取った味方・`Amount` = 移した値〈符号つき〉・`StatusRemaining` = 受け取った後の値）。
  DemoApp は未知のラベルを素通りするので、再生側の変更は 0 行（演出は Codex 側）。
- `UnitCatalog.Lili` は V4（札 6 枚）。`docs/units.md` のリリの行は §6 の文面。

## この期で分かったこと

1. **破片と痛みは逆向きに噛む**——破片で受けた分は痛みに入らないので、**溢れを破片にする版（V1）は、自分の溢れで自分の吸う量を削る**。
   V2（捨てる）で痛みが増え（`耐久` 第四波 48.9 → 56.6）、勝率は上がる行のほうが多い。**V1 だけに膠着が出た**（`反撃改` 第四波 12 / 200）のもこの組み合わせ——床まで下がった吸い取りと、残った破片。
2. **「ヒーラーに見えるか」は波で割れる**——第四波（余裕のある戦）では与ダメ:回復が 1:1 まで下がるが、**第五波（押される戦）では与ダメも 2〜4 倍になる**。吸う量＝与ダメなので、痛みから取ると「押されるほど殴る」にもなる。
3. **段は速く上がる**——`TierStep = 40` は第五波の1手番目で越える（痛み 80 超 → 吸う 40 超）。第四波でも 3〜5 ターン目で段1、戦の終わりには段 3 以上が大半。
   「最初は弱いが積んで強くなる」の**「最初」はほぼ1〜2手番**。
4. **強弱を移すと、ネルの仕事をリリが帳消しにする**——ネルの行では吸うたびに敵の弱体（−19〜−28）を味方へ持ち帰り、第四波の痛みが 3 倍になる。
   天井なので勝率には出ないが、**ポンが遊ぶ `反撃改` はこの行である**。
