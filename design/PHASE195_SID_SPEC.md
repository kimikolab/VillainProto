## 1. 目的

**目標: 毒パがガルド抜きで耐えられるようにする。**

- 今の毒の行は、ほぼすべてにガルドが入っている（下の7行）。ヒーラーと主タンクの両方を前提にした軸は強くて当然で、毒パの個性にならない。ガルドはどの軸からも引っ張りだこでもある（`compare` 61行中35枠）
- 毒パが受けるダメージは2種類ある。**自分の毒・火**はベニ（第190〜193期・反転の結界）が回復に変える。中央のベニは X字の隣4隅すべてを覆うので、隊の5枚全員が結界の内側に入る。残る**敵の攻撃**を、今期のスィドが「敵を鈍らせる」ことで受け止める
- ポンの評価（第177期の観察ログ）は「毒軸以外で使えない」。今期のスィドは、単独でも「一番強い敵を鈍らせ続ける」デバッファーとして置ける形を狙う

## 2. 新しいスィド

HP・速は据え置き（HP84 / 速9）。**`Actions = [Skill]`（攻撃しない）**。

| 札 | 種類 | 内容 |
|---|---|---|
| `Spit`（吐く） | 手番 | **現在攻撃力が最も高い敵**に毒 +6 層（`SpitStack = 6`）と**痺れ毒の印**（同値は席番号の小さい方） |
| `Venom`（既存を改修） | プラス | 殴られると、殴ってきた敵に毒 +4 層（今のまま）＋**痺れ毒の印** |
| `Numb`（痺れ毒） | プラス | **痺れ毒の印がある敵は、与ダメージが「毒の層 × 3%」下がる（上限 60%）** |
| （既存の漏れ） | マイナス | 殴られると、隣接する味方に毒が漏れる（今のまま） |

- 印は状態キー（例 `StatusKeys.Numbed`）で持ち、戦闘中は消えない。**毒の層が 0 なら減らない**（層に比例するだけ）
- 減らす量は**その時点の毒の層**で決まる。層を足す経路（グザ・ミオの +4・ラウの伝染・カタ など）は、印のある敵ではそのまま「鈍らせる燃料」になる。**印が付くのはスィドが吐いた敵・スィドを殴った敵だけ**
- 与ダメージの減少は、その敵が与える**すべてのダメージ**（単体・薙ぎ・貫き・全体、反撃を含む）にかける。掛ける場所は、既存の与ダメージの補正（クビの萎縮・ネルの呪いなど）と同じ系統にそろえる（Phase 0 で入口を決める）
- 旧 `Venom` の定義は対照として残す（第190期の `Devour` と同じ作法）。新旧は版で切り替える
- 札を割るのは第74期の作法。`Spit` を外せば「手番なし」、`Numb` を外せば「鈍らせなし」の版が組める

### 2.1 伸び方の目安（スィド単独・同じ敵に吐き続けた場合）

| ターン | 層 | 与ダメージ |
|---|---|---|
| 1 | 6 | −18% |
| 2 | 12 | −36% |
| 3 | 18 | −54% |
| 4 | 24 | −60%（上限） |

- 前列で殴られると、殴った敵に**その場で** +4 層と印が付く（1発目の後から −12%）
- ミオと組むと、+4 が乗って2ターン目にほぼ上限

## 4. 診断

### 4.1 主表 —— ガルド → スィド（**測る前に固定**）

`compare` のうち、**毒の書き手を含み、かつガルドが入っている行**（Phase 0 時点で7行の見込み）:

- 毒 (グザ×ミオ×ラウ) / 毒+耐久 (ベニ×トウ) / 毒+ベニ+ラウ / 毒爆弾 (ラウ×ヴィオ) /
  毒→被弾強化 (グザ×ムド) / 澱み喰い (グザ×ヴィオ) / 追撃×毒 (ハギ×グザ)

各行を次の4つで並べる（第2〜5波・第一波は実行して除外）:

| 列 | 組み方 |
|---|---|
| 元 | そのまま（ガルドあり。スィドがいれば新スィド） |
| 新 | ガルドの席に新スィド |
| 旧 | ガルドの席に旧スィド |
| 素体 | ガルドの席に素体（**スィドと同じ数値**・特性なし・毎手番殴る） |

- **既にスィドがいる行**（4行の見込み）は、スィドをガルドの席へ移し、スィドの元の席を**同じ数値の素体**で埋める
  （同じ駒の重複を避けるため。Q0-3 で重複が許されても、この組み方にそろえる）
- 読むのは **「新」が「元」にどこまで近いか**（＝ガルドの穴をどこまで埋めたか）と、**新 − 素体**（＝スィドの値）
- 行ごとに **ベニの有無** を併記する。ベニ（自傷を回復に）とスィド（敵を鈍らせる）がそろった行で穴が埋まるかが焦点

### 4.2 `compare` のスィドの在席行

版は **旧 ／ 新 ／ 新・鈍らせなし（`Numb` を外す）／ 新・手番なし（`Spit` を外す）／ 素体**。

### 4.3 帳簿（1戦あたり）

- 痺れ毒で減らした与ダメージの総量（手番で吐いた敵／殴ってきた敵に分けて）
- 印のある敵の数、印のある敵の毒の層の平均と最大、減少が上限 60% に届いたターン
- スィドが倒れた割合と倒れたターン、スィドが受けたダメージ（出どころ別）
- 隊全体が敵から受けたダメージ（§4.1 の各列で比べる）

診断台は回さない（第188〜190期で床に張り付いたため）。

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0-2 の実駒を数えてから入れる。

- スィドを含まない・§4.1 の差し替えを含まない行は ±0.0
- §4.1 で「新」は「旧」「素体」より上。ただし「元」（ガルドあり）には届かない行が多い
- ベニが同じ行にいるときのほうが、「新」と「元」の差が小さい
- ミオが同じ行にいるときは、減少が上限に届くのが早い
- 前列に置いたスィドは、序盤（1〜2ターン目）に倒れる割合が高い（1発目から耐える仕組みが無いため）
