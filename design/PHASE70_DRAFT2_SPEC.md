## 0. 主題

### 0-1. 切り分けるもの

第69期のドラフト台は**平均勝率 6.58%・標本の 78.9% がちょうど 0%** で、中間帯 17.9%（Q1 の線は 60%）。
**台としては使えない。**ただしこの床には**2つの原因が混ざっている:**

1. **ロスターの側** —— 攻撃力6以下が **28/51**。5体中3体以上をそこから引く確率は**超幾何で 59.5%**。
   支援型が多く、無作為5枚では殴る駒が足りない
2. **波の側** —— 既存5波は**理想編成に勝てるよう調整された敵**で、ドラフト編成には最初から強すぎる

**どちらが効いているかで次の作業がまったく変わる**（駒の設計の話か、ステージ構造の話か）。
**この期は切り分けるだけ。設計判断をしない。採否も無い。**

### 0-2. 2×2

| | **既存5波** | **弱い波** |
|---|---|---|
| **無作為5枚**（第69期） | **A（対照・第69期の再現）** | **B** |
| **3枚提示から1枚選ぶ × 5回** | **C** | **D** |

**選択ありを入れる理由**: 実像に近い。無作為配布ではなく**提示から選ばせる**のが想定している流れで、
**選択が入るだけで床は大きく上がるはず**。しかも「何を選ぶか」がゲームの判断そのものになる。

**求めるもの: 4版のうち中間帯が 60% を超える版**。あれば第71期以降の標準台。
**無ければ「現ロスターではドラフトは成立しない」**という結論で、それは最後の1枠の使い道
（**単独で成立する駒を1枚入れる**）の材料になる。

## 2. 作るもの

### 2-1. 共通

- 配置は**規則配置（H）のみ**。第69期の4行規則をそのまま使う
  （前列＝最大HP2体／後列＝残りの攻撃力上位2体／中央＝残り／同値は `Def.Id` 辞書順）。
  **無作為配置（R）は測らない**——第69期で「78.9% が 0% の台では置き方を変えても 0 のまま」で、
  **配置の価値は測定不能だった**（第69期の +0.52pt は結論ではない）。台が直ってから測り直す
- **第一波を除外しない。** 第69期の訂正のとおり、この台では第一波も分別に効く。**5波すべてを集計する**
- seed 帯は2本（再現の確認）

### 2-2. 選択ありドラフト（C / D）の規則（**測る前に固定**）

5回繰り返す:

1. **まだ選ばれていない駒から無作為に3枚**提示する
2. **決定的な規則で1枚選ぶ**（乱数を引かない）:
   - **すでに選んだ駒に攻撃力7以上が 2 枚未満なら、提示の中で攻撃力が最大の駒**
   - **そうでなければ、提示の中で最大HPの駒**
   - **同値は `Def.Id` の辞書順**

**この規則が最適である必要はない。**必要なのは**決定的で、素人が思いつく程度**であること
（第69期の規則配置と同じ思想）。**規則を強くすると選択の価値が過大に出る**ので、
**上の3行から増やさないこと。**

### 2-3. 弱い波（B / D）の作り方（**測る前に固定**）

**既存の `Stages` を書き換えない。**診断のローカルで、**各波の敵の `MaxHp` を一律 0.6 倍**した
複製を作る（切り捨て）。

- **攻撃力・速さ・特性・席・体数は一切変えない。**HP だけの1変数
- **理由**: 第34期の教訓（1変数を振るときは、それが他に何を一緒に動かすかを先に数える）。
  攻撃力を下げると「味方が落ちない → 手数が増える」で決着ターンまで動く。
  **HP だけなら動くのは「敵を倒すのに要る打点」だけ**
- **0.6 の根拠を Phase 0 で書く**。理想編成の 61 行平均が 67.2%、ドラフトが 6.58% なので、
  **中間帯へ持ち上げるのに要る倍率を、既存の波の総HPと編成の総打点から見積もること**。
  **見積もりの結果 0.6 が妥当でなければ変えてよい。ただし測定前に決め、根拠を書く**

### 2-4. 数える量

| 量 | 定義 |
|---|---|
| **標本勝率の分布** | 版ごと・波ごと。**0% ちょうど / 100% ちょうど / 中間帯（5〜95%）の割合** |
| **編成の中身** | 攻撃力7以上の枚数・総攻撃力・総HP・相方の有無（第68期の機械的定義） |
| **駒ごとの在席時勝率** | 版ごと。**寄与（素体差し替え）は中間帯が 60% を超えた版でだけ出す** |
| **枚数効果** | キーごとに 1 / 2 / 3 枚同席の勝率（第69期の表E の再現。**移動が優加法だったかの検算**） |

**寄与の器具は素体差し替えに統一する**（第69期の発見）。**1枚抜きと混ぜない。**
第68期の表D は1枚抜きなので、**比較に使うときは器具を明記すること。**
