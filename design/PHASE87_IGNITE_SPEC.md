## 0. 主題

### 0-1. 第86期が出した天井

| 期 | 機構 | 結果 |
|---|---|---|
| 第74期 | ナタ（消費読み） | 5.70T のうち 3.40T を手番ごと捨てていた |
| 第79期 | 処刑（撃破で育つ） | 育ったあとに振る手番が無い（寄与 +0.6 以下） |
| 第84期 | カドの棘 → 傷 | +0.04pt |
| 第85期 | ハリの両側読み | +1.10 / +1.30pt。**ハリの振り 2.15 回/戦** |
| 第86期 | ノノの傷読み | **紙で停止。ノノの発火 2.10 回/戦** |

第86期の一番大きい発見は判定ではなく**稼働率**だった——**発火 ÷ 決着T が4波とも 35〜40% に張り付き、
波が 4.9T → 7.0T と 1.4 倍になっても比が動かない。** 読み手を替えても波を延ばしても変わらない。

> **発火に比例して払い出す機構は、1戦あたり約2回ぶんしか受け取れない。**

**4期とも発火比例型だった。** 傷1つ = 3点（抉り）も、繕い = 回復（縫い・継ぎ当て）も、
**その一撃で払い切って終わる**。天井は駒ではなく払い出しの形にかかっている。

### 0-2. 何を変えるか

**澱みのミオ（`AmplifierTrait`）が、傷を持つ敵に着火できるようにする。**

現行: 「毎ターン、敵に積まれた毒を濃くする（+4層）／**毒が積まれていなければ完全に無意味**」

新: 「毎ターン、敵に積まれた毒を濃くする（+4層）。**毒が無くても、傷のある敵には毒が回り始める**／
**毒も傷も盤面に無ければ完全に無意味**」

**1文は増えない。** 「毒が無ければ無意味」という条件が「毒か傷が無ければ無意味」に緩むだけで、
**ミオは相変わらず自分では何も供給しない純粋な読み手**のまま。

### 0-3. なぜこれなら天井を越えうるか

**毒は層が残り、毎ターン刻む。** 1回の発火の払い出しが、その発火の回数に比例しない。

| 機構 | 1回の発火が生む即時出力 | 累積出力 | **持続係数** |
|---|--:|--:|--:|
| 抉り（第30期〜） | 3 | 3 | **1.0** |
| 縫い（第85期） | 3 | 3 | **1.0** |
| 継ぎ当て（第86期） | 3 | 3 | **1.0** |
| **ミオの着火 ＋ 増幅** | 0 | 層 × 残りターン数 | **3〜5** |

**第84〜86期の3機構は係数がすべて 1.0 だった。** 稼働率 35〜40% の天井が、そのまま出力の天井になる。
**係数が 1 より大きい機構をロスターで初めて主判定にかける**のがこの期。

**下流の読み手が3枚いる**（新しい駒を作らずに繋がる）。

- **ミオ自身**（`AmplifierTrait.Thicken` は毒の乗った敵**全員**を +4 する。着火した敵の数だけ線形）
- **毒喰らいのベニ**（「毒に侵された**敵の数**だけ味方全体を癒す」＝深さではなく**数**を読む。
  着火は数を増やすので直接効く）
- **疫みのラウ**（毒に侵された駒が倒れると残った敵へ飛ぶ）

**キリは成立し、ノミは成立しないはず。** キリは打点が常に 1 で誰も倒せないので前列の的を毎ターン変えて
**1体ずつ着火していく**。ノミは執着（`FixateTrait`）で1体に食いつくので**着火は1体だけ**で、
ミオの全体増幅が活きない。**同じ資源の長短2つの入口に、初めて「向き」の差が出る。**

### 0-4. あわせて台の乖離を測る（**積み残しの「理想 vs ドラフト」**）

第85期の巻き込み則は同じ機構が

- **理想台（`compare` の `刻み×縫い`）で 第四波 47.0 → 88.5%（+41.5pt）**
- **ドラフト台の 2×2 で +1.30pt**

と **30 倍**離れていた。第86期の稼働率 35〜40% は、ドラフト台では読み手が決着の4割しか生きていない
ということでもある。**主判定をドラフト台の平均に置き続ける限り、読み手を使う設計は全部落ちる可能性がある。**

**この期は同じ機構を両方の台で測り、乖離を副判定として常設する。**
第86期が2×2を1戦も回していないので予算は丸ごと余っている。**調査期を別に立てない。**

### 1-3. 持続係数（**この期に新設する器具。以後常設**）

**即時出力が 0 の機構（着火そのもの）は、分母に「その発火が盤面に置いた層の1ターンぶんの刻み」を使う。**

### 1-4. 潰れる相互作用を先に洗う

1. **ナタ（断ち）は傷を 0 に戻す。ハリ（縫い）は 1 引く。** どちらもミオの着火の機会を奪う。
   **同じ傷を取り合う**——第39期のハリ×ナタと同じ形が、ミオとの間にも立つ。**着火は消費しない**（§2-2）が、
   **着火する前に消されると機会そのものが消える**。速さは キリ12 / ノミ7 / ミオ8 / ナタ5 / ハリ6 なので、
   **ミオはナタ・ハリより速い**。順序が味方するはず。実測で確認する。
2. **軛（第四波・単発上限25）は毒の刻みも切る。** 毒の刻みは `ApplyDamage` を通るので、
   **層が 25 を超えると切られる**。着火型は層が伸びる機構なので第四波で天井に当たる。**波別に出す。**
3. **粛（第二波）・渇き（第三波）はミオに無関係。** ミオは自分の手番で撃ち、回復を持たない。
   **第84〜86期と違って波ルールの影響を受けない機構**であることを予測に書く。
4. **グザ（瘴気）と同席すると着火の機会が消える。** グザは毎ターン敵全体に毒を撒くので、
   **傷を持ち毒を持たない敵が存在しなくなる**。**グザ台では着火型は 0 回発火するはず**——
   これは欠陥ではなく、**毒軸と傷軸が別の入口として並ぶ**ということ。自己検査に入れる。

### 2-2. 書き方

`AmplifierTrait.Thicken` の `if (poison <= 0) continue;` を分岐させる。

```
poison = foe.Counter(StatusKeys.Poison)
if (poison <= 0)
{
    if (!ctx.Ignite.Enabled || foe.Counter(StatusKeys.Wound) <= 0) continue;
    foe.SetCounter(StatusKeys.Poison, IgniteAmount)      // = 1
    ログ（着火したことが分かる文言）
    continue;                                            // ★ 着火したターンは濃くしない
}

```

- **着火量は定数 1。傷の数に比例させない。** 着火型の要点は「1つあれば足りる」こと。
  比例させると「傷N個 × 係数」型に戻り、第84期の単価の壁に自分から入る。
- **★ 着火したターンは濃くしない。** 刻み（`CarveTrait`）の「足す前に読む」と同じ理由で、
  同じターンに着火して +4 すると**1発目から段が付く**。この順序で伸びは
  **1 / 5 / 9 / 13 …** の線形に留まる。
- **傷は消費しない。** 着火は敵1体につき事実上1回しか走らない（以後は毒 > 0 で通常の枝に入る）ので、
  消費させても回数は変わらない。**消費しないことで、抉り・断ち・縫いと同じ傷を邪魔しない**
  ——**傷軸と毒軸を同居させるのがこの機構の目的**なので、ここで取り合いを作らない。
- **味方には着火しない。** `Thicken` は敵だけを走査する。**その範囲を変えない。**
- **`ctx.Ignite` を `BattleContext` / `BattleEngine.Run` に省略可能引数で通す。** 既存の作法どおり。

## 7. 実装の注意

- **`Step`（4）と `IgniteAmount`（1）を振らない。** 掃引の対象はこの期に無い。
- **`AmplifierTrait` は敵の従軍司祭長など敵側が持っていないか確認する。**
  持っていれば `IgniteRule` が敵側にも効く。**味方に傷を書く手段が敵側に無いので実害は無いはずだが、
  敵が味方に着火した回数を 0 として確認すること。**
- **`OnAction` と `OnTurnStart` の両方から `Thicken` が呼ばれる。**
  ミオは `Actions = [Skill]` を持つので `OnAction` を通る。**両方の経路に同じ分岐が乗ること。**
- **`SetCounter` は `NoteStatusGain` を呼ぶので毒の計数は自動で乗る。** 別の計数を新設しない。
- **毒の刻みは `TickStatuses` の毒ループ。** ベニ同席時は味方の毒が2倍になるが、
  **着火は敵だけ**なので味方側は無風。
- **ラウは敵味方どちらの死骸からも飛ぶ。** 着火した敵が倒れたときの拡散を Q4 に計上する。
