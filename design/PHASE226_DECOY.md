## Q0-1 標的の介入の順番

`BattleContext.SelectTargetChain`（単体の一撃）の順。上ほど強い——**先に決まった段が後の段に上書きされるのではなく、後の段（介入）が主目標を差し替える**:

1. 的の固定（追い撃ち・乱れ撃ち＝第223期）——鎖を通さない
2. 貫きは手前で分岐（突き・`SelectPierceEntry`）——以下の段を通らない
3. **主目標**: 執着（ノミ）→ 断ちの選好（ナタ・ハリ）→ 見せしめ（シガ・動けない敵）→ `pool[Roll]`（前列 → 中列 → 全員）
4. 薙ぎ・全体はここで後備え（セッキ）だけ見て返す
5. **介入**（主目標を差し替える）: 標（`Marked`・75%・止めのトメは 100%）→ 後備え（後列の主目標だけ）→ 庇う（ガルド・前列）→ 殉教（敵）→ 棘守り（カド・構えているとき）

身代わり（カド）＝棘守り（5 の最後）。受け流し（ガルド）・逸らし（ソラ）は**標的を変えない**——`ApplyDamageBody` の中で当たった一撃の量を消す／半分を別の敵へ流す（逸らしは的を選び直さない）。
ヒサの矢面（第184期）は標の段（標を付けた味方に被ダメ半減）。

**挑発の置き場所**: 3 の主目標の段の**最後**（`pool[Roll]` の代わり・見せしめの後）。セロが pool にいるときだけ主目標をセロにし、`Roll` を引かない。5 の介入はすべてその後ろに残るので、**既存の介入はどれも挑発より優先**（標・後備え・庇い・殉教・棘守りがセロから的を引き剥がせる）。攻撃者側の選好（執着・断ち・見せしめ）も挑発より優先。

### Q0-7 過去の測定

- **挑発の先例は標（`Marked`）の段**——ヒサの矢面（第184期）・カリの駆り立て（第52期）は味方に標を付け、敵の単体の一撃を 75% で引き寄せる（介入の段の1段目）。
  **回避盾はそれより弱い段に置く**（主目標の段の最後）ので、標が付いた味方がいれば標が勝つ。第184期は「ザンは味方の挑発を敵の標に変える」、第150期は「読み手のいない行では標は避雷針」。
- **ソラの逸らし（第186期）との違い**: 逸らしは的を変えず、当たった一撃の半分を指差した敵へ流す（`ApplyDamageBody` の入口）。**回避盾は的そのものを変え、当たるかどうかを確率で決める**（避けたら 0・撃ち返す）。
- **バサの混乱**（第146〜148期）: 第147期に「行が前に変わった敵を混乱（1戦3回・回数制が確率より 5.6〜8.8pt 優る）」を採った。第146期の波ルール版（全ての移動で混乱・両陣営）は**供給の向きで符号が割れた**（敵だけ +42.3 ／ 味方だけ −41.9）——§3.1 は「敵だけ・バサがいる間」なので敵だけの側。
  第148期は手番版を落とし「**律速は在庫ではなく前へ出た敵の数**」と書いた——§3.1 はその数を増やす（Q0-3 の「うちバサ以外で前へ」）。
- **ハネ**（第189期）: 突き返しは前列の攻撃力最大を後列へ・転倒。「移動軸の台で代金（入れ替え）が +24.7pt」。**押し返しで後列の敵が前へ出る**（入れ替えの相手）——§3.1 でその敵が混乱する（バサとハネの対）。

### Q0 から読めること（実装の前）

1. **第225期の席ではセロはほぼ後列**（ターンの頭の 72% が後列・pool にいたのは 11%）。**挑発が効くのはセロが前へ出たときだけ**なので、K1 の効きは席で決まる——総当たりで選ぶ M-ハネはセロを前列に置くはず。
2. **M-ハネには介入を持つ駒が1枚もいない**——セロが pool にいる間、敵の単体の一撃は丸ごとセロへ来る。九/新兵 × 200/200 の単体の一撃は 1戦 14.2（届いたもの）で、40% で避けると 5.7 回・避け損ねた 8.5 発 × 22 ＝ **187** を HP42 のセロが受ける計算になる。**緊急退避・回避の入れ替えで前列から外れる**ので実際はずっと少ない。
3. **敵の移動の累計は T1 末で 6.0、T2 末で 10〜12**（Q0-5・K0）——段 4/8/14 なら段1 は T1、段2 は T2、段3 は T3〜T4（決着 4.1T）。K2 で供給が増えるので段3 は T3 に来る見込み。**段の条件は仮置きのまま 4/8/14** にした。
4. **バサ以外の移動で前へ出た敵は1戦 3.7**（うちほぼ全部がハネの突き返しの入れ替え相手）。今の混乱は 1.44（上限 3 回に届かない戦が多い）——§3.1 で混乱の候補はおよそ 3.5 倍になる。
5. **K0 の M-ハネ（225 の席）は 200/200 の九/新兵で勝率 89.0%・全員生存 65.0%**。ポンの「勝つことすらできない」とは席（または遊んだときの敵の並び）が違う。
