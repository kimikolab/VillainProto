## 1. 作るもの（診断だけ）

**新機構ゼロ。** 第67期の `creak` の格子（閾値ごとの到達%と到達T）を、
**ヨミ専用から全駒・全状態キーへ一般化する。** 診断名は `carry`（既存モードは書き換えない）。

### 1-1. 数える量（駒ごと・行ごと・波ごと）

| 量 | 定義 |
|---|---|
| **届いた累計** | その駒が1戦で外から受けた量。**キーごとに分ける**（下表） |
| **格子への到達%** | 閾値候補（1 / 2 / 4 / 6 / 8 / 12 / 16 / 24 / 32）に到達した試行の割合 |
| **到達T** | 届いた試行だけの平均ターン |
| **時間分布の判定** | 下の §1-3 |
| **振/戦** | その駒が実際に攻撃を振った回数（変質が乗る回数の上限） |

### 1-2. 対象のキー

**外から届く量**を全部（`TURN_SLOT_PLAN.md` §4-2 の表を実測で埋め直す形）:

| キー | 現状の読み手 |
|---|---|
| 強化（`WhetReceived`・第67期で実装済み） | ウツ（符号のみ） |
| 弱体（受けた累計） | ウツ（符号のみ） |
| 毒 / 燃焼 / 痺れ / 標 / 破片 / 傷 | ベニ・ヴィオ / **ホタ** / シガ / ザン / **ウロ** / エグ・ナタ・ハリ |
| `IdleTurn`（立った回数） | シガ・ガン・バン |
| 被弾（回数と量） | ムド・ガルド・ドハ・セッキ ほか |
| 移動（動かされた回数） | **ヨミのみ** |

**自前の値（`Displaced` の軋み、墓守の層、溜め）は「自前」列に分けて出す。条件の候補には入れない。**

### 1-3. 時間分布の判定（**この期の中心**）

各（駒 × キー × 行）について:

    形 = 2値      … 到達%が「ほぼ 100%」から「ほぼ 0%」へ1格子で落ちる（到達T の分散が 0 に近い）
    形 = 連続     … 到達%が格子に対して単調に落ち、到達T が格子とともに増える
    形 = 不発     … 最小格子（1）への到達%が 20% 未満

**判定式（測る前に固定）:**

- **2値**: 到達% が 80% 以上の最大格子と 20% 未満の最小格子が**隣り合う**、または到達T の**最大−最小 < 0.5 ターン**
- **連続**: 到達% が 20〜80% に入る格子が **2 つ以上**、かつ到達T が単調増加
- **不発**: 格子1 への到達% < 20%

**「載せられる駒」= そのキーで形が『連続』になる行を 2 行以上持つ駒。**

### 1-4. 単独成立度（問2）

各駒について、**その駒を含む行のうち「軸の相方がいない行」での寄与**を出す。

- **相方の定義は機械的に決める**: その行で、その駒と**同じキーの書き手または読み手**である他の駒
- `ablate` 相当（1枚抜きの勝率差）を、**相方あり行**と**相方なし行**に分けて平均する
- **相方なし行が 0 の駒は「単独では測っていない」**として別に並べる（**そこが第69期の穴になる**）
