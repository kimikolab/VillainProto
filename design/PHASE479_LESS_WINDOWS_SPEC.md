## 1. 画面の原則（この期から・製品の画面の決まり）

1. **盤を隠さない。** 出来事は盤の上（旗・名札・駒・光・短い浮き文字）と札（隊の札・金の札）で知らせる
2. **文は短く。** 説明の文は 1 行・20 字まで。それより長い説明は出さない（検証の層 F3 へ）
3. **読ませたいことはキャラのセリフで。** 説明文ではなく、顔つきの 1 行（仮の文でよい・後で直す）
4. **止めて選ばせるのは、選ぶことがあるときだけ。** 選ぶものが無い知らせで時計を止めて窓を出さない
5. 検証のための数字・表は全部 F3 の層へ

## 2. 窓の整理

| 今の窓 | どうするか |
|---|---|
| 中間拠点を取った（呼び戻す・強化・休むのボタンつき） | **窓をやめる**。旗が味方の色に変わる・「金 +8」が浮く・短い音。時計は止めない。金の使いどころは、その隊の札に小さなボタン 3 つ（呼び戻す・強化・休む）が出るだけ |
| 金が貯まっています | 窓・1 行をやめる。金の札が光るだけ |
| 負けた戦闘の後（誰が何ターン目に倒れたか） | **窓をやめる**。隊の札に 1 行「全滅　砦の守将 残り 1」。くわしくは「戦闘の記録」に |
| 門が開いた | 窓なし。門の扉が開く・カメラを 1 秒寄せる・目標の札が「砦を制圧」に変わる |
| 遭遇（戦う前） | **盤を隠さない横の札**にする（画面の右か左の 1／4・暗幕なし）。出すのは 敵の顔と数・名前・重さの印・賞金・「戦う」「引き返す」だけ。長い説明は外す |
| 連戦（続けて戦う／引いて待つ） | 同じ横の札。出すのは 次の相手の顔と数・今の隊の枚数と HP・ボタン 2 つ（同じ大きさ）。「続けて戦う」を押したら**そのまま開戦**（もう 1 度「戦う」を押させない） |
| 迎撃 | 同じ横の札。出せる隊が 1 つなら選ばせない |
| 戦闘の後（戦闘画面の結果） | 勝敗・倒れた駒の顔・残りの HP・賞金・「作戦マップへ」だけ。戦績の表は「詳細」の奥へ |
| ステージの頭の札 | 盤の図（道・拠点・見返りの印）と**目標の 1 行**だけ。勝ち方や道の違いの説明文は外し、キャラのセリフ 1〜2 行に置き換える（§3） |
| ステージの結果の窓 | 「踏破」・刻・失った駒の顔・金。**予告の 1 行は外す**。細かい戦績は「詳細」の奥へ |
| 「※ 拠点が空になります」の赤い 1 行 | 文をやめ、拠点の名札が赤く点滅する・歩いてくる敵の赤い点線を太くする |

## 3. 説明はセリフで（仮の文・後でポンが直す）

顔つきの吹き出しを 1 行。出すのは最初の 1 回だけ・盤の端に 4 秒・押せば消える・時計は止めない。

| いつ | 誰 | セリフ（仮） |
|---|---|---|

| 1-1 で峠の関に触れたとき | ドルガ | 「硬そうだ。……賞金は多いな」 |
| 1-2 の始め | ガン | 「中間拠点を 2 つ押さえりゃ、砦の門が開く」 |
| 1-2 で関所を取ったとき | ムド | 「ここで止める。拠点までは、来させない」 |

| 金が 20 貯まったとき（最初の 1 回） | ガン | 「金が余ってる。強化しとけ」 |

話す駒が手札にいなければ、いる駒の中から先頭の 1 体が話す（文は同じ）。セリフの表は 1 つのファイルにまとめ、後で差し替えやすくする。
**マップとマップのあいだのストーリーパート（会話）はこの期では作らない**——置き場が要ることだけ報告に書く。

## 4. Codex の試遊から拾う 3 点

1. 「引いて待つ」の後は、**撤退先で待機**にする（今は「敵の拠点へ進む」の命令が残って、補給の直後にまた突っ込む）
2. 戦闘の倍速を次の戦闘へ持ち越す
3. 「続けて戦う」の後の 2 度目の「戦う」をなくす（§2 と同じ）

## 5. 拠点を見分けやすく

- **味方の拠点・中間拠点・敵の拠点**の 3 種を、遠くからでも形で分かるように:
  - 高い旗竿と大きな幟（味方は青緑・敵は赤・取っていない中間拠点は灰）。幟に見返りの印（金貨・レリックの札）
  - 台を今の 1.5 倍に・地面に色の輪。建物の影を大きく
  - 引いた視点でも名札が読める大きさ（視点の遠さで名札を拡大）
- 全体図でも同じ 3 種の形と色
- ふつうのマス（道の途中）は今より小さく・地味に

## 6. 本陣を重く（1 章の 1-2・`ChapterRule.V479`）

狙い: 「守りを抜いた隊がそのまま守将も抜く」を減らし、**引いて休む・2 隊目を当てる**が要る山場にする。

測る候補（`--foe-weight` と通し・持ち込みは組 B とポンの写し〔第477・478期〕）:
- 守将 ×0.8／×0.8（今）／×1.0／×1.0／×1.2／×1.0
- 本陣の守りを 1 段重く（今の守り → 騎士の小隊の混ざった守り）

線:
| 線 | 値 |
|---|---|
| ポンの写しの隊・満タンで守将 | 勝てる（18／20 以上）・終わりの HP 30〜50% |
| ポンの写しの隊・守りを抜いた直後に続けて守将 | **8〜12／20**（今は 16） |
| 通し: 方針 1・2 の勝ち（組 B・留守番 2 枚・引く器具） | 60% 以上 |
| 通し: 「引いてから勝った」通し | 方針 1・2 とも 30% 以上 |
| 通し: 続ける器具と引く器具の勝ちの差 | 引く方が 10pt 以上高い（引く得が出る） |
| 制圧の刻の中央値 | 期限 16 の 3 刻以上手前 |

通る候補のうち、いちばん軽いものを採る。通らなければ表を付けて止まる。
