## 1. 号令の玉 ——「余った声援が、ヒサに溜まる」

### 何が起きるか
- ヒサの叫びの回復のうち、満タンで入らなかった分（溢れ）がヒサに溜まる
- **20 で玉1つ・玉は3つまで**。満杯のときに来た溢れは捨てる

### 欲しい絵
- ヒサの頭上（か足元）に**玉の枠3つ**。溜まるたびに1つずつ灯る
- 満杯で捨てたときは、玉から小さく光がこぼれる程度（うるさくしない）

## 2. 号令 ——「ほら、あいつだよ」

### 何が起きるか（`Command`「手番」）
1. ヒサの手番で、ヒサが敵を指差す
2. **玉を使って、その敵に層を一度に刻む**（玉1つ＝1層・最大3）
3. **層1つにつき、浮いているミサの羽が1本ずつその敵へ向きを変えて撃つ**
4. （同じターンの続き）ミサの一斉射撃 → ザンの仇巡り

### 欲しい絵
- ヒサの玉が指先から敵へ飛び、敵の頭上の層の数字が一気に増える
- ミサの羽が**ヒサの指差しに従うように**一斉に向きを変える——「ファンネルの指揮をヒサが執っている」絵（裏設定: ヒサはミサの羽の向きを嘘と指差しで操っている）
- 「4段」（号令 → 羽 → ミサの一斉射撃 → ザンの仇巡り）が1ターンに揃うと気持ちいい。間を詰めすぎず、段ごとに一拍おく
- **予告（第302期で測る版・採否待ち）**: 号令で**味方全員の攻撃力が上がる**（鼓舞）版がある。採られたら、号令の直後・羽より前に「仲間が奮い立つ」絵（全員に短い光・攻撃力の上がった印）が入る。順は 号令 → 鼓舞 → 羽 → 一斉射撃 → 仇巡り

## 3. 庇い ——「一度だけ、仲間の前に立つ」

### 何が起きるか（`Cover`）
- 味方が敵の倒れる一撃を受ける瞬間、**ヒサが前に飛び出して代わりに受ける**。1戦に1度
- 受ける直前に**ヒサが自分を指差す**（自分に標）→ ザンがその敵へ仇討ちに走る
- ヒサは倒れることがある（それでよい・見せ場）

### 欲しい絵
- いつも仲間を盾にするヒサが、この1回だけ前に出る（裏の仲間思いが表に出る瞬間）
- 自分を指差す小さなポーズ（「…こっちだ」）→ 一撃を受ける → ザンが走る
- 庇われた味方は無傷（ダメージ表示なし）

## 4. 粛でヒサが黙る

### 何が起きるか（第302期の規定）
- 粛（第2波）の保持者が生きている間、**ヒサの「あいつがやった！」は出ない**（庇いも出ない）
- 叫び（あいつを狙え！）がどうなるかは第302期の結果次第（`PHASE302` の報告を見ること）

### 欲しい絵（任意）
- 指差しが止まった瞬間に、ヒサの吹き出しが「…」になる、口を押さえられる、など。台本に出来事があれば付ける（無ければ不要）

## 5. 持ち越しの不具合（演出とは別・Codex 側で直してほしい）

- **頭なしの再生で終了後に落ちる**（第301期報告 §6 末尾）: 試遊・標 循環 × ボス規定形の再生は `DEMO_SMOKE_COMPLETE` まで行くが、終了後に Godot が `Illegal instruction`（終了コード 132）で落ちる。ログに `Leaked unsafe reference`（`Tween` ／ `PropertyTweener` など数千行）。戦が短くなった（T6 → T4）ことで演出が残ったまま終了しているように見える。**終了時に Tween を止めて片付ける**のが筋
- **`DemoApp/assets/portraits/` の `.import` 2つが未追跡**（第300期報告）。要るものならコミット、要らないなら `.gitignore`
