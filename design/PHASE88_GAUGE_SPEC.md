## 0. 主題 —— 4期分の否決に、器具の欠陥が2つ混ざっている

### 0-1. 欠陥1: 線の根拠が水準と増分を取り違えていた

第84期の指示書は、主判定の線 +3.0pt の根拠をこう書いた。

> 第80期 表D の組の平均相乗は 供給→読み **+3.36** / 読み→読み **−1.11**

**これは「組の相乗の水準」**——両方の駒が本物か素体かで測った、**駒2枚ぶんの噛み合いの大きさ**。
ところが第84〜87期が測っているのは **Δ相乗**、**片方の駒に規則を1本足した増分**である。

**水準の分布から引いた線を、増分に当てていた。** 第87期の実測がその歪みを直接示している。

- 出力 **+8.3%** → 勝率 **+1.0pt**
- 線の **+3.0pt** に届くには **出力 +25%** が要る

**特性1本で総与ダメージを 25% 増やす駒はロスターにほとんど無い。**

### 0-2. 欠陥2: 2×2 の台に情報帯のフィルタが無い

`compare` には**情報セル**（`0 < x < 100`。床にも天井にも張り付いていないセル）が第31期からある。
**2×2 のドラフト台には無い。**

第87期の報告書:

> ドラフト台の 128 台のうち **y00 が 0% の台が厚い**ので、出力を1割増やしても床から出ない

理想台でも同じことが起きた——4台のうち3台が **100/0/0/0/0** で、
**機構が最も強く働いている台（着火由来の毒 72.6/戦・持続係数 47.1・ベニの回復 6.6 倍）で勝率が 0.0% のまま動かない。**
副判定 (C) の中央値 0.8× は**死んだ台3つの産物**で、**生きている1台だけを見れば 4.6×**、第2波は +18.00pt だった。

### 0-3. 欠陥3（**これが一番深い**）: 大きさを線にしたこと自体

`CLAUDE.md` の優先順位は

> 面白さの探索 ＞ 新しいシナジー ＞ キャラの個性 ＞ 実装のシンプルさ ＞ 大まかなバランス ＞ 細かな数値バランス

**「Δ相乗が +3.0pt 以上」は最下位の「細かな数値バランス」の基準である。**
最優先の「新しいシナジーが生まれるか」を測るなら、見るべきは大きさではなく**特異性**——
**意図した相手だけが動き、意図しない相手が動かないか。**

第87期の実測はその意味では合格していた。

| | 値 |
|---|---|
| 有意な正 | **50 体中 2 体。その2体がキリとノミ**（＝傷の書き手そのもの） |
| 傷を書かない48体 | **\|Δ\| ≤ 0.24 で不動** |
| 2系列 | +0.63 / +1.32（同符号） |
| 順位 | **2 / 50** |

**機構は正しく効いている。効いた量が線に届かなかっただけ。**
第84期（+0.04・順位も出ない・有意でもない）とは**質が違う**のに、同じ線で同じ「×」が付いた。

## 2. 情報帯のフィルタ（**測る前に定義を固定**）

### 2-1. 定義

2×2 の4セルのうち、**A を素体にした2セル**（`y00` ＝ 両方素体・`y01` ＝ A 素体/B 本物）は
**版に依らない**（§1-4）。**版に依らない量だけで台を選べば、選び方が結果を汚さない。**

> **情報帯**: `y00` と `y01` の**両方が 0.0%**、または**両方が 100.0%** の台を、主判定の分母から外す。

**A 本物のセル（`y10` / `y11`）は選別に使わない。** 使うと処置の結果で標本を選ぶことになる。

### 2-2. 出し方

**フィルタ前とフィルタ後を必ず両方出す。** 片方だけにしない。

| 出すもの | 内容 |
|---|---|
| 台の内訳 | 全台数 / 床で死んだ台 / 天井で死んだ台 / **情報帯の台** |
| Δ相乗 | フィルタ前 / フィルタ後（系列別・SE 併記） |
| 有効標本 | 情報帯の台数が **K = 64 のうち何台か**（少なすぎれば SE が跳ねる） |

**情報帯の台が 20 台を下回る組は「測れていない」と書く。** 判定に使わない。

### 2-3. 理想台にも同じ線を当てる

第87期の理想台4台のうち3台が **100/0/0/0/0** だった。
**同じ定義（素体の側で床／天井に張り付いている台を外す）を理想台にも当てる。**
**外した台は「測定になっていない」と書き、乖離の中央値の分母から除く。**

## 4. 新しい判定規約（**§5 の数字を見る前にここを固定する**）

### 4-1. 主判定 —— 特異性

> **Q1: 意図した相手が有意に正で、意図しない相手が動かないこと。**
>
> 1. **意図した相手**（その機構が繋ぐと設計した駒）の Δ相乗 が、**2系列とも正**で、
>    **\|Δ\| がノイズ床（§3 の N2）を超える**
> 2. **意図しない相手**の中で \|Δ\| がノイズ床を超える体数が、**N3（偽陽性の期待数）以下**
>
> **大きさは記録するが線にしない。**

**根拠**: このフェーズの最優先は「新しいシナジーが生まれるか」で、それは
**噛み合いが意図した場所にだけ立っているか**で決まる。勝率が何ポイント動くかは
`CLAUDE.md` の優先順位で最下位の「細かな数値バランス」に属する。

### 4-2. 副判定 —— 新規性

> **Q2: 新しい上位の組が生まれたか。**
> 意図した組の順位（50 体中）が、機構の前後で**上位10位以内に入ったか**。
>
> **Q3: 既存の噛み合いを食っていないか。**
> 負の側で ノイズ床を超えた体数と、その顔ぶれ。

### 4-3. 拒否権（**大きさの線はここにだけ残す**）

**壊れることだけは大きさで見る。** 作ることは特異性で、壊すことは大きさで。

1. **主判定19行の第五波平均が `Baseline.PrimaryFifthFloor` = 33.2% を下回る**
2. **`compare` で第五波が 95% を超える行が新たに2行以上生まれる**
3. **主判定19行のいずれかが、いずれかの波で −10.0pt 以上落ちる**

### 4-4. 常設の副判定（第86・87期から引き継ぐ）

- **(A) 読み手の発火回数/戦（稼働率）**
- **(B) 持続係数**（**単独では採否を決められない。第87期が反例。決着ターン数を必ず併記**）
- **(C) 台の乖離**（**§2-3 のフィルタを当ててから**）

### 4-5. **やってはいけないこと**

## 10. 申し送り（**第89期の入口**）

- **接続子が両方とも出力ゼロの軸どうしは、5枠盤では橋を架けられない**（第87期）。
  キリ（与ダメ常に1）＋ミオ（攻撃しない）で2枠が出力ゼロになり、受け皿を積むと3枠が消える。
  **次に傷を他軸へ繋ぐときは、接続子の少なくとも一方が出力を持つ組を選ぶ。**
- **紙の分子が二次の量なら、1ターンの丸めが2倍の誤差になる**（第87期の自己検査 (h)）。
  累積 = 2L² − L。**線形の分子（第85期）は下限にぴたり乗った。**
- **リィカ型の供給**（第86期）: 一回きりの供給は**広く浅く**、毎ターンの供給は**狭く深い**。
  深さを読む機構と率を読む機構で、効く書き手が違う。
- **残っているもの**: 3分の器具の再設計／ササを広さの側で評価／最後の1枠／ムドの呪い／
  `AcceptsSupport` の統一／情報セルと測れる席の帯の不整合。
