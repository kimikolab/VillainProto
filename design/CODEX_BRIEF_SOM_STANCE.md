# Codex 向け発注メモ（追補）—— 背いた獣の「臨戦態勢」

置き場所: `design/CODEX_BRIEF_SOM_STANCE.md`。`design/CODEX_BRIEF_SOM_SPARK.md` ／ `CODEX_BRIEF_SOM_SWARM.md` の追補。
触るのは `DemoApp` の演出とアセットだけ（`BattleCore` には触らない）。台本の細部は `design/PHASE291_CODEX_MEMO.md` §14 を正とする。

## 0. 直したいこと（ポンの試遊）

いまの獣は「ソムの側から走り込み、着いた瞬間に弾け、光が味方に降る」。この流れが **「下僕を特攻させて、その爆発で回復している」** ように見えてしまう。

見せたいのは特攻ではなく、**寝返った下僕が、こちらに牙を剥く瞬間**。

## 1. 欲しい絵（第312期の規定・仕組みは変えない）

`BeastBurst`（「弾ける」／「群れ」／「緊急」）の1回ごとに、次の4拍で見せる。

1. **寝返り**: 獣がソムの側から敵陣へ走り込む（既存の演出）
2. **牙を剥く**: 敵陣に着くと、**くるりと振り返ってこちらと向き合う**。毛を逆立て、喉を鳴らすように威嚇する（敵の一員になった、が一目で分かる）。ソムは驚きの顔
3. **臨戦態勢**: 獣が雷を纏う。体表の電気が膨らみ、首輪の宝石が明滅する
4. **暴発**: 小さな体では雷を纏いきれず、そのまま暴発して弾ける。隣の敵へ放電が走る（既存の放電）。隣の敵が帯電していれば、そこから連鎖が広がる

その後の光（降る光 ／ 緊急で危ない味方に集まる光）は今のまま。ただし、**光は一度ソムの魔導書に吸い込まれてから降る**ようにする（弾けて散った雷の残り火を、ソムが回収して配っている、と読めるように）。トウの粉やカタの雷で敵が弾けたときの光も同じ流れにする。

### 群れ ／ 空き枠が無いとき

- 群れ: 2〜5匹が一斉に振り返って威嚇し、まとめて暴発する（1拍ずつ順番にやると長いので、群れは同時に）
- 空き枠が無いとき（台本の `BeastBurst` の `Amount` ＝ 1）: 敵の前列に飛び込みながら振り返り、着地と同時に暴発してよい（2〜3拍目を短く）

## 2. 気をつけること

- 毎ターン起きるので、2〜3拍目は**短く**（威嚇の一瞬が読めれば十分）
- 「処刑」には見せない（首輪が罰として爆ぜる、ではなく、獣自身が纏った雷に耐えきれず暴発する）
- 近いうちに、**隣の敵が帯電していないときは獣が弾けずに立って残る**版を測る予定（第314期の候補）。その版が規定になったら、3拍目のまま**雷を纏って立ち続け、味方の攻撃で弾ける**分岐を足すだけで済むように、2〜3拍目と4拍目を分けて作っておく

## 3. 試遊で見たいこと（ポンが画面で確かめる）

- 「特攻して回復」ではなく「寝返った下僕が牙を剥き、勝手に暴発した」と読めるか
- 光がソムの魔導書を経由して降ることで、回復の出どころがソムだと分かるか
