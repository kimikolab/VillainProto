## 2. 作るもの

**診断モード `burn` を1つだけ足す。** 既存モードは書き換えない。

### 2-1. 計数（盤面を動かさない）

`UnitTally` に燃焼の計数を足す。**どれも誰も読んで分岐しない私有カウンタ**
（第49期の `ScapegoatDotByUnit` と同じ扱い）。

| 名前 | 置き場所 | 数えるもの |
|---|---|---|
| `BurnLit` | `BattleContext.Ignite` | 火が**点いた**回数（`relit == false`） |
| `BurnRelit` | 同 | 火が**煽られた**回数（既燃への再付与＝**捨てられた供給**） |
| `BurnLitAlly` | 同 | うち味方へ付けた回数（`friendly: true`） |
| `BurnTicks` | `TickStatuses` の燃焼ループ | 燃えたターンの延べ数 |
| `BurnTaken` | 同 | 燃焼で実際に HP を失った量 |
| `BurnSoaked` | 破片の段 | 燃焼の刻みのうち**破片が吸った**量 |

**着火は「誰が付けたか」ではなく「誰に付いたか」で持つこと。**
`Ignite` は付け手を受け取らない。引数に足すと呼び出し規約が変わり、
「盤面を動かさない」という保証が弱くなる。付け手の側は**その行にボルグが1枚しかいない**ことで一意に決まる。

`BurnSoaked` だけは `ApplyDamage` が「刻みかどうか」を知らないので、
既存の `isFriendlyFire` と同じ形の**既定値つき引数を1本足す**か、`TickStatuses` 側で
**破片の残量の差**から求めること。**どちらでもよいが、選んだ理由を報告書に書く。**

### 2-2. 対照（同数値・特性だけを落とした素体）

診断のローカルに `UnitDef` を2つ定義する（`UnitCatalog` には足さない。第49期の `SgPlain` と同型）。

| 対照 | 中身 | 測れるもの |
|---|---|---|
| `BorgNoCinder` | ボルグと HP・攻・速・薙ぎ・`Splash` まで**完全に同一**。**`Cinder` だけを落とす** | **火の粉の帰属** |
| `HotaPlain` | ホタと HP・攻・速・単体まで**完全に同一**。**特性なし** | **熾火の帰属** |

**`Splash`（巻き込み）を残すのが要点。** 一緒に落とすと「巻き込みが消えたから勝った」と混ざる
——第34期の「HP を振ったつもりが波の総HPも振っていた」と同じ穴。
**差分を燃焼だけに閉じることが対照の成立条件。**

### 2-3. 測る条件

対象は**ボルグを含む8行**（ホタを含む1行はその内数）。1条件 = `compare` 相当を1回。

| # | 条件 | 何が分かるか |
|--:|---|---|
| 0 | 現行のまま | 基準 |
| 1 | ボルグ → `BorgNoCinder`（8行） | **火の粉の帰属** |
| 2 | ホタ → `HotaPlain`（燃焼 の1行） | **熾火の帰属** |
| 3 | 両方を素体に（燃焼 の1行） | 軸まるごとの帰属。**1と2の和との差が交互作用** |

### 表A: 供給の実測（8行 × 5波）

| 行 | 波 | 着火(敵) | 着火(味) | **再着火** | **捨て率** | 燃ターン(敵/味) | 燃ダメ(敵/味) | 破片が吸った | 燃焼で落ちた(敵/味) | 決着T |

**捨て率 = 再着火 ÷ (着火 + 再着火)。これが H2 の判定値。**
波ごとの燃焼量が Phase 0-3 の予測（敵の数と決着ターンで決まる）と合うかもここで見る。

### 表B: 位置との接続（油の判定材料）

**8行はボルグの席がばらけている**（前3・後1・後3など）ので、そのまま勾配になる。

| 行 | ボルグの席 | 次数（隣接する味方の数） | 着火(味)/戦 | 巻き込み(味)/戦 | 火の粉の帰属(pt) |

### 表C: ホタの稼働（燃焼 の1行・波別）

| 波 | 振った回数 | **うち燃えていた割合** | 初着火のターン | ホタが受けた燃焼ダメ | ホタが落ちた率 | 熾火の帰属(pt) |

**「振った回数のうち燃えていた割合」が稼働率の本体。**
ボルグ（速8）はホタ（速7）より速いので、**第1ターンから既に点いている可能性がある**
——供給待ちが存在しないなら H1 は成立しない。

### 表D: 燃焼軸の予算（爆弾の判定材料）

燃焼 (ボルグ×ホタ) の5枠を **供給1 / 読み手1 / それ以外3** に分け、
それ以外の3枠それぞれの寄与を `ablate` 相当（1枚抜きの勝率差）で出す。
**3枠を要求する案が入る余地があるかの材料。**

### 表E: 通貨どうしの接続（本題）

**「燃えている」という事実を読んで分岐する箇所**を通貨ごとに数える。
**ダメージ層の各段は数えない**——あれはダメージを読んでいるのであって燃焼を読んでいない
（§1-2 の区別をそのまま使う）。

| 相手の通貨 | 燃焼 → 相手 | 相手 → 燃焼 | 根拠（ファイル:行） |
|---|--:|--:|---|
| 毒 / 標 / 痺 / 破片 / 傷 / `IdleTurn` / 位置 / 死 / 強化・弱体 | | | |

**0 が並ぶことが予想される。並んだ場合、それは欠落ではなく空き地の地図として書く。**
