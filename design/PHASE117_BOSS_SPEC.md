# 第117期 —— 「被害で育つ駒」×「死なない駒」を測る（ボスの土台）

起点: 引き継ぎのボス戦のメモ。**壁は3つ**（時間を買う手段が薄い／倍率が積み上がらない／**防御を無効化する経路が0本**）で、
そのうち唯一**出力が時間に比例する形**が「被害で育つ駒 × 死なない駒」だと書かれているが、**一度も測っていない。**

**この期は新しい機構を1つも作らない。** `BattleCore` に足すのは計数だけ。**`Presets` も触らない**（診断のローカル台）。

第116期の直後で、物差しが1つ増えている:

> **範囲化の価値は打点ではなく決着ターンに出た**（与ダメ +47% に対し撃破 +11%。第四波 +43.0pt の本体は 7.39 → 6.92T）。

**ボスは逆向きの問題である。** 決着を早める機構ではなく、**長引いたときに出力が伸びる機構**が要る。
**同じ物差し（ターン）で測れる位置にいる。**

**この指示書は自己完結させてある。** 規約は `CLAUDE.md` の規約節（(G1)〜(G16)）。

## 0. 主題

### 0-1. 何を知りたいか

> **戦闘が t ターン続いたとき、味方の出力は t に対してどう伸びるか。**
> 伸びるなら、その傾きは**どの組み合わせで**作られるか。

いまの編成は 400〜600 の総火力で、ボスは総HP 1,400〜1,800（未検証の見積もり）。**3〜4倍足りない。**
定数の火力を足しても届かない——**時間に比例する項が要る。** その項を持ちうるのが:

| 枠 | 駒 | 機構 |
|---|---|---|
| **被害で育つ** | ムド（`Rage`）／カド（棘・`Havoc`）／ヨミ（`Displaced`）／ウツ（`Perverse`） | 被弾・移動・弱体を攻撃力に変える |
| **死なない** | ガルド（`Stoic` ＋庇い）／ヴェル／ムグ（`Splitter`）／ゴルム（`Colossus`） | 時間を買う |

**16 組の総当たりを測る。**

### 0-2. 測るのは勝率ではない（**この期の判定の芯**）

勝率は「決着が早いほど高い」ので、**時間に比例する項を探す期には向かない。**
測るのは**傾き**:

| | 定義 |
|---|---|
| **生存T** | 味方が全滅するまで、または決着までのターン数 |
| **育ちの傾き** | 被害で育つ側の `CurrentAttack` の**ターンあたり増分**（前半3T と後半3T で別々に） |
| **出力の傾き** | 味方の**与ダメ/T** を前半と後半で比べた比 |
| **到達点** | その戦闘での `CurrentAttack` の最大値 |

**出力の傾きが 1.0 を超える組**（後半のほうが強い）が、ボスに向かう候補である。

### 0-3. この期で触らないもの

- **`Presets.Compare` / `Presets.Cross`**（診断のローカル台だけで測る）
- **駒の数値・特性**（1つも変えない）
- **ボスの実装**（数値も敵も作らない。**土台を測るだけ**）
- **添付の「糧タンク」**（§7 で扱う。**この期では実装しない**）

## 1. 台

### 1-1. 16 組（**4 × 4 の総当たり**）

**被害で育つ 1 枚 ＋ 死なない 1 枚 ＋ 共通の土台 3 枚**の5枚組。
**土台は 16 組すべてで同一**（比較の成立条件——第32期以降の作法「ルール保持者は既存と数値・型を完全同一にし、差分を1つに閉じる」）。

**土台3枚の選定規則**（Phase 0 で実装から引いて確定する）:

| | 条件 | 理由 |
|---|---|---|
| (a) | **`AtkBonus` を他人に書かない** | 育ちの傾きに別経路が混ざる |
| (b) | **`Overload` / `Perverse` を持たない**（＝`AtkBonus` の読み手でない） | 第116期で読み手が2枚になった。混ぜない |
| (c) | **被弾・移動・弱体の供給者でない** | 育ちの入力を土台が供給すると、組の差が消える |
| (d) | **16 組すべてで生存し得る**（極端に脆くない） | 土台が先に落ちると生存Tが土台で決まる |

**(a)〜(d) を満たす駒を全数列挙し、その中から選んだ理由と落とした候補を報告書に書く。**

### 1-2. 対照

| 対照 | 内容 |
|---|---|
| **素体** | 被害で育つ側を**同じ数値・特性なし**に置き換えた版（16 組ぶん） |
| **単騎** | 被害で育つ側だけ（死なない側を土台の駒に置換）4 組 |
| **死なない側だけ** | 育つ側を土台の駒に置換 4 組 |

**帰属＝組 − 素体。** ただし**この期の主役は帰属ではなく傾き**（§0-2）。

### 1-3. 波

**第2〜5波 ＋ 長期戦の代用**。ボスは長い戦闘なので、**5波だけでは傾きの後半が取れない可能性がある**。

> **Phase 0 で「16 組の決着ターンの分布」を測り、後半3T が取れる波を選ぶ。**
> 決着が 5T 未満の波しか無いなら、**敵のHPを一律に増やした長期戦の台を1つ足す**
> （**敵の特性・攻撃力・体数は変えない。HP だけ**。差分を1つに閉じる）。

seed 0..199。**分母は毎回明示する**（(G4)）。

## 2. 門と判定

### 2-1. 門（16 組 × 波別）

| 門 | 内容 |
|---|---|
| 門1 生存 | 味方の生存Tの平均／決着T |
| 門2 育ち | 育つ側の `CurrentAttack`（開戦時・前半3T 終了時・後半3T 終了時・最大） |
| 門3 出力 | 味方の与ダメ/T（前半3T・後半3T） |
| **傾き** | **門3 の後半 ÷ 前半** |
| 空振り | 育ったが**振れなかった**回数（休み番・`CanAct` 偽・痺れ） |

**第115期の器具の反省を当てる: 同じ比を作る2つの計数は同じ瞬間で取る。**

### 2-2. 判定

| | 内容 | 線 |
|---|---|---|
| **Q1** | **時間に比例する項が実在するか**: 傾き（門3 後半÷前半）が **1.2 以上**の組が **3 組以上** | 二値 |
| **Q2** | **組み合わせで割れるか**: 16 組の傾きの**最大と最小の差が 0.5 以上** | 二値 |
| **Q3** | **死なない側が生存Tを実際に買っているか**: 各「死なない駒」について、単騎対照との生存Tの差 | **+1.0T 以上**が4枚中**2枚以上** |
| **Q4** | **育ちが出力になっているか**: 門2 の到達点が高い組で門3 も高いか（順位相関） | **r ≥ 0.5**。低いなら**育ちは帳簿の上だけ**（第114期の教訓） |
| **Q5** | **ボスに足りるか（紙）**: 傾き最上位の組で、**戦闘が 15T 続いた場合の累積与ダメ**を外挿する | **1,400 に届くか**を数字で書く。**門ではなく出力**（(G7)） |

**Q4 が落ちたら、それがこの期の結論である**——「被害で育つ駒は時間に比例する出力を作らない」。
**その場合、ボスの壁は3つのうち残り2つ（倍率・防御無効化）でしか越えられないことが確定する。**

### 2-3. 予測（**測る前に書く**）

1. **ゴルム × ムド が傾き最上位**——巨躯が後列への攻撃を全部引き受けるので、`Rage` の入力が最大化される。
   ただし**ゴルム自身の死で傾きが折れる**はず（生存Tの分布が二峰になる）
2. **ウツはどの組でも傾きが低い**——弱体の供給が土台に無い（規則 (c)）ので、入力が敵依存
3. **ヨミは死なない側と噛まない**——`Displaced` の入力は「隊列を動かされること」で、
   **死なない駒は移動の供給者ではない**。16 組で最も低い群になる
4. **Q3 はガルドとゴルムが通り、ムグとヴェルは通らない**（分裂・継ぎ接ぎは「死んでから」の機構で、生存Tを直接は延ばさない）
5. **Q5 は届かない**——15T でも 1,400 の半分程度。**「時間に比例する項はあるが、傾きが足りない」**が結論になる

**外れた項目は「何を数えていなかったか」の形で書く。**

## 5. 結論と分岐

報告書 `design/PHASE117_BOSS.md` の冒頭に、**1つの引用ブロック**で Q1〜Q5 の○×と、傾き上位3組。

- **Q1・Q2・Q4 を通る**: **ボスの土台が立った。**次の期は「その組を `Presets` に収録するか」ではなく、
  **ボスの敵側を作る期**（総HP・防御・波の形）。**傾き上位の組が前提になる**
- **Q4 が落ちる**（育ちが出力にならない）: **この期の結論。**
  「被害で育つ駒は帳簿の上で育つだけ」が確定し、**ボスの壁は倍率か防御無効化でしか越えられない。**
  次の期は**防御を無効化する経路**（貫通・剥がし）を1本作る期
- **Q3 が落ちる**（死なない駒が時間を買っていない）: **「死なない」の定義が実態と違う。**
  ムグ・ヴェルは「死んでから」の機構なので、**時間を買う駒は実は 2 枚しか無い**ことになる。
  ボスの前提が変わるので、**その2枚で組み直して測り直す**
- **Q5 が届く**（15T で 1,400）: 見積もりが甘い可能性が高い。**外挿の前提を全部疑ってから喜ぶこと**

## 7. 添付「糧タンク」の扱い（**この期では実装しない。査定だけ**）

別セッションで書かれた `SPEC_NOURISH_TANK.md`（自己回復タンク ＋「自分を殴った者の攻撃力が上がる」）は、
**この期のテーマと同じ場所を狙っている**——**死なない駒であり、同時に「被害で育つ駒」への供給源**。

**ただし前提が古い。** 実装で確認した差分:

| 添付の記述 | 現在 |
|---|---|
| `compare` **42 行** | **61 行**（＋交差帯 12 行） |
| 「ロスターに空き枠がある」前提 | **52 枠は全部埋まっている。**新規追加は**差し替え**になる |
| **`Armor` は書き手ヒビ1体・読み手 0 の空白地** | **第47期に読み手ができている**（鱗＝破片がある間は貫き化）。**空白地ではない** |
| `AtkBonus` の読み手は実質ウツのみ | **第115〜116期で 2 枚**（ウツ ＋ **バンの `Overload`**＝`AtkBonus >= 5` で薙ぎ化） |

**最後の1行が重い。** `Nourish`（殴った者に +2/hit）は**強化の 8 本目の窓口**になり、
**`Overload` の閾値 5 を3ヒットで超えさせる。** 第116期の実測「強化は段で来るので薙ぎ率は 0% か 100% しか出ない」に対し、
**`Nourish` は初めて『連続量で積む強化』を持ち込む**——閾値の意味が変わる。
**これは面白い方向だが、`Overload` を載せた直後に測ると、どちらが効いたか読めない**（第113期「計測器と測定対象を同時に動かさない」）。

> **順序の提案: 第117期（この期）で土台を測る → 結論が出てから糧タンクを立てる。**
> この期の Q3 が「時間を買う駒は実は2枚しか無い」と出れば、**糧タンクはその穴を埋める駒として位置づけが決まる。**
> Q4 が落ちれば、**そもそも被害で育つ側に供給しても意味が無い**ので、糧タンクの設計も変わる。

**差し替え先の候補**についても、この期が材料を出す——**16 組の対照で「入れても傾きが1ビットも動かない駒」が分かる。**
**Q3・Q4 の結果に、機能していない駒の名前が出るはず。**

**この期の報告書 §8 に、糧タンクへの申し送りとして次の3点を書くこと:**

1. **Q3・Q4 の結果から見た糧タンクの位置づけ**（時間を買う駒として要るのか、供給源として要るのか、要らないのか）
2. **`Overload` との相互作用の見立て**（連続量で積む強化が入ると閾値の意味がどう変わるか）
3. **差し替え候補**（この期の対照で傾きに寄与しなかった駒。**名前と実測値**）
