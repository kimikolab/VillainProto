## 1. 目的

第211期の追加調査（`tsugi pon5` / `pon5log`・報告 §3.7）で、ポンが遊んだ編成（**パターン2で ガン・ツギ・ドルガ・ササ・セロ**。ガルドをガンに入れ替えたもの）でササが倒れる本当の原因が分かった。**第三波ではササが 200 戦とも倒れ、Y0〜Y3 のどの版でも変わらない。**

1. **速い敵が毎ターンの頭にササを殴る**。勇者候補（速14）がササ（速12）とツギ（速8）より先に動き、ササを 23 で殴る。身構え（一撃を 7 まで）はササ自身の手番で張るので、ターンの頭の一撃には効かない。ツギの手番の板も、速い敵が殴り終わった後に届く
2. **応急処置はそのターンの1回目で使い切る**。応急処置で貼った板が狙撃手の 32 でほぼ割れた後、続く攻撃で削られても、そのターンの1回はもう使っている（R315: 条件を満たす機会に対して、上限で貼れなかった回数が貼った回数の約 2.5 倍）
3. **この編成では、板をササに貼る Y1 で第五波がかえって悪くなった**（全員生存 41.5 → 30.0）。守りを足したのに悪くなるのは、カドの棘が板で飢えたのと同じ形に見える。ササの身構えは「受けた一撃を切り落とし、その分を弾いて隣の味方の破片にする」ので、**板が先に一撃を吸うと、身構えが働く一撃が無くなる**のではないか（**未確認の読み**。Q0-3 で確かめる）

あわせて、第210期で入れた**腕（砕かれた累計で基本の厚さが伸びる）はほとんど効いていない**（段2 に届くのが4ターン目で、その頃には板を貼り終えている）。

そこで:

- **腕の中身を「応急処置の回数」に差し替える**（2 への答え）。押されて板が砕かれ続けるほど手際が上がり、同じターンに何人も拾えるようになる
- **出撃前の板**: 開戦時に前列の味方へ板を貼っておく（1 への答え）。行動順に関係なく、最初の一撃から前衛が守られる
- **板とササの身構えの関係を調べ、当たっていればカドと同じ扱いにする**（3 への答え）

### 1.1 絵

- 戦の始まりに、前衛の体にはもう継ぎ当てが貼ってある（職人の段取り）
- 戦が長引くほど、ツギが次々と駆け込んで倒れかけの味方を拾っていく
- フレーバー「治せない。だから、これ以上壊れないように塞いだ。」——壊れる前に塞いでおく

## 2. 変更

### 2.1 腕の中身を「応急処置の回数」に差し替える

- 腕の段の上がり方（板の印を持つ味方が敵を出どころとするダメージで失った破片の累計が 40 → 120 → 240 … の三角数）は**変えない**
- 腕の効果を差し替える:
  - **基本の厚さに掛けていた倍率（1 + 0.2 × 段）をやめる**（基本は常にツギの最大HPの 40%）
  - 代わりに、**応急処置の 1 ターンあたりの上限を 1 + 段** にする（段0: 1回・段1: 2回・段2: 3回 …）
- 応急処置の条件（ダメージの後の (HP＋破片) が最大HPの 40% 未満）・粛で止まる・連鎖しない・倒れた味方には貼らない、は変えない
- 同じ味方に同じターンに2回以上貼ってよいか: **よい**（割れた直後にもう一度拾う絵になる）。ただし1回の被弾で2回は出ない（1回の被弾につき判定は1回）

### 2.2 出撃前の板

- **開戦時**（`OnBattleStart` の段・行動順より前）に、ツギは**前列の味方全員**に板を1枚ずつ貼る
  - 前列＝その陣形で敵の単体攻撃の主目標になる列（X字なら前1・前3、パターン2なら前衛1枚。Q0-4 で特定）
  - 量は手番の板と同じ式（基本＋在庫。開戦時の在庫は 0）。板の印も付く
  - ツギ自身が前列にいれば自分にも貼る
- 会戦で次の戦に入るときも、開戦時に同じく貼る（持ち越しの作法は既存に揃える。Q0-5）
- 応急処置の回数（§2.1）は消費しない

### 2.3 板で受けても、ササの身構えは働く（Q0-3 で読みが当たった場合のみ）

- **Q0-3 で「板が先に吸うとササの身構え（切り落とし・弾いた分の破片・錯乱）が働かない」と確認できた場合だけ**、カド（第211期 Y3）と同じく、**破片で受けた一撃にも身構えを働かせる**
  - 身構えの量（一撃を 7 まで等）・弾く先・錯乱は変えない。「一撃を受けた」の判定を破片で止まった分も含める、という読み替えだけ
  - **ササだけ**を変える
- 読みが外れた場合（板と身構えが干渉していない）は §2.3 を実装せず、Y1 で第五波が悪くなった理由を Q0-3 の調査で分かった範囲で報告する
- ツギのいない行でも、ササが破片を持つ場面があれば動く。Q0-6 で影響範囲を数える

### 2.4 変えないもの

- 手番の板の相手（(HP＋破片)÷最大HP が最も低い味方・Y1）・基本の厚さ（ツギの最大HPの40%）・在庫・反射（失った破片＋残り×50%）・燃えやすさ・分かちを破片の後ろへ・カドの棘は破片で受けても鳴る（Y3）
- 身構えを「次のターンの頭まで残す」案は、ササ自身の作り直しになるので**この期はやらない**（§8）
- HP62／攻9／速8・ツギ自身は殴らない

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0-1〜Q0-3・Q0-6 を数えてから入れる。

- ツギを含まない行は Z0〜Z2 で ±0.0。Z0 は第211期 Y3 の表と一致
- Z1: 上限で貼れなかった応急処置が減る。押される波・長い戦ほど効く。腕の厚さの倍率をやめた分は、ほぼ影響しない（第210期で効きが小さかったため）
- Z2: 1ターン目に倒れる前衛が減る。ポンの編成の第三波でササが倒れる割合が下がる
- Z3（作る場合）: ポンの編成の第五波で、Y1 で悪くなった分が戻る
- 天井の行は勝率に出ないので、全員生存勝ちと決着ターンで読む（R092）

### `units.md` の文面（案・規定）

**ツギ**
- 特性: 戦の始まりに、前列の味方に板を貼っておく / 手番で、最も危ない味方（HPと破片を合わせて最も少ない者）に板を貼る（自分の最大HPの4割の破片）。回復ではないので渇きでも止まらず、回復を受け付けない味方にも届く / 味方のHPと破片の合計が4割を切ると、手番の外で駆け込んで板を貼る。板が砕かれ続けるほど腕が上がり、1ターンに駆け込める回数が増える / 板が敵に砕かれると、破片がその敵へ飛ぶ（砕けた量に、残った板の厚さの半分を足したダメージ） / 味方の破片が砕けたり誰かが倒れたりすると瓦礫を拾い、次の板を厚くする
- マイナス・フレーバーは第210期のまま

**ササ**（Z3 を作った場合）: 特性の文面に「破片で受けた一撃にも身構えは働く」を足す（言い回しは Claude Code の判断でよい）
