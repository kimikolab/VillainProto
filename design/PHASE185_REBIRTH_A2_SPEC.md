## §0. 背景（ポンの評価）

- 縛めのクグ「入れるマイナスのほうが大きい。挙動が読めない」（味方をランダムに縛って攻+16）
- 責め苦のシガ「条件付きで二倍攻撃だけなら使わない。麻痺も混乱も安定して付与できない」
- 据えのバン「バン・ドハ・セッキがごっちゃ」「動けない味方だけを守るのは限定的すぎる」

狙う形:
- **クグが敵の主力を1体押さえ、シガがそれを責めて隣を竦ませる → 4対4 を 4対2 に持ち込む**
- **クグ無しでも、シガ×ガンで回る**可能性（怖気づいたシガをガンが叩き起こし、号令の+8が積もる）
- **バンは範囲攻撃を受け止める壁**（タンク枠。ガルド＝単体、セッキ＝後列、ドハ＝分け合い、と役割を分ける）

## §1. 縛めのクグ —— 「組み付き」

### 1-1. 変えるもの

現行 `BindTrait`: 開戦時に最も速い敵1体を縛る（大縛り）／第2ターン以降は毎ターン味方1体を縛って攻+16。

**新しい動き（新特性 `TraitId.Grapple` として足し、`Bind` は対照として残す）:**

1. **手番**（攻撃しない）: 敵のうち**現在攻撃力が最も高い1体**に組み付く（同値はスロットの小さい方）
2. 組み付かれた敵は**動けない**（痺れと同じく次の手番を失う。既存の `Stun` を使うか専用キーかは Phase 0）
3. 組み付いている間、**クグも何もできない**（毎手番、組み付きを維持するだけ）
4. **クグが殴られたら組み付きがほどける**。次の手番で組み付き直す（相手は選び直す）
5. 組んだ相手が倒れたら、次の手番で次の相手へ
6. 開戦時の大縛りは**残す**（初手の組み付きより前に速い敵が動くため）。味方を縛るのはやめる

- 組み付き中のクグの手番が「差し出した手番」（ガンの号令の対象）になるかは Phase 0 で確認し、
  **ならない**ようにする（クグは働いている。号令の無償収入にしない）

### 1-2. 文案（仮）

プラス「手番で一番手強い敵に組み付き、動けなくする」
／マイナス「組み付いている間は自分も何もできない。殴られるとほどける」

## §2. 責め苦のシガ —— 「見せしめ」

### 2-1. 変えるもの

現行 `TormentTrait`: 動けない敵を殴ると同じ重さの追い打ち／動ける敵を殴ると自分が怖気づく（痺れ）。

**足すもの:**

1. **手番の標的選び**: 動けない敵がいれば**優先して狙う**（単体の主目標。前列の制約の内側で選ぶ。
   標・庇いとの順序は Phase 0 で決める）
2. **見せしめ**: 動けない敵を責めた（追い打ちが発火した）とき、**その敵に隣接する敵全員が竦む**
   ——次の手番を1回失う
3. **ハメ防止**: 竦んだ敵は、竦みが明けた次のターンは竦まない（1ターンの耐性・専用カウンタ）。
   竦みから竦みは広がらない（広げるのはシガの見せしめだけ）
4. 「動けない」の判定は現行どおり（痺れ・そのターン手番を失った敵）＋ **組み付かれた敵**。
   竦んだ敵も「動けない」に含める（シガが続けて責められる）
5. マイナス（動ける敵を殴ると怖気づく）は**現行どおり**

### 2-2. 文案（仮）

プラス「動けない敵を責めると追い打ちを重ね、その悲鳴で隣の敵を竦ませる」
／マイナス「動ける敵を殴ると怖気づき、自分が1ターン動けなくなる」

## §3. 据えのバン —— 「範囲の盾」

### 3-1. 変えるもの

現行: 据え（動かなかった味方の被ダメ半減）＋積み過ぎ（外から積まれた力が閾値を越えると薙ぎ）。
**両方を外し、対照として残す。** 新特性を足す:

1. **手番**（攻撃しない）: **踏みしめる**——据えの層を1つ積む（最大 `BraceMax = 3`）。
   **1層ごとに被ダメ −10%**（最大 −30%）。層は既存の状態アイコンの仕組みで見えるように
   （`StatusGain` の対象に入れるかは Phase 0）
2. **範囲の盾**: 薙ぎ・貫き・全体の攻撃が**バンとバンに隣接する味方に同時に当たる**とき、
   **隣接する味方の分をバンが代わりに受ける**（バン自身の据えの軽減が乗る）
3. **マイナス**: 据えた足は動かない——**入れ替えを受け付けない**（バサ・ヒサ・ハネなど、
   バンを動かす入れ替えは空振りする）。入れ替えられたら層が崩れる、ではなく**そもそも動かない**
4. バンが倒れたら層は消える

- ヒビ（範囲攻撃を受けて破片を配る）と同じ攻撃を奪い合う関係になる。直さない（配置の判断として残す）
- 範囲の盾は庇い（単体）と別の段なので、`SelectTargetChain` の庇いの鎖には入れない（Phase 0 で置き場所を決める）

### 3-2. 文案（仮）

プラス「手番で踏みしめて守りを固める。隣の味方に及ぶ範囲攻撃を代わりに受け止める」
／マイナス「自分では殴らない。据えた足は誰にも動かせない」

## 予測（実装前に宣言。**編成表の実駒を数えて書くこと**）

方向のみ:
- クグ在席行: 敵の主力が止まる分上がる。旧クグの攻+16を受けていた駒がいる行は下がりうる
- シガ在席行: クグ同席なら大きく上がる。クグ無し・ガン同席なら叩き起こしで上がる
- バン在席行: 範囲攻撃を使う敵の多い波（第三・五波の詠唱兵など）で上がる。移動軸と同席する行は下がりうる
- 3枚を含まない行は ±0.0
