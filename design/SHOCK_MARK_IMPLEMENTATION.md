# 感電・標の演出実装

2026-10-07。ユーザー指定に合わせ、ミサの羽を「空中の羽から光線を撃つ」方式へ変更した。
イベントの意味は `PHASE291_CODEX_MEMO.md` に従い、DemoAppで記録された出来事だけを描く。

## 追加したもの

| 対象 | 表示 |
|---|---|
| ミサ | 攻撃の頭で全羽が戦場の左右・奥・手前へ散開し、空中を旋回。各羽の先端から白い芯と紫の外光、細い残光を撃つ。連射中は場に残り、最後にまとめて帰還。飛行の残像、羽の反動、着弾輪、火花、カメラの寄りを追加。管制と乱射の立ち絵を切り替える |
| ミサの乱射 | 台本の実際の敵／味方へ光線を向ける。最初の乱射で周囲に火花が散り、失う羽は射撃後に散って消える。在庫減少と最後の1枚は台本の通知に従う |
| シガ | 蓄電0〜4で電光の本数・頻度を増やす。合図の敵から柄へ電気を引き込み、割り込み差分から電気鞭を伸ばす。消費で1段下がり、怖気は専用の姿勢と震え |
| カタ | 雷雲0〜8で雲が厚くなり、雲の中にも電光。雲量に応じて落雷が太く、枝雷・着弾光・地面の輪・カメラ演出が強くなる。雷雲は落雷しても残る |
| トウ | 散粉姿勢と眼状紋の発光。金色の鱗粉が主目標へ、主目標から隣へ、薄い粉が味方へ漂う。付着時に火花と小さな放電 |
| クグ | 既存の糸に青白い電流が走る。隣の味方から来た電気も描く。解除通知が先でも、残った糸を電流が走ってからほどける |
| 標 | 層ごとの照準と正確な層数。立ち絵に埋もれない描画順を設定。深い層は32個まで照準を描き、数値は省略しない |
| 爪痕 | `Scar.Slot`で最大HPを更新。開幕の最大HPを基準にバー右側へ紫の斜線を残し、回復しても埋めない |

立ち絵5点・FX2点をゲームへコピーした。原画と対応表は [素材一覧](art/shock-mark/ASSETS.md)。
左右反転、足元、カタの頭身を合わせ、雷雲が隣の駒を覆いすぎないよう描画で調整した。

同日の追加指定「羽を攻撃時に場全体へファンネルのように展開」に対応。展開は0.58秒、帰還は0.52秒を基準とし、再生速度に追従する。
場の描画上の広さから射撃位置を配置し、視点を寄せた場合は羽の位置を画面の余白へ収める。攻撃対象・発数・在庫を描画側で変更しない。
展開途中の再戦と死亡・戦闘終了でも散開した羽を持ち越さない。

全域展開版は `MisaCheck --verify` で左右・1倍／2倍、左右幅7以上・奥行き幅3以上の散開、離れた羽からの発射、最後の1枚の帰還、2プリセット各2回の実戦再生を確認。
画像は `output/misa-arena-captures/`、ログは `output/misa-arena-*.log`。描画ありの検証も完走したが、終了時にはテクスチャ解放警告が出る。

同日の追加指定「ピピピピュンと間を空けず発射」に対応。展開後の発射間隔は0.045秒を基準とし、毎発の発射後0.14秒待ちを削除した。
`MisaPresentation` が続く羽のある区間を索引化し、攻撃・ダメージ・撃破などの表示待ちも連射中だけ省略する。台本の順序・HP・在庫は保持し、別の通常攻撃へ早送りを持ち越さない。
光線本体0.34秒と残光0.62秒を重ね、最後の発射だけ0.18秒の余韻を置いて帰還する。ミサには近接連撃の位置保持・帰還待ちを適用しない。
独立した反撃・逸らしなどの専用動作が割り込む場合は、その動作の待ちは残る。

高速連射版は `MisaCheck --verify` が完走。頭なしの左右・1倍速で8発の最初から最後まで0.327〜0.329秒、2倍速で0.155〜0.173秒。
2プリセットを各2回再生し、発数・最終HP・羽の在庫が一致。実戦の通常連射区間49組は、4倍速の実測を1倍換算した平均間隔が0.062秒だった。
ログは `output/misa-burst-*.log`。既存と同様、頭なし実行の終了時にはテクスチャ・フォントのRID解放警告が残る。
描画ありでも左右・1倍／2倍を完走し、1倍で8発の最初から最後まで0.350秒。複数の光線が同時に残る画像を `output/misa-burst-captures/` に保存し、目視確認した。この描画あり実行ではエラーなし。

## 効果音

`BattleAttackAudio.ShockMark.cs` に13種の短い専用SEを追加した。
光線、羽増加、展開、乱射、照準、爪痕、蓄電、割り込み、雷雲、重い落雷、鱗粉、糸の通電、糸切れ。
コードからPCMを生成してキャッシュする。既存の鞭・雷鳴などへ重ね、光線は左右の定位を変える。
専用音の同時発音は6声。同種の短時間の重なりはまとめ、再生速度で音程は変えない。終了・画面離脱・再戦で停止する。

当初のSE制作リストに挙げた20個の外部音源ファイルを制作・導入したものではない。
羽ばたきと粉は一つの合成音にまとめている。常時の遠雷ループやキャラクターボイスは追加していない。

## 接続と状態

- `Main.ShockMark.cs` が `ShockGauge` / `MarkLayer` / `Scar` を読む。ログ本文の解析、命中対象の選び直し、ダメージ計算は行わない。
- ミサは既存の `MisaPresentation` による1発と実標的の対応を保持。通常斬撃を二重に出さない。
- 蓄電・雷雲・標の層は汎用の状態アイコンと別に保持し、状態スナップショットで上書きしない。
- 放電の一括表示は新しいイベントを境界として扱い、糸の放電も1件につき1回だけ描く。
- 非同期の発射・散粉は再戦で無効にする。死亡・勝利時は常駐の新規演出を隠す。
- HP一覧の手動幅と縦アンカーの重複を解消し、大量に出ていたレイアウト警告を修正した。

## 確認

- `dotnet build DemoApp/DemoApp.csproj --no-restore` 成功。
- `MisaCheck --verify`: 左右・1倍／2倍、2つの実戦プリセットの4倍速再生と再戦。追尾122／乱射100／標の移り14／味方への乱射51／喪失59を含む台本対応を検査。
- `ShockMarkCheck --verify`: 専用SE生成と停止、左右・1倍／2倍、5プリセットを各2回。実台本との演出件数、最終HP・最大HP・標層数・蓄電・雷雲、再戦時の初期化を照合。
- `DischargeCheck`: 放電の帰属・反転回復・戦績の表示を確認。過去の数値を固定していた検査は、帰属の固定例と現行台本／画面の照合へ修正。
- `SpecialsCheck --verify`: 毒系4種と相打ちの実台本を各2回。全演出が発生する対戦を選ぶよう修正。
- `ThunderCheck`: 落雷・放電・反転の実件数と再戦、杭の帰還・死亡・蘇生。頭なし実行で画像の描画待ちに入っていた箇所も修正。
- 描画ありの `ShockMarkCheck` で左右・1倍／2倍の28枚を保存して、光線・鞭・雷・粉・糸・照準の重なりを確認。
- `compare` と `dump` は既存の生成物と差分0、`audit` はずれているファイル0件を確認。その後、別作業によるBattleCore変更が作業ツリーに追加された。本作業からBattleCoreとdocsの生成物へ変更は加えていない。

頭なし実行の終了時にフォント・テクスチャ等のRID解放警告が残る。上記の検証アサーションは成功し、描画ありの確認ではエラーなし。
最初のGodot起動で表示された「.NET assemblies not found」は、インストール先のDLLの存在を確認し、制限外の通常実行へ切り替えて再発しなくなった。

ログと画像は `output/shock-mark-*`、`output/misa-funnel-final-*`、`output/discharge-regression-*`、`output/specials-regression-*`、`output/thunder-regression-*`。
