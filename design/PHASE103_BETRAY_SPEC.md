**ロスター 51／上限 52**）

**この期で最後の1枠が埋まり、ロスターが 52 枚で確定する。**

**この指示書は自己完結させてある。** リポジトリの外にある文書を参照しないこと。

## 0. 主題

### 0-1. 爆発の燃料が、全部劣勢側に付いている

| 燃料 | 駒 | 起きるとき |
|---|---|---|
| **味方の死** | 墓守リィカ（層 5/15/30/50/75/105）・破裂のゾト・分裂のムグ・継ぎ接ぎのヴェル | **劣勢** |
| **敵の死** | 追い打ちのハギ・抉りのエグ（ただしマイナス）・疫みのラウ | 優勢 |

**ロスターで一番大きい払い出しが、味方3枚の死と引き換えになっている。**
第99・100期の実測どおり——**噛み合っても「なんとか勝った」にしかならない**（残存 2.47・圧勝率 17.8%）。

> **爆発の燃料が味方の死である限り、爆発は必ず劣勢で起きる。**

**この期は、敵陣に餌を置いて燃料の符号を変える。**

### 0-2. 読み手は既に盤面にある

**新しい読み手を作らない。** 実装を数えた結果:

| | 駒 | 実装 |
|---|---|---|
| **直接読む** | 追い打ちのハギ | `PursuerTrait.OnAnyDeath`。`dead.TeamId == self.TeamId` を弾く＝**敵の死だけ**。倒れると割り込んで薙ぎ |
| | 疫みのラウ | `ContagionTrait.OnAnyDeath`。**餌に毒が乗っているときだけ** |
| | 抉りのエグ | `OverreachTrait.OnKill` ＝ **倒すと次の手番を失う（マイナス）**。飛んだ手番は `IdleTurn` になる |
| **間接** | 号令のガン・据えのバン | **エグが失った手番を買い取る**（`OverreachTrait` のコメントに明記） |
| | 毒喰らいのベニ | **毒に侵された敵の数**を数える。餌が1体増えれば分子が +1 |
| | 澱みのミオ | 毒の乗った敵**全員**を +4。体の数だけ線形 |
| **ついで** | 薙ぎ持ち（ボルグ・ドルガ・ハギ・リィカの薙ぎ化） | 巻き込み先が増える |

**墓守リィカは対象外。** `NecroTrait` は `dead.TeamId != self.TeamId` のとき層を積まない。**敵の死は燃料にならない。**

**第88期の規約（読み手を広げる規則と供給を作る規則は対で測る）に照らすと、
読み手側は既に盤面にあるので、ソムは単独で測れる。** 第85期の巻き込み則と同じ状況。

### 0-3. 餌は敵を守る —— これがマイナス

**標的選択は「前列が生きている限り後列は狙われない」。**
餌を敵の前列に置くと、**前列の標的候補が {前1, 前3} から {前1, 前3, 餌} になり、
本物の敵に当たる確率が 2/3 に落ちる。**

> **餌を食べる手番は、本物の敵を殴らない手番。**

**撃破の読み手がいれば資産、いなければ手番を捨てて敵を守っただけ。**
**可変コスト型。マイナスを別に足さない。**

## 1. 作るもの

### 1-1. 背かれのソム（**最後の1枠**）

| | 値 |
|---|--:|
| MaxHp | **54** |
| Attack | **7** |
| Speed | **6** |
| Pattern | 単体 |
| Traits | **`Betrayed`（背かれ）1つ** |
| Actions | **無し**（通常攻撃を振る。召喚は `OnTurnStart`） |

- **PlusText**: 「毎ターン、敵陣に喚び出す」
- **MinusText**: 「喚ばれたものは背いて敵につく。敵の前列が埋まる」
- **Flavor**: 「誰よりも召喚術に長け、誰よりも召喚獣に嫌われた。呼べば来る。ただし向こう側に立つ。」

**ソムは撃破を1つも読まない。** 自己完結させない（第96期: ムドは「読まないのに最大の受益者」だった。
**攻撃型と成長経路も確認すること**——ソムは単体・攻7・育たないので受益者の輪郭に入らないはず）。

**出力を持たせている**のは、第87期の「接続子が出力ゼロの軸は5枠盤で橋が架からない」に当たらないため。

### 1-2. 背いた獣（餌。**編成には選べない**）

| | 値 |
|---|--:|
| MaxHp | **12** |
| Attack | **0** |
| Speed | **1** |
| Traits | **`Ephemeral` ＋ `Immobile`** |

**HP 12 の根拠（測る前に固定・振らない）**:

| 当て方 | 通る量 | 12 |
|---|--:|:-:|
| ボルグの薙ぎ・巻き込み（60%） | 10 | 耐える |
| **エグ** | 12 | **落ちる** |
| **ハギの薙ぎ・主目標** | 16 | **落ちる** |
| **ボルグの薙ぎ・主目標** | 18 | **落ちる** |
| 燃えたホタ | 24 | 落ちる |

> **単体の一撃で確実に落ちる。餌に吸われた手番が、必ず撃破イベントになる。**
> **巻き込みでは落ちないので、「ついでに倒す」は成立しない**——代金は残る。

- **`Immobile`** は `SurrendersTurn => false` を持つ。**餌の手番が号令・据えの無償収入にならない**
  （カドで一度踏んだ穴）。
- **`Ephemeral`** は蘇生されず、会戦の境界を持ち越さない（胞子・亡者と同じ）。
- **倒れても何も起こさない。** 純粋な体。**爆発させない**——破裂のゾトと機構が重複するし、
  **餌が自分で払い出すと可変コスト型でなくなる**（読み手がいなくても得になる）。

### 1-3. 召喚の規則

```
BetrayedTrait.OnTurnStart:
    if (!ctx.Betray.Enabled) return;
    if (敵陣の ○前2（slot 7）が空いていない) return;
    ctx.Summon(UnitCatalog.Fodder, ctx.Opponent(self.TeamId), slot: 7);
```

- **○前2（slot 7）が空いているときだけ湧く。同時に1体。**
  **上限を数値で書かず、盤の形が天井を決める。**
- **`FormationRules.SummonSlots` を触らない。**
  現行の走査順は **中1・中3 から埋める**（「湧いた駒が減衰1段ぶんの盾として働く」と
  コメントに調整の意図が書いてある）。**餌が中列に湧くと前列が全滅するまで食べられない**ので、
  **席を直接指定する経路が要る。**
  **`Summon` に席を指定する引数を足す**か、**別の入口を作る**かは Phase 0 で決め、
  **既存の呼び出しが1つも変わらないことを示すこと。**
- **`Summon(def, teamId)` は既に陣営を引数に取る。** 新しい engine の窓口は要らないはず。**確認する。**
- **敵側には `Betrayed` を持たせない。**

### 1-4. ノブ

```csharp
public readonly record struct BetrayRule(bool Enabled)
{
    public static BetrayRule Default => new(false);      // 測定中はここ
}
```

**ソムと餌の `UnitDef` は常に存在する**（ロスターは 52 枚になる）が、
**`Enabled` が false のとき `BetrayedTrait` は何もしない。**
**その状態で `compare` 305 セルが 0 件であることを示してから測る。**

## 2. Phase 0

### 2-1. 事実の確定（**戦闘0回**）

1. **`Summon` が敵陣へ書けるか。** `_units.Where(u => u.TeamId == teamId)` で空きを見ているので、
   `teamId` に敵を渡せば敵陣の空きを走るはず。**確認して書く。**
2. **敵の召喚枠が実際に空いているか。** **敵側に召喚を持つ駒がいないこと**を全数で確認する
   （いれば湧き先を取り合う）。
3. **席を指定する経路の作り方**（§1-3）。**既存の `Summon` の呼び出し口を全部列挙**し、
   **1つも挙動が変わらないこと**を示す。
4. **`Ephemeral` / `Immobile` / `SurrendersTurn` の既存の実装**を読み、餌に付けて問題ないか。
   **`ReviverTrait` が儚い駒を明示的に弾いていること**を確認する。
5. **ロスターが 52 枚になることの影響。** 第83期の「キー0の駒 7/51」などの派生値が動く。
   **数え直さないが、動いたと書く。**
6. **`TraitKeyMap` / `TraitEntryMap` に `Betrayed` を足す。**
   **`derive scan`（第94期）の観測で照合する。手で書かない。**

### 2-2. 門（**鎖が繋がっているか。大きさではない**。規約 (G7)）

> 1. **餌が湧いた回数/戦**（波別）
> 2. **湧いた餌が倒された回数/戦**、および**倒した駒の内訳**
> 3. **餌の撃破で読み手が発火した回数**（ハギの追い打ち・ラウの拡散・エグの手番喪失）
>
> **3つとも 0 より大きいことを確認してから 2×2 を回す。**
> **どれかが 0 なら、そこが切れている場所を書いて閉じる。**

### 2-3. 紙のスループット（**門ではなく出力**。規約 (G7)）

    餌由来の出力/戦 = 餌が倒された回数 × 読み手の払い出し
    餌の代金/戦     = 本物の敵に当たらなかった手番の数 × その手番の平均打点

**分子について3つを先に書く**（規約 (G7)）——**線形か二次か／門ではなく出力／分母を削るか**。
**餌は敵の体を増やすので「分母を削る」ではなく増やす側。紙は下限のはず。外したら書く。**

### 予測（**測る前に書く。駒を数えて書くこと**）

- **意図した相手の1位はハギ。** `PursuerTrait` は敵の死だけを読み、**倒れると割り込んで薙ぎ**。
  **餌が毎ターン供給されれば毎ターン起動する。**
- **ラウは効かない**——餌に毒が乗っている必要があり、グザ／スィドが同席する行に限られる。
- **エグは符号が割れる。** 撃破で手番を失う（マイナス）が、`IdleTurn` がガン・バンに回る。
  **ガン・バンが同席する行でだけ正。**
- **単体高倍率（トメ・ナタ・ザン）は下がる。** 前列の標的が3体になり、本物に当たる確率が 2/3。
- **裂きのキリ・刻みのノミも下がる。** **傷を餌に刻むと投資が丸ごと無駄**（餌はすぐ死ぬ）。
  **傷軸はこの機構と逆を向いている**——次期の材料（§7）。
- **第二波（粛）は関係ない**（召喚は自分の手番のターン頭。ターン外の行動ではない）。**確認する。**

## 3. 判定

**第88期 §4 の特異性。第94期の規約 (G8) では新しい駒は「丙」だが、
`BetrayedTrait` は盤面の規則に近いので「乙」で測る**（`compare` 61行の拒否権 ＋ 交差帯12行 ＋
2×2 ＋ 会戦）。

### 3-1. 主判定（**分母 = 51体の組**）

器具は第81期 `pairs2` の 2×2 の写しで定数を1つも変えない。**A ＝ ソムに固定。**
**情報帯の割合を必ず併記する**（第88期 §8-5: 床の厚さは A の体で決まる。
カド 65.2% / ハリ 70.1% / ミオ 56.5% と並べる）。

> **Q1-1: 意図した相手**（**ハギ・ラウ・エグ・ボルグ・ドルガ の5枚**）**のうち、
> 2系列とも正で \|Δ\| がノイズ床を超えるものが 1 枚以上。**
> **Q1-2: 意図しない相手（残り46枚）で床を超える体数が 3 以下。**

**間接の読み手（ガン・バン・ベニ・ミオ・グザ）は意図した相手に入れない。**
**入れると 10 枚になって Q1-1 が通りやすくなり、Q1-2 の分母が減る**
（第96期に「意図した相手を広く取ると判定が緩む」を踏んでいる）。**副判定で見る。**

ノイズ床は第89期 §1-1 の規約（同じ実験の中の意図しない相手の \|Δ相乗\| の 95 パーセンタイル）。

### 3-2. 拒否権（**分母 = `compare` 61行全体**。第91期 (G1)(G2)）

1. **61行のいずれかの波で −10.0pt 以上落ちた行が「壊れ」と判定される**

   **どの駒も \|平均変化\| < 3.0pt なら組み合わせ固有＝制約。拒否しない**）
2. **主判定19行の第五波平均が `Baseline.PrimaryFifthFloor` を下回る**
3. ~~第五波が 95% を超える行が新たに2行以上生まれる~~ → **規約 (G9) により「注意」。記録するが拒否しない**

**ソムは 61行に1体もいないので、拒否権1・2は原理的に立たない。
立たないこと自体を自己検査として報告する。**

## 7. 申し送り（**第104期の入口**）

### 傷軸がこの機構と逆を向いている

**傷を餌に刻むと投資が丸ごと無駄になる**（餌はすぐ死ぬ）。
第85期の実測では**未読の傷は敵側 78%**——**積んだ投資の8割が、敵が倒れた瞬間に消えている。**

> **傷を負った敵が倒れたときに精算する形なら、両方が同時に解ける。**
> **「傷が移る」ではなく「深く傷ついた敵を仕留めた見返り」。**
> **餌に刻んでから倒す手が成立し、傷軸と撃破軸が同じ出来事で立つ。**

**ポンの方針**: 傷は **(b) 他の通貨を通す鍵として読む**。13期で唯一天井を越えたのが第87期のミオの着火。

### ムグ

**「誰に倒されたかで湧く先が変わる」**——敵に倒されたら敵陣、味方が処理したら味方陣。
`OnDamaged` は `source` を持ち、**味方がムグを叩く経路は6本以上ある**（第85期の巻き込み則）。
**放っておけば餌、意図的に処理すれば壁。** 1文がほぼ変わらない。

### その他

- **爆発が1枚の中で閉じている**（ホタ ×4・ウツ ×3・セロ ×2・カド ×2・トメ ×2・ベニ ×2 は全部1枚）。
  **1つの出来事で2枚が同時に立つ形が無い。** 撃破は数少ない「1つの出来事」
- **構想**: 複数部隊の運用／部隊サイズの可変化／作戦層。
