# 第261期 指示書 —— チェック波の作り直し（ボスの手番・癒し手の体）

読み手は Claude Code。第260期（`design/PHASE260_CHECK_WAVE.md`・棄却）の続き。器具 `checkwave`・札・台・seed 0..199 はそのまま使う。盤面・ロスター・本編の波は触らない。

## 0. 位置づけ

第260期で器が2箇所壊れていた:

1. **ボスが手番を失う**。ハネのいる台は「押し込む先がない → 打たれて転んだ」でボスの攻撃ターン 0%、雷は痺れで 40.6%。毎ターンの天井（攻+X）が一度も振られない
2. **癒し手（HP 40）が T1〜T4 に全 3,600 戦で倒れる**。席を○後2 にしても全体攻撃・敵経由の連鎖で割られ、波が立ち上がる前に消える

一方、**ボスを倒したターンは予測どおり軸の順に並んだ**（燃焼 T3〜3.5 ＜ 雷 T6 ＜ 混ぜ T9.2 ＜ 移動 T13.5）。机上計算では +4 の天井が駒を落とし始めるのは T9〜T12。つまり天井さえ振られれば、この順がそのまま勝率に出るはず。物差しの芯は当たっており、器だけ直す。

## 1. 決定（この期はこの前提で進める）

1. **ボスに「手番を失わない」札を1枚足す**（第260期 §6 の候補a）。転倒（打たれて転んだ）・痺れ・まどろみ・混乱など、手番を奪う効果を受け付けない。**毒・燃焼・感電のダメージと層は通る**（削りの軸は生かし、制御の軸だけこの波では解答にならない）。検証波なので完全無効でよい——制御で完封できる限り全軸が同じ理由で勝ち、物差しが分離しない。本編に載せるときの回避手段（取り巻きを割れば耐性が外れる等）はこの期では決めない
2. **ボスの HP は 3,000 を規定にする**（第260期の実測採用）。HP 500 の参考版は対照として残置
3. **癒し手の土台を城塞の重装兵（145/12/3・無特性）に替える**。同数値＋全体回復の特性1枚。司祭ベース（40/9/8）は対照として残置。2体化はしない（体数が変わると対照が濁る）
4. **採否の物差しから r を外す**。倍率なし第四波は6台とも 100%・分散0で r が出せない（第260期の実測）。「2本の波で符号が逆になった台の数」と「倒しT・崩れTの順位が予測と一致するか」で判定する

## 2. Phase 0

1. **手番を奪う経路の列挙**: `IdleTurn` が立つ経路（痺れ・まどろみ・`CanAct` 偽）と、転倒（打たれて転んだ）・混乱がどの経路で手番を奪うかを全部挙げ、新しい札が全経路を塞ぐことを確認する。**塞ぎ漏れが1本でもあると第260期の再演になる**
2. **札の置き場所**: 無効化は入口（状態を付けない）か出口（付くが読まれない）か。既存の無効化（`Stoic` 等）の作法に合わせる
3. **R361 の机上計算**: 改ボス（手番無効・HP 3,000）が各台で何ターン生き、生きているターンの何割で振れるか。改癒し手（145/12/3）が各台で何ターン生きるか。**どちらも見積もりを報告書に書いてから実装する**
4. ハネの「打たれて転んだ」が**ボス側の無効で止まったとき、ハネ自身の挙動**（押し込み失敗の処理）が壊れないことの確認

## 4. 測定と採否

- 6台（燃焼×2・移動・雷・毒・混ぜ）× 上の6版、seed 0..199。指標は第260期と同じ（勝率・全員生存・回復を上回ったターン割合・癒し手/ボスを割ったT・1ターン最大与ダメ・崩れ始めT）＋**ボスが実際に振れたターンの割合**（第260期の 0%/40.6% がどこまで戻るか）
- 採否: **2本の波で符号が逆になった台の数 ≧ 1**（予測は §5）、かつ倒しT・崩れTの順位が予測と一致。r は出さない（出せないため）

## 5. 予測（棚卸しの実測で書き直したもの。実装前に数値を足すこと）

- **手数チェック**: 雷（31発×11.5・軛に1本も切られない）＞ 毒 ＞ 移動（12発×31・軛に切られる）＞ 燃焼（大技が切られ、刻みはターン頭の回復に直後で消される）。第260期の予測「移動が最強」は棚卸しで棄却済み——手数の軸は雷だった
- **ボス**: 倒しT（燃焼3 ＜ 雷6 ＜ 混ぜ9 ＜ 移動13.5）に天井の崩し始め（T9〜12）を重ねると、**燃焼・雷は勝ち、移動は負けに回り、混ぜは際どい**。毒は長期戦の自滅（T6〜・自陣の毒）が先に来るので負け
- **符号が逆になる筆頭は燃焼**（手数チェック ×・ボス ○）。移動が逆向き（手数 ○・ボス ×）に出れば2軸独立の証拠として最良だが、移動の手数チェック成績は前提が崩れたので断言しない
- 毒が両方 × でも軸の性格（長期戦に代金）が出た測定として扱う。失敗ではない
