## 2. 部B —— 時間

### 2-1. 規則（作戦ターン制。リアルタイムにはしない）

マップを**作戦ターン**で進める。1作戦ターンに**全部の隊が1つずつ**行動し、終わったら敵が動く。

**マス**: 各道の拠点と1つ目の敵のあいだに**空きマスを1つ**足す。

    拠点 ― 北0（空き）― 北1 第二波・先遣 ― 北2 第三波
    拠点 ― 南0（空き）― 南1 第四波・先遣 ― 南2 第五波

**隊の行動（1作戦ターンに1つ）**

| 行動 | 中身 |
|---|---|
| 進む | 隣のマスへ1つ。敵のいるマスへ進めば**その場で戦闘**（戦闘も同じ行動の中） |
| 戻る | 拠点へ向かって1マス（**一瞬で戻れない**。北2 からは3作戦ターン） |
| 休む | **拠点でだけ**。生存者の HP を `MaxHp` の **25%** 戻す（死者は戻らない） |
| 待つ | 何もしない |
| 組み直す | **拠点にいる隊だけ**。休むと同じターンにはできない（組み直すか休むかの二択） |

- 道中の回復 50%（勝った隊が次の戦闘の前に戻す）は**そのまま残す**（第168期の本丸の条件）
- 引き返し（接敵ダイアログの「拠点へ引き返す」）は「戻る」に置き換える

**敵の前進**

- 各道で、**まだ抜かれていない先頭の敵部隊**が **K 作戦ターンごとに1マス**拠点へ近づく。後ろの敵部隊は動かない
- 前進先に味方の隊がいれば**その場で戦闘**（敵から当たってきた戦闘。中身は同じ）
- **拠点に着いたら迎撃戦**: 拠点にいる隊を**プレイヤーが1つ選んで**戦わせる（負ければ次の隊。全滅するか勝つまで）。
  **拠点に隊が1つもいなければ陥落＝負け**
- 敵部隊は削れたまま動く（`CrossBoundary` の現行どおり。敵は休まない）

**ノブ**: `K`（敵の前進の間隔）／`RestPercent`（既定 25）／`TimeOn`（切れば第169期と同じ規則）

### 2-2. 段B1 —— 器具で先に当てる（UI の前）

`Map11State` を頭なしで回す（R259: 画面と同じクラス）。**方針（自動で打つ手）を2つ**用意する:

| 方針 | 中身 |
|---|---|
| **貪欲** | 休まない。正の割り当て（カド隊→南／かき回し隊→北）で進み続け、控えは第169期と同じ自動規則 |
| **全快** | 戦う前に、生存者の HP が 100% でなければ拠点へ戻って休む。休み切ってから出る |

`K = 1 / 2 / 3 / 4` × 2方針 × seed 800。**`TimeOn = false` の1本**も回す（対照）。

**量**: 踏破率／**拠点の迎撃が起きた率**／陥落率／作戦ターン数の中央値

**線（測る前に固定）**

| # | 線 |
|---|---|
| 対照 | `TimeOn = false` が第169期と 0.0pt 一致 |
| 線1（休むに値段がある） | **全快**方針で、迎撃が起きた率 ≥ 50% |
| 線2（急げば間に合う） | **貪欲**方針で、陥落率 ≤ 10% |
| 線3（どちらも正解ではない） | 貪欲と全快の踏破率の差が **15pt 以内**、かつ**どちらも 95% 未満** |
| 本丸 | **同じ K で 線1〜3 が同時に ○** |

- 本丸が ○ になった K のうち**最も小さい値**を既定にする。どの K でも × なら、表を報告して**段B2 に進まず止まる**
- 線3 は「急ぐのが常に正解」「休むのが常に正解」をどちらも弾くための線

### 2-3. 段B2 —— 画面（本丸が ○ のときだけ）

| 項目 | 中身 |
|---|---|
| 進め方 | 各隊に行動を1つずつ選ぶ →「**作戦ターンを進める**」ボタンで全隊が動き、続けて敵が動く |
| 表示 | 画面上部に「作戦ターン N」。**各道の先頭の敵に「あと n ターンで前進」**を出す（予定が読めないと休む判断にならない） |
| 迎撃 | 敵が拠点に着いたら、拠点の隊を選ぶダイアログ（「迎撃: 第四波・先遣が拠点に来た」）。隊が無ければ陥落の結果画面 |
| マス | 空きマス（北0・南0）を道の上に描く。隊と敵の位置はマス単位 |
| 記録 | 戦闘の記録に「作戦ターン N」と「迎撃」の印を足す |
