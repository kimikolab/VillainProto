# 第273期 報告 —— レリック採用の正式化と札の増補（橋の多様化）

指示書は `design/PHASE273_RELIC_ADOPT_EXPAND_SPEC.md`。物差しの確定版は **`design/RELIC_MEASURES.md`**（この期に独立させた）。
器具は `BattleSim/Modes/Relic.Expand.cs`（`relic p0x ／ check273 ／ expand`）、新札は `BattleCore/Relics.cs`（`RelicCatalog.Added273`）。

> **レリックは転生の代替にならない**（第270期の条件・継続）。固有の勝者に ✕・△ の駒が含まれても評価は変えない——**素の個性は不変・転生判断の材料にしない。**

## 0. 採用の確定（ポンの決定の記録）

**第272期の選択肢から (C) の精密版を採った**（ポンの決定・第273期の指示書 §0）。物差し「個性の保存」を札種で分ける:

- **繋ぎ・ゴミ**: 個性の保存が必須（第272期 81 ／ 81 ○）
- **変換**: 役割が変わることが設計意図なので個性の保存を適用せず、代わりに**符号反転の成立**（台によって損得が入れ替わる＝選択として機能）を合格線とする（身を固める: 燃焼の台 −100pt ／ 毒の台 +55pt で成立済み・第270期）
- **機構の合格線**: 器・橋が駒の個性を消した件 0（第272期 0 件 ○）

**これは結果を見た後の物差しの変更である。** 理由は、変換の札は定義上「個性の保存」と矛盾する——攻撃力を 0 にする札を殴る駒に付ければ殴る役割は必ず消える——ことで、第271期の分母（ボス）と同じ「物差しと設計意図の不整合」の修正にあたる。**ポンが承認した。第272期の判定（個性の保存 ×・採用の条件を満たさず）は書き換えない。**

この精密化の下で第272期の4物差しはすべて通過しており、**レリックを機構として採用する**。身を固めるは残留。**火付けの矢は現状のまま・外れ値監視対象**（1枚で +94〜+100pt・純増の源は燃焼の脆さ・被弾の燃焼。プロトタイプ段階の方針により数値調整はバランス段階へ）。弾数制の2版（`RelicFireArrow3` ／ `5`）は対照残置。

正式化の作業: `CLAUDE.md` のレリックの規則行を「採用」に更新し物差しの文書を指すようにした・現状値ブロックを差し替えた・確定版の物差しを `design/RELIC_MEASURES.md` に置いた・期の一行を `PHASE_INDEX`、報告を `HISTORY_PHASES` の冒頭に足した。

## 1. Phase 0

### 1.1 実装点の棚卸し（決めたこと）

| 札 | 実装点 | engine に足したもの |
|---|---|---|
| 帯電の足 | `OnMoved`。自分が感電していれば、向かいの敵（自分のレーンの最前・第270期の毒の足跡と同じ読み替え）に `ctx.MarkShock`。**感電は二値**なので「感電 1」＝付ける。自分の感電は消さない | なし（`MarkShock` が保持者の門 `_shockLive` を自分で立てる） |
| 押し毒 | `OnAfterAttack`（主目標に1度）。通った主目標が毒を帯びていれば、弾き返しと同じ行き先（`SpringTrait.DestOf`）へ `ctx.SwapSlots`。**転倒は付けない**・後ろに駒がいれば入れ替わる・据わり（バン）は動かない | なし |
| 溢れの刃 | 回復の溢れ（最大HPで切られた分）を、そのターンだけ攻撃力に足す（ターンの刻印 ＋ `ModifyAttack`・同じターンは足し合わせる） | **`ctx.Heal` に1行**（`HealOutcome` は溢れを返さず、回復される側のフックも無いため）。`_overflowLive` の比較1つで抜ける |
| 勢い余り | `OnKill`。隣の味方（召喚枠・据わりを除く・**席番号の小さいほう**）と入れ替わる。踏み込みの代金（`OverrunTrait`）と同じ選び方で**乱数を引かない**（ヨミの撃破の衝撃は `PickOne` を引くので真似ない）。`ctx.Shoving` で押し出しの再入を止める | なし |
| 毒を招く | 受ける毒の層を2倍 | **`ctx.Poison` に1行**（滲みの後・書く直前）。`_poisonMagnetLive` の比較1つで抜ける |

- **回復の溢れの窓**: `HealOutcome` は溢れを出さないので engine の `Heal` の中（HP を足した直後）で札へ渡す。**全快で 0 しか増えなかった回復も溢れに数える**。支援拒否・渇き・反転の裏で止まった回復は来ない。**ベニの反転の回復（毒・燃焼の刻みが回復に変わったもの）も回復として数える**。
- **「毒を帯びた敵を殴った」の判定点**: `OnAfterAttack` の時点で毒は残っている（殴っても毒は消えない）。札は素の札の後ろなので、同じ手番で自分の札が付けた毒も「帯びている」に入る。
- **感電の付与とカタの既存規則**: 付与は `MarkShock` の1本で、既に感電している敵には何もしない（二値）。起爆は被弾の側（`ApplyDamageBody`）のままで、帯電の足は起爆の条件・行動順に触らない。**`compare` 61 行にカタは居ない。**
- **`ctx.Poison` を通らない毒の書き込み**（2倍にならない）: ミオの濃縮（+4）・リリの口移し・身代わり・会戦の持ち越し。

### 1.2 ベニの結界の毒反転（実装前に書いた）

**毒を招くは `ctx.Poison` の中で層を2倍にするので、結界の中の保持者では「反転後の回復も2倍」になる。** ヴィオ（澱み喰い）はターン頭に**自分以外の味方全員**の毒を吸って攻撃力 +4 ／ 層と腹に変えるので、ヴィオ以外の味方に付ければ吸う量が増える（ヴィオ本人に付けても腹は増えない）。
