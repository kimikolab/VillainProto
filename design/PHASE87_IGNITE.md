## 1. 何を作ったか

澱みのミオ（`AmplifierTrait`）の `Thicken` にある `if (poison <= 0) continue;` を分岐させただけ。

    毒が 0 の敵に対して:
        傷が 0 なら これまでどおり何もしない
        傷があれば 毒を 1 層置く（★ そのターンは濃くしない）

- **着火量は定数 1。傷の数に比例させない**（自己検査 (f) で 1.0000 を確認）。
- **傷は消費しない**（自己検査 (g)。着火前 1110 ／ 着火後 1110）。
- **味方には着火しない**（`Thicken` は敵だけを走査する。範囲を変えていない）。
- **`ctx.Ignite` は燃焼の着火（メソッド）で埋まっている**ので、規則の窓口は **`ctx.WoundIgnite`**。
  指示書 §2-2 の `ctx.Ignite.Enabled` はこれ（名前だけの差）。
- 診断は `blaze2` を1本足しただけで、**既存の診断（`mender` / `suture2` / `thorn` / `pairs2` /
  `breadth` / `blaze` / `ptrace`）は1文字も書き換えていない**。

足した計数は**版に依らないもの**だけ（`UnitTally.Amp*` ／ `IgnitePoisonDamage` ／ `GougeFires` / `GougeOut`）。
`compare` 61 行 × 5 波 × seed 0..199 で **Y0 と Y1 のずれ 0 件**、**`docs/balance.md` との 305 セルも 0 件**。

## 4. 副判定 (B) —— 持続係数は 18 倍になった。それでも勝率は動かない

| 機構 | 発火/戦 | 即時出力/戦 | 累積出力/戦 | **持続係数** |
|---|--:|--:|--:|--:|
| 抉り（エグ・第30期〜） | 1.64 | 5.9 | 5.9 | **1.00** |
| 縫い（ハリ・第85期） | 1.89 | 4.7 | 4.7 | **1.00** |
| 継ぎ当て（ノノ・第86期） | 2.63 | 26.8 | 26.8 | **1.00** |
| **傷口の着火（この期）** | 1.08（着火） | 1.1 | **19.4** | **17.97** |

**3機構が 1.00 になるのは構造から従う**——どれも発火の呼び出しの中で `ApplyDamage` / `ctx.Heal` が1回走って
盤面に残るものが無いので、累積出力と即時出力が**同じ1つの台帳**になる。
**この構造が第84〜86期の天井の正体だ、というのが指示書 §0-3 の主張**だった。

**その主張は否定された。** 持続係数を 18 倍にしても、勝率は +1.0pt しか動かない。

    出力の増分   実測の毒ダメ 19.4/戦 ÷ Y0 の総与ダメ 233.5/戦 = **+8.3%**
    勝率の増分   y11 が 14.4% → 15.4% = **+1.0pt**

**この期がぶつかったのは「出力 → 勝率」の変換率**で、第24期（`yield`）の
「天井・床のセルでは誰に注入しても 0 に潰れる」と同じ壁である。
ドラフト台の 128 台のうち **y00 が 0% の台が厚い**ので、出力を1割増やしても床から出ない。

> **持続係数は「その機構が何回ぶんの出力を生むか」しか測っていない。
> 「その出力が勝率に変わるか」は測っていない。**
> **新設した器具は保守する——ただし単独では採否を決められない。**

**持続係数は波の長さの関数でもある**（第2波 17.52 / 第3波 7.57 / **第4波 30.85** / 第5波 2.84）。
累積は生存ターン L に対して **2L² − L** で伸びるので、**決着が長い台ほど大きく出る。**
**次に使うときは決着ターン数を必ず併記すること。**

### (b) の読み方

計数は `if (!ctx.WoundIgnite.Enabled) continue;` の**手前**にあるので、**同じ盤面なら Y0 と Y1 で必ず
同じ数だけ通る**（コードの形から従う。(a') と (c) がその実証）。残差 1.01% は**盤面が版で分岐したぶん**
——Y1 では毒が敵を削るので決着ターン数も生き残る敵の数も変わる。
**「版に依らない計数」は経路の性質であって、観測される値の性質ではない。**

**延べ回数は版で必ず変わる**（Y0 1.95 → Y1 1.08 回/戦）——着火した敵は次のターンから毒を持つので
候補から外れる。**実体数のほうを見ること。**

### (h) が落ちた理由 —— **紙が下限で、外れ方も予測した向きだった**

Phase 0 に「着火の時刻はターン頭のスナップショットで見ているので、**同じターンの途中で傷が付いた敵は
1ターン遅れて数えている**（紙は下振れ側）」と書いた。**その 1 ターンが 2 倍になる。**

    累積 = Σ_{k=0}^{L-1} (1 + 4k) = 2L² − L        ← L に対して**二次**
    L = 2.26 → 7.96 ／ L = 3.26 → 17.99           ← 1 ターンで **2.26 倍**

実測 / 紙 = 1.66 は、**L がおよそ 0.7 ターン長い**ことと整合する。

> **紙の分子が二次の量なら、1ターンの丸めが 2 倍の誤差になる。**
> **紙のスループットを線で挟むときは、丸めの誤差が分子の何乗に効くかを先に見ること**
> ——第85期は線形（回復 = 回数 × 単価）だったので下限にぴたり乗った。
> **この期の停止条件1（5.0%・線ちょうど）は、正しく直すと 8.3% だった。通したのは正しい。**

## 7. この期で分かったこと

**1. 払い出しの持続係数は天井の原因ではなかった。** 1.00 → 17.97 にしても勝率は +1.0pt。
第84〜86期の4例（棘 +0.04 / ハリ +1.10 / ノノ 紙で停止）に、**払い出しの形を変えた 5 例目が +0.98 で並んだ。**
**5例が同じ場所で止まっている以上、疑うべきは払い出しでも読み手でも供給でもない。**

**2. 律速は「出力 → 勝率」の変換率。** 出力 +8.3% で 勝率 +1.0pt。
第24期の `yield`（天井・床のセルでは誰に注入しても 0 に潰れる）が、機構の採否の側で出た。
**ドラフト台の 2×2 は y00 が 0% の台が厚いので、出力を1割増やしても床から出ない。**

**3. 供給も読み手も詰まっていない。** 着火は **着火できる敵の 100%** に届いている
（表E の 8 行すべてで「着火/戦」＝「着火できる敵の実体数/戦」）。
稼働率は **45.0%**（ハリ 2.15 の 1.18 倍・ノノ 2.10 の 1.21 倍）で、**第86期の 35〜40% を初めて上回った。**
**それでも足りない。**

**4. 「積み上げ系には上限が天井として効く」（第25期）は、積み上がる前に決着する台では成り立たない。**
軛（第四波・上限 25）は毒の刻みを1点も切らなかった——層が 25 に届くのは着火から 7 ターン目で、
着火後の生存は 2.26T しかない。**上限の効き方は上限の値ではなく、上限に届くまでの時間で決まる。**

**5. 執着は「向き」を作る。** キリ（毎ターン的を変える）1.45 体/戦 対 ノミ（1体に食いつく）0.68 体/戦。
初出Tも 1.01 対 1.96。**Δ相乗も キリ +0.98 > ノミ +0.32 で予測どおり。差は 0.66pt。**

**6. 毒軸と傷軸は別の入口として並ぶ。** グザ（瘴気）同席の `compare` 4 行は着火が **0 回**——
毎ターン敵全体に毒を撒くので「傷を持ち毒を持たない敵」が存在しない。**欠陥ではなく設計どおり。**
その結果 **`compare` 61 行は1セルも動かない**（ミオを含む 4 行が全部グザ同席で、交わりは 0 行）。

**7. 下流の読み手（ベニ・ラウ）は実在した。台が床にあるので勝率に出ない。**
ベニの回復 2.8 → 18.5（6.6 倍）・ラウの拡散 0.00 → 0.76 回/戦。**測れる台を先に作る必要がある。**
