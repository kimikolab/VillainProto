## 1. 目的

第208期で継ぎ当てのツギ（`Id = "tsugi"`）に反射（板が敵に砕かれると、砕けた破片がその敵へ飛ぶ）を入れた。

- **全員生存勝ちで、リリの席に置いたツギが第二・三・四波でリリを上回った**（第四波 67.8 対 61.9）
- ドハは倒れなくなり（第四波 200 → 14 / 0 / 0・R313）、燃えやすさ（燃焼ダメージ倍）は代金として働いた

足りないのは**反射の大きさ**:

- 板は 30 前後あるのに、**1本の反射は平均 6〜7**。返るのは「1回の被弾で板が吸った分」だけで、**残った板の厚さは反射に効いていない**
- そのため `反撃改` の膠着は 378 → 260 / 800 までしか減らず、**第五波は勝率 88 対 100** でリリに負けたまま
- 「範囲攻撃の敵が板の破片で消し飛ぶ」は、1回の攻撃で3本以上返るのが1割、その1割前後で攻撃の主が倒れる——見られるが稀

### 1.1 ポンの式

**反射 ＝ 消費した破片 ＋ 残りの破片 × 反射倍率**

| 倍率 | 意味 |
|--:|---|
| 0 | 砕けた量だけ返す（第208期） |
| 1 | 板の厚さをそのまま返す（破片 10 に 3 の攻撃 → 10 を返し、破片は 7） |
| その間 | 積むほど強いが、代金も残る |

- 板が一撃で割れきったとき（攻撃 ≥ 破片）は残りが 0 なので、倍率に関係なく砕けた量だけ返る。**薄い板では差が出ず、厚い板ほど倍率が効く**
- ポンの狙い: **積み上げで加速する**（リリの段・ベニの紅蓮と同じ「最初は弱いが積んで強くなる」）。背中の在庫で板が厚くなるほど、反射も強くなる

## 2. 変更

### 2.1 反射の量（本体）

- 第208期の反射（板の印を持つ味方が、敵を出どころとするダメージで破片を失ったとき、その敵に返す）の**量だけ**を変える:
  **返す量 ＝ 失った破片 ＋ floor(そのダメージを受けた後に残った破片 × `ReboundRatio`)**
- 「残った破片」は、その味方の破片の残り全部（ツギの板か、ヒビ・ササ等の破片かを問わない。第208期と同じく、板の印がある間は出どころを問わない）
- 反射は攻撃ではない・通常の入口を通る（軛の上限 25 などは効く。Q0-6 第208期）・殴った敵が既に倒れていれば返らない、は第208期のまま
- `ReboundRatio` は `const`。版で 0 / 0.25 / 0.5 / 1 を並べる（§2.3）

### 2.2 変えないもの

- 板の厚さ（最も強い敵の一撃ぶん・最低6＋在庫）・貼る相手・在庫の拾い方（砕けた破片の50%・倒れた駒1体につき5）
- 燃えやすさ（板の印を持つ味方の燃焼ダメージ倍・第208期 U2）
- 分かちを殴られた味方の破片の後ろへ（第208期 U3・R313）
- HP62／攻9／速8・ツギ自身は殴らない

### 2.3 版（**並べる・採用は決めない**）

## 4. 診断

主な指標は**「全員生存勝ち」と「勝率」の両方**。ツギは全員生存勝ちでリリを上回り始めたので、今期は**勝率（特に第五波）で追いつけるか**を見る。

1. `compare` のツギ在席行（3行）。版は §2.3 の4つ。第2〜5波
2. **差し替え診断**（第208期の `swap2` と同じ・リリの在席8行でリリの席にツギ）: R0〜R3 とリリ（第206期の規定）を並べる。行ごと × 波ごとに:
   - 勝率・**全員生存勝ち**・倒れた味方の平均数・決着ターン・膠着（30ターン上限）
   - **ツギがリリを上回るセルの数**（勝率・全員生存勝ちそれぞれ。第208期は勝率 1 / 32）
   - **第五波の勝率**（第208期 88 対 100）
   - `反撃改` の膠着（第208期 260 / 800）
3. **反射の帳簿**（版ごと・波ごと・1戦あたり）:
   - 反射の回数・1本あたりの量（うち「失った破片」の分と「残りの厚さ」の分）・1戦の合計・反射で倒した敵の数
   - 軛で頭打ちになった反射の割合（第四波）
   - **1回の攻撃で返った本数の分布**（1・2・3・4以上）と、**その攻撃の主が倒れた割合**（「消し飛ぶ」の頻度）
   - **複数の味方に当たった攻撃で、当たった味方のうち板を持っていた割合**（Q0-2 と同じ数え方）。これが低ければ、消し飛ぶ場面が少ない原因は反射の小ささではなく**板が行き渡っていないこと**
4. 強すぎの確認: R3 で、ツギ在席行・差し替え行のうち第2〜5波すべて 100% に張り付く行の数と、情報セルの増減

## 5. 予測（実装前に宣言してコミット）

方向だけ。数は Q0-1〜Q0-3 を数えてから入れる。

- ツギを含まない行は ±0.0。R0 は第208期 U3 の表と一致
- 倍率を上げるほど、1本あたりの反射と1戦の合計が増え、決着ターンが縮み、`反撃改` の膠着が減る
- 第四波は軛で1本 25 に頭打ちになり、倍率の効きが他の波より小さい
- 差し替え診断の第五波の勝率は、倍率を上げるほどリリとの差が縮む
- 「消し飛ぶ」（3本以上返った攻撃の主が倒れる割合）は倍率とともに上がるが、**3本以上返る攻撃の割合そのものは倍率で変わらない**（板の行き渡りで決まる）
- 天井の行は勝率に出ないので、全員生存勝ちと決着ターンで読む（R092）

## 6. 受け入れ

1. R0 で第208期 U3 の表と一致。ツギを含まない行が 0 セル差分
2. 新しい処理が同値割り以外で乱数を引かない
3. 自己検査: 板が割れきった反射は倍率に関係なく失った量と等しい／1本の反射は「失った量＋残り×倍率」を超えない／板の印の無い味方は返さない（第208期の自己検査も回し直す）
4. `docs/` を再生成して `audit` ずれ 0 件。`units.md` のツギの行は下の文面（R2）

6. 台本: 反射の出来事（`Plank` の `Reflect`）に、**返した量のうち「失った破片」の分と「残りの厚さ」の分**が読める形で載っていること（Codex が破片の量で絵を描き分けるため）

### `units.md` の文面（案・R2）

- 名前: 継ぎ当てのツギ
- 特性: 手番で、破片が最も薄い味方に板を貼る（最も強い敵の一撃ぶんの破片・最低6）。回復ではないので渇きでも止まらず、回復を受け付けない味方にも届く / 板が敵に砕かれると、破片がその敵へ飛ぶ（砕けた量に、残った板の厚さの半分を足したダメージ）。板が厚いほど強く撃ち返す / 味方の破片が砕けたり、誰かが倒れたりすると、瓦礫を拾って背中に積み、次の板を厚くする
- マイナス: 板は燃えやすい。板を貼られた味方は、燃焼で倍の傷を負う。自分では攻撃しない
- フレーバー: 「治せない。だから、これ以上壊れないように塞いだ。」
