## 4. 読み（§5 の順）

1. **特異性 ○**: 台3 の全セル（勝率 ／ 倒しT）が規定と同じ。ウツに萎縮を乗せる口はクビの漏れだけで、隣にいないウツには届かない（第5波で敵に引きずり出されたときの 0.1 回 ／ 戦は、勝敗にも T にも出ない）。
2. **精鋭（台1 ／ 2 ／ 4 の近衛 ／ 大隊 6 セル）**:
   - U-d1: +6.0 ／ +2.0 ／ 0 ／ 0 ／ 0 ／ 0 — +5 以上 1 セル・**通らない**。
   - U-d2: +6.0 ／ **+52.0** ／ 0 ／ 0 ／ +1.0 ／ +5.0 — +5 以上 3 セル・−10 は 0・**通る**。
   - U-d3: +6.0 ／ **+99.0** ／ 0 ／ 0 ／ 0 ／ 0 — +5 以上 2 セル・−10 は 0・**通る**（ただし台1 だけ）。
   - 台2 はどの版でも精鋭 0 のまま（ネルがいない＝ウツは 1 発 9 の駒で、倍でも 18。全員 T4〜8 に倒れる）。
3. **強すぎの見張り**: ボスの 1T 決着はどの版にも無い。倒しT が規定の半分以下になったのは **U-d3 の台1 近衛（17.7 → 8.0T）だけ**。U-d2 は 17.7 → 10.0T（56%）で線の上。
4. **ボス**: 1,200 を超える手番はどの版・台にも無い（最大 450 ＝ 台4 U-d2）。**勝ち筋 (1) には届かない**。台3 ／ 4 のボス 100 は規定のまま（勝ち筋 (2) の最大 HP の削り）で、版は倒しT を 8.0 → 6.9〜7.0T に縮めるだけ。
5. **考えることが増えるか**:
   - **U-d1**: 倍になるのは 1 発目だけで、手数の多いウツほど薄まる。クビの隣に置く理由は「半分の代金が消えて少し得」止まりで、新しい読みはほぼ無い。
   - **U-d2**: 萎縮が「次の一撃」ではなく「次の一振り」の資源になるので、**ネルの呪い（手数）とクビの萎縮（倍）が掛け算で噛み合う**——クビの隣にウツを置く理由が立ち、ネルとの同席も同時に要る（台1 大隊 +52・台2（ネルなし）は 0）。ワタ ／ ムドをクビの隣から外す読み（台4）も素直に出る。速さ ウツ 6 ／ クビ 4 なので萎縮は必ず次の手番まで残り、「手番まで残す」読みは要らない（遊び手は迷わない代わりに、読みもそこには無い）。
   - **U-d3**: 萎縮がウツ自身への呪いの書き手に変わる。ネルがいなくても伸び（台2 第4波 0 → 100・ボスの最大 4 → 128）、台1 大隊 +99 と一番強い。代わりに「萎縮した一撃」という手触りは消え、クビが「隣のウツに 1 ターン 3 ずつ呪いを積む駒」になる——読みは「クビの隣にウツ」の 1 つに縮み、ネル ／ ワタとの絡みは要らなくなる。倒しT の見張りに 1 セル掛かった。

**推すのは U-d2**（線 1 ／ 2 を通り、見張りに掛からず、台4 で動くのは U-d2 だけ）。U-d3 は比べるための版として強さの上限を見せた（台1 大隊 +99・台2 第4波 +100）。
