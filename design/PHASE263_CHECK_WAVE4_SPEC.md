# 第263期 指示書 —— チェック波の物差しを連続量に替える・勝率用の桁合わせ版

読み手は Claude Code。第260〜262期（3期連続棄却）の続き。器具 `checkwave`・台6つ・seed 0..199・動じない・全体攻撃・400/300 土台はそのまま使う。盤面・ロスター・本編の波は触らない。

## 0. 位置づけ —— 3期の総括

器は3つとも直った（手番＝動じない／誰に入るか＝全体攻撃／土台＝400/300）。残ったのは物差しの選び間違いで:

- **勝率（二値）は3期で一度も軸を割らなかった**。この6台は 400/300 の第四波でも天井に張り付く
- **倒しT（連続量）は3期連続で軸を割り、版の変更に反応した**（燃焼3 ＜ 雷6 ＜ 混ぜ ≈ 移動。移動は 13.5 → 10.5 → 8.0 と版ごとに動いた）
- ボスの入りは隊の回復とほぼ相殺（移動: 入262・回復210・差引52）。隊HP 268〜442 に勝率で届かせるには桁の引き上げが要る

`compare` が天井に張り付いたからチェック波を作ったのに、チェック波の中で同じ「飽和した二値の物差し」を使っていた。物差しを替える。

## 1. 決定（この期はこの前提で進める）

1. **主の物差しを連続量にする**。チェック波は「勝率で割る波」ではなく「連続量で軸を測る検証器具」（的の波・九体の波の系譜）として完成させる。正式な指標:
   - ボス側: **倒しT**（倒せない台は打ち切りTと総与ダメ）
   - 手数側: **回復を上回ったターンの割合**・窓あたり出力・癒し手を割ったT
   - 共通: 差し引きの純実入り（R361 完成形の計数）
2. **勝率用の「桁合わせ版」を各1つだけ作る**（本編ボス設計の下敷き用）。ただし**数値は逆算で決める**: 第262期の実測（隊HP・隊の回復総量・実入り率 18〜52%）から「T10 前後で隊が尽きる毎ターン純入り」を先に計算し、そこから攻・天井の傾き・回復割合を導く。天井は札の定数なので倍率に乗らない——**傾き自体を逆算値にする**
3. 第260〜262期の既測データは再集計で使う（連続量の指標は取得済みの計数から出せるはず。再測が要るのは桁合わせ版だけ）

## 2. Phase 0

1. **逆算（この期の中核・実装前に報告書へ書く）**:
   - ボス: 台ごとの隊HP総量＋1戦の回復総量を分子に、目標の崩壊T（倒しT最速の燃焼 T3 では崩れず、最遅の移動 T8 では際どくなる帯）を分母に、必要な毎ターン純入りを出す。実入り率 18〜52% で割り戻して名目の攻と天井の傾きを決める
   - 癒し手: 回復を割合にした場合（候補 20%＝580/ターン・6台の窓あたり出力 640〜1,440 と同桁）に、各台が回復を上回れるターン率の見積もり
2. **毒台の切り分け**: 毒は 400/300 の素の土台だけで 0%。土台負けとチェック負けが混ざるので、どこで落ちているか（自陣の毒か・敵前衛を抜けないのか）を1段落で切り分ける。毒台が軸の代表として不適なら、差し替え候補（`Presets` の毒+ベニ+ラウ 等）を挙げるだけにして、この期では替えない
3. **連続量の再集計**: 第262期の計数から、6台 × 全版の連続量指標（§1-1）の順位表を作る。足りない計数があれば挙げる

## 3. 版（新規に測るのはこの2つだけ）

| 版 | 内容 |
|---|---|
| B3-桁 | 全体攻撃・動じない・HP 3,000・全快。**攻と天井の傾きは Phase 0 の逆算値**（候補の目安: 攻 36・傾き +12。逆算が別の値を出したらそちらを採る） |
| W3-割合 | 400/300 土台・癒し手（倍率あり・席 後3）。**回復は最大HPの割合**（候補 20%。逆算で確定） |

ノブを同時に2つ以上動かさない——B3-桁 で動くのは攻と傾きだけ、W3-割合 で動くのは回復の式だけ。

## 4. 採否

- **主（連続量）**: 2本の波で**連続量の順位が逆転する軸の組が ≧ 1**（予測は燃焼：ボスで最速・手数で最下位。雷がその逆側）。3期の既測データの再集計で判定できたら、それ自体が採用の根拠になる
- **従（桁合わせ版）**: 勝率が **5〜95% に入る台 ≧ 3**（0/100 への張り付きが解けたこと）。かつ勝率の順位が連続量の順位と矛盾しないこと
- どちらも満たせば、チェック波を検証器具として**採用**し、本編への載せ方は次の論点に送る

## 5. 予測（Phase 0 の逆算値で数値を足してから実装）

- 連続量の順位逆転: **燃焼**（ボス最速 T3 ／ 手数側は大技が軛に切られ回復超過率が最低）と**雷**（手数側で回復超過率が最高 ／ ボスは中位 T6）の組で出る
- B3-桁: 燃焼・雷は崩壊Tより先に倒して勝ち、移動は全体攻撃の被弾反応で倒しTが縮む（8.0 からさらに）ものの崩壊Tとの競争で 5〜95% の帯に入る。毒は負け
- W3-割合: 回復 580/ターン は雷の出力でも上回れないターンが出始め、初めて勝率が割れる。癒し手を割れるか（T2.7〜4.8 の生存）が解答の中心に戻る
