## 実装（予測のコミット 9c7b1f0 の後）

- **散らし**: `SpewTrait.PickTarget`——痺れ毒の印がまだ無い敵のうち現在攻撃力が最大（同値は席番号の小さい方）、全員に印があれば `GrappleTrait.Pick`。ノブは `const SpewTrait.SpewSpreads = true`。**乱数を引かない**
- 対照の札2枚（**どちらも `UnitCatalog.All` に保持者 0 枚**）: `SpewFixed`（散らさない吐き＝第195期）と `VenomHeavy`（殴られたときの毒 +8・`const VenomTrait.HeavyStackPerHit = 8`）。`Venom` の本体を `VenomTrait.Hit` に切り出して2枚で共有した（中身は第195期のまま）
- S+HP は `const UnitCatalog.SidHardyHp = 100` を診断の写しの `MaxHp` に入れる。**規定の版（`UnitCatalog.Sid`）は S（HP 84）**
- 計数を1本足した: `UnitTally.SpewOnMarked`（既に印のある敵に吐いた回数）
- `units.md` のスィドの文面を指示書 §6 のとおりに（「まだ毒を浴びていない一番手強い敵に」）
- `checkup` の分類表・`TraitKeyMap` / `TraitHookMap` に2枚ずつ足した。`Run` の引数は増やしていない
- **診断で1度踏んだ**: 版の配列（`Versions196`）を `Sid.R196.cs` の静的フィールドにしたら、別のファイル（`Sid.Run.cs`）の `SidNew` / `SidPlainG` がまだ null のまま詰まり、**ガルドの席が空席になって S と素体が同じ値（0.0 / 7.8）を出した**。partial クラスの静的フィールドの初期化順はファイルをまたいで決まらない。プロパティにして直した（R277 の再発）
