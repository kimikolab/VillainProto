## 0. 方針の変更（この作業の前提）

**ポン氏の判断（2026-08-26）: 基本（メイン）は単発戦。会戦もありえる、というくらいの位置づけ。**

これは第5期以降の枠組みの位置づけを変える。

**代金（払った HP の割合）は、会戦でしか意味を持たない。** 単発戦では HP が毎回リセットされるので、90% 削られて勝つのと 20% で勝つのは同じ価値。**代金という概念そのものが成立しない。**

| 期 | 内容 | 単発が主なら |
|---|---|---|
| 第1〜4期 | 会戦の機構（`EngagementEngine` ほか） | オプションモードの土台として残る |
| 第5〜8期 | 代金の向き（範囲/単体） | **会戦専用** |
| 第9期 | 自傷率と代金 | **会戦専用** |
| 第10〜11期 | 行動パターン・チャージ | **単発でも効く**（勝敗に直接効く） |
| 第12〜14期 | 突破度に対する地力の分解 | **会戦専用の目的変数**に対する分解だった |

**捨てない。** 会戦を実装する以上どれも要る。ただし**主の物差しではなかった**——第14期で分かったとおり、単発戦の勝率と突破度の相関は 主 0.15 / 従 0.33 しかない。

### 単発が主なら、狙うものが変わる

出発点は「波が易しすぎる」だった。会戦はその答えの一つとして始まったが、単発が主なら別の答えが要る。

`docs/balance.md` の天井率（勝率 100.0% の編成数）:

| 波 | 天井 |
|---|---|
| 第1波 | **31/31** |
| 第2波 | 13/31 |
| 第3波 | 14/31 |
| 第4波 | 13/31 |
| 第5波 | 2/31 |

**第1波は評価に一切寄与していない。** 第2〜4波も4割が天井。差が付くのは実質 第5波だけ。

単発戦で目指すものは、配分判断ではなく:

> **波によって最適な編成が違うこと（編成 × 波の交互作用）**

「この波にはこの編成」が成立すれば、それだけで編成パズルが成立する。第6〜8期でずっと探していた「向き」は、**突破度ではなく波ごとの勝率に対して測るべきだった。**

## 2. Phase FA — 編成 × 波の交互作用

### 2-1. 測る対象

**既存5波 + 第5〜7期で作った候補波を全部。** 候補は診断のローカルに散っている（`gradient` / `aim` / `flip`）ので、**1箇所に集めて名前を付ける**。

| 出どころ | 候補 |
|---|---|
| 第5期 `gradient` | 農兵5 / 農兵6 / 農兵5+斧 / 新兵3+斧 / 騎士混成 / 騎士2+狙撃 / 精鋭3 / 精鋭+司祭長 / 精鋭2 |
| 第6期 `aim` | H2a 裸5 / H2b 革5 / H2c 鎖5 / H2d 革4 / H1a〜c 人足 / M1 傭兵5 |
| 第7期 `flip` | R5 重甲3 / R7（処刑なし対照）/ R8 重甲5 / R11 従卒6 / 攻7・攻5・攻4 の各版 / 板金従卒6 |

**代金ではなく勝率で測り直す。** 第5〜7期はすべて「代金」で評価していたので、**勝敗の観点では一度も見ていない。**

### 2-2. 出すもの

編成（31）× 波（既存5 + 候補全部）の**勝率表**。加えて波ごとに:

1. **天井率** — 勝率 100.0% の編成数。**天井に張り付いた波は評価に寄与しない**
2. **床率** — 勝率 0.0% の編成数。**全滅する波も同じく寄与しない**
3. **勝率の標準偏差** — 編成をどれだけ区別できるか
4. **残存**（勝った試行の平均生存数）— 勝率が飽和した波でも差を見られる補助指標。`chain` に既にある

### 2-3. 交互作用（本題）

**波をまたいだ編成の順位相関の行列。**

- 全波ペアでスピアマン相関を取る
- **第13期の半割 0.985〜0.995（補正後 0.99）が信頼性の上限**なので、有意に下回るかを判定できる
- **相関が低いペア（順位が入れ替わるペア）を上位から並べる**。これが「性格の違う波」の組み合わせ

**天井・床の扱いに注意**: 勝率 100% が並ぶと順位が同値塊になり、相関が意味を持たなくなる（第8期の突破度で同じ問題が起きた）。**天井率が高い波は相関の計算から外すか、残存を併用する。どちらにしたか明記する。**

### 2-4. 判定

| 観測 | 結論 |
|---|---|
| 順位が入れ替わる波のペアが複数ある | **編成 × 波の交互作用が実在する。** 単発戦のステージ設計の骨格になる |
| どの波でも順位がほぼ同じ（相関 0.9 以上） | **波を何種類作っても編成パズルにならない。** 波の側では差が作れないので、編成側（特性・スキル）で作るしかない |
| 入れ替わるが、天井・床を外すとペアがほとんど残らない | 実質的に「勝てる波」と「勝てない波」しか無い。**難度の一次元**に潰れている |

**2行目・3行目が出た場合が重い。** 波の設計では編成パズルが作れないことになるので、次の方向が変わる。

### 2-5. 受け入れ条件

- 18モードすべての差分 **ゼロ**（新しい診断の追加のみ）
- 候補波の定義（HP / 攻撃 / 速度 / パターン / 配置）が1箇所で読めること
- 天井・床の扱いを明記

## 3. Phase FB — 地力の分解（単発版）

### 3-1. やること

**第14期 Phase EA と同じ手順・同じ候補集合で、目的変数だけを差し替える。**

- 目的変数: **突破度 → 単発の勝率**（波ごと。および全波平均）
- 特徴量: 第14期の13候補（同語反復を除外したもの）をそのまま

**同語反復の判定をやり直すこと。** 目的変数が変わると、何が言い換えかも変わる。

- 突破度に対しては `撃破/戦` が同語反復だった（部隊の全滅＝突破）
- **単発の勝率に対しても同じか**。1戦での撃破数は「敵を全滅させたか」と直結するので、**やはり同語反復の可能性が高い**。判定して理由を書く
- 逆に、突破度では言い換えだった量が単発では言い換えでなくなるものがあるか

### 3-2. 見どころ

第14期は突破度に対して r² 0.308 / 0.242 で、「地力は既存の特徴量では表せない」だった。

**単発の勝率に対しては、総攻や総HPがずっとよく効く可能性がある。** 効くなら「編成した時点で単発の勝敗はかなり決まっている」ことになり、**静的説明力 0.35 / 0.16 が突破度に対する値でしかなかった**ことが分かる。

- **静的だけの説明力**を波ごとに出す。**天井の波（第1波）は全編成 100% なので分散ゼロ**——計算できないはず。その旨を出す
- 波によって効く特徴量が違うか。**違えば、それがそのまま交互作用の説明になる**（Phase FA と突き合わせる）

### 3-3. 受け入れ条件

- 18モード差分ゼロ
- 同語反復の再判定と理由
- 波ごとの第一近似と、それが波で入れ替わるか
