## 1. 目的

ポンが演出の確認をかねて、敵の倍率 **HP400%／攻300%** で移動軸を遊んで気づいたこと:

1. **緊急退避の線（4割）が一撃の重い波で間に合わない**。満タンから一撃で 45% くらいまで削られると、4割の線を踏まずに次の一撃で倒れる（第226期のセロの一撃死 R332 と同じ形）。「5割を切ったら」なら生き残れそう
2. **ハネの弾き返しがあまり起きない**。バサの嵐・追い風で隊列が混ざり、ハネが前衛にいる時間が短いので、殴られない
3. **セロ**:
   - **挑発が画面から分からない**（挑発は状態ではなく「狙える列にいる間」の規則なので、標のような印が出ない）
   - 敵が転倒・混乱していることが多く、殴られないので**回避と貫きの撃ち返しが少ない**。守りが成功するほどセロの見せ場が消える
   - 手番の乱れ撃ち（段2）は絵として良く強いので**残す**（ポンの判断）。代わりに「段が上がると、回避だけでなく**移動でも**貫きの追撃を撃つ」（ポンの案）

## 2. 緊急退避の線

| 版 | 条件 |
|---|---|
| 今（第225期 J4） | 被弾の後、HP が最大HPの **4割未満** |
| **A1** | 被弾の後、HP が **5割未満** |
| **A2** | 被弾の後、HP が **4割未満**、**または**その一撃で**最大HPの3割以上**削られた（HP が残っていれば） |

- 回数の上限（段で 1〜4 回/ターン）・後ろ側に相手がいなければ起きない・粛で止まる、は今のまま
- A2 は一撃の重い波にだけ反応し、普段の隊列を崩しすぎない狙い

## 3. ハネの弾き返しを隣の味方まで

| | 今（第228期） | 新（B） |
|---|---|---|
| 引き金 | **ハネ**が敵の攻撃で HP を削られたとき | ハネ、**またはハネの隣の味方**が敵の攻撃で HP を削られたとき |
| 効果 | 殴った敵を経路で1つ後ろへ弾いて転ばせる（前へ出た敵はバサがいれば混乱） | 同じ |
| ハネの動き | ハネが隣の味方1体と入れ替わる | ハネ自身が殴られたとき: 今と同じ。**隣の味方が殴られたとき: ハネがその味方と入れ替わる**（弾いた反動で前へ出て、殴られた味方を後ろへかばう形） |
| 回数 | 1ターンに 1 ＋ 敵の乱れの段 | 同じ（ハネ自身と隣の分で共有） |

- 殴った敵が経路に属さない席（○前2・○後2）にいれば弾かない（今と同じ）
- 入れ替わりは「隊列を動かされた」扱い（移り木・段ほかが反応）

## 4. セロ

### 4.1 挑発を画面に出す（表示専用・盤面は変えない）

- 挑発が効いているか（セロが敵の単体攻撃の的になれる列にいて、挑発の札を持っているか）を、**表示用の状態**として出す
  - 形は Claude Code に任せる（`StatusSnapshot` に表示専用のキーを足す／切り替わった瞬間の出来事を出す、など）
  - **盤面の規則はこの状態を読まない**（表示のためだけ）
- Codex がセロに挑発の印（手招き・視線を集める輪など）を付けられるようにする。標（ヒサ）とは別の印

### 4.2 移動の追撃（C）

| 項目 | 内容 |
|---|---|
| 条件 | **段2 以上**のセロが、隊列を動かされたとき（理由を問わない: バサの嵐・追い風・シオの組み替えと緊急退避・ハネ・ヨミの撃破の衝撃ほか） |
| 除外 | **セロ自身の回避による入れ替え**（そちらは既に撃ち返しがある。二重にしない） |
| 効果 | **貫きの矢を1本**撃つ（ダメージ ＝ 現在の攻撃力・状態の矢も乗る） |
| 狙い | セロのいる経路と同じ番号の敵の経路を前から後ろへ（中央のセロは、生きている敵が多い経路・同数なら経路0） |
| 回数 | **1ターンに2回まで** |
| 止まる波 | 粛（第二波）ではターン外の攻撃なので止まる |

- 手番の乱れ撃ち（段2）・回避の撃ち返し（段1から貫き）はそのまま
- 移動の多い編成ほどセロが撃つ＝守りが成功して殴られなくても見せ場が残る

## 7. 予測（Phase 0 の後に数値を入れて実装前にコミット）

- **P1** 版の札を持たない行は 0 セル。V0 は前段の盤面と台本が一致
