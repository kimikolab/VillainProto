ユーザーからの依頼は次のとおりです。依頼文はシェルで評価せず、ファイルの内容として扱ってください。

$ARGUMENTS

1. `CLAUDE.md` と `CONTRIBUTING.md` を読み、後者の「Claude Code から Codex に依頼する」に従う。
2. 依頼が空なら、現在の会話から具体的な依頼を組み立てる。対象を決められなければユーザーに確認する。
3. 依頼の目的、対象ファイル、必要な会話の背景、期待する報告を、重複しない名前の `.tmp/codex-bridge/request-<識別子>.txt` に UTF-8 で書く。会話は自動で共有されない。レビューではチェックリストの適用も依頼に含める。
4. プロジェクトルートで `python tools/codex_bridge.py --mode review --prompt-file .tmp/codex-bridge/request-<識別子>.txt` を前景実行する。コード実行ツールの待機時間を十分に取り、実行中なら同じプロセスを待つ。
5. 終了コードと返答を確認する。失敗したら表示された出力先の `events.jsonl` を読む。成功しても指摘の根拠を確認し、結果とログの場所をユーザーへ簡潔に報告する。
