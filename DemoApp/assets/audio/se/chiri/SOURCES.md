# チリの効果音 v1

2026-11-01。外部音源・学習済み音声モデルを使わないオリジナルの合成音。
作成スクリプト: `design/art/chiri/presentation-assets-v1/make_sounds.py`。
Python標準ライブラリのみ。固定seedで再現する。既存ファイルがあれば上書きせず停止する。

| ファイル | 用途 | 長さ |
|---|---|---:|
| plant.wav | 設置時の軽い金属音 | 0.14秒 |
| fuse.wav | 一撃で導火線が縮む短い火花 | 0.16秒 |
| blast.wav | 低い破裂と短い余韻 | 0.70秒 |
| mirror.wav | 向かいへ抜ける火球 | 0.43秒 |
| dud.wav | 不発の小さな消火音 | 0.22秒 |

すべて48kHz・16bit・mono WAV。ピークは0.85未満。
プレビューでは爆発-13dB、その他-18dBで再生する。爆発音を誘爆先すべてで重ねる場合は、接続時に同時発音数を制限する。
購入済みEffectBlocksシーン内の音声は無効にし、音の二重再生を防ぐ。
